📖 《存在与时间》研读 逐段解析
首页 / 第 026 章 / 片段 012
📜 原文片段 (026/012)
海德格尔 原文
在“设置标志”的活动中，标志特有的用具性质就变得格外清楚了。这种活动是在寻视上的先行视见之中并以这种先行视见为出发点来进行的。这种先行视见需要一种上手的可能性，即能够让当下的周围世界随时通过某种上手事物向寻视呈报出来。但是，世内上手事物的存在具有前面描写过的那种守身自在、裹足不前的性质。因此，在周围世界中的寻视交往就需要一种上手的用具，这种用具的性质就在于能够承担起让上手事物变得触目的“工作”。所以，在制作这种用具〔标志〕的时候必须先考虑到它是否触目。虽然标志是触目的，但人们仍不是让它们随随便便现成存在，它们是为了便于通达而以确定的方式“配置”起来的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 设置标志：指一种人类日常活动，通过制作或放置一个具有特殊指示功能的物体（如路标、记号），来帮助我们在环境中更有效地行动和定向。其核心在于“让事物变得触目”，即凸显其指引作用。

  • 寻视：此在（人）在日常环境中与世界打交道时，所具备的一种非反思的、直接投入的“看”。它不是理论性的观察，而是为了实践目的（如使用工具、到达某处）而对周遭环境的整体把握和导航。

  • 先行视见：在具体的寻视活动之前，此在已经对世界有一种预先的、整体性的理解和预期。它决定了我们“寻找什么”以及“如何与事物相遇”，为所有具体行动提供了背景和方向。

  • 上手事物：指那些在实践活动中，被我们熟练使用、与我们的目的紧密融合而未被专题审视的事物（如熟练使用的锤子）。它们以“不触目”的方式存在，是工具使用的最佳状态。

  • 触目：指上手事物因其“不合用”（如损坏、缺失或作为标志被特意设置）而从其背景中凸显出来，成为我们明确注意的对象。它标志着工具正常使用状态的中断或特定指引功能的启动。

  • 守身自在、裹足不前：这是上手事物在其正常使用状态下的存在方式。它们“守身”于其工具性角色之中，“裹足”于其被使用的目的之内，从而隐匿在背景里，不成为关注的焦点。

  • 配置：指为了特定的实践目的，有意识地将标志安置在环境中的特定位置，以确保其能有效地被看到并发挥指引功能（如在路口设置路牌）。

2. 逐句转译

  1. 原文：在“设置标志”的活动中，标志特有的用具性质就变得格外清楚了。 转译：当我们去“设置一个标志”（比如立一个路牌）时，我们最能看清标志作为一种工具的独特本质。

  2. 原文：这种活动是在寻视上的先行视见之中并以这种先行视见为出发点来进行的。 转译：这个设置标志的行为，并不是盲目的，它源于我们事先对环境的整体把握和行动预期（比如，我们知道人们会迷路，需要指引）。

  3. 原文：这种先行视见需要一种上手的可能性，即能够让当下的周围世界随时通过某种上手事物向寻视呈报出来。 转译：这种预先的把握，需要有一种工具能随时把周围环境的情况“报告”给我们，帮助我们导航。

  4. 原文：但是，世内上手事物的存在具有前面描写过的那种守身自在、裹足不前的性质。 转译：然而，我们日常使用的工具，在它们好用的时候，是“隐身”的，它们完全融入我们的活动背景中，不会跳出来吸引我们的注意。

  5. 原文：因此，在周围世界中的寻视交往就需要一种上手的用具，这种用具的性质就在于能够承担起让上手事物变得触目的“工作”。 转译：所以，为了在环境中顺利行动，我们就需要一种特殊的工具，它的本职工作就是“让事物变得显眼”，把我们的注意力引向需要关注的地方。

  6. 原文：所以，在制作这种用具〔标志〕的时候必须先考虑到它是否触目。 转译：正因如此，我们在设计制作标志时，首先要考虑的就是它够不够显眼，能不能成功吸引目光。

  7. 原文：虽然标志是触目的，但人们仍不是让它们随随便便现成存在，它们是为了便于通达而以确定的方式“配置”起来的。 转译：尽管标志需要显眼，但我们也不是胡乱地把它们放在那里。它们是为了让我们能更便捷地到达目的地，而被有意识、有规划地安置在特定位置的。

3. 论证逻辑梳理

  1. 起点/现象观察：从“设置标志”这一具体活动入手，指出这是理解标志之工具特性的最佳案例。
  2. 前提一：任何实践活动（包括设置标志）都源于一种对世界的“先行视见”（预设和规划）。
  3. 前提二：这种“先行视见”要求有工具能将世界状况“报告”给行动者。
  4. 核心矛盾/转折：然而，普通上手事物的常态是“不触目”的（守身自在），它们隐没在背景中。
  5. 推导出的需求：因此，需要一种特殊工具，其功能恰恰是打破这种“不触目”的状态，主动变得“触目”。
  6. 结论一：因此，标志的本质就是承担“使之触目”的工作。
  7. 结论二：因此，制作标志的核心考量就是其“触目性”。
  8. 最终结论/特征补充：标志的“触目”并非随意，而是为了“便于通达”这一实践目的，被系统地“配置”在环境中。

4. 整体概括

这段话的核心是在探讨“标志”这种特殊工具的哲学本质。海德格尔认为，我们日常使用的大部分工具（如上手的锤子）在最佳状态时是“透明”的，我们专注于任务而不会注意到工具本身。但“标志”（如路牌）恰恰相反，它的存在价值就在于“被注意到”，它的功能就是通过“触目”来中断我们流畅的、不假思索的行动，从而为我们提供指引，重构我们与周围世界的关系。因此，设置标志是一种深思熟虑的实践活动，它基于我们对环境的事先理解（先行视见），通过设计和安置一个足够显眼的物体，来确保我们能高效地到达目的地。标志是工具家族中的一个“异类”，它通过主动凸显自身，来服务于我们更宏大的、隐性的行动网络。

5. 争议与说明

本段解读相对一致。海德格尔对“触目”的分析（标志作为触目状态的积极利用）是他用具整体性理论中一个被广泛接受且较少争议的经典例证。学者们通常聚焦于如何将这一具体分析更精确地整合到他对“世界性”、“上手状态”和“应手状态”等更核心概念的总体论述之中。
