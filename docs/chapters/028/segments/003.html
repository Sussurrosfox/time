海德格尔 原文
笛卡尔把作为res cogitans〔思执〕的ego cogito〔我思〕同res corporea〔肉身或物质实体〕加以区别。这种区别后来在存在论上就规定了“自然与精神”的区别。无论这种对立在存在者层次上是通过多少内容演变才确定下来的，反正这一对立的存在论基础以及对立环节本身都没有得到澄清，之所以未澄清，其最切近根源就在笛卡尔所作的区别之中。他是以何种存在之领会来规定这两种存在者的存在的呢？自在的存在者的存在，称为substantia。这个术语一会儿意指某种作为实体的存在者的存在，即实体性；一会儿则意指这个存在者本身，即实体。Substantia的这种两义性不是偶然的，在。va。这一古代概念中就已有这种两义性。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • res cogitans（思执）：指“思考之物”，即进行思想活动的主体，通常理解为心灵或意识。
  • ego cogito（我思）：笛卡尔哲学的核心概念，指“我思故我在”中的“我思”，即通过思想活动确认自我存在。
  • res corporea（肉身或物质实体）：指具有广延性的物质实体，即身体或物理世界中的物体。
  • 存在论（Ontology）：哲学中研究“存在”本身的学问，探讨事物“是什么”以及它们如何存在。
  • 存在者层次（ontic）：指具体存在的事物或事实层面，关注实际存在的对象及其属性。
  • 存在论基础（ontological foundation）：指支撑某种区分或概念的存在论前提，即从“存在”角度理解的深层依据。
  • Substantia（实体）：拉丁词，指独立自存的基础性存在。在海德格尔语境中，它有时指存在者的“实体性”（存在方式），有时指存在者本身（实体）。

2. 逐句转译

  • “笛卡尔把作为res cogitans〔思执〕的ego cogito〔我思〕同res corporea〔肉身或物质实体〕加以区别。”
    → 笛卡尔将“我思”这一思考主体（心灵）与物质实体（身体）区分开来。

  • “这种区别后来在存在论上就规定了‘自然与精神’的区别。”
    → 这种区分后来在哲学上奠定了“自然”（物质世界）与“精神”（心灵世界）对立的基础。

  • “无论这种对立在存在者层次上是通过多少内容演变才确定下来的，反正这一对立的存在论基础以及对立环节本身都没有得到澄清。”
    → 不管这种对立在具体内容上经历了多少演变，它的存在论根基（为什么这样区分）以及对立双方的本质关系，始终没有被说清楚。

  • “之所以未澄清，其最切近根源就在笛卡尔所作的区别之中。”
    → 问题的直接根源，就在于笛卡尔当初做这个区分时埋下的隐患。

  • “他是以何种存在之领会来规定这两种存在者的存在的呢？”
    → 那么，笛卡尔是用什么样的“存在”理解来定义心灵和物质这两种东西的呢？

  • “自在的存在者的存在，称为substantia。”
    → 他认为，独立自存的事物的存在，就叫作“实体”。

  • “这个术语一会儿意指某种作为实体的存在者的存在，即实体性；一会儿则意指这个存在者本身，即实体。”
    → 但“实体”这个词用法很模糊：有时指存在者的“实体性”（它的存在方式），有时又直接指那个存在者本身（具体的实体）。

  • “Substantia的这种两义性不是偶然的，在οὐσία这一古代概念中就已有这种两义性。”
    → 这种模糊性并非偶然，早在古希腊的“οὐσία”（本质/实体）概念里，就已经有这种双重含义了。

3. 论证逻辑梳理

  • 前提：笛卡尔区分了“我思”（心灵）与“物质实体”，这一区分奠定了后世“自然与精神”对立的基础。
  • 问题提出：尽管这一对立在历史上被广泛接受，但其存在论基础（即为什么这样区分）始终未被澄清。
  • 溯源分析：问题的直接根源在于笛卡尔本人的区分方式——他用以定义心灵和物质的“存在”概念本身有问题。
  • 核心批判：笛卡尔使用的“实体”（substantia）概念存在两义性：既指存在者的“存在方式”（实体性），又指存在者“本身”（实体）。
  • 历史关联：这种模糊性并非笛卡尔的独创，而是继承自古希腊哲学中的“οὐσία”概念。

4. 整体概括

这段文字批评笛卡尔对“心灵”与“物质”的区分，指出这一区分虽然后来成为哲学中“自然与精神”对立的基础，但其存在论根基始终是模糊的。问题的关键在于笛卡尔使用了“实体”这一概念来定义两者的存在，而“实体”一词本身就有双重含义：有时指事物“如何存在”（实体性），有时又指事物“本身”（实体）。这种概念上的混乱并非偶然，而是从古希腊哲学一脉相承下来的老问题。

5. 争议与说明

本段解读相对一致。海德格尔对笛卡尔的批判是《存在与时间》中的经典论述，学界普遍认同他指出的“实体概念两义性”问题。可能的细微争议在于：有人认为海德格尔过于强调笛卡尔的“断裂”，而忽略了中世纪哲学对实体概念的过渡性发展；但就本段而言，核心论点并无重大分歧。
