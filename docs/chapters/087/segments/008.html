📖 《存在与时间》研读 逐段解析
首页 / 第 087 章 / 片段 008
📜 原文片段 (087/008)
海德格尔 原文
带近前来使得“消散于事”的操作和经营成为可能。在带近前来之际，沉沦这一操心的本质结构昭示出来。在沉沦之际并从而也在奠基于“当前”的带近前来之际，有所期待的遗忘跟着当前跳；由此就展示出沉沦的生存论时间性建制。当前化把某种东西从那里带近前来；而在这种当前化中，“那里”被遗忘了，于是当前化失落在它自身之中。于是就有这样的情况：当对世内存在者的“观察”始于这样一种当前化时，便发生出一种假象——“首先”只是一个物现成摆在这里，同时也是不确定地摆在一个一般空间之中。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 消散于事（Zerstreuung）：指此在（人的存在）在日常状态中，将自己的注意力分散、沉浸于各种具体的事务和操作之中，从而失去了对自身存在的整体性把握。在本段中，这是“沉沦”状态的具体表现。
  • 沉沦（Verfallen）：此在的一种非本真存在方式。此在在日常世界中，倾向于逃避自身，将自己交付给“常人”（das Man）的支配，沉浸在世内存在者（事物）之中，从而遗忘了自身的存在问题。
  • 操心（Sorge）：此在存在的整体结构，是“先行于自身—已经在世—依于世内存在者”的统一整体。它描述了此在始终“关心”着自身的存在，并与世界打交道的基本方式。
  • 带近前来（Heranholen）：一种将事物带到眼前，使其成为可被直接操作和观察的时间性行为。它与“当前化”紧密相关，是让事物以“现成在手”方式呈现出来的过程。
  • 当前（Gegenwart）：时间性的一个出位（绽出）维度，指此在投身并专注于“眼前”事物和情境的生存状态。在本段中，它特指一种非本真的“当前化”。
  • 当前化（Gegenwärtigen）：一种非本真的时间化模式，此在将事物仅仅视为“此刻”在场的、可供使用或观察的现成对象，从而切断了事物与未来的可能性（期待）及过去的由来（遗忘）的关联。
  • 生存论时间性（existenziale Temporalität）：不是指我们通常理解的线性、可测量的物理时间，而是此在存在的源始时间结构。它由“将来（先行）”、“曾在（重演）”和“当前（当下即是）”三个出位（绽出）维度动态统一地构成，是此在理解自身和世界意义的基础。
  • 遗忘（Vergessen）：在生存论时间性中，指一种非本真的“曾在”模式。此在遗忘了自身存在的源始可能性和历史性，从而沉溺于当前的“现实”。

2. 逐句转译

  • 带近前来使得“消散于事”的操作和经营成为可能。 我们通过“带近前来”这个动作，把事物拉到眼前，这样才能让我们真正投入并忙碌于各种具体事务之中，也就是进入“消散于事”的状态。

  • 在带近前来之际，沉沦这一操心的本质结构昭示出来。 正是在这种“带近前来”的行为发生时，“沉沦”作为“操心”（我们与生俱来的生存结构）的一个根本特性，就清楚地显现出来了。

  • 在沉沦之际并从而也在奠基于“当前”的带近前来之际，有所期待的遗忘跟着当前跳；由此就展示出沉沦的生存论时间性建制。 当我们处于沉沦状态，以及由此产生的、建立在“当前”这个时间维度上的“带近前来”行为中，会发生一种情况：我们一方面好像有所“期待”（一种非本真的未来指向），但另一方面却又“遗忘”了事物本来的背景和意义，这种“遗忘”紧紧地跟随着、受制于“当前”的节奏。通过这种运作方式，就揭示出了“沉沦”这种状态背后，它所特有的那种扭曲的时间性结构。

  • 当前化把某种东西从那里带近前来；而在这种当前化中，“那里”被遗忘了，于是当前化失落在它自身之中。 “当前化”这个动作，就是把某个东西从它原本所处的“那里”（即它的背景和关联整体）拉到“这里”来。但在这个过程中，那个东西原本所在的“那里”——它的来龙去脉和整体环境——却被我们遗忘了。结果，“当前化”这个行为就仅仅局限和困在了它自己制造出来的这个孤立“当前”里，失去了与更广阔视野的联系。

  • 于是就有这样的情况：当对世内存在者的“观察”始于这样一种当前化时，便发生出一种假象——“首先”只是一个物现成摆在这里，同时也是不确定地摆在一个一般空间之中。 这样一来，就产生了一个后果：当我们用这种“当前化”的方式开始去“观察”世界里的某个东西（世内存在者）时，就会产生一种错觉——我们会觉得，眼前“首先”存在的，只是一个孤零零、赤裸裸的物体，它就这么摆在这里，而且好像是漂浮在一个抽象的、没有具体规定的“一般空间”里。

3. 论证逻辑梳理

  1. 前提：“带近前来”是此在日常与事物打交道的基本方式。
  2. 第一步推进：这种行为揭示了“操心”的本质结构之一是“沉沦”。此在在操作事物时，已经处于一种逃避自身存在的沉沦状态。
  3. 第二步推进：分析沉沦状态的时间性结构。指出在沉沦的“带近前来”（基于“当前”）中，时间性呈现出一种扭曲形态：“有所期待的遗忘”紧跟着“当前”跳动。这意味着，此在看似关注未来（期待），但这种期待是空洞的，因为它建立在对自身历史性和真实可能性的“遗忘”之上。
  4. 第三步推进：具体分析“当前化”的机制。它把事物从其背景（“那里”）剥离出来，但同时遗忘了这个背景，导致自身封闭在孤立、片面的“当前”之中。
  5. 最终结论：这种孤立化的“当前化”是产生传统形而上学“物”的观念的根源。它制造了一种假象，让我们以为首先遇到的只是一个独立的、处在抽象空间中的“现成物”，从而遮蔽了事物最初是在一个意义关联整体（世界）中与我们照面的真相。

4. 整体概括

这段话的核心是在剖析我们日常看待事物的方式背后隐藏的时间性陷阱。海德格尔指出，当我们把事物“带近前来”进行操作时，我们其实已经处在一种“沉沦”的存在状态中。这种状态有一种特定的时间结构：我们过分专注于“眼前”（当前化），为了操作它，我们把事物从它原本的生活背景和意义网络（“那里”）中抽离出来，但同时却遗忘了这个至关重要的背景。这种遗忘使我们被困在孤立、片面的“当下”。于是，当我们以这种方式开始“观察”事物时，就会产生一个根本性的错觉——我们以为我们看到的是一个首先独立存在的、摆在抽象空间里的“物体”。这恰恰掩盖了事物最初总是作为一个有意义的世界的一部分向我们显现的事实。海德格尔在此揭示的是，传统哲学（尤其是笛卡尔以降）将世界视为由“现成物”构成的集合这一观点，其根源就在于这种沉沦的、非本真的时间性体验。

5. 争议与说明

本段解读相对一致，是海德格尔对“沉沦”的时间性分析以及其对传统存在论（将存在者视为“现成物”）批判的核心段落之一。可能的细微讨论点在于对“有所期待的遗忘跟着当前跳”中“期待”一词的理解：它是否仅仅指一种非本真的、对下一个即将到来的“当前”的渴望，还是也隐含了即使在沉沦中，此在也无法完全摆脱“向未来筹划”的时间性结构，只是这种筹划被扭曲了。主流解读倾向于前者，即这是一种空洞的、被“当前”所裹挟的伪期待。
