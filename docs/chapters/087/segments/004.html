📖 《存在与时间》研读 逐段解析
首页 / 第 087 章 / 片段 004
📜 原文片段 (087/004)
海德格尔 原文
在生存论阐释的进程中，此在具有“空间性时间性的”规定，这话不会等于说这一存在者现成存在“在空间中以及时间中”；这一点无须乎赘论了。时间性是操心的存在意义。此在的建构和它去存在的方式在存在论上只有根据时间性才是可能的，无论这一存在者是否摆在“时空中”。于是，此在特有的空间性也就必定奠基于时间性。另一方面，指出这一空间性在生存论上只有通过时间性才可能，这却既非意在从时间中演绎出空间来，也非意在把空间抹灭为纯粹时间。如果说此在的空间性在生存论上被作为基础的时间性所“包纳”，那么这一在下文中将要澄清的联系却也有别于康德意义上的时间优先于空间这种提法。“在空间中”的现成事物的种种经验表象作为心理上出现的事物“在时间中”进行，于是“物理的东西”间接地出现“在时间中”，这种说法并不是对空间之为直观形式进行生存论存在论上的阐释，而是从存在者层次上确认心理上的现成事物“在时间中”一一相续。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 生存论阐释：海德格尔哲学中的核心方法，指从“此在”的实际生存方式和结构出发，来分析其存在意义，而非从传统形而上学的抽象范畴入手。
  • 此在：特指“人”这种存在者，其本质在于“去存在”，即总是处在动态的生存过程中，具有自我理解和筹划的能力。
  • 空间性时间性：此在的存在方式具有空间和时间两个维度。“空间性”并非指物理位置，而是指此在与世界打交道时，通过“去远”（拉近距离）和“定向”（确定方位）等方式所展开的一种生存论空间。“时间性”是此在存在的深层结构，是操心（关心自身存在）的意义所在。
  • 操心：此在的整体存在结构，表现为“先行于自身-已经在世界中-依寓于世内存在者”的统一现象。它描绘了此在始终关心自身存在、投身于世界、并与事物打交道的生存状态。
  • 时间性：操心的存在意义。它是此在理解和筹划自身存在的原初时间视野，由“曾在”、“当前”和“将来”三个维度（即“绽出”）动态统一构成。它不是线性流逝的物理时间，而是使此在的生存成为可能的时间性结构。
  • 现成存在：传统哲学看待存在者的方式，即认为事物是已经完成、固定不变的、摆在时空中的对象。海德格尔强调此在不是“现成存在”。
  • 存在论：探究存在者之“存在”本身的意义和结构的学问。
  • 存在者层次上：指从具体、经验的事实层面来描述存在者，而不触及它们的存在意义。

2. 逐句转译

  1. 原文: “在生存论阐释的进程中，此在具有‘空间性时间性的’规定，这话不会等于说这一存在者现成存在‘在空间中以及时间中’；这一点无须乎赘论了。”

    • 转译: 当我们从生存论的角度来理解人（此在）时，我们说人的存在结构本身就包含着空间性和时间性。但这绝不等于说，人像一张桌子或一块石头那样，是一个已经完工的、摆在物理空间和物理时间里的物件。这一点应该是显而易见的，不需要多说了。

  2. 原文: “时间性是操心的存在意义。此在的建构和它去存在的方式在存在论上只有根据时间性才是可能的，无论这一存在者是否摆在‘时空中’。”

    • 转译: 时间性，是“操心”（即人关心和经营自身存在的整体状态）之所以能够存在的根本意义。人（此在）的整个结构，以及他不断“去成为”、不断筹划未来的生存方式，从哲学根源上讲，只有依托于时间性才有可能。这和这个人是不是在物理时空坐标里完全无关。

  3. 原文: “于是，此在特有的空间性也就必定奠基于时间性。另一方面，指出这一空间性在生存论上只有通过时间性才可能，这却既非意在从时间中演绎出空间来，也非意在把空间抹灭为纯粹时间。”

    • 转译: 因此，人所特有的那种生存论上的空间性（比如我们感觉一个地方“近”或“远”，不仅仅看物理距离，还看心理关联和可达性），它的根基也必然在于时间性。但是，我指出空间性依赖于时间性，目的并不是要用数学或逻辑的方法，从时间这个概念里推导出空间这个概念，也不是要把空间完全还原掉、消解掉，只剩下时间。

  4. 原文: “如果说此在的空间性在生存论上被作为基础的时间性所‘包纳’，那么这一在下文中将要澄清的联系却也有别于康德意义上的时间优先于空间这种提法。”

    • 转译: 即使我们说，人的空间性在生存论上是被更基础的时间性所“包含”或“支撑”的，但这种关系也不同于哲学家康德所说的“时间比空间更优先”那种观点。它们是两回事。

  5. 原文: “‘在空间中’的现成事物的种种经验表象作为心理上出现的事物‘在时间中’进行，于是‘物理的东西’间接地出现‘在时间中’，这种说法并不是对空间之为直观形式进行生存论存在论上的阐释，而是从存在者层次上确认心理上的现成事物‘在时间中’一一相续。”

    • 转译: 像康德那样，认为我们对空间中的物体产生的知觉和印象，是作为心理事件在时间中一个接一个发生的，从而物理世界的东西只是间接地和时间扯上关系——这种说法并不是从生存论和存在论的角度去解释空间（即空间如何作为我们理解世界的一种先天形式）。它只是在经验的、事实的层面上，确认了心理活动（比如一连串的感觉和念头）是在物理时间中依次发生的而已。

3. 论证逻辑梳理

  • 前提1：海德格尔已经确立，此在的存在方式是“操心”，而“时间性”是操心的存在意义。
  • 前提2：此在的存在结构（包括其空间性）必须在生存论框架下理解，而不能还原为物理时空中的现成存在。
  • 核心论证步骤：
    1. 由前提1和前提2推导出：此在的整个建构和生存方式都植根于时间性。
    2. 由此进一步推导出：此在特有的空间性也必然奠基于时间性。
    3. 关键澄清：明确指出这种“奠基于”的关系，并非传统哲学（如数学推导或观念论）意义上的演绎或还原，也不是要取消空间的独立性。
    4. 划界：进一步将自己的观点与康德的观点划清界限。康德的“时间优先于空间”是在认识论和心理发生的层面上讲的（表象在时间中相续），而海德格尔的“空间性奠基于时间性”是在生存论-存在论的层面上讲的（空间性作为此在在世存在的一种方式，其可能性条件在于时间性）。
  • 结论：此在的空间性具有生存论性质，它根源于更原初的时间性，但这是一种存在论上的奠基关系，不同于康德的认识论优先性。

4. 整体概括

这段文字的核心目的是在生存论框架下，厘清此在的“空间性”与“时间性”之间的关系。海德格尔强调，当我们说人是“空间性时间性的”存在时，绝不是在说人像物体一样存在于物理时空坐标中。他重申，时间性是人的存在（操心）的根本意义，人的所有生存活动，包括他对空间的体验和理解，都只有从时间性出发才可能。因此，人所特有的那种空间感（比如感到家“近”而远方“远”）是植根于时间性的。但他立刻划清界限：这绝非要用时间“推导”出空间或吞并空间，也完全不同于康德那种认为时间比空间更基本（因为所有心理表象都在时间中）的认识论观点。康德的讨论停留在经验心理事实的层面，而海德格尔探讨的是使空间性得以可能的、更深层的存在论基础——时间性。

5. 争议与说明

本段解读相对一致。核心争议点通常不在于这段文字本身，而在于对海德格尔“空间性奠基于时间性”这一命题在整个哲学计划中的重要性及其后果的理解。一种常见的质疑是：这是否过于强调时间而轻视了空间在人类经验中的原初性？海德格尔后期思想对空间（如“栖居”、“地方”）的强调，有时被视为对《存在与时间》中这种“时间中心论”的一种修正或平衡。但就本段而言，他的主要意图是方法论上的划界，即阐明他的生存论-存在论进路与康德式先验哲学进路的根本区别。
