📖 《存在与时间》研读 逐段解析
首页 / 第 081 章 / 片段 018
📜 原文片段 (081/018)
海德格尔 原文
将来、曾在与当前显示出“向自身”、“回到”、“让照面”的现象性质。“向…”、“到…”、“寓于…”等现象干干脆脆地把时间性公开为〔站出去，绽出〕。时间性是源始的、自在自为的“出离自身”本身。因而我们把上面描述的将来、曾在、当前等现象称作时间性的绽出。时间性并非先是一存在者，而后才从自身中走出来；而是：时间性的本质即是在诸种绽出的统一中到时。流俗领会所通达的“时间”的种种特性之一恰恰就在于：时间被当作一种纯粹的、无始无终的现在序列，而在这种作为现在序列的时间中，源始时间性的绽出性质被敉平了。而敉平绽出性质这件事本身，按其生存论意义来看，却又奠基在某一种确定的可能的到时之中，时间性依照这种到时而作为非本真的时间性使上面提到的“时间”到时。因而，如果表明了此在的知性所通达的“时间”不是源始的，而毋宁是源自本真的时间性的，那么，依照apotiori fit denominatio〔根据主要事实命名〕这一原则，把现已崭露的时间性称为源始的时间就是合情合理的了。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 时间性：海德格尔哲学中的核心概念，指此在（人的存在）的根本时间结构。它不是客观的、可测量的物理时间，而是此在自身展开的存在方式。其本质是“出离自身”，即不断超越当下状态、在时间维度上动态展开。
  • 绽出：时间性的基本特征，意为“站出去”或“超越自身”。时间性不是静止的，而是通过将来、曾在、当前这三个维度不断地“向外展开”，形成一个动态的统一体。
  • 到时：时间性的实现方式，指时间性在具体的存在活动中“成为时间”或“实现自身”。时间性总是通过某种方式“到时”，从而展现出不同的时间形态（如本真或非本真）。
  • 流俗领会的时间：日常生活中人们对时间的普遍理解，即把时间看作一条由无数“现在”点组成的、均匀流逝的线性序列。这种时间观掩盖了时间性的源始动态结构。
  • 本真/非本真时间性：本真时间性是此在直面自身有限性、在决断中统一把握过去、现在、未来的时间体验；非本真时间性则是此在沉溺于日常琐事、将时间视为现成序列的逃避状态。

2. 逐句转译

  • “将来、曾在与当前显示出‘向自身’、‘回到’、‘让照面’的现象性质。”
    → 将来、过去和现在这三个时间维度，分别表现出“朝向自身未来可能性”、“回到已有的经历”和“让事物在当下呈现”这些现象特征。

  • “‘向…’、‘到…’、‘寓于…’等现象干干脆脆地把时间性公开为〔站出去，绽出〕。”
    → 这些“朝向…”、“到达…”、“沉浸于…”的现象，直接揭示了时间性的本质就是“不断向外展开、超越自身”。

  • “时间性是源始的、自在自为的‘出离自身’本身。”
    → 时间性从根本上说，就是一种本源的、独立自足的“不断超越自身”的运动。

  • “因而我们把上面描述的将来、曾在、当前等现象称作时间性的绽出。”
    → 因此，我们将来来、过去、现在这些时间维度称为时间性的“绽出”，即它们都是时间性向外展开的不同方式。

  • “时间性并非先是一存在者，而后才从自身中走出来；而是：时间性的本质即是在诸种绽出的统一中到时。”
    → 时间性并不是先作为一个固定的东西存在，然后再向外运动；相反，它的本质就是在将来、过去、现在这三种绽出的统一体中“实现为时间”。

  • “流俗领会所通达的‘时间’的种种特性之一恰恰就在于：时间被当作一种纯粹的、无始无终的现在序列，而在这种作为现在序列的时间中，源始时间性的绽出性质被敉平了。”
    → 日常理解中的“时间”有一个典型特征：它被看作一条纯粹由“现在”瞬间连成的、无始无终的线。在这种线性时间观中，源始时间性那种动态展开的特性被抹平、被掩盖了。

  • “而敉平绽出性质这件事本身，按其生存论意义来看，却又奠基在某一种确定的可能的到时之中，时间性依照这种到时而作为非本真的时间性使上面提到的‘时间’到时。”
    → 但这种“抹平绽出性质”的现象，从生存论的角度看，其实也根源于时间性的一种特定实现方式——时间性通过这种“非本真”的实现方式，使得前面提到的那种日常线性时间得以呈现。

  • “因而，如果表明了此在的知性所通达的‘时间’不是源始的，而毋宁是源自本真的时间性的，那么，依照apotiori fit denominatio〔根据主要事实命名〕这一原则，把现已崭露的时间性称为源始的时间就是合情合理的了。”
    → 因此，如果我们能够证明日常理智所理解的那个“时间”并非本源，而是从本真时间性中衍生出来的，那么按照“根据本质命名”的原则，将我们刚刚揭示出的这种时间性称为“源始时间”就是完全合理的。

3. 论证逻辑梳理

前提：时间性的三个维度（将来、曾在、当前）分别对应“向自身”、“回到”、“让照面”的动态现象。
推进1：通过这些动态特征，直接指出时间性的本质就是“绽出”——不断出离自身。
推进2：强调时间性并非先存在后运动，其本质就是在三种绽出的统一中“到时”（实现为时间）。
对比与批判：指出日常理解的线性时间（“现在序列”）是对源始时间性绽出特性的“敉平”（掩盖与简化）。
深层分析：即使这种“敉平”现象，本身也源于时间性的一种特定实现方式——非本真的到时。
结论：既然日常时间是衍生的，而时间性是更本源的，那么将时间性称为“源始时间”是合理的。

4. 整体概括

这段话的核心是在界定海德格尔的“时间性”概念，并将其与流俗的时间观进行对比。海德格尔认为，真正源始的时间（时间性）并非一条由“现在”点连成的直线，而是此在的一种动态存在结构——它通过“将来”（朝向可能性）、“曾在”（承担历史）、“当前”（与事物照面）这三个维度不断地“绽出”，即超越自身、向外展开。我们日常生活中那种均匀流逝的线性时间，其实是这种源始时间性的一种退化形态（非本真到时），它掩盖了时间固有的动态性和超越性。因此，从根源上说，只有这种不断“绽出”的时间性，才配称为真正的、源始的时间。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“非本真到时”与“流俗时间”关系的理解：一种解读强调非本真到时是流俗时间的生存论基础；另一种则认为流俗时间是对非本真时间性的某种“物化”或“对象化”表达。但核心论点——时间性是源始的，流俗时间是衍生的一一在学界是共识。
