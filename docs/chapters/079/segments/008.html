📖 《存在与时间》研读 逐段解析
首页 / 第 079 章 / 片段 008
📜 原文片段 (079/008)
海德格尔 原文
此在的存在中包含有自身解释。在寻视操劳地揭示“世界”之际，操劳活动本身也被一道视见。此在实际上总已经在某些确定的生存的可能性中领会自己，即使诸种筹划可能只不过生自常人的知性也罢。无论明确与否，合适与否，生存总已经以某种方式被一道领会着。一切存在者层次上的领会都有其“暗含的东西”，即使这些东西还只是前存在论的，亦即未作为理论专题加以理解的。一切在存在论上明确提出的询问此在存在的问题都已通过此在的存在方式有所预备。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：指人的存在方式，特指那种能够反思自身存在、对存在发问的存在者。此在的本质在于它的“生存”，即它总是通过筹划和选择来实现自己的可能性。

  • 自身解释：此在对自身存在的理解和阐释。这不是一种理论反思，而是在日常活动中自然而然发生的、对自己“如何存在”的领会。

  • 寻视操劳：此在在日常世界中与事物打交道的基本方式。这是一种非主题化的、实用性的关注，比如我们使用锤子时不会思考“锤子是什么”，而是直接投入“敲打”这个活动中。

  • 世界：不是物理宇宙的集合，而是此在生活于其中、与事物产生意义关联的整体境域。是此在“居住”并与之互动的意义网络。

  • 生存：此在特有的存在方式，意味着此在总是“去存在”，总是在实现自己的可能性，而非像石头那样仅仅“现成存在”。

  • 领会：此在对其存在可能性的基本把握。不是认知上的理解，而是更原初的、在行动中展现的对“我能如何”的觉知。

  • 常人：指日常生活中非本真的存在模式，此在沉浸于公众意见和惯例中，失去了对自身存在的独特把握。

  • 存在者层次上的领会：在具体生活中对事物的实际理解，尚未上升到哲学反思层面。

  • 前存在论的：在系统的哲学思考之前，已经在日常生活中运作的理解。

  • 存在论：对存在本身的研究，追问“存在何以如此”的根本问题。

2. 逐句转译

  • “此在的存在中包含有自身解释。” → 人这种存在者的一个根本特点，就是它总是会对自己“如何活着”有所理解和阐释。

  • “在寻视操劳地揭示‘世界’之际，操劳活动本身也被一道视见。” → 当我们在日常生活中忙着做事情（比如工作、交往）并由此理解我们周围的世界时，我们对自己正在进行的这些活动本身，也会有一种伴随性的觉察。

  • “此在实际上总已经在某些确定的生存的可能性中领会自己，即使诸种筹划可能只不过生自常人的知性也罢。” → 实际上，人总是已经在某些具体的生活方式（比如成为医生、或按照社会常规生活）中理解着自己了，哪怕这些人生规划仅仅是来自社会大众的普通见解。

  • “无论明确与否，合适与否，生存总已经以某种方式被一道领会着。” → 不管这种自我理解是清晰还是模糊，是恰当还是扭曲，人对自己的“活着”总已经有了某种方式的把握。

  • “一切存在者层次上的领会都有其‘暗含的东西’，即使这些东西还只是前存在论的，亦即未作为理论专题加以理解的。” → 所有在生活中产生的具体理解，都包含着一些没有明说出来的前提。这些前提虽然还停留在生活实践的层面，没有成为哲学思考的明确主题，但它们已经在那里了。

  • “一切在存在论上明确提出的询问此在存在的问题都已通过此在的存在方式有所预备。” → 因此，所有那些在哲学上被明确提出的、关于“人这种存在者究竟为何”的根本问题，其实都已经被人在其日常的存在方式中预先准备好了基础。

3. 论证逻辑梳理

  • 前提1：此在的本质包含自身解释（它是一个自我阐释的存在者）。
  • 前提2：此在通过日常活动（寻视操劳）与世界互动，并在互动中同时觉察到自身。
  • 推进1：由此指出，此在总是在具体的生存可能性中（哪怕是随大流的方式）理解着自己。这种理解是始终伴随的、先于反思的。
  • 推进2：进而论证，这种日常层面的理解（存在者层次上的领会）并非空无一物，它内部已经“暗含”了对存在的某种把握，只是尚未被主题化（前存在论的）。
  • 结论：因此，所有后来的、系统化的哲学追问（存在论问题），其根基和可能性都早已植根于此在最初的、前哲学的存在方式之中。哲学问题并非凭空产生，而是从生活本身中“生长”出来的。

4. 整体概括

这段话的核心意思是：人这种存在者，从最日常的生活开始，就在不断地理解和解释着自己的存在。我们在做事、与人交往的过程中，不仅熟悉了世界，也同时对自己“如何活着”有了一种或明或暗的觉察。哪怕我们的活法只是遵循社会惯例，这也是一种自我理解。这种在日常生活中运作的理解，虽然还不是系统的哲学理论，但它内部已经包含了关于“存在”的朴素领会。正因如此，后来那些深刻的哲学问题（比如“人是什么？”），并不是突然冒出来的，它们的种子早已埋藏在人最本初的生活实践之中了。海德格尔想强调的是，哲学的高楼并非建于空中，它的地基就是我们每个人最寻常不过的生活本身。

5. 争议与说明

本段解读相对一致。核心论点——即存在论问题源于此在的前存在论领会——是海德格尔基础存在论的核心支柱，学界对此框架本身争议不大。可能的细微讨论点在于对“前存在论”与“存在论”之间界限的刻画，但这段文本本身表述清晰，没有产生重大分歧。
