📜 原文片段 (012/003)
海德格尔 原文
存在的意义问题是最普遍最空泛的问题。但追问这个问题却也可能把这个问题本己地、最尖锐地个别化于每一此在本身。赢获“存在”这一基本概念，草描出这一概念所要求的概念方式及这一方式的种种必然演变，这些工作需要一条具体的指导线索。存在概念的；普遍性不排斥探索的“特殊性”；这种“特殊性”就是：通过对某种存在者即此在特加阐释这样一条途径突入存在概念。因为我们在此在中将能赢获领会存在和可能解释存在的视野。但这个存在者本身是“历史的”，所以，以最本己的方式从存在论上对这一存在者透彻地进行解说就必然成为一种“历史学的”解释。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 存在（Sein）：在海德格尔哲学中，“存在”不是指具体某个东西（存在者），而是指使得一切存在者得以“存在起来”的那个过程、状态或可能性本身。它是最基本、最普遍的问题，但通常隐而不显。

  • 此在（Dasein）：特指“人”这种存在者。此在的独特之处在于，它能够追问自己的存在，并对“存在”有所领会。它不是一般的“主体”，而是总已经在世界之中、关心自身存在的“在世之在”。

  • 存在论（Ontologie）：传统上指研究“存在”本身的哲学分支。海德格尔的存在论则是通过分析此在的生存结构，来揭示存在意义的一种探究方式。

  • 历史学的（historisch）：此处并非指一般编年史研究，而是强调此在的存在本质上是时间性的、历史性的——此在总是已经在某个历史情境中展开其可能性，并通过对自身历史性的理解来通达存在。

2. 逐句转译

  • “存在的意义问题是最普遍最空泛的问题。”
    → 追问“存在”的意义，这个问题范围最广、听起来也最抽象，似乎跟每个人的具体生活没什么直接关系。

  • “但追问这个问题却也可能把这个问题本己地、最尖锐地个别化于每一此在本身。”
    → 但当我们真正去追问它时，这个问题就会变得非常切身、非常紧迫，它会成为每一个“此在”（也就是每一个人）自己的问题。

  • “赢获‘存在’这一基本概念，草描出这一概念所要求的概念方式及这一方式的种种必然演变，这些工作需要一条具体的指导线索。”
    → 要想弄清楚“存在”这个概念，并描绘出理解它的方法和这种方法必然会经历的演变过程，我们需要一个明确的切入点。

  • “存在概念的普遍性不排斥探索的‘特殊性’；这种‘特殊性’就是：通过对某种存在者即此在特加阐释这样一条途径突入存在概念。”
    → 虽然“存在”是个很普遍的问题，但这并不妨碍我们从一种特殊的角度去研究它——这个特殊角度就是：通过深入分析“此在”（人）这种特殊的存在者，来切入“存在”问题。

  • “因为我们在此在中将能赢获领会存在和可能解释存在的视野。”
    → 因为正是在此在身上，我们能够找到理解和解释“存在”所需要的那个视角。

  • “但这个存在者本身是‘历史的’，所以，以最本己的方式从存在论上对这一存在者透彻地进行解说就必然成为一种‘历史学的’解释。”
    → 但此在的存在本身就是历史性的（它总已经在时间与历史情境中展开），因此，要真正透彻地从存在论上解说此在，就不得不采取一种“历史学的”解释方式——也就是把此在放到它的历史境遇中去理解。

3. 论证逻辑梳理

  • 前提：存在的意义问题虽然普遍而空泛，但可以通过“个别化”成为每一个此在的切身问题。
  • 推进1：要探讨存在，需要一个具体的指导线索，不能仅停留在空泛的普遍性上。
  • 推进2：这个线索就是从此在（人）入手，因为此在是唯一能领会和解释存在的存在者。
  • 结论：由于此在本身是历史性的，对它的存在论分析必然也是历史学的解释——存在意义的问题必须放在此在的历史性生存中展开。

4. 整体概括

这段文字是《存在与时间》的方法论总纲。海德格尔指出：虽然追问“存在”听起来很抽象，但它其实是我们每个人最切身的问题。他主张，不能直接从空洞的“存在”概念出发，而必须从一个具体的入口切入——这个入口就是“此在”，也就是人。因为只有人这种存在者会关心“存在”是什么意思，并且能够在自己的生存中领会它。而由于人本质上是一种历史性的存在（总活在具体的历史情境中，带着过去的痕迹、面向未来而生存），所以，要真正理解存在，就必须采取一种“历史学的”解释方法，从人的历史性生存入手，揭示存在的意义。

5. 争议与说明

本段是《存在与时间》“导论”部分的核心段落，学界解读相对一致。可能的细微争议在于：海德格尔强调通过“此在”通达“存在”，这是否会导致一种“人类中心主义”的解读？但主流观点认为，海德格尔恰恰是要避免传统主体哲学的人类中心倾向——他通过此在的“历史性”与“被抛境况”，恰恰是要说明此在并非世界的主宰，而是始终已经在世界与历史之中展开的存在者。
