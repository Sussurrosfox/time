📖 《存在与时间》研读 逐段解析

📜 原文片段 (078/014)
海德格尔 原文
如果决心作为本真的决心趋向于由先行加以界说的样式而先行造就了此在的本真的整体能在，那么在从生存上得以见证的决心中就有此在的一种本真的整体能在一道得以见证。整体能在的问题是一个实际的生存的问题。此在作为下了决心的此在对这个问题加以回答。此在的整体能在问题在开始时显示出来的性质似乎是：这个问题仅仅是此在分析工作的一个理论和方法问题，源自那为达到整体此在的某种充分的“给予状态”而作的努力。现在，这个问题完全脱除了这种性质。开始只从存在论方法论上讨论此在整体性问题自有其道理，但这只因为这道理的根据是回归到此在的一种存在者层次上的可能性之上的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 决心 (Entschlossenheit)：在海德格尔哲学中，决心指此在（人）本真地面对自身存在，清醒地承担起自己的生存可能性，并在行动中做出决断的状态。它不是指日常意义上的“下定决心做某事”，而是此在摆脱常人（das Man）的支配，回归自身本真存在的核心方式。
  • 本真 (eigentlich)：指此在真实地面对自己的存在，清醒认识到自身是被抛入世界的、有限的、面向死亡的存在，并主动承担起自身的生存可能性，而非随波逐流地活在“常人”的匿名状态中。
  • 整体能在 (Ganzseinkönnen)：此在作为一种“能是”的存在者，其全部生存可能性的整体。由于此在始终“尚未”完成（直至死亡），整体能在就是此在面向死亡、统合了其全部可能性的本真生存结构。
  • 先行 (Vorlaufen)：此在主动地、本真地“跑向”其最本己的可能性——死亡，并在这种面向终结的视野中理解和筹划自身整体存在的方式。
  • 生存 (Existenz)：此在特有的存在方式，即它并非现成存在，而是不断地“去存在”，在其可能性中筹划和实现自身。
  • 存在论 (ontologisch)：关于存在本身的结构和意义的研究。
  • 存在者层次上 (ontisch)：指实际存在着的、具体事实层面的状态。

2. 逐句转译

  • “如果决心作为本真的决心趋向于由先行加以界说的样式而先行造就了此在的本真的整体能在...”
    → 如果此在的本真决心，是通过“先行到死”这种方式，主动构建出了此在的本真整体能在（即清醒地、完整地面对自己的全部生存可能性）...

  • “那么在从生存上得以见证的决心中就有此在的一种本真的整体能在一道得以见证。”
    → 那么，在实际生存中能够被观察到的决心行为里，此在的这种本真整体能在也就一同被展现出来了。

  • “整体能在的问题是一个实际的生存的问题。”
    → 所以，整体能在的问题不是一个理论空谈，而是此在必须实际面对和回答的生存问题。

  • “此在作为下了决心的此在对这个问题加以回答。”
    → 唯有当此在处于本真决心状态时，它才能真正回应这个问题。

  • “此在的整体能在问题在开始时显示出来的性质似乎是：这个问题仅仅是此在分析工作的一个理论和方法问题，源自那为达到整体此在的某种充分的‘给予状态’而作的努力。”
    → 在哲学分析的开端，整体能在问题看起来只是一个理论和方法论问题，好像只是为了在概念上完整把握此在而提出的。

  • “现在，这个问题完全脱除了这种性质。”
    → 但现在我们看到，它完全不是这么回事。

  • “开始只从存在论方法论上讨论此在整体性问题自有其道理，但这只因为这道理的根据是回归到此在的一种存在者层次上的可能性之上的。”
    → 起初从哲学方法论角度探讨整体性是必要的，但这种方法论之所以成立，其根基恰恰在于此在在实际生存中（存在者层次上）本就具备实现本真整体能在的可能性。

3. 论证逻辑梳理

  • 前提：本真的决心通过“先行到死”构建了此在的本真整体能在。
  • 核心推进1：由前提直接推导出，在实际的决心现象中，此在的本真整体能在是“一同被见证”的。这表明整体能在并非遥不可及的理论构想，而是在决心这种生存态度中可被亲身体验和确认的现实。
  • 核心推进2：基于此，论证扭转了问题的性质。整体能在问题从“一个理论和方法问题”转变为“一个实际的生存问题”。哲学分析（存在论探讨）的起点看似是理论的，但其有效性和意义最终根植于此在实际生存中（存在者层次上）实现本真存在的可能性。方法论（如何认识）服务于生存实际（如何存在）。
  • 结论：整体能在问题的本质是生存实践的，而非纯理论的。存在论的方法论探讨之所以可能和必要，是因为此在本身在生存上就有实现整体能在的可能性。

4. 整体概括

这段话的核心在于阐明“此在的整体能在”这一问题的性质转变。海德格尔指出，当我们深入探究“决心”这一本真生存状态时，会发现此在的本真整体能在并非一个需要从外部去拼凑或理论上证明的难题，而是在决心这种生存态度中直接展现出来的。因此，关于整体能在的问题，本质上是一个此在必须亲身去回答和承担的“生存实践问题”，而不是哲学家在书斋里构想的“理论方法问题”。他进一步强调，哲学上（存在论上）对整体性的方法论探讨之所以有意义，其根基恰恰在于此在在实际生活（存在者层次上）本就拥有实现这种本真整体性的潜能。理论探讨是为理解生存实践服务的。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“存在论方法论”与“存在者层次上的可能性”之间关系的理解。最主流的解读（如前文所示）认为，海德格尔是在强调存在论研究（理论）的根基在于生存实际（实践）。另一种解读可能更侧重两者的循环关系：存在论分析揭示了此在生存的可能性，而这种可能性又反过来要求并证实了存在论分析的正当性。但两种解读都认同本段的核心在于将整体能在问题从理论层面拉回生存实践层面。
