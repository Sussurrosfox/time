📖 《存在与时间》研读 逐段解析
首页 / 第 078 章 / 片段 016
📜 原文片段 (078/016)
海德格尔 原文
先行的决心并非一条逃路，发明出来以便“克服”死：它是追随着良知呼声的领会，这一领会向死开放出将去掌握生存的可能性和把一切逃遁式的自身遮蔽彻底摧毁的可能性。被规定为向死存在的愿有良知也不意味着遁世的决绝，相反却毋宁意味着无所欺幻地投入“行动”的决心。先行的决心也不是来自某种高飞在生存及其可能性之上的“理想主义”期求，而是源自对此在诸实际的基本可能性的清醒领会。清醒的畏〔把此在〕带到个别化的能在面前，坦然乐乎这种可能性。坦荡之乐与清醒的畏并行不悖。在这坦荡之乐中，此在摆脱了求乐的种种“偶然性”，而忙忙碌碌的好奇首要地是从诸种世事中为自己求乐的。不过，对以上种种基本情绪的分析超出了基础存在论目标为目前阐释所划的限度。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 先行的决心：指此在（人的存在）在直面自身死亡的前提下，对自身最本己可能性的一种清醒、主动的承担和决断。它不是逃避，而是主动迎向死亡这一最极端的可能性，从而真正掌握自己的生存。
  • 良知呼声：在海德格尔哲学中，良知并非道德良知，而是此在从沉沦于常人状态中被唤醒，呼唤其回归自身、面对自身最本己可能性的内在声音。
  • 向死存在：此在的一种存在方式，即清醒地认识到死亡是自身无法逾越、必然降临的终极可能性，并将这种认识融入生存的整体筹划中。
  • 畏：一种基本情绪，它不同于对具体事物的“怕”，而是此在面对自身存在之虚无与不确定性的深层不安。清醒的畏能使人从日常的沉沦中抽离，直面自身本己的能在。
  • 能在：此在的核心特征，即它永远是一种“能够去存在”、面向未来各种可能性的存在者。
  • 坦荡之乐：在清醒地畏并决心承担自身能在时，此在体验到的一种解脱与自由之乐。它并非感官享乐，而是从日常琐碎追求的束缚中解放出来的安宁与开阔。
  • 基础存在论：海德格尔在《存在与时间》中的核心任务，旨在通过分析此在的存在结构，来追问“存在”本身的意义。

2. 逐句转译

  • “先行的决心并非一条逃路，发明出来以便‘克服’死”：先行的决心并不是一种为了逃避或精神上“战胜”死亡而想出来的办法。
  • “它是追随着良知呼声的领会，这一领会向死开放出将去掌握生存的可能性和把一切逃遁式的自身遮蔽彻底摧毁的可能性”：它是此在听从内心良知呼唤后的一种深刻理解。这种理解因为直面死亡，反而为我们打开了真正掌握自己人生的可能性，并且彻底摧毁了所有试图逃避、掩耳盗铃式的自我欺骗。
  • “被规定为向死存在的愿有良知也不意味着遁世的决绝，相反却毋宁意味着无所欺幻地投入‘行动’的决心”：即便是被理解为“直面死亡、愿意听从良知”的状态，也并不意味着要悲观厌世、与世隔绝；恰恰相反，它意味着一种不带任何幻觉、脚踏实地投入到现实行动中的决心。
  • “先行的决心也不是来自某种高飞在生存及其可能性之上的‘理想主义’期求，而是源自对此在诸实际的基本可能性的清醒领会”：这种先行的决心，也不是源于那种高高在上、脱离现实的理想主义空想，而是来自于对我们自身所拥有的、实实在在的各种根本可能性的清醒认识。
  • “清醒的畏〔把此在〕带到个别化的能在面前，坦然乐乎这种可能性”：当我们处于清醒的“畏”这种情绪中时，我们就被带到了自己那个独一无二、必须由自己承担的人生可能性面前，并且能够坦然甚至愉悦地接受这种可能性。
  • “坦荡之乐与清醒的畏并行不悖”：这种因坦荡而生的快乐，和清醒的畏是同时存在、互不矛盾的。
  • “在这坦荡之乐中，此在摆脱了求乐的种种‘偶然性’，而忙忙碌碌的好奇首要地是从诸种世事中为自己求乐的”：在这种坦荡之乐中，人摆脱了那些依赖于外界偶然事件（比如得到什么、看到什么新鲜事）的浅层快乐；而日常生活中那种忙于追逐新奇事物的“好奇”，主要就是从这些外在世事中为自己寻找乐趣。
  • “不过，对以上种种基本情绪的分析超出了基础存在论目标为目前阐释所划的限度”：不过，关于“畏”、“坦荡之乐”这些更深层情绪的分析，已经超出了当前基于基础存在论目标的讨论范围。

3. 论证逻辑梳理

  • 前提：存在一种被称为“先行的决心”的存在状态。
  • 核心论证与澄清： 1. 首先，作者澄清了对“先行的决心”可能的两种误解：它不是逃避死亡的工具（第一句），也不是脱离现实的遁世态度（第三句）。 2. 接着，正面界定其来源与本质：它源于对良知呼唤的领会（第二句），根植于此在对其实际可能性的清醒认识，而非空想（第四句）。 3. 然后，引入“清醒的畏”这一关键情绪，说明其功能是将此在带向其本己的“能在”，并伴随有“坦荡之乐”（第五、六句）。 4. 进一步对比：将“坦荡之乐”与沉沦于日常世界中所追求的偶然、表面的快乐（“好奇”之乐）区分开来（第七句）。
  • 结论/界限说明：最终指出，对这些基本情绪的深入分析超出了当前章节的任务范围（第八句），为后续探讨留下空间。

4. 整体概括

这段话的核心在于澄清“先行的决心”这一重要概念的真正内涵。海德格尔强调，先行的决心绝非一种消极的、用来逃避或克服死亡恐惧的心理策略，也不是要人离群索居。恰恰相反，它是一种最积极、最清醒的生存态度：通过听从良知，勇敢地直面人终有一死这一事实，从而将自己从随波逐流、自我欺骗的日常状态中解放出来。这种直面带来了一种深刻的清醒（“畏”），它让人看到自己必须独自承担的生命可能性，并在此基础上去果断地行动。伴随这种清醒的，并非痛苦，而是一种摆脱了外在偶然因素束缚的、深刻的自由与安宁（“坦荡之乐”）。这整个过程，都是建立在对人生实际可能性的踏实理解之上，而非任何虚浮的理想主义。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“坦荡之乐”的理解：有学者可能更强调其与“畏”一体两面的紧张关系，认为“乐”并非通常意义上的愉悦，而是在承担命运时的释然与自由感；而另一些解读可能更倾向于将其视为一种积极的、近乎斯多葛式的内在宁静。但总体上都认同这是直面本真生存时的一种解放性体验。
