海德格尔 原文
但此在又同样源始地在不真之中。先行的决心同时给予此在对其封闭状态的源始确知。此在先行地下了决心，从而就对持驻的、基于本己存在就可能的失落于常人的无决心状态保持其敞开。无决心状况作为此在的持驻的可能性被万道砂知。决心对其本身是透彻的；决心领会到：能在的不确定性只有在面向当下处境的决定中才能使自己得到规定。决心对自始至终统治着那一生存着的存在者的不确定性有所知。但若这种知要与本真的决心相应，它自身就必须源自一种本真地作出决定的活动。本己能在的不确定性—虽然能在在决定中向来已变成确知的——只有在向死存在中才整体地公开出来。先行活动把此在带到一种可能性面前：这种可能性持驻地是确知的；然而就可能性何时变为不可能而言，这种可能性却时时刻刻保持其为不确定的。这种可能性公开出：这一存在者被抛入了它的“极限处境”的不确定性之中；此在因面对这种“极限处境”下决心而赢得其本真的整体能在。死的不确定性在畏中源始地开展自身。这一源始的畏则又趋进于期求自身下决心。畏把加在此在委弃于其自身这一状况之上的一切遮蔽都加清除。畏是对无的畏，“无”绽露出在此在的根据处规定此在的不之状态，而这根据本身则作为被抛入死的状况而存在。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学中的核心概念，指“人的存在”或“在世存在”，是一种能够发问、理解自身存在的存在者。在本段中，此在指的就是那个能够进行“决心”和“面对死亡”的具体个体。

  • 不真/封闭状态：不真并非指“错误”，而是此在的一种日常存在方式——沉沦于“常人”的闲谈、好奇与模棱两可之中，从而遮蔽了本己的能在。封闭状态就是这种自我遮蔽、逃避本真自我的生存状态。

  • 决心：此在的一种本真存在方式。它不是指日常的“做决定”，而是此在清醒地面对自身被抛的有限性，承担起自己的存在，并向着最本己的能在（可能性）展开行动。

  • 先行/向死存在：此在通过预先领会并直面其最极端的可能性——死亡——来把握自身整体存在的方式。这种“先行到死”不是消极的等死，而是通过体认死亡的确定性与不确定性，激发出对有限生命的本真承担。

  • 无决心：此在逃避自身、沉沦于“常人”的公共意见，放弃为自己作出本真选择的生存状态。它是此在一种持久存在的可能性。

  • 畏：一种基本的情绪体验。不同于对具体事物的“怕”，畏是对“无”的体验，它让此在直面自身被抛入世界的偶然性与有限性，从而从常人世界中脱身，回到本真的自我。

  • 不之状态：此在存在论结构中的否定性、有限性维度。它意味着此在的存在本质上包含着“无”——死亡、不确定性、有限性——正是这种“不”构成了此在的根据。

2. 逐句转译

  • “但此在又同样源始地在不真之中。先行的决心同时给予此在对其封闭状态的源始确知。”

  • 人的存在从一开始就同时处在自我遮蔽（沉沦）的状态中。但当他通过“向死存在”而变得本真时，他也就对自己之前的封闭状态有了最根本的清醒认识。

  • “此在先行地下了决心，从而就对持驻的、基于本己存在就可能的失落于常人的无决心状态保持其敞开。”

  • 当人本真地面对死亡并决心承担自己时，他就能持续地对那种随时可能发生的、沉沦于大众庸常生活的非本真状态保持警醒和开放。

  • “无决心状况作为此在的持驻的可能性被万道砂知。决心对其本身是透彻的；决心领会到：能在的不确定性只有在面向当下处境的决定中才能使自己得到规定。”

  • 本真的决心清楚地知道，逃避自我的状态是人一直都有可能陷入的。决心是自我透明的：它明白，人那充满不确定性的“可能性”，只有在每一个具体的、当下的抉择中才能真正成形和实现。

  • “决心对自始至终统治着那一生存着的存在者的不确定性有所知。但若这种知要与本真的决心相应，它自身就必须源自一种本真地作出决定的活动。”

  • 决心深刻地理解到，不确定性是贯穿人一生的根本处境。但这种理解要真正到位，它本身就必须是从一次次本真的抉择行动中生长出来的，而不是一种理论上的认知。

  • “本己能在的不确定性—虽然能在在决定中向来已变成确知的——只有在向死存在中才整体地公开出来。”

  • 尽管在每一次决定中，人的可能性会变得具体而确定，但人最本己的可能性（即面向死亡的整体存在）其最终结局（死亡）却是不确定的。这种根本的不确定性，只有当你真正“向死而生”时，才会完全向你展现。

  • “先行活动把此在带到一种可能性面前：这种可能性持驻地是确知的；然而就可能性何时变为不可能而言，这种可能性却时时刻刻保持其为不确定的。”

  • “向死存在”把人带到死亡这个可能性面前：死亡是必然会发生的，这一点是确凿无疑的；但死亡究竟何时来临，这一点又永远是未知的。

  • “这种可能性公开出：这一存在者被抛入了它的‘极限处境’的不确定性之中；此在因面对这种‘极限处境’下决心而赢得其本真的整体能在。”

  • 死亡的可能性揭示出：人是被毫无选择地抛入到一个充满极限挑战（如死亡）和不确定性的世界中的。恰恰是通过面对这种极限处境并作出本真的决心，人才能赢得他完整而本真的生命。

  • “死的不确定性在畏中源始地开展自身。这一源始的畏则又趋进于期求自身下决心。”

  • 死亡所带来的那种不确定感，在最本源的“畏”的情绪中向我们显露。而这种最本真的畏，又会反过来推动我们去寻求作出本真的决心。

  • “畏把加在此在委弃于其自身这一状况之上的一切遮蔽都加清除。畏是对无的畏，‘无’绽露出在此在的根据处规定此在的不之状态，而这根据本身则作为被抛入死的状况而存在。”

  • 畏这种情绪，把人被抛入世的、必须独自承担自身存在的赤裸状态，完全暴露出来，剥去了所有伪装。畏所畏的是“无”，这个“无”揭示了人的存在根基处就是有限的、否定的（“不之状态”），而这个根基，就是人被抛向死亡的命运。

3. 论证逻辑梳理

  1. 前提：此在同时源始地处于“真”（本真决心）与“不真”（沉沦）之中。
  2. 第一步推进：先行的决心（向死存在）不仅让此在进入本真状态，也让它同时确知自己曾处于并可能再次陷入的“封闭状态”（无决心）。决心是透明的，它清醒地认识到不确定性是生存的常态，并认为只有通过具体的决定才能应对这种不确定性。
  3. 第二步推进：论证这种对不确定性的“知”必须来自本真的行动本身。进而指出，最根本的不确定性——本己能在的整体不确定性——只有在“向死存在”中才能被完全把握。这里点明了死亡的两个特性：发生的确定性与时间的绝对不确定性。
  4. 核心结论：死亡这种“极限处境”的不确定性，恰恰是此在赢得本真整体能在的契机。因为面对它，此在必须下决心。
  5. 最终阐明：这种死亡的不确定性，其显现的场所是畏。畏作为一种基本情绪，剥去所有遮蔽，让此在直面其根基处的“无”（不之状态，即有限性与死亡），而这种直面又反过来呼唤此在下决心。

4. 整体概括

这段文字的核心在于探讨人的本真存在如何与生存的根本不确定性相关联。海德格尔指出，人虽然常常沉沦于日常琐事而逃避自我，但通过“向死存在”的本真决心，人能清醒地认识到这种逃避的可能性，并直面贯穿一生的不确定性。这种不确定性在最极端的死亡问题上达到顶点：死亡必然发生，但何时发生完全未知。正是通过“畏”这种情绪体验，人得以赤裸地面对这种由“无”（有限性和死亡）所定义的生存根基。最终，不是去消除不确定性，而是通过勇敢地在这种不确定性中作出本真的抉择，人才能活出真正属于自己的、完整的生命。

5. 争议与说明

本段解读相对一致，是海德格尔关于“向死存在”、“决心”与“畏”的核心论述。可能的争议点更多在于如何理解“不之状态”和“无”的形而上学地位。主流解读认为这是此在存在论结构中的否定性环节，是构成有限性的根据。但也有学者质疑，这是否将一种生存情绪（畏）过度拔高到了存在论根基的地位，存在“心理主义”或“虚无主义”的倾向。不过，就本段文字内部而言，其论证链条是清晰且自洽的。
