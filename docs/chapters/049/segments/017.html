📖 《存在与时间》研读 逐段解析
首页 / 第 049 章 / 片段 017
📜 原文片段 (049/017)
海德格尔 原文
不仅沉沦从生存论上规定着在世。同时旋涡还公开出在此在的现身中可以落到此在本身头上的被抛境况的抛掷性质与动荡性质。被抛境况不仅不是一种“既成事实”，而且也不是一种已定论的实际情形。在这一实际情形的实际性中包含有：只要此在作为其所是的东西而存在，它就总处在抛掷状态中而且被卷入常人的非本真状态的旋涡中。实际性是在被抛境况中从现象上见出的，而被抛境况属于为存在本身而存在的此在。此在实际地生存着。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 沉沦：此在（人）在日常生活中，倾向于逃避自身本真的存在可能性，而陷入一种非本真、闲谈、好奇、两可的日常状态。这种状态是此在在世的基本方式之一。
  • 旋涡：指此在在沉沦中，被“常人”（das Man，即匿名的、平均化的众人）所支配，陷入一种无法自主、动荡不安的存在状态。它揭示出此在身不由己地被卷入非本真生活的动态过程。
  • 被抛境况：此在的存在总是已经被投入（抛入）一个特定的世界、历史与境遇之中，它从未自由选择过这个起点，却必须从这个既定的、事实性的处境开始其生存。这不是一个静态的事实，而是一种持续的、动荡的存在状态。
  • 实际性：指此在总是已经在某个具体、事实性的境况中生存着。它强调的是此在生存的具体性、事实性和处境性，是被抛境况在现象上的显现。
  • 非本真状态：此在逃避自身独特的、个体化的存在可能性，而服从于“常人”的统治，失去自我抉择责任的状态。
  • 本真状态：此在直面自身的存在，承担起自身的被抛境况与死亡，作出真正属于自己的决断的存在方式。

2. 逐句转译

  1. “不仅沉沦从生存论上规定着在世。” - 沉沦并不仅仅是此在在世的一种偶然状态，它是从生存论结构上，从根本上规定了我们日常在世存在的方式。

  2. “同时旋涡还公开出在此在的现身中可以落到此在本身头上的被抛境况的抛掷性质与动荡性质。” - 同时，那种将我们卷入日常闲谈与忙碌的“旋涡”，也向我们揭示出：我们此在的处境，是一种“被抛”的境况。这种境况带有一种“被扔进来”的被动性，以及随之而来的不稳定和动荡不安的特性。

  3. “被抛境况不仅不是一种‘既成事实’，而且也不是一种已定论的实际情形。” - 被抛境况不仅仅不是一个已经完成、可以置之不理的过去事实（比如你的出生日期），它甚至也不是一个已经定型、不再变化的生活现状。

  4. “在这一实际情形的实际性中包含有：只要此在作为其所是的东西而存在，它就总处在抛掷状态中而且被卷入常人的非本真状态的旋涡中。” - 在我们这种具体的、事实性的生存境况中，包含着一个核心特质：只要我们作为人存在着，我们就始终处于“被抛”的状态里，并且持续不断地被拖入那种由“常人”主导的、失去自我的非本真生活的漩涡中。

  5. “实际性是在被抛境况中从现象上见出的，而被抛境况属于为存在本身而存在的此在。” - 我们所处的具体、现实的生存状况（实际性），正是通过“被抛境况”这个现象向我们显现出来的。而这种被抛境况，本质上归属于那种不断追问自身存在、为自身存在而操心的此在。

  6. “此在实际地生存着。” - 此在，就是如此这般地、真实具体地生活着、生存着。

3. 论证逻辑梳理

  • 前提：沉沦是此在在世的基本规定性之一。
  • 推进1：由沉沦所表现的“旋涡”现象，引出了其背后更深层的生存论结构——“被抛境况”，并点明其“抛掷”（被动性）与“动荡”（不稳定性）的特征。
  • 推进2：进一步澄清“被抛境况”的性质，否定对其作静态化、事实化的理解（不是“既成事实”，也不是“已定论的实际情形”），强调它是一种持续进行的存在状态。
  • 推进3：将“被抛境况”与“实际性”联系起来。指出此在的实际性（其具体的生存现实）正体现在它持续地处于被抛状态，并因而持续地被卷入非本真状态的旋涡中。这揭示了沉沦与非本真状态的根源在于被抛境况。
  • 结论：最终明确，被抛境况是此在（这个以存在为问题的存在者）的根本属性，此在就是在这样一种被抛的实际性中“实际地生存着”。

4. 整体概括

这段话的核心在于深化对“沉沦”的理解。海德格尔指出，我们日常陷入的沉沦状态（如随波逐流、人云亦云）并非偶然，其根源在于我们与生俱来的“被抛境况”。我们就像是被毫无选择地扔进了一个既定的世界和生活方式中（被抛），这种处境本身是动荡不安的，并且持续地将我们卷入由“常人”统治的非本真生活。因此，我们的具体生存现实（实际性）本质上就是这种持续“被抛”和“卷入”的动态过程。我们并不是先作为一个静态的实体存在，然后再去生活；恰恰相反，我们就是在这样一种不断被抛入世界、不断与沉沦搏斗的过程中，实际地展开我们的生存。

5. 争议与说明

本段解读相对一致。核心概念“被抛境况”（Geworfenheit）及其与“沉沦”、“实际性”的关系是海德格尔基础存在论的关键环节，学界对此段的框架性理解分歧不大。可能的细微讨论点在于对“旋涡”意象的强调程度，以及“被抛”的被动性与后期“本真决断”的能动性之间张力的理解，但这并不影响对本段核心论点的把握。
