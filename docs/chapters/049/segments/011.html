📖 《存在与时间》研读 逐段解析
首页 / 第 049 章 / 片段 011
📜 原文片段 (049/011)
海德格尔 原文
闲言与在闲言中得出来的公众解释事情的讲法都是在共处同在中组建起来的。闲言不是作为一种从共处中脱离出来的产物独自在世界之内现成摆着。闲言也是逃不到“普遍”中去的，因为“普遍”在本质上不归属于任何一个人，所以“普遍”“本真地”是无而只“实在地”摆在说着话的个别的此在那里。闲言是共处同在本身的存在方式.而不是靠“从外部”对此在起作用的某些环境才产生的。但若此在本身在闲言中以及在公众讲法中宁愿让它本身有可能在常人中失落，沉溺于无根基状态，那么这就说明：此在为它自己准备了要去沉沦的不断的引诱。在世就其本身而言就是有引诱力的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 闲言（Gerede）：在海德格尔哲学中，一般指一种非本真的、人云亦云的日常交谈方式。它并非基于个人真实理解，而是重复和传播公众流行的观点，从而遮蔽了存在的真相。在本段中，它被明确为“共处同在本身的存在方式”，强调其并非外部环境的产物，而是此在（Dasein）在世的一种基本且构成性的模式。
  • 共处同在（Mitsein）：此在（人）与世界上的其他此在共同存在的基本方式。它描述了人的存在总是与他人共在的社会性维度。
  • 此在（Dasein）：海德格尔哲学的核心概念，特指“人”这种存在者。此在的本质在于它的“存在”（Sein），它能追问并理解自己的存在。
  • 公众解释事情的讲法（öffentliche Ausgelegtheit）：由闲言构建起来的、在社会中流行的、标准化的理解和解释世界的方式。它提供了一个看似自明的、无需质疑的意义框架。
  • 常人（das Man）：指代匿名的、平均化的“大家”。它不是某个具体的人，而是一种使个体失去独特性、沉沦于公众意见的非本真存在状态。
  • 沉沦（Verfallen）：此在的一种基本存在状态，指此在从面对自身本真可能性的状态中“坠落”或“滑入”到被“常人”和世界内事物所支配的非本真日常状态。
  • 在世（In-der-Welt-sein）：此在最基本的存在结构。它指人并非一个孤立的主体，而是始终已经“在世界之中”存在，与世界和他人纠缠在一起。

2. 逐句转译

  1. 原文：闲言与在闲言中得出来的公众解释事情的讲法都是在共处同在中组建起来的。 转译：我们日常生活中那种不经深思熟虑的闲聊，以及通过这种闲聊形成的、社会上流行的、大家都那么说的观点和解释，并不是凭空产生的，它们恰恰是在我们与他人共同生活的过程中形成和确立起来的。

  2. 原文：闲言不是作为一种从共处中脱离出来的产物独自在世界之内现成摆着。 转译：所以，闲言并不是一个可以独立存在的东西，仿佛它先被制造出来，然后作为一个现成的物件摆在那里。它无法与我们共同生活的状态分离开来。

  3. 原文：闲言也是逃不到“普遍”中去的，因为“普遍”在本质上不归属于任何一个人，所以“普遍”“本真地”是无而只“实在地”摆在说着话的个别的此在那里。 转译：我们也不能说闲言属于某个高高在上的、抽象的“普遍”领域。因为这个所谓的“普遍”（比如“大家都这么认为”），本质上不属于任何具体的人；就其本身而言，它是空洞的、没有真实根基的。它只是看起来“实在”，实际只存在于每个具体说话、闲聊的个人身上。

  4. 原文：闲言是共处同在本身的存在方式，而不是靠“从外部”对此在起作用的某些环境才产生的。 转译：因此，闲言本身就是我们与他人共处的一种基本模式。它不是由外部的社会环境强加给我们的，而是我们“共在”这种生存结构的直接体现。

  5. 原文：但若此在本身在闲言中以及在公众讲法中宁愿让它本身有可能在常人中失落，沉溺于无根基状态，那么这就说明：此在为它自己准备了要去沉沦的不断的引诱。 转译：但是，如果此在（人）自己就甘愿沉浸在闲言和公众意见中，宁愿放弃自己的独立判断，迷失在“大家”都这样的状态里，沉迷于这种没有真实根基的生活，那么这就揭示了一个更深层的事实：此在自身就内在地、持续不断地为自己准备好了走向“沉沦”的诱惑。

  6. 原文：在世就其本身而言就是有引诱力的。 转译：因为，此在“存在于世界之中”这一基本事实，其本身就带有一种诱惑力，它会自然地倾向于沉溺于世俗的、非本真的生活。

3. 论证逻辑梳理

  • 前提1：闲言和公众解释源于“共处同在”，是其内在构成部分，而非外部产物。
  • 前提2：闲言无法获得“普遍性”的崇高地位，它本质上是空洞的，只实现在具体的、闲聊的个人身上。
  • 推理1：由前提1和前提2可推出，闲言就是“共处同在”的一种存在方式本身。
  • 观察：此在常常主动选择沉浸在闲言和公众意见中，在“常人”中迷失自我。
  • 核心推论：这一观察表明，沉沦并非偶然事故，而是此在自身为自己准备的、持续存在的内在诱惑。
  • 最终结论：此在的“在世”结构本身就具有引诱此在沉沦的特性。沉沦是此在存在方式的一种基本可能性。

4. 整体概括

这段话的核心观点是：我们日常的人云亦云（闲言）和随大流的看法，并非社会环境从外部强加给我们的，它们恰恰就是我们与他人“共在”这种生存方式的直接体现。这种闲言看似普遍，实则空洞，因为它不真正属于任何人，只是附着在每个闲聊的个体身上。关键在于，人（此在）并非被动受害，而是主动倾向于沉浸在这种无根基的状态中，在“大家”都这样的氛围里逃避自我。这揭示了“沉沦”并非意外，而是内在于我们“在世”生存结构中的一种强大诱惑——我们活在世界上，本身就容易被世界和他人所同化，从而迷失本真的自我。

5. 争议与说明

本段解读相对一致。主要的讨论点可能在于对“沉沦”价值的判断。海德格尔在此描述的“沉沦”并非一个道德上的“堕落”，而是一个存在论上的结构性概念，是中性的。它描述的是此在不可避免的、最初且通常的存在状态。争议不在于这段话本身，而在于如何从全书角度理解“沉沦”：它仅仅是需要克服的负面状态，还是此在开启本真性的必经阶段？但就本段而言，它清晰地指出了沉沦的内在性和诱惑性。
