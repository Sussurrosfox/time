海德格尔 原文
但通过展示沉沦，岂非造出一种现象来，而这种现象和以前曾用以从形式上提示生存观念的规定针锋担对吗？如果此在这种存在者在其日常生活中恰恰丧失了自身而且在沉沦中脱离自身而“生活着”，还可以把此在理解为为能在而存在的存在者吗？但是只有当此在被当成绝缘的主体我，当成一个自我点，而此在却脱离这一自我点而去的时候，沉沦于世界才是与此在的生存论结构针锋相对的现象上的“证明”。这样，世界就是一个客体；沉沦于世界就要从存在论上被另行阐释为具有世内存在者的方式的现成存在。但若我们在展示出的在世建构中坚持此在的存在，那就显而易见：沉沦作为这种“在之中”的存在方式倒为此之生存论结构提供了最基本的证明。在沉沦中，主要的事情不是别的，正是为能在世，即使是以非本真状态的方式亦然。只因为就此在说来，主要的事情就是为了有所领会地现身在世，所以此在才能够沉沦。反过来说，本真的生存并不是任何飘浮在沉沦着的日常生活上空的东西，它在生存论上只是通过式变来对沉沦着的日常生活的掌握。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 沉沦：此在（人的存在）在日常生活中的一种非本真存在方式。此在沉溺于世界中的琐事和他人（常人）的意见，逃避自身的存在问题，从而“丧失自身”。
  • 此在：指人的存在，其本质在于“去存在”（Zu-sein），即总是处在不断展开和实现自身可能性的过程中。
  • 能在：此在的根本特征，即它总是面向未来、筹划自身可能性的能力。
  • 生存论结构：此在存在的先天构成形式，核心是“在世之在”（In-der-Welt-sein），即此在总是已经与一个世界相关联并存在于其中。
  • 非本真状态：此在逃避自身、顺从“常人”的统治，丧失个体性的存在方式。
  • 本真状态：此在面对自身的存在，承担起自身的独特性和可能性，个体性地存在的状态。
  • 在世建构：此在存在的整体结构，即“在世界之中存在”，包含与世界、他人和自身的关系。
  • 现成存在：像物体那样固定的、已经完成的、不具备可能性的存在方式（与此在的“能在”相对）。

2. 逐句转译

  1. “但通过展示沉沦，岂非造出一种现象来，而这种现象和以前曾用以从形式上提示生存观念的规定针锋相对吗？”

    • （转译）但是，当我们揭示出“沉沦”这种现象时，岂不是呈现了一种与我们先前从形式上描述“生存”（此在的本质）的概念相矛盾的现象吗？

  2. “如果此在这种存在者在其日常生活中恰恰丧失了自身而且在沉沦中脱离自身而‘生活着’，还可以把此在理解为为能在而存在的存在者吗？”

    • （转译）如果此在（人）在日常状态中恰恰是迷失了自我，在沉沦中过着一种“脱离自身”的生活，那我们还能把它理解为一个以“面向可能性存在”（能在）为本质的存在者吗？

  3. “但是只有当此在被当成绝缘的主体我，当成一个自我点，而此在却脱离这一自我点而去的时候，沉沦于世界才是与此在的生存论结构针锋相对的现象上的‘证明’。”

    • （转译）然而，只有当我们预先错误地把此在看作一个孤立的“主体”，一个封闭的“自我点”，而沉沦表现为从这个自我点“逃离”出去的时候，沉沦于世界才会显得是与生存论结构相矛盾的证据。

  4. “这样，世界就是一个客体；沉沦于世界就要从存在论上被另行阐释为具有世内存在者的方式的现成存在。”

    • （转译）在这种错误理解下，世界被看作一个外在的客体；而沉沦于世界，就会被错误地从存在论上解释为此在变成了像世界内其他现成物体一样的存在方式。

  5. “但若我们在展示出的在世建构中坚持此在的存在，那就显而易见：沉沦作为这种‘在之中’的存在方式倒为此之生存论结构提供了最基本的证明。”

    • （转译）但是，如果我们坚持从此在的“在世界之中存在”这个基本结构出发来看问题，那么事情就很清楚了：沉沦，作为“在世界中存在”的一种具体方式，反而为这个生存论结构提供了最根本的证明。

  6. “在沉沦中，主要的事情不是别的，正是为能在世，即使是以非本真状态的方式亦然。”

    • （转译）因为在沉沦中，此在所做的核心事情不是别的，正是它“能够在世界中存在”，只不过它是以一种“非本真”的方式（即逃避自身、随波逐流的方式）来实现这种“能在世”。

  7. “只因为就此在说来，主要的事情就是为了有所领会地现身在世，所以此在才能够沉沦。”

    • （转译）正因为对于此在来说，其存在的核心就是“带着某种理解和情绪在世界中存在”，所以它才可能陷入沉沦。

  8. “反过来说，本真的生存并不是任何飘浮在沉沦着的日常生活上空的东西，它在生存论上只是通过式变来对沉沦着的日常生活的掌握。”

    • （转译）反过来看，本真的生存也并非一个悬浮于沉沦的日常生活之上的、完全不同的境界。从生存论上看，本真状态不过是通过一种“存在方式的变化”（式变），对沉沦着的日常生活进行的一种“把握”或“接管”。

3. 论证逻辑梳理

  1. 提出质疑（第1-2句）： 首先提出一个表面上的矛盾：描述此在本质的“生存”（面向可能性存在）与描述此在日常状态的“沉沦”（丧失自我）似乎是相互对立的。如果此在总在沉沦中“丧失自身”，它还能算是“能在”吗？
  2. 剖析错误前提（第3-4句）： 指出这个矛盾源于一个错误的前提——将此在视为孤立的“主体”，将世界视为外在“客体”。基于这个错误框架，沉沦才被误解为从此在“内部”逃向“外部”世界的消极现象。
  3. 正面论证（第5-6句）： 回到正确的“在世建构”前提，论证沉沦非但不是对生存结构的否定，反而是其证明。因为沉沦本身就是“在世界之中存在”的一种方式，它恰恰体现了此在“能够在世”这一根本特性，只是采取的是“非本真”形态。
  4. 深化论证（第7句）： 进一步说明沉沦的可能性正根植于此在的生存论结构。正因为此在本质上是“领会着现身于世”的，它才有能力、有“地方”去沉沦。
  5. 统一本真与非本真（第8句）： 最后将本真生存与沉沦统一起来，指出本真并非脱离日常生活的另一个世界，而是对同一种日常生活（沉沦状态）的一种态度转变和主动把握。

4. 整体概括

这段话的核心在于化解一个表面矛盾：此在的本质是“能在”（面向可能性存在），但其日常状态却是“沉沦”（逃避自身）。海德格尔指出，这个矛盾只有在把人看作孤立主体、把世界看作外在客体时才会出现。一旦回归到此在“在世界之中存在”这一正确起点，就会发现沉沦恰恰证明了此在的生存结构——它正是此在“能够在世”的一种（非本真的）实现方式。沉沦的可能性本身就源于此在“领会着在世”的本质。因此，本真生存并非抛弃日常生活，而是对沉沦着的同一种生活采取一种不同的、更清醒和负责的存在方式。简言之，沉沦不是生存的反面，而是生存的一种（有缺陷的）形态。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“式变”和“掌握”的理解。主流解读认为，“式变”指此在存在方式从非本真到本真的转变，这种转变是此在对自身生存可能性的重新把握。另一种解读可能更强调“式变”是一种存在论层面的结构性转变，而不仅仅是态度或意识上的改变。但总体而言，海德格尔在此处旨在统一本真与非本真，强调它们都基于同一个生存论结构，这一核心思想是学界共识。
