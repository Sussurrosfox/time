📜 原文片段 (049/004)
海德格尔 原文
这个名称并不表示任何消极的评价，而是意味着：此在首先与通常寓于它所操劳的“世界”。这种“消散于…”多半有消失在常人的公众意见中这一特性。此在首先总已从它自身脱落、即从本真的能自己存在脱落而沉沦于“世界”。共处是靠闲言，好奇与两可来引导的，而沉沦于“世界”就意指消散在这种共处之中。我们曾称为此在之非本真状态的东西，现在通过对沉沦的阐释而获得了更细致的规定。但非本真或不是本真绝不意味着“真正不是”，仿佛此在随着这种存在样式就根本失落了它的存在似的。非本真状态殊不是指不再在世之类。它倒恰恰构成一种别具一格的在世，这种在世的存在完全被“世界”以及被在常人中的他人共同此在所攫获。这种“不是它自己存在”是作为本质上操劳消散在一个世界之中的那种存在者的积极的可能性而起作用的。这种不存在必须被领会为此在之最切近的存在方式，此在通常就保持在这一存在方式之中。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔用来指“人”这种存在者的术语，其本质在于“去存在”，即不断筹划和实现自身可能性。
  • 本真状态：此在清醒地意识到自身作为个别化的、向死存在的可能性整体，并承担起自身的存在。
  • 非本真状态：此在日常沉溺于世界事务和他人意见，逃避自身独特的存在责任的状态。
  • 沉沦：此在“跌入”世界和常人的公共状态，消散于日常操劳，从而从本真自我“脱落”的动态过程。
  • 常人：一个无名的、平均化的“他人”，支配着日常的公众意见和行为标准，此在通常迷失于其中。
  • 消散于…：此在完全投入并迷失于所操劳的世界事务中的存在方式。
  • 在世：此在的基本存在结构，意味着它从来都不是孤立的，总是已经在一个世界之中并与他人共处。
  • 操劳：此在与其他存在者打交道的日常实践性活动。
  • 共处：此在与其他此在共同在世的基本方式。
  • 闲言、好奇、两可：沉沦状态下共处的具体方式。闲言是空洞的闲聊；好奇是贪新鹜奇的分散注意力；两可是使一切变得模棱两可、失去真正区分。

2. 逐句转译

  • “这个名称并不表示任何消极的评价，而是意味着：此在首先与通常寓于它所操劳的‘世界’。” -> “这里说的‘沉沦’并不是一个贬义词，它只是在描述一个事实：人（此在）在绝大多数日常情况下，他的心思和精力都沉浸在他所忙碌的那个‘世界’里（比如工作、社交、家务等）。”
  • “这种‘消散于…’多半有消失在常人的公众意见中这一特性。” -> “这种‘完全投入外界’的状态，通常有一个典型特征，就是人迷失在了‘大家’都这么说、这么想的公众意见里，失去了自己的独立判断。”
  • “此在首先总已从它自身脱落、即从本真的能自己存在脱落而沉沦于‘世界’。” -> “所以，人从一开始，就已经在某种程度上从‘真正的自己’身边溜走了，他放弃了去成为那个本真、独立的自己的可能性，而是沉溺、坠落到了这个由外界事物和他人构成的世界中。”
  • “共处是靠闲言，好奇与两可来引导的，而沉沦于‘世界’就意指消散在这种共处之中。” -> “在这种状态下，人和他人的日常相处，主要是通过漫无目的的闲聊、对新鲜事物的表面猎奇，以及一种对什么都模棱两可、不较真的态度来进行的。所谓的‘沉沦于世界’，指的就是人彻底迷失在了这样一种与他人共处的模式里。”
  • “我们曾称为此在之非本真状态的东西，现在通过对沉沦的阐释而获得了更细致的规定。” -> “我们之前笼统地称之为‘非本真状态’的那种人的存在方式，现在通过分析‘沉沦’这个概念，我们对它有了更具体、更深入的理解。”
  • “但非本真或不是本真绝不意味着‘真正不是’，仿佛此在随着这种存在样式就根本失落了它的存在似的。” -> “但是，必须强调，‘非本真’或者‘不是本真’，绝不等于说这种状态是‘假的’或者人在这里就完全不存在了。好像人一旦这样生活，就彻底丢掉了他的‘存在’一样。”
  • “非本真状态殊不是指不再在世之类。它倒恰恰构成一种别具一格的在世，这种在世的存在完全被‘世界’以及被在常人中的他人共同此在所攫获。” -> “非本真状态根本不是指人不在这个世界上了。恰恰相反，它构成了另一种非常独特的‘在世’方式。在这种方式中，人的整个存在都被‘世界’里的事物以及那个作为‘常人’的他人牢牢地抓住和支配了。”
  • “这种‘不是它自己存在’是作为本质上操劳消散在一个世界之中的那种存在者的积极的可能性而起作用的。” -> “这种‘不做自己’的状态，其实是作为人这种必然要在世界中忙碌和投入的存在者，一种积极的、固有的可能性在运作。”
  • “这种不存在必须被领会为此在之最切近的存在方式，此在通常就保持在这一存在方式之中。” -> “这种‘非本真’的存在，必须被理解为人最熟悉、最日常、最触手可及的生活方式，人绝大部分时间就是维持在这种状态里的。”

3. 论证逻辑梳理

  1. 前提/定义：首先澄清“沉沦”是一个描述性、现象性的概念，而非价值评判。它指此在的日常常态：寓于并消散于所操劳的世界。
  2. 现象深化：指出这种“消散”的核心特征是“消失在常人的公众意见中”，并由此引出“沉沦”的关键内涵：此在从本真的自身“脱落”。
  3. 机制说明：具体描述了沉沦状态下“共处”的引导方式：闲言、好奇与两可。沉沦于世界就等于消散于这种被引导的共处之中。
  4. 概念关联：将“沉沦”与之前提出的“非本真状态”概念联系起来，指出“沉沦”是对“非本真状态”的更细致规定。
  5. 关键澄清（消除误解）：立即纠正一个可能的误解，强调“非本真”不等于“不存在”或“虚假”。它并非此在的缺失，而是此在的一种积极的、实存的方式。
  6. 正面规定：从反面（不是什么）转向正面规定（是什么）：非本真状态是一种独特的“在世”，其特征是被世界和他人完全“攫获”。
  7. 存在论定位：最后将这种状态定位为此在的一种本质的、积极的可能性，并且是此在最常见、最切近的存在方式。

4. 整体概括

这段话的核心是在深入阐释此在的“沉沦”现象。海德格尔指出，我们人（此在）的日常常态并非清醒、独立地做自己，而是一种“沉沦”状态：我们完全沉浸在自己忙碌的世界里，尤其迷失于“大家”都这么说、这么想的公众意见中，从而从“本真的自己”身边脱落。这种状态下的社交（共处）充满了闲聊、猎奇和模糊性。他强调，这种“非本真”或“沉沦”状态绝不是虚假或无意义的，它恰恰是人最熟悉、最普通的一种实实在在的生活方式。它是一种人这种“世界中的存在者”与生俱来的、积极的可能性，我们绝大部分时间都生活在这种被外界和他人牢牢抓住的状态里。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“积极的可能性”的理解： - 主流解读：“积极”在此是存在论意义上的，指它是此在结构上固有的、现实运作着的一种存在方式，并非价值上的“好”。就像说“生病是身体的一种积极反应”，指其是真实发生的机制。 - 其他可能解读：少数解读可能会倾向于赋予其更多正面价值，认为这种沉沦的“安稳”为后来本真的决断提供了基础或背景。但海德格尔在此段的语气更侧重于描述其作为一种“脱落”和“被攫获”的常态，强调其作为分析起点的普遍性，而非其价值。
