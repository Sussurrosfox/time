📖 《存在与时间》研读 逐段解析

📜 原文片段 (007/009)
海德格尔 原文
各种科学都是此在的存在方式，在这些存在方式中此在也对那些本身无须乎是此在的存在者有所交涉。此在本质上就包括：存在在世界之中。因而这种属于此在的对存在的领会就同样源始地关涉到对诸如“世界”这样的东西的领会以及对在世界之内可通达的存在者的存在的领会了。由此可见，凡是以不具备此在式的存在特性的存在者为课题的各种存在论都植根于此在自身的存在者层次上的结构并由以得到说明，而此在的存在者层次上的结构包含着先于存在论的存在之领会的规定性。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔用以指代“人”这种存在者的术语，其核心特征是能够发问并理解“存在”本身。此在的存在方式是“生存”，它总是已经在世界之中，并与世界内的其他存在者打交道。
  • 存在在世界之中：此在的根本存在结构。它不是一个空间上的“在…之中”，而是指此在与世界是原初一体的、不可分割的构成关系。世界是此在生存、操劳、理解的场域。
  • 存在者层次上的：指涉具体存在者（如人、石头、工具）的实际状态与事实属性，是前哲学的、日常的经验层面。
  • 存在论层次上的：指对“存在”本身（而非具体存在者）进行发问和研究的哲学层面。它探究的是使得存在者能够作为存在者显现出来的那个先行的条件和意义。
  • 领会：此在的一种基本生存能力，不是指理智上的“理解”，而是指此在总已经对自身的存在、对世界的意义有一种前反思的、活生生的熟悉和通晓。
  • 可通达：指存在者能够在此在的生存活动中，以某种方式（如作为工具、作为对象）被遭遇到、被体验到。

2. 逐句转译

  • “各种科学都是此在的存在方式，在这些存在方式中此在也对那些本身无须乎是此在的存在者有所交涉。” 这句话是说：所有的科学活动，本质上都是人（此在）活着、存在着的一种特定方式。当人进行科学研究时，他所研究的对象（比如物理学的粒子、生物学的细胞），其本身不必是人这种能发问存在的特殊存在者，但人依然与它们发生着关联和互动。

  • “此在本质上就包括：存在在世界之中。” 这句话点明了人的一个根本属性：人天生就被“抛入”一个世界，他的存在无法脱离与世界的关系。他不是先作为一个孤立的主体，然后才进入世界；他一开始就是“在世界之中存在”。

  • “因而这种属于此在的对存在的领会就同样源始地关涉到对诸如‘世界’这样的东西的领会以及对在世界之内可通达的存在者的存在的领会了。” 正因如此，人那种与生俱来的、对“存在”的模糊理解（领会），从一开始就同时包含着对“世界”是怎么回事的理解，以及对世界上我们能碰到的各种东西（比如桌椅、他人、自然物）是如何“存在”的理解。这三者（存在、世界、世内存在者）是捆绑在一起被我们原初地领会到的。

  • “由此可见，凡是以不具备此在式的存在特性的存在者为课题的各种存在论都植根于此在自身的存在者层次上的结构并由以得到说明，” 所以，那些研究“非人”对象（如石头、数字）的哲学理论（存在论），它们的根基其实深深地扎在“人”这个存在者自身的实际生存结构里。要想说清楚那些理论是怎么回事，必须回过头来分析人的生存结构。

  • “而此在的存在者层次上的结构包含着先于存在论的存在之领会的规定性。” 而人的这种实际生存结构，其核心就在于，它天然地、在一切哲学理论产生之前，就已经包含着对“存在”的领会了。正是这种先行的领会，规定并引导着所有后来的哲学追问。

3. 论证逻辑梳理

  1. 前提：科学是此在（人）的一种存在方式。
  2. 核心论断：此在的本质结构是“在世界之中存在”。
  3. 第一层推论：因此，此在对“存在”的原初领会，必然同时包含着对“世界”以及“世内存在者”的领会。这三者是无法割裂的整体。
  4. 第二层推论（核心结论）：于是，所有研究非人存在者的哲学（存在论），其可能性和基础都源于此在自身的生存结构。它们是从这个结构中“长”出来的。
  5. 最终奠基：此在的生存结构的根本特征，就在于它拥有一种先于任何理论哲学的、对“存在”的活生生的领会。这是全部存在论问题的最终源头和规定者。

逻辑链条：科学是此在的活动 → 此在在世 → 在世领会是整体的（含世界与世内存在者）→ 故，一切非此在中心的存在论，都根源于此在的生存结构 → 此在生存结构的核心是先于存在论的“存在之领会”。

4. 整体概括

这段文字的核心论点是：一切学问（科学）和哲学理论（尤其是研究外物的哲学），其最终的根基都在于人（此在）独特的生存方式。人天生就在世界之中生活、操劳，并对自身、世界以及世间万物的“存在”有一种先于理论的、活生生的理解。正是人的这种“在世”且“领会着存在”的根本状态，使得去研究那些“非人”的对象（如自然物体、数学对象）成为可能，并为这些研究提供了意义框架。因此，海德格尔强调，任何哲学追问都必须首先回到对“此在”的生存分析这一根本任务上来，因为这里是所有问题的源头。

5. 争议与说明

本段是《存在与时间》中奠定“基础存在论”规划的关键段落，其核心主张——所有存在论都根植于此在的生存分析——是相对清晰的。可能的争议点不在于段落的字面意思，而在于对这一纲领性主张的后续阐释：

  • 主流解读：认为海德格尔在此确立了一种“哲学的人类学奠基”，即通过分析人的生存来为整个存在论问题奠定基础。这是一种“从下而上”的进路。
  • 可能的争议方向：这种将一切存在论问题都回溯到“此在”的做法，是否隐含了一种“人类中心主义”？它是否可能忽略了“存在”本身超越于人类理解的维度？海德格尔后期思想的发展，也被一些学者认为是对此处的“此在中心论”的一种修正或超越。但就本段而言，其意图是明确的，即为存在意义的问题寻求一个无可置疑的出发点，而这个出发点就是发问者自身——此在的存在。
