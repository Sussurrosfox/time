📖 《存在与时间》研读 逐段解析
首页 / 第 007 章 / 片段 003
📜 原文片段 (007/003)
海德格尔 原文
科学一般地可以被规定为通过诸真命题的相互联系而建立起来的整体。这个定义既不完全也不中肯。注重科学都是人的活动，因而都包含有这种存在者〔人〕的存在方式。我们用此在这个术语来表示这种存在者。科学研究既不是这种存在者唯一可能的存在方式，也不是它最切近的可能存在方式。此在本身就还有与其它存在者的突出不同之处。现在就应把这种与众不同之处先摆到眼前来。这番讨论预演着以后将要进行的真正展示内容的分析。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 科学：在此指的不是具体学科（如物理学、生物学），而是广义上通过“真命题”（正确陈述）的系统性关联所构成的认知体系。海德格尔强调，这种定义虽然常见，但忽略了科学作为“人的活动”这一根本特征。
  • 此在：海德格尔哲学的核心概念，特指“人”这种存在者。此在的本质在于它的“存在方式”——它总是通过理解、关心、筹划等方式与世界打交道，而非仅仅作为一个现成的物体。
  • 存在方式：此在与世界互动的基本模式，例如科学研究、日常操劳、艺术创作等。不同的存在方式决定了此在与世界的关系形态。
  • 真命题：传统哲学中视为“真理”的判断或陈述。海德格尔暗示这种真理观是表面的，因为真理更深层地与此在的“展开状态”相关。

2. 逐句转译

  • “科学一般地可以被规定为通过诸真命题的相互联系而建立起来的整体。”
    → 人们通常把科学定义为：由许多正确陈述相互关联而构成的系统知识。

  • “这个定义既不完全也不中肯。”
    → 但这个定义其实既不够全面，也没有抓住最核心的问题。

  • “注重科学都是人的活动，因而都包含有这种存在者〔人〕的存在方式。”
    → 要看到，科学本质上是人在进行的活动，所以它必然体现了人这种特殊存在者的生存方式。

  • “我们用此在这个术语来表示这种存在者。”
    → 我们专门用“此在”这个词来指代人这种存在者。

  • “科学研究既不是这种存在者唯一可能的存在方式，也不是它最切近的可能存在方式。”
    → 对此在来说，科学研究既不是它唯一能做的事，甚至也不是它最自然、最日常的活动方式。

  • “此在本身就还有与其它存在者的突出不同之处。”
    → 此在本身就有一种非常突出的特质，使它与其他一切存在者（比如石头、动物）都不一样。

  • “现在就应把这种与众不同之处先摆到眼前来。”
    → 我们现在就要先把这种独特之处点出来，让大家注意到。

  • “这番讨论预演着以后将要进行的真正展示内容的分析。”
    → 这里的讨论其实是一个“预告”，为后面更深入、更系统的分析做铺垫。

3. 论证逻辑梳理

  • 前提：传统上把科学定义为“真命题的系统”。
  • 批判：指出这一定义不充分，因为它忽略了科学是“人的活动”。
  • 推进1：引入“此在”概念，强调科学只是此在多种存在方式之一。
  • 推进2：指出科学研究并非此在最本源或最日常的活动方式，暗示日常生活中的“在世存在”更为根本。
  • 推进3：预告此在有一种根本的“与众不同之处”，这将是后续分析的焦点。
  • 结论：本段作为全书导引，旨在把读者的注意力从传统科学观转向对此在之独特存在方式的探索。

4. 整体概括

这段话的核心意思是：我们通常认为科学就是一堆正确陈述构成的系统，但这个看法太浅了。科学本质上是人在做的事情，而人（此在）活着的方式多种多样，科学研究只是其中一种，甚至不是最自然的一种。海德格尔特别强调，此在有它独一无二的存在特质，这使它从根本上区别于其他事物（比如物体或动物）。这段话就像是全书的一个“预告片”，先点出这个关键问题，告诉大家：后面我们会深入分析此在到底特别在哪里。

5. 争议与说明

本段解读相对一致，学界普遍认同这是海德格尔对传统科学观的初步批判，并为引入“此在”分析做铺垫。可能的细微争议在于： - 有学者认为，海德格尔此处对“科学”的批评，不仅针对实证科学，也暗指传统哲学过于“科学化”的倾向； - 另一些解读则强调，海德格尔并非否定科学的价值，而是要求先澄清其存在论基础——即科学何以可能的前提在于此在的生存结构。
