📖 《存在与时间》研读 逐段解析
首页 / 第 018 章 / 片段 004
📜 原文片段 (018/004)
海德格尔 原文
然而迄今为止，我们关于原始人的知识都是从人种学提供的。而人种学还在最初“吸收”、筛选、加工材料的时候，就已经活动在关于人的一般此在的确定的先行概念与确定解释中了。人种学家所习用的日常心理学乃至科学心理学以及社会学能否为适当地通达、解释和转达那有待探究的现象提供科学的保证，这一点并非确定无疑。在这里显现出来的实情也同在前面提到的那些学科里一样。人种学本身就要求以充分进行此在分析为其指导线索，所以，进一步的研究进程将不是以“向前进展”的方式进行，而是以重温的方式，以在存在论上更透彻地纯化那在存在者层次上已经揭示了的东西的方式来进行。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 人种学：在海德格尔语境中，此处的“人种学”（Ethnologie）并非仅指现代学科意义上的民族志研究，而是泛指一切对“原始人”（即前文明、非西方社会人群）进行观察、描述和理论化的经验性研究学科。它代表着一种试图通过外部观察来理解人类存在方式的科学进路。

  • 此在：海德格尔哲学的核心概念，特指“人的存在”。它不是指一个现成的、具有某种属性的实体，而是指人那种不断筹划、理解自身可能性、并且始终与世界融为一体的存在方式。此在的本质在于它的“生存”。

  • 先行概念与确定解释：指研究者在其研究开始之前，就已经不自觉地持有的、关于研究对象（此处是人）的基本理解和预设框架。这些概念先于具体研究，并暗中引导着材料的筛选、观察的角度和最终的解释。

  • 存在论：探究“存在”本身之意义与结构的哲学研究。它追问的是“什么使得一个存在者能够作为其所是的存在者”，关注的是存在的方式和条件，而非具体的存在者属性。

  • 存在者层次：与“存在论层次”相对。指对具体、现成存在者（如人、物体、文化现象）的事实性、经验性属性的研究层面。人种学正属于此层次，它收集和描述关于人的各种经验事实。

  • 重温：并非简单的重复，而是指一种回溯性的、更为根源的重新审视。它要求返回到研究活动得以可能的基础（即此在的存在结构），以便更深刻地理解那些在经验层面上已经被观察到的东西。

2. 逐句转译

  • 然而迄今为止，我们关于原始人的知识都是从人种学提供的。 首先，海德格尔指出，我们目前所有关于所谓“原始人”的知识，其来源都是人种学这门学科。

  • 而人种学还在最初“吸收”、筛选、加工材料的时候，就已经活动在关于人的一般此在的确定的先行概念与确定解释中了。 但是，人种学这门学科，从它一开始接触、挑选和处理研究材料的那一刻起，它的整个研究过程就已经被某些预先设定好的、关于“人是什么”（此在）的概念和解释框架所主导和渗透了。这就像一个人戴着有色眼镜看世界，他从一开始看到的就是被他眼镜颜色过滤后的景象。

  • 人种学所习用的日常心理学乃至科学心理学以及社会学能否为适当地通达、解释和转达那有待探究的现象提供科学的保证，这一点并非确定无疑。 紧接着，他对人种学所依赖的工具提出了质疑。人种学家通常使用的那些理论，比如常识心理学、科学心理学和社会学，它们本身是否真的有能力帮助我们正确地接触、理解和描述我们想要研究的对象（即原始人的生存方式）？海德格尔认为，这一点是非常值得怀疑的，这些工具本身的可靠性并没有得到保证。

  • 在这里显现出来的实情也同在前面提到的那些学科里一样。 他指出，在人种学这里暴露出来的问题（即依赖不可靠的先行框架），和之前他批评过的其他学科（如心理学、社会学）所存在的问题，在本质上是完全一样的。

  • 人种学本身就要求以充分进行此在分析为其指导线索，所以，进一步的研究进程将不是以“向前进展”的方式进行，而是以重温的方式，以在存在论上更透彻地纯化那在存在者层次上已经揭示了的东西的方式来进行。 最后，他提出了解决方案。他认为，人种学这门学科要想真正取得进展，其前提恰恰是需要一种关于“此在”（人的基本存在结构）的深刻分析作为它的理论指南。因此，真正的研究进步，不是一味地向前收集更多新材料，而是要“回过头来”，用一种“重温”的方式，去进行更根本的追问。具体来说，就是要用存在论层面的深刻洞察，去提炼和净化那些在经验研究（存在者层次）中已经被我们发现的现象，从而揭示出现象背后更深层的存在意义。

3. 论证逻辑梳理

  1. 前提/现状陈述：我们关于“原始人”的知识依赖于人种学。
  2. 核心批判：人种学的整个研究过程，从起点（吸收材料）就已被关于“人”的特定先行概念所污染，其研究方法（心理学、社会学）的有效性本身是可疑的。
  3. 问题普遍化：指出人种学的问题并非孤例，而是与其他经验科学（心理学、社会学）共享着同样的根本缺陷——即缺乏对自身研究前提（人的存在方式）的彻底反思。
  4. 解决方案/未来路径：真正的进步不在于经验的积累（“向前进展”），而在于进行回溯性的奠基工作（“重温”）。必须首先进行彻底的“此在分析”（存在论研究），以此来指导和净化经验研究（存在者层次）的发现，使其获得真正的科学严谨性。

4. 整体概括

这段话的核心意思是，海德格尔在质疑整个人类学（以人种学为代表）的科学基础。他认为，我们看似客观的关于“他者”（如原始人）的知识，实际上从最开始就被我们自己所持有的、未经检验的关于“人是什么”的预设观念所塑造和扭曲了。人种学以及它所依赖的心理学、社会学等工具，本身都建立在不牢靠的地基上。因此，学术研究不能仅仅满足于不断地发现新事实、新数据（向前进展），那只是在沙滩上盖楼。必须先停下来，回过头去（重温），深入挖掘并厘清“人这种存在者究竟是如何存在”这个最根本的问题（此在分析）。只有用这种哲学层面的深刻洞察（存在论）作为指南，我们才能恰当地理解和解释在经验层面（存在者层次）所观察到的那些人类现象。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“重温”和“向前进展”关系的理解： - 主流解读：如上述，海德格尔并非完全否定经验研究，而是强调经验研究必须建立在稳固的存在论基础之上。“重温”是奠基性的工作，是为“向前进展”提供可能性和方向。 - 其他可能解读：有论者可能过度强调二者的对立，认为海德格尔是在用哲学思辨彻底取代经验科学。但结合《存在与时间》的整体思路，他更倾向于一种互补关系：存在论为各门科学奠基，而科学的实证发现反过来也可能促使存在论的修正与深化。本段重点在于强调奠基的优先性。
