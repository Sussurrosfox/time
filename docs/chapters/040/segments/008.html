📖 《存在与时间》研读 逐段解析
首页 / 第 040 章 / 片段 008
📜 原文片段 (040/008)
海德格尔 原文
人们要是把展开的东西和带有情绪的此在“同时”所认识的、所知道的和所相信的东西混为一谈，那么，人们在现象上就完全误解了情绪开展了什么以及情绪如何开展。即使此在“确信”其“何所往”，或在理性的追查中以为它知道何所来，这一切仍然丝毫也否定不了下述现象实情：情绪把此在带到它的此的“它存在着”面前来，而这个“它存在着”正在一团不为所动的谜样气氛中同此在面面相觑。在生存论存在论上，决不允许用关于纯粹现成东西的某种理论认识的无庸置疑的确定性来衡量现身情态的“明白确凿”，这么做倒减少了现身的“明白确凿”。对现身现象的另外一种曲解则是把现身现象推进非理性事物的避难所了事。这种曲解也同样无理。非理性主义唱得是理性主义的对台戏，理性主义盲目以待的东西，非理性主义也不过目丐顾而言罢了。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 展开的东西：指此在（人的存在）在情绪中无遮蔽地、直接显现出来的自身存在状态。它不是理论认知的内容，而是生存体验的直接给予。
  • 情绪：此在源初的、前反思的存在方式，它让此在直接面对自己的“存在于此”这一事实，并揭示世界整体如何在情感上向此在呈现。
  • 此在：海德格尔对“人”的存在方式的专门称呼，指那种以理解存在、关心自身存在为本质的存在者。
  • 现身情态：情绪使此在“现身”于此的方式，是此在直接感受并承担自身存在的状态。
  • 开展：指情绪以一种非认知、非主题化的方式，让此在的存在状态直接显现和敞露出来。
  • 生存论存在论：从此在的实际生存出发，探究存在意义的基础存在论进路。
  • 非理性主义/理性主义：两种哲学立场。理性主义认为只有通过理性认知才能把握真理；非理性主义虽反对理性主义，但仍预设了理性主义的框架，只是把理性无法解释的东西归为“非理性”，并未真正触及情绪源初的开展方式。

2. 逐句转译

  1. “人们要是把展开的东西和带有情绪的此在‘同时’所认识的、所知道的和所相信的东西混为一谈，那么，人们在现象上就完全误解了情绪开展了什么以及情绪如何开展。” - 如果有人把情绪直接揭示出来的东西，与此在通过理性认识、知识或信仰所把握的东西等同起来，那就从根本上错看了情绪到底揭示了什么，以及它是如何揭示的。

  2. “即使此在‘确信’其‘何所往’，或在理性的追查中以为它知道何所来，这一切仍然丝毫也否定不了下述现象实情：情绪把此在带到它的此的‘它存在着’面前来，而这个‘它存在着’正在一团不为所动的谜样气氛中同此在面面相觑。” - 哪怕此在对自己要去向何方非常确信，或者通过理性思考自以为清楚自己从何而来，这些都完全无法改变一个基本事实：情绪直接把此在带到“它正存在着”这个赤裸的事实面前。这个“存在着”的事实，以一种无法被理性穿透、谜一般的氛围，直接与此在对峙。

  3. “在生存论存在论上，决不允许用关于纯粹现成东西的某种理论认识的无庸置疑的确定性来衡量现身情态的‘明白确凿’，这么做倒减少了现身的‘明白确凿’。” - 从生存论存在论的角度看，绝不能拿那种针对纯粹客观对象的理论认知所具有的确定性，来评判情绪现身状态的那种“确凿无疑”。这样做，反而会贬低和削弱情绪现身状态本身的那种源初的、直接的“确凿性”。

  4. “对现身现象的另外一种曲解则是把现身现象推进非理性事物的避难所了事。这种曲解也同样无理。” - 对情绪现身现象的另一种歪曲，是简单粗暴地把它归为“非理性”的领域，认为那是理性无法触及的黑暗角落就算了事。这种处理方式同样是没道理的。

  5. “非理性主义唱得是理性主义的对台戏，理性主义盲目以待的东西，非理性主义也不过目丐顾而言罢了。” - 非理性主义本质上只是在和理性主义唱反调。理性主义视而不见（盲目以待）的东西，非理性主义也并没有真正看清和说清楚（不过目丐顾而言），它只是转移了话题，回避了问题本身。

3. 论证逻辑梳理

  • 前提：人们常常将情绪所直接“展开”的东西与此在通过认知、知识、信仰所把握的东西相混淆。
  • 核心论证： 1. 首先，海德格尔指出这种混淆导致了对情绪开展功能的根本误解。 2. 接着，他强调，即便此在拥有理性的确定性（如何所往、何所来），情绪依然以一种更源初、更直接的方式，将此在带到其赤裸的“存在事实”面前。这个事实是理性无法穿透的“谜”。 3. 然后，他从方法论上批判：不能用理论认识的确定性标准（适用于“现成东西”）来衡量情绪现身情态的“明白确凿”，这样做会错失后者的本质。 4. 最后，他批判了另一种逃避问题的做法——将情绪现象归入“非理性”领域。他指出，非理性主义并未真正超越理性主义的框架，它只是理性主义的反面镜像，同样未能触及情绪源初的揭示功能。
  • 结论：情绪的开展是一种独特的、不可被理性认知所替代或衡量的源初揭示方式，对它既不能进行认知论的“归化”，也不能进行非理性主义的“放逐”。

4. 整体概括

这段话的核心是在为情绪的揭示功能进行“正名”和划定界限。海德格尔强调，情绪（现身情态）是此在理解自身存在的一种源初方式，它先于并独立于任何理性的认知、知识和信仰。情绪直接把“我存在”这个最基本、最赤裸的事实抛到我面前，这个事实带有一种理性无法解释的、谜一般的特质。因此，我们既不能用科学或哲学理论那种追求客观确定性的标准来要求和衡量情绪揭示的“确凿性”，也不能因为理性说不清楚，就把它打发到“非理性”的模糊领域了事。后者所谓的“非理性主义”其实和“理性主义”是一体两面，它们共享着同样的前提，都未能真正尊重和进入情绪本身独特的揭示方式。

5. 争议与说明

本段解读相对一致。核心争议点可能在于对“非理性主义”批判的细化：有学者认为，海德格尔此处并非完全反对“非理性”，而是反对将情绪简单地标签化为“非理性”，从而回避对其存在论意义的深入探究。他的目的在于将情绪从理性/非理性的传统框架中解放出来，将其确立为一个独立的、源初的存在论范畴。
