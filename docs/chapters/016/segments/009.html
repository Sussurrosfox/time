📜 原文片段 (016/009)
海德格尔 原文
此在总是从它所是的一种可能性、从它在其存在中这样那样领会到的一种可能性来规定自身为存在者。这就是此在的生存建构的形式上的意义。但其中就有这种存在者的存在论阐释所需的提示：要从这种存在者的存在的生存论建构中发展出它的存在问题的提法来。然而这却不是说，要用一个具体的可能的生存观念来组建此在。此在在分析之处恰恰不应在一种确定的生存活动的差别相中来被阐释，而是要在生存活动的无差别的当下情况和大多情况中来被发现。此在的日常状态的这种无差别相并不是无，而是这种存在者的一种积极的现象性质。一切如其所是的生存活动都从这一存在方式中来而又回到这一存在方式中去。我们把此在的这种日常的无差别相称作平均状态。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在 (Dasein)：海德格尔哲学的核心概念，指人的存在方式，其本质在于“去存在”，即通过不断筹划自身可能性而构成自身。
  • 生存 (Existenz)：此在特有的存在方式，它不是现成的属性，而是指此在总是超出自身、面向可能性而存在的动态过程。
  • 生存论建构 (existenziale Konstitution)：此在存在的本质结构，包括操心、沉沦、向死存在等基本环节。
  • 日常状态 (Alltäglichkeit)：此在最常见的存在模式，处于平均化、公众意见主导的非本真状态。
  • 无差别相/平均状态 (Durchschnittlichkeit)：日常状态的特征，指此在消融于常人（das Man）之中，失去个性差异的生存方式。

2. 逐句转译

"此在总是从它所是的一种可能性、从它在其存在中这样那样领会到的一种可能性来规定自身为存在者。" → 人（此在）总是通过自己能够成为的某种可能性，通过自己在生活中或多或少理解到的可能性，来定义自己是什么样的人。

"这就是此在的生存建构的形式上的意义。" → 这就是人之为人的存在结构的根本含义。

"但其中就有这种存在者的存在论阐释所需的提示：要从这种存在者的存在的生存论建构中发展出它的存在问题的提法来。" → 这里暗示了理解这种存在者（人）的关键方法：必须从人的存在结构的分析出发，来提出关于人如何存在的问题。

"然而这却不是说，要用一个具体的可能的生存观念来组建此在。" → 但这并不意味着要用某种特定的生活理想或模式来定义人。

"此在在分析之处恰恰不应在一种确定的生存活动的差别相中来被阐释，而是要在生存活动的无差别的当下情况和大多情况中来被发现。" → 在分析之初，我们不应该从某种特殊、与众不同的生活状态入手，而应该从日常生活中最普通、最常见的那种无差别状态开始研究。

"此在的日常状态的这种无差别相并不是无，而是这种存在者的一种积极的现象性质。" → 日常生活的这种无差别状态并非空洞无物，而是人存在的一种真实而重要的现象特征。

"一切如其所是的生存活动都从这一存在方式中来而又回到这一存在方式中去。" → 所有具体的生活状态，无论多么特殊，都源于这种日常状态，最终也会回归到这种状态。

"我们把此在的这种日常的无差别相称作平均状态。" → 我们把人的日常生活的这种无差别特征称为"平均状态"。

3. 论证逻辑梳理

前提：此在通过领会自身可能性来定义自己（生存建构的形式意义）。

分析推进： 1. 由此提出存在论研究的方法论要求：从此在的生存论建构出发。 2. 但立即澄清这种方法不是要用某种理想化的生存模式来规定此在。 3. 相反，研究的起点恰恰是最普通、最无个性的日常状态。 4. 论证这种无差别状态并非虚无，而是具有积极的现象学意义。 5. 指出所有生存状态都以这种平均状态为背景和归宿。

结论：将此在日常的无差别相界定为"平均状态"，确立为存在论分析的恰当起点。

4. 整体概括

这段文字在说明：我们理解人的存在，不能从某种理想化的生活模式入手，而应该从最普通、最常见的日常生活状态开始。人虽然总是通过自己能够成为的可能性来定义自己，但在大多数时候，我们都处在一种"平均状态"中——既不是特别突出，也不是毫无特色，而是消融在常规的生活方式里。这种看似平淡无奇的状态恰恰是理解人之存在的关键入口，因为所有的特殊生活状态都以此为背景，最终也会回归到这里。海德格尔强调，这种"平均状态"并非没有研究价值，反而是我们必须认真对待的真实现象。

5. 争议与说明

本段解读相对一致。可能的细微争议在于对"平均状态"的价值判断：有学者强调这是海德格尔对现代人异化状态的批判，另一些则认为这是中性的现象学描述。但就本段而言，海德格尔明确将其视为存在论分析的恰当起点，这一方法论意义是明确的。
