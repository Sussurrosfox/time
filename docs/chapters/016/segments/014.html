📖 《存在与时间》研读 逐段解析
首页 / 第 016 章 / 片段 014
📜 原文片段 (016/014)
海德格尔 原文
在导论中已经提示过：在此在的生存论分析工作中，另一个任务也被连带提出来了，其迫切性较之存在问题本身的迫切性殆无逊色。要能够从哲学上对“人是什么”这一问题进行讨论，就必须识见到某种先天的东西。剖明这种先天的东西也是我们的迫切任务。此在的生存论分析工作所处的地位先于任何心理学、人类学，更不消说生物学了。如果我们把生存论分析工作的课题同这几种可能的关于此在的研究划分开来，那么生存论分析的课题就会得到更为鲜明的界说。这同时也将更进一步证明这一分析课题的必要性。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学的核心概念，特指“人”这种存在者。它不是生物学或心理学意义上的“人”，而是指能够追问自身存在、并对存在有所领会（理解）的存在者。此在的本质在于它的“生存”，即它总是通过自己的行动、选择和筹划来塑造自己的可能性。
  • 生存论分析：对此在的存在方式进行的研究。它不关心此在的具体心理状态或生理特征，而是探究此在“存在”的基本结构和条件。其目标是揭示此在是如何“在世界之中存在”的。
  • 先天：在此并非指时间上“出生以前”，而是哲学（尤其是康德哲学）术语，指“先于经验”的、使经验成为可能的条件。海德格尔用它指此在生存结构中那些必然的、使此在能够理解世界和理解自身的根本条件。
  • 心理学、人类学、生物学：这些代表传统的、实证科学的研究“人”的方式。它们将人视为一个现成的、可供观察和分类的对象。海德格尔认为，他的生存论分析在基础层面上先于这些科学，因为这些科学本身已经预设了对“人是什么”的某种前哲学的理解（即生存论分析所要揭示的东西）。

2. 逐句转译

  • “在导论中已经提示过：在此在的生存论分析工作中，另一个任务也被连带提出来了，其迫切性较之存在问题本身的迫切性殆无逊色。”

    • 转译：我们之前在书的导论部分提到过，当我们分析“此在”这种存在者的生存方式时，除了核心的“存在问题”，还有一个同样重要的任务也随之浮现出来。

  • “要能够从哲学上对‘人是什么’这一问题进行讨论，就必须识见到某种先天的东西。”

    • 转译：如果我们想真正从哲学层面回答“人是什么”这个问题，我们就必须首先认识到，存在着一些构成人之为人的、先于一切具体经验的根本条件。

  • “剖明这种先天的东西也是我们的迫切任务。”

    • 转译：所以，把这些根本条件清晰地揭示出来，就是我们当前非常紧迫的任务。

  • “此在的生存论分析工作所处的地位先于任何心理学、人类学，更不消说生物学了。”

    • 转译：我们正在做的这种生存论分析，它的基础性位置是在心理学、人类学，乃至于生物学这些学科之上的。它为这些学科提供了前提。

  • “如果我们把生存论分析工作的课题同这几种可能的关于此在的研究划分开来，那么生存论分析的课题就会得到更为鲜明的界说。”

    • 转译：只要我们能把生存论分析的研究主题，和心理学等研究人的具体学科明确地区分开，那么生存论分析的任务和目标本身就会变得更加清晰。

  • “这同时也将更进一步证明这一分析课题的必要性。”

    • 转译：通过这种区分，我们也能更加有力地证明，进行这种基础性的生存论分析是绝对必要的。

3. 论证逻辑梳理

  1. 前提与任务提出：论证始于一个已被提及的前提——在探究“存在”问题时，一个与分析“此在”同等重要的任务出现了。
  2. 核心论点：要哲学地回答“人是什么”，必须找到那个“先天”的基础。这直接定义了新任务的核心内容：揭示这个先天结构。
  3. 划界与定位：为了明确这个任务，海德格尔将其与传统学科（心理学、人类学、生物学）划清界限，强调他的分析在层次上“先于”它们。这是一种方法论上的澄清。
  4. 双重目的：进行这种划界有两个目的：一是让生存论分析本身的目标更清晰（定义功能），二是反过来证明进行这种基础分析的必要性（论证功能）。整个段落逻辑上是从“任务是什么”推进到“为何必须这么做”。

4. 整体概括

这段话的核心意思是：海德格尔重申，他的哲学工作除了探究“存在”本身，还有一个与之并行的紧迫任务，那就是为“人是什么”这个问题找到一个先于所有具体科学的哲学基础。这个基础就是对此在的“生存论分析”。他强调，他的分析比心理学、人类学等学科更为根本，因为这些学科在研究人时，其实已经不自觉地在利用某种对人之存在的预先理解了。因此，通过把他的分析与这些学科明确区分开来，不仅能更清楚地说明他的分析工作到底是什么，也能有力地证明，进行这种刨根问底式的哲学分析是任何关于人的讨论所不可或缺的基石。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“先天”一词的理解：有学者会强调海德格尔的“先天”与康德纯粹形式化的“先天”不同，它是在此在的动态生存活动中显现的，是“生存论的先天”。但在此段落中，此概念主要是为了标明其基础地位，这一细微差别尚未充分展开，因此主流解读聚焦于其“基础性”和“在先性”的含义。
