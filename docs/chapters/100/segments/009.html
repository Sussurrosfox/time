📖 《存在与时间》研读 逐段解析
首页 / 第 100 章 / 片段 009
📜 原文片段 (100/009)
海德格尔 原文
现在序列连续不断、严丝合缝。无论我们怎样“不断地”把现在“分割下去”，现在总还是现在。人们是在一种不可消解的现成事物的视野上看见时间的持续性的。人们在存在论上依照一拽持驻的现成事物制定方向，或由此寻索时间的连续性问题，或由此就抛下这进退两难之境不管。这样一来，世界时间所特有的结构必然始终被遮蔽着，因为世界时间随着可定期性——可定期性的基础是绽出——一道伸张分段〔gespannt〕。在操劳于时间之际公开化了的时间性的绽出统一在视野上有所延展〔erstreckt〕，但时间的伸张分段却不曾从这种视野的延展得到领会。无论每个现在如何转瞬即逝，在其中总已经是现在；这件事必须从更“早先”的东西来理解——每一个现在都生自这更早先的东西；也就是说，这件事必须从一种时间性的绽出延展来理解——这种时间性异乎任何现成事物的连续性，而这本身却又表现为之所以可能通达现成持续之事的条件。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 现成事物（Vorhandenheit）：一般指以静态、客体化方式存在的对象，仿佛独立于人的活动而“在那里”。在本段中，海德格尔批判人们常将时间也视为这样一种现成、分割的“现在”序列。
  • 世界时间（Weltzeit）：不是物理或客观时间，而是与人的生存活动（操劳）紧密相连的时间，具有“可定期性”（如“开会的时候”“吃饭的时候”），其结构与人的时间性息息相关。
  • 绽出（Ekstase）：指时间性（Zeitlichkeit）不是静止的“点”，而是不断“向外跃出”的动态过程——过去、现在、未来三者交织统一，互相开放。
  • 可定期性（Datenbarkeit）：指时间能被我们赋予具体内容（如“在……之时”），而非空洞的“现在点”，它建立在时间性的绽出结构之上。
  • 伸张分段（gespannt）：时间并非均匀流逝，而是像被“拉紧分段”，与世界事件和人的活动节奏相应，有张有弛。
  • 操劳（Besorgen）：人在世界中与事物打交道、投入活动的生存方式，在这里特指“操劳于时间”，即我们在生活中不断使用、安排、理解时间的方式。

2. 逐句转译

  • “现在序列连续不断、严丝合缝。无论我们怎样‘不断地’把现在‘分割下去’，现在总还是现在。”
    → 人们习惯把时间看作一连串无缝连接的“现在点”，就像把一条线不断切分，切出来的每一段仍然是一个“现在”。

  • “人们是在一种不可消解的现成事物的视野上看见时间的持续性的。”
    → 这种看法其实是从“现成事物”的角度来看时间——就像看待一个静止不动的物体那样，把时间也当作一连串固定不变的点。

  • “人们在存在论上依照一拽持驻的现成事物制定方向，或由此寻索时间的连续性问题，或由此就抛下这进退两难之境不管。”
    → 于是，我们在理解存在时，要么用这种现成事物的模式去追问“时间怎么连起来的？”要么干脆避开这个难题不去深究。

  • “这样一来，世界时间所特有的结构必然始终被遮蔽着，因为世界时间随着可定期性——可定期性的基础是绽出——一道伸张分段。”
    → 这样一来，我们就把“世界时间”的真正结构掩盖了。世界时间是有内容、有事件、可标记的（比如“开会时”“下雨时”），而且它的分段是随着我们生命活动的节奏展开的，这种分段的基础正是时间性的“绽出”结构。

  • “在操劳于时间之际公开化了的时间性的绽出统一在视野上有所延展，但时间的伸张分段却不曾从这种视野的延展得到领会。”
    → 我们在生活中使用时间时，时间性那种“绽出统一”（过去-现在-未来一体）的状态其实已经在我们的视野中展开了，但我们却没有从这种“视野的延展”去理解时间的分段。

  • “无论每个现在如何转瞬即逝，在其中总已经是现在；这件事必须从更‘早先’的东西来理解——每一个现在都生自这更早先的东西；也就是说，这件事必须从一种时间性的绽出延展来理解——这种时间性异乎任何现成事物的连续性，而这本身却又表现为之所以可能通达现成持续之事的条件。”
    → 为什么我们总感觉“现在”不断出现？这不是因为“现在点”一个接一个冒出来，而是因为每一个“现在”都源自时间性那种更原始的“绽出延展”——过去、现在、未来原本就是一体展开的。这种时间性不同于任何现成事物的连续，但它恰恰是我们能理解“事物持续存在”的前提条件。

3. 论证逻辑梳理

  • 前提：人们通常将时间视为一连串连续的“现在点”，就像看待静止的现成事物一样。
  • 推进1：这种看待时间的方式，掩盖了“世界时间”的真实结构——世界时间其实是可被赋予内容、与人的活动节奏相应的。
  • 推进2：世界时间的“伸张分段”来自时间性的“绽出”结构，即过去-现在-未来的统一动态。
  • 推进3：我们在生活中其实已经在“使用”这种绽出的时间性（“操劳于时间”），但并未真正理解它。
  • 结论：每个“现在”的出现，必须从更原始的时间性绽出延展来理解，这种时间性不是现成事物的连续，反而是我们理解事物持续存在的条件。

4. 整体概括

这段文字核心在批判我们通常对时间的误解：我们把时间当成一连串“现在点”组成的现成序列。海德格尔指出，这种看法掩盖了“世界时间”的真实面貌——时间其实是和我们生活活动紧密相连的，能被赋予具体内容（比如“吃饭时”“工作时”），并且它的分段节奏来自时间性本身那种过去、现在、未来交织的动态结构。他进一步强调，每一个“现在”都不是孤立冒出来的，而是源自这种更原始的、绽出的时间性；这种时间性虽然不同于任何物体的连续存在，但却是我们能理解“事物持续存在”的基础。

5. 争议与说明

本段解读相对一致，争议较少。主要可能的讨论点在于“伸张分段”（gespannt）的具体意涵——有学者强调其与“紧张”“牵拉”的生活节奏感联系，也有解释偏向于时间“分段”与“定期”的事件性结构。但整体上，海德格尔批判流俗时间观、揭示绽出时间性为原初基础的立场是清晰的。
