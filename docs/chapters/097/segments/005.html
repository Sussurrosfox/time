📖 《存在与时间》研读 逐段解析

📜 原文片段 (097/005)
海德格尔 原文
实际此在计算时间而未从生存论上领会时间。计算时间这种行为是基本的；在解答什么叫“存在者存在在时间中”这个问题之前先须澄清这种行为。此在的一切行为都应从它的存在亦即从时间性来阐释。应得显示此在作为时间性是如何使得以计时方式与时间相关联这样一种作法到时的。所以，前此对时间性特征的描述不仅由于未曾把这一现象的各个维度都注意到，因而一般来说就是不充分的；而且它在原则上也是残缺不全的，因为从生存论时间性上的世界概念的严格意义上看，时间性本身就包含有世界时间这样的东西。我们应该领会：这事如何可能以及为何必要。这将使我们明见存在者发生“在其中”的流俗所识的“时间”，并与此一道明见这一存在者的时间内状态。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学中的核心概念，指人的存在方式，其本质在于“在世之中”并通过行动和领会展开自身可能性。
  • 生存论：从人（此在）实际生存的角度进行分析的哲学方法，关注此在如何具体地理解并活出自身。
  • 时间性：此在存在的根本结构，是时间三维（曾在、当前、将来）的统一动态整体，构成了此在领会存在的基础。
  • 到时：时间性的实现或具体显现方式，指时间性如何在实际生存中展开为具体的时间经验。
  • 世界时间：并非物理的客观时间，而是此在在操劳活动中直接遭遇的、具有意义关联的时间（如“收获时节”、“开会时间”），它源于时间性。
  • 时间内状态：指普通存在者（非此在的存在者，如物体、事件）在时间中被遭遇和规定的存在方式，它们是“在时间之中”的。

2. 逐句转译

  • “实际此在计算时间而未从生存论上领会时间。”
    → 我们日常生活中的人（此在）习惯于“计算时间”（比如看表、安排日程），但这种做法并没有从生存论层面去理解时间的本质。

  • “计算时间这种行为是基本的；在解答什么叫‘存在者存在在时间中’这个问题之前先须澄清这种行为。”
    → 计算时间是一种基础性的日常活动，我们必须先把这种行为搞清楚，才能去回答“一个东西存在于时间之中”到底是什么意思。

  • “此在的一切行为都应从它的存在亦即从时间性来阐释。”
    → 理解人的任何行为，都应该追溯到其最根本的存在方式——也就是时间性。

  • “应得显示此在作为时间性是如何使得以计时方式与时间相关联这样一种作法到时的。”
    → 我们需要说明：此在作为时间性，是如何让它那种“用计时方式和时间打交道”的做法得以具体实现的。

  • “所以，前此对时间性特征的描述不仅由于未曾把这一现象的各个维度都注意到，因而一般来说就是不充分的；而且它在原则上也是残缺不全的，因为从生存论时间性上的世界概念的严格意义上看，时间性本身就包含有世界时间这样的东西。”
    → 因此，之前对时间性的描述不仅因为忽略了某些方面而不够完整，而且它在根本上就有缺失——因为严格来说，时间性本身就内在地包含了“世界时间”这个维度。

  • “我们应该领会：这事如何可能以及为何必要。”
    → 我们必须理解：时间性包含世界时间这件事是如何发生的，以及为什么必须如此。

  • “这将使我们明见存在者发生‘在其中’的流俗所识的‘时间’，并与此一道明见这一存在者的时间内状态。”
    → 理解了这一点，我们就能看清普通事物“在时间中”发生所依赖的那个流俗时间概念，同时也看清这些事物所具有的“时间内状态”。

3. 论证逻辑梳理

  • 前提：此在在日常生活中“计算时间”，但这并未触及时间的生存论本质。
  • 推进1：指出必须首先澄清“计算时间”这一行为，才能探讨“存在者在时间中”的问题。
  • 推进2：提出核心方法论原则——此在的一切行为都应从其时间性来理解。
  • 推进3：具体任务——展示时间性如何使“计时行为”得以可能（到时）。
  • 转折与深化：指出以往对时间性的描述存在双重缺陷（不充分且残缺），因为忽略了时间性本身就包含“世界时间”这一关键维度。
  • 结论与任务设定：因此，必须阐明时间性包含世界时间的可能性与必要性，这样才能真正理解流俗时间概念及存在者的时间内状态。

4. 整体概括

这段文字的核心在于强调，我们日常“计算时间”的行为看似基础，实则根源于此在更本质的“时间性”结构。海德格尔认为，必须从时间性出发，才能解释清楚计时行为是如何发生的，以及普通事物“在时间中存在”究竟意味着什么。他同时批评了以往对时间性描述的不足，指出时间性本身就必然包含“世界时间”（即有意义、关联于操劳活动的时间），并认为阐明这一点是理解流俗时间概念的关键。简单说，这是在为从生存论角度彻底重构时间概念做铺垫，要把流俗的时间观念（如物理时间）拉回到此在生存的时间性根源上来。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“世界时间”与“时间性”关系的理解：有学者更强调世界时间是时间性的直接衍生物或展开形式；而另一些解读则更倾向于认为世界时间是时间性内在的、不可分割的构成环节。海德格尔此处的表述“时间性本身就包含有世界时间这样的东西”更支持后一种解读，即二者是本源与具现的同一关系，而非先后衍生的关系。
