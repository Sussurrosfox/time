📖 《存在与时间》研读 逐段解析
首页 / 第 024 章 / 片段 014
📜 原文片段 (024/014)
海德格尔 原文
制好的工件不仅指向它的合用性的何所用、它的成分的何所来；在简单的手工业状况下，它同时还指向承用者和利用者。工件是依他量体剪裁而就，在工件的产生过程中他也一道“在”那里。在批量生产中绝不缺乏这种具有组建作用的指引，只不过这种指引是不确定的罢了，它指向随便哪些人，指向平均。这么看起来，随着工件一起来照面的不仅有上手的存在者，而且也有具有人的存在方式的存在者。操劳活动所制作的东西就是为人而上手的。承用者和消费者生活于其中的那个世界也随着这种存在者来照面，而那个世界同时就是我们的世界。操劳所及的工件在工场的家庭世界中上手，而且也在公众世界中上手。周围世界的自然随着这个公众世界被揭示出来，成为所有人都可以通达的。在小路、大街、桥梁、房舍中，自然都在一定的方向上为操劳活动所揭示。带顶篷的月台考虑到了风雨，公共照明设备考虑到了黑暗，也就是说，考虑到了日光间有间无的这种特殊变化，考虑到了“太阳的位置”。在钟表中则考虑到了宇宙系统中的一定的星辰位置。当我们看表的时候，我们不知不觉地使用了“太阳的位置”，官方天文学就是按照“太阳的位置”来调整时间量度的。在使用当下而不显眼地上手的钟表设备之际，周围世界的自然也就共同上手了。任何消散在最切近的工件世界中的操劳都具有揭示功能。这种揭示功能的本质就是：按照消散于工件世界的方式，那个在工件中——亦即在起组建作用的指引中——被连带指引出的世内的存在者总是在种种不同的明确程度上、在寻视所突入的种种不同深度上保持其为可揭示的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 工件 (Zeug / equipment)：在海德格尔哲学中，指我们日常使用、与之打交道的工具或物品，它们的存在方式被称为“上手状态”（Zuhandenheit），即我们是在使用中、而非客观观察中理解它们的。工件总是处于一个“指引网络”中，指向其用途、材料来源和使用者。
  • 上手状态 (Zuhandenheit)：存在者（如工件）的一种存在方式，其特征是“为了作…之用”，我们在使用中直接理解它，而非将其视为一个客观对象。
  • 操劳 (Besorgen / concern)：此在（人）与上手事物打交道的基本方式，是一种忙于事务、投入使用的生存活动。
  • 指引 (Verweisung / reference)：工件与世界的基本关联结构。一个工件总是指向它的用途（何所用）、材料来源（何所来）以及使用者，这些指向共同组建了工件所处的意义整体。
  • 照面 (Begegnen / encounter)：存在者在我们的操劳活动中与我们相遇、显现自身的方式。
  • 世界 (Welt / world)：不是一个物理空间的集合，而是此在生存于其中、由意义关联整体所构成的现象。它包括“工场家庭世界”、“公众世界”等，是此在理解自身和事物的境域。
  • 周围世界 (Umwelt / environment-world)：此在直接生活于其中、由上手事物及其指引关系所构成的切近世界。
  • 寻视 (Umsicht / circumspection)：操劳活动所特有的一种“看”，它不是理论凝视，而是在使用事物的活动中对情境的 practical understanding（实践理解）。

2. 逐句转译

  1. 原文：制好的工件不仅指向它的合用性的何所用、它的成分的何所来；在简单的手工业状况下，它同时还指向承用者和利用者。

    • 转译：一件被制作完成的工具（工件），它的意义不仅仅在于它有什么用（合用性的目的），以及它是由什么材料做成的。在传统手工作坊的条件下，这件工具还清晰地指向将要使用它、接受它服务的具体的人。

  2. 原文：工件是依他量体剪裁而就，在工件的产生过程中他也一道“在”那里。

    • 转译：这件工具就像是为他量身定做的，在工具被制造出来的过程中，这个未来的使用者其实已经“在场”了——他的需求已经被考虑在内。

  3. 原文：在批量生产中绝不缺乏这种具有组建作用的指引，只不过这种指引是不确定的罢了，它指向随便哪些人，指向平均。

    • 转译：即使在现代批量生产中，工具指向使用者这种构成性的关系也依然存在，只不过变得模糊不清了。它不再指向某个具体的人，而是指向一个模糊的、“平均的”、随便哪个消费者。

  4. 原文：这么看起来，随着工件一起来照面的不仅有上手的存在者，而且也有具有人的存在方式的存在者。

    • 转译：由此可见，当我们使用一件工具时，与我们打交道的不仅仅是这个作为工具的存在者本身，同时还有以“人的方式”存在的他人（使用者或消费者）。

  5. 原文：操劳活动所制作的东西就是为人而上手的。承用者和消费者生活于其中的那个世界也随着这种存在者来照面，而那个世界同时就是我们的世界。

    • 转译：我们忙碌制作出的东西，本质上就是供人使用的。于是，使用者和消费者所生活于其中的那个世界（他们的生活方式、社会关系等），也随着这个工具一同向我们显现出来。而且，这个世界并不是一个外在于我们的世界，它同时也是我们所共有的世界。

  6. 原文：操劳所及的工件在工场的家庭世界中上手，而且也在公众世界中上手。

    • 转译：我们日常打交道的工具，既可以在像家庭作坊这样私密、熟悉的世界里被使用，也可以在像市场、社会这样的公共世界里被使用。

  7. 原文：周围世界的自然随着这个公众世界被揭示出来，成为所有人都可以通达的。

    • 转译：我们生活于其中的自然环境，也通过这个公共世界向我们展现出来，并且成为所有人都能够理解和接触到的东西。

  8. 原文：在小路、大街、桥梁、房舍中，自然都在一定的方向上为操劳活动所揭示。

    • 转译：比如，在小路、大街、桥梁、房屋这些人工物中，自然界其实已经被我们的日常活动以某种特定的方式揭示和利用了（例如，路是顺着地势修的，桥是跨越河流的）。

  9. 原文：带顶篷的月台考虑到了风雨，公共照明设备考虑到了黑暗，也就是说，考虑到了日光间有间无的这种特殊变化，考虑到了“太阳的位置”。

    • 转译：带顶棚的月台是为了应对风雨而建的，公共照明是为了应对黑暗而设的。这实际上意味着，我们的设计已经考虑到了自然现象（比如阳光的有无、太阳的位置）的变化规律。

  10. 原文：在钟表中则考虑到了宇宙系统中的一定的星辰位置。

    • 转译：钟表的设计，则更是考虑到了宇宙天体的运行规律（比如地球自转和公转）。

  11. 原文：当我们看表的时候，我们不知不觉地使用了“太阳的位置”，官方天文学就是按照“太阳的位置”来调整时间量度的。

    • 转译：当我们看表时，我们其实在不自知的情况下，就在运用着“太阳位置”所定义的时间系统，因为官方的计时标准（如时区）就是根据天文观测（太阳位置）来制定的。

  12. 原文：在使用当下而不显眼地上手的钟表设备之际，周围世界的自然也就共同上手了。

    • 转译：所以，在我们再自然不过地、不假思索地使用钟表时，我们生活于其中的整个自然环境（天体运行规律）也一同被我们“使用”着、理解着了。

  13. 原文：任何消散在最切近的工件世界中的操劳都具有揭示功能。

    • 转译：总之，任何投入、沉浸于我们身边工具世界中的日常忙碌活动，本身都具有一种“让事物显现出来”的功能。

  14. 原文：这种揭示功能的本质就是：按照消散于工件世界的方式，那个在工件中——亦即在起组建作用的指引中——被连带指引出的世内的存在者总是在种种不同的明确程度上、在寻视所突入的种种不同深度上保持其为可揭示的。

    • 转译：这种揭示功能的根本特点是：根据我们投入工具世界的具体方式，那些通过工具（以及工具所构成的指引关系）而连带指向的世界内的存在者（比如自然、他人、社会），总是以不同的清晰度、在不同的理解深度上，持续地向我们保持着开放，等待我们去发现和揭示。

3. 论证逻辑梳理

  1. 前提：工件（工具）的存在本质在于其“指引”结构，它不仅指向用途和材料，也指向使用者。
  2. 初步推进：从具体手工生产（指向特定使用者）推进到批量生产（指向“平均的”使用者），论证了“指向使用者”这一指引的普遍性。由此得出结论：通过工件，我们不仅接触到物，也接触到人。
  3. 进一步拓展：将“人”拓展到“人的世界”。工件是为人的，因此使用者和他们所处的世界（家庭世界、公众世界）也随工件一同显现。这个世界是共有的世界。
  4. 核心例证与深化：以公共设施（月台、照明）和钟表为例，具体展示“自然”如何通过工件的指引网络被纳入并揭示于我们的世界之中。论证从“人造物包含自然因素”深入到“在使用人造物时，我们其实在不自知地运用着自然规律”。
  5. 最终结论：总结并提炼出核心论点——沉溺于工件世界的日常操劳本身具有“揭示”功能。这种揭示是动态的、有层次的，取决于我们与工件打交道的具体方式和深度。

4. 整体概括

这段文字的核心在于阐明，我们日常生活中使用的任何工具（工件），都绝非孤立的物件。它们像一个网络节点，天然地指向它们的用途、材料来源，以及最关键的是——指向使用它们的人，以及这些人所生活于其中的整个世界。即使在大规模生产中，这种指向变得模糊（指向“平均”消费者），但它依然存在。因此，当我们使用一件工具时，我们实际上是在与一个庞大的意义网络打交道，这个网络包括了他人、社会关系，甚至整个自然界。海德格尔通过月台、钟表等生动的例子告诉我们，我们习以为常的公共设施和计时工具，其实已经将风雨、昼夜、乃至天体运行等自然规律，悄无声息地融入了我们的日常生活。所以，我们沉浸于工具使用中的每一种忙碌（操劳），都不仅仅是在完成具体任务，更是在以一种或深或浅、或明或暗的方式，不断地揭示和理解着我们身处其中的整个世界。

5. 争议与说明

本段解读相对一致。核心思想——“上手事物（工件）在其指引整体中连带揭示出世界（包括他人与自然）”——是《存在与时间》中关于“世界性”论述的关键部分，学界对此基本框架争议不大。可能的细微讨论点在于对“公众世界”与“工场家庭世界”之间关系的具体理解，但这段文字主要旨在展示指引网络的普遍性，并未深入探讨不同世界层次间的复杂动态，因此在此不构成主要争议。
