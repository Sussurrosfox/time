海德格尔 原文
但是，即使在更加深入的存在论阐释中果真能够证明上手状态乃是在世界内首先被揭示的存在者的存在方式，甚至证明上手状态对纯粹在手状态的源始性，迄今所讲的东西是否就使我们略许增益了对世界现象的存在论领会呢？其实我们在阐释这种世内存在者之际总已经“预先设定”了世界。世内存在者的拼合并不产生作为总和的“世界”这样的东西。那么，世内存在者的存在究竟能引导我们把世界现象展示出来呢？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 上手状态（Zuhandenheit）：海德格尔用此概念描述我们日常与工具、物品打交道时，它们不是作为冷冰冰的客观对象摆在那里，而是作为“为了……之用”的东西，融入了我们的活动整体中。比如锤子，我们用它时并不先思考“这是一个有重量的木质物体”，而是直接用来敲钉子。它处于不显眼的、熟练使用的状态。

  • 在手状态（Vorhandenheit）：与“上手状态”相对，指的是事物仅仅作为现成摆在眼前的、与我们的活动无关的客观对象。比如锤子坏了，我们把它当作一个需要研究的物体观察它的材质、结构，这时它就从“上手状态”转变为“在手状态”。

  • 源始性（Ursprünglichkeit）：指的是在存在论上更根本、更优先的地位。说A对B有源始性，意味着A是B的基础，B是从A派生出来的。

  • 世界（Welt）：在海德格尔哲学中，“世界”不是一个所有存在者加起来的总和，也不是物理宇宙，而是此在（人）生存于其中的、由意义关系构成的整体境域。是此在理解自身与事物的背景和视野。

  • 世内存在者（das innerweltlich Seiende）：指的是在世界之中、被我们所遭遇的各种具体事物，无论是上手的工具还是在手的对象。

  • 存在论（Ontologie）：探究“存在”本身的意义的哲学研究。它不问“这个东西是什么属性？”，而是问“这个东西‘存在’意味着什么？”。

2. 逐句转译

  • “但是，即使在更加深入的存在论阐释中果真能够证明上手状态乃是在世界内首先被揭示的存在者的存在方式，甚至证明上手状态对纯粹在手状态的源始性，迄今所讲的东西是否就使我们略许增益了对世界现象的存在论领会呢？”

  • 这句话是说：退一步讲，就算我们能从哲学上证明，我们最初接触事物时，是以“上手状态”（融入使用的状态）的方式，并且这种状态比“在手状态”（纯观察对象的状态）更根本、更优先。但我们之前讨论的这些内容，真的让我们对“世界”这个最根本的现象，有了更深的理解吗？答案很可能是否定的。

  • “其实我们在阐释这种世内存在者之际总已经‘预先设定’了世界。”

  • 我们在理解和使用任何一个世内存在者（比如一个锤子）时，其实已经不知不觉地以整个“世界”（那个意义关联的整体）为前提和背景了。没有这个背景，单个事物就无法作为有意义的东西出现。

  • “世内存在者的拼合并不产生作为总和的‘世界’这样的东西。”

  • “世界”不是像搭积木一样，把所有世内存在者（一个一个的东西）加起来就能得到的。“世界”是这些东西得以显现和具有意义的那个整体场域，它本身不是另一个更大的“东西”。

  • “那么，世内存在者的存在究竟能引导我们把世界现象展示出来呢？”

  • 所以，仅仅通过研究世内存在者本身（无论是研究它的上手状态还是在手状态），我们真的能反过来揭示和说明“世界”这个最根本的现象吗？海德格尔在这里提出了一个根本性的质疑。

3. 论证逻辑梳理

  1. 前提/让步：即使我们接受了“上手状态是世内存在者最先显现的方式”且“上手状态比在手状态更源始”这两个核心论点。
  2. 核心质疑：这些关于“世内存在者”的发现，并没有直接解答关于“世界”本身的问题。我们对“世界”的理解依然模糊。
  3. 关键分析：指出我们理解任何“世内存在者”时，都已经预设了“世界”的存在。“世界”是理解事物的先决条件，而不是从它们中推导出的结果。
  4. 进一步论证：“世界”不是所有存在者的简单加总，它在性质上不同于任何世内存在者。
  5. 结论/新问题：因此，仅仅通过分析“世内存在者”的存在方式，这条路径本身可能是有问题的，无法通达“世界”现象的核心。这实际上是在为下文转向直接分析“世界”本身和“此在在世”做铺垫。

4. 整体概括

这段话的核心在于划清界限并提出一个方法论上的转折。海德格尔承认，之前对“上手状态”和“在手状态”的精彩分析，虽然揭示了我们在世界中与事物打交道的基本方式，但这并没有直接帮助我们理解“世界”本身到底是什么。因为我们总是在一个已经展开的“世界”背景下去接触和使用具体事物的，“世界”就像是舞台，事物是舞台上的演员。你研究再多的演员（世内存在者），也研究不出舞台（世界）的本质。因此，他质疑并试图超越这条从“部分”（世内存在者）推导“整体”（世界）的传统思路，暗示需要一条更直接的路径来探究“世界”现象。

5. 争议与说明

本段解读相对一致。其核心意图是进行方法论上的自我审视和转折，为从对“世内存在者”的分析转向对“世界”和“此在在世”的直接分析铺路。学界普遍认同这是《存在与时间》论证推进中的一个关键节点，没有重大的解释分歧。
