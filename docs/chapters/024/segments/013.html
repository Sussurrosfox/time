📖 《存在与时间》研读 逐段解析
首页 / 第 024 章 / 片段 013
📜 原文片段 (024/013)
海德格尔 原文
这里却不可把自然了解为只还现成在手的东西，也不可了解为自然威力。森林是一片林场，山是采石场，河流是水力，风是“扬帆”之风。随着被揭示的周围世界来照面的乃是这样被揭示的“自然”。人们尽可以无视自然作为上手事物所具有的那种存在方式，而仅仅就它纯粹的现成状态来揭示它、规定它，然而在这种自然揭示面前，那个“澎湃争涌”的自然，那个向我们袭来、又作为景象摄获我们的自然，却始终深藏不露。植物学家的植物不是田畔花丛，地理学确定下来的河流“发源处”不是“幽谷源头”。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 自然：在海德格尔哲学中，通常指与我们打交道的、作为我们生存活动背景的环境整体，它首先以“上手事物”的方式与我们照面，而不是作为独立于我们活动的客观对象。在本段中，海德格尔特别强调，不能将自然理解为纯粹的、与我们无涉的“现成在手”之物，也不能理解为某种原始的、野性的“自然威力”。
  • 上手事物：指那些在我们日常活动中直接使用、与之打交道的工具或物品，它们因其有用性而融入我们的生存活动，而非作为被观察和分析的孤立对象。
  • 现成在手：指仅仅作为一个客观存在、与我们当下的活动无关的对象，它被从我们的生存活动和世界中抽离出来，成为一个纯粹的、可供观察和研究的客体。
  • 周围世界：指我们日常生存于其中、并通过我们的活动与之打交道的世界，这个世界由各种“上手事物”及其关联构成。
  • 揭示：指事物通过我们的生存活动和理解，从其隐藏状态中显现出其存在方式和意义的过程。

2. 逐句转译

  • “这里却不可把自然了解为只还现成在手的东西，也不可了解为自然威力。”
    这里所说的自然，不能被理解成仅仅作为一个客观存在的、与我们无关的物体，也不能被理解为某种原始、野性的自然力量。

  • “森林是一片林场，山是采石场，河流是水力，风是‘扬帆’之风。”
    在我们日常的活动中，森林是作为提供木材的林场出现的，山是作为开采石料的采石场出现的，河流是作为可以利用的水力资源出现的，风是作为可以帮助帆船航行的“扬帆之风”出现的。这些都不是作为独立的、客观的自然对象，而是作为我们活动的一部分、对我们有用的东西。

  • “随着被揭示的周围世界来照面的乃是这样被揭示的‘自然’。”
    随着我们日常活动的世界被揭示出来，我们所遇到的“自然”就是以上述这种方式——作为我们活动的一部分、对我们有用的东西——显现出来的。

  • “人们尽可以无视自然作为上手事物所具有的那种存在方式，而仅仅就它纯粹的现成状态来揭示它、规定它，”
    人们完全可以忽略自然作为我们日常活动中使用的工具（上手事物）的存在方式，而只把它当作一个纯粹的、客观存在的对象来研究和定义，

  • “然而在这种自然揭示面前，那个‘澎湃争涌’的自然，那个向我们袭来、又作为景象摄获我们的自然，却始终深藏不露。”
    但是，通过这种（客观研究的）方式所揭示的自然，那个充满生命力、汹涌澎湃、直接冲击我们、以其景象深深吸引我们的自然，却始终没有被触及，仍然是隐藏的。

  • “植物学家的植物不是田畔花丛，地理学确定下来的河流‘发源处’不是‘幽谷源头’。”
    植物学家研究的植物标本，并不是我们在田间地头看到的、生机勃勃的花丛；地理学所确定的河流“发源地”，也不是那个我们感受到的、充满神秘和意境的“幽谷源头”。

3. 论证逻辑梳理

  1. 前提设定：首先，海德格尔明确了讨论的起点——我们不能将自然理解为纯粹的“现成在手”之物或抽象的“自然威力”。
  2. 正面阐述：接着，他通过具体例子（森林作为林场、山作为采石场等）说明，自然首先是作为我们日常活动世界（周围世界）的一部分，以“上手事物”的方式与我们照面。这是自然最原初的显现方式。
  3. 批判性转折：他指出，人们可以选择忽略自然这种原初的存在方式，转而将其视为纯粹的客观对象（现成在手状态）进行研究。
  4. 揭示局限：通过这种客观化、理论化的研究方式，自然的另一个维度——即那个充满生机、直接触动我们的、活生生的自然——反而被遮蔽了，无法被触及。
  5. 举例强化：最后用植物学家研究的植物与田畔花丛、地理学的发源处与“幽谷源头”的对比，形象地强调了理论化的“自然”与原初生活经验中的“自然”之间的根本差异。

4. 整体概括

这段话的核心是批判我们通常将自然视为一个纯粹的、客观的研究对象的做法。海德格尔指出，在我们最原初、最日常的生活经验中，自然并不是一个冷冰冰的客体，而是作为我们生活世界的一部分，与我们的活动息息相关、对我们“有用”的东西，比如森林是提供木材的林场，风是帮助我们航行的动力。当我们用科学的、理论化的眼光，试图将自然剥离出来，仅仅作为一个客观对象来研究和定义时（比如植物学或地理学的方式），我们实际上已经远离了那个活生生的、直接触动我们的自然。我们得到的只是一个被抽象化、概念化的自然，而那个充满生命力、能直接冲击和吸引我们的、原初的自然经验反而被遮蔽和遗忘了。

5. 争议与说明

本段解读相对一致。核心争议点通常不在于对本段字面意思的理解，而在于如何更精确地把握“上手状态”与“现成在手状态”的关系，以及这种区分在海德格尔整体哲学中的权重。有学者强调这是一种存在论上的优先性次序（上手优先于现成在手），而另一些解读则更谨慎，认为海德格尔意在揭示两种不同的揭示方式，而非简单地贬低科学认知。但就本段而言，其主旨是清晰地批判对自然的纯粹理论化、对象化认知所造成的遮蔽，这一点的理解是广泛共识。
