📖 《存在与时间》研读 逐段解析
首页 / 第 095 章 / 片段 010
📜 原文片段 (095/010)
海德格尔 原文
约克归根到底是在要求一种走在科学前面并领导科学的逻辑，就像柏拉图和亚里士多德的逻辑那样。在这一要求中包括一项任务：积极而截然地为两种存在者—一种作为自然存在，另一种〔此在〕作为历史存在—制订出相互区别的范畴结构。约克发现狄尔泰的探索“太少注重存在者层次上的东西与历史学上的东西之间的发生上的差别”〔第191页，重点号为作者所加〕。“尤其是您要求把比较的方法当作人文科学的方法来使用。这里我与您有分歧。…比较总是美学上的，总依附于形态。文德尔班把多种形态赋予历史。您的类型概念是完完全全内在的概念。因为这里的关键是性质，而不是形态。对文德尔班来说，历史是一系列图像、各别的形态——一种美学要求。对于自然科学家来说，除了科学而外，只还有一种美学享受，作为一种人生的镇静剂。您的历史概念却是一种力量纠结的概念，是种种力量统一体的概念，形态这一范畴只能以转义方式应用到这些概念上”〔第193页〕。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 逻辑：在海德格尔哲学中，这里的“逻辑”并非现代形式逻辑，而是指一种更本源的存在论方法，它能够先行于并指导各门科学。它揭示的是事物存在的根本结构，类似于古希腊哲学中那种探究“存在本身”的学问。
  • 存在者：泛指一切“存在着的东西”。在本段中，特别区分了两种存在者：
  • 自然存在者：指那些作为现成在手、受因果规律支配的物理对象，比如石头、树木等。
  • 历史存在者：特指“此在”（Dasein），即人的存在。其本质在于它在时间中展开，具有历史性，它的存在就是它的“去存在”过程。
  • 范畴结构：指用来规定和理解不同类型“存在者”的基本概念框架。自然存在和历史存在需要不同的范畴结构来理解。
  • 存在者层次上的东西：指实际存在的、具体的事物和事实层面。
  • 历史学上的东西：指在历史研究中被理解和解释的存在，它关注的是历史的意义和内在关联。
  • 形态：指外在的、静态的形式、样貌或结构。约克和文德尔班用它来描述历史，将历史视为一系列分离的图像或类型。
  • 性质：指内在的、动态的、构成事物本质的力量或关系。狄尔泰的历史概念强调历史是“力量纠结的概念”，关注的是内在的动力结构而非外在形态。
  • 此在：海德格尔哲学的核心概念，指人的存在方式。其本质在于它的“生存”（Existenz），即它总是处在筹划、理解自身和世界的动态过程中。

2. 逐句转译

  • 第一句： 约克的根本主张是，需要一种能够走在科学前面、并为科学指明方向的逻辑，就像柏拉图和亚里士多德的逻辑曾经做到的那样。
  • 第二句： 要实现这个主张，就必须完成一项具体任务：为两种不同的存在者——一种是自然界的事物，另一种是作为历史性存在的人（此在）——分别建立各自独特的概念框架（范畴结构）。
  • 第三、四句： 约克批评狄尔泰的研究，认为他过于忽略了“实际存在的自然事物”与“被历史学所研究的历史事物”这两者之间，在“如何产生和存在”这个问题上的根本差异。（约克引文1）
  • 第五至九句： 约克进一步指出，他尤其不赞同狄尔泰将“比较的方法”作为人文科学的根本方法。他认为，比较方法本质上是美学式的，它关注的是事物的外在形态。文德尔班就是把历史看成各种不同的形态或图像，这是一种美学的要求。相反，对于狄尔泰来说，历史概念的核心不是形态，而是内在的“性质”，是各种力量相互交织、形成的动态统一体。“形态”这个概念，根本无法准确描述历史的这种力量关系，只能勉强借用一下。（约克引文2）

3. 论证逻辑梳理

  • 前提（第一句）： 提出一个高标准的目标——需要一种能领导科学的、本源性的“逻辑”。
  • 任务推导（第二句）： 为了实现这个目标，必须完成一项核心任务，即为自然存在和历史存在（此在）制定不同的范畴结构。这指出了方法论上的关键分水岭。
  • 引入批判（第三、四句）： 以约克对狄尔泰的批评为例，证明狄尔泰的工作恰恰没有完成这个任务，因为他忽视了自然存在与历史存在在“发生”（即存在方式）上的根本差异。
  • 具体论证与对比（第五至九句）： 通过剖析“比较方法”和“形态”概念，深化了上述批判。论证逻辑如下： 1. 指出狄尔泰的核心方法（比较法）是有问题的，因为它本质是美学的、依附于形态的。 2. 将文德尔班的历史观（作为形态系列）作为反面典型，暗示狄尔泰与之有潜在相似性。 3. 明确狄尔泰历史概念的核心是“力量”和“性质”，这比“形态”更深入。 4. 得出结论：“形态”范畴不适合描述历史的动态本质，从而有力地支持了“必须为历史存在建立独特范畴”这一核心论点。

4. 整体概括

这段文字的核心是借由约克伯爵对狄尔泰的批评，来强调一个关键哲学任务：必须为“自然存在”和“历史存在”（即人的存在，此在）这两种根本不同的东西，建立起各自专属的理解框架。约克认为，狄尔泰的失误在于，他使用的工具（如比较方法）和关注的焦点（形态）仍然是美学化和静态的，这模糊了自然对象（如一个化石）与历史生命（如一个人的生平）之间最根本的区别——前者是现成的、可分类的形态，后者则是活生生的、由内在力量和关系构成的动态过程。因此，研究历史不能照搬研究自然的方法，必须找到能抓住其“生命力量”本身的逻辑。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对约克与狄尔泰思想关系的精确界定：一种解读认为约克是在根本上否定狄尔泰，另一种解读则认为约克是敏锐地指出了狄尔泰思想中尚未彻底化、仍受自然科学方法论束缚的部分，是在推动狄尔泰思想走向更彻底的存在论根基。但总体上都认同本段旨在强调自然存在与历史存在在范畴上的根本差异。
