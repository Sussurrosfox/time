📜 原文片段 (095/013)
海德格尔 原文
“真正的语言文献学家把历史学理解为文物箱。哪里没有可触的东西，这些先生们就从不涉足，——唯有一脉相通的灵犀才能把我们导向那里。他们在骨子里是些自然科学家；而且因为缺乏实验，他们更变成了怀疑论者。我们得远避所有那些无用的材料，例如关于柏拉图曾多少次到过大希腊或叙拉古之类。那里没什么有生命的东西。我现在已用批判的眼光透视了这种外在的姿态，它最终归结为一个大间号，而在荷马、柏拉图、新约的伟大实在面前黯然失色。一切实际上实在的东西，如果被当作物自身来考察，如果离开了体验，就都会变成幻象”〔第61页〕。“这些科学家们和时间的威势相对峙，一如精致的法国社会和当时的革命运动相对峙。两下都是形式主义，对形式的崇拜。对关系的种种规定成了智慧的结语。这一思维方向当然有它的历史，我想那是尚未成文的历史。从认识论上考察起来，这种思想及对这种思想的信念是一种形而上学的活动，它们的无根基状态是历史的产物”〔第39页〕。“四百多年前偏心率原理引出了一个新时代；在我看来，偏心率原理所喷出的浪潮已宽泛到了它的极限了；认识进步到了扬弃它自身的田地，人远远地出离了他自己，乃至他不再为他自己所看到。‘现代人’，亦即文艺复兴以来的人，已行将入墓”〔第83页〕。另一方面，“一切真有生命的而非仅仅涂上一层生命的历史学则是批判”〔第19页〕。“但历史知识中最好的一部分是隐蔽的关于资料来源的知识”〔第109页〕。“说到历史，造成景观、触动眼目的东西不是要事。神经看不见，正如一般本质性的东西看不见一样。有话说：‘静则强’，而这话变一个样子也是真的：‘静则觉，则会’”，〔第26页〕。“于是我乐于静静地与自己对话，乐于与历史精神相往来。这一精神不曾在浮士德的书斋里向他显象，也不曾向大师歌德显象。但它若显象，纵便咄咄逼人，他们也不会惊恐避让。因这种显象亲如手足，比起林边田间的居民，它们与我们的亲缘有一种不同的、更深的意义。这努力与雅各的角斗有相似之处：角斗者已知赢定了。而这是最要紧的”〔第133页〕。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 语言文献学家：指传统历史研究中专注于文本考据、文物收集与考证的学者。在海德格尔看来，这类研究过于依赖外在、可触的实证材料，却忽略了历史的“生命”与“精神”。

  • 历史学：在此段中具有双重含义：一种是传统理解中的“文物箱”式历史学，即堆积事实与材料；另一种是海德格尔所主张的“有生命的历史学”，即通过内在体验与批判，触及历史的本质精神。

  • 体验：指人对于存在的直接、内在的领会，不是通过外在观察或材料堆积，而是通过一种“灵犀相通”的参与。

  • 批判：在此并非否定或批评，而是指一种穿透表象、触及本质的思考方式，是对历史材料的内在审视与精神对话。

  • 偏心率原理：隐喻自哥白尼革命中的“日心说”，在此象征文艺复兴以来以人为中心、理性至上的现代思想传统。海德格尔认为这一思想浪潮已走到尽头。

  • 历史的产物：指某种思想或信念并非永恒真理，而是特定历史条件所塑造的结果，其本身具有“无根基状态”。

  • 历史精神：不是指具体的历史事件或人物，而是历史中蕴含的、需要通过内在对话才能触及的本质性力量。

2. 逐句转译

  • “真正的语言文献学家把历史学理解为文物箱。哪里没有可触的东西，这些先生们就从不涉足，——唯有一脉相通的灵犀才能把我们导向那里。”
    → 那些研究古代文献的学者，把历史当作装满古董的箱子。他们只关心能摸得着、看得见的东西，而真正理解历史，需要的是那种心灵相通的直觉。

  • “他们在骨子里是些自然科学家；而且因为缺乏实验，他们更变成了怀疑论者。”
    → 他们的思维方式其实和自然科学家一样，但因为历史无法做实验，他们就更容易变成怀疑一切的人。

  • “我们得远避所有那些无用的材料，例如关于柏拉图曾多少次到过大希腊或叙拉古之类。那里没什么有生命的东西。”
    → 我们不应该沉迷于那些琐碎的材料，比如柏拉图去过几次西西里岛之类的考据，这些是没有生命力的。

  • “我现在已用批判的眼光透视了这种外在的姿态，它最终归结为一个大问号，而在荷马、柏拉图、新约的伟大实在面前黯然失色。”
    → 我现在看透了这种外在的研究方式，它最终只剩下一个巨大的疑问，在像荷马史诗、柏拉图哲学、《新约》这样真实而有力量的历史遗产面前，显得苍白无力。

  • “一切实际上实在的东西，如果被当作物自身来考察，如果离开了体验，就都会变成幻象。”
    → 即使是真实存在的东西，如果只被当作一个外在对象来研究，而不通过内在体验去理解，就会变成虚幻的假象。

  • “这些科学家们和时间的威势相对峙，一如精致的法国社会和当时的革命运动相对峙。”
    → 这些学者试图对抗时间的洪流，就像法国上流社会试图对抗大革命一样，都是徒劳的。

  • “两下都是形式主义，对形式的崇拜。对关系的种种规定成了智慧的结语。”
    → 两者都陷入形式主义，只关注表面的规则和关系，以为这就是智慧的终点。

  • “这一思维方向当然有它的历史，我想那是尚未成文的历史。”
    → 这种思维方式也有它的历史根源，只是这段历史还没有被人真正书写出来。

  • “从认识论上考察起来，这种思想及对这种思想的信念是一种形而上学的活动，它们的无根基状态是历史的产物。”
    → 从认识论的角度看，这种思想及其信念其实是一种形而上学活动，它们的虚无状态是由历史条件造成的。

  • “四百多年前偏心率原理引出了一个新时代；在我看来，偏心率原理所喷出的浪潮已宽泛到了它的极限了。”
    → 四百多年前，哥白尼革命开启了一个新时代；但现在，这股浪潮已经走到了尽头。

  • “认识进步到了扬弃它自身的田地，人远远地出离了他自己，乃至他不再为他自己所看到。”
    → 人类的认识已经发展到要超越自身的地步，人离自己太远，以至于看不清自己是谁。

  • “‘现代人’，亦即文艺复兴以来的人，已行将入墓。”
    → 现代人，也就是文艺复兴以来那种以人为中心的人，快要走到尽头了。

  • “一切真有生命的而非仅仅涂上一层生命的历史学则是批判。”
    → 真正有生命的历史学，不是表面涂了一层生命色彩，而是批判性的。

  • “但历史知识中最好的一部分是隐蔽的关于资料来源的知识。”
    → 但历史知识中最重要的部分，其实是隐藏在资料来源背后的东西。

  • “说到历史，造成景观、触动眼目的东西不是要事。神经看不见，正如一般本质性的东西看不见一样。”
    → 历史中那些表面引人注目的东西并不重要。就像神经看不见一样，真正本质的东西也是看不见的。

  • “有话说：‘静则强’，而这话变一个样子也是真的：‘静则觉，则会’。”
    → 有人说“静则强”，但换个说法也是对的：“静则觉，则会”——只有在静中才能觉察、才能理解。

  • “于是我乐于静静地与自己对话，乐于与历史精神相往来。”
    → 所以我喜欢安静地与自己对话，也喜欢与历史的精神交流。

  • “这一精神不曾在浮士德的书斋里向他显象，也不曾向大师歌德显象。”
    → 这种精神不曾显现在浮士德的书房里，也不曾显现在歌德面前。

  • “但它若显象，纵便咄咄逼人，他们也不会惊恐避让。因这种显象亲如手足，比起林边田间的居民，它们与我们的亲缘有一种不同的、更深的意义。”
    → 但如果它真的显现，即使来势汹汹，他们也不会害怕躲避。因为这种显现就像亲人一样，比乡间居民与我们更亲近，有一种更深层的血缘关系。

  • “这努力与雅各的角斗有相似之处：角斗者已知赢定了。而这是最要紧的。”
    → 这种努力就像《圣经》中雅各与天使角斗一样：角斗的人知道自己一定会赢。这才是最重要的。

3. 论证逻辑梳理

  1. 前提：传统历史研究（语言文献学）只关注外在材料，忽视内在体验，导致历史失去生命力。

  2. 分析推进： - 指出这种研究方式本质上是自然科学思维的延伸，但因无法实验而沦为怀疑主义。 - 批判外在材料研究在面对伟大经典时的无力。 - 提出“体验”是理解历史实在的关键，否则一切都会变成幻象。

  3. 扩展批判： - 将这种思维与法国大革命时期的“形式主义”类比，指出其历史根源与无根基性。 - 进一步指出现代认识论已走到尽头，人已迷失自我。

  4. 正面主张： - 真正有生命的历史学是批判性的，关注隐藏的本质。 - 强调“静”的重要性，唯有静中才能触及本质。 - 提出与“历史精神”的内在对话，是一种必然胜利的精神角斗。

  5. 结论：历史研究不应停留于表象，而应通过静观、批判与内在体验，与历史精神进行深层对话。

4. 整体概括

这段文字批判了传统历史研究过于依赖外在材料、忽视内在体验的弊端，指出这种“文物箱”式的研究在面对伟大历史遗产时显得苍白无力。海德格尔认为，真正有生命的历史学应当是一种批判性的、静观的精神活动，通过内在体验与历史精神对话。他进一步指出，自文艺复兴以来的现代认识论已走向尽头，人已远离自我；唯有通过静观与内在角斗，才能重新触及历史的本质，赢得与历史精神的深层亲缘关系。

5. 争议与说明

本段内容在海德格尔早期思想中较为边缘，争议不大。但其中对“历史精神”的理解可能引发两种解读：

  • 主流解读：认为“历史精神”是海德格尔对历史本质性力量的呼唤，强调人通过内在体验与之交融。
  • 另类解读：少数研究者认为，此处带有某种神秘主义倾向，与后期海德格尔的“存在历史”思想有所呼应，但尚未充分展开。

整体而言，本段解读在学界相对一致，争议不显著。
