结构化精读

1. 术语释义

  • 可能状态（Möglichsein）：在海德格尔哲学中，此在（人的存在）的本质特征之一，指此在始终处在“尚未完成”的状态，它面向未来，不断筹划和实现自身的可能性。此在不是现成的、固定不变的实体，而是通过不断选择和行动来展开其存在。在本段中，约克将“可能状态”视为历史的基本性质，意味着历史不是已完成的、封闭的事实总和，而是由人的生存可能性不断生成的动态过程。

  • 此在（Dasein）：海德格尔哲学的核心概念，特指人的存在方式。此在的本质是“生存”，即它总是关心和追问自己的存在，并通过在世活动（如理解、情绪、言谈）展开自身。在本段中，约克通过认识此在的存在性质（即它的历史性和可能性）而获得对历史的洞见。

  • 历史性（Geschichtlichkeit）：此在的根本存在方式之一，指此在不是孤立的存在，而是始终已被抛入一个历史情境中，并通过对传统的承袭和未来的筹划来构成自身。历史性不是外在的、客观的历史进程，而是此在内在的、构成性的时间性结构。本段强调，哲学思考不能脱离这种历史性。

  • 心理物理的给定状态（psychophysische Gegebene）：传统哲学和心理学中的概念，将人视为由心理（精神）和物理（身体）两部分构成的现成对象。约克反对这种观点，认为人不是静态的“给定”实体，而是“生活着”的、动态的历史性存在。

  • 非历史化（Entgeschichtlichung）：指哲学或科学方法试图脱离历史性，追求一种超越时间、普遍有效的理论体系。约克批判这种做法，认为它割裂了哲学与历史的本质联系。

2. 逐句转译

  • 第一句：约克清晰地洞察到，“可能状态”是历史的基本性质；他是通过认识人的此在本身的存在性质而获得这种洞察的。也就是说，他不是从科学理论出发，而是直接从历史考察的具体对象（即人的生存）中看到这一点的。

  • 第二句：“整个心理物理的给定状态并非存在着（存在=自然的现成存在），而是生活着，这是历史的萌发点。”——约克认为，人不是一个由心理和身体拼凑而成的现成对象，而是一个活生生的、不断展开的存在过程，这才是历史的真正起点。

  • 第三句：“对自身的思考并不指向一个抽象的我而是指向我自身的全幅；这种思考发现我是从历史学上规定的，正如物理学认识到我是从宇宙论上规定的。”——当我们反思自己时，并不是在思考一个抽象的“自我”概念，而是面对完整的、具体的自己。这种反思揭示出：我的存在是由历史所塑造的，就像物理学揭示出我的身体是由宇宙规律所决定的一样。

  • 第四句：“我是历史，一如我是自然的。”——我的存在既是历史的（由传统和未来可能性构成），也是自然的（有物理身体和生物规律），两者不可分割。

  • 第五句：约克看透了那些不真实的“关系规定”和“无根基”的相对主义；他毫不犹豫地从对此在历史性的洞察中得出最终结论。

  • 第六句：“然而另一方面，就自我意识的内在历史性说，一种从历史中离异出来的体系在方法论上是不充分的。”——从自我意识本质上具有历史性这一点来看，任何试图脱离历史的哲学体系在方法上都是有缺陷的。

  • 第七句：“正像心理学不能从物理学抽离开一样。哲学，尤其当它是批判性的时候，也不能从历史性抽离开来…”——就像心理学不能脱离对人的物理存在的研究一样，哲学（尤其是批判性哲学）也不能脱离历史性。

  • 第八句：“自身的行为与历史性就像呼吸与气压一样，而且，即使听起来有几分悖谬，但从方法的联系上来说，哲学运动的非历史化在…”——我们的行动与历史性的关系，就像呼吸与气压的关系一样密不可分。虽然听起来有些矛盾，但从方法论的角度看，哲学试图摆脱历史性是不可能的（原文在此中断）。

3. 论证逻辑梳理

  • 前提：约克认识到此在的存在性质（尤其是其历史性和可能状态），并且这种认识不是来自抽象理论，而是来自对历史生存的直接考察。

  • 核心论证： 1. 首先确立历史的起点不是现成的“心理物理给定状态”，而是活生生的“生活”本身。 2. 通过对自我的具体反思，证明人的存在既由历史规定，也由自然规定，二者统一于“我是历史，一如我是自然的”。 3. 基于此在的历史性本质，批判那些脱离历史的哲学体系和方法，认为它们就像让心理学脱离物理学一样荒谬。 4. 通过“呼吸与气压”的比喻，强调历史性与哲学思考的不可分离性。

  • 结论：任何试图“非历史化”的哲学方法都是不充分的，哲学必须建立在对此在历史性的承认之上。

4. 整体概括

这段文字通过介绍约克伯爵的洞见，阐述了历史性与人的存在之间的本质联系。约克认为，历史的基本性质是“可能状态”——人不是现成固定的存在，而是不断面向未来展开其可能性的历史性存在。他批判了将人视为“心理物理给定状态”的传统观点，强调人是在历史中“生活着”的。因此，对自我的理解必须置于具体的历史情境中，就像对自然的理解需要物理学一样。最终，约克坚决反对哲学脱离历史性的倾向，认为这种行为就像让呼吸脱离气压一样不可能。整个论证的核心是：哲学思考必须扎根于此在的历史性，否则就会失去其真实性和有效性。

5. 争议与说明

本段解读相对一致。约克伯爵（Paul Graf Yorck von Wartenburg）是海德格尔的重要思想来源之一，海德格尔在《存在与时间》中多次引用他的观点来支持自己的历史性理论。学界普遍认为这段引文体现了海德格尔对历史性的理解：历史不是客观研究对象，而是此在的存在方式。可能的细微争议在于对“可能状态”与历史性关系的理解：有些学者强调其面向未来的维度，有些则更注重其与传统的关系，但都承认这是此在时间性的体现。
