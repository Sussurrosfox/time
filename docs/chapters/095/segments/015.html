结构化精读

1. 术语释义

  • 形而上学：在海德格尔哲学中，这通常指西方哲学传统中追问“存在者之存在”但遗忘了“存在本身”的思维方式。它把存在当作现成的对象来研究，脱离了人的实际生存体验。在本段中，作者批评某些哲学做法是这种思维方式的“残余”，即未能真正切入生活本身。

  • 历史哲学：通常指对历史进程进行整体性、目的论解释的哲学体系。但本段强调，真正的哲学活动“就是去生活”，因此历史哲学应指哲学思考本身必须扎根于人的历史性生存，而非构建一套外在的历史规律系统。

  • 系统哲学与历史表现的分野：“系统哲学”指试图构建逻辑严谨、范畴完备的理论体系；“历史表现”指对哲学思想的历史性描述或梳理。作者认为这种区分“本质不正确”，因哲学本质上是历史性的活动，无法脱离生存实践而被纯粹系统化。

  • 教育学上的实践目标：此处的“教育学”取其最广义，指引导人实现其本真存在的“唤醒”过程。它关乎人的整体转变与成长，而非狭义的教学活动。作者视之为“真哲学的灵魂”，与柏拉图和亚里士多德的哲学精神一脉相承。

  • 伦理学作为一门科学：作者质疑将伦理学构建为一门规范性的、提供普遍道德法则的“科学”。他认为这种进路脱离了具体生存情境，但承认在现有框架内“改善的余地总还是有的”。

2. 逐句转译

  • “我看来却是一种形而上学的残余”：作者认为某些哲学做法仍未摆脱传统形而上学的思维惯性，把哲学当成脱离生活的理论建构。

  • “因为从事哲学就是去生活，所以——您且勿惊诧——我以为有一种历史哲学，——谁竟能写出它来呢！”：哲学的本质就是活生生的生存活动；因此，真正的历史哲学并非外在于生活的理论，而是内在于我们的历史性存在。这种哲学无人能“写完”，因为它就是生活本身。

  • “当然不是像迄今所了解所尝试的那种种，那些都是您无可辩争地宣布加以反对的”：作者反对传统历史哲学那种试图站在历史之外、构建宏大叙事的做法。

  • “迄今对问题的提法是错误的，其实根本是不可能的，但它不是唯一的提法”：过去的提问方式（如把历史当作对象化研究的课题）本身就有问题，但还有其他可能的进路。

  • “所以，不再有任何现实的哲学活动竟会不是历史的”：一切真正的哲学思考都必然扎根于人的历史性生存，无法脱离这一维度。

  • “系统哲学与历史表现的分野从本质说来就是不正确的”：将哲学划分为“系统构建”和“历史描述”是人为割裂，忽略了哲学本质上是人在历史中的生存实践。

  • “一门科学可能变成有实践意义的东西，如今这理所当然是一切科学的真正合理根据”：科学的价值在于其实践意义，这是当代共识。

  • “但数学的实践却不是唯一的实践。我们的立场的实践目标是教育学上的实践目标——就教育这个词最广最深的意义来说”：数学等科学的实践只是其中一种；哲学的实践目标在于“教育”——即引导人实现本真存在，这是最深远意义上的成长与转化。

  • “它是一切真哲学的灵魂，是柏拉图与亚里士多德的真理”：这种“教育”实践是真正哲学的核心，体现了古希腊哲学的根本精神。

  • “您知道我对伦理学作为一门科学的可能性有何看法。尽管如此，改善的余地总还是有的”：作者对伦理学成为一门提供抽象道德法则的“科学”持怀疑态度，但认为在现有框架内仍有调整空间。

  • “那些书到底是为谁写的呀？汗牛充栋。唯一值得注意的只有那从物理...”：大量伦理学著作脱离实际，不知为谁而写；唯一值得关注的是从“物理...”【原文截断，可能指从“物理”或具体生存出发的探索】。

3. 论证逻辑梳理

  • 前提1：哲学的本质是生活本身，而非理论建构。
  • 前提2：传统形而上学及历史哲学的提问方式错误，试图外在于历史来对象化研究历史。
  • 推论1：因此，一切真正的哲学活动都必然是历史的，即内在于人的历史性生存。
  • 推论2：系统哲学与历史表现的区分是本质错误的，因哲学无法脱离历史性而被纯粹系统化。
  • 转向实践维度：科学的合理性在于实践意义，但哲学的实践是“教育学”意义上的——引导人实现本真存在。
  • 最终立场：这是真哲学的灵魂，呼应古希腊传统；同时质疑伦理学成为抽象科学的可能性，但留有余地。

4. 整体概括

这段文字核心在批判传统哲学将自身构筑为脱离生活的理论体系，尤其是那种试图站在历史之外构建宏大叙事的“形而上学残余”。作者强调，哲学就是生活本身，因此真正的哲学思考必然是历史性的——它内在于我们的生存实践，无法被割裂为“系统建构”或“历史描述”。哲学的实践目标不是数学那样的应用，而是最深远意义上的“教育”：引导人实现本真存在，这才是柏拉图与亚里士多德哲学的真谛。最后，作者对伦理学成为一门提供抽象道德法则的科学表示怀疑，认为大量著作脱离实际，唯一有价值的是从具体生存出发的探索。

5. 争议与说明

  • 主流解读：这段体现了海德格尔早期对“生活哲学”及“实际性解释学”的坚持，强调哲学必须回归“此在”（人）的历史性生存。反对新康德主义等将哲学系统化、科学化的倾向。
  • 其他解读方向：
  • 有学者认为，海德格尔此处对“历史哲学”的重新界定，预示了他后期对“存在历史”的思考。
  • 对“教育学”目标的强调，也可联系到他早期在弗莱堡大学关于“哲学教化”的讲座，但此解读需结合更多文本佐证。
  • 争议点：如何准确理解“教育学”在此处的含义？是仅指大学教育中的哲学育人，还是泛指人在世存在的本真转化？后者更符合海德格尔的整体思想，但前者在具体语境中也可能被论及。
