📜 原文片段 (095/008)
海德格尔 原文
在狄尔泰与他的朋友约克伯爵的通信中，约克伯爵有一次提示，“我们共同的兴趣在于领会历史性”〔重点号为作者所加〕，这话明明白白地把狄尔泰最木己的哲学倾向表达出来了。狄尔泰的种种研究工作现在刚刚就其整个范围成为可通达的；而要把这些研究工作变为己有，则须持续而具体地从根本处进行讨论。这里无法详细讨论是哪些问题曾推动他以及它们曾如何推动他。不过，我们应从那些信件中挑选一些特别的段落，借以浅近地标识出约克伯爵的一些中心观念。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 历史性（Geschichtlichkeit）：在海德格尔哲学中，历史性并非仅指“历史事实”或“编年史”，而是指人类此在（Dasein）的存在方式本身即是历史的。此在并非“处于”历史中，而是其存在本身就由时间性和历史性构成。此在的理解、选择和行动都根植于其被抛入的历史情境。在本段中，狄尔泰和约克伯爵所关注的“领会历史性”，正是要探究这种存在论层面的历史性，而非一般实证历史研究。
  • 领会（Verstehen）：不是指智力上的“理解”，而是此在在世存在的一种基本方式，是此在对其自身存在可能性的把握和展开。在本段语境中，“领会历史性”意味着从存在论上把握此在的历史性本质。
  • 可通达（zugänglich）：指狄尔泰的研究工作变得可以被理解、被接触到、变得清晰。这里暗示狄尔泰的思想遗产正从晦涩中显现出来，可供后人深入研究。
  • 变为己有（Aneignung）：不是简单的“学习”或“掌握”，而是指通过持续的、深入的讨论，将狄尔泰的思想真正内化为自己的哲学素养，使其成为自身哲学探索的一部分。

2. 逐句转译

  • 原文第一句：在狄尔泰与他的朋友约克伯爵的通信中，约克伯爵有一次提示，“我们共同的兴趣在于领会历史性”〔重点号为作者所加〕，这话明明白白地把狄尔泰最本己的哲学倾向表达出来了。

  • 转译：狄尔泰和他的朋友约克伯爵有过书信往来。在这些信中，约克伯爵曾明确指出，他们两人共同的核心兴趣，就是要去“领会历史性”。海德格尔认为，这句话精准地揭示了狄尔泰哲学最核心、最根本的追求。

  • 原文第二句：狄尔泰的种种研究工作现在刚刚就其整个范围成为可通达的；而要把这些研究工作变为己有，则须持续而具体地从根本处进行讨论。

  • 转译：狄尔泰留下的众多学术成果，直到现在，其全部内容和意义才逐渐变得清晰、能够被我们把握。然而，如果我们想真正吸收这些思想精髓，使之成为我们自己思想的一部分，就必须对它进行持续、深入且触及根基的探讨。

  • 原文第三、四句：这里无法详细讨论是哪些问题曾推动他以及它们曾如何推动他。不过，我们应从那些信件中挑选一些特别的段落，借以浅近地标识出约克伯爵的一些中心观念。

  • 转译：在目前这个讨论中，我们无法去深究究竟是哪些具体问题驱动着狄尔泰思考，以及这些问题是如何推动他的。但我们可以退一步，从他们的通信中选取一些关键段落，用它们来初步勾勒出约克伯爵思想中的一些核心观点。

3. 论证逻辑梳理

  1. 前提与起点：以约克伯爵书信中的一句话——“我们共同的兴趣在于领会历史性”——作为论述的起点。这句话被海德格尔视为理解狄尔泰哲学精神的钥匙。
  2. 现状评估：紧接着，对狄尔泰思想遗产的现状进行评估：其研究工作的全貌目前才变得清晰（“可通达”），但要真正吸收它，需要深入的根本性讨论。
  3. 划定论述范围：明确本段（或本节）论述的界限——不深入探讨驱动狄尔泰的具体问题及其作用方式，这超出了当前任务的范围。
  4. 提出论述策略：基于以上划定，提出一个更聚焦、更可行的论述方法：通过引用约克伯爵书信中的关键段落，来初步阐明约克伯爵的核心思想观念。这为后续的具体分析做好了铺垫。

4. 整体概括

这段文字可以看作是海德格尔讨论狄尔泰和约克伯爵思想的“开场白”。他首先引用了一句关键引文，点明了狄尔泰哲学的核心关切是“领会历史性”。接着，他说明了狄尔泰思想遗产在当前（指海德格尔写作时）的研究状况，强调需要对其进行根本性的探讨才能真正吸收。最后，他明确了本节的论述策略：由于无法全面展开，他将通过分析约克伯爵书信中的选段，来初步勾勒其核心思想。整段话的目的在于为接下来的具体哲学讨论设定背景、划定范围并指明路径。

5. 争议与说明

本段主要是海德格尔对狄尔泰和约克伯爵思想的引介和方法论说明，其本身的表述清晰，解读相对一致，不存在重大的学术争议。可能的细微讨论点在于海德格尔对狄尔泰“最本己的哲学倾向”的概括是否完全准确，但这通常属于思想史阐释中常见的、见仁见智的范畴，并非针对本段文字的特定争议。
