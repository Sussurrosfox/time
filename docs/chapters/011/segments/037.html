📜 原文片段 (011/037)
海德格尔 原文
我们已经界说了现象学的先行概念；在这一地基上，我们也就能确定“现象的”和“现象学的”这两个术语的含义了。以现象的照面方式给予的以及可用这种方式解说的，称为“现象的”；现象的结构这种说法便由此而生。而所有属于展示方式与解说方式的东西，所有构成这种研究所要求的概念方式的东西，则都叫作“现象学的”。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 现象学：海德格尔哲学中的核心方法，指一种通过让事物“如其自身所是”地显现自身的方式来研究“存在”的学问。它强调直接面对和描述事物本身，而非预设理论框架。
  • 现象的：指事物“如其自身所呈现的样子”。在本段中，特指那些以“现象的照面方式”被给予并能以相应方式被解说的事物。
  • 现象学的：在本段中，并非指现象学这门学问本身，而是指构成现象学研究方法的一切要素，包括展示方式、解说方式以及研究所要求的概念工具。

2. 逐句转译

  • “我们已经界说了现象学的先行概念；在这一地基上，我们也就能确定‘现象的’和‘现象学的’这两个术语的含义了。”

  • 我们已经把现象学最基础、最先要明确的概念说清楚了；有了这个基础，我们现在就可以来给“现象的”和“现象学的”这两个词下定义了。

  • “以现象的照面方式给予的以及可用这种方式解说的，称为‘现象的’；”

  • 那些以事物“如其自身显现”的方式直接呈现给我们，并且我们也能用这种方式去理解和说明它们的，就叫做“现象的”。

  • “现象的结构这种说法便由此而生。”

  • 我们所说的“现象的结构”这个概念，就是从这种理解方式中自然而然产生的。

  • “而所有属于展示方式与解说方式的东西，所有构成这种研究所要求的概念方式的东西，则都叫作‘现象学的’。”

  • 而所有用来进行这种展示和解说的具体方法、手段，以及构建这项研究所需的所有概念工具，这些统统都叫做“现象学的”。

3. 论证逻辑梳理

  • 前提：已经完成了对“现象学先行概念”的界定工作。
  • 核心步骤： 1. 基于这个前提，作者开始对两个关键术语——“现象的”和“现象学的”——进行区分和定义。 2. 首先定义“现象的”：它指向研究对象，即那些以特定方式（现象的照面方式）呈现并可以被如此理解的事物本身。 3. “现象的结构”作为对研究对象的一种描述，是从“现象的”这一概念中推导出的。 4. 然后定义“现象学的”：它指向研究方法论，囊括了进行研究所需的一切工具、方法和概念。
  • 结论：清晰地区分了“现象的”（研究对象/内容）和“现象学的”（研究方法/工具），为后续的现象学研究划定了清晰的领域和路径。

4. 整体概括

这段文字是海德格尔在为他的现象学研究建立术语规范。他首先声明已经打好理论基础，然后开始精确区分两个容易混淆的关键词：“现象的”指的是我们直接面对和研究的对象本身，以及这些对象呈现出来的样子；而“现象学的”则是指我们为了研究这些对象所需要使用的一整套方法、工具和概念系统。简单来说，他是在给研究内容和研究方法划清界限，前者是“我们要看什么”，后者是“我们怎么看”。

5. 争议与说明

本段作为《存在与时间》中方法论奠基的一部分，其解读在学界相对一致。核心在于理解海德格尔对“现象的”（ontic，关乎存在者）与“现象学的”（ontological，关乎存在本身的研究方法）所做的区分，这一区分是他整个哲学计划的基石，争议不大。
