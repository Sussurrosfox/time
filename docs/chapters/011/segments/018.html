📜 原文片段 (011/018)
海德格尔 原文
在柏拉图与亚里士多德那里，〔逻各斯〕这个概念具有多重含义；而且，这些含义相互抗争，没有一个基本含义在积极地主导它们。事实上这只是假象。只要我们的阐释不能就其本来内涵适当把握〔逻各斯〕的基本含义，这种假象就会持续下去。如果我们说：〔逻各斯〕的基本含义，那么只有先规定了“话语”这词本身说的是什么，这种字面上的翻译才有用处。〔逻各斯〕这个词的含义的历史，特别是后世哲学的形形色色随心所欲的阐释，不断掩蔽着话语的本真含义。这含义其实是够显而易见的。〔逻各斯〕被“翻译”为，也就是说，一向被解释为：理性、判断、概念、定义、根据、关系。但“话语”怎么竟能变出这么多种模式，竟使〔逻各斯〕得以意味着上列种种，而且还是在科学的语言用法范围之内？即使把〔逻各斯〕的意义领会为命题，一旦把命题又领会为“判断”，这种貌似正当的翻译仍然可能使〔逻各斯〕的基本含义交臂失之；我们若在当今的任何一种“判断理论”的意义上来理解判断，那情况就尤其不妙。如果人们把判断领会为一种“联结”或一种选取角度〔认可、反对〕，那么〔逻各斯〕说的就不是判断，无论如何他本来并不等于说判断。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 逻各斯：在海德格尔哲学中，通常指一种本源性的“言说”或“话语”，它不仅指语言表达，更是一种让事物如其自身显现出来的方式，是存在得以开显的境域。在本段中，海德格尔强调，必须回到“话语”这一基本含义，才能理解逻各斯在后世哲学中为何会被曲解为理性、判断等概念。
  • 话语：即逻各斯的基本含义，指一种让事物被看见、被理解的源初言说方式，不是简单的语言交流，而是存在本身的展开与揭示。
  • 判断：这里特指后世哲学（尤其是逻辑学传统）中对逻各斯的误解，将其窄化为一种对事物进行联结、认可或反对的思维活动，从而遮蔽了其更原初的“话语”含义。

2. 逐句转译

  • “在柏拉图与亚里士多德那里，〔逻各斯〕这个概念具有多重含义；而且，这些含义相互抗争，没有一个基本含义在积极地主导它们。”
    → 在柏拉图和亚里士多德的著作中，逻各斯这个词有很多种不同的意思，这些意思之间互相冲突，没有一个根本的、核心的定义能够统一它们。

  • “事实上这只是假象。只要我们的阐释不能就其本来内涵适当把握〔逻各斯〕的基本含义，这种假象就会持续下去。”
    → 但这其实是一种表面现象。如果我们不能真正理解逻各斯原本的意思，这种混乱的局面就会一直存在。

  • “如果我们说：〔逻各斯〕的基本含义，那么只有先规定了‘话语’这词本身说的是什么，这种字面上的翻译才有用处。”
    → 如果我们想要找到逻各斯的根本含义，就必须先弄清楚“话语”这个词到底指的是什么，否则仅仅把它翻译成“话语”也没什么意义。

  • “〔逻各斯〕这个词的含义的历史，特别是后世哲学的形形色色随心所欲的阐释，不断掩蔽着话语的本真含义。这含义其实是够显而易见的。”
    → 历史上对逻各斯的各种解释，尤其是后来哲学家的随意发挥，掩盖了它原本作为“话语”的真实含义。其实这个含义本来是很清楚的。

  • “〔逻各斯〕被‘翻译’为，也就是说，一向被解释为：理性、判断、概念、定义、根据、关系。”
    → 一直以来，逻各斯都被解释成理性、判断、概念、定义、根据、关系等等。

  • “但‘话语’怎么竟能变出这么多种模式，竟使〔逻各斯〕得以意味着上列种种，而且还是在科学的语言用法范围之内？”
    → 但为什么“话语”这个基本含义会衍生出这么多不同的理解？甚至这些理解还都在学术语言中被广泛使用？

  • “即使把〔逻各斯〕的意义领会为命题，一旦把命题又领会为‘判断’，这种貌似正当的翻译仍然可能使〔逻各斯〕的基本含义交臂失之；我们若在当今的任何一种‘判断理论’的意义上来理解判断，那情况就尤其不妙。”
    → 就算我们把逻各斯理解为“命题”，但如果再把命题理解为“判断”，那还是可能错过它的根本意义。特别是如果我们用现代判断理论来理解“判断”，那就错得更远了。

  • “如果人们把判断领会为一种‘联结’或一种选取角度〔认可、反对〕，那么〔逻各斯〕说的就不是判断，无论如何他本来并不等于说判断。”
    → 如果把判断理解为对事物的联结或者表态（比如赞成或反对），那么逻各斯根本说的就不是这个意思，它原本就和判断不是一回事。

3. 论证逻辑梳理

  • 前提：逻各斯在柏拉图与亚里士多德那里含义混乱，看似没有主导含义。
  • 推进1：海德格尔指出这是假象，根本原因在于后世哲学未能把握逻各斯的本真含义——“话语”。
  • 推进2：他列举了历史上对逻各斯的各种曲解（理性、判断等），并提出质疑：为什么“话语”会衍生出这么多不同的理解？
  • 推进3：进一步批判将逻各斯理解为“判断”的做法，指出即使通过“命题”这一中介，最终仍会偏离其本义。
  • 结论：逻各斯的原意并非判断，而是更源初的“话语”，后世的理解（尤其是判断理论）是对它的遮蔽。

4. 整体概括

这段文字的核心意思是：逻各斯在哲学传统中看似含义混乱，但其实是因为后人没能抓住它最根本的意思——“话语”。历史上人们把它解释成理性、判断、概念等等，但这些都偏离了原意。即使把它理解为“命题”再转为“判断”，仍然是一种误解。海德格尔强调，必须回到“话语”这一源初含义，才能看清逻各斯真正的哲学意义。

5. 争议与说明

  • 主流解读：海德格尔在此强调了对哲学概念进行“解构—回溯”的重要性，即必须穿越历史上的种种曲解，回到概念的原初经验。
  • 其他可能解读：有学者认为，海德格尔对“逻各斯”的重新解释并非单纯回到古希腊，而是借古希腊资源展开他自己的存在论计划，因此这里的“话语”已经带有他本人的现象学—解释学烙印。
  • 争议点：在于海德格尔对古希腊文本的解读是否准确，以及他是否过于强调“本真含义”而忽略了概念的历史流变性。
