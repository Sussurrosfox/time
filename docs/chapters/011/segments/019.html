📖 《存在与时间》研读 逐段解析

📜 原文片段 (011/019)
海德格尔 原文
〔逻各斯〕作为话语，毋宁说恰恰等于：把言谈之时“话题”所及的东西公开出来。亚里士多德把话语的功能更精细地解说为〔有所展示〕。〔逻各斯〕是让人看某种东西，让人看话语所谈及的东西，而这个看是对言谈者〔中间人〕来说的，也是对相互交谈的人们来说的。话语“让人”〔从〕某某方面“来看”，让人从话题所及的东西本身方面来看。只要话语是真切的，那么，在话语中，话语之所谈就当取自话语之所涉；只有这样，话语这种传达才能借助所谈的东西把所涉的东西公开出来，从而使他人也能够通达所涉的意思。这就是〔逻各斯〕之为〔展示〕的结构。这种“使…公开”的意义就是展示出来让人看。当然，并非一切“话语”都具有这种意义上的“使…公开”的样式。譬如请求也使某种东西公开，但却是以其它的方式来进行的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 逻各斯 (Logos)：在海德格尔哲学中，逻各斯不是指逻辑或理性，而是指“话语”或“言谈”，是此在（人的存在）展开和揭示世界的基本方式。在本段中，它特指通过话语将事物公开出来、展示给他人看的功能。
  • 展示 (Apophansis)：源于亚里士多德，指逻各斯具有“显示”或“揭示”事物的功能。在本段中，它强调话语能让人看到所谈论的东西本身。
  • 真切 (Echt)：这里指话语的本真状态，即话语的内容直接来源于它所谈及的事物本身，从而能够如实地揭示事物。
  • 公开/通达：指通过话语使被谈论的事物对他人变得可理解、可接触，让他人也能“看到”话语所指向的东西。

2. 逐句转译

  • “〔逻各斯〕作为话语，毋宁说恰恰等于：把言谈之时‘话题’所及的东西公开出来。”
    → 逻各斯作为话语，其本质功能是在谈话时，把正在谈论的那个东西（话题）公开揭示出来。

  • “亚里士多德把话语的功能更精细地解说为〔有所展示〕。”
    → 亚里士多德更精确地定义了话语的功能：它具有展示事物的作用。

  • “〔逻各斯〕是让人看某种东西，让人看话语所谈及的东西，而这个看是对言谈者〔中间人〕来说的，也是对相互交谈的人们来说的。”
    → 逻各斯是让人“看到”某种东西，即看到话语所谈论的那个对象；这种“看到”既是对说话者本人而言，也是对参与对话的其他人而言。

  • “话语‘让人’〔从〕某某方面‘来看’，让人从话题所及的东西本身方面来看。”
    → 话语引导人们从某个特定的角度去“看”，并且是从话题对象本身的角度去观看。

  • “只要话语是真切的，那么，在话语中，话语之所谈就当取自话语之所涉；只有这样，话语这种传达才能借助所谈的东西把所涉的东西公开出来，从而使他人也能够通达所涉的意思。”
    → 只要话语是真实、本真的，那么话语中所说的内容就应该直接来自它所指向的那个事物；只有这样，话语才能通过所说的内容，把那个事物本身展示出来，从而让他人也能理解那个事物的意义。

  • “这就是〔逻各斯〕之为〔展示〕的结构。”
    → 这就是逻各斯作为“展示”功能的内在结构。

  • “这种‘使…公开’的意义就是展示出来让人看。”
    → 这种“使事物公开”的本质，就是把它展示出来，让人看到。

  • “当然，并非一切‘话语’都具有这种意义上的‘使…公开’的样式。譬如请求也使某种东西公开，但却是以其它的方式来进行的。”
    → 当然，并非所有话语都以这种“展示”方式使事物公开。比如“请求”也会公开某种东西，但它是通过不同的方式实现的。

3. 论证逻辑梳理

  • 前提：逻各斯是话语，其基本功能是公开话题所及的事物。
  • 细化定义：引用亚里士多德，指出逻各斯的核心是“展示”，即让人看到所谈论的东西。
  • 展示的对象与主体：展示既是对说话者自己，也是对对话中的其他人；并且是从事物本身的角度去展示。
  • 真切话语的条件：话语若要真实展示事物，必须让所说的内容直接来源于事物本身。只有这样，才能通过话语让他人也理解那个事物。
  • 总结结构：这就是逻各斯作为展示的结构，其核心是“使人公开看到”。
  • 补充说明：并非所有话语都以展示方式公开事物，例如“请求”是另一种公开方式。

4. 整体概括

这段文字在解释海德格尔如何理解“逻各斯”作为话语的本质功能。逻各斯不是抽象的逻辑，而是在言谈中把所谈论的事物“公开出来”，让人（包括说话者和听者）都能“看到”它。这种“展示”功能要求话语内容必须直接来自事物本身，才能真实地传达意义。海德格尔特别强调，这种“使人看到”的结构是逻各斯的核心，但也指出并非所有话语（如请求）都以这种方式运作。

5. 争议与说明

本段解读相对一致。主要争议可能在于“展示”是否涵盖所有话语类型，但海德格尔在此已明确区分了展示性话语（如陈述）与非展示性话语（如请求），因此争议不大。
