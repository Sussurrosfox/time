📖 《存在与时间》研读 逐段解析

📜 原文片段 (011/032)
海德格尔 原文
无论什么东西成为存在论的课题，现象学总是通达这种东西的方式，总是通过展示来规定这种东西的方式。存在论只有作为现象学才是可能的。现象学的现象概念意指这样的显现者：存在者的存在和这种存在的意义、变式和衍化物。而显现并非任意的显现，更不是现相这类事情。存在者的存在绝不会是那样一种东西——好像还有什么“不现相的东西”在它的背后似的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 存在论：海德格尔哲学中，研究“存在”本身（而非具体存在者）的学问。它追问“存在”为何，以及“存在”的意义如何显现。
  • 现象学：一种哲学方法，主张“回到事物本身”，通过直接展示和描述现象来探究其本质。在海德格尔这里，它是通达存在问题的唯一途径。
  • 现象：不是指表面的、虚假的“表象”，而是指如其自身所显现的东西。特指存在者的存在及其意义、变化形态和衍生形式的自我显现。
  • 存在者：任何具体存在着的东西，如一把椅子、一个人、一个观念。
  • 存在：使存在者得以成为存在者的那个“是”本身，是存在者的根据和意义来源。
  • 现相：与“现象”相对，指一种不真实的、遮蔽本质的表象或假象。

2. 逐句转译

  • “无论什么东西成为存在论的课题，现象学总是通达这种东西的方式，总是通过展示来规定这种东西的方式。” 这句话是说：无论我们研究什么终极的哲学问题（存在论问题），唯一正确的方法就是现象学。这个方法的核心是“展示”——不是用理论去套，而是让问题本身如实地显现出来，我们根据这个显现来理解它。

  • “存在论只有作为现象学才是可能的。” 这可以理解为：如果你想真正研究“存在”这个问题，那你只能用现象学的方法。其他方法都达不到目标，因为存在本身只能通过自我显现被我们把握。

  • “现象学的现象概念意指这样的显现者：存在者的存在和这种存在的意义、变式和衍化物。” 这里定义了什么是海德格尔所说的“现象”。它不是日常看到的表面东西，而是指“一个东西为何能存在”这个根本事实，以及这个事实所包含的全部意义、各种可能的变化形态和由此衍生出的其他概念。

  • “而显现并非任意的显现，更不是现相这类事情。” 海德格尔特别强调，他说的“显现”不是随便什么表面的、偶然的出现，更不是指那种掩盖了本质的假象（现相）。

  • “存在者的存在绝不会是那样一种东西——好像还有什么‘不现相的东西’在它的背后似的。” 这句话是核心断言：一个东西的“存在”，并不是藏在这个东西背后、需要我们去猜测的某个神秘实体。它就是在这个东西的整个显现过程中直接给我们的。存在，就在显现之中，背后别无他物。

3. 论证逻辑梳理

  1. 前提设定：存在论是研究的领域（研究“存在”）。
  2. 方法确立：要研究这个领域，唯一有效的方法是现象学，因为它通过“展示”来规定研究对象。
  3. 核心定义：对现象学中的“现象”进行了严格界定——它不是表象，而是“存在者的存在”及其全部内容和形态的自我揭示。
  4. 划清界限：明确区分了“显现”（现象）与“假象”（现相），防止概念混淆。
  5. 最终结论：通过一个强有力的否定，确立了现象学存在论的基本原则：“存在”并非隐藏在现象背后的独立实体，它就在现象本身的显现之中。存在即显现。

4. 整体概括

这段话的核心思想是：哲学上探究“存在”这门学问（存在论），必须采用现象学的方法。这种方法要求我们直接去观察和描述“存在”是如何通过世间万物显现出来的。这里所说的“现象”，指的不是事物的表面皮毛，而是事物之“所以存在”这个根本事实本身，连同它的全部意义和变化形态。海德格尔激烈地反对一种传统观念，即认为在我们看到的现象背后，还藏着一个更真实的、不显现的本体。他斩钉截铁地宣布：存在，就赤裸裸地、完整地呈现在它的显现过程里，除此之外，背后什么也没有。我们不需要，也不应该去现象背后寻找什么“真正”的存在。
