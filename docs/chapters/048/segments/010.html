📜 原文片段 (048/010)
海德格尔 原文
我们已提供出闲言、好奇与两可这些现象。提供它们的方式已经揭示出在它们本身之间就有着某种联系。现在应从生存论存在论上来把握这种联系的存在方式了。而我们应该从前此获得的此在诸存在结构的视野上来领会日常存在的基本方式。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 闲言、好奇、两可：这三个概念在海德格尔哲学中都描述了此在（人的存在）在日常生活中的非本真存在状态。闲言指空洞的、人云亦云的话语方式；好奇指不断追逐新奇事物却缺乏真正理解的浮躁状态；两可指一切可能性都看似可能却又无法确定的模糊状态。它们共同构成了此在日常沉沦于世的基本特征。
  • 生存论存在论：海德格尔哲学的核心方法论，指从"此在"的实际生存出发来探讨存在问题的研究进路。它关注的是人如何通过具体的生存活动展现存在的意义。
  • 此在：特指人的存在方式，是一种能够追问自身存在的存在者。此在的基本结构是"在世之在"，即总是已经处在世界之中并与世界打交道。
  • 存在结构：此在固有的基本构成要素，如操心、沉沦、被抛等，它们共同规定了此在的存在方式。
  • 日常存在：此在在日常生活中最常见的存在状态，通常表现为随波逐流、失去自我的非本真状态。

2. 逐句转译

  • "我们已提供出闲言、好奇与两可这些现象。提供它们的方式已经揭示出在它们本身之间就有着某种联系。" → 前面我们已经详细描述了闲言、好奇和两可这三种现象。在描述它们的过程中，我们已经发现这三者之间存在着内在的关联。
  • "现在应从生存论存在论上来把握这种联系的存在方式了。" → 现在我们需要从生存论存在论的角度，深入理解这种关联的本质及其存在方式。
  • "而我们应该从前此获得的此在诸存在结构的视野上来领会日常存在的基本方式。" → 同时，我们要基于之前已经探讨过的此在的各种存在结构，来理解日常存在的基本模式。

3. 论证逻辑梳理

  • 前提：已经完成了对闲言、好奇、两可三种现象的现象学描述，并且发现它们之间存在联系。
  • 推进：从单纯的现象描述阶段，转向对这些现象的存在论基础进行探究。具体而言，就是要从生存论存在论的高度，来把握这些现象之间关联的本质。
  • 结论：提出了下一步的研究任务——基于已经阐明的此在的存在结构，来系统地理解日常存在的根本模式。

4. 整体概括

这段话标志着海德格尔研究进程的一个重要转折点。他之前已经详细剖析了闲言、好奇和两可这三种日常生活中常见的现象，现在他要从更深层的哲学高度来探讨这些现象之间的内在联系。他明确表示，接下来的任务是要运用之前已经建立的关于人的存在结构的理论框架，从生存论存在论的角度，系统地理解日常生活中人的存在方式的本质特征。这实际上是从现象描述向存在论分析的深化。

5. 争议与说明

本段作为承上启下的过渡段落，主要功能是标明论证进程的推进，在解读上相对一致，没有明显的学术争议。
