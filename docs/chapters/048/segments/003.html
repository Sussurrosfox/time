📖 《存在与时间》研读 逐段解析
首页 / 第 048 章 / 片段 003
📜 原文片段 (048/003)
海德格尔 原文
在日常相处中来照面的那类东西是人人都可得而通达的；关于它们，人人都可以随便说些什么。既然如此，人们很快就无法断定什么东西在真实的领会中展开了而什么东西却不曾。这种模棱两可不仅伸及世界，而且同样伸及共处本身乃至此在向它自己的存在。 一切看上去都似乎被真实地领会了、把捉到了、说出来了；而其实却不是如此，或者一切看上去都不是如此而其实却是如此。两可不仅涉及对那些在使用和享用中可以通达的东西的支配和调整，而且它还被固定在作为能在的领会之中，固定在对此在的可能性的筹划方式和呈现方式之中。不仅摆在那里的事情和摆在眼前的事情，人人都知道都议论；而且将要发生的事情、还未摆在眼前但“夺半”一定要弄成的事情，人人都已经会大发议论了。别人料到的、觉察的事情，人人也都总先已料到了、觉察到了。这种捕踪捉迹来自道听途说，因为谁要是以真实的方式捕捉一事的踪迹，他是不会声张的。捕踪捉迹是两可借以佯充此在之可能性的最迷惑人的方式，结果却也已经窒息了这些可能性的力量。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 照面（Begegnen）：在海德格尔哲学中，指事物在与人的日常互动中“显现”或“遭遇”的方式。它不是被动的看见，而是在人投身于世界的过程中，事物自然而然地进入我们的关注范围。

  • 此在（Dasein）：指人的存在方式，这种存在总是对自身的存在有所领会、有所关切，并在世界中与他人共处。

  • 能在（Seinkönnen）：指此在的根本特征是“能够去存在”，它不是固定的实体，而是不断面向可能性展开的存在方式。

  • 领会（Verstehen）：不是指理智上的理解，而是此在在世的基本方式，意味着此在总是对自身与世界有所筹划、有所开启。

  • 两可（Zweideutigkeit）：指日常生活中的一种模糊不清、真伪难辨的状态。人们似乎什么都懂、什么都能谈论，但往往并未真正触及事物的本质与本真。

2. 逐句转译

  • “在日常相处中来照面的那类东西是人人都可得而通达的；关于它们，人人都可以随便说些什么。”
    → 我们在日常生活中遇到的那些东西，人人都能接触到；关于它们，每个人都能随便说上几句。

  • “既然如此，人们很快就无法断定什么东西在真实的领会中展开了而什么东西却不曾。”
    → 正因如此，我们很快就分不清：哪些东西是被我们真正理解了的，哪些其实并没有。

  • “这种模棱两可不仅伸及世界，而且同样伸及共处本身乃至此在向它自己的存在。”
    → 这种模糊不清的状态，不仅影响了我们对世界的理解，也影响了我们与他人的共处，甚至影响了我们对自己的理解。

  • “一切看上去都似乎被真实地领会了、把捉到了、说出来了；而其实却不是如此，或者一切看上去都不是如此而其实却是如此。”
    → 表面上看，好像一切都真懂了、抓住了、说清楚了，但其实并非如此；或者表面上看不是这样，实际上却是这样。

  • “两可不仅涉及对那些在使用和享用中可以通达的东西的支配和调整，而且它还被固定在作为能在的领会之中，固定在对此在的可能性的筹划方式和呈现方式之中。”
    → 这种“两可”状态，不仅影响我们如何掌控和安排日常事物，它还深深嵌入我们理解自身的方式中——我们如何设想自己的可能性，如何展现自己。

  • “不仅摆在那里的事情和摆在眼前的事情，人人都知道都议论；而且将要发生的事情、还未摆在眼前但‘夺半’一定要弄成的事情，人人都已经会大发议论了。”
    → 不仅眼前已经发生的事情人人都在议论，就连那些还没发生、只是“可能”会发生的事情，大家也早就在那里说个不停了。

  • “别人料到的、觉察的事情，人人也都总先已料到了、觉察到了。”
    → 别人想到的、察觉到的事情，每个人也都觉得自己早就想到了、察觉到了。

  • “这种捕踪捉迹来自道听途说，因为谁要是以真实的方式捕捉一事的踪迹，他是不会声张的。”
    → 这种对事情的捕捉和追踪，其实都来自于道听途说。真正在默默追踪事情真相的人，反而不会到处张扬。

  • “捕踪捉迹是两可借以佯充此在之可能性的最迷惑人的方式，结果却也已经窒息了这些可能性的力量。”
    → 这种“捕踪捉迹”是“两可”状态最迷惑人的手段：它假装能捕捉到人生的可能性，但实际上却恰恰扼杀了这些可能性。

3. 论证逻辑梳理

  • 前提：日常生活中的事物是人人可以接触并随意谈论的。
  • 推进1：这种随意谈论导致我们无法分辨什么是真实的理解，什么是虚假的理解。
  • 推进2：这种模糊状态（“两可”）不仅影响我们对外部世界的把握，也影响我们与他人的共处，甚至影响我们对自己的理解。
  • 推进3：两可状态还深入到我们对自身可能性的设想中——我们如何筹划自己的未来、如何呈现自己。
  • 推进4：这种状态不仅针对眼前事物，也延伸到尚未发生的事情，人们热衷于捕风捉影、道听途说。
  • 结论：这种捕踪捉迹的方式看似抓住了可能性，实则恰恰窒息了可能性，因为它使人停留在表面的、非本真的谈论中。

4. 整体概括

这段文字揭示了日常生活中一种普遍存在的“两可”状态：因为人人都能接触到日常事物并随意谈论，我们渐渐无法分辨什么是真正的理解。这种模糊不清不仅影响了我们对外部世界的把握，也渗透到我们与他人的相处以及我们对自己的理解中。我们不仅对眼前的事情夸夸其谈，连尚未发生的事情也热衷议论，仿佛早已洞察一切。然而，这种捕风捉影式的“捕踪捉迹”看似能捕捉人生的可能性，实际上却通过道听途说和表面的议论，扼杀了我们真实面对可能性的能力。海德格尔在此批判的是日常生活中的非本真状态——我们活在一种似乎什么都懂、其实什么都没真正理解的模糊地带。

5. 争议与说明

本段解读相对一致，学界普遍认为这是海德格尔对日常“闲谈”与“两可”现象的现象学描述，揭示此在沉沦于非本真状态的方式。略有争议之处在于：“捕踪捉迹”是否仅仅指向消极的沉沦，还是也暗示了此在即使在非本真中仍对可能性有所“觉察”？主流解读倾向于前者，认为这是对沉沦状态的批判；少数解读则试图在其中寻找此在对可能性保持开放的痕迹。
