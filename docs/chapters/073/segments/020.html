📖 《存在与时间》研读 逐段解析
首页 / 第 073 章 / 片段 020
📜 原文片段 (073/020)
海德格尔 原文
虽然如此，这一生存论上的不之状态的不性〔Nichtheit〕的存在论意义却仍晦暗不明。但说到一般的“不”之存在论本质，情况也是一样。存在论与逻辑学对“不”的作用一向寄以厚望，从而也零碎片段地使不的种种可能性映入眼帘。然而它们却不曾从存在论上揭开“不”本身。存在论过去曾发现这个“不”摆在那里，于是就使用它。但每一个“不”都这样不言而喻地意味着匮乏意义上的否定因素吗？“不”的肯定性难道仅在于组建着“过渡”吗？为什么所有的辩证法都躲避到否定性中，却不辩证地论证这类东西本身，甚至不能把它作为问题确定下来呢？人们可曾把“不”的存在论起源变成问题了吗？或哪怕先行对“不”及其不性和可能性这些问题得以提出所赖的诸条件探寻一番了吗？但若不专题澄清一般存在的意义，不澄清“是”，还该在何处找到这些条件呢？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 生存论上的不之状态（Existenzial Nichtheit）：指此在（人的存在）在其生存结构中所包含的否定性维度。这不是简单的逻辑否定或匮乏，而是此在面向可能性时，因选择一种可能性而放弃其他可能性所产生的根本性否定。
  • 不性（Nichtheit）：指“不”或“否定”的本质属性，在海德格尔这里，它不是简单的逻辑否定或缺失，而是此在生存结构中的一种构成性要素。
  • 存在论（Ontologie）：探究“存在”本身的意义和结构的哲学领域，区别于仅研究存在者的具体科学。
  • 辩证法（Dialektik）：这里指传统哲学（尤其是黑格尔哲学）中通过正题-反题-合题的矛盾运动来推进思想的方法。海德格尔质疑其未能真正追问“否定”的存在论根基。
  • “是”（Sein）：即“存在”本身，海德格尔哲学的核心问题。这里强调必须首先澄清“存在”的意义，才能理解“不”的来源。

2. 逐句转译

  1. “虽然如此，这一生存论上的不之状态的不性〔Nichtheit〕的存在论意义却仍晦暗不明。”
    → 尽管我们前面讨论了此在生存结构中的否定性，但这种否定性（“不性”）的存在论意义——也就是它在“存在”层面究竟意味着什么——仍然没有被说清楚。

  2. “但说到一般的‘不’之存在论本质，情况也是一样。”
    → 其实，不仅是我们刚讨论的“生存论上的不”，就连一般的“不”（比如逻辑上的否定）的存在论本质，也同样没有被搞清楚。

  3. “存在论与逻辑学对‘不’的作用一向寄以厚望，从而也零碎片段地使不的种种可能性映入眼帘。”
    → 过去的哲学和逻辑学虽然很重视“不”的作用（比如在推理中），也零零散散地看到了一些“不”可能有的形态。

  4. “然而它们却不曾从存在论上揭开‘不’本身。”
    → 但它们都没有真正从存在论的深度，去揭示“不”本身的根源和本质。

  5. “存在论过去曾发现这个‘不’摆在那里，于是就使用它。”
    → 以前的哲学只是发现世界上有“不”这个现象，然后就拿过来直接用，没有深究。

  6. “但每一个‘不’都这样不言而喻地意味着匮乏意义上的否定因素吗？”
    → 难道每一个“不”都理所当然地只是表示一种“缺了点什么”的否定吗？

  7. “‘不’的肯定性难道仅在于组建着‘过渡’吗？”
    → 难道“不”所具有的积极意义，仅仅体现在它能在辩证运动中充当从一个环节过渡到另一个环节的桥梁吗？

  8. “为什么所有的辩证法都躲避到否定性中，却不辩证地论证这类东西本身，甚至不能把它作为问题确定下来呢？”
    → 为什么各种辩证法都一味地依赖否定性，却从来没有用辩证法本身的方法，去论证否定性到底是什么？甚至没有把它当成一个明确的问题提出来？

  9. “人们可曾把‘不’的存在论起源变成问题了吗？”
    → 有人真的把“不”的存在论起源当作一个问题来追问过吗？

  10. “或哪怕先行对‘不’及其不性和可能性这些问题得以提出所赖的诸条件探寻一番了吗？”
    → 或者，哪怕只是先一步去探寻一下：我们要想提出关于“不”、关于“不性”、关于它的可能性这些问题，究竟需要哪些前提条件？

  11. “但若不专题澄清一般存在的意义，不澄清‘是’，还该在何处找到这些条件呢？”
    → 但是，如果我们不先专门去澄清“存在”的一般意义，不先弄清“是”到底是什么意思，我们又怎么可能找到这些前提条件呢？

3. 论证逻辑梳理

  1. 前提：海德格尔首先指出，无论是生存论上的“不之状态”，还是一般意义上的“不”，其存在论意义都未被真正阐明。
  2. 批评现状：他指出，传统存在论和逻辑学虽然使用了“不”，并看到了它的一些作用，但从未深究其存在论根基。
  3. 质疑传统理解：他连续发问，质疑“不”是否仅仅意味着“匮乏”或仅在辩证法中充当“过渡”环节。
  4. 核心指控：他进一步批评辩证法逃避了对否定性本身的论证，甚至未能将其确立为一个明确的问题。
  5. 提出根本问题：他追问，我们是否曾真正追问过“不”的存在论起源，以及提出这些问题的前提条件是什么。
  6. 最终结论：他断言，这些前提条件只能通过首先澄清“一般存在的意义”（即“是”的意义）才能被发现。

4. 整体概括

这段文字是海德格尔对传统哲学处理“否定”（“不”）现象的根本性质疑。他认为，无论是生存论中的否定性，还是一般逻辑中的否定，其深层的存在论意义一直被忽视。传统哲学和逻辑学仅仅是利用“不”这个概念，要么将其视为某种缺失，要么在辩证法中将其当作一个过渡工具，却从未追问“不”本身从何而来，其本质是什么。海德格尔指出，所有关于“不”的问题，其提出和解答的前提，都依赖于一个更根本的问题——即对“存在”本身意义的澄清。不先解决“存在是什么”这个核心问题，任何关于“不”的讨论都将是浮于表面、无根无基的。

5. 争议与说明

  • 主流解读：学界普遍认为，这段文字清晰地展现了海德格尔的现象学-存在论方法与传统形而上学（特别是黑格尔辩证法）的根本分歧。他强调必须回溯到“存在”问题本身，才能为“否定”等派生性概念奠基，反对任何未经存在论审查就直接使用哲学概念的做法。
  • 其他解读方向/争议点：
    1. 与黑格尔辩证法的关系：有学者强调这是对黑格尔“否定之否定”辩证法的彻底拒绝；也有学者认为海德格尔并非完全拒绝否定性，而是要为其寻找一个比辩证法更原始的基础（即此在的生存论结构）。
    2. “不”的肯定性：对于海德格尔所问的“‘不’的肯定性”，存在不同理解。一种认为他是在暗示“不”作为此在自由选择（选择此而放弃彼）的构成性条件，具有一种积极的、建设性的意义，而非单纯的消极否定。

本段解读在核心论点上相对一致，争议主要集中在对其批判对象（尤其是黑格尔）的理解深度，以及海德格尔本人对“否定性”的正面建构究竟为何。
