📖 《存在与时间》研读 逐段解析
首页 / 第 073 章 / 片段 014
📜 原文片段 (073/014)
海德格尔 原文
此在的存在是操心，操心包括实际性〔被抛〕、生存〔筹划〕与沉沦。作为存在者，此在是被抛的此在，但却不是把它自身带入它的“此”。作为存在者，此在被规定为这样一种能在“它听到了它自身，但却不是作为它自身把自己给与本己的。生存着的此在从不回到其被抛境况后面去，以便能把这一“它存在，且不得不存在”从它的自身存在割舍掉并把它引入“此”。但被抛境况并非挂在此在身后好似随此在发生的、事实上落到此在身上却又能从它身上脱落的事件。实则只要此在存在，此在作为操心就总是它的“它存在且不得不存在”。此在委托给了这个存在者，它只有作为它所是的存在者才能生存；作为这样一个存在者，此在生存着就是它能在的根据，虽然此在不曾自己设置这根据，但它依栖在这根据的重量上，而情绪把这重量作为负担向此在公开出来。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：指人的存在方式，是那种能够追问自身存在意义的存在者。此在的本质在于它的“存在”本身是一个问题，它总是以某种方式理解着自己的存在。
  • 操心：此在存在的整体结构，包含三个构成环节：实际性（被抛）、生存（筹划）和沉沦。它描述了此在始终处于一种“ ahead-of-itself-Being-already-in-(the-world)-as-Being-alongside (entities encountered within-the-world)”的复杂统一状态。简单说，就是人始终“先行于自身、已经在世界中、并且依于世内存在者”的存在方式。
  • 实际性 / 被抛：指此在总是已经被抛入一个既定的、它未曾选择的“世界”和“处境”之中。它发现自己“已经”在此，并“不得不”存在。这不是一个过去的事件，而是此在持续的生存论规定。
  • 生存 / 筹划：指此在总是“领先于”它当前所是的样子，向着自身的可能性去存在。它不是现成的，而是不断通过理解和抉择来“成为”它自己。
  • 沉沦：指此在日常地迷失于“世界”（常人、杂务、闲谈）之中，逃避自身本真的能在，处于一种非本真状态。
  • 能在：此在的本质在于它是一种“能够去存在”的存在者，它总是一种尚未完成、面向可能性开放的存在。
  • 根据：指此在生存的根基或源头。此在是这个根据，但它并非自己创造了这个根据（它没有选择被抛），它必须承担这个它“是”但却“不是它自己设立”的根基。
  • 情绪：不是心理学的情感，而是此在基本的“现身情态”。它以一种前反思的方式，向此在揭示其被抛入世、不得不存在的“负担”和“重量”。

2. 逐句转译

  1. 原文：此在的存在是操心，操心包括实际性〔被抛〕、生存〔筹划〕与沉沦。 转译：人的根本存在方式就是“操心”，这种操心包含了三个不可分割的方面：一是人总是被抛入一个既定的现实（实际性）；二是人总是面向未来进行筹划（生存）；三是人日常中往往迷失于外部世界而逃避自身（沉沦）。

  2. 原文：作为存在者，此在是被抛的此在，但却不是把它自身带入它的“此”。 转译：作为一个具体的人，他是被抛到这个世界上的，但他并不是自己把自己带到这个处境中来的。他的“在此”（他的具体人生境况）是给定的，不是他选择的。

  3. 原文：作为存在者，此在被规定为这样一种能在“它听到了它自身，但却不是作为它自身把自己给与本己的。 转译：人本质上是一种面向可能性存在的存在者（能在）。他能在日常中“听到”关于自己的种种说法（比如社会对他的期望和评价），但这些并不是他本真的自我所给予和决定的。

  4. 原文：生存着的此在从不回到其被抛境况后面去，以便能把这一“它存在，且不得不存在”从它的自身存在割舍掉并把它引入“此”。 转译：一个活着的人，永远无法回溯到他被抛入世界之前的某个时间点，他不可能把自己“不得不存在”这个事实从他的存在中剥离出去，然后重新选择要不要进入这个世界。

  5. 原文：但被抛境况并非挂在此在身后好似随此在发生的、事实上落到此在身上却又能从它身上脱落的事件。 转译：但是，被抛境况并不是一个发生在我们身后、像一件偶然事件砸中我们、以后又能甩掉的包袱。

  6. 原文：实则只要此在存在，此在作为操心就总是它的“它存在且不得不存在”。 转译：实际上，只要人还活着，他作为“操心”的存在，就始终背负着“他存在且不得不存在”这个最基本的事实。

  7. 原文：此在委托给了这个存在者，它只有作为它所是的存在者才能生存；作为这样一个存在者，此在生存着就是它能在的根据，虽然此在不曾自己设置这根据，但它依栖在这根据的重量上，而情绪把这重量作为负担向此在公开出来。 转译：人被交付给了他自己这个特定的存在者，他只能以这个特定的、被抛的身份去生活，去筹划他的可能性。他就是他自身可能性的那个根基。虽然这个根基不是他自己设立的（是被抛的），但他必须栖息在这个根基所带来的“重量”之上。而情绪（比如焦虑、无聊）正是把这种“不得不承担自己生命”的重量感，作为一种负担，清晰地揭示给人看。

3. 论证逻辑梳理

  • 前提1：此在的存在结构是操心，它包含了被抛、筹划和沉沦这三个环节。
  • 前提2：此在是被抛的存在者，它的“此”（具体处境）是给定的，而非自我选择的。
  • 核心论证与推进：
    1. 首先，澄清被抛的“非事件性”：海德格尔反驳了一种可能误解，即认为被抛是发生在过去、可以事后分离的事件。他强调，被抛是此在持续不断的生存论状态。
    2. 然后，确立被抛的“本体论优先性”：他指出，只要此在存在，它就“是”它的被抛（它存在且不得不存在）。这是操心结构的基础环节。
    3. 最后，阐明被抛与能在的关系：此在作为被抛的存在者，恰恰是它自身可能性（能在）的根据。这是一个深刻的悖论——此在是它自身可能性的基础，但这个基础本身却是被给予的、非它自己创造的。它必须承担起这个它“是”但却“不曾设置”的根基。
  • 结论：此在的生存就是承担起这个被抛的根据，而这个承担的“重量”通过情绪被揭示出来。被抛境况是此在无法摆脱、必须背负的生存事实，它构成了此在筹划其可能性的起点和沉重背景。

4. 整体概括

这段文字的核心，是在深入阐释“被抛”这一概念。海德格尔想告诉我们，人的存在有一个无法选择的底色：我们发现自己已经“被扔”到了这个世界上，拥有一个特定的身体、时代、家庭和文化背景（被抛），这并不是一个可以回顾或丢弃的过去事件，而是我们每时每刻都在活着的、必须承担的基本事实。我们所有的未来规划、人生选择（筹划），都是在这个既定的、我们不曾亲自选定的“地基”上展开的。我们就是自己人生可能性的根基，但这个根基本身却是被给予的，带着一种沉甸甸的“重量”。这种“不得不存在、不得不为自己负责”的沉重感，并非通过理性思考，而是通过情绪（如焦虑）直接向我们袭来。因此，人的自由（能在）并非轻飘飘的任意妄为，而是在沉重被抛境况下的负重前行。

5. 争议与说明

本段解读相对一致，核心概念“被抛”及其与“根据”的关系是海德格尔哲学中比较清晰的论述。可能的细微争议点在于对“情绪”揭示“负担”的理解：一种解读强调这是此在直面本真存在的契机（焦虑使人面对虚无与自身责任）；另一种解读可能更消极，认为这仅仅描述了此在被抛境况的被动性和压抑性。但主流观点倾向于前者，认为情绪的揭示具有开启本真生存的积极意义。
