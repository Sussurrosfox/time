📖 《存在与时间》研读 逐段解析

📜 原文片段 (073/005)
海德格尔 原文
我们已经用一个命题给出了这个问题的答案：呼声不说出任何可供议论的东西，它不提供任何关于事件的知识。呼声向前指引此在到其能在处去，而这时呼声是出自无家可归状态的呼声。呼唤者诚然是不确定的，但他从何处呼唤，对呼唤来说却并非无关紧要。这个何所由来，即被抛的个别化的无家可归状态，在呼唤中被一道呼出，也就是说，一道展开。在唤上前去到一之际，呼唤的何所由来就是唤回的何所归去。呼声并不给出任何理想的普遍的能在供人领会；它把能在展开为各个此在的当下个别化了的能在。唯当我们把呼声领会为唤上前来的唤回，才能充分规定呼声的开展特点。只有依循这一方向以这种方式把捉呼声，才问得上呼声给出什么东西供人领会。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 呼声：在海德格尔哲学中，指此在（人的存在）内在的、非语言的召唤，它呼唤此在直面自身最本己的能在（可能的生存方式）。此段强调它不传递具体信息，而是指引此在回归自身。
  • 此在：指人的存在方式，其本质在于“去存在”，即不断筹划和实现自身的可能性。
  • 能在：此在面向未来的可能生存方式，不是固定的属性，而是需要通过行动去实现的动态可能性。
  • 无家可归状态：此在被抛入世界后的根本处境——失去了对存在的本真理解，处于一种迷失和不安定状态。
  • 被抛：此在无法选择已被投入世界的事实，带着既定的历史和环境开始存在。
  • 个别化：呼声将此在从沉沦于“常人”的公共状态中唤醒，使其面对自身独一无二的生存责任。

2. 逐句转译

  • “我们已经用一个命题给出了这个问题的答案：呼声不说出任何可供议论的东西，它不提供任何关于事件的知识。”
    → 我们之前已经说过：良知的声音（呼声）不会像聊天那样讨论具体事情，也不告诉你发生了什么外部事件。

  • “呼声向前指引此在到其能在处去，而这时呼声是出自无家可归状态的呼声。”
    → 这声音是指引你面向未来可能的生存方式的，而且它恰恰来自于你内心深处那种“无家可归”的漂泊感。

  • “呼唤者诚然是不确定的，但他从何处呼唤，对呼唤来说却并非无关紧要。”
    → 虽然我们说不清到底是谁在呼唤（不是具体的人或神），但呼唤的“来源地”非常重要。

  • “这个何所由来，即被抛的个别化的无家可归状态，在呼唤中被一道呼出，也就是说，一道展开。”
    → 这个来源，就是你被抛入世界后那种独特的、孤独的无依状态，它随着呼唤一同被呈现出来。

  • “在唤上前去到一之际，呼唤的何所由来就是唤回的何所归去。”
    → 当呼声召唤你向前展望未来可能性的同时，它也让你回归到你的根源——你的被抛境遇。

  • “呼声并不给出任何理想的普遍的能在供人领会；它把能在展开为各个此在的当下个别化了的能在。”
    → 呼声不会给你一个标准答案或通用人生模板，它只是让你看到此时此刻专属于你的独特可能性。

  • “唯当我们把呼声领会为唤上前来的唤回，才能充分规定呼声的开展特点。”
    → 只有理解呼声同时具备“向前召唤”和“向后召回”的双重动作，我们才能真正把握它是如何展现的。

  • “只有依循这一方向以这种方式把捉呼声，才问得上呼声给出什么东西供人领会。”
    → 只有按照这个思路去理解呼声，我们才有资格追问：它到底让我们领悟到什么。

3. 论证逻辑梳理

  • 前提：呼声不提供具体知识，而是指引此在面向其能在（第一句）。
  • 推进1：揭示呼声的源头是被抛的无家可归状态，这种状态随着呼唤被同时展现（第二至四句）。
  • 关键转折：指出呼声具有双向结构——唤向前方（能在）的同时也在唤回根源（被抛境遇）（第五句）。
  • 推进2：强调呼声的个体性，它不提供普遍方案，只揭示此人此时的独特可能（第六句）。
  • 结论：只有把握这种“唤前-唤回”的双重结构，才能正确理解呼声的展开方式，进而探讨它的启示意义（第七、八句）。

4. 整体概括

这段文字在深入阐释良知呼声的本质。海德格尔强调，呼声不是给我们提供具体建议或道德教条，而是通过让我们感受到自身“无家可归”的被抛境遇，召唤我们直面自己独一无二的人生可能性。它有一个精妙的双向结构：一方面指引我们向前筹划未来，另一方面又把我们拉回现实的生存根基。只有理解这种既唤前又唤回的动态过程，我们才能真正领会呼声要告诉我们什么——它不是外在的训导，而是内在的觉醒，让我们从随波逐流的状态中挣脱出来，承担起属于自己的生命可能。

5. 争议与说明

本段解读相对一致。可能的细微争议在于对“唤回”的理解：有学者强调这主要是对“被抛事实”的召回，另一些则认为更是对“本真决心”的召回。但总体上海德格尔强调“向前-召回”的辩证结构是学界共识。
