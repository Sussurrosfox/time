📖 《存在与时间》研读 逐段解析
首页 / 第 073 章 / 片段 033
📜 原文片段 (073/033)
海德格尔 原文
良知阐释的最后一步是从生存论上界说在良知中得以见证的本真能在。为了保证良知的流俗理解也得通达这一步，就需要明确指出存在论分析的结果与日常良知经验之间的联系。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 良知：在海德格尔哲学中，“良知”并非指道德上的善恶判断或内心的道德声音，而是一种“呼唤”，它把此在（人）从沉沦于“常人”的日常状态中唤醒，召唤此在回到它自己最本己的能在。
  • 生存论：海德格尔的“生存论”不是生物学意义上的“生存”，而是指此在（人）的存在方式，即此在如何通过筹划、理解、决断等方式展开其存在的可能性。
  • 本真能在：“本真”指此在不再人云亦云，而是真正成为自己；“能在”指此在本质上是一种朝向未来的可能性存在，而不是一个固定不变的东西。“本真能在”就是此在真正把握并承担起自己独特的存在可能性。
  • 流俗理解：指日常生活中未经哲学反思的、通常对“良知”的理解，例如将其理解为道德谴责或上帝的声音。

2. 逐句转译

  • “良知阐释的最后一步是从生存论上界说在良知中得以见证的本真能在。”
    → 我们分析良知，最后要完成的一步是：从“人是如何活着、如何面对自己可能性”这个角度，来明确界定一种真正的、属于自己的生活可能性——这种可能性，正是在良知的呼唤中被我们亲身见证到的。

  • “为了保证良知的流俗理解也得通达这一步，就需要明确指出存在论分析的结果与日常良知经验之间的联系。”
    → 为了让那些在日常生活中凭直觉理解“良知”的人也能理解我们这一步哲学分析，我们必须清楚说明：我们的哲学分析结果，和人们在日常生活中对良知的体验之间，到底有什么关联。

3. 论证逻辑梳理

  • 前提：对良知的生存论阐释即将完成，其目标是界定“本真能在”。
  • 中间推进：海德格尔意识到，他的哲学分析（存在论分析）不能悬在空中，必须与现实经验连接。因此，他提出需要建立一个桥梁。
  • 结论/任务：必须明确展示哲学分析的结果（本真能在）与日常良知经验之间的具体联系，以确保日常理解也能“抵达”哲学阐释的结论。

4. 整体概括

这段话是海德格尔在规划他阐释良知的最后步骤。他明确表示，最后的目标是从“人的存在方式”这一哲学角度，去定义那个在良知呼唤中向我们显现的、真正属于自己的生命可能性。同时，他非常注重理论的落地，强调必须说清楚他这套哲学分析和普通人日常所理解的“良知”有什么关联，这样才能让哲学思考不只停留在书本上，也能被日常经验所理解和通达。

5. 争议与说明

本段内容更多地是阐述研究方法和目标，而非提出一个具体的、有争议的哲学论断。因此，在学界对于这段话本身的解读相对一致，没有广为人知的重大争议。争议更多地集中在海德格尔对“良知”和“本真性”的整体论述上，而非这段方法论说明。
