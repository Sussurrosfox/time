📜 原文片段 (067/003)
海德格尔 原文
实际上此在首先与通常把自身保持在一种非本真的向死存在中。如果此在根本从来不本真地对它的终结有所作为，或者说这个本真的存在按其意义看来不能不始终对他人隐而不现的话，那么本真的向死存在之存在论的可能性会有什么办法得到“客观的”标画呢？如果这种生存上的能在本有疑问，那从生存论上对这种能在的可能性进行筹划岂不是一项幻想的事业吗？为要使这样的筹划脱出只不过是任意杜撰的虚构的范围，究竟需要什么呢？此在本身提供了为此筹划所需的指示吗？从此在本身中找得出此在的现象上的合法性的根据来吗？现在提出来的存在论任务能够从以往对此在进行的分析中为自身提供出一些在先的标识，以便迫使这一任务的计划走在一条可靠的轨道中吗？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学中的核心概念，指人的存在方式。此在不是指作为生物体的人，而是指那个能够追问自身存在、对存在有所领悟的存在者。此在的本质在于它的“生存”，即它总是处在不断展开、筹划自身可能性的过程中。

  • 向死存在：此在的一种基本生存结构，指此在始终面向死亡这一最本己的可能性而存在。死亡不是遥远的事件，而是构成此在整体性的根本视野。

  • 本真与非本真：此在的两种存在方式。“非本真”指此在沉溺于日常闲谈、好奇和两可的公众意见中，逃避自身独特的可能性；“本真”则指此在直面自身最本己的可能性（如死亡），承担起自身的独特性与有限性。

  • 生存论：海德格尔分析此在存在结构的特定方法论。它不关注经验事实，而是揭示使此在之生存成为可能的存在论条件。

  • 筹划：此在的存在方式特征，指此在总是超前于自身，向着可能性开放，并据此理解自身与世界。

2. 逐句转译

  • “实际上此在首先与通常把自身保持在一种非本真的向死存在中。” → 我们日常生活中，大多数时候都处于一种逃避直面死亡的状态。我们习惯于随波逐流，用各种琐事和公共意见来麻痹自己，不去认真思考死亡这个每个人最终都要面对的、最个人化的事实。

  • “如果此在根本从来不本真地对它的终结有所作为，或者说这个本真的存在按其意义看来不能不始终对他人隐而不现的话，那么本真的向死存在之存在论的可能性会有什么办法得到‘客观的’标画呢？” → 如果人们从来都不曾真正地面对死亡（即处于本真状态），或者即使有人做到了，这种状态也因其极端个人化而无法被外人直接观察到，那么我们这些研究者，又凭什么能对这种“本真地向死存在”的可能性进行客观的描述和分析呢？

  • “如果这种生存上的能在本有疑问，那从生存论上对这种能在的可能性进行筹划岂不是一项幻想的事业吗？” → 如果连这种“本真地面对死亡”的可能性本身都值得怀疑，那么我们试图从哲学上系统地分析这种可能性，岂不是在构建一个空中楼阁？

  • “为要使这样的筹划脱出只不过是任意杜撰的虚构的范围，究竟需要什么呢？” → 那么，要让这种哲学分析摆脱主观臆断的嫌疑，我们究竟需要什么作为依据呢？

  • “此在本身提供了为此筹划所需的指示吗？从此在本身中找得出此在的现象上的合法性的根据来吗？” → 我们人类自身的存在方式，能否为我们提供分析所需的线索？我们能否从人类生存的现象本身，找到进行这种分析的正当理由和坚实基础？

  • “现在提出来的存在论任务能够从以往对此在进行的分析中为自身提供出一些在先的标识，以便迫使这一任务的计划走在一条可靠的轨道中吗？” → 我们现在要进行的这项哲学研究，能否从之前对人类存在的分析中找到一些先行的路标，从而确保我们的研究计划能走在一条可靠的道路上，而不至于迷失方向？

3. 论证逻辑梳理

  1. 前提/起点：此在的日常状态是“非本真的向死存在”（即逃避死亡）。
  2. 提出的核心问题（困境）：
    • 既然本真的向死存在在经验上难以观察（要么人们不去做，要么做了也无法被外人看到），那么从哲学上（存在论上）如何去客观地界定和描述它？
    • 这引发了对整个研究计划合法性的怀疑：如果研究对象如此“虚无缥缈”，那这项研究会不会只是哲学家的空想？
  3. 追问解决方案：
    • 为了摆脱“空想”的指控，必须找到坚实的依据。
    • 作者将目光转向“此在本身”，追问：我们人类自身的存在结构，是否能提供这种依据？
  4. 最终导向：
    • 问题的答案指向了对“以往分析”的回顾。作者暗示，必须回溯到之前已经阐明的关于此在的基本结构，从中寻找能够指引当前这项关于“本真向死存在”研究的“路标”。

逻辑链条：现象描述（日常的非本真性） → 揭示方法论困境（如何研究不可直接观察的本真性） → 寻求合法性基础（如何避免空想） → 提出解决方案的路径（回溯到此在自身及其先前被揭示的结构）。

4. 整体概括

这段话是海德格尔在正式深入分析“本真的向死存在”之前所做的方法论反思。他清醒地认识到，由于人们通常都在逃避死亡，而真正直面死亡又是一种高度个人化、难以从外部观察的体验，这就使得从哲学上系统地研究这种“本真状态”变得非常困难，甚至显得像是凭空臆想。为了确保研究的严谨性和客观性，他必须为其找到一个牢靠的根基。因此，他提出要回到“此在”本身，即回到人类最基本的存在结构中，去探寻能够指引这一研究方向的线索和路标。本质上，这是哲学家在攀登险峰前，反复检查和确认自己的登山装备与路线图是否可靠。

5. 争议与说明

本段解读相对一致。核心共识在于，这是海德格尔方法论自觉的体现，他在进入一个艰难论域前，先清理地基，回应可能的质疑。可能的细微争议点在于对“客观的”一词的理解：有学者强调，海德格尔这里的“客观”并非指自然科学式的对象化客观，而是在现象学意义上，要求其描述必须严格植根于此在可显现的存在结构本身，具有现象上的明证性和约束力，而非主观臆断。
