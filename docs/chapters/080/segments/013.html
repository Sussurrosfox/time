📖 《存在与时间》研读 逐段解析
首页 / 第 080 章 / 片段 013
📜 原文片段 (080/013)
海德格尔 原文
这种逃遁式的说我动因何在？在于此在的沉沦。此在因沉沦而逃避它自己，逃到常人中去。“自然的”说我是由常人自身来进行的。在“我”中说出其本身的那个自身是我首先与通常并不本真所是的那个自身。对于消散在日常状态的形形色色与所操劳的纷扰自逐这种境况来说，遗忘自身的“我操劳”的自身作为持驻自一但空洞无定的简单者显现出来。就因为人是人所操劳的东西。“自然的”存在状态上的言我〔Ich-Rede〕漏看了用我所意指的此在的现象内涵，但对“我”的存在论阐释却不能以此为理由也一道这样漏看，并把一种不适当的“范畴”视野强加到自身问题的讨论上去。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在 (Dasein)：海德格尔哲学的核心概念，指人的存在方式。此在的本质在于“去存在”，即它总是处在动态的、筹划自身可能性的过程中，而非一个现成的、固定的事物。
  • 沉沦 (Verfallen)：此在日常存在的基本方式。此在总是已经沉陷于它所操劳的世界中，被“常人”所支配，从而逃避面对自己本真的、个别化的存在可能性。
  • 常人 (das Man)：指日常生活中的匿名公共权威。它规定了“大家”都如何行事、如何思考，消除了个人的独特性和责任，提供了一种安稳但非本真的生存方式。
  • 本真 (Eigentlichkeit) 与非本真 (Uneigentlichkeit)：本真状态是此在直面自身、承担起自身独一无二的存在可能性的状态；非本真状态则是此在逃避自身、消散于“常人”之中的状态。
  • 操劳 (Besorgen)：此在与世界打交道的基本方式，特指此在与他物（工具、事物）打交道的日常实践活动。
  • 存在论 (Ontologie)：探究“存在”本身的意义的哲学研究，区别于仅研究具体存在者的“存在状态”研究。
  • 范畴 (Kategorie)：传统哲学（如亚里士多德哲学）中用于规定“现成事物”的概念框架。海德格尔认为，用这类范畴来理解“此在”这种非现成的存在者是根本错误的。

2. 逐句转译

  • “这种逃遁式的说我动因何在？在于此在的沉沦。”

  • 我们为什么会用这种逃避的方式来言说“我”？根源在于“此在”的“沉沦”状态。

  • “此在因沉沦而逃避它自己，逃到常人中去。”

  • 此在因为处在沉沦状态中，所以它要逃避面对真实的自己，于是就逃到“常人”的集体中去寻求庇护。

  • “‘自然的’说我是由常人自身来进行的。”

  • 我们日常生活中那种看似“自然而然”的、脱口而出的“我”，其实是那个支配着我们的“常人”在替我们说话。

  • “在‘我’中说出其本身的那个自身是我首先与通常并不本真所是的那个自身。”

  • 当我们随口说出“我”时，所指向的那个“自我”，其实并非我本真的、真实的自己，而是我平日里通常所不是的那个被常人同化了的“假我”。

  • “对于消散在日常状态的形形色色与所操劳的纷扰自逐这种境况来说，遗忘自身的‘我操劳’的自身作为持驻自一但空洞无定的简单者显现出来。”

  • 当我们完全沉溺于日常生活的各种琐事和繁忙活动时，那个忘记了自己真实面目的、只知道“我在忙这忙那”的自我，看起来好像是一个稳定、统一、简单的实体，但它实际上是空洞而没有具体内容的。

  • “就因为人是人所操劳的东西。”

  • 这是因为，人（此在）在根本上就是由他所从事、所操劳的那些活动所定义和构成的。

  • “‘自然的’存在状态上的言我〔Ich-Rede〕漏看了用我所意指的此在的现象内涵...”

  • 日常的、非反思的“说我”方式，完全忽略掉了当我们说“我”时，这个词背后所指的那个丰富的、作为“此在”的现象本身。

  • “但对‘我’的存在论阐释却不能以此为理由也一道这样漏看，并把一种不适当的‘范畴’视野强加到自身问题的讨论上去。”

  • 但是，哲学上对“我”进行存在论层面的深入探究，绝不能因为日常言谈的疏漏，也跟着犯同样的错误，更不能把原本用于分析“物”的那些僵化的“范畴”概念，生搬硬套到对“自我”问题的讨论上。

3. 论证逻辑梳理

  1. 前提与问题提出：从现象观察入手，指出日常言谈中的“我”有一种“逃遁”的特性。
  2. 根源分析：立刻将这种特性的根源追溯到“此在的沉沦”，并阐明了其机制：沉沦 → 逃避自身 → 逃入“常人”。
  3. 现象描述：具体描述这种非本真的“说我”是如何运作的：它是“常人”在说话；它指向的是一个非本真的、被遗忘的自我；这个自我在繁忙的操劳中显现为一个空洞的“简单者”。
  4. 原理深化：点明这种现象的深层原因在于“人是人所操劳的东西”，即人的存在是由其实践活动建构的。
  5. 存在论划界与任务：在完成现象描述后，划清界限：日常言谈（存在状态）可以“漏看”，但存在论研究绝不能。并由此引出存在论研究的正确路径：必须避免用不恰当的“范畴”来理解“自身”。

4. 整体概括

这段文字的核心是在剖析我们日常生活中言说“我”的方式为何是虚假和逃避的。海德格尔指出，当我们不假思索地说“我”时，我们并不是在指代那个本真的、需要为自己负责的自我，而是在言说一个被“常人”（社会公众意见）所塑造和支配的、空洞的“假我”。我们沉沦于日常生活的繁忙事务中，用这个虚假的、看似简单统一的“我”来逃避面对自身真实存在的复杂性与可能性。最后，他强调，哲学研究（存在论）的任务，正是要穿透这种日常的迷雾，避免用研究“物”的思维方式来错误地理解“人”，从而揭示“我”背后所蕴含的“此在”的丰富内涵。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“持驻自一但空洞无定的简单者”的理解。主流解读认为这是对传统哲学（尤其是笛卡尔式）将“我”视为一个现成的、不变的“思维实体”的批判性描述，指出现象上它看似如此，实则空洞。另一种解读可能更强调这个“简单者”本身就是“常人”自我所呈现出的幻象，是沉沦安定性的来源。但整体上，核心论旨——对日常言“我”的非本真性的揭露——是学界共识。
