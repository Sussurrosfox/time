📖 《存在与时间》研读 逐段解析
首页 / 第 039 章 / 片段 013
📜 原文片段 (039/013)
海德格尔 原文
在此的诸存在性质的分析是一种生存论分析。这等于说：这些性质不是现成东西的属性，它们本质上是生存论上去存在的方式。所以我们必须把它们在日常生活中的存在方式整理出来。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在 (Dasein)：海德格尔哲学的核心概念，特指“人”这种存在者。其根本特征在于，它的“存在”对它本身总是一个问题，它总是以某种方式理解着自己的存在。它不是一个现成的物体，而是一种“去存在”的动态过程。
  • 生存论分析 (existential analytic)：一种哲学分析方法，旨在揭示此在之存在的先天基本结构（即生存论建构）。它不关注具体个人的心理或生物属性，而是探究使人之为人的那些根本的存在方式。
  • 现成东西 (Vorhandenes)：指以“现成在手”方式存在的物体，如一块石头、一张桌子。它们只是在那里存在着，其存在是固定的、被规定的，不包含对其自身存在的理解和可能性。
  • 生存论性质 (Existenzialien)：此在存在的先天规定性，是此在存在的结构性环节（如“在世之中”、“操心”）。它们不是现成东西的“属性”，而是此在“去存在”的“方式”。
  • 去存在 (Zu-sein)：此在存在的根本方式。此在不是先作为一个实体然后拥有属性，它的“本质”就在于它的“去存在”，即它总是在筹划、实现其自身的种种可能性。

2. 逐句转译

  • “在此的诸存在性质的分析是一种生存论分析。”
    • 对“此在”所具有的那些根本特性的分析，是一种特殊类型的分析，即“生存论分析”。这种分析的目标是揭示人作为此在的根本存在结构。
  • “这等于说：这些性质不是现成东西的属性，它们本质上是生存论上去存在的方式。”
    • 这句话是在解释生存论分析意味着什么。它意味着，此在的这些性质（比如理解、情绪、言谈）不像一块石头的“硬度”、一张桌子的“高度”那样，是附着在一个现成物体上的静态属性。相反，它们本身就是此在如何“去存在”、如何活出自己生命的一系列动态方式。你不能像观察一个物体的颜色那样观察它们，你必须通过理解此在如何生活、如何行动来把握它们。
  • “所以我们必须把它们在日常生活中的存在方式整理出来。”
    • 因此，我们的任务就是去系统地描述和阐明，这些根本的存在方式（生存论性质）究竟是如何在我们最普通、最切近的日常生活中具体展现和运作的。

3. 论证逻辑梳理

  • 前提：我们所要分析的对象是“此在的诸存在性质”。
  • 核心界定：首先明确这种分析的性质——它不是普通的属性分析，而是“生存论分析”。这一步是关键区分，它将此在与非此在的存在者（现成东西）从根本上划分开来。
  • 理由阐述：紧接着解释为何是生存论分析——因为此在的性质本质上是“去存在”的方式，而非静态的属性。这是对核心界定的直接论证和深化。
  • 任务推导：基于上述界定和理由，自然地推导出方法论上的要求——既然这些性质是动态的“存在方式”，那么研究的正确路径就是回到此在最原初、最熟悉的生活现场（日常生活），去如实地描绘这些方式是如何展开的。

4. 整体概括

这段文字的核心在于界定研究此在的方法论原则。海德格尔强调，对于人（此在）的研究，不能沿用研究物体的那套方法。因为人的本质不在于他拥有哪些固定的特质，而在于他总在动态地“成为”自己，总在“活出”各种可能性。因此，我们必须采用“生存论分析”的方法，即深入到日常生活的具体情境中，去揭示和描述那些构成人之存在的根本活动方式（如理解、筹划、与他人共处等）是如何运作的。简单来说，研究人，就要研究他是怎么“过日子”的，而不是把他当作一个标本去测量其属性。

5. 争议与说明

本段是《存在与时间》方法论的核心宣言之一，其解读相对一致。可能的细微争议点在于对“日常生活”的初始理解：有学者强调，此处的“日常生活”已经是一种非本真状态，分析它只是为了回溯到更源始的存在结构；而另一些解读则更看重日常生活本身作为存在展开的原初场域。但就本段文字而言，这两种解读都同意海德格尔在此确立了从日常经验入手的现象学方法。
