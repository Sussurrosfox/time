📖 《存在与时间》研读 逐段解析
首页 / 第 039 章 / 片段 005
📜 原文片段 (039/005)
海德格尔 原文
除了“寓世”〔操劳〕、共在〔操持〕、自己存在〔谁〕之间的本质关联外，“在世”还有什么东西可以进一步加以展示呢？我们至少还可以比较和描述操劳及其寻视的种种衍化与操持及其顾视的种种衍化，从而扩建我们的分析工作；我们还可以透彻解说一切可能的世内存在者的存在，从而把此在从非此在式的存在者那里崭露出来。在这一方向上无疑还有未完成的任务。若着眼于在哲学人类学把生存论的先天的东西都整理出来，则前此提出来的东西还需多方面的补充。但这却不是这部探索的目标所在。这部探索的目的是基础存在论上的。所以当我们专题追问“在之中”的时候，我们不可能想要通过从其它现象派生出这一现象的方法，亦即通过某种分解意义上的不适当的分析方法来毁掉这一现象的源始性。但源始东西的非派生性并不排除对源始东西具有起组建作用的存在性质的多样性。如果这些性质是显现出来的，它们在生存论上就是同等源始的。组建环节的同等源始性现象在存在论上常遭忽视；这是因为人们在方法上未经管束，事无巨细，总倾向于用一个简单的“元根据”来指明其渊源。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 在世：指人（此在）最基本的存在方式，即人总是已经“在世界之中存在”。这不是指物理空间上的“在……里面”，而是指人与世界的一种本源、不可分割的纠缠关系。世界是此在展开其生存活动的场域。
  • 寓世：此在在世界之中，通过与“用具”（如锤子、笔）打交道而存在的方式。这种打交道海德格尔称之为“操劳”。
  • 共在：此在的存在总是与其他此在共同在世，这种与他人的共同存在方式就是“共在”，与之相关的活动是“操持”。
  • 自己存在：指此在作为“谁”而存在。此在的本质在于它的“生存”，在于它去成为它自己的可能性，而不是一个现成的、固定的“什么”。
  • 操劳：此在与世内“上手”的用具打交道的基本方式，是一种融入了实践性“寻视”的忙碌活动。
  • 操持：此在与其他此在打交道的基本方式，蕴含着对他人生活的“顾视”与关怀。
  • 寻视：操劳活动本身所带有的一种实践的、非主题化的“看”，指引着如何与用具打交道。
  • 顾视：共在活动中所带有的一种对他人生存的关切与理解。
  • 生存论：探究此在之存在结构的理论。它追问此在如何“生存”，即如何筹划其可能性并理解其自身存在。
  • 先天：在哲学中通常指先于经验的、使经验成为可能的结构或条件。在此指此在生存论结构中那些必然的、先于任何具体经验的形式规定。
  • 基础存在论：海德格尔哲学的核心计划，旨在通过分析此在的生存论结构，来为解答一般“存在”意义的问题奠定基础。此在的分析是通往存在问题的入口。
  • 源始性：指某物在存在论上是根本的、不可还原的、非派生的。它是其他现象的根基，不能从其他更基本的东西推导出来。
  • 组建环节：构成一个整体现象（如“在世”）的各个结构性部分或要素。

2. 逐句转译

  1. 原文：除了“寓世”〔操劳〕、共在〔操持〕、自己存在〔谁〕之间的本质关联外，“在世”还有什么东西可以进一步加以展示呢？ 转译：我们已经分析了“在世”的三个核心结构——与物打交道的“寓世”（操劳）、与人共处的“共在”（操持）、以及作为“谁”的“自己存在”——它们之间的本质联系。那么，除了这些，“在世”这个整体现象还有哪些方面值得我们去深入探究呢？

  2. 原文：我们至少还可以比较和描述操劳及其寻视的种种衍化与操持及其顾视的种种衍化，从而扩建我们的分析工作；我们还可以透彻解说一切可能的世内存在者的存在，从而把此在从非此在式的存在者那里崭露出来。 转译：至少，我们可以做两件事来扩展分析：第一，详细考察“操劳”（及其附带的实践视角“寻视”）和“操持”（及其附带的关怀视角“顾视”）的各种具体表现形态，并进行比较；第二，深入解释世界上所有非此在的存在者（如物体、工具等）是如何存在的，通过这种对比，让此在独特的存在方式更加清晰地凸显出来。

  3. 原文：在这一方向上无疑还有未完成的任务。若着眼于在哲学人类学把生存论的先天的东西都整理出来，则前此提出来的东西还需多方面的补充。 转译：沿着这个方向走下去，肯定还有很多研究工作要做。如果我们的目标是建立一个哲学人类学的完整体系，把此在生存论中所有先天的（即必然的、结构性的）要素都系统地整理出来，那么我们目前所分析的这些内容显然还需要大量的补充和细化。

  4. 原文：但这却不是这部探索的目标所在。这部探索的目的是基础存在论上的。 转译：但是，构建一个完整的哲学人类学体系，并不是我这本书的目的。这本书的核心任务是“基础存在论”。

  5. 原文：所以当我们专题追问“在之中”的时候，我们不可能想要通过从其它现象派生出这一现象的方法，亦即通过某种分解意义上的不适当的分析方法来毁掉这一现象的源始性。 转译：因此，当我们专门研究“在之中”（即在世的核心环节）这个现象时，我们绝不能采用一种错误的方法：试图从其他更基本的、被认为是更简单的现象中，推导或组合出“在之中”这个现象。这种分解式的、还原论的分析方法，会破坏“在之中”作为最本源、不可还原之现象的独特地位。

  6. 原文：但源始东西的非派生性并不排除对源始东西具有起组建作用的存在性质的多样性。 转译：然而，一个现象是本源的和非派生的，这并不意味着它本身是单一、贫乏的。恰恰相反，这个本源的现象可以是由多个同样本源、共同起作用的性质或环节构成的。

  7. 原文：如果这些性质是显现出来的，它们在生存论上就是同等源始的。 转译：只要这些构成性质是“在世”这个整体现象本身所显现出来的，那么它们在生存论的层面上，就具有同等的本源地位，没有谁先谁后、谁派生谁的问题。

  8. 原文：组建环节的同等源始性现象在存在论上常遭忽视；这是因为人们在方法上未经管束，事无巨细，总倾向于用一个简单的“元根据”来指明其渊源。 转译：这种“构成环节具有同等本源地位”的现象，在传统存在论研究中经常被忽略。原因在于方法论上的懒惰和混乱：人们总是不加约束地习惯于寻找一个单一的、最简单的终极原因或基础（“元根据”），然后用它来解释一切复杂现象的来源。

3. 论证逻辑梳理

  • 前提设定：作者承认，对“在世”现象的分析可以沿着“哲学人类学”的道路无限扩展（如细化操劳与操持的各种形态，对比此在与非此在的存在者）。
  • 目标限定：但作者明确划清界限，指出本书的目标并非构建详尽的哲学人类学体系，而是进行“基础存在论”的探究。
  • 核心方法论原则：基于基础存在论的目标，作者提出了一个关键的方法论禁令：不能使用“还原论”或“派生论”的方法来分析“在之中”这一核心现象，必须保护其“源始性”。
  • 对源始性的辩证阐述：紧接着，作者对“源始性”进行澄清：源始不等于单一。一个源始的整体（如“在世”）可以包含多个“同等源始”的组建环节（如寓世、共在、自己存在）。
  • 指出常见错误及其根源：最后，作者指出，传统哲学常常忽视这种“同等源始性”，其根源在于方法论上的一种坏习惯——追求一个单一的“元根据”来解释一切，从而把复杂的结构性整体强行简化了。

4. 整体概括

这段话的核心在于捍卫海德格尔现象学分析的方法论原则。作者首先承认了对“在世”现象进行更细致、更广泛分析的可能性（如深入探究操劳与操持的各种具体形式），但他立刻强调，他本书的任务并非建立面面俱到的哲学人类学，而是进行基础存在论的奠基工作。因此，他确立了一个关键方法论：绝不能将“在之中”这个最本源的现象，还原或分解为其他更基本的成分，从而抹杀它的源始性和独特性。同时，他又辩证地指出，维护其源始性不等于说它内部是铁板一块；恰恰相反，“在世”是由寓世、共在、自己存在等多个“同等源始”的环节共同组建的复杂结构。最后，他批评了传统哲学由于方法论上的懒惰，总想找一个“终极原因”来解释一切，从而忽视了这种结构性整体内部各环节的同等本源地位。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“基础存在论”与“哲学人类学”之间关系的理解。一种解读（也是主流解读）认为，海德格尔在此明确将二者区分开来，基础存在论是为解答“存在意义”问题服务的，是更根本的；哲学人类学则是以此为基础，对“人”进行更全面的、体系化的描述，是次一级的、衍生的任务。另一种可能的解读会更强调二者的联系，认为基础存在论的分析本身已经构成了哲学人类学的核心部分，只是海德格尔为了突出其根本性而有意暂时搁置了更经验性、更细节的扩充。但总体而言，海德格尔在此划清方法论语境的意图是非常清晰的，争议不大。
