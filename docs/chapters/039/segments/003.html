海德格尔 原文
存在论的此在分析工作在其准备阶段中以这一存在者的基本建构即在世为主题。这一工作的切近目标是从现象上端出此在存在的源始统一结构；此在“去在”的方式及其可能性由此而从存在论上得到的规定。对“在世界之中”的现象描述至此是依循着世界这一结构环节以及在世的存在者在其日常生活中是谁这一问题的答案来进行的。但我们在一开始提示出对此在进行准备性的基础分析这一任务之时就已经预先就在之中本身作过说明，并且以对世界的认识这一具体样式为例加以阐发。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学中的核心概念，指“人”这种特殊存在者，其本质在于“去存在”，即通过自身的生存活动和可能性来展现其存在。此在不是现成的物体，而是不断筹划、理解自身的存在。
  • 存在论：探究“存在”本身意义的哲学研究，区别于研究具体存在者的“存在者层次”研究。此在分析是存在论研究的基础。
  • 在世：此在的基本建构，指此在始终已经处于世界之中，与世界不可分割地联系在一起。不是指物理空间中的容纳关系，而是指此在通过操劳、理解等活动与世界打交道的基本生存状态。
  • 世界：不是指物理宇宙的集合，而是指此在生活于其中、与之打交道的意义整体和关系网络。包括工具、他人、文化等构成的指引关联整体。
  • 存在者层次：研究具体存在者（如物体、人）的属性和状态的层次，与探究存在意义的存在论层次相对。
  • 日常生活中是谁：指此在日常状态下的存在方式，通常表现为“常人”状态，即被社会常规和他人意见所支配的非本真状态。

2. 逐句转译

  • “存在论的此在分析工作在其准备阶段中以这一存在者的基本建构即在世为主题。”

  • 我们对“此在”（人这种存在者）进行的存在论研究，在刚开始的准备阶段，主要是要弄清楚此在最根本的结构，那就是“在世”——人总是已经在世界之中生活、活动。

  • “这一工作的切近目标是从现象上端出此在存在的源始统一结构；此在‘去在’的方式及其可能性由此而从存在论上得到规定。”

  • 这个阶段的核心目标，就是要如实地呈现出此在存在的那种最原初、最根本的统一结构。这样一来，此在“如何去存在”的各种具体方式以及它可能成为的样子，才能从存在论的角度被真正界定清楚。

  • “对‘在世界之中’的现象描述至此是依循着世界这一结构环节以及在世的存在者在其日常生活中是谁这一问题的答案来进行的。”

  • 到目前为止，我们对“在世界之中”这个现象的描述，主要是围绕着两个线索展开的：一是“世界”这个结构成分本身是什么；二是去回答：在日常生活里，这个在世界之中的存在者（此在）究竟是以“谁”的身份出现的（比如，是随大流的“常人”还是独特的自己）。

  • “但我们在一开始提示出对此在进行准备性的基础分析这一任务之时就已经预先就在之中本身作过说明，并且以对世界的认识这一具体样式为例加以阐发。”

  • 不过，需要提醒的是，其实在我们最早提出要对“此在”做基础分析这个任务的时候，就已经提前对“在之中”这个环节本身做过解释了，当时我们还特意拿“对世界的认识”（比如科学观察、理论研究）这种具体活动作为例子，来阐明“在之中”是怎么回事。

3. 论证逻辑梳理

  • 前提：此在分析是存在论研究的基础，而其准备阶段的核心主题是此在的基本建构——“在世”。
  • 目标设定：明确指出此阶段的分析目标是揭示此在存在的“源始统一结构”，从而在存在论上规定此在的存在方式及其可能性。
  • 已采用的路径：说明到目前为止的分析是沿着两个方向展开的：1) 剖析“世界”这一结构环节；2) 探究此在在日常生活中呈现为“谁”（即“常人”状态）。
  • 回顾与补充：指出在更早的规划中，已经预先对“在之中”本身进行过说明，并以“对世界的认识”为例进行了初步阐发。这表明当前的描述并非凭空开始，而是对之前已铺垫内容的延续和深化。
  • 逻辑推进：从设定总任务（分析此在） -> 明确核心主题（在世） -> 指出具体目标（揭示统一结构） -> 说明当前分析方法（通过世界和“谁”的问题） -> 回溯并关联更早的论述（对“在之中”的预先说明），形成了一个从宏观任务到具体分析路径，再回顾论证基础的完整链条。

4. 整体概括

这段话是海德格尔对《存在与时间》中“此在分析”工作方法的一个阶段性总结和说明。他告诉我们，在准备阶段，研究的核心是弄清楚人（此在）最基本的存在状态——“在世”，也就是人总是已经沉浸在世界中并与世界打交道这个事实。当前的目标是揭示这种存在状态的完整、原初的结构，从而从哲学根本上界定人如何存在以及可能如何存在。目前的分析主要从两个方面入手：一是剖析“世界”本身的结构，二是考察人在日常生活中通常是以“常人”这种非本真的身份存在的。最后，他提醒读者，对于“在之中”这个关键环节，其实在更早的论述中已经用“认识世界”这个例子做过铺垫了，现在的分析是在那个基础上的展开。

5. 争议与说明

本段内容属于海德格尔对自身方法论和论述路径的说明性文字，其解读相对一致，旨在明确其分析工作的主题、目标与进路，不存在广为人知的重大争议。
