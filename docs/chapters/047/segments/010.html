📖 《存在与时间》研读 逐段解析

📜 原文片段 (047/010)
海德格尔 原文
闲言甚至也控制着好奇的方式。闲言所说的是人们必已读过的见过的东西。好奇到处都在而无一处在，这种状态委托给了闲言。话语和视见的这两种日常存在样式就其连根拔起的倾向来说还不仅仅是并排摆在手头的‘而且其中溶秒存在方式还牵扯着那万秒存在方式。没有什么对好奇封闭着，没有什么是闲言不曾领会了的；它们自担自保，满以为自己—亦即如此这般存在着的此在—正过着一种真实而“生动的生活”呢。然而，从这种自以为是中却显现出描述着日常此在的展开状态的第三种现象。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 闲言：指日常交流中空洞、流于表面的言谈方式。人们通过闲言传递信息，但这些话语未经深入理解，只是人云亦云地重复和传播。
  • 好奇：在此指一种浮躁、分散的注意力状态，表现为不断追逐新鲜事物却从不深入探究。这种好奇永远在表面滑行，不扎根于任何真正的理解。
  • 此在：海德格尔哲学的核心概念，指人的存在方式。此在的本质在于它的“存在”本身是个问题，它通过在世界中的活动来理解和定义自己。
  • 展开状态：指此在对自身存在的理解和开放程度。此在总是以某种方式理解着自己的存在，这种理解构成了它的“展开”。

2. 逐句转译

  • “闲言甚至也控制着好奇的方式。闲言所说的是人们必已读过的见过的东西。” → 我们的日常闲聊不仅传播内容，还规定了我们“好奇”的方向和形式。闲言谈论的总是那些人们早已读过、见过、听说过的内容，本质上是在重复已有的信息。

  • “好奇到处都在而无一处在，这种状态委托给了闲言。” → 这种浮躁的好奇心无处不在，却又哪里都不真正停留和深入。它完全被交给了闲言来引导和支配。

  • “话语和视见的这两种日常存在样式就其连根拔起的倾向来说还不仅仅是并排摆在手头的‘而且其中此种存在方式还牵扯着彼种存在方式。” → 闲言（话语）和好奇（视见）这两种日常生活中常见的方式，都有一个共同特点：它们都倾向于让人脱离真实的、扎根的理解。不仅如此，它们还互相依赖、互相强化。

  • “没有什么对好奇封闭着，没有什么是闲言不曾领会了的；它们自担自保，满以为自己—亦即如此这般存在着的此在—正过着一种真实而‘生动的生活’呢。” → 在它们构建的世界里，没有什么事物是好奇不能触及的，也没有什么内容是闲言不能谈论的。它们形成一个自我封闭、自我确证的循环，并让沉浸其中的“此在”（人）误以为自己正过着一种真实、鲜活的生活。

  • “然而，从这种自以为是中却显现出描述着日常此在的展开状态的第三种现象。” → 然而，恰恰是这种自以为是、自我感觉良好的状态，揭示出了描述日常生活中“此在”如何理解自身存在的第三种关键现象。

3. 论证逻辑梳理

  • 前提：日常生活中的“闲言”和“好奇”是两种紧密相关的存在方式。
  • 分析推进： 1. 首先指出闲言不仅传播内容，还规定了好奇的浅薄方式。 2. 接着阐明好奇的本质是“无所不在却又无处扎根”，它依赖于闲言提供的内容。 3. 然后论证这两种方式具有共同的“连根拔起”倾向，即让人脱离真实、本己的理解，并且它们互相依存、互相强化。 4. 进而描述它们共同构建了一个看似无所不包、实则封闭的虚假世界，并让此在（人）产生一种“过着真实生活”的错觉（自以为是）。
  • 结论/新现象揭示：从这种“自以为是”的错觉中，海德格尔揭示出了描述日常此在“展开状态”的第三种现象（即“两可”，虽然本段未直接命名，但从全书语境可知，这是在为引入“两可”做铺垫）。

4. 整体概括

这段文字深刻地揭示了日常生活中两种相辅相成的消极存在模式——“闲言”和“好奇”。它们共同营造了一种虚假的生活景象：闲言提供着人云亦云的话题，好奇则驱使人们不断追逐这些流于表面的信息。它们使人脱离对事物和自身存在的深入理解，漂浮在一种看似无所不知、无所不晓，实则空洞无根的状态中。最可悲的是，沉浸其中的人还会产生一种“我正在真实地生活”的错觉。海德格尔指出，恰恰是这种普遍的自欺欺人，暴露了日常此在理解自身存在的另一种关键特征。

5. 争议与说明

本段解读相对一致。核心争议通常不在于对本段字面意思的理解，而在于如何更精确地界定“闲言”、“好奇”与随后将引入的“两可”三者之间的关系。有学者强调三者是递进揭示此在沉沦状态的不同侧面；也有研究认为，此段中的“自以为是”已初步具备了“两可”的特征，三者更像是同一沉沦结构的不同表现维度，而非严格的线性发展。但就本段文字本身而言，其描述的现象和内在逻辑是清晰且公认的。
