📖 《存在与时间》研读 逐段解析
首页 / 第 098 章 / 片段 013
📜 原文片段 (098/013)
海德格尔 原文
实际被抛的此在之所以能够“获得”和丧失时间，仅只在于它作为绽出的、伸展了的时间性又被赋予了某种“时间”，而这种赋予是随着植根于这种时间中的此在的展开而进行的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：指人的存在方式，是能够追问自身存在意义的存在者。此在的本质在于它的“生存”，它不是现成的物体，而是不断展开其可能性的过程。
  • 被抛：指此在总是已经被投入到一个它未曾选择的世界和生存境况中。这不是一次性的坠落，而是其存在的基本状态：它发现自己已经在“这里”，承担着特定的历史、文化和社会条件。
  • 绽出的、伸展了的时间性：“绽出”指此在的时间性并非一个静止的点或容器，而是不断地“向外站出”，即它总是通过“曾在”、“当前化”和“将来”这三个维度来理解自身和世界。“伸展”则强调这种时间性不是一个点，而是一个有宽度、有历史的整体。此在的存在是在时间的“绵延”或“跨度”中展开的。
  • 赋予……时间：这不是指物理时间的给予，而是指此在在其生存中“获得”了一种理解和体验时间的方式。时间对此在而言是可“有”可“无”的——它可以本真地抓住时间，也可以在日常沉沦中“丧失”时间。

2. 逐句转译

  • 原文第一句：实际被抛的此在之所以能够“获得”和丧失时间，仅只在于它作为绽出的、伸展了的时间性又被赋予了某种“时间”……

  • 转译：我们每个人，作为已经活在世上、处在特定处境中的人（“实际被抛的此在”），之所以有时候能真切地“拥有”时间（例如，在专注或决断时感觉时间充实），有时候却感觉“浪费”或“丢失”了时间（例如，在百无聊赖或随波逐流中），根本原因在于：我们的存在本身，就是一种动态的、不断向外展开的时间性结构（“绽出的、伸展了的时间性”）。正是基于这种时间性的存在方式，我们才被“给予”了一种可以把握或错失的时间体验。

  • 原文第二句：而这种赋予是随着植根于这种时间中的此在的展开而进行的。

  • 转译：而这种“被给予时间”的过程，并非一蹴而就，它是伴随着此在在其时间性根基上的生存展开而同步发生的。也就是说，我们如何体验时间（获得或丧失），取决于我们如何活出自己——如何筹划未来、承担过去、投入当下。

3. 论证逻辑梳理

  1. 前提/现象：此在（人）的存在状态中，存在着“获得时间”与“丧失时间”这两种不同的时间体验。
  2. 核心论证/原因分析：这种现象之所以可能，其根本原因（“仅只在于”）必须追溯到此在的存在论结构——此在本质上是“绽出的、伸展了的时间性”。
  3. 关键环节：这种时间性结构是此在能够“被赋予时间”的基础。这里的“赋予”不是一个外部动作，而是此在自身生存活动的一部分。
  4. 动态过程阐明：这种“赋予”行为是与此在的“展开”过程紧密相连、同步进行的。此在如何在其生活中实现自身（即“展开”），决定了时间如何向它呈现（是被本真地“获得”还是非本真地“丧失”）。
  5. 隐含结论：因此，时间对此在而言，不是一个外在的、均匀流逝的容器，而是内在于其生存的、需要通过其存在方式去赢取或可能错失的东西。时间体验的质量直接反映了此在生存的本真性程度。

4. 整体概括

这段话的核心意思是：我们人之所以有时感觉时间在手、充实而有力，有时又感觉时间虚度、无从把握，根源在于我们本身就是一种“时间性的存在”。我们的生命不是活在时间里的静态物体，而是活成了时间本身——它是一种不断向前筹划、同时承担着过去、并投身于当下的动态过程。我们如何生活（是积极决断地规划人生，还是浑浑噩噩地随大流），就直接决定了时间对我们而言，是作为一种被深刻“获得”的维度而展开，还是作为一种被“丧失”的、空洞的流逝而被体验。时间，在此是被“活”出来的，而不是被“看”到的。

5. 争议与说明

本段解读相对一致。核心争议点通常不在这段话本身，而在于对“被赋予时间”的理解。一种更强调生存论的解释认为，“赋予”完全是此在自身时间性运作的结果；另一种解释则带有些许被动意味，认为此在的“被抛”境况本身就包含了被给予了一种原初的时间性视野。但两种解读都承认，时间的获得与丧失取决于此在如何在其时间性中展开自身。
