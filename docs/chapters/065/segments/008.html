📖 《存在与时间》研读 逐段解析

📜 原文片段 (065/008)
海德格尔 原文
诱惑、安定与异化却标识着沉沦的存在方式。日常的向死存在作为沉沦着的存在乃是夸邓西煎的一种持续的逃遁。一向本己的此在实际上总已经死着，这就是说，总已经在一种向死存在中存在着。然而此在把这一实际情况对自己掩蔽起来了——因为它把死亡改铸成日常摆到他人那里的死亡事件，这类事件有时倒令我们更清楚地担保“人自己”确乎还“活着”。然而，凭借在死面前的沉沦逃遁，此在的日常状态倒证明了：连常人本身也一向已经被规定为向死存在了；即便它没有明确地活动在一种“想到死”的状态中也是这样。即使在平均的日常状态中，此在的本旨也始终在于这种最本己的、无所关联的、不可逾越的能在，即使其样式是为一种针对其生存的最极端的可能性的无动于衷而操劳也罢。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 沉沦：此在日常的生存方式，此在沉浸在“常人”（das Man）的公众意见与日常事务中，逃避面对自己最本己的能在，表现为诱惑、安定与异化。
  • 向死存在：此在的一种本质性结构，指此在从始至终都面向着它最本己的可能性——死亡——而存在。
  • 此在：海德格尔用来指代“人”这种存在者的术语，其本质在于“去存在”，即以理解、筹划的方式展开其生存。
  • 本己的：属于此在自身、无法被他人取代的、最个人化的存在方式。
  • 常人：一个匿名的、平均化的公众主体，它规定着日常生活的见解、趣味与行为模式，此在在沉沦中将自己交付给“常人”。
  • 能在：此在不是一种现成的、固定的实体，而总是作为“能够去存在”、面向其可能性而存在。

2. 逐句转译

  1. 原文：诱惑、安定与异化却标识着沉沦的存在方式。 转译：我们日常生活中那种随波逐流的状态，其特点就是被各种事物所“诱惑”、在平庸中感到“安定”、并最终“异化”从而远离了自己的本真面目。

  2. 原文：日常的向死存在作为沉沦着的存在乃是夸邓西煎的一种持续的逃遁。 转译：（“夸邓西煎”疑为“畏死前行”的翻译或排版错误）在日常生活中，我们虽然本质上是一种“向死存在”，但这种日常状态恰恰是一种持续的逃避——逃避去真切地面对死亡。

  3. 原文：一向本己的此在实际上总已经死着，这就是说，总已经在一种向死存在中存在着。 转译：从最根本的层面说，人（此在）从生到死，其实一直都处于“正在赴死”的过程中，他的整个存在都是由“终有一死”这个事实所塑造和贯穿的。

  4. 原文：然而此在把这一实际情况对自己掩蔽起来了——因为它把死亡改铸成日常摆到他人那里的死亡事件，这类事件有时倒令我们更清楚地担保“人自己”确乎还“活着”。 转译：但是，我们往往自欺欺人，掩盖这个事实。我们通过把死亡看作只是发生在“别人”身上的不幸事件，从而心安理得。当我们看到“别人死了”，反而更能确证和安慰自己“我还活着”。

  5. 原文：然而，凭借在死面前的沉沦逃遁，此在的日常状态倒证明了：连常人本身也一向已经被规定为向死存在了；即便它没有明确地活动在一种“想到死”的状态中也是这样。 转译：然而，讽刺的是，正是这种在日常生活中对死亡的逃避行为本身，恰恰反过来证明了：即便是那个沉沦于“常人”状态的我们，其生存根基也早已被“向死存在”所规定。哪怕我们平时根本不去明确地思考死亡，这一点也依然成立。

  6. 原文：即使在平均的日常状态中，此在的本旨也始终在于这种最本己的、无所关联的、不可逾越的能在，即使其样式是为一种针对其生存的最极端的可能性的无动于衷而操劳也罢。 转译：所以，即使在最浑浑噩噩的日常生活中，人（此在）生存的核心与目的，也始终指向着他那最个人化（无人能替）、无法依靠任何他人、且最终无法逃避的可能性（即死亡）。即便他呈现出来的样子，是通过忙于各种琐事，来表现对死亡这个最极端可能性的彻底麻木不关心。

3. 论证逻辑梳理

  • 前提1：此在的本质结构是“向死存在”，死亡是其最本己的可能性。
  • 观察现象：但在日常生活中，此在处于“沉沦”状态，通过将死亡视为他人的事件来逃避面对它，以此获得一种虚假的“活着”的安心感。
  • 关键推理：这种逃避行为并非证明“向死存在”无关紧要；恰恰相反，逃避这个行为本身，正从反面印证了“向死存在”是此在无法摆脱的、根基性的规定。正因为死亡是如此根本的威胁，此在才需要如此费力地去逃避它。
  • 结论：因此，即使在看似最不关心死亡的日常沉沦中，此在生存的核心（“本旨”）也依然被其“向死存在”所驱动和定义，只不过是以一种麻木和回避的消极样式表现出来。

4. 整体概括

这段文字的核心是在剖析我们日常生活中对待死亡的矛盾态度。海德格尔指出，人从根本上是“向死而生”的，死亡是我们个人最真实、无法替代的宿命。然而，在日常生活中，我们却通过沉沦于琐事和公众意见，刻意逃避这一点。我们把死亡看作是发生在“别人”身上的新闻，以此获得“我还安全”的幻觉。但海德格尔的精妙论点在于：正是这种处心积虑的逃避，恰恰暴露了死亡对我们的生存具有何等根本性的力量。就像一个人拼命否认一件事，反而证明了这件事对他的巨大影响一样。所以，哪怕我们表现得再麻木，我们生命的底层代码，其实早已被“终有一死”这个事实所刻写和驱动。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“日常向死存在”的消极性程度的理解。一种解读强调这是一种完全的“非本真”状态，是此在的失败；另一种解读可能认为，即便在沉沦中，此在也以扭曲的方式“回应”着它的向死存在，因此向死存在作为生存论结构是更为基础和顽固的。本解读采纳了后一种更侧重于生存论结构本身之优先性的立场。
