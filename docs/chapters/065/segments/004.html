📜 原文片段 (065/004)
海德格尔 原文
日常共处的公众意见把死亡“认作”不断摆到眼前的事件，即“死亡事件”。这个或那个亲近的人或疏远的人“死了”。每日每时都有不相识的人们“死着’，。“死亡’，作为熟知的、世内摆到眼前的事件来照面。作为这样一种事件，死亡保持在那种用以描述日常照面者特征的不触目状态中。常人对这类事件也已经备好了一种解释。对此道出的话以及多半是有所保留的“躲躲闪闪”的话都像是说：人终有一死，但自己当下还没碰上。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 日常共处（Alltägliches Miteinandersein）：指人在世界中与他人共同生活、交往的普通日常状态。这种状态中，个体往往被公众意见所支配，缺乏本真的自我思考。
  • 公众意见（Öffentliche Meinung）：海德格尔用以描述社会普遍接受、未经反思的集体看法或常识。它掩盖了事物的真实本质，使人停留在表面理解中。
  • 死亡“认作”（Auffassen als）：这里指公众意见对死亡的一种非本真理解，将死亡视为外部世界中发生的普通事件，而非与个体存在息息相关的可能性。
  • 不触目状态（Unauffälligkeit）：日常照面的事物或事件因其熟悉和普通而不会引起特别注意的状态。死亡在这种状态下被视为寻常之事，失去了其独特性。
  • 常人（das Man）：指代一种非本真的存在方式，个体在其中放弃自身独特性，迎合社会常规和 expectations。常人提供现成的解释，让人逃避对死亡的深入思考。
  • 躲躲闪闪（Ausweichen）：一种回避或逃避的态度，尤其指对死亡这一终极问题的回避，通过陈词滥调或保留态度来减轻其冲击。

2. 逐句转译

  • “日常共处的公众意见把死亡‘认作’不断摆到眼前的事件，即‘死亡事件’。”
    在日常与他人共处的状态下，人们普遍持有的看法是将死亡理解为一个不断发生在眼前的事情，就像日常生活中的其他事件一样。

  • “这个或那个亲近的人或疏远的人‘死了’。每日每时都有不相识的人们‘死着’。”
    我们总会听说某个亲近的人或陌生的人去世了，每时每刻都有不认识的人正在死去。

  • “‘死亡’，作为熟知的、世内摆到眼前的事件来照面。”
    死亡就这样作为一个熟悉的、在世界中发生的事件与我们相遇。

  • “作为这样一种事件，死亡保持在那种用以描述日常照面者特征的不触目状态中。”
    正因为死亡被看作这样一种普通事件，它就停留在那种不会引起我们特别注意的状态中，就像日常生活中其他寻常事物一样。

  • “常人对这类事件也已经备好了一种解释。”
    社会中的普通人对于死亡这类事件，已经准备好了一套现成的说法。

  • “对此道出的话以及多半是有所保留的‘躲躲闪闪’的话都像是说：人终有一死，但自己当下还没碰上。”
    人们谈论死亡时，常常用一些含糊其辞、回避实质的话，比如：“人总会死的，但我现在还没轮到。”

3. 论证逻辑梳理

  • 前提：公众意见主导着日常共处的存在方式。
  • 分析推进：
    1. 公众意见将死亡简化为一个普通事件（“死亡事件”），使其失去独特性。
    2. 通过列举亲近者、疏远者和陌生人的死亡，强调死亡在日常中的普遍性和“外部性”。
    3. 指出死亡因此处于“不触目状态”，即不被深入反思。
    4. “常人”提供了现成的、回避性的解释，将死亡推延到未来，与自身剥离。
  • 结论：日常存在通过将死亡对象化、外部化和普遍化，使人逃避了对自身死亡的本真思考。

4. 整体概括

这段文字揭示了我们日常生活中对死亡的普遍态度：人们习惯于将死亡看作一个外部的、不断发生的普通事件，就像新闻里陌生人的去世一样平常。这种看法让死亡失去了独特性，变得不再引人注目。社会上的普通人对此早有了一套现成的解释，用一些含糊的话比如“人固有一死，但我还没轮到”来回避直面死亡的意义。本质上，这是在通过将死亡推远和普遍化，逃避对自身死亡的深入思考，停留在非本真的存在状态中。

5. 争议与说明

本段解读相对一致，学界普遍认为这是海德格尔对死亡“非本真态”的经典描述。可能的细微争议在于对“常人”解释死亡的具体机制是更侧重于语言逃避还是心理防御，但核心论点并无分歧。
