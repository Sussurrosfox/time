结构化精读

1. 术语释义

  • 被敉平的现在：在海德格尔哲学中，这一概念指一种将时间简化为“现在”这一单一维度的流俗理解，它将时间视为由一系列等价的、前后相继的“现在点”构成的序列，从而抹杀了时间的本真性和丰富性（如过去与未来的独特意义）。在本段中，海德格尔用它来指黑格尔时间观的特征。

  • 现在：在海德格尔的一般用法中，“现在”是流俗时间观中的核心单元，被视为一个孤立的、不断消逝的点。在本段中，它被黑格尔描述为既张扬自身又转瞬即逝的存在，体现了其内在的矛盾性。

  • 维度（过去与将来）：在海德格尔的本体论中，过去（曾在）和将来是时间性的核心构成部分，不是简单的线性序列。本段中黑格尔认为在“自然”中，这些维度没有固定区别，这恰恰是海德格尔所批判的“敉平”时间的方式。

2. 逐句转译

  • “黑格尔是首要地依循被敉平的现在对时间进行阐释的，这一点有下列命题为证”： 海德格尔首先指出，黑格尔对时间的理解，核心是把时间看作一种被简化、被拉平了的“现在”序列。他下面引用的黑格尔的话就是证据。

  • “‘现在具有一种非常的权利：它只作为各个单独的现在‘存在’，但这个张扬自身排斥其它一切的现在，一旦我去说出它时，就消解、融化、粉碎了’”： 黑格尔说，“现在”仿佛有某种特权，它总是以一个个孤立点的形式呈现，每一个“现在”都强调自己的独一无二，排斥其他时间点。但讽刺的是，一旦我们试图去抓住它、谈论它，它立刻就消失不见了，像沙子一样从指缝中流走。

  • “此外，在自然中，时间是现在，而现在同那些维度〔过去和将来〕之间却没有什么固定的区别”： 黑格尔进一步说，在自然界中，时间就是由无数个“现在”构成的，过去和将来这些时间维度，与“现在”之间并没有截然的、固定的界限。

  • “因此，人们...”： 所以，人们（通常会据此得出某种结论，但原文在此中断）。

3. 论证逻辑梳理

  • 前提：海德格尔要论证“黑格尔的时间观是基于‘被敉平的现在’”。
  • 论证过程： 1. 他首先提出核心论点。 2. 随即引用黑格尔的两个原句作为证据。
    • 第一句引文揭示了“现在”的内在矛盾：它试图确立自身，但本身却是转瞬即逝、无法把握的。这展示了流俗“现在”观的脆弱性。
    • 第二句引文表明，在黑格尔看来，时间的其他维度（过去、未来）在自然中与“现在”没有本质区别，这等于将时间的丰富性还原为单一的“现在”序列，即“敉平”了时间。
  • 结论/推进：通过这两段引文，海德格尔成功地支撑了他的初始论断，即黑格尔的时间观是一种非本真的、流俗的时间理解。段末的“因此”预示着他将基于此批判展开进一步的论述。

4. 整体概括

这段话的核心是海德格尔对黑格尔时间观的诊断性批判。他指出，黑格尔理解时间的方式，本质上是流俗的，即把活生生的、统一的时间流，切割并简化为一系列前后相连、孤立且不断消逝的“现在”点。为了证明这一点，他引用了黑格尔的原话：黑格尔自己都承认“现在”既妄自尊大又无法被把握，并且认为过去和未来与“现在”没有根本区别。在海德格尔看来，这种将时间“敉平”的做法，恰恰掩盖了时间性更为本源的结构——即此在（人）基于其生存筹划所展开的、统一了未来、曾在与当前的本真时间。

5. 争议与说明

本段解读相对一致。海德格尔对黑格尔时间观的这一批评是其哲学中的经典论述，学界普遍认同他将黑格尔视为“流俗时间观”代表人物的这一判断。可能的细微争议点在于，海德格尔的解读是否完全公允地呈现了黑格尔辩证时间观的全貌（即黑格尔的“现在”是否真如海德格尔所言的如此扁平），但就本段引文本身而言，海德格尔的引用和定性是直接且明确的。
