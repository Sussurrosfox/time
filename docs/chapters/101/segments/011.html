📖 《存在与时间》研读 逐段解析

📜 原文片段 (101/011)
海德格尔 原文
“时间，作为出离自己存在的否定性的统一，同样也是一种纯粹的抽象、纯粹的观念。时间是存在，这存在借其存在而不存在，借其不存在而存在，亦即被直观着的变易，这就是说，那些纯然瞬间的、直接的自我抛弃着的类别被规定为外在的、然而却是对其自身外在的差别。”时间对这一解释绽露自身为“被直观着的变易”。依照黑格尔，变易意味着从存在到无与从无到存在的过渡。变易既是生又是灭。存在“过渡”，或不存在“过渡”。对时间来说，这说的是什么？时间的存在是现在‘但每一个现在“现在”就已经不再存在或现在向来先就还不存在，就此而论，也就可以把现在理解为不存在。时间是“被直观的”的变易，亦即是虽不被思却直接表现在现在序列中的过渡。如果时间的本质被规定为“被直观的变易”，这也就公开出：时间首要地从现在得到领会；也就是说：就像它可以由纯直观碰上的那样得到领会。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 出离自己存在：在海德格尔哲学中，此概念常指事物超越其当下状态、向未来敞开的存在方式。在本段中，黑格尔用以描述时间并非静止，而是不断离开自身（现在）的动态过程。
  • 否定性的统一：指时间通过不断否定每一个“现在”（使其消逝）而达成自身的整体性。时间正是由这些不断自我否定的瞬间构成的统一体。
  • 变易：黑格尔哲学核心概念，指从“存在”到“无”，再从“无”到“存在”的永恒过渡过程。它同时包含产生（生）与消逝（灭）两个方面。
  • 被直观着的变易：指变易这一抽象过程以直接、感性（而非通过概念思考）的方式呈现出来，即我们直接在经验中观察到时间的流逝。
  • 现在序列：指由无数“现在”时刻依序排列而成的时间流，是我们日常理解时间的基本形式。

2. 逐句转译

  • “时间，作为出离自己存在的否定性的统一，同样也是一种纯粹的抽象、纯粹的观念。”
    → 时间是一种不断离开自身当下状态、通过否定每一个瞬间而构成的整体，它本身非常抽象，更像是一种思想观念。

  • “时间是存在，这存在借其存在而不存在，借其不存在而存在，亦即被直观着的变易，”
    → 时间是这样一种“存在”：它刚一到场（存在）就立即消失（不存在），正因为它不断消失，才能持续流转为新的“存在”。这其实就是我们直接观察到的“变化过程”。

  • “这就是说，那些纯然瞬间的、直接的自我抛弃着的类别被规定为外在的、然而却是对其自身外在的差别。”
    → 这意味着，那些转瞬即逝、不断自我否定的时间点（现在），被界定为一种外在的、却又与自身相异的差别——每个“现在”既属于时间整体，又立刻与自身不同。

  • “时间对这一解释绽露自身为‘被直观着的变易’。”
    → 时间通过这种描述，显示出它其实就是我们直接感知到的变化过程。

  • “依照黑格尔，变易意味着从存在到无与从无到存在的过渡。变易既是生又是灭。”
    → 在黑格尔看来，变易就是从“有”到“无”，再从“无”到“有”的转变过程，同时包含产生和消亡。

  • “存在‘过渡’，或不存在‘过渡’。对时间来说，这说的是什么？”
    → 这种“过渡”（变易）或者发生，或者不发生。这对时间意味着什么？

  • “时间的存在是现在‘但每一个现在“现在”就已经不再存在或现在向来先就还不存在，就此而论，也就可以把现在理解为不存在。”
    → 时间的体现就是“现在”，但每一个“现在”刚一出现就已经成为过去（不再存在），或者它总是尚未到来（还不存在）。从这个角度看，“现在”几乎可以说是“不存在”的。

  • “时间是‘被直观的’的变易，亦即是虽不被思却直接表现在现在序列中的过渡。”
    → 时间是我们直接观察到的变易，也就是说，这种从有到无的过渡虽然不经思考，却直接显现在一连串“现在”的序列中。

  • “如果时间的本质被规定为‘被直观的变易’，这也就公开出：时间首要地从现在得到领会；也就是说：就像它可以由纯直观碰上的那样得到领会。”
    → 如果把时间的本质定义为“被直观的变易”，这就揭示出：我们首先是通过“现在”来理解时间的；也就是说，我们是在纯粹直接的观察中把握时间的。

3. 论证逻辑梳理

  • 前提：时间是“出离自己存在的否定性的统一”，即由不断自我否定的瞬间构成的动态整体。
  • 分析推进1：通过分析“变易”概念（从存在到无、从无到存在的过渡），将时间解释为“被直观的变易”——即我们在经验中直接观察到的变化过程。
  • 分析推进2：聚焦“现在”概念，揭示其矛盾性：每个“现在”既标志时间的存在，又立即不再存在或尚未存在。这种特性正体现了“变易”的本质。
  • 结论：因此，时间的本质若被规定为“被直观的变易”，则表明我们对时间的理解首要地、直接地来源于对“现在”序列的直观把握。

4. 整体概括

这段文字阐释了黑格尔对时间的理解：时间并非静止的容器，而是一个不断自我否定的动态过程。每个“现在”刚一到场就立即消失，这种永恒的流转就是我们直接观察到的“变易”。因此，我们理解时间的方式，首先来自于对一连串“现在”的直接感知，而非通过抽象思考。时间本质上就是这种直观到的、永不停息的变化本身。

5. 争议与说明

本段解读相对一致，主要争议点在于： - 海德格尔在《存在与时间》中引用并批判黑格尔的时间观，认为这种将时间视为“现在序列”的理解流于表面，遮蔽了时间更原始的“时间性”。 - 另一种解读强调，黑格尔的“被直观的变易”已经隐含了对时间动态性的把握，但海德格尔认为这仍未触及时间与存在问题的深层关联。 核心争议在于：黑格尔的时间观是揭示了时间的本质，还是仅仅描述了时间的流俗理解？海德格尔显然持后者立场。
