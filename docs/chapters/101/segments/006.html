📖 《存在与时间》研读 逐段解析
首页 / 第 101 章 / 片段 006
📜 原文片段 (101/006)
海德格尔 原文
哲学上的时间解释“在体系中的地位”可以被看成是借以衡量在这一体系中对时间的主要的和基本的看法的标准。最初流传下来的、对流俗时间领会的详尽的专题解释是在亚里士多德的《物理学》一书中，也就是说，它是与某种关于自然的存在论联系在一起的。“时间”与“地点”和“运动”相提并论。黑格尔的时间分析忠实于传统，这一分析位于《哲学全书》的第二部，其标题是：自然哲学。第一部分讨论机械性。它的第一篇用于“空间与时间”的讨论。空间与时间是“抽象的相互外在”。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • “体系中的地位”：在海德格尔哲学中，这通常指某个概念或主题在一个哲学系统（如亚里士多德或黑格尔的哲学）中所占据的理论位置和功能，它反映了该概念的系统重要性及其与其它核心概念的关联。

  • “流俗时间领会”：海德格尔用以指代日常或传统哲学中对时间的通常理解，这种理解往往将时间视为一种客观、均匀、可测量的序列（如过去-现在-未来的线性流程），而未深入到时间与存在本身的关系。

  • “自然的存在论”：指一种以自然界（物理世界）为基本研究对象的存在论，它将存在者的存在理解为自然物或物理过程的存在，而非从“此在”（人的存在）的生存结构出发。

  • “抽象的相互外在”：此为黑格尔术语，指空间和时间在概念上被理解为彼此分离、相互外在的形式；空间被看作并列的点的集合，时间被看作前后相继的瞬间序列，二者均被视为抽象、空洞的形式框架。

2. 逐句转译

  • “哲学上的时间解释‘在体系中的地位’可以被看成是借以衡量在这一体系中对时间的主要的和基本的看法的标准。” → 一个哲学体系中对时间的解释所处的位置，可以作为判断这个体系如何看待时间的关键标准。

  • “最初流传下来的、对流俗时间领会的详尽的专题解释是在亚里士多德的《物理学》一书中，也就是说，它是与某种关于自然的存在论联系在一起的。” → 历史上第一个系统解释我们日常时间观念的著作是亚里士多德的《物理学》，这个解释是和他对自然界的存在方式的理解紧密相连的。

  • “‘时间’与‘地点’和‘运动’相提并论。” → 在亚里士多德那里，时间是被和地点、运动这些概念放在一起讨论的，它们都属于物理世界的范畴。

  • “黑格尔的时间分析忠实于传统，这一分析位于《哲学全书》的第二部，其标题是：自然哲学。” → 黑格尔对时间的分析也遵循了这个传统，他的分析出现在《哲学全书》的第二部分，这部分叫做“自然哲学”。

  • “第一部分讨论机械性。它的第一篇用于‘空间与时间’的讨论。” → 这部分的第一篇先讨论“机械性”这类最基本的自然现象，其中第一章就是专门讨论空间和时间的。

  • “空间与时间是‘抽象的相互外在’。” → 黑格尔认为，空间和时间都是抽象的形式，它们之间的关系是彼此外在、互不包含的。

3. 论证逻辑梳理

  • 前提：海德格尔指出，考察一个哲学体系如何定位“时间”，是理解其时间观的关键。
  • 论证推进： 1. 他首先引证亚里士多德的《物理学》作为最早系统阐述“流俗时间领会”的例子，并点明这种解释根植于“自然的存在论”，即将时间视为与地点、运动并列的自然范畴。 2. 接着，他以黑格尔为例，说明这一传统在后世哲学（特别是德国唯心论）中得到延续。黑格尔将时间分析置于“自然哲学”部分，并将其作为讨论“机械性”自然现象的开端，与空间并列。 3. 最后，通过引用黑格尔“抽象的相互外在”这一论断，海德格尔揭示了传统时间观的核心特征：时间被理解为一种外在的、抽象的形式框架。
  • 结论/意图：通过追溯从亚里士多德到黑格尔的传统，海德格尔旨在揭示西方主流的哲学时间解释始终被束缚在“自然的存在论”视野内，未能触及时间更本源的现象（即他后来要展开的“存在与时间”）。

4. 整体概括

这段话的核心意思是，海德格尔在梳理哲学史上对时间的理解时，指出一个关键线索：看一个哲学体系把“时间”放在什么位置，就能看出它怎么看待时间。他举例说，从老祖宗亚里士多德开始，在《物理学》里就把时间和地点、运动这些自然现象绑在一起讨论，这种将时间纳入“自然哲学”范畴的传统，后来被黑格尔全盘继承，黑格尔也把空间和时间当作抽象的、外在的形式，放在他研究自然界的著作开头部分。海德格尔点出这段思想史，其实是在为他自己的理论做铺垫：他想说，自古以来的哲学家都只是在“自然物”的层面打转，没能真正触及“时间”对于人之“存在”的根本意义。

5. 争议与说明

本段内容主要是海德格尔对哲学史的事实性梳理和定位，旨在为其后续批判做铺垫，因此学界对此段的直接解读争议不大。可能的细微讨论点在于：海德格尔对亚里士多德和黑格尔时间观的概括是否完全准确？有学者认为，海德格尔的概括侧重于凸显其与传统“流俗时间观”的连续性，可能简化或忽略了亚里士多德（如时间与灵魂的关系）或黑格尔（如时间与精神的辩证运动）思想中更为复杂的面向。但总体而言，这段的历史叙述服务于其自身理论建构的目的，是相对清晰的。
