结构化精读

1. 术语释义

  • 概念：此处的“概念”并非指抽象的思维形式或类别名称，而是海德格尔现象学中的特定术语，指存在者（此处特指“此在”，即人的存在）在其存在方式中理解自身的那种基本发生事件或生成过程。它是此在通过理解活动，使自身得以显现和构成的方式。
  • 此在：海德格尔哲学的核心概念，指人的存在。此在的本质在于其“存在”，它不是现成的、固定的实体，而是不断“去存在”的可能性，其存在总是与对自身存在的理解相关联。
  • 本真：此在的一种存在状态，即此在直面自身、承担自身，如其所能是地存在，而非沉沦于常人（das Man）的公众意见之中。
  • 自由存在：在这里，并非指政治或意志上的自由选择，而是指此在依其最本己的可能性去存在的状态，即它能够是它所是的那个样子，不受非本真状态的遮蔽。

2. 逐句转译

  1. “据此，概念就是自身以理解着自己的方式得到概念理解的情况。” 这句话的意思是：所谓“概念”，指的就是这样一种情形——一个存在者（自身）通过理解它自己的过程，从而真正被“概念”（作为动词，意指“被把握、被理解”）所把握。这描述了此在存在的一种动态结构：理解自己，并在此理解中成为自己。

  2. “自身作为这种得到概念理解的情况本真地是如它所能是的那样存在，亦即，自由存在。” 这句话接着说明：当这个“自身”处于上述那种“在理解中被把握”的状态时，它才真正地、本真地成为了它能够成为的那个样子。这种状态，就是“自由存在”。这里的“自由”不是为所欲为，而是指它摆脱了外来的、非本己的规定，纯粹地依其本己的可能性展开自身。

  3. “我是纯粹概念自身，这概念作为来到了此在的概念而存在。” 这句话可以理解为：此时，“我”不再是别的什么东西，我就是那个“纯粹的概念”本身——这个“概念”是作为已经“来到”并“在此”（即“此在”）的、活生生的理解活动而存在的。我不是一个概念的对象，我就是这个概念活动本身。

  4. “但我就是这种源初的、纯粹的、自己与自...” 这句话（原文似乎不完整）试图进一步强调：“我”就是这种最原初的、未经污染和扭曲的、自己与自己相关联的存在活动。

3. 论证逻辑梳理

  • 前提：存在一种特定的“概念”定义，它不是静态的思维产物，而是“自身在理解自身过程中被把握”的动态事件。
  • 推进1：从“概念”的定义出发，论证当“自身”处于这种“被理解”的事件中时，它的存在状态就是“本真”的。因为此时它不再依赖于外物来定义自己，而是基于对自身可能性的理解来存在。这种状态被等同于“自由存在”。
  • 推进2：将上述抽象论述具体化到“我”这个此在之上。“我”的本质，就在于我是那个正在进行自我理解的“概念”活动本身。这个活动不是在我之外的，我就是它的发生地（此在）。
  • 结论/方向：（根据不完整的最后一句推断）最终将“我”的存在归结为一种最源初、最纯粹、自我指涉的存在活动。这指向了此在的本真状态是其最内在、最核心的存在方式。

4. 整体概括

这段话的核心是在重新定义“概念”，并将其与此在的本真存在和自由联系起来。海德格尔认为，真正的“概念”不是我们脑子里对事物的一个死板定义，而是此在（人）理解自身、并在这种理解中展开其存在的那种活生生的过程。当我们以这种方式存在——即我们就是我们自身的理解活动——时，我们就达到了本真的状态。在这种状态中，我们不再是按照社会常规或他人期望去生活的“常人”，而是直面自身的可能性，自由地成为我们所能是的样子。因此，“我”的本质，就在于我是这个源初的、自我相关的理解活动本身。

5. 争议与说明

本段内容非常抽象且属于海德格尔思想的核心部分，解读存在一定难度和视角差异。

  • 主流解读：如上所述，认为这是在描述此在通过生存论上的理解（Verstehen）活动构成自身，并将这种本已的、筹划性的存在方式标识为“自由”。
  • 可能的争议点：
    1. “概念”的用法：将传统哲学中静态的“概念”彻底动态化、存在论化，这与哲学史通常的理解有巨大差异，需要读者进行思维转换。
    2. “自由”的定义：这里的“自由”是存在论层面的，与日常或政治哲学中的自由概念不同，容易引起误解。
    3. 唯心论倾向：强调“我”就是“概念自身”，有被解读为某种观念唯心论的风险。但海德格尔的本意是现象学-存在论的，指的是存在方式的构成，而非意识内容的构成。
