📖 《存在与时间》研读 逐段解析
首页 / 第 102 章 / 片段 003
📜 原文片段 (102/003)
海德格尔 原文
前面诸项考察的任务是：丛此在的根据处出发，从生存论存在论上着眼于本真生存活动与非本真生存活动的可能性来阐释实际此在的源始整体。时间性公开自己为这一根据从而为操心的存在意义。因此，在剖析时间性冬煎对此在进行的准备件生存论分析工作所端出来的东西现在被回收到此在的存在整体性的源始结构之中了。借助源始时间的业经分析的诸种到时可能性，早先只曾加以“展示”的结构得到了“论证”。不过此在的存在建构的提出仍只是一条道路；目标是解答一般存在问题。而对生存的专题分析工作恰又需要事先已澄清了的一般存在观念的朗照。这样，我们更是应当把导论中道出的那个命题确定为一切哲学探索的准则了——哲学是普遍的现象学存在论，它是从此在的诠释学出发的，而此在的诠释学作为生存的分析工作则把一切哲学发问的主导线索的端点固定在这种发问所从之出且所向之归的地方上了。诚然，不可把这一命题当作教条，而要当作那个仍然“遮蔽着的”原则问题的表述——存在论可以从存在论上加以论证吗？或，存在论为此还需要一种存在者层次上的基础吗？若是，则必须由何种存在者承担这种奠基的作用？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学中的核心概念，特指“人”这种存在者。此在的本质在于其“生存”，即它总是通过理解和筹划自己的可能性而存在。它不是现成的、固定不变的东西，而是一种动态的“去存在”的过程。
  • 生存论存在论：一种探究此在之存在的哲学方法。它不从外部观察人，而是从此在自身的生存活动（理解、情绪、操心等）出发，来分析其存在的结构和意义。
  • 本真生存与非本真生存：此在存在的两种基本方式。“非本真生存”指此在沉溺于日常公众意见，失去自我；而“本真生存”指此在直面自身，承担起自身独特的生存可能性。
  • 操心：此在存在的整体结构。它描述了此在“先行于自身—已然在世—依寓于世内存在者”的统一现象，概括了此在生存的操心牵挂特征。
  • 时间性：操心结构的深层存在论基础。海德格尔认为，此在的操心本质上是时间性的，它源于一种由“将来-曾在-当前”三个维度统一构成的动态涌现过程。
  • 到时：时间性的具体实现方式。它指时间性并非一个现成的框架，而是通过各种具体方式（如决断、沉沦等）在生存中“绽出”并构成意义。
  • 存在论：研究“存在”本身（而非具体存在者）的学问。
  • 存在者层次：与“存在论层次”相对，指涉具体存在者（如人、物体）的事实性层面。

2. 逐句转译

  1. “前面诸项考察的任务是：丛此在的根据处出发，从生存论存在论上着眼于本真生存活动与非本真生存活动的可能性来阐释实际此在的源始整体。” 我们之前所有研究的核心目标，是找到此在（人）存在的根本源头。我们采用的方法是，深入分析人真实地做自己（本真）和随波逐流（非本真）这两种生存方式的可能性，从而揭示出日常生活中的人最原初、最完整的生存结构。

  2. “时间性公开自己为这一根据从而为操心的存在意义。” 我们发现，这个根本源头就是“时间性”。时间性揭示了“操心”（人牵挂、谋划着的生存状态）之所以如此存在的深层意义。

  3. “因此，在剖析时间性冬煎对此在进行的准备件生存论分析工作所端出来的东西现在被回收到此在的存在整体性的源始结构之中了。” 所以，之前我们通过对时间性的剖析，把《存在与时间》前半部分所有关于此在的预备性分析（比如对世界、对他人、对死亡的讨论），现在都整合、安放回了此在最源始的整体结构——即由时间性奠基的操心结构——之中了。

  4. “借助源始时间的业经分析的诸种到时可能性，早先只曾加以‘展示’的结构得到了‘论证’。” 之前我们只是描述了此在的各种生存结构（比如沉沦、畏、死等），现在，通过分析时间性如何具体地实现（“到时”），我们为这些结构找到了存在的根据和理由，证明了它们为何必然如此。

  5. “不过此在的存在建构的提出仍只是一条道路；目标是解答一般存在问题。” 但是，搞清楚人的存在结构并不是最终目的，它只是我们走的一条路径。我们最终的目标是要回答那个最根本的哲学问题：“存在”本身究竟是什么？

  6. “而对生存的专题分析工作恰又需要事先已澄清了的一般存在观念的朗照。” 然而， paradoxically，我们要想深入地分析人的生存，又必须先对那个一般的“存在”观念有所理解，它就像一盏灯，能照亮我们分析工作的方向。

  7. “这样，我们更是应当把导论中道出的那个命题确定为一切哲学探索的准则了——哲学是普遍的现象学存在论，它是从此在的诠释学出发的，而此在的诠释学作为生存的分析工作则把一切哲学发问的主导线索的端点固定在这种发问所从之出且所向之归的地方上了。” 因此，我们更有理由把导论里提到的那个核心观点作为所有哲学研究的根本原则：哲学就是普遍的现象学存在论，它的起点和基础是对此在的诠释（即分析人的生存）。通过分析此在，我们就把一切哲学追问的起点和终点，都锚定在了“此在”这个既提出问题、又最终要回归答案的存在者身上。

  8. “诚然，不可把这一命题当作教条，而要当作那个仍然‘遮蔽着的’原则问题的表述——存在论可以从存在论上加以论证吗？或，存在论为此还需要一种存在者层次上的基础吗？若是，则必须由何种存在者承担这种奠基的作用？” 当然，我们不能把这个原则当成死板的教条。它本身恰恰指出了一个仍然隐藏着的、更根本的问题：研究“存在”的学问（存在论），能仅仅依靠自身（即纯粹在概念层面）就证明自己的合法性吗？还是说，它必须建立在某种具体“存在者”（比如人）的现实基础之上？如果答案是后者，那么，应该由哪一种存在者来承担这个为一切存在论奠基的重任呢？

3. 论证逻辑梳理

  • 前提与起点：本段的前提是，前文已经完成了对“此在”基于“时间性”的生存论分析，并将此在揭示为“操心”。
  • 核心推进（从具体到抽象，再从抽象回到奠基问题）：
    1. 首先，总结前阶段成果：通过揭示“时间性”是“操心”的根基，将此前所有对此在的分析整合成了一个源始的整体。
    2. 接着，阐明方法论意义：对时间性的分析，为之前仅仅“展示”的现象提供了存在论上的“论证”。
    3. 然后，点明终极目标：分析此在只是手段，最终是为了解答“一般存在”问题。
    4. 随即，揭示深层困境：分析此在（特殊存在者）需要一般存在观念作为前提，但这前提本身正是要通过此在分析才能获得。这形成了一个解释学循环。
    5. 最终，提出纲领并引出根本问题：为解决这个循环，必须将“哲学是普遍的现象学存在论，从此在的诠释学出发”确立为核心准则。但这个准则本身并非答案，而是引出了一个更尖锐的、关于哲学自身奠基的问题：存在论是否需要以及为何需要一个存在者层次的基础（即此在）。

4. 整体概括

这段话是《存在与时间》中的一个承上启下的关键段落。作者首先总结道，之前的所有分析最终揭示出“时间性”是理解人之存在（此在）的整体结构“操心”的终极根据。这使之前描述性的分析获得了坚实的论证。但他随即指出，研究人并非终点，终极目标是理解“存在”本身。这里出现了一个方法论上的循环：理解存在需要先理解人，而理解人又需要先对存在有所领会。面对这个循环，海德格尔重申了他的核心哲学纲领——哲学必须是从分析人的生存出发的普遍存在论。然而，他立刻强调，这个纲领本身指向了一个更深层、尚未完全解决的“奠基”问题：研究存在的学问（存在论）本身，是否必须依赖于某个特定的存在者（即“此在”）来为其提供基础？这段话最终将这个根本问题悬置出来，为后续的探索打开了空间。

5. 争议与说明

本段的核心争议点在于对“哲学是普遍的现象学存在论，它是从此在的诠释学出发的”这一纲领性命题的理解，以及由此引出的“存在论的基础”问题。

  • 主流解读：海德格尔在此确立了一种“基础存在论”。他认为，传统形而上学追问“存在”却无根，而这个根必须扎在唯一能发问存在的特殊存在者——“此在”——的生存分析中。因此，存在论需要一个存在者层次的基础，此在就是承担这一奠基作用的存在者。这种解读认为，海德格尔给出了肯定的暗示。
  • 其他解读方向：
    1. 激进解读：有学者认为，海德格尔在此提出的问题比他给出的答案更重要。他最终要问的是“存在论可以从存在论上加以论证吗？”这暗示着存在论或许有某种不依赖于此在的“自在”的尊严，此在的分析只是通向它的路径，而非其永恒的基础。这种解读更强调问题的开放性。
    2. 方法论与本体论的张力：争议还在于，将此在作为基础，究竟是纯粹方法论上的权宜之计（因为只有人能追问存在），还是本体论上的必然要求（此在的存在方式本身就参与构成了存在的意义）。这段文字同时蕴含了这两种可能性，造成了阐释的张力。
