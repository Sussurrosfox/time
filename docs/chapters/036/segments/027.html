📖 《存在与时间》研读 逐段解析
首页 / 第 036 章 / 片段 027
📜 原文片段 (036/027)
海德格尔 原文
“移情”正如一般认识一样绝不是源始的生存论现象；但这并不是说，根本没有关乎移情的问题。移情特有的诠释学将不得不显示：此在本身的各种不同的存在可能性如何把共处及其自我认识引入歧途，并设置了重重障碍，以致真正的“领会”受到压制而此在却逃避到代用品中去了；它还不得不显示：为了能够正确地领会别人，须把何种积极的生存论条件设为前提。整个分析已经显示：共同存在是在世的生存论组建因素之一。共同此在表明自己具有世内照面的存在者的存在方式。只消此在存在，它就有了共处的存在方式。共处不能被理解为总计许多现成主体的结果。发现一定数目的“主体”摆在那里，这本身只有通过下述过程才可能：在其共同此在中照面的他人首先只还被作为“数字”对待。这样一个数目只有通过共处与相向的某种特定的存在方式才能被揭示。这种“无所顾惜”的共在把他人作了“计量”，却没有认真把他人“算数”，甚至没打算和他们“打打交道”。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 移情：在海德格尔哲学中，指一种试图通过“设身处地”来理解他人的方式。但它并非源始现象，而是基于更基础的生存结构的派生现象。
  • 生存论：探究此在（人）的存在方式的哲学进路，关注其实际生活、可能性与时间性结构。
  • 此在：指人的存在，其本质在于“去存在”，即不断筹划、理解自身可能性的方式。
  • 共处 / 共同此在：此在固有的、与他人共同在世的存在方式，不是后天形成的，而是此在的基本结构。
  • 源始：最根本、最基础的层次，不是从其他东西推导出来的。
  • 诠释学：这里指揭示和理解存在意义的 interpretive 方法。
  • 世内照面：在世界中与我们相遇的存在者（包括他人）。
  • 现成主体：传统哲学中将人视为预先给定、固定不变的实体对象。

2. 逐句转译

  • “移情正如一般认识一样绝不是源始的生存论现象；但这并不是说，根本没有关乎移情的问题。”
    → 移情和我们平常说的“认识”一样，都不是人最根本的存在方式。但这不意味着我们不该讨论移情。

  • “移情特有的诠释学将不得不显示：此在本身的各种不同的存在可能性如何把共处及其自我认识引入歧途，并设置了重重障碍，以致真正的‘领会’受到压制而此在却逃避到代用品中去了；”
    → 专门研究移情的解释学需要说明：人自身的各种可能的存在方式，是怎样误导了人与他人的共处和自我认知，制造了很多障碍，结果真正的理解被压抑，人反而躲到一些替代品（比如肤浅的同情或公式化的理解）里。

  • “它还不得不显示：为了能够正确地领会别人，须把何种积极的生存论条件设为前提。”
    → 它还得说明：要想真正理解他人，我们必须先具备哪些积极的存在条件。

  • “整个分析已经显示：共同存在是在世的生存论组建因素之一。共同此在表明自己具有世内照面的存在者的存在方式。”
    → 之前的分析已经表明：和他人一起存在，是人生在世的一个基本构成要素。这种“共同此在”表现为我们在世界中遇到的他人所具有的存在方式。

  • “只消此在存在，它就有了共处的存在方式。共处不能被理解为总计许多现成主体的结果。”
    → 只要人存在，他就已经处在与他人共处的模式中。共处不能理解成把一堆现成的、独立的主体简单加在一起。

  • “发现一定数目的‘主体’摆在那里，这本身只有通过下述过程才可能：在其共同此在中照面的他人首先只还被作为‘数字’对待。”
    → 我们能数出有多少个“主体”在那里，这本身只有通过一个过程才可能：我们在共同此在中遇到的他人，首先被我们仅仅当作数字来处理。

  • “这样一个数目只有通过共处与相向的某种特定的存在方式才能被揭示。”
    → 这种数量化的认识，只有通过一种特定的共处方式——一种彼此疏离、不深入交往的方式——才能呈现出来。

  • “这种‘无所顾惜’的共在把他人作了‘计量’，却没有认真把他人‘算数’，甚至没打算和他们‘打打交道’。”
    → 这种冷漠的共处方式只是把他人当作可计量的对象，并没有真正把他人当回事，甚至没想过要和他人有真实的交往。

3. 论证逻辑梳理

  • 前提：移情不是源始的生存论现象（它是派生的）。
  • 推进1：尽管如此，对移情的研究仍有价值，它可以揭示：此在自身的存在可能性如何扭曲了共处和自我认知，导致真正的理解被压抑，人躲入代用品。
  • 推进2：这种研究还需指明，正确理解他人需要哪些积极的生存论前提。
  • 关键论据：共同存在（共处）是此在在世的基本结构，不是后天合成的。
  • 反驳对象：反对将共处视为众多“现成主体”的集合。
  • 结论/深化：将他人视为可计数的“主体”恰恰是一种特定的、非本真的共处方式（“无所顾惜”的共在）的结果，这种方式不把他人当真，缺乏真实交往。

4. 整体概括

这段话的核心在于，海德格尔并不完全否定“移情”作为一个哲学问题，但他坚决将其置于更基础的“共处”（共同此在）生存论结构之下。他强调，人与他人共同在世是人之存在的先天模式，而非后天将独立个体简单相加。我们之所以有时会把他人视为可计数的、冷漠的对象（就像统计数字一样），恰恰是因为我们陷入了一种非本真、疏离的共处方式。真正的、深度的相互理解（“领会”）需要特定的积极生存条件，而研究移情的目的，正是要揭示那些导致理解被扭曲的障碍，并阐明通向真正理解的生存论前提。简单说，海德格尔是在为“理解他人”这个问题，找到一个比心理学“移情”更深刻的存在论根基。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“移情特有的诠释学”具体所指的理解：有学者认为海德格尔此处是在规划一个他并未完全展开的具体研究纲领；另一些则认为他仅是在原则上指出，任何关于移情的探讨都必须植根于生存论分析，他本人并无意构建一个详尽的“移情诠释学”。但就本段核心论点的理解——即移情非源始、共处是基础——学界共识度很高。
