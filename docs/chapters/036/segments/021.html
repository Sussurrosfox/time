📖 《存在与时间》研读 逐段解析

📜 原文片段 (036/021)
海德格尔 原文
他人的共同此在的展开属于共在；这展开等于说：因为此在的存在是共同存在，所以在此在的存在之领会中已经有对他人的领会。这样的领会和一般的领会一样，都不是一种由认识得出的知识，而是一种源始生存论上的存在方式，唯这种源始的存在方式才使认识与识知成为可能。自我识知以源始地有所领会的共在为基础。此在同他人一道在周围世界中寻视着有所发现有所操劳；按照作为共同存在者而在世的最切近的存在方式来看，自我识知首先就活动在对上述这些被发现被操劳的东西的领会中。有所操持的操劳是从被操劳的东西方面并随着对被操劳的东西的领会而得到领会的。所以，他人首先是在有所操劳的操持中展开的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 共同此在（Mitdasein）：指此在（人的存在）在本体论层面总是已经与他人共处于世界之中的存在方式。它不是指偶然的社交关系，而是此在存在的先天结构。
  • 共在（Mitsein）：此在的存在本质上就是与他人共同在世界中存在，这是此在的基本建构。
  • 领会（Verstehen）：不是指理智上的理解，而是此在源始地、前反思地理解自身与世界可能性的生存能力，是存在的方式。
  • 生存论（existenzial）：指从此在的存在结构出发分析其基本条件，区别于具体生存经验（existenziell）。
  • 操劳（Besorgen）：此在与世内存在者（工具、事物）打交道的日常实践方式。
  • 操持（Fürsorge）：此在与他人在世界中相遇和互动的存在方式。
  • 寻视（Umsicht）：在操劳活动中对工具整体和情境的直接、非主题化的环顾洞察。

2. 逐句转译

  • "他人的共同此在的展开属于共在；这展开等于说：因为此在的存在是共同存在，所以在此在的存在之领会中已经有对他人的领会。"
    → 我们之所以能够理解他人，是因为我们本就活在共同世界之中。理解他人是我们理解自身存在的一部分，这并非后天的学习，而是我们存在的先天方式。

  • "这样的领会和一般的领会一样，都不是一种由认识得出的知识，而是一种源始生存论上的存在方式，唯这种源始的存在方式才使认识与识知成为可能。"
    → 这种对他人的理解，和所有根本的理解一样，不是通过思考或观察得来的知识，而是我们活着就具备的底层生存模式。正因为有这种活生生的理解，后来的理性认知才有可能。

  • "自我识知以源始地有所领会的共在为基础。"
    → 我们对自己的认识，其实扎根于我们早已在共同生活中理解他人的基础上。

  • "此在同他人一道在周围世界中寻视着有所发现有所操劳；按照作为共同存在者而在世的最切近的存在方式来看，自我识知首先就活动在对上述这些被发现被操劳的东西的领会中。"
    → 我们和他人一起在日常生活中忙着做事情、使用工具；在这种最直接的生活方式中，我们对自己的认识首先体现在对正在处理的那些事物和情境的理解中。

  • "有所操持的操劳是从被操劳的东西方面并随着对被操劳的东西的领会而得到领会的。"
    → 我们关心他人的方式（操持），是通过一起处理共同面对的事物、并在处理过程中逐渐明晰的。

  • "所以，他人首先是在有所操劳的操持中展开的。"
    → 因此，我们最初是在共同处理日常事务的过程中，才真正“遇见”并理解他人的。

3. 论证逻辑梳理

  • 前提：此在的存在本质上是“共在”（与他人共处）。
  • 第一步：基于此前提，得出对此在而言，理解他人是其存在领会的内在部分，且这种领会是前反思的生存论结构。
  • 第二步：论证这种源始领会是理性认识的基础，自我认识也依赖于共在的领会。
  • 第三步：通过描述此在与他人共同操劳的具体情境，说明自我认识首先体现在对共同活动中的事物的理解上。
  • 第四步：进一步将操持（与他人的互动）关联到对操劳事物（共同活动对象）的领会，形成循环解释。
  • 结论：因此，他人首先是在共同操劳的实践中被遭遇和展开的，而非通过理论观察。

4. 整体概括

这段文字的核心论点是：我们对他人的理解并非通过观察或思考习得，而是因为我们本就活在共同世界之中——这是人类存在的先天结构。这种共同存在（共在）使得我们在最基础的生存层面就已经包含着对他人的领会。我们对自己的认识也依赖于这种共同生活的理解。在日常生活中，我们和他人一起处理各种事务，正是在这种共同忙碌的过程中，我们才真正理解他人和自己。因此，人际关系首先发生在具体的共同活动中，而不是抽象的认识中。

5. 争议与说明

本段解读相对一致，核心争议较少。可能的细微讨论点在于： - 对“源始”的理解：有学者强调这完全是非反思的，近乎本能；也有解释认为它已包含某种前概念的觉察。 - “操劳”与“操持”的关系：是严格区分还是相互渗透？海德格尔此处强调操持通过操劳显现，但未详尽展开二者的辩证关系。
