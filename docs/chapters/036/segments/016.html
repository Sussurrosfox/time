📖 《存在与时间》研读 逐段解析

📜 原文片段 (036/016)
海德格尔 原文
操持表明自身是此在的这样一种存在建构：按照操持的种种不同的可能性，这种存在建构既与此在的向着操劳所及的世界的存在相关联，同样也与向着此在本身的本真存在相关联。共处首先和往往只基于在这样的存在中共同被操劳的东西。由于人们从事同样的事而源生出〔entsrpring〕的共处，多半不仅保持在外在的界限中，而且还采取保持距离与态度审慎的方式。雇来共事的人们的共处，常常只靠猜疑来滋养。反之，为同一事业而共同戮力，这是由各自掌握了自己的此在来规定的。这种本真的团结才可能做到实事求是，从而把他人的自由为他本身解放出来。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 操持（Sorge / Care）：在海德格尔哲学中，“操持”是此在（人的存在）的整体性存在结构。它描述了人总是已经“关心着”、“担忧着”与世界打交道，并在这种关心中理解自身的存在。它不仅指向对外部事物的操心（操劳），也指向对自身可能性的筹划。
  • 此在（Dasein）：特指“人的存在”，是一种能够追问自身存在、并对存在有所理解的存在者。此在的本质在于它的“去存在”（Zu-sein），即它总是在可能性中成就自身。
  • 操劳（Besorge / Concern）：此在与他物（工具、物品等）打交道的存在方式。是一种“忙于某事”、“处理某事”的日常状态。
  • 共处（Mitsein / Being-with）：此在的一种基本建构，意味着此在在本质上总是与他人共同在世。即使独自一人，也由“共处”所规定。
  • 本真存在（Eigentlichkeit / Authenticity）：此在的一种存在方式，在其中此在直面自身，承担起自己的自由与可能性，而非人云亦云。与之相对的是“非本真存在”。
  • 源生出（entspringen）：在此语境下带有“逃避”、“逃遁”的意味，指一种非本真的共处是从对自身责任的逃避中产生的。

2. 逐句转译

  • 第一句：“操持表明自身是此在的这样一种存在建构：按照操持的种种不同的可能性，这种存在建构既与此在的向着操劳所及的世界的存在相关联，同样也与向着此在本身的本真存在相关联。”

  • 转译：我们人的存在（此在）其根本结构就是“操持”（关心/担忧）。这个结构很有意思，它有两种主要的展开方式：一种是向外，表现为我们和周围世界的事物、任务打交道（操劳）；另一种是向内，关系到我们如何面对自己最本己、真实的可能性（本真存在）。

  • 第二句：“共处首先和往往只基于在这样的存在中共同被操劳的东西。”

  • 转译：所以，我们通常所说的“与人相处”（共处），在最开始和最普遍的情况下，仅仅是建立在“我们一起处理某件事”这个层面上的。

  • 第三、四句：“由于人们从事同样的事而源生出〔entspringt〕的共处，多半不仅保持在外在的界限中，而且还采取保持距离与态度审慎的方式。雇来共事的人们的共处，常常只靠猜疑来滋养。”

  • 转译：这种仅仅因为大家在做同一份工作而形成的“共处关系”，其本质其实是一种对自身责任的“逃避”。这种关系往往很肤浅，仅仅停留在事务性的、外在的合作界限内，大家互相保持距离，态度谨慎。就像公司里雇佣关系的同事，彼此的相处常常充满了相互猜忌。

  • 第五、六句：“反之，为同一事业而共同戮力，这是由各自掌握了自己的此在来规定的。这种本真的团结才可能做到实事求是，从而把他人的自由为他本身解放出来。”

  • 转译：但是，还有一种完全不同的情况，那就是为了共同的“事业”而一起奋斗。这种共同奋斗的前提是，团队中的每个人都首先清醒地掌握了自己的生命和可能性（即达到了本真存在）。只有这种发自本真状态的、真正的团结，才能让我们直面事情本身（实事求是），并且，这种团结的真正目的，恰恰是帮助他人也成为他自己，解放他人自身的自由。

3. 论证逻辑梳理

  1. 前提确立：首先点明核心论点——此在的根本结构是“操持”，它有两个基本方向：对世界的“操劳”和对自身的“本真存在”。
  2. 现象描述（非本真共处）：基于这个前提，开始分析日常生活中的“共处”现象。指出最常见的共处形式，是仅仅建立在共同“操劳”（一起做事）之上的。这种共处是肤浅的、工具性的，甚至是充满猜忌和防备的。海德格尔认为，这种关系的根源是人们“逃避”了承担自身存在的责任。
  3. 对比分析（本真共处）：通过“反之”一词，引出与上述情况形成鲜明对比的“本真共处”。这种共处是为“同一事业”而奋斗，其核心前提是每个人都“掌握了自己的此在”（达到了本真存在）。
  4. 结论升华：最后阐明这种“本真团结”的两个高级特质：第一，它能让人“实事求是”，即无偏见地面对事情本身；第二，它的终极目的不是控制或利用他人，恰恰相反，是“把他人的自由为他本身解放出来”。

4. 整体概括

这段话的核心是在探讨人与人之间“共处”的两种截然不同的境界。海德格尔认为，我们人的存在本质上是“关心着”世界和自身的。最常见的、肤浅的共处，仅仅是基于共同处理外部事务而形成的，这种关系充满了算计、距离和猜疑，因为我们是在逃避自身。而真正的、高级的团结，则源于每个人都先成为清醒、自立的自己，然后为了一个共同的崇高事业而携手。这种团结不仅能让团队直面真相，其最高贵的价值更在于：它致力于让团队中的每一个人都获得真正的自由，成为他本该成为的样子。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“为同一事业而共同戮力”中“事业”的理解。主流的、最自洽的解读认为，这里的“事业”并非指一个具体的社会目标或政治理想，而是指每个此在都面临的、本真的“向死存在”或“良知呼唤”等生存论意义上的“事业”，即对自身存在可能性的整体承担。

另一种可能的解读方向会更多地从社会政治层面理解“事业”，但这样容易使海德格尔的思想被误解为一种集体主义。多数学者认为，海德格尔强调的是个体本真性是个体间本真团结的先决条件，其根基仍在生存论层面，而非社会层面。
