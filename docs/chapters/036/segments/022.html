📜 原文片段 (036/022)
海德格尔 原文
但因为操持首先与通常滞留在残缺的方式或者至少是淡漠的方式中，滞留在陌如路人的无所谓中，所以最切近的、本质的自我识认需要自我结识。而如果自我识认竟丧失在矜持、隐秘、乔装这些方式中，那么共处就需要特殊的途径，以求接近他人或者“深入他人背后”。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 操持 (Fürsorge)：在海德格尔哲学中，指此在（人）在日常生活中与他人打交道的存在方式。它包含两种基本模式：一种是替代性的、支配性的操持（“越俎代庖”），这会让他人依赖并失去自我；另一种是“率先解放”的操持，即帮助他人回归其自身的可能性与责任。在本段中，它主要指我们日常与他人相处的默认状态。

  • 残缺的方式 (defiziente Modi)：指操持的一种非本真、不充分的存在模式。它不是指生理或心理的残疾，而是指一种在共处中缺乏真诚投入、保持距离、关系浅薄的状态，比如冷漠、敷衍或流于表面。

  • 淡漠的方式 / 陌如路人的无所谓 (Gleichgültigkeit)：一种对他人的存在漠不关心、觉得无所谓的态度，如同对待陌生人一样，缺乏真正的关切与联系。

  • 自我识认 (Selbsterkenntnis)：指个体对自身真实存在（此在）的理解与认识。在本真状态下，这意味着直面自己的“向死存在”与可能性；但在非本真状态下，这种自我认识会迷失或被掩盖。

  • 矜持、隐秘、乔装 (Verstellen)：这些是自我识认迷失的具体方式。“矜持”指刻意保持距离、不显露真实自我；“隐秘”指隐藏内心；“乔装”则指伪装、戴上面具，向他人也向自己展示一个不真实的形象。

  • 共处 (Miteinandersein)：此在（人）的根本存在方式之一，意味着人总是已经与他人共同存在于世界之中。共处是此在的结构性特征，而非偶然的聚集。

2. 逐句转译

  • 第一句：“但因为操持首先与通常滞留在残缺的方式或者至少是淡漠的方式中，滞留在陌如路人的无所谓中，所以最切近的、本质的自我识认需要自我结识。” 这句话的意思是：我们日常与他人的相处（操持），大多时候都停留在一种不投入、不真诚的状态，要么是关系有缺陷（残缺的方式），要么干脆就是冷漠、像对陌生人一样无所谓。正因为日常相处是这样一种浮于表面的状态，所以，我们每个人对于那个最贴近自己、最本质的自我认识，反而需要自己去主动“结识”——也就是说，它不会在平常的社交中自动显现，需要我们有意识地探寻。

  • 第二句：“而如果自我识认竟丧失在矜持、隐秘、乔装这些方式中，那么共处就需要特殊的途径，以求接近他人或者‘深入他人背后’。” 这句话接着上一句说：如果一个人对自己的认识（自我识认）进一步迷失在了“刻意保持距离”、“隐藏真实想法”或者“戴上面具伪装”这些行为里，那么，我们作为共同生活的人（共处），如果想要真正了解这个人，就不能靠普通的社交了，必须采取一些“特殊途径”，要么想办法“接近”他，要么试图“看穿他表面行为背后的真实意图”（深入他人背后）。

3. 论证逻辑梳理

  • 前提： 此在（人）的日常共处（操持）通常处于一种非本真、浅薄的状态（残缺或淡漠的方式）。
  • 推论1： 由于日常相处是表面的，人最本质的自我认识无法从中自然获得，必须通过主动的“自我结识”来达成。
  • 进一步的条件： 如果一个人连这种自我认识都丧失了，并进一步用矜持、隐秘、乔装等方式掩盖自我。
  • 最终结论： 那么，在共处中，想要理解这样的人，常规的社交方式就失效了，必须寻求特殊的方法（接近或深入背后）才能穿透其表象，触及真实。

逻辑链条： 日常共处的浅薄 → 本质自我认识需要主动探寻 → （若自我认识还被主动掩盖）→ 理解他人需要特殊方法。

4. 整体概括

这段话的核心是在探讨人与人之间理解的困难性。海德格尔指出，我们平时的社交大多流于表面，是一种“无所谓”的冷漠状态。在这种状态下，一个人最深层的自我认识是无法自然显现的，需要自己主动去探索和认识。而问题更严重的是，如果一个人连自己都迷失了，还刻意用矜持、隐藏或伪装来掩饰真实的自己，那么，别人若想真正理解他，常规的社交手段就完全不够用了，必须采取一些“特殊手段”去接近他，或者努力看穿他表面的伪装，去探索他背后的真实想法和存在。这揭示了本真理解在非本真日常中的稀缺与艰难。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“深入他人背后”的理解：一种解读认为这是一种试图对象化、掌控他人的非本真行为；另一种解读则认为，在海德格尔的框架下，即使是本真的共处（率先解放的操持），也需要某种“深入”的理解，但这不是窥探，而是帮助他人澄清其自身的存在。不过，结合上下文“矜持、隐秘、乔装”的语境，主流的解读倾向于前者，即这是一种在自我隐藏的困境下，共处所面临的、带有一定对象化色彩的艰难尝试。
