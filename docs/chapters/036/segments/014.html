📖 《存在与时间》研读 逐段解析
首页 / 第 036 章 / 片段 014
📜 原文片段 (036/014)
海德格尔 原文
就其积极的样式来看，操持有两种极端的可能性。操持可能从他人身上仿佛拿过“操心”来而且在操劳中自己去代替他，为他代庖〔einspringen〕。这种操持是为他人把有待于操劳之事揽过去。于是这个他人被抛出原地，退步抽身，以便事后把所操劳之事作为停妥可用之事承接过来，要不然就是使自己完全脱卸其事。在这样的操持中他人可能变成依附者或被控制者，虽然这种控制也许是默不作声的、对被控制者始终掩蔽着的。这种把“操心”揽过去的代庖之操持在广大范围内规定着共处，而且它多半关乎对上手事物的操劳。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 操持（Fürsorge）
    海德格尔用此术语描述“此在”（人的存在）与他人共在时，对他人的存在方式所采取的态度或行为。它不是指具体的“照顾”或“关心”，而是此在与他人在世界中共处的一种基本方式。

  • 操心（Sorge）
    此在存在的整体结构，指人始终处于对自身存在的关注与筹划之中。它是此在生存的基本特征，包含了对世界的操劳（与物打交道）和对他人的操持。

  • 操劳（Besorgen）
    此在与世界中的物（工具、用具）打交道的方式，指处理日常事务的实践性活动。

  • 代庖（Einspringen）
    在本段中指一种替代他人去“操心”的操持方式，即代替他人去处理他本应自己面对的事务，从而剥夺了他亲自操心的机会。

2. 逐句转译

  • 第一句：
    “就其积极的样式来看，操持有两种极端的可能性。”
    → 从积极的形态来说，我们与他人共处的方式有两种极端的形式。

  • 第二句：
    “操持可能从他人身上仿佛拿过‘操心’来而且在操劳中自己去代替他，为他代庖。”
    → 第一种方式是：我们好像把他人本应自己承担的“操心”（对自身存在的关注）拿过来，在具体事务中代替他去做。

  • 第三句：
    “这种操持是为他人把有待于操劳之事揽过去。”
    → 这种共处方式，就是替他人把他该处理的事情全部包办。

  • 第四句：
    “于是这个他人被抛出原地，退步抽身，以便事后把所操劳之事作为停妥可用之事承接过来，要不然就是使自己完全脱卸其事。”
    → 这样一来，他人就被从他自己原本的位置上推开，他可以退到一边，等到事情办好了再坐享其成，或者干脆完全甩手不管。

  • 第五句：
    “在这样的操持中他人可能变成依附者或被控制者，虽然这种控制也许是默不作声的、对被控制者始终掩蔽着的。”
    → 在这样的代替中，他人可能变得依赖或被控制，即便这种控制是无声无息、甚至对方自己都察觉不到的。

  • 第六句：
    “这种把‘操心’揽过去的代庖之操持在广大范围内规定着共处，而且它多半关乎对上手事物的操劳。”
    → 这种代替他人操心的方式，实际上广泛地决定了我们日常的相处模式，而且它常常表现在对日常物件、工具的使用和处理上。

3. 论证逻辑梳理

  • 前提： 操持作为此在与他人的共在方式，具有积极的形态。
  • 推进： 本段聚焦第一种极端可能性——“代庖式操持”。
  • 先描述它的运作方式：代替他人去操心，包办他的事务。
  • 再分析其后果：他人被排除出他本应自己承担的存在位置，成为依附者或被控制者。
  • 指出这种控制的隐蔽性：它常常是无形的，不被对方察觉。
  • 结论： 这种代庖式的操持广泛支配着我们的日常共处，尤其体现在对“上手事物”（日常用具）的操劳中。

4. 整体概括

这一段讲的是我们与他人相处时，一种常见的“代庖”式关心：你以为是在帮他，其实是把他本该自己面对的责任揽过来，替他做了本该由他自己做的事。结果呢？他反而被排除在外，变得依赖你、受你控制，哪怕他自己没意识到。这种“替人操心”的模式，其实广泛存在于日常相处中，尤其在我们一起处理具体事务的时候——比如你替别人做完所有工作，他反而失去了自己动手、自己成长的机会。

5. 争议与说明

本段解读相对一致，学界普遍认为这是海德格尔对日常“代庖式”人际关系的现象学描述，重点在于揭示这种“帮助”背后对他人自主性的剥夺。部分研究者会联系到教育、护理、管理等现实领域，讨论这种操持方式的伦理困境。
