海德格尔 原文
康德用“正义法庭”作为主导观念来奠定他的良知解释，这不是偶然的；这通过道德律令的观念已露端倪—虽然他的道德概念离功利道德及快乐主义还相去甚远。就连价值论，无论从形式上还是从质料上开端，也都将一种“道德形而上学”，亦即将此在及生存的存在论，设为其未经道出的存在论前提。此在被当作可以对之操劳的存在者，而这种操劳具有“实现价值”或“实现规范”的意义。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 正义法庭：在海德格尔语境下，此术语指康德伦理学中作为道德判断内在权威的比喻。它象征一种内在的、如同法庭审判般的道德裁决机制，个体在此机制中同时充当被告、法官和原告。
  • 道德律令：康德伦理学核心概念，指一种无条件的、先验的道德法则。它不依赖经验后果，而是基于纯粹理性，表现为“定言命令”的形式。
  • 价值论：研究价值本质的哲学分支。海德格尔揭示其隐含前提——任何价值判断都已预设了关于“何为有价值的存在”的本体论立场。
  • 此在：海德格尔核心概念，特指“人的存在方式”。这种存在者以理解存在、关切自身存在为本质特征。
  • 生存：此在特有的存在方式，体现为不断筹划自身可能性的动态过程。
  • 操劳：此在介入世界的基本方式，指日常实践中与事物打交道的操心活动。
  • 道德形而上学：康德提出的概念，指基于先验原则的道德体系。海德格尔指出其背后实则需要更基础的存在论奠基。
  • 存在论：研究“存在本身”而非“存在者”的哲学领域。海德格尔强调传统伦理学都暗含了某种未明言的存在论前提。

2. 逐句转译

  • “康德用‘正义法庭’作为主导观念来奠定他的良知解释，这不是偶然的；这通过道德律令的观念已露端倪——虽然他的道德概念离功利道德及快乐主义还相去甚远。”
    → 海德格尔指出，康德将良知比喻为“内部法庭”绝非随意之举。这种法律隐喻其实早已蕴含在他的“道德律令”思想中——尽管康德的道德观确实比功利主义或享乐主义更为深刻。

  • “就连价值论，无论从形式上还是从质料上开端，也都将一种‘道德形而上学’，亦即将此在及生存的存在论，设为其未经道出的存在论前提。”
    → 进一步说，所有价值理论（无论关注价值形式还是具体内容），实际上都默默预设了一套关于“人的存在方式”（此在）和“动态生存”的本体论框架作为基础。这套框架在康德那里被称为“道德形而上学”，但它本身仍是未经检视的前提。

  • “此在被当作可以对之操劳的存在者，而这种操劳具有‘实现价值’或‘实现规范’的意义。”
    → 在这些理论中，人（此在）被看作一种能够通过实际行动去“实现价值”或“履行规范”的存在者。也就是说，人的日常活动被理解为执行某种预定的道德脚本。

3. 论证逻辑梳理

  1. 前提揭露：从康德良知理论的“正义法庭”隐喻入手，揭示其思想深处隐含的法律化、审判性思维模式。
  2. 脉络延伸：指出这种思维模式不仅存在于康德的律令伦理，更潜藏于一切价值论研究——无论它们关注形式规则还是具体价值内容。
  3. 深层批判：论证所有道德学说都依赖于一个未经反思的底层框架：即把“人”理解为某种能够执行价值规范的存在者（“道德形而上学”）。
  4. 存在论还原：最终将问题引向核心——这些理论都预设了关于“此在”和“生存”的特定存在论观点，却从未深入追问这种预设本身的合理性。

4. 整体概括

海德格尔这段文字核心是在对传统伦理学进行“刨根问底”。他指出：康德的良心观像法庭审判，这暴露了整个现代道德哲学的本质——把人看作必须遵守某种最高法则的存在。进而揭示，所有谈论“价值”的理论，不管什么流派，其实都默默预设了一套关于“人是什么”的观念（即“此在”如何“生存”），却从不检验这个前提本身是否合理。本质上，这是在批评传统哲学忽略了最根本的问题：在讨论人该怎么行动之前，先要弄清人这种存在者的根本方式究竟是什么。

5. 争议与说明

本段解读相对一致。可能的细微争议在于：海德格尔对“价值论”的批评是否过于笼统？有学者认为他未能区分不同价值理论间的重要差异；但主流观点认为，他的批判恰恰针对的是所有价值理论共同依赖的“存在论预设”，这一核心论证是成立的。
