📖 《存在与时间》研读 逐段解析

📜 原文片段 (069/004)
海德格尔 原文
这种见证应供人领会一种本真的能自身存在。我们曾用“自己”这个词来回答此在为谁的问题。我们曾从形式上把此在的自己之所以为自己规定为一种去生存的方式，也就是说并非规定为一种现成存在者。此在之谁首先并非我自己，而是常人自己。本真的自己存在规定自身为常人的一种生存变式，这种生存变式可以从生存论上加以界说。这种变式中含有些什么？这种变式之所以可能的存在论条件都有哪些？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学的核心概念，指“人”这种存在者。此在的本质在于它的“存在”总是与它自身的生存问题相关，它通过筹划、理解、关切等方式“去存在”，而不是一个固定的、完成了的实体。

  • 本真的能自身存在：此在以自身的方式去存在，不逃避自身的可能性与死亡，直面自身的生存抉择，承担起自己的存在。

  • 自己 / 自身：此在作为“谁”的那个身份核心。海德格尔强调它不是现成的、固定的实体（比如一个灵魂或一个主体），而是通过“去生存”的方式构成和实现的。

  • 常人：此在在日常生活中沉沦于其中的非本真状态。它代表着匿名的、平均化的公众意见和生活方式，此在在这种状态下逃避自己的个体性与责任，按照“大家怎么做，我就怎么做”的方式生活。

  • 生存变式：此在存在方式的一种模态或样态。这里指此在从“常人”的非本真状态转变为“本真自身”状态的生存方式变化。

  • 生存论：海德格尔用来分析此在存在结构的哲学方法。它不从心理学或人类学出发，而是从此在的“生存”（Existenz）本身出发，探讨其存在的可能性与结构条件。

  • 现成存在者：与“此在”相对的存在方式，指那些已经完成、固定在那里的物体或实体（如石头、树木），它们不关切自己的存在，也不以“去存在”为本质。

2. 逐句转译

  • “这种见证应供人领会一种本真的能自身存在。”
    → 这种见证（指前文提到的良知呼唤等）应该让人能够领悟到一种真正属于自己的、本真的存在方式。

  • “我们曾用‘自己’这个词来回答此在为谁的问题。”
    → 我们之前是用“自己”这个概念来回答“此在究竟是谁”这个问题的。

  • “我们曾从形式上把此在的自己之所以为自己规定为一种去生存的方式，也就是说并非规定为一种现成存在者。”
    → 我们从形式上把此在的“自己”定义成一种不断去生活、去实现的方式，而不是一个已经固定在那里的东西（比如一个物体或一个静态的灵魂）。

  • “此在之谁首先并非我自己，而是常人自己。”
    → 此在最开始的身份，通常并不是真正属于“我”自己的那个我，而是被社会常规、他人眼光所塑造的那个“常人自己”。

  • “本真的自己存在规定自身为常人的一种生存变式，这种生存变式可以从生存论上加以界说。”
    → 本真的自身存在，其实是从“常人”这种日常状态中转变而来的一种生存方式，这种转变可以从生存论的角度来分析和说明。

  • “这种变式中含有些什么？这种变式之所以可能的存在论条件都有哪些？”
    → 那么，这种转变具体包含哪些内容？它之所以能够发生的深层条件是什么？

3. 论证逻辑梳理

  • 前提：此在的“自己”不是现成的，而是通过“去生存”构成的；在日常状态中，此在首先是作为“常人”存在的。
  • 推进：指出本真的自身存在并非凭空出现，而是对“常人”状态的一种“变式”——即一种生存方式的转变。
  • 问题提出：进而追问这种转变的具体内容（“含有些什么”）以及其得以可能的存在论条件（“存在论条件都有哪些”）。
  • 结论/问题导向：本段并未给出答案，而是为接下来的分析设定了问题框架：要探究从“常人”到“本真自身”的转变机制与条件。

4. 整体概括

这段文字的核心在于阐明：此在最开始并不是以“本真自己”的方式存在的，而是活在“常人”的支配之下——即被社会常规和他人意见所笼罩。本真的自身存在，并非一个完全独立于常人的状态，而是对常人状态的一种“生存变式”，一种觉醒和转变。海德格尔在此提出了两个关键问题：这种转变具体包含哪些内容？它之所以可能发生的深层条件是什么？这为后文分析良知的呼唤、决心等本真存在方式做了铺垫。

5. 争议与说明

本段解读相对一致，核心争议不大。主要讨论点可能在于对“常人”与“本真自身”关系的理解：一种观点强调两者是截然对立的断裂；另一种则更强调本真自身是对常人状态的“改造”或“回收”，并非完全抛弃日常世界。但总体而言，本段作为问题提出段落，其基本指向是清晰的。
