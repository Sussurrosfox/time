📖 《存在与时间》研读 逐段解析
首页 / 第 030 章 / 片段 028
📜 原文片段 (030/028)
海德格尔 原文
与我们最初对“在之中”的先行描绘〔参考第十二节〕相关联，我们把存在在空间之中的一种方式称为“在之中”。此在必须同“在之内”这种存在方式划清界线。“在之内”等于说：一个本身具有广袤的存在者被某种广袤事物的具有广袤的界限环围着。在之内的存在者与环围者都现成摆在空间之内。我们拒不承认此在如此这般地在一个空间容器之内，这却不是原则上拒绝承认此在具有任何空间性，而只是使视线保持畅通，得以看到对此在具有组建作用的空间性。这一点现在就必须提出来。但只要世界之内的存在者同样也在空间之中，那么这种存在者的空间性就同世界具有某种存在论联系。所以有待规定的就是：空间在何种意义上是世界的要素。世界本身曾被描述为“存在在世界之中”的一个结构环节。尤其须得指出的是：周围世界的周围性、在周围世界中照面的存在者本身的空间性如何通过世界之为世界而获得根基，而不是反过来，仿佛世界倒现成存在在空间中。探索此在的空间性与世界的空间规定，这项工作要从分析世内在空间中上到手头的东西出发。考察分三个阶段进行：1．世内上到手头的东西的空间性〔第二十二节〕，2在世界之中存在的空间性〔第二十三节〕，3．此在的空间性，空间〔第二十四节〕。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 在之中：海德格尔用以描述此在与世界之间原初关系的核心术语。它并非指一个物体在另一个物体内部的物理位置关系，而是此在通过操劳活动与世界融为一体、沉浸于其中的生存论结构。此在本质上就是“在世界之中存在”。

  • 在之内：指两个现成事物之间外在的、物理的空间包容关系。例如，水在杯子“之内”，书在抽屉“之内”。这是一种传统形而上学和物理学所理解的空间关系。

  • 此在：指人的存在，其本质在于“去存在”，即它总是对自己的存在有所领会，并关切着自己的存在可能性的存在者。

  • 世界：并非所有现成事物的总和，而是此在生存于其中、并与之打交道的那个意义关联整体。它是一个生存论概念，而非物理空间概念。

  • 空间性：此在在世存在的一种基本方式。它不是物体的广延属性，而是此在通过其操劳活动（如定向、去远）所开显出的空间。

  • 世内存在者：在世界之中与此在照面的存在者，可分为“上到手头”的工具和“现成在手”的客体。

  • 周围世界：此在日常操劳活动所直接关涉的、由工具和用具所构成的周遭环境。

  • 周围性：周围世界的空间特性，它源于此在的操劳活动，是此在空间性的直接体现。

2. 逐句转译

  • “与我们最初对‘在之中’的先行描绘〔参考第十二节〕相关联，我们把存在在空间之中的一种方式称为‘在之中’。”

    • 承接之前对“在之中”的初步描述，我们现在要讨论的是此在存在于空间中的一种特定方式，我们称之为“在之中”。

  • “此在必须同‘在之内’这种存在方式划清界线。‘在之内’等于说：一个本身具有广袤的存在者被某种广袤事物的具有广袤的界限环围着。在之内的存在者与环围者都现成摆在空间之内。”

    • 我们必须明确区分此在的“在之中”和一般物体的“在之内”。“在之内”就像说：一个本身有体积的东西，被另一个有体积的事物的边界所包围。无论是被包围的东西还是包围它的东西，都像现成的物品一样摆放在空间里。

  • “我们拒不承认此在如此这般地在一个空间容器之内，这却不是原则上拒绝承认此在具有任何空间性，而只是使视线保持畅通，得以看到对此在具有组建作用的空间性。这一点现在就必须提出来。”

    • 我们不认为此在是像一个物体被装在容器里那样存在于空间中，但这不等于我们否认此有有空间性。我们这样做，是为了排除干扰，让我们能看清楚真正构成此在的那种空间性。这个问题现在必须明确提出来。

  • “但只要世界之内的存在者同样也在空间之中，那么这种存在者的空间性就同世界具有某种存在论联系。”

    • 然而，既然世界中的各种东西（比如工具、物品）也出现在空间里，那么它们的空间性就和“世界”这个整体有着深层的、关乎存在方式的联系。

  • “所以有待规定的就是：空间在何种意义上是世界的要素。世界本身曾被描述为‘存在在世界之中’的一个结构环节。”

    • 因此，我们需要弄清楚：空间到底在什么意义上构成了世界的一部分。我们之前说过，世界本身就是“在世界之中存在”这个结构中的一个组成部分。

  • “尤其须得指出的是：周围世界的周围性、在周围世界中照面的存在者本身的空间性如何通过世界之为世界而获得根基，而不是反过来，仿佛世界倒现成存在在空间中。”

    • 尤其需要强调的是：我们周围环境的“周遭感”，以及我们在这个环境中遇到的事物的空间安排，它们的根源在于世界本身的存在方式。绝不是反过来，好像世界是先存在于一个现成的物理空间里的。

  • “探索此在的空间性与世界的空间规定，这项工作要从分析世内在空间中上到手头的东西出发。考察分三个阶段进行：1．世内上到手头的东西的空间性〔第二十二节〕，2在世界之中存在的空间性〔第二十三节〕，3．此在的空间性，空间〔第二十四节〕。”

    • 我们要研究此在的空间性和世界的空间规定，这项工作的起点是分析那些在世界中、在空间里，我们直接使用和打交道的东西（即“上到手头”的东西）。整个研究将分三步走：第一步，分析这些日常用具的空间性；第二步，分析“在世界之中存在”这一整体结构的空间性；第三步，最终分析此在本身的空间性，以及空间本身。

3. 论证逻辑梳理

  1. 前提确立：作者首先重申了核心概念“在之中”，并将其与需要被区分的“在之内”概念对立起来。通过对“在之内”（物理包容关系）的否定性界定，为正面阐述“在之中”的空间性扫清了道路。
  2. 核心论点与澄清：明确提出此在并非以“在之内”的方式存在于空间，但这不等于否认此在有空间性。这是一个关键的澄清，将讨论从“有无空间性”转向了“有何种空间性”。
  3. 问题域的拓展与深化：将问题从“此在的空间性”延伸到“世界的空间性”，并指出两者存在存在论上的关联。这引出了核心问题：空间如何作为世界的构成要素？
  4. 论证方向与原则重申：强调了论证的根本方向——世界的空间性（周围性）是由世界本身的存在方式奠定的，坚决反对将世界视为存在于一个预先给定的物理空间中的传统观点。这是海德格尔存在论空间观的核心主张。
  5. 方法论规划：最后，为整个论证规划了清晰的研究路径：从最切近、最易理解的“用具的空间性”出发，逐步深入到“在世存在的空间性”，最终抵达“此在的空间性”这一源头。这体现了一个由表及里、从具体到抽象的现象学分析方法。

4. 整体概括

这段文字的核心目的在于，划清此在与世界原初的“在之中”关系，和物体间物理的“在之内”关系的界限。海德格尔强调，人（此在）并非像水在杯子里那样存在于一个现成的物理空间中；相反，空间性是人参与世界、与世界打交道的一种基本方式。我们周遭环境的空间布局和感觉（周围性），其根源在于我们生存于其中的那个意义世界本身，而不是世界被放进一个预先存在的物理框架里。为了阐明这一点，他规划了一个研究步骤：从分析日常用具的空间性入手，逐步揭示“在世界之中存在”的整体空间结构，最终溯源到此在本身如何开显出空间。

5. 争议与说明

本段文字主要是纲领性和界定性的，旨在划清概念界限并提出研究计划，因此其解读相对一致，争议不大。主要的争议点和后续深入的讨论会集中在海德格尔所规划的这三个步骤的具体展开上，尤其是： - 他如何具体论证“周围性”是由世界的存在方式奠定的，而不是相反。 - 他对“去远”和“定向”等具体空间性现象的分析是否充分，以及这些分析在多大程度上成功颠覆了传统的物理空间观。 本段本身为这些后续讨论设定了框架和方向。
