📜 原文片段 (030/012)
海德格尔 原文
在原则性论争的园地里，这种论争不可仅仅拘泥于可以从文本上把握的论题，它还必须以提出问题的实质倾向来判定方向，哪怕这种倾向本身并不超出通俗把握事物的方式。凭借res cogitans与res extensa，笛卡尔不仅想要提出“我与世界”的问题，而且他还要求彻底解决这个问题；在他的《沉思录》〔尤其参考I与Ⅳ〕中这一点十分清楚。他依循传统制订存在论的基本方向而完全不加积极的批判，这就使他不可能剖明此在的源始的存在论问题，使他不得不蒙蔽了看待世界现象的眼光，使他把“世界”的存在论硬塞到某种确定的世内存在者的存在论之中。前文的讨论应已指明了这些情形。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • res cogitans与res extensa：笛卡尔哲学中的核心概念，前者指“思维之物”（心灵、意识），后者指“广延之物”（物质、身体）。在海德格尔看来，这一区分预设了主体与世界的割裂，将“我”视为思维主体，将“世界”视为外在于我的客体。
  • 此在：海德格尔用来指代“人”的存在方式，强调人并非现成的实体，而是通过“在世存在”动态地展开其可能性、理解自身与世界的关系。
  • 存在论：探究“存在”本身意义（而非具体存在者）的哲学领域。海德格尔认为传统存在论（如笛卡尔）误将“存在”等同于某种特定存在者的属性。
  • 世内存在者：在世界之内被遭遇的具体事物（如桌椅、工具），它们的存在方式取决于它们如何向“此在”显现。
  • 世界现象：并非指物理宇宙的总和，而是此在生存于其中、与之打交道的意义整体，是此在理解自身和万物的背景。

2. 逐句转译

  • “在原则性论争的园地里，这种论争不可仅仅拘泥于可以从文本上把握的论题，它还必须以提出问题的实质倾向来判定方向，哪怕这种倾向本身并不超出通俗把握事物的方式。”
    → 讨论根本哲学问题时，不能只看字面意思，更要看提问背后的真实意图，即便这种意图本身可能很粗浅。

  • “凭借res cogitans与res extensa，笛卡尔不仅想要提出‘我与世界’的问题，而且他还要求彻底解决这个问题；在他的《沉思录》〔尤其参考I与Ⅳ〕中这一点十分清楚。”
    → 笛卡尔通过“思维之物”与“广延之物”的区分，不仅要问“我如何认识世界”，还自信能彻底解答它，这在《沉思录》中有明确体现。

  • “他依循传统制订存在论的基本方向而完全不加积极的批判，这就使他不可能剖明此在的源始的存在论问题，使他不得不蒙蔽了看待世界现象的眼光，使他把‘世界’的存在论硬塞到某种确定的世内存在者的存在论之中。”
    → 笛卡尔不加批判地沿袭传统哲学框架，导致他无法触及“此在”最本真的存在问题，也遮蔽了“世界”的真正现象，最终错把“世界”本身归结为某种具体事物（如物质实体）的存在方式。

  • “前文的讨论应已指明了这些情形。”
    → 前面章节已经揭示了这些问题。

3. 论证逻辑梳理

  1. 前提：哲学论争应关注提问的深层意图，而非仅停留于字面。
  2. 案例分析：笛卡尔以“思维/广延”二元论处理“我与世界”的关系，并试图一劳永逸地解决该问题。
  3. 批判推进： - 笛卡尔因未批判传统存在论框架，无法提出“此在”的源始存在问题。 - 这一盲点导致他：
    • 遮蔽了“世界”作为意义整体的现象；
    • 将“世界”错误地还原为“世内存在者”（如物质实体）的存在方式。
  4. 结论：笛卡尔的存在论路径从根本上误解了“世界”与此在的关系。

4. 整体概括

这段话批判笛卡尔哲学在处理“人与世界”关系时的根本缺陷。海德格尔指出，笛卡尔虽试图用“思维之物”与“广延之物”厘清“我”与“世界”的关系，但因盲目继承传统哲学框架，未能意识到“世界”并非外在于人的客体集合，而是人（此在）生存于其中、与之互动的意义场域。结果，笛卡尔把“世界”错误地等同于某种具体事物（如物质）的存在方式，既忽略了此在的生存动态，也遮蔽了“世界”作为现象的本质。

5. 争议与说明

  • 主流解读：学界普遍认同海德格尔对笛卡尔主体形而上学的批判，认为其揭示了传统哲学将“世界”客体化的谬误。
  • 可能的争议点：有学者质疑海德格尔是否过于简化笛卡尔的意图，忽略了笛卡尔在认识论上的突破性；亦有分析哲学家认为海德格尔的“世界现象”过于模糊，缺乏清晰界定。但总体而言，本段解读在现象学与存在主义传统中较为一致。
