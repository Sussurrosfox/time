📖 《存在与时间》研读 逐段解析

📜 原文片段 (052/016)
海德格尔 原文
畏在此在中公开出向最本己的能在的存在，也就是说，公开出为了选择与掌握自己本身的自由而需的自由的存在。畏把此在带到它的“为…”的自由存在〔propensio in…〕之前，带到它的存在的本真状态之前，而这种本真状态乃是此在总已经是的可能性。但这个存在同时就是在世的此在已被交付于其中的东西。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 畏：海德格尔哲学中的核心概念，指的是一种基本的、非对象性的情绪体验。它不是对具体事物的害怕（恐惧），而是对“世界本身”或“在世之在”的整体性不安。这种情绪揭示了此在的“被抛”状态和面对自身可能性时的自由。
  • 此在：指人的存在方式，其本质是“去存在”，即不断筹划、实现自身的可能性。此在不是现成的实体，而是通过它的生存活动展开的。
  • 最本己的能在：此在最本真、最属于自身的潜在存在方式。它不是外在赋予的，而是此在必须自己承担和实现的可能性。
  • 本真状态：此在清醒地把握并承担自身的存在，直面自身的自由与有限性，不再沉溺于日常的“常人”状态。
  • 在世：此在的基本存在结构，意味着此在从来不是孤立的主体，而是始终已经处于与世界、与他人共在的境域中。
  • 被交付：此在的一种基本处境，指此在总是已经被抛入一个既定的世界（具有特定的历史、文化、社会背景），并不得不从这个背景出发去存在。

2. 逐句转译

  • “畏在此在中公开出向最本己的能在的存在，也就是说，公开出为了选择与掌握自己本身的自由而需的自由的存在。” 畏这种情绪，在此在身上，把一种最根本的可能性给揭示出来了：此在总是朝向那个只属于它自己的、最本真的可能性的存在。换句话说，畏揭示了此在需要一种自由，这种自由是为了让此在能够去选择和掌握它自己。

  • “畏把此在带到它的‘为…’的自由存在〔propensio in…〕之前，带到它的存在的本真状态之前，而这种本真状态乃是此在总已经是的可能性。” 畏，就像一位严厉的向导，把此在带到了它自身那种“为了（某种可能性）而存在”的自由面前，带到了它本真存在的门槛前。需要强调的是，这种本真状态并不是什么遥远的东西，它其实是此在一向就已经是、就已经拥有的可能性。

  • “但这个存在同时就是在世的此在已被交付于其中的东西。” 然而，这个被畏所揭示的、需要此在去自由承担的本真存在，同时又是此在（作为一个在世的存在者）已经被抛入、不得不接受的既定事实和处境。

3. 论证逻辑梳理

  1. 前提：存在一种叫做“畏”的基本情绪。
  2. 第一步推进：畏具有一种揭示功能。它不像恐惧那样指向具体对象，而是让此在的“最本己的能在”（即最属于自己的未来可能性）整体性地呈现出来。这种可能性关联于此在做出选择的“自由”。
  3. 第二步推进：畏不仅揭示可能性，还将此在“带向”这种可能性。它让此在直面其生存的“自由”本质，以及由这种自由所定义的“本真状态”。海德格尔强调，这种本真状态不是外来的，而是此在固有的、一直潜藏的可能性。
  4. 结论/辩证综合：然而，这个被揭示的自由和本真状态，并非悬在半空。它恰恰就是此在“在世”并且“已被交付”于其中的那个存在本身。自由与命运是一体两面：此在的自由，正是在它所被抛入的那个具体、有限的世界中得以展开和实现的。

4. 整体概括

这段话的核心意思是，海德格尔通过分析“畏”这种情绪，揭示了人的存在（此在）的一个根本悖论：畏让我们突然直面自身最本真的自由——我们必须自己选择、自己承担自己的人生。然而，这种看似抽象的自由，恰恰就实现在我们被“抛入”的、既定的、充满限制的具体生活世界之中。所以，真正的自由不是为所欲为，而是清醒地认识到自己总已经在某个命运般的处境中，并勇敢地在这个处境中去成为自己。

5. 争议与说明

本段解读相对一致。核心争议点通常不在这段话本身，而在于对“畏”的后续理解，例如：畏揭示本真状态后，此在是否必然或如何能进入本真生存？这是一种一次性的顿悟还是持续的努力？但这些是更宏观的议题，对本段的具体论述影响不大。
