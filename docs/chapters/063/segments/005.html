📖 《存在与时间》研读 逐段解析
首页 / 第 063 章 / 片段 005
📜 原文片段 (063/005)
海德格尔 原文
这种生物学生理学的死亡研究是以某种存在论问题的提法为根据的。仍然要间的是：死亡的存在论本质如何从生命的存在论本质得到规定。存在者层次上的死亡探讨在某种方式中总已经对此有所取舍了。对生命和死亡的或多或少澄清了的先行概念在这类探讨中发挥着作用。须得借助此在的存在论把这些先行概念标画出来。此在的存在论列于生命的存在论之先；而在此在存在论之内，死亡的生存论分析则又列于此在基本建构的特征标画之后。我们曾把有生命的东西的结束标为完结。此在也“有”其同任何有生命的东西一样的生理上的死亡；虽然这种死亡不是在存在者层次上与其源始存在方式相绝缘的，倒是由这种存在方式参与规定的；此在也能够结束而不是本真地死，但作为此在，它也不是简简单单地就完结了。只要是这样，我们就把这种中间现象标识为亨熬〔Ableben〕。而不或死亡则作为此在借以向其死亡存在的存在方式的名称。因此就得说：此在从不完结。但此在只有在死的时候，才能够亡故。如果死亡的生存论阐释的基本方向已经得到保障，那么医学生物学上对亡故的研究会获得一些在存在论上也颇有意义的成果。也许，即使就医学而论，疾病与死亡也必须从根本上被理解为生存论现象？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 存在论：研究“存在”本身的结构与方式，即事物“是其所是”的根本方式。在本段中，指的是从哲学上探究生命和死亡的本质，而非仅从生物学或经验层面描述。
  • 存在者层次：指从实际、具体、可观察的现象层面进行研究，例如生物学、医学对死亡的生理描述。
  • 此在：海德格尔哲学的核心概念，指“人”这种特殊的存在者，其本质在于“去存在”，即总是处在理解自身、筹划可能性的动态过程中。
  • 生存论：特指从此在的存在方式出发进行分析的视角，关注此在如何“生存”，如何面对自己的可能性与极限。
  • 完结：指生物学意义上的生命终结，是所有生命体共有的生理过程。
  • 亡故：此在结束生命的一种非本真方式，即仅仅是生理上的死亡，而未在生存意义上本真地面对死亡。
  • 死亡：在此段中特指此在“向死亡存在”的本真方式，即此在在世的一种生存论可能性。

2. 逐句转译

  • “这种生物学生理学的死亡研究是以某种存在论问题的提法为根据的。”

  • 生物学和生理学对死亡的研究，其实背后已经预设了某种哲学上对“死亡是什么”的理解。

  • “仍然要间的是：死亡的存在论本质如何从生命的存在论本质得到规定。”

  • 但关键问题是：如何从“生命”的哲学本质出发，去理解“死亡”的哲学本质。

  • “存在者层次上的死亡探讨在某种方式中总已经对此有所取舍了。”

  • 所有从经验层面研究死亡的方式（如医学），其实都已经暗中做了选择，接受了某些关于死亡的前提假设。

  • “对生命和死亡的或多或少澄清了的先行概念在这类探讨中发挥着作用。”

  • 在这些研究中，研究者或多或少已经带着一些对生命和死亡的模糊或不清晰的观念在进行探讨。

  • “须得借助此在的存在论把这些先行概念标画出来。”

  • 我们需要通过对此在的哲学分析，把这些隐藏的观念明确揭示出来。

  • “此在的存在论列于生命的存在论之先；而在此在存在论之内，死亡的生存论分析则又列于此在基本建构的特征标画之后。”

  • 对“此在”的哲学分析要优先于对“生命”的哲学分析；而在分析此在的时候，又要先弄清楚此在的基本结构，之后才能分析此在如何面对死亡。

  • “我们曾把有生命的东西的结束标为完结。此在也‘有’其同任何有生命的东西一样的生理上的死亡；虽然这种死亡不是在存在者层次上与其源始存在方式相绝缘的，倒是由这种存在方式参与规定的；此在也能够结束而不是本真地死，但作为此在，它也不是简简单单地就完结了。”

  • 我们把一般生物的死亡称为“完结”。人（此在）当然也有生理上的死亡，和动物一样。但人的生理死亡并不是孤立发生的，它是由人的独特存在方式（即理解自身、筹划未来）所参与塑造的。人可以只是生理上结束生命，而没有真正在生存意义上面对死亡（即“非本真”地死）。但即便如此，人的死亡也并不仅仅是像动物那样“完结”了事。

  • “只要是这样，我们就把这种中间现象标识为亡故。而死亡则作为此在借以向其死亡存在的存在方式的名称。”

  • 所以，我们把这种仅仅是生理结束、但未本真面对死亡的现象称为“亡故”。而“死亡”这个词，则专指此在以一种本真的方式去面对并走向自己终点的生存状态。

  • “因此就得说：此在从不完结。但此在只有在死的时候，才能够亡故。”

  • 因此可以说：此在从来不会仅仅“完结”。此在只有在经历本真的“死亡”时，才会同时发生生理上的“亡故”。

  • “如果死亡的生存论阐释的基本方向已经得到保障，那么医学生物学上对亡故的研究会获得一些在存在论上也颇有意义的成果。”

  • 如果我们先把“死亡”的生存论分析搞清楚，那么医学和生物学对“亡故”的研究，也能得到一些在哲学层面很有价值的发现。

  • “也许，即使就医学而论，疾病与死亡也必须从根本上被理解为生存论现象？”

  • 或许，即便从医学角度看，疾病和死亡也应该从根本上被理解为此在的生存现象？

3. 论证逻辑梳理

  • 前提：生物学、医学对死亡的研究并非中立，它们背后已经预设了某种存在论的理解。
  • 核心问题：死亡的存在论本质必须从生命的存在论本质出发来规定。
  • 推进步骤： 1. 指出所有经验层面的死亡研究都依赖于某种先行概念。 2. 强调必须通过此在的存在论来澄清这些先行概念。 3. 确立此在的存在论优先于生命的存在论，而死亡的生存论分析又建立在此在的基本结构分析之上。 4. 区分“完结”（生物性结束）、“亡故”（此在的非本真生理死亡）与“死亡”（此在的本真向死存在）。 5. 论证此在的死亡不是简单的“完结”，而是与其生存方式息息相关。
  • 结论：只有先完成死亡的生存论阐释，才能为医学生物学研究提供存在论基础；甚至医学中的疾病与死亡也应被重新理解为生存论现象。

4. 整体概括

这段文字的核心在于：海德格尔批评生物学和医学对死亡的研究，认为它们已经在不自觉地依赖于某种哲学前提。他主张，必须从“此在”（人的独特存在方式）出发，先哲学地澄清死亡的本质。他区分了三种不同的“结束”：所有生命体共有的“完结”、此在非本真生理死亡的“亡故”、以及此在本真面对自身终结的“死亡”。他强调，人的死亡不是简单的生理事件，而是由人的生存方式参与塑造的。因此，只有先做好死亡的哲学分析，医学研究才能获得更深层的意义；甚至疾病和死亡本身，都应被视为人的生存现象，而不仅仅是生理过程。

5. 争议与说明

本段解读相对一致。可能的细微争议在于： - “亡故”与“死亡”的严格区分是否必要？有学者认为这种二分略显生硬，在实际经验中难以截然分开。 - 海德格尔对生物学研究的批评是否过于严厉？一些科学哲学学者认为，生物学自有其方法论独立性，不必完全依赖存在论基础。 但总体而言，这段是海德格尔构建其死亡哲学的基础环节，核心意图清晰。
