📖 《存在与时间》研读 逐段解析
首页 / 第 010 章 / 片段 008
📜 原文片段 (010/008)
海德格尔 原文
在开头处〔第一节〕已经显示，存在的意义问题不仅尚未了结，不仅没有充分提出，而且不论人们对“形而上学”有多少兴趣，它仍被付诸遗忘了。希腊存在论通过形形色色的分流与扭曲直到今天还规定着哲学的概念方式，而这一存在论历史证明：此在从“世界”方面来领会自己以及一般存在，这样成长起来的存在论沉陷于其中的传统使存在论降低为不言而喻之事，降低为只不过有待重新加工的材料〔黑格尔就是这样〕。这种无根的希腊存在论在中世纪变成了固定教材。这份教材的系统化并非只是把承袭下来的诸构件凑合成一座建筑了事。在教条式地承受希腊对存在的基本看法的限度内，在这个系统的构造中还是做出了不少初拙的工作。希腊存在论的本质部分盖上了经院哲学的印记，通过苏阿列兹的形而上学论辩，过渡到近代的“形而上学”和先验哲学，并且它还规定着黑格尔《逻辑学》的基调和目标。在这个历史过程中，某些别具一格的存在领域曾映入眼帘并在此后主导着问题的提法〔笛卡尔的我思、主体、我、精神、人格〕；但同时，与始终耽搁了存在问题的情况相适应，人们从没有就它们的存在及其存在结构发问。人们反而把传统存在论的范畴内涵加以形式化，作为纯粹消极的限制加到这种存在者之上，或者为了在存在论上对主体的实体性做出解释并乞灵于辩证法。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 存在：在海德格尔哲学中，“存在”并非指某个具体事物的存在状态，而是指使一切存在者得以成为存在者的那个最根本的、动态的显现过程。它是一切“是什么”背后的“如何是”。
  • 存在论：探究“存在”本身的意义、结构和方式的哲学领域。不是研究某个具体事物（如物理、生物），而是研究“存在”何以可能。
  • 此在：特指“人”这种存在者。此在的特殊性在于它能追问、理解自己的存在，并以某种方式“是”它的存在（即它的存在是通过它的理解和生存活动展开的）。
  • 传统/希腊存在论：指自柏拉图、亚里士多德以来的西方哲学传统，它以一种特定的方式（如将存在理解为“实体”、“属性”）来探讨存在，但这种探讨在开端处就遗忘了“存在”问题本身。
  • 沉陷于传统：指后世哲学不加批判地继承了希腊存在论的基本框架和概念，将其视为理所当然的前提，从而丧失了源头性的追问能力。
  • 形式化：指将传统存在论的范畴（如实体、属性）抽掉具体内容，变成空洞的逻辑形式，然后套用到其他领域（如人的主体性）上。

2. 逐句转译

  • 第一句：在本书开头就说了，关于“存在”的意义这个问题，不仅还没得到最终答案，甚至连问题本身都没被正确地、充分地提出来过。尽管人们总在谈论“形而上学”，但“存在”这个最根本的问题实际上一直被大家忽略了。
  • 第二句：从希腊哲学开始的各种存在论，虽然经历了很多变化和走样，但直到今天还在深刻地影响着哲学思考的基本模式。这段历史告诉我们：人（此在）习惯于从他所处的“世界”出发来理解自己和一切存在者。这种理解方式代代相传，结果让存在论本身变成了一套看似不证自明、只需要后人修修补补的老生常谈（黑格尔就是个例子）。
  • 第三、四句：这种在源头上就没扎下根来的希腊存在论，到了中世纪变成了固定的教科书内容。中世纪的学者们并不是简单地把前人的理论零件拼凑起来，在遵从希腊基本世界观的前提下，他们也做了一些虽然粗糙但系统化的建构工作。
  • 第五句：希腊存在论的核心部分，被打上了经院哲学的烙印，然后通过苏阿列兹等人的著作，传递到了近代的“形而上学”和先验哲学那里，并且它还决定了黑格尔《逻辑学》的基本思路和目标。
  • 第六句：在这个漫长的历史中，也曾出现过一些独特的存在领域，引起了人们的注意，并主导了后来的提问方式（比如笛卡尔的“我思”、主体、自我、精神、人格等概念）。
  • 第七句：但是，与“存在”问题一直被耽搁的情况相对应，人们从未去追问这些“主体”之类的东西，它们本身的存在方式和结构究竟是怎样的。
  • 第八句：相反，人们只是把传统存在论里的那些概念（比如实体、属性）进行形式化处理，抽空具体内容，然后要么把它们当作一些消极的限制条件套用到这些新的存在者（如主体）上，要么就试图用辩证法的技巧，来为主体的实体性做一个存在论上的辩护和解释。

3. 论证逻辑梳理

  1. 前提与问题提出：海德格尔首先重申了他的核心观察：“存在”意义问题不仅未被解决，甚至未被充分提出，处于被遗忘状态。
  2. 历史诊断（原因分析）：他紧接着分析了造成这一状况的历史根源。指出希腊存在论通过其强大的传统，塑造了后世哲学的基本概念方式。
    • 具体机制是：此在（人）习惯于从“世界”出发理解存在，这导致原初的存在论逐渐沉陷于传统，变成了不加反思的“材料”。
  3. 历史脉络的勾勒：为了证明上述诊断，他勾勒了一条历史线索：希腊存在论 -> 中世纪经院哲学（系统化但教条） -> 近代形而上学与先验哲学（经由苏阿列兹等人） -> 黑格尔。这表明遗忘存在的问题是一个源远流长的、系统性的传统。
  4. 关键转折与批判：在近代，虽然出现了新的关注点（如笛卡尔的“我思”、主体），但这并未扭转局面，反而加剧了问题。
    • 核心批判点在于：人们关注了“主体”等新领域，却没有追问这些主体自身的“存在”。
    • 错误做法：人们只是形式化地套用旧范畴，或求助于辩证法，来处理新问题。这被海德格尔视为一种逃避真正存在论问题的不彻底方案。

逻辑链条：存在问题被遗忘 -> 根源在于希腊存在论传统的力量 -> 该传统在历史中不断传递和变形 -> 即便近代哲学转向主体，也因未能追问主体之存在而沿用旧方法 -> 结果：存在问题被持续耽搁。

4. 整体概括

这段话是海德格尔对西方哲学史的一个“病理诊断”。他认为，哲学的核心任务——追问“存在”的意义——从古希腊开始就被带错了方向。后世哲学家们不加批判地继承了古希腊对“存在”的特定理解，把它当成不言自明的真理，使得真正的存在问题被深深埋藏。即使哲学史上出现了重要的转折（比如笛卡尔转向了“我思”和主体），哲学家们也只是用旧瓶装新酒，把传统的那套存在论范畴修修补补，套用在新的研究对象上，而从未去追问“主体本身是如何存在的？”、“‘我思’的存在方式是什么？”这些更根本的问题。因此，整个西方形而上学史，在海德格尔看来，就是一部“存在”被遗忘的历史。

5. 争议与说明

本段解读相对一致，是海德格尔对哲学史标准叙事的核心批判，学界普遍认同这是他的基本立场。可能的细微争议点在于：

  1. 对希腊哲学的解读是否公允：有学者认为，海德格尔为了构建他的“存在遗忘史”叙事，对柏拉图、亚里士多德的思想进行了过于工具化的、有选择性的解读，可能简化或曲解了希腊哲学的复杂性。他笔下的“希腊存在论”更像是一个为他的理论服务的、理想化的批判靶子。
  2. 对近代哲学（尤其是笛卡尔和黑格尔）的评价：海德格尔认为他们对存在问题的处理是“形式化”和逃避性的。但一些哲学史家会辩护说，笛卡尔的“我思”恰恰开启了对主体性的深刻探索，而黑格尔的辩证法本身就是为了解决存在与思维的关系问题，并非简单的“乞灵”。海德格尔的批判是从他自己的“基础存在论”立场出发的，与其他哲学传统的自我理解存在张力。
