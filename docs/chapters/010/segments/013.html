📖 《存在与时间》研读 逐段解析

📜 原文片段 (010/013)
海德格尔 原文
在以时间状态的成问题之处为线索来完成结构工作的过程中，本书的第二部将试图解释图型说那一章并由此出发去解释康德的时间学说。同时还将显示：为什么康德终究无法窥时间问题之堂奥。有两重因素妨碍了他。一是他一般地耽搁了存在问题，与此相联，在他那里没有以此在为专题的存在论，用康德的口气说，就是没有先行对主体之主体性进行存在论分析。康德存在论教条地继承了笛卡尔的立场，虽然他在某些本质方面多少有所推进。另一重因素在于：尽管康德已经把时间现象划归到主体方面，但他对时间的分析仍然以流传下来的对时间的流俗领会为准，这使得康德终究不能把“先验的时间规定”这一现象就其自身的结构与功能清理出来。由于传统的这种双重作用，时间和“我思”之间的决定性的联系就仍然隐藏在一团晦暗之中，这种联系根本就没有形成为问题。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 时间状态：海德格尔哲学中的核心概念，指时间并非仅仅是客观的、均匀流逝的序列，而是此在（人的存在）理解和展开自身存在的基本视野或境域。
  • 图型说：康德哲学中的一个理论，指在《纯粹理性批判》中提出的“图型”（Schema），作为连接纯粹知性范畴和感性直观的中间媒介，本质上是时间的先验规定。
  • 此在：海德格尔哲学的核心术语，指人的存在方式，其本质在于“去存在”，并总是已经在世界之中，对自己的存在有所领会。
  • 存在论：哲学中对“存在”本身的研究，区别于对具体存在者的研究。海德格尔认为传统存在论遗忘了存在本身的问题。
  • 主体之主体性：传统哲学（如笛卡尔、康德）中，将人视为“主体”，即认知和行动的中心；主体性则指这种主体的本质结构。海德格尔批判这种主体概念遗忘了此在的存在方式。
  • 流俗的时间领会：指日常生活中将时间理解为一系列“现在”点的无限序列，如同一条河流，可计量、可分割，海德格尔认为这掩盖了时间的本源现象。
  • 先验的时间规定：康德哲学中，时间作为感性直观的纯形式，是先验的，即不依赖于经验，却又使经验可能；图型正是这种先验时间规定的体现。
  • “我思”：源自笛卡尔的“我思故我在”，康德将其发展为“先验统觉”，指意识统一的最高原则。海德格尔认为传统哲学未能深入探究“我思”与时间的本质关联。

2. 逐句转译

  • “在以时间状态的成问题之处为线索来完成结构工作的过程中，本书的第二部将试图解释图型说那一章并由此出发去解释康德的时间学说。” 这段话的意思是：在《存在与时间》的第二部中，海德格尔将以“时间状态”这一核心问题为线索，展开其哲学体系的构建工作。具体而言，他将先分析康德《纯粹理性批判》中关于“图型说”的章节，并以此为基础，重新审视康德的整个时间理论。

  • “同时还将显示：为什么康德终究无法窥时间问题之堂奥。有两重因素妨碍了他。” 同时，海德格尔也要揭示康德最终未能真正深入时间问题核心的原因。他认为有两个关键因素阻碍了康德。

  • “一是他一般地耽搁了存在问题，与此相联，在他那里没有以此在为专题的存在论，用康德的口气说，就是没有先行对主体之主体性进行存在论分析。” 第一个因素是：康德总体上忽视了对“存在”本身问题的追问。与此相关，他的哲学体系中缺乏一种以此在（人的存在）为核心主题的存在论。用康德自己的话来说，就是他没有事先对“主体”（即人作为认知主体）的“主体性”（其存在方式）进行存在论层面的深入分析。

  • “康德存在论教条地继承了笛卡尔的立场，虽然他在某些本质方面多少有所推进。” 康德的存在论观点基本上是未经批判地继承了笛卡尔的哲学立场（即将“我思”作为确定性的基点），尽管康德在某些关键方面比笛卡尔有所进步。

  • “另一重因素在于：尽管康德已经把时间现象划归到主体方面，但他对时间的分析仍然以流传下来的对时间的流俗领会为准，这使得康德终究不能把‘先验的时间规定’这一现象就其自身的结构与功能清理出来。” 第二个因素是：虽然康德已经将时间视为属于主体（作为感性直观的形式），但他对时间的分析仍然依赖于日常流俗的时间观念（即将时间看作一系列“现在”点的序列）。这导致他未能真正揭示“先验的时间规定”（如图型）本身的结构和功能。

  • “由于传统的这种双重作用，时间和‘我思’之间的决定性的联系就仍然隐藏在一团晦暗之中，这种联系根本就没有形成为问题。” 由于上述双重传统的影响（即忽视存在论和流俗时间观），时间与“我思”（主体的核心活动）之间至关重要的本质联系，就一直被遮蔽在黑暗之中，从未成为一个真正被提出和探讨的问题。

3. 论证逻辑梳理

  1. 前提/目标：海德格尔声明《存在与时间》第二部的工作计划——以时间状态为线索，通过分析康德的图型说来审视其时间学说，并揭示其失败根源。
  2. 核心论点：康德未能深入时间问题的核心。
  3. 论证推进（双重障碍分析）：
    • 第一重障碍（存在论缺失）：康德忽略了“存在”问题本身，因而未能建立以此在为核心的存在论，也就未能对“主体之主体性”进行存在论分析。他教条地继承了笛卡尔的主体哲学框架。
    • 第二重障碍（时间观局限）：尽管康德将时间主体化，但其分析仍固于“流俗时间领会”，导致他无法厘清“先验时间规定”（如图型）的真正结构与功能。
  4. 结论：这两重传统束缚共同导致“时间”与“我思”的决定性关联被遮蔽，未能成为哲学课题。

4. 整体概括

这段话是海德格尔对其《存在与时间》第二部研究计划的纲领性陈述。他计划以自己提出的“时间状态”概念为武器，去重新解读康德哲学，特别是其连接概念与直观的“图型说”和时间理论。海德格尔的核心批判在于，他认为康德虽然做出了划时代的贡献（将时间归于主体），但由于两大致命局限——一是从根本上忽略了“存在”问题，因而未能深入分析“主体”本身的存在方式（此在）；二是其时间分析仍不自觉地被日常的、流俗的时间观念所束缚——最终未能揭示时间与主体核心（“我思”）之间深层的、建构性的本质联系，使得这一关键问题始终沉陷于晦暗之中。

5. 争议与说明

关于海德格尔对康德的这一解读，学界存在讨论：

  • 主流解读：认为海德格尔的批判切中了康德哲学的要害，即康德在“哥白尼革命”后，仍然受制于传统形而上学的主体概念和客观时间观，未能将时间性视为此在存在的根本境域。这种解读强调海德格尔是在挖掘康德哲学中未言明的预设与局限。

  • 其他解读方向/争议点：

    1. 诠释的正当性：有学者质疑海德格尔对康德“图型说”的解读是否过于“暴力”，是否将其 own 的存在论问题强加于康德的认识论框架，忽略了康德理论自身的完整性和目标（为自然科学奠基）。
    2. 对“流俗时间”批判的力度：有观点认为，海德格尔可能低估了康德先验时间观的革命性，康德的“先验时间”作为感性形式，本身已与日常经验时间有区别，并非完全流俗。海德格尔的批判或许过于绝对。
    3. “存在论”要求的合理性：从康德哲学的立场看，其任务本就是认识论而非海德格尔式的存在论。因此，批评康德“耽搁了存在问题”可能是一种来自不同哲学范式的“外部”批评。

总之，海德格尔对康德的解读是建构性的、为己所用的，旨在通过解构康德来铺陈自己的思想，其精确性和公允性是学界持续讨论的话题。
