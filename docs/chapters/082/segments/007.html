📜 原文片段 (082/007)
海德格尔 原文
在时间内状态那里，首先从存在者层次上发现的“时间”成为形成流俗的传统时间概念的基础。但时间内状态这种时间则发源于源始时间性的一种到时方式。这一源头告诉我们，现成事物“在其中”生灭的时间是一种真切的时间现象，而不似柏格森的时间解释——一种在存在论上全无规定的和远不充分的时间解释——要让我们相信的那样，仿佛那种时间是“具有质的时间”外在化为空间的结果。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 时间内状态：指我们在日常经验中直接观察到的“时间”，如事件发生的前后顺序、持续长短等。它是从“源始时间性”中衍生出来的一种具体表现方式。
  • 源始时间性：海德格尔哲学的核心概念，指此在（人）最根本的存在结构，它由“曾在-当前化-将来”三个维度动态统一构成，是时间最深层、最本真的形态。
  • 到时：指源始时间性以某种特定的方式实现或展现出来。不同的“到时方式”会产生不同形态的时间经验（如“时间内状态”）。
  • 现成事物：指那些已经存在、摆在我们面前的对象或事物（如一块石头、一张桌子），它们具有固定的属性，被视为独立于我们的、客观存在的东西。
  • 流俗的传统时间概念：指在日常生活中和传统哲学中被普遍接受的、将时间视为一条由无数“现在”点构成的、均匀流逝的直线的观念（类似于物理时间）。

2. 逐句转译

  • “在时间内状态那里，首先从存在者层次上发现的‘时间’成为形成流俗的传统时间概念的基础。”

  • 我们日常生活中最先接触和认识到的“时间”（比如钟表显示的时间、事件的先后顺序），是在“存在着层次”上被我们发现的。这种最直观的时间经验，构成了后来那种“流俗的”、将时间看作一条直线的传统时间观念的基础。

  • “但时间内状态这种时间则发源于源始时间性的一种到时方式。”

  • 但是，这种我们日常体验到的“时间内状态”，它的根源其实更深。它来自于我们人最根本的“源始时间性”以某种特定的方式（即“到时”）展现出来的结果。

  • “这一源头告诉我们，现成事物‘在其中’生灭的时间是一种真切的时间现象，而不似柏格森的时间解释——一种在存在论上全无规定的和远不充分的时间解释——要让我们相信的那样，仿佛那种时间是‘具有质的时间’外在化为空间的结果。”

  • 从“源始时间性”这个根源出发，我们就能明白：那些客观事物（“现成事物”）在其中产生和消亡的时间，本身就是一种真实、真切的时间现象。它并不像法国哲学家柏格森所解释的那样。海德格尔认为柏格森的解释在“存在论”（关于“存在”本身的学问）上是完全没有触及根本、非常不充分的。柏格森似乎想让我们相信，我们体验到的那种生动、有质感的“绵延”（“具有质的时间”），只是后来外在化、投射到空间里，才变成了我们通常理解的线性时间。海德格尔反对这种看法，他认为时间内状态本身就是从源始时间性中真切地“生发”出来的，并非某种更真实时间的“退化版”或“空间化产物”。

3. 论证逻辑梳理

  1. 前提/起点：存在着一个在日常生活（存在者层次）中被直接给予的、作为现象的“时间内状态”。
  2. 第一步分析与推进：指出这个“时间内状态”是“流俗的传统时间概念”（如物理时间）得以形成的基础。这是对时间现象来源的一种常见误解的澄清。
  3. 第二步分析与推进（核心论证）：转而揭示“时间内状态”的真正起源并非自身，而是根植于更深层的“源始时间性”及其“到时”。这确立了本真时间性对于派生时间性的优先地位。
  4. 第三步分析与推进（驳论与立论）：基于上述起源，论证“现成事物在其中生灭的时间”（即时间内状态）本身就是“真切的”时间现象。并以此为据，批判柏格森的时间理论，认为后者将时间内状态视为“具有质的时间”（绵延）外在化、空间化的结果，这在存在论上是无根基和不充分的。海德格尔在此划清了自己与柏格森的界限。
  5. 结论/主张：时间内状态并非某种更本真时间的堕落或衍生品，它本身是源始时间性真切的显现方式之一，具有现象上的正当性。流俗时间概念的问题不在于它是“空间化的”，而在于它遗忘了自己的这个源头。

4. 整体概括

这段话的核心在于为日常时间经验（“时间内状态”）正名并追溯其根源。海德格尔首先承认，我们平常感受到的那种前后相续的时间，确实是形成“时间是一条线”这种流俗观念的基础。但他紧接着指出，这种日常时间并非无源之水，它其实来源于人最根本的存在结构——“源始时间性”的某种具体展现方式。正因为有这个更深的根源，我们眼中那些客观事物生死变化所依托的时间，本身就是一种真实不虚的时间现象，而不必像柏格森那样，将其解释为某种更本真、更有质感的“绵延”在空间里被摊平、异化的结果。简而言之，海德格尔在为日常时间的真实性辩护的同时，将其锚定在了他哲学中最核心的“源始时间性”之上。

5. 争议与说明

本段解读相对一致。主要的学术讨论点通常集中在海德格尔对柏格森批评的准确性与公允性上。一些学者认为海德格尔可能简化或误解了柏格森“绵延”概念的复杂性，柏格森的“绵延”本身也是一种反对科学化、空间化时间的生命体验，与海德格尔的“源始时间性”有可对话的空间。但就本段主旨而言，即海德格尔旨在确立“时间内状态”源于“源始时间性”并拥有现象上的真切性，学界的理解是高度一致的。
