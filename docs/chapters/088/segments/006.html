💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学的核心概念，指人的存在方式，这种存在总是对自身存在有所领会，并通过与世界互动来展开自身。
  • 日常状态：此在最常见、最普通的存在方式，在这种状态中，此在沉浸于常规、重复的生活流程，往往失去了对自身存在本身的深刻觉察。
  • 共处：此在总是与他人共同存在于世界之中，其行为举止深受这种共同存在的影响。
  • 操劳：此在投身于、忙于周遭世界事务的生存活动，是与世界内的物和事打交道的基本方式。
  • 习常：日常生活中形成的、被习惯所支配的、近乎自动化的行为模式与生活轨道。
  • 单调：日常状态的一种特征，指生活呈现出重复、缺乏新意、令人麻木的性质。

2. 逐句转译

  • “日常状态意指此在依以‘进入白日生活’的‘如何’，无论是此在的一切行为举止的‘如何’抑或是由共处草描出来的那些行为举止的‘如何’。” 这句话是说，所谓“日常状态”，指的是此在（人）每天醒来后，投入到白天生活中所遵循的那个“方式方法”。这个“方式方法”既包括了此在个人所有行为举止的模式，也包括了在与他人共处时，被这种共同生活所塑造和规定出来的行为模式。

  • “这个‘如何’还包含有喜溺于习常这类情况，即使习常把此在迫向负累之事和‘非所期愿’之事也罢。” 这里进一步说明，这种日常生活的“方式方法”中，还包含着一种“沉溺于习惯”的特性。即便这些习惯常常把此在推向那些让人感到负担、劳累，以及自己内心并不真正期望去做的事情，此在依然会习惯性地、不假思索地去做。

  • “日常操劳始终期备的是明日之事，而这明日之事则是‘永久的昨日之事’。” 这句话描述的是，在日常状态下，此在的忙碌和操心总是着眼于“明天要做的事”。但讽刺的是，这个所谓的“明天的事”，本质上不过是“永远重复着的昨天的事”。也就是说，生活看似在向前（明日）推进，实际上却是在重复过去（昨日）的模式。

  • “日常状态的单调把...” 这句话没有写完，但从语境可以推断，它意在引出日常状态的“单调”特性所带来的某种后果，比如它如何笼罩、限制或塑造着此在的存在。

3. 论证逻辑梳理

  1. 前提/定义：首先对“日常状态”进行定义，指出其核心是此在进入日常生活的那个“如何”（方式方法）。
  2. 特征展开：接着具体描述这个“如何”的两个关键特征：
    • 它渗透于此在个体和群体的所有行为中。
    • 它包含着对“习常”（习惯）的沉溺，哪怕这些习惯是令人不快的。
  3. 深化分析：然后深入到日常状态的时间性结构，揭示了其内在的悖论：看似面向未来（“期备明日之事”），实则只是对过去的无尽重复（“永久的昨日之事”）。
  4. 引出特性：最后，基于上述分析，点明“单调”是日常状态的一个根本属性，并为下文（由于原文未完）探讨这种单调性的影响做铺垫。

4. 整体概括

这段话的核心是在描绘海德格尔眼中“人”的日常生存样态。我们每天醒来，都按照一套固定的、习以为常的模式投入到生活和工作中，这套模式既来自我们自己，也来自我们所处的社会群体。我们甚至沉迷于这种习惯，哪怕它带来的是负担和无奈。我们的忙碌看似总在为“明天”做准备，但所谓的“明天”不过是“昨天”的翻版，生活陷入一种机械的、无新意的循环。正是这种日复一日的重复，构成了日常状态那种挥之不去的“单调”感。海德格尔在此是在揭示一种非本真存在的初步面貌：我们在日常生活中，往往活得像一个自动化的、失去了自我深刻觉察的“常人”。

5. 争议与说明

本段解读相对一致。它清晰地勾勒了“日常状态”作为“非本真状态”的基本特征，是理解海德格尔对常人沉沦状态分析的起点，学界对此段的解读分歧不大。
