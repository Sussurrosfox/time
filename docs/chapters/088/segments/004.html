📜 原文片段 (088/004)
海德格尔 原文
若从存在论上予以界说，这一术语究竟意味的是什么则还含混不明。而且在探索之后也没有任何途径使日常状态的生存论及存在论意义哪怕只作为问题提出来。现在此在的存在意义作为时间性亮相了。现在谈到“日常状态”这个名称的生存论时间性含义还有什么可怀疑的吗？虽说如此，我们离这一现象的存在论概念还远远的呢。甚至前此进行的时间性阐释是否足以界说日常状态的生存论意义也还是可疑问的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 存在论：在海德格尔哲学中，指研究“存在”本身的方式和结构的学问。它不关心具体存在者（如物体、人）的属性，而是追问“存在”何以成为可能。
  • 生存论：特指此在（人）的存在方式的分析。此在不是现成的物体，而是通过它的生存活动（如理解、操心、时间性）展开其存在。
  • 日常状态：此在沉沦于常人的公共解释和平均化理解中的非本真生存方式。它是此在最常见、最切近的生存样态。
  • 时间性：此在存在的整体意义，是此在之所以能够展开其生存（如操心、理解、沉沦）的根本境域。它不是普通的线性时间，而是由将来、曾在、当前统一构成的出位统一体。
  • 此在：指人的存在，其本质在于它的“去存在”，即它总是通过它的生存活动和理解来构成自身。

2. 逐句转译

  • “若从存在论上予以界说，这一术语究竟意味的是什么则还含混不明。”
    这句话是说：如果我们想从存在论（研究存在本身的学问）的角度来给“日常状态”下一个明确的定义，那么它到底指的是什么，其实还是很模糊的。

  • “而且在探索之后也没有任何途径使日常状态的生存论及存在论意义哪怕只作为问题提出来。”
    进一步说，即便我们做了很多探索，到目前为止，我们甚至还没有找到一条路径，能把“日常状态”在生存论和存在论层面的意义作为一个明确的问题提出来讨论。

  • “现在此在的存在意义作为时间性亮相了。”
    但现在，我们明白了：此在（人）的存在的根本意义，其实就是时间性。

  • “现在谈到‘日常状态’这个名称的生存论时间性含义还有什么可怀疑的吗？”
    既然时间性已经揭示为此在的根本意义，那么，当我们说“日常状态”这个词的时候，难道还会怀疑它在生存论层面是和时间性紧密相关的吗？（这其实是一个反问，答案显然是“不该怀疑”。）

  • “虽说如此，我们离这一现象的存在论概念还远远的呢。”
    尽管如此，我们现在对于“日常状态”这个现象，要形成一个真正严格的存在论概念，还差得很远。

  • “甚至前此进行的时间性阐释是否足以界说日常状态的生存论意义也还是可疑问的。”
    甚至，我们之前所做的关于时间性的阐释，是否真的足够用来界定“日常状态”的生存论意义，这一点也仍然是值得怀疑和需要进一步审视的。

3. 论证逻辑梳理

  1. 前提/起点：对“日常状态”的存在论界定是模糊的，甚至其核心意义都尚未被真正当作一个问题来提出。
  2. 关键转折/新基础：此前的研究已经揭示，此在的整体存在意义是时间性。这为解决上述问题提供了一个全新的、根本性的视角。
  3. 初步推论：基于此，从逻辑上似乎可以顺理成章地将“日常状态”与时间性联系起来（反问句暗示了这种关联的必然性）。
  4. 立即的保留与深化：然而，作者立刻刹车，指出即便有了时间性这个基础，我们距离一个清晰的“日常状态”的存在论概念仍然非常遥远。
  5. 最终的质疑与开放：论证推进到最谨慎的一步：作者甚至对我们已拥有的时间性阐释工具本身是否足够用来理解日常状态，提出了根本性质疑。这表明探索远未完成，任务依然艰巨。

4. 整体概括

这段话的核心意思是：虽然我们已经发现了此在存在的根本意义在于时间性，这为我们理解“日常状态”（此在沉沦于世俗生活的常态）提供了一个关键的哲学基础，但我们绝不能因此就认为问题已经解决。实际上，我们对“日常状态”的存在论理解仍然非常初步和模糊，甚至我们赖以进行分析的“时间性”这个概念本身，是否足以透彻地解释日常状态的深层意义，也是一个需要继续追问和检验的开放性问题。海德格尔在此表现出一位严谨哲学家特有的审慎：在宣布一个重大发现（时间性）后，立即指出其应用的具体困难和限度。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“现在谈到……还有什么可怀疑的吗？”这句反问句语气的理解。一种解读（如本文所采）认为这是海德格尔在指出，从时间性出发理解日常状态在方向上是必然的；另一种解读可能更强调这句话的讽刺意味，意在表明虽然逻辑上似乎无可怀疑，但实际上正因为这种“理所当然”，我们才更可能忽略其真正的复杂性。但这两种解读在“必须从时间性理解日常状态”这一根本点上并无分歧。
