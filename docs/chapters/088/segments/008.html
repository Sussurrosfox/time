📖 《存在与时间》研读 逐段解析

📜 原文片段 (088/008)
海德格尔 原文
日常状态的这些多重性质却绝非是把日常状态标识为一些单纯的“方面”，仿佛当“人们”“看”人的所行所为之际此在便提供某种方面似的。日常状态是一种去存在的方式，公众的公开状态当然属于这种方式。作为此在固有的生存活动的方式，日常状态却也或多或少地为各个“个别的”此在所熟悉，这熟悉靠的是懒洋洋无情无绪的现身情态。此在可能木木然“受着”日常状态，可能沉浸到日常状态的木木然之中去；此在可能为涣散在诸种经营的境况找寻新的消遣，以这种方式闪避日常状态。而生存甚至还可能在当下即是〔当然往往也不比“当下即是”更持久〕掌握起日常，虽然生存从不能抹灭日常。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 日常状态（Alltäglichkeit）：在海德格尔哲学中，日常状态指此在（人的存在）在日常生活中的基本存在方式。它并非指平凡琐碎的生活细节，而是此在沉沦于世界、被“常人”（das Man）支配的非本真生存状态。在本段中，日常状态被强调为此在“固有的生存活动方式”，即一种既熟悉又往往被被动承受的存在模式。

  • 此在（Dasein）：海德格尔用此在指代“人”这种存在者，其本质在于“去存在”（Zu-sein），即不断通过选择和行动来展开自身的存在。此在的核心特征是它能追问并关心自己的存在。

  • 生存（Existenz）：此在特有的存在方式，即它总是面向可能性、通过筹划和理解来塑造自身。在本段末尾，生存与此在“掌握日常”的能力相关，暗示一种更主动、清醒的存在姿态。

  • 现身情态（Befindlichkeit）：此在始终处于某种情绪或心境中，这种情绪先于认知而揭示此在“身在何处”的基本状态。本段中提到的“懒洋洋无情无绪的现身情态”，特指一种麻木、迟钝的情绪状态，它让此在熟悉并沉沦于日常。

  • 常人（das Man，文中译为“人们”）：指代支配日常状态的匿名的、平均化的他人。此在在日常中往往放弃自身选择，按“大家都会怎么做”来行动，从而逃避自身的存在责任。

2. 逐句转译

  • “日常状态的这些多重性质却绝非是把日常状态标识为一些单纯的‘方面’，仿佛当‘人们’‘看’人的所行所为之际此在便提供某种方面似的。”
    → 日常状态具有多重性质，但这些性质不能简单地被看作是一些表面的“侧面”或“角度”——就好像当我们用“一般人”的眼光去观察人的行为时，此在只是呈现出某种固定的面貌那样。海德格尔在此反对将日常状态客体化、旁观化的理解。

  • “日常状态是一种去存在的方式，公众的公开状态当然属于这种方式。”
    → 日常状态本身就是一种存在的方式，一种“活着”的具体形态。而那种被公众意见和视野所笼罩的“公开状态”，正是这种存在方式的典型表现。

  • “作为此在固有的生存活动的方式，日常状态却也或多或少地为各个‘个别的’此在所熟悉，这熟悉靠的是懒洋洋无情无绪的现身情态。”
    → 日常状态是此在与生俱来的、进行生存活动的基本模式。因此，每个具体的此在都多多少少熟悉它。但这种熟悉，并非源于清醒的认知，而是靠着一种懒散、麻木、无所谓的情感状态来维持的。

  • “此在可能木木然‘受着’日常状态，可能沉浸到日常状态的木木然之中去；此在可能为涣散在诸种经营的境况找寻新的消遣，以这种方式闪避日常状态。”
    → 此在可能会麻木地“忍受”着日常状态，甚至完全沉溺在这种麻木之中；它也可能通过不断寻找新的娱乐和消遣，来分散自己对各种琐碎事务的注意力——用这种方式来逃避直面日常状态本身。

  • “而生存甚至还可能在当下即是〔当然往往也不比‘当下即是’更持久〕掌握起日常，虽然生存从不能抹灭日常。”
    → 然而，此在的“生存”（即它本真的、主动的存在能力）偶尔也能在“当下此刻”把握并承担起日常状态（尽管这种把握通常很短暂）。不过，即使是这种本真的生存，也永远无法彻底消除日常状态。

3. 论证逻辑梳理

  1. 前提：日常状态具有多重性质。
  2. 核心界定：首先澄清对日常状态的误解——它并非可从外部观察的“方面”，而是此在“固有的”存在方式，其中公众性（常人统治）是其内在环节。
  3. 机制分析：进而分析此在与日常状态的关系：
    • 此因熟悉日常状态，但这种熟悉依赖于一种消极、麻木的情感状态（现身情态）。
    • 此在通常以两种方式沉沦于日常：要么被动忍受其麻木，要么主动寻求消遣以逃避它。
  4. 转折与限度：最后提出一种可能性，即此在的本真生存（Existenz）或能在瞬间（当下即是）主动承担起日常。但立即强调：这种把握是短暂且有限的，生存无法根除日常状态。此在注定要与日常状态共存。

4. 整体概括

这段话的核心在于阐明“日常状态”并非此在生命中可以随意剥离的某个侧面，而是它最基本、最固有的存在方式，由“常人”的公众意见所塑造。我们每个人之所以习惯于这种日常，并非因为主动选择，而是由于一种懒散麻木的情感。因此，人通常要么被动地沉溺于日常的麻木，要么通过不断寻求新鲜事来逃避它。海德格尔在最后留下了一丝可能性：人或许能在某些清醒的瞬间，主动承担起自己的日常，但这种本真的把握非常短暂，人永远无法彻底摆脱日常状态，它就像我们存在的底色，挥之不去。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“当下即是”的理解：有学者强调这特指此在在“畏”（Angst）等基本情绪中获得的、决断性的本真时刻；而另一种更宽泛的解读则将其视为任何从日常麻木中短暂苏醒的清醒瞬间。但核心共识是，这种“掌握”是短暂且无法消除日常状态的。
