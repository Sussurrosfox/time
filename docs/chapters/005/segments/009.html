📜 原文片段 (005/009)
海德格尔 原文
在这个有待回答的问题中，问之所问是存在——使存在者之被规定为存在者的就是这个存在；无论我们怎样讨论存在者，存在者总已经是在存在已先被领会的基础上才得到领会的。存在者的存在本身不“是”一种存在者。哲学领会存在问题的第一步在于“不叙述历史”，也就是说，不要靠把一个存在者引回到它所由来的另一存在者这种方式来规定存在者之为存在者，仿佛存在具有某种可能的存在者的性质似的。所以，存在作为问之所问要求一种本己的展示方式，这种展示方式本质上有别于对存在者的揭示。据此，问之何所以问，以及存在的意义，也要求一种本己的概念方式，这种概念方式也有别于那些用以规定存在者的意义的概念。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 存在 (Sein/Being)：在海德格尔哲学中，指使一切“存在者”得以成为“存在者”的那个最根本的根据或可能性。它不是任何一个具体的“东西”，而是使得所有“东西”能够显现、能够被我们谈论和经验的背景条件。在本段中，海德格尔强调“存在”本身不是一个“存在者”，不能像理解一个具体事物那样去理解它。

  • 存在者 (Seiendes/beings)：指所有具体、现成的事物或实体，比如人、椅子、观念、事件等，一切“是”某种东西的东西。它们是我们可以直接谈论、研究和定义的对象。

  • 领会 (Verstehen/understanding)：不是指理智上的“理解”，而是指此在（人）与生俱来的、对自身存在及其世界的一种前反思的、活生生的熟悉和把握。在本段中，海德格尔指出，我们对任何“存在者”的讨论，都已预先建立在对“存在”的某种（虽可能未明言的）领会之上。

  • 问之所问 (das Gefragte / that which is asked about)：一个问题的核心对象，即我们真正想问的那个东西。在这里，特指“存在”本身。

  • 问之何所以问 (das Erfragte / that which is to be found out by the asking)：通过提问所想寻求到的答案或意义。在这里，特指“存在的意义”。

  • 叙述历史 (Historie berichten / telling history)：在这里是比喻用法，并非指讲述实际的历史事件，而是指一种错误的思想方法，即试图通过追溯一个存在者的来源（另一个存在者）来解释它“是什么”。海德格尔认为，这种方法无法触及“存在”问题。

2. 逐句转译

  • 原文第一句：“在这个有待回答的问题中，问之所问是存在——使存在者之被规定为存在者的就是这个存在；无论我们怎样讨论存在者，存在者总已经是在存在已先被领会的基础上才得到领会的。”

  • 转译：我们现在要探讨的这个核心问题，它的真正对象是“存在”本身。正是这个“存在”，使得所有具体的事物（存在者）能够作为事物呈现给我们。不管我们怎么去研究和描述这些具体事物，我们之所以能认出它们、谈论它们，前提条件是我们已经对那个更根本的“存在”有了一种（哪怕是很模糊的）事先的把握。

  • 原文第二句：“存在者的存在本身不‘是’一种存在者。”

  • 转译：但是，千万要记住，“存在”本身并不是众多事物中的一员。它不是像一张桌子、一个想法那样的具体对象。

  • 原文第三句：“哲学领会存在问题的第一步在于‘不叙述历史’，也就是说，不要靠把一个存在者引回到它所由来的另一存在者这种方式来规定存在者之为存在者，仿佛存在具有某种可能的存在者的性质似的。”

  • 转译：所以，哲学要想真正理解“存在”这个问题，第一步就必须摒弃一种惯常的思维模式，那就是“追根溯源”的模式。我们不能用“这个东西是从那个东西来的”这种方式，去定义这个东西“是什么”。比如，我们不能说“人是从猿进化来的，所以人就是猿的一种”。因为这种做法，实际上是把“存在”（是什么）的问题，错误地当成了一种具体事物（存在者）之间的关系问题，仿佛“存在”本身也是一种可以追溯来源的物件似的。

  • 原文第四句：“所以，存在作为问之所问要求一种本己的展示方式，这种展示方式本质上有别于对存在者的揭示。”

  • 转译：正因为“存在”如此特殊，我们要把它作为研究对象展示出来，就需要一种完全属于它自己的、独一无二的方法。这种方法，和我们在科学研究中揭示一个具体事物（比如分析水的分子结构）的方法，从根子上就是两回事。

  • 原文第五句：“据此，问之何所以问，以及存在的意义，也要求一种本己的概念方式，这种概念方式也有别于那些用以规定存在者的意义的概念。”

  • 转译：基于同样的理由，我们想要探寻的那个答案——“存在”的意义究竟是什么——也需要一套全新的、专门为它打造的概念工具和语言。这套语言，和我们平时用来描述和定义具体事物（比如“硬度”、“颜色”、“功能”）的那些概念，也必须有本质的区别。

3. 论证逻辑梳理

  1. 前提确立：首先明确，我们探讨的核心问题是“存在”，它是使所有“存在者”得以可能的根本前提。
  2. 核心区分：紧接着进行一个关键区分：“存在”本身不是任何一个“存在者”。这是整个论证的基石，防止我们犯下最根本的范畴错误。
  3. 方法论批判：基于上述区分，批判了传统哲学中一种常见的错误方法，即“叙述历史”或因果溯源法。指出这种方法混淆了“存在”与“存在者”，试图用处理后者关系的方式来处理前者，此路不通。
  4. 方法论要求：既然旧方法无效，就必须为“存在”这个独特的研究对象，量身定做一套新的方法。这包括：
    • 一种全新的展示方式（如何让“存在”显现出来）。
    • 一种全新的概念方式（如何言说和思考“存在”的意义）。

逻辑链条清晰：从问题对象（存在）的特殊性（非实体性），推导出研究方法的独特性要求。

4. 整体概括

这段话的核心是在为“存在”问题的研究划定界限和方法论基础。海德格尔强调，“存在”是我们理解世界上一切事物的幕后背景，但它本身并不是这些事物中的任何一个。因此，我们绝不能沿用研究具体事物（比如研究一个物体的构成或来源）的那套思路去研究“存在”。传统哲学常常犯这个错误，试图用“A来源于B”的方式来定义A的存在，但这只是在不同存在者之间打转，完全错过了“存在”本身。所以，哲学必须开辟全新的道路，发展出专属于“存在”的、与众不同的展现方式和概念语言，才能真正触及“存在的意义”这个核心问题。

5. 争议与说明

本段解读相对一致，是《存在与时间》导论部分的方法论核心，学界对其基本含义的共识度较高。可能的细微争议点在于对“不叙述历史”这一比喻的具体所指，有学者会更具体地将其关联到对传统形而上学（尤其是亚里士多德的实体论）或近代科学因果律思维的批判，但其反对用存在者之间的关系来界定存在本身的核心意图是明确的。
