📜 原文片段 (085/035)
海德格尔 原文
此在能够被本真地带到被抛境况面前，以便在被抛境况之中本真地领会自己；虽然如此，从其存在者层次上的“何所来”以及“如何”着眼，被抛境况对此在还封闭着。这种封闭状态却绝不只是一种事实上存有的不知，而是组建着此在的实际性。它也一道规定着生存之被委弃于其自身的具有不之状态的根据这回事所具有的绽出性质。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在（Dasein）：海德格尔哲学的核心概念，指人的存在方式。此在的特点是：它总在关心自己的存在，并通过“在世存在”（与世界打交道）来展开自身。
  • 本真（Eigentlichkeit）：此在的一种存在方式，指此在清醒地认识到自己的有限性与可能性，并基于这种认识，主动承担起自己的存在，做出属于自己的抉择。
  • 被抛境况（Geworfenheit）：此在的一个基本规定性，指此在总是已经被投入到这个世界中，处在某个特定的时间、地点和历史情境里。这不是此在自己选择的，而是它必须接受和承担的“既定事实”。
  • 存在者层次（ontisch）：指从具体、事实性的层面来考察一个存在着（比如人、物体）的属性或状态。例如，你的出生日期、国籍、性别等，就是你存在者层次上的事实。
  • 实际性（Faktizität）：此在存在的一个基本结构，强调此在总是已经在世界之中，并且被它的“被抛境况”所规定。它就是此在必须面对和承担的“事实性处境”。
  • 不之状态（Nichtigkeit）：指在此在的根基处，存在着一种根本的“否定性”或“虚无”。这意味着此在的筹划和选择永远不是绝对完满或自足的，它总是包含着未被实现的可能性、失败的风险以及有限性。
  • 绽出性质（Ekstase / ekstatisch）：描述此在的时间性结构。此在的存在是“向外绽出”的，它总是超越当下的瞬间，投射向未来（筹划），并承担着过去（被抛）。

2. 逐句转译

  • “此在能够被本真地带到被抛境况面前，以便在被抛境况之中本真地领会自己” 这句话是说：我们人（此在）是有可能以一种清醒、不逃避的态度（本真地），去真正面对那个我们无法选择的、既定的生存起点（被抛境况），并从这个起点出发，去理解和塑造属于自己的生命。

  • “虽然如此，从其存在者层次上的‘何所来’以及‘如何’着眼，被抛境况对此在还封闭着。” 但是，尽管我们可以从态度上面对它，如果我们要追问这个起点在事实层面上的具体细节——比如“我到底是从哪里来的？”（何所来），以及“我何以成为了今天这个样子？”（如何）——那么，这个被抛境况对我们来说，依然是一个谜，是无法被完全看清和掌握的。

  • “这种封闭状态却绝不只是一种事实上存有的不知，而是组建着此在的实际性。” 然而，这种“看不清、说不清”的状态，并不是我们知识上的一个偶然缺陷。恰恰相反，它正是构成了我们真实生存处境（实际性）的一个核心部分。我们就是活在一种“根基处有迷雾”的状态中。

  • “它也一道规定着生存之被委弃于其自身的具有不之状态的根据这回事所具有的绽出性质。” 这种“根基处的迷雾”（封闭状态）和“生存中的根本缺陷感”（不之状态）共同决定了：我们的人生（生存）就像是被抛给了自己，必须独自承担，而这种承担本身，在时间性上就表现为一种不断“向外投射、同时又背负着过去”的动态过程（绽出性质）。

3. 论证逻辑梳理

  1. 前提/起点：此在有能力本真地面对其被抛境况。
  2. 第一个转折与分析：但这种面对，并不能穿透到被抛境况在事实细节（存在者层次）上的全部真相。被抛境况在根源上是“封闭”的。
  3. 核心推进：指出这种“封闭”并非偶然的无知，而是此在实际性的构成性部分。这就将“无知”从一个认识论问题，提升到了存在论的高度。
  4. 最终结论/深化：这种构成性的封闭，与生存本身固有的“不之状态”（虚无、有限性）相结合，共同塑造了此在生存的根本样态——一种被抛给自身、必须在时间中不断筹划和展开的“绽出”过程。

4. 整体概括

这段话的核心是在探讨人的生存处境中的一个深刻悖论：我们能够也必须勇敢地面对自己与生俱来的、无法选择的生存条件（被抛境况），并在此基础上活出真实的自我；然而，我们永远无法完全穷尽和掌控这些生存条件的全部事实根源。这种“根源上的未知”并非我们的知识不足，而是我们生存结构的一部分，它和生存本身固有的不完美与有限性一起，决定了我们的人生注定是一种在时间中不断向前投射、同时又背负着过去的动态旅程。简单来说，我们既要承担自己的命运，又永远无法完全看清命运的底牌，正是这种“承担着未知”的状态，构成了我们真实的生命体验。

5. 争议与说明

本段解读相对一致。主要的讨论点可能在于对“不之状态”和“绽出性质”之间关系的细微理解，但海德格尔在此要表达的核心思想——被抛境况的事实性封闭是构成性的，并参与规定了生存的绽出性结构——是学界普遍接受的基础解读。
