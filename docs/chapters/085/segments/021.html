📖 《存在与时间》研读 逐段解析
首页 / 第 085 章 / 片段 021
📜 原文片段 (085/021)
海德格尔 原文
对怕起组建作用的遗忘迷性乱真而让此在在未经掌握的“世间的”可能性之间冲来荡去。与这种未经把持的摆到当前相对的是在把自己带回到最本己的被抛境况中的对畏之当前的把持。畏按其生存论意义就不可能迷失于可加操劳之事。如果迷失之类的事情在一种与畏相似的现身情态中发生，那便是怕，而日常领会则把怕与畏混为一谈。虽说畏之当前业经把持，它却并非已经具有那在决定中到时的当下即是的性质。畏只是带入某种可熊作决定的情绪。畏之当前本身就作为“当下即是”存在并且只有它可能作为当下即是存在；它以正在跃起的方式把持住这一当下即是。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学中的核心概念，指“人”这种存在者。此在的本质在于其“生存”，它不是现成的、固定不变的实体，而是不断筹划自身可能性的、关心自身存在的存在者。

  • 怕：一种情绪，其对象是世内（即世界之内）的、确定的、有威胁性的具体事物。怕让此在迷失于并纠缠于这些具体事物之中，扰乱此在对其本真状态的领会。

  • 畏：与“怕”相对的另一种基本情绪。畏的对象不是任何世内的具体事物，而是“世界本身”以及“在世存在”本身。它让此在从沉沦于日常琐事的状态中抽离出来，直面自身最本己的（属于自己的）、被抛的（无缘无故已被抛入的）存在，从而为做出本真决断开启可能性。

  • 组建：在海德格尔哲学中，指某种元素或结构对于形成一个整体所具有的构成性、奠基性作用。

  • 遗忘：特指此在在沉沦（日常的、非本真的存在方式）状态中，对自己最本己的可能性（即能够自由筹划自身）的遗忘。

  • 迷性乱真：描述“怕”这种情绪所造成的效果。“迷”指迷失于世间事物；“性”指此在的本性；“乱真”指扰乱、遮蔽了此在对其本真存在的领会。

  • 被抛境况：此在的基本生存论规定之一。指此在总是已经被抛入一个它无法选择的、既定的世界和历史情境中，并必须在此基础上去存在。

  • 当前 / 把持当前：“当前”是时间性（过去、现在、未来统一）的一个维度。“把持当前”指此在并非被动地沉沦于眼前的世俗事务（“未经掌握的当前”），而是主动地持守和承担起由“畏”所揭示的那个直面自身存在的时刻。

  • 生存论意义：从“此在”的生存结构本身出发进行分析所揭示出的意义，区别于心理学或生物学的解释。

  • 操劳：此在与世内存在者（如工具、事物）打交道的非本真日常模式，忙于处理各种事务。

  • 日常领会：此在沉沦于“常人”（匿名的、公共的平均状态）时所具有的平均化、非本真的理解方式。

  • 决定 / 决断：特指本真决断。此在在“畏”中直面自身被抛的、自由的本质后，所做出的、真正属于自己的、对自身存在可能性的主动选择和承担。

  • 到时：时间性的各维度（曾在、当前、将来）作为一个统一的整体动态呈现出来。

  • 当下即是：本真的“当前”时刻。它不是指一个孤立的、转瞬即逝的“现在”，而是此在在决断中，将未来（筹划）和过去（被抛境况）统摄于自身，从而全身心地投入并持守于那个决定性的瞬间。

  • 正在跃起的方式：一种动态的、主动的、从沉沦状态中挣脱出来的存在方式。

2. 逐句转译

  1. 原文：对怕起组建作用的遗忘迷性乱真而让此在在未经掌握的“世间的”可能性之间冲来荡去。 转译：“怕”这种情绪，其核心是一种“遗忘”机制在起作用。这种遗忘会让人迷失本性、扰乱了对自己真实面目的认识，结果就是，人会被那些他自己并未真正理解和掌控的、仅仅属于世俗生活的各种可能性所裹挟，像无头苍蝇一样在其中来回奔波、无法自主。

  2. 原文：与这种未经把持的摆到当前相对的是在把自己带回到最本己的被抛境况中的对畏之当前的把持。 转译：与这种被动、失控地沉溺于眼前事务的状态相反，另一种状态是：通过“畏”这种情绪，人能够主动地把持住一个关键性的“当前”时刻。这个时刻能把人带回到他最本己的、被抛的生存境况之中（即意识到自己是无缘无故被抛到这个世界上的、必须为自己负责的自由个体）。

  3. 原文：畏按其生存论意义就不可能迷失于可加操劳之事。 转译：从生存论的根本意义上看，“畏”这种情绪的本质决定了它不可能让人迷失在那些可以忙于操办的具体事务里。

  4. 原文：如果迷失之类的事情在一种与畏相似的现身情态中发生，那便是怕，而日常领会则把怕与畏混为一谈。 转译：如果在某种看起来和“畏”很像的情绪状态中，人却依然迷失了，那么这种情绪其实不是“畏”，而是“怕”。然而，我们日常的平均化理解方式，常常会把“怕”和“畏”混淆起来，认为它们是一回事。

  5. 原文：虽说畏之当前业经把持，它却并非已经具有那在决定中到时的当下即是的性质。 转译：尽管通过“畏”所把持住的“当前”时刻已经是一种主动的持守，但它还不直接等同于在“决断”中完整呈现出来的那个“当下即是”的时刻。

  6. 原文：畏只是带入某种可熊作决定的情绪。 转译：“畏”仅仅是一种将人带入某种“能够做出决断”的情绪状态。它打开了可能性的大门，但尚未完成决断本身。（注：原文“可熊”应为“可以”的笔误或排版错误。）

  7. 原文：畏之当前本身就作为“当下即是”存在并且只有它可能作为当下即是存在；它以正在跃起的方式把持住这一当下即是。 转译：然而，“畏”所揭示的“当前”，其本身就已经是一种“当下即是”的存在方式了，而且，只有它才可能成为“当下即是”。它是以一种“正在跃起”（从沉沦中挣脱出来、主动挺身而出）的动态方式，来把持住这个决定性的“当下即是”的时刻。

3. 论证逻辑梳理

  1. 前提与对立面确立：段落开头首先描述了“怕”的负面效果——它通过“遗忘”让此在迷失于未经掌握的世间可能性，这是一种失控的、非本真的存在状态。
  2. 核心对比引入：紧接着，作者提出与“怕”相对立的“畏”。明确指出“畏”能通过“把持当前”，将此在带回其本真的“被抛境况”。
  3. 概念澄清：为了精确区分，作者强调“畏”在生存论上不可能导致迷失（这是“怕”的特征），并指出日常理解常将二者混淆。这步论证是为了排除对“畏”的流俗误解。
  4. 界定“畏”的功能与局限：然后，作者对“畏”的作用进行更精细的定位：它把持的“当前”还不是完整的、在“决断”中到时的“当下即是”，它只是为决断创造了可能性和情绪准备。
  5. 最终定性并揭示其本质：最后，看似与上一步矛盾，实则深化：作者断言，“畏”之当前本身就是“当下即是”，而且是其唯一可能的存在方式。这里的逻辑是：“畏”所开启的那个直面自身的时刻，虽然尚未包含具体的决断行动，但其存在方式（正在跃起、主动把持）在性质上已经是本真的“当下即是”了。它是在动态中持守着本真时间的核心。

4. 整体概括

这段话的核心是在精细辨析“怕”与“畏”这两种情绪如何塑造此在截然不同的存在状态。“怕”让人遗忘自身的本真性，迷失于世俗杂务，是一种被动的沉沦。而“畏”则像一记警钟，将人从这种浑浑噩噩中震醒，让人直面自身孤独无依、必须自我负责的“被抛”命运。虽然“畏”本身并不直接就是做出具体人生选择的“决断”行动，但它为决断扫清了道路，创造了内在条件。更重要的是，“畏”所呈现的那个直面自身的时刻，其本身就已经是一种挣脱流俗、挺身而出的本真生存姿态了，它就是本真时间——“当下即是”的雏形和唯一基础。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“畏之当前”与“在决定中到时的当下即是”之间关系的理解。一种更强调先后顺序，认为畏是决断的准备阶段；另一种（如本解读所倾向的）则更强调其内在统一性，认为畏所开启的瞬间在生存论性质上已经就是决断性的“当下即是”了，只是尚未在具体行动中展开。这两种解读的差异在于对“决断”的过程性与瞬间性侧重点不同，但都承认畏是通往本真决断的关键环节。
