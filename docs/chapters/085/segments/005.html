📜 原文片段 (085/005)
海德格尔 原文
我们用领会这一术语意指一种基础的生存论环节。它既不是与澄清解释和概念领会并列而有别的某一种特定的认识方式，也不是在专题把握这一意义上的一种一般认识；领会倒是这样组建此之在：一个此在能够生存着根据领会使视、四下寻视、仅仅观看等等诸种不同的可能性成形。澄清解释即是对不领会的东西有所领会地加以揭不，故而一切澄清解释都植根在此在的原本的领会中。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 领会（Verstehen / Understanding）：在海德格尔哲学中，领会不是指理智上的理解或认知活动，而是此在（Dasein，即人的存在）在世存在的一种基本方式。它构成了此在能够筹划自身可能性、与世界打交道的基础，是先于任何明确解释或概念把握的生存能力。

  • 生存论环节（Existenzial / Existential）：指构成此在存在方式的基本结构要素，不是具体的经验性质，而是使此在的存在成为可能的先验条件。

  • 此之在（Da-sein）：即“此在”，指人的存在，其本质在于它的“去存在”（Zu-sein），总是已经在世界之中并理解自身可能性。

  • 澄清解释（Auslegung / Interpretation）：对已经以领会方式被理解的东西进行明确揭示和阐述的活动，是领会的衍生模式。

  • 视（Sicht / Sight）、四下寻视（Umsicht / Circumspection）、观看（Hinsehen / Looking-at）：分别指此在与世界打交道时的不同方式：“视”是此在理解自身存在的基本方式，“四下寻视”是在操劳活动中对周遭环境的顾及，“观看”则是专题性的观察。

2. 逐句转译

  • “我们用领会这一术语意指一种基础的生存论环节。”
    我们所说的“领会”，指的是构成人之存在的一个根本性结构要素。

  • “它既不是与澄清解释和概念领会并列而有别的某一种特定的认识方式，也不是在专题把握这一意义上的一种一般认识；”
    它既不是和解释、概念理解并列的某种特定认知方式，也不是那种把事物当作对象来研究的普通认识。

  • “领会倒是这样组建此之在：一个此在能够生存着根据领会使视、四下寻视、仅仅观看等等诸种不同的可能性成形。”
    实际上，领会是这样构成人之存在的：人能够基于领会，让“视”（理解自身）、“四下寻视”（顾及环境）、“仅仅观看”（专注观察）等各种与世界打交道的方式成为可能。

  • “澄清解释即是对不领会的东西有所领会地加以揭不，故而一切澄清解释都植根在此在的原本的领会中。”
    所谓解释，就是把那些尚未明确理解的东西，基于已有的领会揭示出来；因此，所有解释活动都扎根于人原本就具备的领会之中。

3. 论证逻辑梳理

  • 前提：领会被定义为生存论的基本环节，而非某种具体的认识方式。
  • 推进：通过否定两种对领会的常见误解（作为特定认识方式或专题认识），正面指出领会的真正功能——它是此在能够以多种方式（视、寻视、观看）与世界打交道的可能性条件。
  • 结论：澄清解释作为派生性的活动，必须以原初的领会为基础；没有领会，就不可能有任何解释。

4. 整体概括

这段文字的核心在于确立“领会”作为此在生存的基本结构。海德格尔强调，领会不是我们平时所说的理解或认识，而是使一切理解活动得以可能的前提。正是因为我们原本就以领会的方式“在世”，才能进而发展出解释、观察等各种具体的认知模式。换句话说，领会就像土壤，解释只是从这土壤中生长出的植物；没有领会这片土壤，任何明确的理解都无法生根发芽。

5. 争议与说明

本段解读相对一致，学界普遍认同海德格尔对“领会”作为生存论基本环节的界定。可能的细微争议在于“视”、“寻视”、“观看”等具体模态的划分是否足够清晰，但这不影响对领会之基础地位的整体把握。
