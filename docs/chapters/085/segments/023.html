📖 《存在与时间》研读 逐段解析

📜 原文片段 (085/023)
海德格尔 原文
怕与畏这两种情绪却从不孤零零地“出现”在“体验流”里，它们向来就规定着一种领会并从这样一种领会规定自身。怕的事由是周围世界中操劳所及的存在者。畏则相反发源于此在自身。怕从世内事物袭来。畏从被抛向死存在这一在世升起。从时间性上来领会，畏的这一从此在的“升腾”等于说：畏的将来与当前从一种源始的曾经存在到时，这曾经存在的意义是带回到可重演性。但畏只能真正在一个下了决心的此在中升腾。下定决心者不识怕，却恰恰把畏的可能性领会为对他无所拦阻无可迷乱的那种情绪。畏〔把他〕从种种“具有不之状态”的“可能性”中解放出来，让〔他〕为种种本真的可能性成为自由的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 怕（Furcht）：海德格尔区分的两种基本情绪之一。怕是对世界中具体、确定威胁对象（如危险的事物或事件）的反应，它总是“有所怕”，对象是明确的。
  • 畏（Angst）：另一种基本情绪。畏不是怕具体事物，而是对此在自身“在世存在”这一基本境况的回应。畏没有具体对象，它揭示的是此在“被抛向死亡”的、无家可归的赤裸状态，是此在直面自身“无”的体验。
  • 领会（Verstehen）：此在的一种基本存在方式。它不是指理智上的理解，而是指此在总是已经在筹划自己的可能性，先行于自身而存在。情绪（如怕与畏）本身就包含并规定着一种对世界的领会。
  • 此在（Dasein）：指人的存在。海德格尔用此在特指那种能够发问并关切自身存在的存在者。
  • 在世（In-der-Welt-sein）：此在最基本的存在结构。此在从来不是孤立的主体，它总是已经“在世界之中”与他人、他物共同存在。
  • 被抛（Geworfenheit）：此在的一个基本规定性。指此在总是已经被抛入一个它未曾选择的世界、历史和环境之中，并必须从这个被给予的处境出发去存在。
  • 决断（Entschlossenheit，文中译为“下了决心”）：此在的一种本真存在状态。指此在摆脱常人的支配，直面自身的被抛境况和向死存在的命运，果断地承担起自身的可能性，并行动。
  • 时间性（Zeitlichkeit）：此在存在的意义。在海德格尔看来，此在的存在本质上是在时间中展开的，是一种由“将来-曾在-当前”三维统一构成的动态过程。
  • 到时（Zeitigung）：时间性实现自身的方式。指将来、曾在、当前这三个时间维度并非依次到来，而是共同、统一地“绽放”出来，构成此在的生存。
  • 不之状态（Nichtigkeit）：此在生存论结构中的一个本质环节。指在筹划自身可能性时，此在所不是的那些可能性，以及其选择所带来的放弃和否定性。

2. 逐句转译

  1. “怕与畏这两种情绪却从不孤零零地‘出现’在‘体验流’里，它们向来就规定着一种领会并从这样一种领会规定自身。” 怕和畏不是偶然飘过我们意识的一些孤立感觉。它们本身就塑造着我们理解世界的方式（领会），并且它们自身的性质和内容也是由这种理解方式所决定的。

  2. “怕的事由是周围世界中操劳所及的存在者。畏则相反发源于此在自身。” 怕总是有具体原因的，这个原因就是我们日常打交道（操劳）的世界里的某个东西，比如一条蛇或一个截止日期。而畏则完全不同，它的根源在于我们自身的存在（此在）。

  3. “怕从世内事物袭来。畏从被抛向死存在这一在世升起。” 怕是从世界内部的事物向我们扑来，袭击我们。畏则是从我们“被抛入世界、并且注定走向死亡”这一基本生存境况中升腾起来的。

  4. “从时间性上来领会，畏的这一从此在的‘升腾’等于说：畏的将来与当前从一种源始的曾经存在到时，这曾经存在的意义是带回到可重演性。” 从时间性的角度来理解，畏从我们自身内部升起，意味着：畏这种情绪所涉及的“未来”和“当下”，是从一个更根源的“过去”（曾经存在）中一起涌现出来的。这个“过去”的意义在于，它把此在带回到其最本己的、可以被重新把握和承担的可能性面前（可重演性）。

  5. “但畏只能真正在一个下了决心的此在中升腾。” 但是，真正的、纯粹的畏，只会在一个已经下了决心、处于决断状态的人（此在）那里升起。

  6. “下定决心者不识怕，却恰恰把畏的可能性领会为对他无所拦阻无可迷乱的那种情绪。” 一个处于决断状态的人，不会被“怕”所困扰，但他恰恰能理解“畏”的可能性，并把畏看作是那种不会阻碍他、也不会使他迷乱的情绪。

  7. “畏〔把他〕从种种‘具有不之状态’的‘可能性’中解放出来，让〔他〕为种种本真的可能性成为自由的。” 畏将人从那些包含着“否定性”（即选择了A就意味着放弃了非A）的、非本真的可能性中解放出来，从而让他能够自由地去面对和选择那些真正属于他自己的、本真的可能性。

3. 论证逻辑梳理

  • 前提： 怕与畏是两种不同的、规定着领会的原初情绪。
  • 对比分析： 段落的核心在于严格区分怕与畏。怕的源头在外（世内存在者），畏的源头在内（此在自身）；怕的对象是具体的，畏的对象是此在自身“被抛向死”的生存整体。
  • 深化论证（引入时间性与决断）： 接着，从时间性角度阐释畏的结构，指出畏是将来、当前从一种本源的“曾在”（被抛境况）中统一“到时”的。进而提出，这种本真的畏只有在下了决心的此在（即本真的此在）中才能出现。
  • 结论： 最终阐明畏的解放功能：对于一个下了决心的人来说，畏不再是令人瘫痪的恐惧，反而是一种解放性的力量。它使人摆脱那些琐碎、非本真的可能性（它们因其“不之状态”而使人分心迷乱），从而自由地投向本真的可能性。

4. 整体概括

这段话的核心思想是：怕和畏虽然都是基本情绪，但有本质区别。怕是针对世界内具体事物的恐惧，而畏则是源于人对自身“被抛向死亡”这一残酷事实的觉察。真正的畏，只有在一个人直面命运、下定决心成为自己时才会出现。此时，畏不再是令人恐慌的东西，反而成为一种解放的力量。它像一声惊雷，把人从日常琐碎事务和无穷无尽但又无关紧要的选择（非本真可能性）中震醒，让他看清什么才是自己生命中真正值得投入的、本真的可能性，从而获得自由。

5. 争议与说明

本段解读相对一致，核心争议点不多。一个可能的细微讨论在于对“畏只能真正在一个下了决心的此在中升腾”的理解。有学者认为，这并非指常人或非本真状态下的此在完全体验不到畏，而是指那种能发挥解放作用的、被清晰领会的、本真的畏，只出现在决断状态中。常人也会感到莫名的焦虑（畏的一种雏形），但通常会立刻将其误解或解释为对某物的“怕”，从而逃避了其本真含义。
