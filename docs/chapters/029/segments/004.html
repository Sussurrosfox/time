结构化精读

1. 术语释义

  • 实体 (Substance)：在海德格尔哲学中，实体通常指独立自存、不依赖于他者而存在的东西。在本段中，海德格尔借用了笛卡尔和中世纪哲学的用法，特指上帝（无限实体）和受造物（有限实体，如物质世界和心灵）这两种存在者。
  • 存在 (Being / Sein)：一般指使存在者得以成为存在者的那个“是”本身，即存在者的根据或本质。本段中，海德格尔聚焦于“存在”一词在不同实体（上帝与世界）中的含义是否相同。
  • 类推的类比 (Analogous Meaning)：源自经院哲学，指“存在”一词在用于不同实体时，既非完全同一含义，也非完全无关，而是以一种有比例、有关联的相似方式被理解（例如，上帝的存在是自因的、无限的，世界的存在是被造的、有限的，但两者都分有“存在”）。

2. 逐句转译

  1. “所以，只有当我们澄清了三种实体〔其一是无限的实体，另两种是有限的实体〕所‘共有的’存在的意义，我们才可能从存在论根基上来规定那种以extensio为其特殊proprietas〔属性〕的实体的存在。”
    → 这段话是说：我们必须要先搞清楚“存在”这个词，对于上帝（无限实体）和受造物（两种有限实体，比如物质和心灵）来说，到底意味着什么；只有搞清楚了这一点，我们才能真正从哲学根基上理解，像物质实体（它的特性是广延，即占据空间）这样的东西的存在方式。

  2. “然而，把‘实体’一词在同一意义下〔借用经院哲学中最惯用的术语〕应用于上帝和受造物是不恰当的，这就是说，我们完全未能清晰地理解那用于上帝与其所造物的共同名称的含义。”
    → 但问题在于：我们不能简单粗暴地用同一个意思的“实体”这个词，同时去称呼上帝和受造物。这说明我们其实没想明白，这个共同使用的词——“实体”——到底在上帝和世界这两者身上分别指什么。

  3. “在这里，笛卡尔接触到了中世纪存在论多次讨论的问题。这问题就是：存在的含义以何种方式意味着上述的各种存在者？”
    → 海德格尔指出，笛卡尔在这里其实碰到了一个老问题——中世纪哲学家们反复争论的问题：当我们说“上帝存在”和“世界存在”时，“存在”这个词，到底是以怎样的方式，来分别指向上帝和世界这两种不同的存在者的？

  4. “在‘上帝存在’和‘世界存在’这些命题中我们道出了存在。但是，既然这两种存在者的存在之间有着无限的差别，‘存在’这个词就不可能在同一意义下意指各种存在者。”
    → 我们确实在两个句子里都用了“存在”这个词：一个说上帝存在，一个说世界存在。但上帝的存在（无限、永恒、自因）和世界的存在（有限、被造、依赖）有天壤之别，所以“存在”不可能在两者身上意味完全相同的东西。

  5. “假使‘存在’的含义相同，那么受造物就意指着非受造物了，或者非受造物就降格为一种受造物了。”
    → 如果硬要说“存在”的意思完全一样，那就会导致混乱：要么把受造物（世界）当成非受造物（上帝），要么把上帝贬低成一种受造物。这显然是不合理的。

  6. “‘存在’也并非仅仅作为一个形同实异的名号起作用；在两种场合下，领会到的都是‘存在’。”
    → 但“存在”这个词也不是完全偶然、碰巧在两个地方都用到了——当我们说上帝“存在”或世界“存在”时，我们领会到的确实都是某种“存在”，不是毫不相干的 homonym（同音异义）。

  7. “经院哲学家把‘存在’所意味的肯定意义把握为‘类推的’含义，以区别于相同的含义或仅仅同名的含义。”
    → 所以，中世纪哲学家（经院哲学家）提出了一种解决方案：他们把“存在”的含义理解为“类推的”——也就是说，上帝的存在和世界的存在，不是意思完全一样，也不是完全无关，而是一种有比例、有关联的相似关系。

  8. “在亚里士多德那里，或者说在一般希腊存在论发端之时，这个词的雏形就已形成。后世从亚里士多德出发，确定下了各式各样的类推方式，后来在如何看待存在的意指功能这个问题上甚至还分出诸种‘学派’来。”
    → 这种“类推”的思想其实早在亚里士多德那里，甚至整个希腊存在论刚开始的时候，就已经有了雏形。后来的哲学家们以亚里士多德为起点，发展出了各种不同的类推理论，甚至在“存在”到底怎么意指不同事物这个问题上，还形成了不同的学派和争论。

3. 论证逻辑梳理

  • 前提：要理解某种特定实体（如物质实体）的存在，必须先澄清“存在”一词对于上帝（无限实体）和受造物（有限实体）的共同含义。
  • 问题提出：但将“实体”一词无差别地用于上帝和受造物是不恰当的，因为我们并未真正理解其共同含义。
  • 核心问题：这是中世纪存在论反复讨论的问题——“存在”一词如何以不同方式意指上帝和世界这两种截然不同的存在者？
  • 论证推进： 1. 指出若“存在”含义完全相同，会导致逻辑矛盾（受造物被视为非受造物，或上帝被降格）。 2. 但又承认“存在”并非偶然同音词——我们在两种情况下确实都领会到“存在”。
  • 解决方案引入：经院哲学家提出“类推”概念，作为介于“完全相同”和“完全无关”之间的中间道路。
  • 历史溯源：此思路可追溯至亚里士多德及希腊存在论开端，后世发展出多种类推方式并形成学派分歧。

4. 整体概括

这段文字核心是在讨论一个经典的存在论难题：当我们用“存在”一词描述上帝和世界时，这个词的含义是否相同？海德格尔借助笛卡尔的论述指出，由于上帝（无限、非受造）与世界（有限、受造）有着本质区别，“存在”不可能在两者身上意味完全相同的东西，否则就会导致逻辑混乱——要么把世界神化，要么把上帝俗化。但“存在”也并非完全偶然的同音词，因为我们确实在两种情况下都领会到了某种“存在”。为了解决这个困境，经院哲学家提出了“类推”理论——即“存在”在上帝和世界那里的含义既非同一也无关，而是一种有比例、有关联的相似关系。这个思路可追溯到亚里士多德，并在后世引发了许多哲学流派的讨论与发展。

5. 争议与说明

本段内容在学界解读相对一致，主要是对海德格尔转述笛卡尔及经院哲学观点的忠实解析。可能的细微争议点在于： - 海德格尔对“类推”理论的最终态度：他在这里是单纯介绍历史观点，还是隐含批评（认为类推仍未能真正追问“存在本身”）？多数解读认为后者，即海德格尔在后续论证中会揭示，即使是“类推”也仍是从现成存在者出发，未能触及存在问题的本源。 - “存在”的类推具体是何种比例关系？经院哲学内部（如托马斯·阿奎那与邓斯·司各脱）对此确有不同理解，但海德格尔在此仅点到为止，未深入细节。
