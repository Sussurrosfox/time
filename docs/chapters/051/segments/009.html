海德格尔 原文
满足这些方法上的要求的现身情态是号，这种现象将为我们的分析奠定基础。把这种基本现身情态清理出来，从存在论上对在畏之中展开的东西进行特征标画，这些工作是以沉沦现象为出发点的。这些工作还把畏同怕界划开来，后者是我们以前曾分析过的一种与畏相近的现象。畏，作为此在存在的可能性之一，连同在畏中展开的此在本身一道，为鲜明地把握此在源始存在的整体性提供了现象基地。此在之在绽露为操心。要从存在论上把这种生存论上的基本现象清理出来，就须得同那些一开始很容易同操心混同的现象划清界限。这类现象是意志、愿望、嗜好与追求。操心不能从这些东西派生出来，因为这些东西本身奠基在操心之中。像每一种存在论分析一样，对此在之为操心的存在论阐释，以及这种阐释所赢得的东西，与始终由先于存在论的存在领会通达的东西风马牛不相及，更别提由关于存在者的存在者层次上的知识所通达的东西了。平庸的知性所着眼的是它唯一从存在者层次上熟知的东西；存在论上认识到的东西对它陌生特异，原无足为怪。尽管如此，这里从存在论上把此在阐释为操心的尝试一旦从存在者层次上提出来就可能显得牵强附会，似乎是一种理论上的虚构；何况我们始终把流传下来的经过验证的人的定义束之高阁，人们很可能会觉得我们强词夺理。所以，还须得从先于存在论的角度来验证此在之为操心的生存论阐释。这种证据就是：此在刚刚对它自身道出它自身的时候，就早已把自己解释为操心〔cura〕，虽说还只是以先于存在论的方式。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 现身情态：此在（人）在特定处境中的基本情绪或情感状态，是此在向世界敞开并感受自身存在的方式。它先于认知，直接揭示此在的“被抛”境况。
  • 畏：此在面对自身“在世之在”整体时的一种深层情绪，揭示此在作为“可能之在”的自由与无家可归感。它无具体对象，不同于有具体对象的“怕”。
  • 怕：针对具体威胁对象（如猛兽、灾难）的日常恐惧情绪，对象明确。
  • 此在：海德格尔对“人”的存在论称谓，指能够发问、理解并承担自身存在的存在者。
  • 操心：此在存在的整体结构，指此在始终“超前于自身—已在世界之中—依寓于世内存在者”的统一现象。它是此在生存的基本建构。
  • 沉沦：此在在日常世界中迷失于闲谈、好奇、两可等状态，逃避自身本真性的非本真存在方式。
  • 存在论：探究存在本身（而非具体存在者）的哲学研究，关注存在如何显现。
  • 先于存在论：此在日常未经哲学反思的对自身存在的天然理解（如日常说“我很担心”）。
  • 存在者层次：对具体事物或属性的经验性、实证性知识（如心理学研究情绪）。

2. 逐句转译

  • “满足这些方法上的要求的现身情态是畏，这种现象将为我们的分析奠定基础。”
    → 我们选择“畏”这种情绪状态作为方法论的起点，因为它符合哲学分析的要求，能帮我们深入理解此在的存在结构。

  • “把这种基本现身情态清理出来，从存在论上对在畏之中展开的东西进行特征标画，这些工作是以沉沦现象为出发点的。”
    → 我们要把“畏”从日常混淆中剥离出来，从哲学层面描述它在畏中揭示的内容；这个工作是从“沉沦”（日常迷失状态）入手分析的。

  • “这些工作还把畏同怕界划开来，后者是我们以前曾分析过的一种与畏相近的现象。”
    → 同时，我们要区分“畏”和“怕”——怕是对具体事物的恐惧，我们之前分析过它。

  • “畏，作为此在存在的可能性之一，连同在畏中展开的此在本身一道，为鲜明地把握此在源始存在的整体性提供了现象基地。”
    → “畏”作为此在的一种本真可能状态，连同它所揭示的此在自身，一起为我们把握此在最本原的整体存在提供了现象依据。

  • “此在之在绽露为操心。”
    → 此在的存在由此显露出它的根本结构——“操心”。

  • “要从存在论上把这种生存论上的基本现象清理出来，就须得同那些一开始很容易同操心混同的现象划清界限。”
    → 要在哲学上澄清“操心”这一基本现象，就必须先和那些容易与它混淆的概念（如意志、愿望等）划清界限。

  • “这类现象是意志、愿望、嗜好与追求。操心不能从这些东西派生出来，因为这些东西本身奠基在操心之中。”
    → 比如意志、愿望、嗜好、追求等，它们看起来像“操心”，但实则不然；“操心”是更底层的基础，这些现象反而建立在“操心”之上。

  • “像每一种存在论分析一样，对此在之为操心的存在论阐释，以及这种阐释所赢得的东西，与始终由先于存在论的存在领会通达的东西风马牛不相及，更别提由关于存在者的存在者层次上的知识所通达的东西了。”
    → 就像所有哲学分析一样，我们对“操心”的哲学阐释及其结论，和日常非哲学的理解（如“我操心工作”）完全不同，更不用说和心理学的经验研究（如研究焦虑）无关了。

  • “平庸的知性所着眼的是它唯一从存在者层次上熟知的东西；存在论上认识到的东西对它陌生特异，原无足为怪。”
    → 普通人只熟悉日常经验层面的事物；觉得哲学层面的认识陌生奇怪，这很正常。

  • “尽管如此，这里从存在论上把此在阐释为操心的尝试一旦从存在者层次上提出来就可能显得牵强附会，似乎是一种理论上的虚构；何况我们始终把流传下来的经过验证的人的定义束之高阁，人们很可能会觉得我们强词夺理。”
    → 即便如此，如果从日常经验角度看我们把此在说成“操心”，会显得生硬、像理论编造；尤其因为我们搁置了传统对人的定义（如“人是理性动物”），更容易让人觉得是强辩。

  • “所以，还须得从先于存在论的角度来验证此在之为操心的生存论阐释。”
    → 因此，我们需要从日常非哲学的理解中，找到对“此在是操心”这一哲学观点的印证。

  • “这种证据就是：此在刚刚对它自身道出它自身的时候，就早已把自己解释为操心〔cura〕，虽说还只是以先于存在论的方式。”
    → 证据在于：当人最初表达自己时，就已经用“操心”（如拉丁词cura）来形容自己了——虽然那只是日常非哲学的说法。

3. 论证逻辑梳理

  • 前提：
    1. “畏”是符合现象学方法要求的基本现身情态。
    2. 通过分析“畏”可以揭示此在的整体存在结构。

  • 推进过程：
    1. 从“沉沦”现象出发，清理并刻画“畏”，并与“怕”划清界限。
    2. 指出“畏”所展开的现象基地揭示了此在的整体存在即“操心”。
    3. 为澄清“操心”，需与意志、愿望等易混淆现象划界，并强调后者奠基于前者。
    4. 阐明存在论阐释（操心）与先于存在论的领会、存在者层次知识本质不同。
    5. 承认从日常视角看，此阐释可能显得牵强，故需寻求先于存在论的验证。

  • 结论：
    此在在日常自我理解中（如拉丁语cura）已非哲学地将自身解释为“操心”，这为生存论阐释提供了来自前哲学经验的佐证。

4. 整体概括

这段话的核心在于：海德格尔以“畏”为方法入口，揭示出此在的整体存在结构是“操心”。他强调这一哲学分析不同于日常经验或心理学，可能显得抽象甚至牵强，但事实上，人在日常自我表达中（如拉丁语用cura指人的本质）早已不自觉地印证了“人是操心”这一生存论洞见。因此，哲学上的“操心”并非虚构，而有其深厚的生活经验根基。

5. 争议与说明

  • 主流解读：此段被视为海德格尔从“畏”到“操心”的关键过渡，强调存在论分析与日常理解的差异及内在关联。“操心”作为此在的整体结构，既需现象学澄清，又需日常语言（如cura）的非哲学印证。

  • 其他解读方向：
    1. 有学者质疑“畏”到“操心”的推导是否必然，或认为“畏”揭示的更多是“无”而非直接导出“操心”。
    2. 对“先于存在论验证”的作用存在争议：是辅助说明，还是不可或缺的论证环节？
    争议点在于：海德格尔是否过于依赖词源（cura）来支撑存在论论断，以及“畏”的现象描述是否足够支撑“操心”作为整体结构。
