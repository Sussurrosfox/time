海德格尔 原文
从而，准备性的此在基础分析的最后一章就包括以下的课题：畏这一基本现身情态作为此在别具一格的展开状态〔第四十节〕；此在之存在—操心〔第四十一节〕；由先于存在论的此在自我解释验证此在之为操心的生存论阐释〔第四十二节〕；此在、世界之为世界、实在〔第四十三节〕；此在、展开状态、真理〔第四十四节〕。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学的核心概念，指“人的存在”。它不是指一个固定不变的人，而是指那种不断追问自身存在意义、并在世界中行动着的存在者。此在的本质在于它的“生存”，即它总是“去存在”，总是处在可能性的展开之中。
  • 基础分析：指海德格尔在《存在与时间》中，对此在的存在方式所进行的系统性的、准备性的探究。目的是要揭示此在的基本结构，为最终追问“存在本身的意义”打下基础。
  • 现身情态：此在总是带着某种情绪或心境“现身”于世界之中。这种情绪不是主观的心理状态，而是此在揭示自身“被抛”于世、并整体性地领会其处境的根本方式。
  • 畏：一种非常特殊的基本现身情态。它与“怕”不同，“怕”总是怕某个具体的东西，而“畏”没有确定的对象，它揭示的是此在面对其自身“在世界之中”这一赤裸裸的事实，以及面对其自身最本己的、作为可能性的存在时所产生的基本情绪。
  • 展开状态：此在的存在方式就是不断地“展开”或“揭示”。它通过理解、现身情态和话语，将自身、世界以及他人带入一种“被照亮”的、可被领会的状态。
  • 操心：此在的整体存在结构。它描述此在总是一刻不停地“关心”着自己的存在，投身于其可能性之中，并为之“忙碌”和“担忧”。此在先行于自身（面向未来谋划）、已经存在于世界之中（被抛的过去）、并正沉沦于周围世界（当下与常人共在），这三重结构的统一整体就是“操心”。
  • 生存论阐释：一种哲学方法，它不是从外部观察人，而是从此在自身的生存活动和自我理解出发，来揭示其存在结构。
  • 先于存在论的此在自我解释：指此在在日常生活中，未经哲学反思前，对自己存在方式的自然而然的、前理论的理解和表达。
  • 实在：海德格尔在此要探讨的不是传统哲学中作为“客观现实”的实在，而是要追问：事物（包括世界）是如何对此在显现为“真实”的？其“实在性”根植于此在的何种存在方式？
  • 真理：海德格尔将真理追溯到古希腊语“aletheia”的原意，即“无蔽”。真理不是一个正确的陈述与一个客观事实的符合，而是指存在者从隐蔽状态中被带入“无蔽”状态，被揭示出来的事件。这个事件发生于此在的展开状态之中。

2. 逐句转译

  • 第一句：“从而，准备性的此在基础分析的最后一章就包括以下的课题：”

  • 转译：所以，我们这本作为铺垫、专门分析“此在”基本结构的书，在它最后一个部分，要研究以下几个核心问题：

  • 第二句：“畏这一基本现身情态作为此在别具一格的展开状态〔第四十节〕；”

  • 转译：第一个问题是“畏”这种根本性的情绪。它不同于一般的害怕，是一种非常特别的、能将此在的整体存在彻底照亮和打开的状态。（这会在第40节详细讨论。）

  • 第三句：“此之存在—操心〔第四十一节〕；”

  • 转译：第二个问题是，此在的整体存在结构，被我们称之为“操心”。（这会在第41节展开。）

  • 第四句：“由先于存在论的此在自我解释验证此在之为操心的生存论阐释〔第四十二节〕；”

  • 转译：第三个问题是，我们将回到此在未经哲学思考前的日常自我理解中（比如神话、寓言），看看它们是否也在无意中印证了我们哲学分析得出的“此在即操心”这个结论。（这会在第42节验证。）

  • 第五句：“此在、世界之为世界、实在〔第四十三节〕；”

  • 转译：第四个问题是，探讨此在、世界（世界之所以成其为世界的那个结构）以及“实在”（事物真实存在的意义）这三者之间的关系。（这会在第43节处理。）

  • 第六句：“此在、展开状态、真理〔第四十四节〕。”

  • 转译：最后一个问题是，探究此在、此在的展开状态（它揭示世界的能力）以及“真理”的本质之间密不可分的联系。（这会在第44节完成。）

3. 论证逻辑梳理

  • 前提：海德格尔已经在前面的章节中对此在的日常存在（沉沦于“常人”状态）进行了分析。
  • 推进与目标：本段是一个纲领性的宣告，它指出基础分析的最终任务，是要通过一系列环环相扣的课题，层层深入地揭示此在最为根本的存在结构。 1. 首先，从一个最极端的情绪体验——“畏”入手，因为它能最纯粹地揭示此在的“展开状态”。 2. 然后，基于这种揭示，正面提出此在的整体存在结构就是“操心”。 3. 接着，为了证明这个哲学结论不是空穴来风，要返回到此在的非哲学自我理解中去寻找证据，进行“验证”。 4. 在确立了此在的核心结构后，进一步探讨此在与“世界”和“实在”这些关键哲学范畴的关系，说明它们都植根于此在的存在方式。 5. 最后，将这一切推向顶点，重新定义“真理”，论证真理的本质在于此在的展开状态，从而将此在的分析与最根本的哲学问题——“存在之真理”——联系起来。
  • 结论：这一系列课题构成了一个完整的论证序列，旨在从情绪、结构、验证、关联性及最终意义等多个维度，彻底完成对此在的准备性基础分析。

4. 整体概括

这段话是海德格尔为自己著作第一篇（此在的基础分析）的最后部分所设定的研究路线图。他告诉我们，为了最终完成对此在的透彻分析，他将依次探讨五个核心议题：从“畏”这种能彻底暴露人存在状态的特殊情绪出发，引出并定义人的整体存在结构就是“操心”；然后，他会回到人的日常理解中去寻找对这个哲学观点的支持；进而，他将以此为基础，重新解释“世界”、“实在”这些概念与人的存在的内在关联；最终，他将论证，连“真理”这件事，其根源也在于人这种不断展开、不断揭示的存在方式。整段话展现了一个由表及里、由结构到意义、步步深入的宏大哲学规划。

5. 争议与说明

本段是一个纲领性、目录性的段落，其本身内容是对后续章节主题的宣告，因此不存在实质性的文本解读争议。学界讨论的焦点和分歧主要集中在后续这些章节（第40-44节）所展开的具体哲学论证上，而非这段预告文字本身。因此，对本段的解读是相对一致的。
