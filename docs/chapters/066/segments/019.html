📜 原文片段 (066/019)
海德格尔 原文
本真的向死存在意味着此在的一种生存上的可能性。这种存在者层次上的能在复又必须在存在论上是可能的。这种一可能性的生存论条件都是些什么？这些条件本身又应如何成为可通达的？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 本真：在海德格尔哲学中，“本真”指此在（人的存在）摆脱了常人（日常的、匿名的公众意见）支配，直面自身最本己的可能性的存在方式。它是一种清醒、决断的存在状态。
  • 向死存在：此在面向自身最极端的可能性——死亡——而存在的生存论结构。死亡不是遥远的事件，而是此在始终携带着的、构成其整体性的可能性。
  • 此在：指人的存在，是一种能够发问、理解自身存在的特殊存在者。
  • 生存上的可能性：此在作为能在，其存在总是面向未来、筹划自身的种种可能方式。
  • 存在者层次上的能在：此在实际地、具体地实现其可能性的能力。
  • 存在论：探究存在本身意义与结构的学问，区别于研究具体存在者的科学。
  • 生存论：海德格尔用以分析此在存在结构的特定存在论。

2. 逐句转译

  • “本真的向死存在意味着此在的一种生存上的可能性。” → 当我们说一个人是“本真地面对死亡而活着”，这其实描述了人的一种非常根本的生存方式——它不是指具体做什么事，而是指人能够以清醒、直面自身终极命运的态度去存在。
  • “这种存在者层次上的能在复又必须在存在论上是可能的。” → 这种在实际生活中能够真实活出来的状态（本真向死存在），其背后必须有更深层的、关于存在本身的结构作为支撑，使得这种活法在原理上成为可能。
  • “这种一可能性的生存论条件都是些什么？” → 那么，究竟是哪些构成人之存在的基本条件，使得这种本真地向死存在得以可能？
  • “这些条件本身又应如何成为可通达的？” → 更进一步，我们怎样才能真正理解和触及这些深层条件本身？

3. 论证逻辑梳理

  1. 前提确立：首先明确提出“本真的向死存在”是此在的一种生存可能性。
  2. 层次转换与问题深化：接着指出，这种实际生存层面（存在者层次）的可能性，其根基必须追溯到更基础的存在论层面。这完成了一个从“是什么”到“何以可能”的提问转换。
  3. 核心问题提出：基于以上，提出两个层层递进的核心问题：
    • 第一问：构成这种可能性的具体生存论条件是什么？（追问条件的“内容”）
    • 第二问：我们如何才能通达并认识这些条件本身？（追问认识条件的“方法”）

4. 整体概括

这段话的核心在于，海德格尔将“本真地向死存在”确立为一个核心的哲学问题。他不仅仅是指出有这样一种人生态度，更是要刨根问底：一个人究竟凭什么能够以这种本真的方式面对死亡？这要求我们超越表面的生活现象，去探寻使这种深刻生存方式成为可能的、关于人本身存在结构的那些最根本条件，并且思考我们该如何去揭示和认识这些隐藏的条件。这段话就像一个研究计划的导言，指明了下一步哲学分析的方向和任务。

5. 争议与说明

本段是《存在与时间》中一个承上启下的过渡段落，其作用是明确后续分析的任务和目标，本身不包含复杂的论证或容易产生歧义的断言。因此，对于这段话的字面意思和意图，学界的解读是相对一致的，即公认它是在为接下来对“向死存在”的生存论结构进行详细分析做铺垫和设问。
