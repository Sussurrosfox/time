📖 《存在与时间》研读 逐段解析

📜 原文片段 (066/006)
海德格尔 原文
确知某一存在者，这等于说：把它作为真的存在者持以为真〔fur ahr halten〕。而真理意味着存在者的被揭示状态。一切被揭示状态在存在论上都基于源始的真理即此在的展开状态，此在作为展开了且开展着的和揭示着的存在者本质上就“在真〔理〕之中”。确知则基于真理或同样源始地隶属于真理。“确知”这个词同“真理”这个述语一样有双重含义。真理源始地等于说有所开展的，这是此在的一种作为〔Verhaltung〕。由此派生的含义意味着存在者的被揭示状态。与此相应，确知源始地意味着作为此在的存在方式那样的一种确知。而在派生的含义上，此在所能确知的存在者却也被称作某种“被确知的”或“确定的”存在者。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 真理：在海德格尔哲学中，真理的一般含义并非传统的“符合论”（命题与事实相符），而是存在者的被揭示状态。源始的真理是此在的展开状态，即此在通过其生存活动，让存在者如其所是地显现出来。派生的含义则指存在者被揭示后的结果状态。
  • 确知：源始含义是此在的一种存在方式，即此在在生存中“持以为真”的基本行为。派生的含义指存在者被确知后的属性（“被确知的”或“确定的”）。
  • 此在：指人的存在方式，其本质是“去存在”，即以理解、开展、揭示的方式在世。
  • 展开状态：此在通过操心、理解、现身情态等，使世界和自身得以敞开和显现的基本境域。
  • 被揭示状态：存在者在此在的展开活动中得以去除遮蔽、显现自身的状态。

2. 逐句转译

  • “确知某一存在者，这等于说：把它作为真的存在者持以为真〔fur ahr halten〕。”
    → 当我们说“确知”某个东西时，意思就是我们把它当作真实存在的东西来相信和认定。

  • “而真理意味着存在者的被揭示状态。”
    → 而“真理”在这里的意思，是事物（存在者）被我们从遮蔽状态中打开、显现出来。

  • “一切被揭示状态在存在论上都基于源始的真理即此在的展开状态，此在作为展开了且开展着的和揭示着的存在者本质上就‘在真〔理〕之中’。”
    → 所有事物能够被揭示，其根本基础在于一种最原初的真理——那就是人（此在）自身就是一种“展开”的状态。人天然就是开放的、不断开展世界并揭示事物的存在者，所以人本质上就“生活在真理之中”。

  • “确知则基于真理或同样源始地隶属于真理。”
    → 因此，“确知”这种行为，要么是以真理为基础，要么它本身就和真理一样源始，属于真理的一部分。

  • “‘确知’这个词同‘真理’这个述语一样有双重含义。”
    → “确知”这个词和“真理”一样，都有两层意思。

  • “真理源始地等于说有所开展的，这是此在的一种作为〔Verhaltung〕。”
    → 真理最根本的意思是指一种“开展”的活动，这是此在（人）的一种存在方式或行为。

  • “由此派生的含义意味着存在者的被揭示状态。”
    → 从那个源始含义派生出来的意思，才是指事物被揭示出来的状态。

  • “与此相应，确知源始地意味着作为此在的存在方式那样的一种确知。”
    → 与此对应，“确知”最根本的意思也是指此在（人）的一种存在方式，即人主动去确知的行为。

  • “而在派生的含义上，此在所能确知的存在者却也被称作某种‘被确知的’或‘确定的’存在者。”
    → 而在派生出来的意思上，那些被人确知了的事物，也被我们说成是“被确知的”或“确定的”东西。

3. 论证逻辑梳理

  • 前提：从“确知某一存在者”这一日常经验出发，将其定义为“持以为真”。
  • 核心转换：将“真理”重新定义为“存在者的被揭示状态”，从而将认识论问题（确知）引向存在论基础（揭示）。
  • 奠基关系：论证一切“被揭示状态”（派生的真理）都植根于“此在的展开状态”（源始的真理）。此在因其本质是展开的、揭示着的，故本质上“在真理之中”。
  • 概念对应：指出“确知”与“真理”具有平行的双重结构：
  • 源始层：真理是此在的开展活动；确知是此在的存在方式。
  • 派生层：真理是存在者的被揭示状态；确知是存在者的被确知属性。
  • 结论：确知的行为（认识）并非独立，而是隶属于或基于此在在世的揭示活动（存在）。

4. 整体概括

这段话的核心在于，将我们通常认为的“确知”（认识一个东西为真）和“真理”（事物的真实状态）彻底地拉回到人的生存活动之中来理解。海德格尔认为，真理最根本的意思不是静态的“符合”或“正确”，而是人（此在）在其生存中不断地“开展”和“揭示”世界的活动。正因为人天生就是这种开放的、揭示着的存在，事物才能被揭示出来，呈现在我们面前（派生的真理）。同样，“确知”也不是一个孤立的认识行为，它要么是基于这种源始的揭示活动，要么它本身就是此在揭示世界的一种方式。因此，无论是真理还是确知，其源头都在于此在的生存本身，认识论是以存在论为基础的。

5. 争议与说明

本段解读相对一致，是海德格尔真理观的核心表述。可能的细微争议点在于对“同样源始地隶属于真理”中“同样源始”的理解：有学者强调确知作为此在的存在方式，与真理（展开状态）是同一活动的不同侧面，本就是一体；另一些解读则稍弱一些，认为确知虽源始，但仍是在真理（展开状态）所开辟的境域中发生的。但整体上，对于海德格尔将真理和认识奠基于此在的展开状态，学界并无根本分歧。
