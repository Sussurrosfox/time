📜 原文片段 (066/008)
海德格尔 原文
持以为真是否敷用要以它隶属于其下的真理的要求来衡量。真理的要求则从有待开展的存在者方面与开展活动的方向方面获得它的权利。随着存在者的种种不同，按照开展活动的主导倾向与广度，真理的方式，从而还有确知的方式就有所变化。眼下的考察还始终局限于对确知死亡的分析，而这种确知最终会表现为一种别具一格的对此在之确知。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 持以为真：一般指我们对某事物“认定它为真”或“信以为真”的状态，强调的是一种认知上的确信。
  • 真理：在海德格尔这里，真理不是符合论意义上的“与事实相符”，而是“去蔽”或“揭示”——让存在者如其所是地显现出来。
  • 开展活动：指的是此在对存在的理解和揭示过程，此在通过生存活动使存在者的意义得以展开。
  • 确知：一种基于生存理解的、有坚实基础的“知道”，不是单纯心理上的相信，而是此在对自身或世界的一种通透把握。
  • 此在：指人的存在，是一种能够发问并理解自身存在的存在者。

2. 逐句转译

  • “持以为真是否敷用要以它隶属于其下的真理的要求来衡量。”

  • 我们判断一个“信以为真”的状态是否够格、是否充分，要看它是否符合“真理”本身提出的标准。

  • “真理的要求则从有待开展的存在者方面与开展活动的方向方面获得它的权利。”

  • “真理”所提出的标准，其正当性来自两个方面：一方面是那个等待被揭示的存在者本身的特点，另一方面是我们去揭示它的方式和方向。

  • “随着存在者的种种不同，按照开展活动的主导倾向与广度，真理的方式，从而还有确知的方式就有所变化。”

  • 因为存在者各不相同，再加上我们揭示它的主要方式和范围也不同，所以“真理”显现的方式就会不一样，相应地，我们“确知”某物的方式也会随之改变。

  • “眼下的考察还始终局限于对确知死亡的分析，而这种确知最终会表现为一种别具一格的对此在之确知。”

  • 目前我们的讨论还只集中在分析“对死亡的确知”上，而这种对死亡的独特确知，最终会显示出它是一种非常特别的、对此在自身存在的确知。

3. 论证逻辑梳理

  1. 前提：存在一个判断“持以为真”是否充分的标准，这个标准来自“真理”本身。
  2. 推进一：阐明“真理”的标准并非凭空而来，而是由“有待揭示的存在者”和“我们如何去揭示它”共同决定的。这意味着真理是情境化的、关系性的。
  3. 推进二：基于上述关系，进一步推论：由于存在者千差万别，我们的揭示活动（开展活动）也各有侧重和范围，因此，“真理”的具体形态和与之对应的“确知”形态必然是多种多样的，不是一成不变的。
  4. 结论/定位：最后将这一普遍原理落实到当前的具体任务上：我们现在正在分析的“对死亡的确知”，就是这种多样性中的一个特例，它是一种独特的、指向此在自身存在的确知方式。

4. 整体概括

这段话的核心是在说明，我们判断一个“信以为真”是否靠谱，标准在于它是否符合“真理”的要求，而真理的要求又取决于被认识的对象（存在者）和我们认识它的方式（开展活动）。因此，不同的认识对象和认识方式，会导致不同形态的真理和不同形态的确知。海德格尔以此为依据，将他正在进行的“对死亡的确知”分析，定位为探索一种特殊的、关于人自身存在的确知方式，从而为后面的具体分析奠定了方法论基础。

5. 争议与说明

本段内容主要是方法论上的铺垫，将真理与确知置于存在论和生存论的动态关系中理解，这一基本框架在学界解读相对一致。可能的细微争议点在于对“真理的要求”和“开展活动的方向”之间关系的具体界定，但这段文字本身并未深入这一细节，因此不存在广为人知的重大争议。
