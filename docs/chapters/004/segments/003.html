📖 《存在与时间》研读 逐段解析
首页 / 第 004 章 / 片段 003
📜 原文片段 (004/003)
海德格尔 原文
我们的时代虽把重新肯定“形而上学”当作自己的进步，但这里所提的问题如今已久被遗忘了。人们认为自己无须努力来重新展开巨人们关于存在的争论。然而，这里提出的问题却绝不是随随便便的问题。它曾使柏拉图和亚里士多德为之思殚力竭。当然，从那以后，它作为实际探索的专门课题，就无人问津了。这两位这人赢得的东西，以各式各样的偏离和“润色”一直保持到黑格尔的“逻辑学”之中。曾经以思的至高努力从现象那里争得的东西，虽说是那么零碎那么初级，早已被弄得琐屑不足道了。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 形而上学：在海德格尔哲学中，这首先指传统哲学对“存在者之存在”的追问方式，但在他看来，这种传统形而上学恰恰遗忘了“存在本身”的问题，而沉溺于对存在者的研究。在本段中，“重新肯定形而上学”指的是当时哲学界（如新康德主义等）自认为在复兴形而上学传统，但海德格尔认为他们并未触及真正核心的“存在”问题。
  • 存在：这不是指具体某个东西“存在”的事实，而是指使一切存在者得以成为存在者的那个根本条件或显现过程。海德格尔认为，柏拉图、亚里士多德曾真正挣扎于这个问题，但后世哲学却逐渐遗忘了它。
  • 思：不是指一般意义上的思考，而是特指对“存在”问题进行深刻探询的哲学活动，是一种全力以赴的“追问”和“开显”的努力。

2. 逐句转译

  • “我们的时代虽把重新肯定‘形而上学’当作自己的进步，但这里所提的问题如今已久被遗忘了。”
    → 我们这个时代，哲学界自以为复兴形而上学是一大进步，但其实他们完全忽略了我（海德格尔）在这里要探讨的那个真正关键的问题。

  • “人们认为自己无须努力来重新展开巨人们关于存在的争论。”
    → 大家觉得没必要再费力气去重新探讨像柏拉图和亚里士多德那样的哲学巨匠曾经激烈争论过的“存在”问题了。

  • “然而，这里提出的问题却绝不是随随便便的问题。”
    → 但我现在提出的这个问题，绝对不是个可有可无的小问题。

  • “它曾使柏拉图和亚里士多德为之思殚力竭。”
    → 当年，这个问题曾让柏拉图和亚里士多德绞尽脑汁、耗尽心力。

  • “当然，从那以后，它作为实际探索的专门课题，就无人问津了。”
    → 可惜，自他们之后，就再没有人真正把它当作一个需要认真研究的核心课题了。

  • “这两位哲人赢得的东西，以各式各样的偏离和‘润色’一直保持到黑格尔的‘逻辑学’之中。”
    → 柏拉图和亚里士多德当年关于“存在”所取得的一些洞见，后来被历代哲学家（直到黑格尔）不断曲解、修饰，表面上好像传承下来了，但其实已经变了味。

  • “曾经以思的至高努力从现象那里争得的东西，虽说是那么零碎那么初级，早已被弄得琐屑不足道了。”
    → 先哲们费尽心血从现实（现象）中艰难提炼出的那些关于存在的理解，哪怕还只是些不完整、不成熟的片段，也早已被后人庸俗化，当成无关紧要的东西了。

3. 论证逻辑梳理

  1. 前提：当代哲学界自以为在推进形而上学，表现出一种“进步”的自我认知。
  2. 转折与批判：但海德格尔指出，这种“进步”是虚假的，因为他们遗忘了一个根本问题——即“存在”问题。
  3. 历史追溯与对比： - 这个问题曾经是柏拉图和亚里士多德哲学思考的核心，他们为此付出了巨大努力。 - 但自他们之后，这个问题就不再被当作真正的课题。
  4. 揭示传承中的变异： - 柏拉图和亚里士多德的成果在后世（直至黑格尔）的传承中，被不断“偏离”和“润色”，实质是被遮蔽和曲解。
  5. 结论性评价： - 先哲们辛苦得来的成果，即使是初步的、不完整的，也在后世变得琐碎不堪，失去了原有的分量。

4. 整体概括

这段文字是海德格尔对当时哲学界的尖锐批评。他指出，虽然大家自以为在复兴形而上学，但其实已经完全遗忘了哲学最根本的问题——“存在”问题。这个问题曾经让柏拉图和亚里士多德耗尽心血，但后世哲学家不但没有继续深入探索，反而把他们那点珍贵的、尚且不完整的思考，通过不断的曲解和庸俗化，变得无足轻重。海德格尔在此实际上是呼吁：我们必须回到那个被遗忘的根本问题上去。

5. 争议与说明

  • 主流解读：这段通常被解读为海德格尔对西方形而上学史的“遗忘存在”这一核心诊断的开篇宣告。他强调哲学在根源上就发生了“存在的遗忘”，后世哲学（包括他同时代的新康德主义等）都是在一种无根的状态下从事研究。
  • 可能的争议点：
  • 对“巨人们关于存在的争论”的具体所指：有学者认为海德格尔可能过度解读或简化了柏拉图和亚里士多德的思想，将他们统一纳入“存在之思”的框架，而忽略了他们之间的重大差异。
  • 对哲学史处理的公允性：海德格尔这种“回溯原点以批判后世”的笔法，有时被认为是为了构建他自己的哲学叙事而“厚古薄今”，对亚里士多德之后直至黑格尔的哲学传统评价过低，存在一定的片面性。

总的来说，本段在海德格尔思想体系中的定位是清晰且无太大争议的，但其对哲学史的具体论断则一直是学界讨论和审视的焦点。
