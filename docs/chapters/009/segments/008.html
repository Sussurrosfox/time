海德格尔 原文
于是，此在的分析工作必须保持为存在问题中的第一要求。然而，赢得并确保通达此在的主导方式这一问题就因而愈发焦灼。用否定的方式说：不允许把任何随意的存在观念与现实观念纯凭虚构和教条安到这种存在者头上，无论这些观念是多么“不言而喻”；同时，也不允许未经存在论考察就把用这类观念先行描绘出来的“范畴”强加于此在。毋宁说，我们所选择那样一种通达此在和解释此在的方式必须使这种存在者能够在其本身从其本身显示出来。也就是说，这类方式应当像此在首先与通常所是的那样显示这个存在者，应当在此在的平均的日常状态中显示这个存在者。我们就日常状态提供出来的东西不应是某些任意的偶然的结构，而应是本质的结构；无论实际上的此在处于何种存在方式，这些结构都应保持其为规定着此在存在的结构。从此在的日常状态的基本建构着眼，我们就可以循序渐进，着手准备性地端出这种存在者的存在来。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学的核心概念，特指“人”这种存在者。它不是泛指一般意义上的“人”，而是指能够发问、关心自身存在、并以“在世之中”的方式存在的存在者。此在的存在方式就是“生存”。
  • 存在问题：指对“存在本身的意义”进行追问的根本哲学问题。海德格尔认为，传统形而上学遗忘了这个问题，他的工作就是要重新提出并回答它。
  • 存在论：哲学的一个分支，探究“存在者之存在”的学问。海德格尔要做的是“基础存在论”，即以此在的分析为基础，来解答一般存在的意义问题。
  • 日常状态：此在最常见、最普通的存在方式。这不是指具体的生活内容，而是此在沉沦于世界、与他人共在、并逃避自身本真可能性的平均化生存模式。
  • 范畴：传统哲学（如亚里士多德、康德）中用来规定存在者的普遍概念（如实体、属性、因果等）。海德格尔认为，这些范畴不适合用来理解此在的生存性结构。

2. 逐句转译

  • “于是，此在的分析工作必须保持为存在问题中的第一要求。”
  • 所以，对“此在”（人这种存在者）的分析，必须是研究“存在”这个根本问题的首要任务和最基础的工作。
  • “然而，赢得并确保通达此在的主导方式这一问题就因而愈发焦灼。”
  • 但是，这样一来，我们究竟应该通过什么正确的方法来接触和理解此在，这个问题就变得更加紧迫和关键了。
  • “用否定的方式说：不允许把任何随意的存在观念与现实观念纯凭虚构和教条安到这种存在者头上，无论这些观念是多么‘不言而喻’；”
  • 从反面来说，我们不能凭着想象或者死板的教条，就把那些随随便便关于“存在”和“现实”的看法（比如传统哲学里的那些概念）强加给此在，哪怕这些看法看起来好像非常“理所当然”。
  • “同时，也不允许未经存在论考察就把用这类观念先行描绘出来的‘范畴’强加于此在。”
  • 同时，也不能在没有经过严格的存在论审查之前，就把那些由传统观念预先设定好的“范畴”（比如主体、客体、实体等概念）硬套在此在头上。
  • “毋宁说，我们所选择那样一种通达此在和解释此在的方式必须使这种存在者能够在其本身从其本身显示出来。”
  • 正确的做法应该是：我们选择和采用的接触、解释此在的方法，必须能够让此在自己从它自身出发，如其所是地把自己显现出来。
  • “也就是说，这类方式应当像此在首先与通常所是的那样显示这个存在者，应当在此在的平均的日常状态中显示这个存在者。”
  • 换句话说，这种方法要能显示出此在最开始、最通常是什么样子的，要在它那种平均化的、日常的生活状态中把它呈现出来。
  • “我们就日常状态提供出来的东西不应是某些任意的偶然的结构，而应是本质的结构；”
  • 我们从日常状态中揭示出来的，不能是随便碰巧出现的、表面的结构，而必须是那些构成其存在根基的、本质性的结构。
  • “无论实际上的此在处于何种存在方式，这些结构都应保持其为规定着此在存在的结构。”
  • 无论此在现实中表现出什么样的具体状态，这些本质结构都始终是规定着此在之所以如此存在的根本框架。
  • “从此在的日常状态的基本建构着眼，我们就可以循序渐进，着手准备性地端出这种存在者的存在来。”
  • 所以，只要我们抓住了此在日常状态的基本构造，我们就可以一步一步地、先做预备性的工作，最终把此在的“存在”本身揭示出来。

3. 论证逻辑梳理

  • 前提：解决“存在问题”必须从分析“此在”入手（因为此是唯一能追问存在的存在者）。
  • 核心问题提出：因此，如何正确地“通达”（接触和理解）此在就成了一个至关重要且紧迫的方法论问题。
  • 否定性划定（方法论禁令）：
  • 不能将传统或常识的、未经审查的存在观念（如主体、实体）直接套用在此在上。
  • 不能将基于这些观念的“范畴”先入为主地强加于此在。
  • 肯定性方法论原则确立：
  • 方法必须让此在“从自身显示自身”，即现象学原则——“面向事情本身”。
  • 具体路径是：从此在最常见、最平均的“日常状态”入手。
  • 对“日常状态”分析的要求：
  • 要从中提取出“本质结构”，而非偶然特征。
  • 这些本质结构是此在无论以何种方式存在都具备的、规定性的结构。
  • 结论与展望：
  • 通过分析日常状态的基本建构，我们能为最终揭示此在的“存在”意义做好预备工作。

4. 整体概括

这段话的核心是确立分析“此在”的方法论原则。海德格尔强调，要解答“存在”问题，必须先研究“此在”。但研究的方法至关重要，绝不能把传统哲学里那些看似不证自明的概念（如主体、实体）直接套在人身上。正确的方法是“让事物自身显示自身”，具体来说，就是要回到人最普通、最常见的日常生活状态中去观察和分析。我们要从这种日常状态里，找出那些最根本、最决定人之所以为人的生存结构（而不是表面的生活琐事）。只有通过这条路径，我们才能为最终理解“存在”的意义打下坚实的基础。简言之，这是在为哲学研究立下一个新规矩：要理解人，必须放下成见，回到人最本真的日常生存现场。

5. 争议与说明

本段解读相对一致。核心方法论——“面向事情本身”的现象学原则，以及从此在的“日常状态”入手进行分析的路径，是海德格尔在《存在与时间》中明确确立的，争议不大。可能的细微讨论点在于对“日常状态”与“本真状态”关系的不同侧重，但这在本段作为方法论奠基的文字中尚未展开，因此不属于本段的核心争议。
