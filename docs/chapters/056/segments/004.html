📖 《存在与时间》研读 逐段解析

📜 原文片段 (056/004)
海德格尔 原文
这里所谓“关于‘真理’的研究”或“真理”的科学意味着什么？在这种研究中，“真理”是在认识理论或判断理论上的意义上成为课题的吗？显然不是；因为“真理”所意味的和“事情”、“自己显示着的东西”是一样的。如果“真理”这个词是用来指“存在者”和“存在”的术语，那么这个词究竟意味着什么呢？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 真理：在海德格尔哲学中，“真理”并非指传统的“符合论”真理观（即判断与对象相符），而是指存在者的自我显现或无蔽状态。真理的本质是“让存在者如其所是地显现自身”。
  • 认识理论/判断理论：指传统哲学中基于主客二分、强调主体对客正确再现的认识论框架。海德格尔明确反对将真理问题局限于此。
  • 存在者：泛指一切“存在着的东西”，包括物体、人、事件等具体或抽象的对象。
  • 存在：海德格尔的核心概念，指使存在者得以成为存在者的那个“生成显现”的过程或条件，强调动态的“在场”与“开显”。

2. 逐句转译

  1. “这里所谓‘关于真理的研究’或‘真理’的科学意味着什么？”
    海德格尔首先提问：当我们说研究“真理”、甚至把真理当作一门科学时，我们到底在研究什么？

  2. “在这种研究中，‘真理’是在认识理论或判断理论上的意义上成为课题的吗？”
    他进一步追问：这种研究是把“真理”放在传统认识论或逻辑学（即讨论“判断是否正确”）的框架下探讨的吗？

  3. “显然不是；因为‘真理’所意味的和‘事情’、‘自己显示着的东西’是一样的。”
    他立刻否定：当然不是。因为“真理”在这里的真实含义，其实就是指“事物本身”或“那自行显现出来的东西”。

  4. “如果‘真理’这个词是用来指‘存在者’和‘存在’的术语，那么这个词究竟意味着什么呢？”
    他进一步推进问题：如果我们用“真理”一词来指代“存在者”和“存在”本身，那么这个术语到底在说什么？

3. 论证逻辑梳理

  • 前提：提出一个关于“真理研究”本质的疑问。
  • 推进一：通过设问排除一种常见误解——即将真理问题窄化为认识论或判断理论的问题。
  • 推进二：正面给出海德格尔的立场——真理的本质是事物的“自我显现”。
  • 推进三：将真理与“存在者/存在”直接关联，从而把真理问题引向存在论领域，为后续探讨奠基。
  • 结论：真理不应在认识论中寻找，而应在存在者的“自我开显”与存在的“显现方式”中探寻。

4. 整体概括

这段话是海德格尔对“真理”概念的存在论转向宣言。他明确指出，真理问题不能还原为“判断是否符合对象”的传统认识论问题，而应回到更本源的现象——即事物自身的显现。真理就是“那自己显示出来的东西”，它与“存在者何以存在”以及“存在如何开显”直接相关。海德格尔借此将真理从知识论领域连根拔起，重新植入存在论的土壤。

5. 争议与说明

本段解读相对一致，学界普遍认同这是海德格尔对传统真理观的明确切割，并转向存在论真理观的关键段落。若有争议，主要在于“真理即无蔽”是否完全摆脱了符合论的影子（例如后期德里达的质疑），但就本段而言，其批判意图与存在论转向是清晰无疑的。
