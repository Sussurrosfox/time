📖 《存在与时间》研读 逐段解析

📜 原文片段 (056/061)
海德格尔 原文
所以，人们在提出真理的存在问题和把真理设为前提的必然性问题的时候，就像在提出认识的本质问题时一样，其实一着手就假设了一个“理想主体”。这种作法的或言明或未言明的动机在于这样一种要求：哲学的课题是“先天性”〔Aprori〕，而不是“经验事实”本身。这个要求有些道理，不过还需先奠定它的存在论基础。再则，假设一个“理想主体”就满足了这一要求吗？这个理想主体不是一个甲匆捍加以理想化的主体吗？这样一个主体概念不会恰恰把那个仅仅是“事实上的”主体的先天性，亦即此在的先天性，交臂失之吗？实际主体或此在同样源始地在真理和不真中；这一规定性不属于实际主体或此在的先天吗？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 真理的存在问题：指追问“真理本身是什么”，即真理的本质和其存在方式为何。在海德格尔哲学中，真理并非单纯的命题与事实的符合，而是与此在的展开状态密切相关。
  • 理想主体：传统哲学（如笛卡尔、康德哲学）中预设的一个抽象、纯粹、无时间性的认知主体，它被假定为具有先验的认知结构，不受具体历史、经验条件的影响。
  • 先天性 (Apriori)：指先于经验、使经验成为可能的条件或结构。在海德格尔这里，先天性并非纯粹逻辑形式，而是与此在的存在结构（生存论结构）相关。
  • 此在 (Dasein)：海德格尔哲学的核心概念，指“人”这种存在者，其本质在于“去存在”（Zu-sein），即以理解、筹划、关怀的方式在世界之中存在。此在是真理得以揭示的场所。
  • 真理和不真：真理在此指存在者的无蔽状态（aletheia），不真则指存在者的遮蔽或伪装状态。此在既能让存在者如其所是地显现，也可能沉沦于日常而遮蔽存在者的本真面目。

2. 逐句转译

  1. “所以，人们在提出真理的存在问题和把真理设为前提的必然性问题的时候，就像在提出认识的本质问题时一样，其实一着手就假设了一个‘理想主体’。”
    → 所以，当我们追问“真理是什么”以及“为什么我们必须预设真理”这类问题的时候，其实从一开始，就已经暗中设定了一个完美的、抽象的认知主体，就像我们探讨“认识如何可能”时也会做的那样。

  2. “这种作法的或言明或未言明的动机在于这样一种要求：哲学的课题是‘先天性’，而不是‘经验事实’本身。”
    → 这种做法（不管是明确说出来还是隐含的）背后的动机是：哲学要研究的应该是那种先于经验、使经验成为可能的条件（先天性），而不是具体琐碎的经验事实。

  3. “这个要求有些道理，不过还需先奠定它的存在论基础。”
    → 这个要求本身是有合理性的，但问题在于，我们得先弄清楚它的存在论根基——也就是说，要追问这种“先天性”本身的存在方式是什么。

  4. “再则，假设一个‘理想主体’就满足了这一要求吗？这个理想主体不是一个甲匆捍加以理想化的主体吗？”
    → 但是，仅仅设定一个“理想主体”真的能满足这个要求吗？这个理想主体难道不就是一个被我们随意抽象、美化出来的虚构物吗？

  5. “这样一个主体概念不会恰恰把那个仅仅是‘事实上的’主体的先天性，亦即此在的先天性，交臂失之吗？”
    → 这样一个理想主体的概念，会不会反而让我们错过了那个活生生的、具体存在的主体（此在）本身所具有的先天性——也就是此在的存在结构？

  6. “实际主体或此在同样源始地在真理和不真中；这一规定性不属于实际主体或此在的先天吗？”
    → 实际上，真实的主体（此在）从一开始就同时处于真理（无蔽）和不真（遮蔽）的状态中。这种既揭示又遮蔽的双重性，难道不正是此在的先天结构的一部分吗？

3. 论证逻辑梳理

  • 前提：传统哲学在探讨真理与认识问题时，不自觉地预设了一个脱离具体生存的“理想主体”，其动机是为了把握“先天性”（先于经验的条件）。
  • 推进1：海德格尔承认对“先天性”的追求是合理的，但指出其前提（理想主体）未经存在论奠基，即未追问“先天性”本身的存在方式。
  • 推进2：质疑“理想主体”这一预设的有效性，指出它是对真实主体的抽象化，反而可能遮蔽了真实主体（此在）的先天性。
  • 推进3：提出此在的先天结构正在于它“同样源始地在真理和不真中”，即真理与遮蔽是此在生存的根本结构。
  • 结论：真正的“先天性”应扎根于此在的存在方式，而非一个虚构的理想主体；此在的真理与不真双重性本身就是其先天规定。

4. 整体概括

这段话的核心是批判传统哲学对“理想主体”的预设。海德格尔指出，传统哲学为了追求“先天性”（先于经验的条件），虚构了一个抽象、完美的认知主体，但这恰恰忽略了真实主体——此在——的存在结构。此在并非纯粹的认知机器，而是活生生地处于世界之中，既揭示真理又陷入遮蔽。这种“在真理与不真中”的双重性，才是此在真正的先天结构。因此，哲学要把握真理的先天性，必须回到此在的生存论分析，而不是依赖一个虚构的理想主体。

5. 争议与说明

本段解读相对一致。争议点可能在于：
- 海德格尔对“理想主体”的批判是否完全否定了先验哲学（如康德）的价值？有学者认为海德格尔并非全盘否定，而是试图将先验问题“生存论化”；
- “此在在真理和不真中”的“源始性”如何理解？有解读强调这是存在论层次的结构，而非伦理学上的“对错”问题。
