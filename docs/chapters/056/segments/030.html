📖 《存在与时间》研读 逐段解析
首页 / 第 056 章 / 片段 030
📜 原文片段 (056/030)
海德格尔 原文
揭示活动是在世的一种方式，寻视着的操劳或甚至逗留着观望的操劳都揭示着世内存在者。世内存在者成为被揭示的东西，只在第二位意义上它才是“真的”。原本就“真”的，亦即进行揭示的，乃是此在。第二位意义上的真说的不是进行揭示的存在〔揭示〕，而是被揭示的存在〔被揭示状态〕。前面对世界之所以为世界的分析及对世内存在者的分析曾指出二世内存在者的揭示状态奠基于世界的展开状态。而展开状态是此在的基本方式，此在以这种方式是它的此。展开状态是由现身、领会和话语来规定的。它同样源始地涉及世界、在之中和自身。操心的结构是先行于自身的一已经在一世界中的一作为寓于世内存在者的存在。操心的这种结构包含着此在的展开状态于自身。随着这种开展状态并通过这种展开状态才有被揭示状态；所以只有通过此在的展开状态才能达到最源始的真理现象。前文就此的生存论建构方面和此的日常存在方面指示出来的东西，涉及的恰恰就是它的展开状态。只要此在作为展开的此在开展着、揭示着，那么，它本质上就是“真的”。此在“在真理中”。这一命题具有存在论意义。它不是说：在存在者层次上，此在一向或有那么一次被引进了“全真境界”；而是说：此在的最本己的存在的展开状态属于它的生存论结构。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 揭示活动：指此在对世界或存在者的“去蔽”或“使其显现”的过程。它不是客观认知，而是此在在世的一种基本存在方式。
  • 此在：海德格尔用以指称“人”的存在者，其本质在于“去存在”，能够领会自身的存在并关心自己的存在方式。
  • 展开状态：此在的基本生存结构，指此在对其世界、自身及在世整体的开放性和通透性。由“现身”“领会”“话语”三个环节构成。
  • 真理：在海德格尔这里，真理的本义是“无蔽”，是存在者被此在揭示而显现出来的状态。最源始的真理是此在的展开状态本身。
  • 操心：此在的整体存在结构，即“先行于自身—已经在世界之中—作为寓于世内存在者的存在”。它概括了此在生存的整体方式。

2. 逐句转译

  • “揭示活动是在世的一种方式，寻视着的操劳或甚至逗留着观望的操劳都揭示着世内存在者。”

  • 我们与世界打交道的方式，无论是日常忙碌中的关注，还是停下来仔细打量，都是一种让事物显现出来的活动。

  • “世内存在者成为被揭示的东西，只在第二位意义上它才是‘真的’。原本就‘真’的，亦即进行揭示的，乃是此在。”

  • 我们周围的事物之所以能被称为“真的”，是因为它们被我们揭示出来了。但真正源头上的“真”，是那个正在做揭示活动的“我们”（此在）。

  • “第二位意义上的真说的不是进行揭示的存在〔揭示〕，而是被揭示的存在〔被揭示状态〕。”

  • 所谓第二位的真，不是说揭示这个动作本身，而是说事物被揭示出来的那种状态。

  • “前面对世界之所以为世界的分析及对世内存在者的分析曾指出：世内存在者的揭示状态奠基于世界的展开状态。”

  • 之前我们分析过，事物之所以能被我们揭示，是因为我们的世界整体对我们来说是开放的、可理解的（世界的展开状态）。

  • “而展开状态是此在的基本方式，此在以这种方式是它的此。”

  • 这种“展开状态”是我们（此在）的基本生存方式，我们正是以这种方式活在世界上，成为“此”（一个具体的位置和情境）。

  • “展开状态是由现身、领会和话语来规定的。它同样源始地涉及世界、在之中和自身。”

  • 这种展开状态是由我们的情绪感受（现身）、理解能力（领会）和言谈交流（话语）共同构成的。它从一开始就同时关系到我们所处的世界、我们在世界中的状态，以及我们自身。

  • “操心的结构是先行于自身的一已经在一世界中的一作为寓于世内存在者的存在。操心的这种结构包含着此在的展开状态于自身。”

  • 我们整个存在的结构（操心）可以概括为：总是在筹划未来（先行于自身）、已经处在某个情境中（已经在世界中）、并与各种事物打交道（寓于世内存在者）。这个结构本身就包含着我们的展开状态。

  • “随着这种开展状态并通过这种展开状态才有被揭示状态；所以只有通过此在的展开状态才能达到最源始的真理现象。”

  • 正是因为我们（此在）是开放的、展开的，事物才能被我们揭示。所以，最根本意义上的“真理”，其实就是我们这种展开状态本身。

  • “前文就此的生存论建构方面和此的日常存在方面指示出来的东西，涉及的恰恰就是它的展开状态。”

  • 之前从我们的生存结构和日常状态所做的分析，谈的其实就是这种展开状态。

  • “只要此在作为展开的此在开展着、揭示着，那么，它本质上就是‘真的’。此在‘在真理中’。”

  • 只要我们（此在）是以这种开放的、揭示着的方式存在，那么我们本质上就是“真的”。我们就“处在真理之中”。

  • “这一命题具有存在论意义。它不是说：在存在者层次上，此在一向或有那么一次被引进了‘全真境界’；而是说：此在的最本己的存在的展开状态属于它的生存论结构。”

  • 这句话是存在论层面的论断。它的意思不是说我们某一天突然进入了某个完美无缺的“真理天堂”，而是说，这种能够展开、能够揭示的状态，就是我们（此在）最根本的生存结构的一部分。

3. 论证逻辑梳理

  • 前提1：揭示活动是此在在世的基本方式。
  • 前提2：世内存在者的被揭示状态（第二位的“真”）依赖于世界的展开状态。
  • 前提3：世界的展开状态是此在的基本生存方式，由现身、领会和话语构成，并包含在操心的整体结构之中。
  • 推进1：从“存在者被揭示”回溯到“世界的展开状态”，再追溯到“此在的展开状态”。
  • 推进2：论证被揭示状态（真理）的源头在于此在的展开状态本身。
  • 结论：此在本质上就是“真的”，此在“在真理中”。这不是一个偶然达到的状态，而是此在最本己的生存论结构。

4. 整体概括

这段话的核心论点是：真理的源头不在于客观事物与陈述的符合，而在于人（此在）本身的存在方式。我们日常生活中认为的“真”（比如这个东西是桌子），是因为它被我们揭示出来了。但更根本的“真”，是我们这种能够去理解、去感受、去言说，从而让事物得以显现的开放状态（展开状态）。这种状态不是我们偶尔获得的，它就是我们生存结构的一部分。因此，海德格尔说“此在在真理中”，意味着人本质上就是一种“去蔽”的、让真理得以发生的存在者。

5. 争议与说明

本段解读相对一致。海德格尔将真理从传统的“符合论”（判断与对象一致）扭转为“存在论的无蔽”，强调此在的展开状态是真理得以可能的源始条件，这一核心观点在学界是公认的。可能的讨论点在于对“展开状态”的具体构成（现身、领会、话语）及其相互关系存在更精细的哲学辨析，但就本段主旨而言，并无根本性争议。
