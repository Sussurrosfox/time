📖 《存在与时间》研读 逐段解析
首页 / 第 056 章 / 片段 003
📜 原文片段 (056/003)
海德格尔 原文
哲学自古把真理与存在相提并论。巴门尼德首次揭示了存在者的存在，这一揭示把存在同听取着存在的领会“同一”起来。亚里士多德在他的关于〔原理〕的发现史的纲要中强调说：在他之前的哲人是由“事情本身”所引导而不得不进行追问的。他还用这样的话来标识这一事实。他〔巴门尼德〕不得不追随那个依其自身显示出来的东西。在另一处他又说道：他们为“真理”本身所迫而进行研究。亚里士多德把这种研究活动称为：关于“真理”的“哲学活动”，有时也称为：鉴于“真理”并在“真理”范围之内展示给人看。哲学本身被规定为“真理”的科学。然而同时哲学又被标画为：考察存在者之为存在者的科学，也就是说，就存在者的存在来考察存在者的科学。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 真理：在海德格尔哲学中，“真理”并非指命题与事实相符的传统认识论概念，而是指存在者的无蔽状态。真理是存在者如其所是地显现自身的发生过程。
  • 存在：指使存在者得以成为存在者的那个基础或依据，它不是任何具体的存在者，而是存在者得以显现和可被理解的可能性条件。
  • 存在者：指一切具体、现成的事物或实体，例如桌子、人、观念等，它们是我们可以谈论和经验的对象。
  • 领会：此处的“领会”特指对存在的领会，即此在（人）对存在本身所具有的先于概念的理解，它是我们能够与存在者打交道的生存论前提。
  • 无蔽：是“真理”的希腊文（aletheia）原意，指存在者从隐藏状态中走出来，进入敞开领域，从而能够被我们遭遇和认识。

2. 逐句转译

  1. 原文：哲学自古把真理与存在相提并论。 转译：从哲学诞生之初开始，哲学家们就一直把“真理”和“存在”这两个概念放在一起讨论，认为它们密不可分。

  2. 原文：巴门尼德首次揭示了存在者的存在，这一揭示把存在同听取着存在的领会“同一”起来。 转译：巴门尼德是第一个明确指出“存在者的存在”的人。他的这个发现，意味着“存在”这个东西，和我们人能够“听”到并“领会”存在的能力，本质上是一回事。

  3. 原文：亚里士多德在他的关于〔原理〕的发现史的纲要中强调说：在他之前的哲人是由“事情本身”所引导而不得不进行追问的。 转译：亚里士多德在回顾哲学思想发展史时强调，他之前的哲学家们之所以不断追问，并不是出于主观意愿，而是被“事情本身”所驱动，不得不去探究。

  4. 原文：他还用这样的话来标识这一事实。他〔巴门尼德〕不得不追随那个依其自身显示出来的东西。 转译：亚里士多德用这样一句话来描述这个情况：巴门尼德是“被迫去追随那个凭借自身力量显现出来的东西”。

  5. 原文：在另一处他又说道：他们为“真理”本身所迫而进行研究。 转译：在别的地方，亚里士多德又说：这些哲学家是受到了“真理”本身的力量逼迫，才去从事研究工作的。

  6. 原文：亚里士多德把这种研究活动称为：关于“真理”的“哲学活动”，有时也称为：鉴于“真理”并在“真理”范围之内展示给人看。 转译：亚里士多德将这种研究活动称作是围绕“真理”展开的哲学活动；有时也说，这是在“真理”的光照下，并且在“真理”所划定的界限内，把事物展示给人看。

  7. 原文：哲学本身被规定为“真理”的科学。 转译：于是，哲学本身就被定义为一门关于“真理”的科学。

  8. 原文：然而同时哲学又被标画为：考察存在者之为存在者的科学，也就是说，就存在者的存在来考察存在者的科学。 转译：但同时，哲学也被描述为：研究“存在者之所以为存在者”的科学。换句话说，哲学是从事物的“存在”这个角度，来考察所有事物。

3. 论证逻辑梳理

  1. 前提与起点：海德格尔开篇立论，指出一个历史事实——哲学传统始终将“真理”与“存在”紧密关联。
  2. 历史证据一（巴门尼德）：他引用巴门尼德的贡献作为首个例证。巴门尼德揭示了“存在者的存在”，并且关键性地将“存在”与人对存在的“领会”等同起来。这初步建立了“真理”（作为无蔽的发生）与“存在”的内在联系，因为领会正是真理得以发生的场所。
  3. 历史证据二（亚里士多德）：接着，他通过亚里士多德的回顾，进一步强化这一观点。亚里士多德指出，早期哲学家的追问是被“事情本身”或“真理”所“迫使”的。这表明哲学活动不是主观随意的，而是对某种自行显现之物的响应和追随。
  4. 双重定义与结论：最后，基于上述历史梳理，海德格尔引出哲学的两个经典定义：一是“真理的科学”，二是“考察存在者之为存在者的科学”。他将这两个定义并列，旨在表明：在传统哲学中，研究真理与研究存在是一体两面的事情。因为研究存在者之为存在者，就是探究其存在；而探究存在，就是在真理（无蔽）的光照下让存在者显现出来。

4. 整体概括

这段话的核心意思是，海德格尔通过追溯哲学史（从巴门尼德到亚里士多德）向我们阐明：西方哲学从一开始就将“真理”和“存在”视为一枚硬币的两面。哲学家们从事哲学思考，并非出于个人兴趣，而是像被一种无形的力量（即“事情本身”或“真理”的自行显现）所驱动。因此，哲学被定义为关于“真理”的科学，同时也就意味着它是从“存在”的角度来考察万事万物的科学。海德格尔在此铺垫的是：传统哲学对真理的理解，根植于对存在的追问，而他本人将要重新审视这个传统的根基。

5. 争议与说明

本段是海德格尔对哲学史的释读，其解读本身存在一定的“创造性”。主要争议点在于：

  • 主流解读：海德格尔旨在揭示“存在-真理”问题在哲学开端处的原始统一性，为他后续批判传统形而上学遗忘“存在”问题做铺垫。他认为古希腊人（尤其是前苏格拉底哲人）对“真理”的理解是原发性的“无蔽”，而后世（特别是罗马拉丁化后）才逐渐僵化为“正确性”或“符合论”。
  • 其他解读与争议：一些哲学史家认为，海德格尔对巴门尼德和亚里士多德的解读带有强烈的“六经注我”色彩，他可能过度强调或曲解了原文（尤其是“同一”这个词），以服务于他自己的哲学计划。他笔下的古希腊哲学，某种程度上是他本人思想的“理想化投射”。但对于理解《存在与时间》自身的理论建构而言，这段历史回顾的逻辑是自洽且关键的。
