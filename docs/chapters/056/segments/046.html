📖 《存在与时间》研读 逐段解析
首页 / 第 056 章 / 片段 046
📜 原文片段 (056/046)
海德格尔 原文
被揭示状态是奠基于此在的展开状态的生存论现象。这种生存论现象现在变成了现成的属性，尽管它还包含着联系性质于自身。它作为现成属性折裂为一种现成关系。展开状态和对被揭示的存在者的有所揭示的存在这一意义上的真理变成了世内现成存在者之间的符合这一意义上的真理。我们以此指出了传统真理概念的存在论谱系。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 被揭示状态（Erschlossenheit）：指事物从其原本隐藏的状态中被开显出来，成为此在（人的存在）可以理解和把握的对象。这是此在展开世界的基本方式。
  • 此在（Dasein）：海德格尔对人的存在的专门称呼，指那种能够追问自身存在、并在世界中展开自身可能性的存在者。
  • 展开状态（Erschlossenheit）：此在通过理解、情绪和言谈等方式向世界开放，让自身和世界中的事物得以显现的基本生存结构。
  • 生存论现象（existenzial-ontologisches Phänomen）：从存在论角度对此在生存结构的描述，关注的是此在如何“去存在”的方式，而非具体事实。
  • 现成属性（Vorhandenheit）：指事物像摆在面前的客体那样具有固定、客观的属性，失去了与此在动态生存的联系。
  • 符合（Übereinstimmung）：传统真理观认为真理是陈述（或思想）与客观事实之间的对应关系。

2. 逐句转译

  1. “被揭示状态是奠基于此在的展开状态的生存论现象。”
    → 事物的“被揭示状态”，其根源在于人（此在）自身向世界开放、理解世界的生存结构。这是一种关于人之存在方式的描述。

  2. “这种生存论现象现在变成了现成的属性，尽管它还包含着联系性质于自身。”
    → 原本动态的、与人息息相关的揭示过程，现在却被视为事物本身具有的固定属性。尽管它内在仍然保留着与人的关联性，但这种关联被掩盖了。

  3. “它作为现成属性折裂为一种现成关系。”
    → 当它被当作现成属性后，就进一步分裂成了一种现成的、对象之间的关系（比如主体与客体之间的符合关系）。

  4. “展开状态和对被揭示的存在者的有所揭示的存在这一意义上的真理变成了世内现成存在者之间的符合这一意义上的真理。”
    → 于是，原本作为“此在展开世界并揭示事物”这种动态过程的真理，就蜕变成了“世界内部两个现成对象（比如我的陈述和外部事实）之间相互符合”这种静态的真理。

  5. “我们以此指出了传统真理概念的存在论谱系。”
    → 通过以上分析，我们实际上追溯了传统真理观念（即符合论真理观）在存在论上的起源和演变过程。

3. 论证逻辑梳理

  • 前提：真理最初的现象是“被揭示状态”，它根植于此在的“展开状态”（即人向世界开放的基本生存方式）。
  • 第一步转变：这个动态的、与人的生存息息相关的现象（生存论现象），被误解和固化，变成了事物本身具有的“现成属性”。
  • 第二步转变：这种现成属性进一步发生“折裂”，从一个统一的揭示过程，分裂为两个现成事物（如主体与客体、观念与对象）之间的关系。
  • 结论：于是，真理的本意（此在的揭示活动）就被遮蔽了，取而代之的是流俗的“符合论真理观”（真理即主客相符）。本段最终点明，这是在追溯传统真理观的“存在论谱系”。

4. 整体概括

这段话的核心是在解释，我们通常所理解的“真理”（即一个陈述与事实相符合）是怎么来的。海德格尔认为，真理的源头其实是人（此在）在世界上生活、与世界打交道时，让事物显现出来的那个动态过程（“被揭示状态”）。但是，在后来的哲学传统中，这个活生生的、与人紧密相连的过程被遗忘了，人们错误地把它看作事物本身固有的静态属性，然后又进一步把它分裂成“我的思想”和“外部事物”这两个现成东西之间的符合关系。所以，我们熟悉的“符合论真理观”，其实是真理原始含义的一种退化和扭曲。这段话就是在揭示这个被遗忘的起源和演变过程。

5. 争议与说明

本段解读相对一致。核心争议通常不在于对本段字面意思的理解，而在于对海德格尔所追溯的这个“谱系”的历史准确性和哲学价值的评价。有些哲学史家可能认为，海德格尔对传统真理观（尤其是亚里士多德）的谱系追溯是一种“创造性解读”或“解构”，而非严格的历史考证。他旨在通过这种谱系学分析，颠覆传统认识论，为其本人的存在论真理观铺平道路。
