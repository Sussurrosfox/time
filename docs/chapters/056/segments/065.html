📖 《存在与时间》研读 逐段解析
首页 / 第 056 章 / 片段 065
📜 原文片段 (056/065)
海德格尔 原文
唯当真理在，才“有”存在—而非才有存在者。而唯当此在在，真理才在。存在和真理同样源始地“在”。存在“在”，这意味着什么？存在同一切存在者的区别究竟在哪里？只有先澄清了存在的意义和存在之领会的全部范围，才可能具体地问及上面的问题。研究存在之为存在这门科学的概念中包含什么，以及它的可能性和它的变形中包含什么，也只有等澄清了存在的意义和存在之领会的全部范围才能得到源始的分析。划出了这一研究及其真理的界限，也就可以从存在论上规定揭示存在者的那类研究及其真理了。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 存在（Sein）：在海德格尔哲学中，指使一切存在者得以“是”其所是的那个最根本的、动态的过程或显现本身。它不是任何具体的东西，而是让一切事物得以在场、得以被理解的背景条件。
  • 存在者（Seiendes）：指一切具体、现成的事物、实体或对象，比如一张桌子、一个人、一个观念。它们是“存在着”的东西，其存在需要由“存在”来规定。
  • 此在（Dasein）：特指人的存在方式。人这种存在者的独特之处在于，它能够发问并理解“存在”本身的意义。此在是存在得以揭示、真理得以发生的场所。
  • 真理（Wahrheit）：在海德格尔这里，真理不是命题与事实的符合，而是“去蔽”（Unverborgenheit），即存在者从隐匿状态进入敞开状态，被理解和照亮的过程。真理是发生在此在的生存活动中的事件。
  • 存在论（Ontologie）：研究“存在”本身（而非具体存在者）的哲学学科。它追问“存在何以成为存在”、“存在的意义是什么”等根本问题。

2. 逐句转译

  1. “唯当真理在，才‘有’存在—而非才有存在者。” 只有当“去蔽”（即真理）这一事件发生，那个最根本的“存在”本身才能显现出来，我们才能谈论“有”存在这回事——注意，这里说的是“存在”得以显现，而不是说具体的事物（存在者）开始存在。

  2. “而唯当此在在，真理才在。” 而只有当“此在”（人这种能够发问存在的存在者）存在，并且在其生存活动中，“去蔽”（真理）这一事件才可能发生。

  3. “存在和真理同样源始地‘在’。” 因此，“存在”的显现和“真理”的发生，是同一层次、同时起源的。没有先后之分，它们是一体两面的关系。

  4. “存在‘在’，这意味着什么？存在同一切存在者的区别究竟在哪里？” 那么，我们说存在“在”或“有”存在，这到底是什么意思？存在和所有具体事物之间的根本区别到底是什么？

  5. “只有先澄清了存在的意义和存在之领会的全部范围，才可能具体地问及上面的问题。” 我们必须首先弄清楚“存在”究竟是什么意思，以及我们理解“存在”的整个可能范围有多大，之后才能有效地、具体地去追问上面那两个问题。

  6. “研究存在之为存在这门科学的概念中包含什么，以及它的可能性和它的变形中包含什么，也只有等澄清了存在的意义和存在之领会的全部范围才能得到源始的分析。” 同样，对于那门研究“存在本身”的学问（即存在论），它本身的概念、它得以成立的条件、以及它可能出现的各种偏差，所有这些的根本性分析，也必须等到我们把存在的意义和理解存在的范围彻底搞清楚之后才能进行。

  7. “划出了这一研究及其真理的界限，也就可以从存在论上规定揭示存在者的那类研究及其真理了。” 只有当我们为存在论研究及其“真理”（去蔽方式）划定了明确的界限，我们才能从哲学根本上，去规定那些专门研究“具体事物”（存在者）的各门科学（如物理学、生物学）的研究方式及其“真理”（它们的揭示方式）是什么。

3. 论证逻辑梳理

  • 前提1：真理（作为去蔽）是存在得以显现的条件。
  • 前提2：此在（人的存在）是真理得以发生的条件。
  • 推论1：因此，存在与此在紧密关联，两者通过真理而共同“在”（显现）。
  • 提出核心问题：基于这个紧密关联，引出了两个根本性问题：存在的“在”意味着什么？存在与存在者的区别何在？
  • 核心方法论主张：要回答这些问题，必须先完成一项基础工作——彻底澄清“存在的意义”和“我们领会存在的全部可能方式”。
  • 推论2：这项基础工作也是厘清“存在论”（研究存在的科学）本身的前提。
  • 最终结论：只有先完成了对存在意义的基础研究（划定了存在论的界限），才能反过来正确地理解和规定各门具体科学（研究存在者的科学）的性质与界限。

4. 整体概括

这段话的核心论点是：“存在”的显现依赖于“真理”（去蔽）的发生，而“真理”的发生又依赖于“此在”（人）的存在。 因此，存在与真理是共生共存的。要真正理解“存在”是什么，以及它如何区别于一个个具体事物，我们必须首先完成一项最基础的任务——全面深入地探究“存在”的意义以及我们理解“存在”的全部方式。只有搭建好这个关于“存在”的哲学地基，我们才能有意义地去探讨研究“存在”本身的学问（存在论），也才能正确地为研究“具体事物”的各门科学（如物理学）划定范围和确立基础。简而言之，一切哲学和科学问题的最终答案，都取决于我们对“存在”这个最根本问题的先行探索。

5. 争议与说明

本段解读相对一致。海德格尔在这里确立的“此在的基础存在论”路径是其思想的核心，学界对此段的基础地位没有争议。可能的细微讨论点在于，如何精确理解“唯当此在在，真理才在”这句话是否带有强烈的主观主义或人类中心主义色彩。主流的、更自洽的解读是：海德格尔并非说存在依赖于人的主观意识而存在，而是说，存在的“意义”之揭示和开显，必须通过此在的生存活动这一唯一通道。 在没有此在的世界里，存在或许依然“在”，但它将是一片沉寂、毫无意义的在场，无所谓揭示与真理。
