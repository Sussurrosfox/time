海德格尔 原文
然而，按照生存论存在论的根系联系的顺序来说是最后的东西，在实际存在者层次上却被当作最先最近的。但若就其必然性来看，这一实际情形复又基于此在本身的存在方式。在消散于操劳活动之际；此在从世内照面的存在者方面来领会自己。被揭示状态虽然从属于揭示活动，但它首先从世内存在者方面摆在道出的东西里面。不仅真理作为现成的东西来照面，而且一般的存在领会也首先把一切存在者都领会为现成的东西。最初对从存在者层次上首先来照面的“真理”所作的存在论思考，把〔说〕领会为〔关于某某东西的说，某某东西的被揭示状态〕。但这种思考却把现象尽可能地按其现成性阐释为现成的东西。真理的这种存在方式与真理的这种切近照面的结构是不是源始的？然而，因为人们已经把现成性同一般的存在的意义等同起来，这个问题就根本不可能获得生命。首先占据了统治地位而且至今尚未从原则上明确克服的那种此在的存在之领会本身遮盖了真理的源始现象。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 生存论存在论：海德格尔哲学的核心方法，指从此在（人的存在）的实际生存出发，探究存在意义的基础存在论。它强调存在理解必须植根于此在的生存活动。
  • 此在：指人的存在，其本质在于“去存在”，即以操心为核心，不断筹划、理解自身可能性的存在者。
  • 操劳：此在日常与世界打交道的基本方式，指忙于事务、沉溺于用具世界的非本真生存状态。
  • 被揭示状态：真理的本质形态，指存在者从隐蔽中被带出的敞开状态，依赖于此在的揭示活动。
  • 现成性：存在者被当作固定不变的、客体化的存在方式（如物体属性），海德格尔认为这是传统形而上学对存在的误解。
  • 存在领会：此在对存在的基本理解能力，通常首先将一切存在者理解为现成对象。

2. 逐句转译

  • “然而，按照生存论存在论的根系联系的顺序来说是最后的东西，在实际存在者层次上却被当作最先最近的。”
    → 从哲学上追根溯源时最后才发现的本质（此在的生存结构），在日常生活经验中却被当成最直接、最先接触到的东西。

  • “但若就其必然性来看，这一实际情形复又基于此在本身的存在方式。”
    → 这种本末倒置的现象其实源于人（此在）固有的生存方式——人天生就容易沉溺于眼前事物。

  • “在消散于操劳活动之际；此在从世内照面的存在者方面来领会自己。”
    → 当人沉浸于日常忙碌时，总是通过周围世界中的具体事物（比如工具、任务）来理解自己。

  • “被揭示状态虽然从属于揭示活动，但它首先从世内存在者方面摆在道出的东西里面。”
    → 虽然真理（被揭示状态）本质上是人主动揭示的结果，但日常生活中，真理总是首先表现为关于某个具体对象的陈述。

  • “不仅真理作为现成的东西来照面，而且一般的存在领会也首先把一切存在者都领会为现成的东西。”
    → 不仅真理被当作固定的事实，人对存在的基本理解也习惯性地把所有东西都看成既定对象。

  • “最初对从存在者层次上首先来照面的‘真理’所作的存在论思考，把〔说〕领会为〔关于某某东西的说，某某东西的被揭示状态〕。”
    → 早期哲学研究直接采纳这种日常真理观，把言说理解为对某个对象的描述（即真理即符合）。

  • “但这种思考却把现象尽可能地按其现成性阐释为现成的东西。”
    → 这种思路却把活生生的现象强行塞进“现成对象”的框架里来解释。

  • “真理的这种存在方式与真理的这种切近照面的结构是不是源始的？”
    → 但这种真理理解方式（作为现成对象）真的是最根源的吗？

  • “然而，因为人们已经把现成性同一般的存在的意义等同起来，这个问题就根本不可能获得生命。”
    → 可惜，由于人们早已将“存在”等同于“现成性”，这个问题根本不可能被真正提出。

  • “首先占据了统治地位而且至今尚未从原则上明确克服的那种此在的存在之领会本身遮盖了真理的源始现象。”
    → 那种统治至今、未被根本克服的成见——把此在理解为现成对象——恰恰遮蔽了真理原本鲜活的模样。

3. 论证逻辑梳理

  • 前提：此在日常沉沦于操劳，从世内存在者理解自身与真理。
  • 推进1：揭示日常真理观的构成——被揭示状态首先依附于对世内存在者的陈述。
  • 推进2：指出这种真理观导致存在领会的现成化倾向，即把所有存在者视为固定对象。
  • 推进3：批判传统哲学将这种派生真理观当作自明起点，用现成性框架扭曲现象。
  • 关键转折：质疑这种真理结构的源始性，但指出该问题被现成性霸权所压制。
  • 结论：此在的流俗存在领会（现成性范式）本身成为遮蔽真理源始现象的根源。

4. 整体概括

这段文字揭示了日常经验与哲学洞察之间的根本错位：我们最熟悉的“真理”（作为关于事物的正确陈述）其实是从此在沉沦于世界的状态中派生出来的，而真理更根源的形态——作为此在让事物无蔽敞开的动态过程——反而被遗忘了。由于传统思维早已把“存在”等同于“现成对象”，我们甚至难以提出“什么才是真理真正的样子”这个问题。海德格尔在此诊断西方形而上学的宿疾：那套占据统治地位的、把一切客体化的思维方式，正是遮蔽真理本源的罪魁祸首。

5. 争议与说明

本段解读相对一致，核心争议点仅在于： - 主流解读认为海德格尔在此坚决反对真理符合论，强调真理作为“无蔽”的生存论起源； - 少数诠释者质疑海德格尔对传统真理观的批判是否过于激进，认为符合论在特定语境中仍有其有效性。但争议不涉及本段具体论述。
