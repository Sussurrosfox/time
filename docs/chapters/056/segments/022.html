📖 《存在与时间》研读 逐段解析
首页 / 第 056 章 / 片段 022
📜 原文片段 (056/022)
海德格尔 原文
一命题是真的，这意味着：它就存在者本身揭示存在者。它在存在者的被揭示状态中说出存在者、展示存在者、“让人看见”存在者。命题的“真在”〔真理〕必须被理解为揭示着的存在。所以，如果符合的意义是一个存在者〔主体〕对另一个存在者〔客体〕的肖似，那么，真理就根本没有认识和对象之间相符合那样一种结构。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 命题：在海德格尔哲学中，命题（Aussage）不只是逻辑学中的判断或陈述，而是此在（Dasein）对世界中的存在者进行揭示和展示的一种方式。它通过语言将事物如其所是地呈现出来。
  • 存在者：指任何“是其所是”的具体事物或对象，可以是人、物、事件等。在本段中，存在者既是命题揭示的对象，也是被展示的内容。
  • 揭示：海德格尔哲学的核心概念之一，指此在通过自身的存在方式，让存在者如其所是地显现出来。揭示不是被动反映，而是主动的、开放性的让事物“在场”。
  • 被揭示状态：存在者通过此在的揭示活动而呈现出的本真样貌。它是事物在真理中“被看见”的状态。
  • 真在/真理：在这里不是指命题与事实的符合，而是指揭示活动本身的存在方式。真理是此在的一种存在模式，即“让事物被如其所是地看见”。
  • 符合：传统真理观中的概念，指命题或认识与客观对象之间的一致或相似关系。海德格尔在此明确反对这种真理观。

2. 逐句转译

  • “一命题是真的，这意味着：它就存在者本身揭示存在者。” → 当我们说一个命题是“真的”，并不是说它和事实对得上，而是说它把事物本身的样子给揭示出来了。它没有扭曲或添加，而是让事物如其本然地显现。

  • “它在存在者的被揭示状态中说出存在者、展示存在者、‘让人看见’存在者。” → 这个命题是在事物已经被揭示的状态中，去言说它、展示它、并且让人能够“看见”它。就像你指着一棵树说“这是一棵树”，你不是在创造树，而是让听者注意到树本身的存在。

  • “命题的‘真在’〔真理〕必须被理解为揭示着的存在。” → 所以，命题之所以为真，本质在于它是一种“正在进行揭示”的存在方式。真理不是静态的属性，而是动态的活动。

  • “所以，如果符合的意义是一个存在者〔主体〕对另一个存在者〔客体〕的肖似，那么，真理就根本没有认识和对象之间相符合那样一种结构。” → 因此，如果我们仍然把“真”理解成主体和客体之间的相似或对应（比如我的认识像镜子一样反映对象），那么真理就根本不是那样的结构。海德格尔彻底否定了传统符合论的真理观。

3. 论证逻辑梳理

  • 前提：从日常语言中“命题为真”这一现象出发。
  • 推进1：重新定义“真”——真不是符合，而是“揭示存在者本身”。
  • 推进2：具体说明命题如何在“被揭示状态”中运作：说出、展示、让人看见。
  • 推进3：由此得出本质结论：真理是“揭示着的存在”，是一种存在方式。
  • 结论：明确反对传统符合论——如果真理是符合，那么海德格尔所说的真理就根本不是那种结构。

4. 整体概括

这段话的核心是在颠覆传统的真理符合论。海德格尔认为，命题的真理性不在于它是否与客观对象相符，而在于它能否让事物如其所是地显现出来。真理是此在的一种揭示活动，是“让人看见”存在者本身的存在方式。因此，真理的本质是揭示，而非主客体之间的对应关系。

5. 争议与说明

本段解读相对一致。海德格尔对符合论的批判是其真理观的核心主张，学界普遍认同这是他前期思想中的关键转折。可能的细微争议在于：他是否完全否定了符合论，还是将其纳入更基础的“揭示”活动中？但主流解读认为，他确实用“揭示”取代了“符合”作为真理的本质。
