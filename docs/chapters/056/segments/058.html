📖 《存在与时间》研读 逐段解析
首页 / 第 056 章 / 片段 058
📜 原文片段 (056/058)
海德格尔 原文
“设定前提”说的是什么？说的是把某种东西领会为另一存在者的存在之根据。这就是在存在者的存在之联系中领会存在者。这种领会只有在展开状态的基础上才是可能的；也就是说，只有根据此在的进行揭示的存在才是可能的。于是，把“真理”设为前提指的就是把“真理”领会为此在为其故而存在的东西。但操心这一存在建构包含有这样的情况：此在一向已先行于自身。此在是为最本己的能在而在的存在者。展开状态和揭示活动本质上属于此在的存在和能在。而此在是在世的存在。事关此在的是它的能在世，其中也就有寻视着揭示世内存在者的操劳活动。最源始的“设为前提”在于操心这一此在的存在建构，在于先行于自身的存在。因为这种设自身为前提属于此在的存在，所以，“我们”必须把由展开状态规定的“我们”也设为前提。另外还有非此在式的存在者；但此在的存在所固有的这一“设定前提”无关乎非此在式的存在者，而只关乎此在本身。被设为前提的真理和人们用以规定真理之在的“有”，都具有此在本身的存在方式和存在意义。我们必须“造出”真理前提，因为它随着“我们”的存在已经是“造好的”。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 设定前提 (Setzen einer Voraussetzung)：在海德格尔哲学中，这不是指逻辑推理中的假设，而是指将此在（Dasein）的存在本身领会为一切存在者之存在意义的根据。在本段中，特指将“真理”领会为此在生存的根本目的。
  • 此在 (Dasein)：指人的存在方式，其本质在于“去存在”（Zu-sein），即以操心（Sorge）为基本建构，不断筹划自身可能性、揭示世界意义的存在者。
  • 展开状态 (Erschlossenheit)：此在在世的基本方式，指此在通过其生存活动，使得世界、自身与他人的意义得以呈现和可理解。
  • 操心 (Sorge)：此在存在的整体结构，包含“先行于自身-已在世界之中-依寓世内存在者而存在”三个环节，体现了此在的投射性、事实性和沉沦性。
  • 能在 (Seinkönnen)：此在的根本特征，指此在总是面向未来、筹划自身可能性的能力，它并非现成属性，而是需要通过生存实践实现的动态过程。
  • 真理 (Wahrheit)：在此不是指命题与事实相符，而是指存在的无蔽状态（Unverborgenheit），即存在者如其所是地在此在的展开活动中被揭示。

2. 逐句转译

  • “设定前提说的是把某种东西领会为另一存在者的存在之根据。这就是在存在者的存在之联系中领会存在者。”
    → 所谓“设定前提”，其实就是把某个东西理解成其他事物之所以存在的根本原因。这意味着我们要从“存在”本身的关联网络中去理解事物。

  • “这种领会只有在展开状态的基础上才是可能的；也就是说，只有根据此在的进行揭示的存在才是可能的。”
    → 但这种理解只有在此已经“打开”了世界、让事物显现出来的前提下才可能发生。说白了，只有人这种能够揭示意义的存在者，才能做这种“设定前提”的事情。

  • “于是，把‘真理’设为前提指的就是把‘真理’领会为此在为其故而存在的东西。”
    → 所以，当我们说把“真理”设为前提，其实就是把“真理”看作人活着所要追求的那个终极目标——人是为了让真理显现而存在的。

  • “但操心这一存在建构包含有这样的情况：此在一向已先行于自身。此在是为最本己的能在而在的存在者。”
    → 而人的存在结构（操心）决定了人总是“跑在自己前面”——人本质上就是为了实现自己最本真的可能性而活的。

  • “展开状态和揭示活动本质上属于此在的存在和能在。而此在是在世的存在。”
    → 打开世界、揭示事物，这本来就是人存在的方式，也是人实现可能性的方式。人从来都是“活在世界上”的。

  • “事关此在的是它的能在世，其中也就有寻视着揭示世内存在者的操劳活动。”
    → 人最关心的是自己如何在世生存，这包括在日常生活中通过具体活动（比如使用工具）让周围事物显现出意义。

  • “最源始的‘设为前提’在于操心这一此在的存在建构，在于先行于自身的存在。”
    → 最根本的“设定前提”其实就藏在人的生存结构里——就是那种“总在筹划未来”的存在方式。

  • “因为这种设自身为前提属于此在的存在，所以，‘我们’必须把由展开状态规定的‘我们’也设为前提。”
    → 既然这种自我预设是人的本性，那么我们这些已经被世界所塑造的“我们”，也必须被当作前提来接受。

  • “另外还有非此在式的存在者；但此在的存在所固有的这一‘设定前提’无关乎非此在式的存在者，而只关乎此在本身。”
    → 世界上当然还有石头、树木这些非人的存在者，但人这种“自我预设”的特性只跟人自己有关，不适用于它们。

  • “被设为前提的真理和人们用以规定真理之在的‘有’，都具有此在本身的存在方式和存在意义。”
    → 被当作前提的“真理”，以及我们说真理“存在”时的那个“存在”，其实都带着人特有的存在方式和意义。

  • “我们必须‘造出’真理前提，因为它随着‘我们’的存在已经是‘造好的’。”
    → 表面上看是我们在“设立”真理前提，实际上这个前提随着我们出生就已经被“预制”好了——它就是我们生存自带的背景条件。

3. 论证逻辑梳理

  1. 前提界定：首先明确“设定前提”的本质是领会存在根据，而非逻辑假设。
  2. 可能性条件：指出这种领会依赖此在的展开状态，只有能揭示意义的存在者才能进行这种活动。
  3. 核心论证：
    - 将“真理”设为前提，就是把真理领会为此在的生存目的。
    - 此在的操心结构决定了它总是“先行于自身”，为最本己的能在而存在。
    - 展开与揭示活动内在于此在的生存，并通过在世操劳具体实现。
  4. 溯源深化：最源始的设定前提就是操心结构本身，即此在的先行存在。
  5. 推论扩展：
    - 由于此在本质上是自我预设的，我们不得不接受已经被展开状态规定的自身。
    - 这种自我预设仅适用于此在，不适用于非此在存在者。
  6. 存在论归属：真理及其存在方式都由此在的存在规定。
  7. 辩证总结：真理前提看似是我们主动设立，实则是随着我们存在已然被给予的。

4. 整体概括

这段话的核心是在说：当我们谈论“设定前提”时，其实是在说人（此在）把某种东西理解为事物存在的根本依据。这种理解活动只有人这种能够打开世界、揭示意义的存在者才能做到。所以把“真理”设为前提，其实就是把真理看作人活着所要追求的那个让事物显现的意义核心。而人的存在结构（操心）决定了人总是面向未来、筹划可能性，这种“跑在前面”的存在方式本身就是最原始的“自我预设”。因此，不是我们主动去设立了真理前提，而是随着我们来到世界上，这个前提已经作为我们生存的背景被给定了——真理及其存在意义都是由人的存在方式所决定的。

5. 争议与说明

本段解读相对一致，核心争议点在于： - 主流解读：认为海德格尔在此完成了真理问题的“存在论转向”，真理既非符合论也非融贯论，而是此在展开活动的产物。 - 可能的争议：
1. “设定前提”是否隐含了循环论证？海德格尔刻意接受这种“解释学循环”，认为这正是此在存在的本性。
2. “真理随此在存在已被造好”是否走向了相对主义？海德格尔会辩称这是先于主客对立的更本源真理。
