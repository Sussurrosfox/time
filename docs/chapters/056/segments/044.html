📖 《存在与时间》研读 逐段解析

海德格尔 原文
此在无须乎借“原初”经验把自己带到存在者面前，但尽管如此它却仍然在某种向着存在者的存在中。在大多数情况下，人们不是借亲身揭示来占有被揭示状态的，而是通过对人云的道听途说占有它的。消散于人云之中是常人的存在方式。道出来的东西本身把向命题所揭示的存在者的存在这回事接了过来。然而，若要明确地就存在者的揭示状态占有存在者，那么我们就得说：应当证明命题是起揭示作用的命题。但道出的命题是一个上手的东西，而且，作为保存被揭示状态的东西，它本来就同被揭示的存在者具有某种联系。那么，要证明命题是起揭示作用的存在就等于说：证明保存着被揭示状态的命题同存在者有联系。命题是上手的东西。命题作为揭示着的命题同存在者有联系，这个存在者是世内的上手事物或现成事物。这种联系本身也表现得像是现成联系。但这种联系在于：保存在命题中的被揭示状态是某某东西的被揭示状态。判断“包含着对诸对象有效的东西”〔康德语〕。这种联系被旋扭到现成东西之间的某种联系上面，于是，这种联系本身获得了现成性质。某某东西的被揭示状态变成了现成的一致性，即道出的命题这一现成东西对所谈的存在者这一现成东西的现成一致。只要我们还只把这种一致性看成现成东西之间的关系，也就是说，只要我们不加区别地把这些关系项的存在方式领会为仅仅现成的东西，那么，那种联系就表现为两个现成东西的现成符合。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学中的核心概念，特指“人”这种存在者。它不是指作为生物或物体的人，而是指能够追问自身存在、理解自身在世界中之位置的存在者。此在的本质在于“去存在”，它总是已经处于与世界、与他人打交道的动态过程中。

  • 存在者：泛指一切“是着”的东西，既包括物体、工具等“上手事物”，也包括观念、数字等“现成事物”。在此语境中，尤其指那些可以被我们谈论、判断的对象。

  • 揭示 / 被揭示状态：指此在通过自身的活动（如使用、谈论、判断）让存在者以其所是的方式显现出来，被我们理解和把握。被揭示状态就是存在者被如此这般揭示出来的“真相”或“实际情况”。

  • 道听途说 / 人云：指此在在日常生活中，不经由亲身探究，而是通过公众意见、流言蜚语、传统说法等间接方式来理解和占有关于存在者的知识。这是一种非本真的存在方式。

  • 常人：指日常生活中的“大家”、“一般人”，代表一种匿名的、平均化的公众权威。此在消散于“常人”之中，意味着放弃了自身独特的、本真的存在可能性，而按照公众的标准和看法去生活。

  • 命题：在此并非仅指逻辑学中的判断语句，更广泛地指被“道出来”的、关于某物的陈述、断言或说法。它是一个已经上到手头、可供使用和交流的语言物品。

  • 上手事物：指那些在我们日常操劳活动中直接与之打交道的器具，它们因服务于某个目的而显得“称手”，其存在方式是与我们的实践活动融为一体的（如一把锤子）。

  • 现成事物：指那些仅仅摆在那里、作为观察和研究对象的客体，其存在方式是从我们的实践活动中抽离出来，被当作独立自存的、具有各种属性的东西（如物理学研究的原子）。

  • 现成性 / 现成一致 / 现成符合：指将事物（包括命题与存在者的关系）理解为两个彼此分离、独立自存的现成对象之间的一种外在的、静态的“符合”或“一致”关系。海德格尔认为，这是对源始的“揭示”关系的一种扭曲和降格。

2. 逐句转译

  • “此在无须乎借‘原初’经验把自己带到存在者面前，但尽管如此它却仍然在某种向着存在者的存在中。” 我们人（此在）并不是非得通过自己亲身的、第一手的体验，才能接触到世界上的事物（存在者）。但即便如此，我们生存的基本状态，就是总在跟各种事物打交道，总在关注着它们。

  • “在大多数情况下，人们不是借亲身揭示来占有被揭示状态的，而是通过对人云的道听途说占有它的。” 大部分时候，我们了解一件事的真相，并不是靠自己亲自去探究，而是听信别人的说法，随大流。

  • “消散于人云之中是常人的存在方式。” 这种沉溺于公众意见、失去自我的状态，就是日常生活中“常人”的典型活法。

  • “道出来的东西本身把向命题所揭示的存在者的存在这回事接了过来。” 当我们把某种说法讲出来，形成一个命题（比如一个判断或陈述），这个命题本身就承载了“它所说的事物是什么样子”这回事。

  • “然而，若要明确地就存在者的揭示状态占有存在者，那么我们就得说：应当证明命题是起揭示作用的命题。” 但是，如果我们想清清楚楚地、基于事物被揭示出来的样子去把握这个事物，那我们就要去证明，我们所说的这个命题，确实真实地揭示了那个事物。

  • “但道出的命题是一个上手的东西，而且，作为保存被揭示状态的东西，它本来就同被揭示的存在者具有某种联系。” 然而，被说出来的命题本身，就像一件工具一样，是我们手头可以用的东西。并且，因为它保存着关于那个事物的信息，它天然就和那个被谈论的事物有联系。

  • “那么，要证明命题是起揭示作用的存在就等于说：证明保存着被揭示状态的命题同存在者有联系。” 所以，要证明命题真正起到了揭示作用，就等于说：要证明这个保存了“真相”的命题，确实和那个事物本身是对得上号的。

  • “命题是上手的东西。命题作为揭示着的命题同存在者有联系，这个存在者是世内的上手事物或现成事物。” 命题是件手头的工具。这个作为揭示工具的命题，它所联系的那个事物，可以是我们在生活中使用的器具（上手事物），也可以是我们观察研究的对象（现成事物）。

  • “这种联系本身也表现得像是现成联系。” 这种“命题与事物之间的联系”，在我们看来，也常常表现为像是两个现成东西之间的外在联系。

  • “但这种联系在于：保存在命题中的被揭示状态是某某东西的被揭示状态。” 但这种联系的本质在于：命题里所保存的那个“被揭示的状态”，是“关于某个特定事物的被揭示状态”。

  • “判断‘包含着对诸对象有效的东西’〔康德语〕。” 就像康德说的，一个判断本身就包含着对它所指向的对象有效的内容。

  • “这种联系被旋扭到现成东西之间的某种联系上面，于是，这种联系本身获得了现成性质。” 但是，我们往往把这种源始的联系，强行解释成两个现成东西（命题和事物）之间的某种外在关系。这样一来，联系本身也被我们看成是一种现成的东西了。

  • “某某东西的被揭示状态变成了现成的一致性，即道出的命题这一现成东西对所谈的存在者这一现成东西的现成一致。” 于是，“某物被揭示出来的样子”这个活生生的过程，就僵化成了“现成的一致性”。也就是说，变成了一个现成的命题（一句话）和另一个现成的事物（一个对象）之间，像两个物体一样严丝合缝地匹配。

  • “只要我们还只把这种一致性看成现成东西之间的关系，也就是说，只要我们不加区别地把这些关系项的存在方式领会为仅仅现成的东西，那么，那种联系就表现为两个现成东西的现成符合。” 只要我们仍然仅仅把这种“一致”看作是两个现成物件之间的关系，也就是说，只要我们糊里糊涂地把命题和事物都当成是仅仅摆在那里的现成物件，那么，命题揭示事物这种源始的联系，就彻底堕落为两个死东西之间的、静态的“符合”了。

3. 论证逻辑梳理

  1. 前提与起点：此在总是在与存在者打交道（“向着存在者的存在”），但通常并非通过亲身揭示，而是通过“道听途说”和公共意见（“常人”方式）。
  2. 引入核心对象：被“道出”的“命题”承载了关于存在者的“被揭示状态”，我们若要确认真相，就需要证明这个命题是“起揭示作用的”。
  3. 分析命题的奇特地位：命题本身是“上手的东西”（可使用的语言工具），它又声称与存在者（无论是上手的还是现成的）有联系。这种联系本应是揭示性的。
  4. 揭示关系的扭曲过程：
    • 首先，这种源始的、动态的“揭示关系”被误解了。
    • 它被“旋扭”成两个现成东西（命题和对象）之间的外在联系。
    • 于是，“被揭示状态”这种活生生的理解事件，被降格为“现成一致性”，即命题内容与对象事实之间的静态符合。
  5. 最终结论/刻画：当我们不加批判地将命题和存在者都视为现成对象时，真理（揭示状态）就必然被误解为现成符合论意义上的“真理”，即两个现成物之间的匹配关系。

4. 整体概括

这段文字的核心在于揭示传统“真理符合论”（认为真理是命题与事实的符合）的根源和局限性。海德格尔指出，我们人原本就活在与事物打交道的揭示活动中，但我们常常不亲自去揭示，而是人云亦云。当我们试图确认真理时，我们关注的是说出来的“命题”是否真实。然而，命题本身成了一件可用的工具，它和事物的关系本是一种动态的“揭示”。问题在于，我们习惯于把一切都看成是摆在那里的现成对象，于是这种活生生的“揭示关系”就被扭曲了：它被看作是两个现成东西（命题和事物）之间的静态“符合”。海德格尔认为，这种符合论是对更源始的、作为此在在世存在方式的“揭示”活动的一种派生的、甚至歪曲的理解。他意在引导我们追问：在说“这个命题符合那个事实”之前，那种让事物得以被我们理解和言说的、更基础的“揭示”活动，其本身是怎样的？

5. 争议与说明

本段解读相对一致，核心争议点不在于这段文字本身，而在于海德格尔对传统符合论的批判是否成功，以及他提出的作为“揭示”的真理观能否完全取代或奠基符合论。一些批评者认为：

  1. 主流解读：海德格尔成功地揭示了符合论预设了一个更源始的存在论基础——此在的揭示活动，符合论是此在沉沦于“常人”状态和对世界做现成化理解的结果。
  2. 其他可能的解读方向/质疑：
    • 循环性问题：有学者质疑，海德格尔用“揭示状态”来定义真理，但如何判断一个“揭示”是真正的揭示而非幻象？这似乎又需要某种标准，可能暗中仍依赖了某种符合的观念。
    • 适用性范围：符合论在处理形式科学（如数学、逻辑）和某些经验陈述时显得非常直接有效，海德格尔的“揭示”真理观似乎更适用于对存在和生存意义的理解，两者是不同层面的问题，未必是非此即彼的替代关系。
    • 对符合论的刻画是否公允：海德格尔所批判的“现成符合”是否就是符合论拥护者所理解的全部？有些符合论者可能会认为他们的理论也包含了动态的认识过程，而并非仅仅是对两个静态实体的比较。

争议的焦点在于海德格尔对传统真理观的“解构”是否彻底，以及他自己的“揭示”真理观是否自足。
