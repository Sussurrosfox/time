📖 《存在与时间》研读 逐段解析
首页 / 第 090 章 / 片段 005
📜 原文片段 (090/005)
海德格尔 原文
虽然我们前此一直看不出有以更激进的办法开始生存论分析工作的可能，但只要回顾前面对日常状态的存在论意义的讨论，还是能醒悟到一重困难的考虑：就此在本真的整体夺在着眼，我们究竟有没有把此在的整体带进了生存论分析的先行具有？与此在的整体性相关的问题提法或许天然具有存在论上的明了一义。问题本身甚或会借回顾向终结存在找到答案。不过，死只是此在的“终结”，从形式上来看，只是囊括此在整体性的一个“终端”。而另一个终端是“开端”、是“出生”。只有这个生死“之间”的存在者表现出所寻求的整体。所以，尽管我们努力求取生存着的整体存在，尽管我们用天然的方式阐释了本真的和非本真的向死存在，分析工作前此所制订的方向仍然是“片面的”。在前面形成的课题中，此在只是“向前”生存着而把一切曾在“留在身后”。始终未经重视的不仅是向开端的存在，而且尤其是此在在生死之间的途程。对整体存在的分析所曾忽视的恰恰是此在这样那样总持身于其中这一“生命的联系”。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学的核心概念，指“人”这种能够追问自身存在的存在者。此在的本质在于其“生存”，即不断筹划、理解自身可能性的存在方式。
  • 生存论分析：对此在之存在结构的哲学探究。它旨在揭示此在如何“在世存在”的基本方式，而非心理学或人类学描述。
  • 本真：此在的一种存在模式，指此在清醒地认识到自身的有限性和死亡，并因此个体化地、决断地承担起自身的存在。
  • 非本真：此在沉沦于日常公共世界（常人）的生存模式，逃避自身的个体性与死亡，以社会惯例和闲谈为指引。
  • 整体存在 / 整体性：指此在作为一个完整、统一的生命历程的存在。它不是各个部分的简单相加，而是贯穿从生到死的整个动态过程。
  • 先行具有：指任何理解或分析都必然预设和依赖于一个已经存在的基本背景或视野。这里指生存论分析是否在一开始就将此在的“整体”纳入其基本视野。
  • 向终结存在：此在面向其自身最本己的可能性——死亡——而存在的生存论结构。死亡不是外在事件，而是内在于此在、构成其整体性的一个维度。
  • 曾在：此在的过去。但海德格尔的“曾在”不是已完成的、与现在割裂的事实，而是持续对当前和未来的理解产生影响的生存论维度。

2. 逐句转译

  • “虽然我们前此一直看不出有以更激进的办法开始生存论分析工作的可能，但只要回顾前面对日常状态的存在论意义的讨论，还是能醒悟到一重困难的考虑...”

    • 虽然之前我们没找到更根本的方法来开始分析此在，但回想一下之前讨论的“日常状态”在存在论上的意义，我们就能意识到一个难题。

  • “...就此在本真的整体夺在着眼，我们究竟有没有把此在的整体带进了生存论分析的先行具有？”

    • 如果我们着眼于本真状态下的此在整体，我们不得不问：我们之前的分析，真的从一开始就把此在的“整体性”作为前提和背景了吗？

  • “与此在的整体性相关的问题提法或许天然具有存在论上的明了一义。问题本身甚或会借回顾向终结存在找到答案。”

    • 关于此在整体性的问题，其提问方式本身在存在论上可能是清晰明确的。甚至，这个问题本身可能会通过回顾我们关于“向死存在”的分析而得到解答。

  • “不过，死只是此在的‘终结’，从形式上来看，只是囊括此在整体性的一个‘终端’。而另一个终端是‘开端’、是‘出生’。只有这个生死‘之间’的存在者表现出所寻求的整体。”

    • 但是，死亡仅仅是此在的“终点”，从形式上看，它只是构成此在整体性的一个“终端”。另一个终端是“开端”，即“出生”。我们所要寻找的整体，恰恰是那个存在于“出生”与“死亡”之间的整个生命历程。

  • “所以，尽管我们努力求取生存着的整体存在，尽管我们用天然的方式阐释了本真的和非本真的向死存在，分析工作前此所制订的方向仍然是‘片面的’。”

    • 因此，尽管我们努力去把握此在的整体存在，也详细分析了本真的和非本真的面对死亡的态度，但我们之前分析工作的方向仍然是“不全面”的。

  • “在前面形成的课题中，此在只是‘向前’生存着而把一切曾在‘留在身后’。始终未经重视的不仅是向开端的存在，而且尤其是此在在生死之间的途程。”

    • 在之前的课题中，此在似乎只是“向前”活着（面向未来），而把它的过去（曾在）抛在了脑后。我们不仅一直忽视了“向着开端（出生）的存在”，更忽视了此在从生到死的整个生命旅程。

  • “对整体存在的分析所曾忽视的恰恰是此在这样那样总持身于其中这一‘生命的联系’。”

    • 之前对整体存在的分析，恰恰忽略了一点：此在总是以某种方式持续地存在于其中的那个“生命的联系”或“生命整体”。

3. 论证逻辑梳理

  • 前提/问题提出： 回顾之前的分析，发现一个根本困难：我们是否真的将此在的“整体性”作为生存论分析的起点和基础视野（先行具有）？
  • 初步分析与转折： 虽然通过分析“向死存在”触及了整体性问题（因为死亡是构成整体性的一个终端），但这还不够。
  • 核心论证： 指出整体性在形式上必须包含两个终端：开端（出生）和终结（死亡）。真正的整体是这“之间”的整个生命历程。
  • 诊断与结论： 因此，之前的分析是“片面的”，因为它过于强调此在“向前”（面向未来）的生存，而忽略了其“曾在”（过去）和整个生命历程的统一性。最终结论是，之前的分析遗漏了此在始终贯穿于其中的“生命联系”。

4. 整体概括

这段话是海德格尔对《存在与时间》前期工作的一个自我检讨和转向声明。他指出，尽管之前的分析深入探讨了“向死存在”，看似触及了此在的整体性，但实际上这种分析是片面的。因为它只抓住了构成整体性的一个终端——“死亡”，而忽略了另一个同样构成性的终端——“出生”。真正的此在整体，是贯穿于“出生”与“死亡”之间的整个动态生命历程。之前的分析过于聚焦于此在“向前”筹划未来，仿佛把过去（曾在）甩在了身后，未能把握此在如何作为一个统一的、从生到死的“生命联系”而存在。因此，必须将分析的目光扩展到整个生命历程，才能真正理解此在的整体性。

5. 争议与说明

本段解读相对一致。其核心在于指出从“向死存在”到“整体存在”分析的必要性过渡，是为后续分析“历史性”与“时间性”做铺垫。学界普遍认同这是《存在与时间》从第二篇第一章向第二章（历史性）过渡的关键段落，论证逻辑清晰，无明显争议。
