海德格尔 原文
而且，既然我们的标的是基础存在论，所以对历史性的存在论问题的讲解必然是有限度的。这一讲解有下列环节：流俗的历史领会与此在的演历〔第七十三节〕；历史性的基本建构〔第七十四节〕；此在的历史性与世界历史〔第七十五节〕；历史学在此在历史性中的生存论源头〔第七十六节〕；此处对历史性问题的讲解与狄尔泰的研究及约克〔Yorck〕伯爵的观念的联系〔第七十七节〕。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 基础存在论：海德格尔哲学的核心概念，指一种旨在探究“存在”本身意义的哲学基础。它不研究具体存在者（如物体、生物），而是追问这些存在者为何“存在”以及如何“存在”，并以“此在”（人的存在）为切入点。在本段中，基础存在论是全书《存在与时间》的根本目标，而历史性问题是其中的一个组成部分。

  • 历史性：指此在（人的存在）本质上是一种时间性的、历史化的存在。此在不是静止的实体，而是在时间中展开、承前启后、具有命运与传统的存在方式。本段中，对历史性的讲解是基础存在论计划的一部分。

  • 流俗的历史领会：指日常生活中人们对历史的通常理解，往往把历史看作过去发生的、客观的、可研究的“事件序列”，而忽略了历史根植于此在的存在方式。

  • 此在的演历：“演历”指此在在时间中具体展开、发生的过程，是历史性在个体或共同体生命中的实际体现。

  • 生存论源头：指从“生存”（Existenz）角度追溯某个现象（如历史学）的根源。生存是此在特有的存在方式——此在总是筹划自身、面向可能性而存在。在这里，海德格尔要从历史学的生存论源头（即此在的历史性）出发，解释历史学如何可能。

2. 逐句转译

  • “而且，既然我们的标的是基础存在论，所以对历史性的存在论问题的讲解必然是有限度的。”
    这句话是说：我们这本书的根本目标是建立基础存在论，因此对“历史性”这个存在论问题的探讨，只能在这个大目标下进行，不可能面面俱到，而是有它的范围限制。

  • “这一讲解有下列环节：流俗的历史领会与此在的演历〔第七十三节〕；历史性的基本建构〔第七十四节〕；此在的历史性与世界历史〔第七十五节〕；历史学在此在历史性中的生存论源头〔第七十六节〕；此处对历史性问题的讲解与狄尔泰的研究及约克伯爵的观念的联系〔第七十七节〕。”
    这句话列出了接下来几节的内容大纲：首先分析常人如何理解历史，以及此在的实际历史过程；然后剖析历史性的基本结构；接着探讨此在的历史性与所谓“世界历史”的关系；再从根源上说明“历史学”（作为一门学科）如何从此在的历史性中生发出来；最后说明这里的讲解与狄尔泰、约克伯爵的思想有哪些关联。

3. 论证逻辑梳理

  • 前提：本段的前提是，全书的核心任务是“基础存在论”，所有具体问题的探讨（包括历史性）都服务于这一任务，因此讲解有其限度。
  • 推进过程：海德格尔以“基础存在论”的目标为出发点，明确了对“历史性”问题的讲解将遵循一个逐步深入的环节顺序： 1. 从“流俗的历史领会”入手，揭示日常理解历史的方式与此在的实际历史过程（演历）之间的差异。 2. 进而分析“历史性的基本建构”，即此在作为历史性存在的根本结构。 3. 将这一结构扩展到“世界历史”的层面，说明此在的历史性如何参与并构成所谓的世界历史。 4. 再回溯“历史学”的根源，指出它并非无源之水，而是植根于此在的历史性这一生存论基础。 5. 最后通过与狄尔泰、约克伯爵的对话，定位自己的理论在思想史中的位置。
  • 结论：通过这一系列环节，海德格尔为读者勾勒出他将如何在基础存在论框架内，系统地处理历史性问题。

4. 整体概括

这段话是《存在与时间》中关于历史性讨论的“路线图”。海德格尔首先说明，由于全书的根本目标是基础存在论，因此对历史性的探讨是在这一框架下进行的，有其特定的范围与深度。他随后列出了五个讲解环节：从批判流俗历史观开始，逐步深入到历史性的本质结构，探讨此在历史性与世界历史的关系，追溯历史学的生存论根源，最后与相关思想家的理论进行对话。整段话的作用是预告并结构化后续关于历史性的分析，表明他将从存在论层面，而非一般历史学角度，重新奠基历史的理解。

5. 争议与说明

本段本身是全书的结构预告，内容相对明确，争议较少。可能的细微讨论点在于：有学者认为，海德格尔对“流俗历史领会”的批评是否过于贬低了日常与史学工作的价值；以及他将历史学完全收摄于此在的历史性，是否忽略了历史客观性的维度。但这些争议更多出现在对后续章节的解读中，而非本段。
