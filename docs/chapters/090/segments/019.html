📖 《存在与时间》研读 逐段解析
首页 / 第 090 章 / 片段 019
📜 原文片段 (090/019)
海德格尔 原文
虽说如此，此在也必须在存在“在时间中”这一意义上被称作“时间性的”。即使历史学没有成形，实际此在也需要并确实使用着日历与钟表。此在把“随着它”所演历的事经验为“在时间中”演历的。有生命的自然与无生命的自然“在时间中的”进程也是以同一种方式来照面的。这些进程是在时间内的。所以，虽然我们把对时间内状态的“时间”如何源出于时间性的分析推迟到下一章才去进行，但似乎本也可以把这一分析放到对历史性与时间性之间的联系的讨论之前。然而对历史事物的流俗描述借助于时间内状态的时间而显得是不言而喻和唯一可能的；而要消除这种不言而喻与唯一可能的性质就应得首先纯粹地从此在的源始时间性中“演绎”出历史性来。甚至“事情本身”的联系也要求这样做。当然，时间，作为时间内状态，也是从此在的时间性中“生长”出来的，就此说来，历史性与时间内状态表明自身为同样源始的。从而，对历史的时间性质的流俗解释在自己的限度内也不无道理。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：指人的存在方式，即“在世界之中存在”的具体个体。它不仅“是”某物，更以理解、筹划、关切的方式展开其生存。在本段中，此在是历史性与时间性的承载者。
  • 时间性：此在存在的根本结构，是过去、现在、未来统一展开的源始时间。它不是钟表时间，而是使理解、决断和历史成为可能的生存论基础。
  • 历史性：此在因其时间性而本质上具有“曾在-现在-将来”的统一历程，并在此历程中承担传统、做出决断。它是此在“是历史”的存在论条件。
  • 时间内状态：日常流俗理解的时间，表现为一条由“现在”点构成的、均匀流逝的序列（日历与钟表时间）。它是从源始时间性“衍生”出来的。
  • 演历：此在生存过程中的具体发生与展开，包括行动、遭遇、经验等。它本质上属于历史性，但日常中被误解为“在时间内”发生。

2. 逐句转译

  • “虽说如此，此在也必须在存在‘在时间中’这一意义上被称作‘时间性的’。”

  • 尽管前面强调了此在的源始时间性不同于流俗时间，但此在确实也生活在日常的“在时间中”的意义上，所以也可以被称为“时间性的”（这里指衍生意义上的时间性）。

  • “即使历史学没有成形，实际此在也需要并确实使用着日历与钟表。”

  • 就算没有形成系统的历史学，日常生活中的此在仍然离不开日历和钟表这些计时工具。

  • “此在把‘随着它’所演历的事经验为‘在时间中’演历的。”

  • 此在把自己经历的各种事情，都体验成是在那条均匀流淌的时间长河里发生的。

  • “有生命的自然与无生命的自然‘在时间中的’进程也是以同一种方式来照面的。”

  • 无论是动植物的生命过程，还是自然界的物理变化，此在都是以同样的方式，把它们当作在时间序列中展开的事件来看待的。

  • “这些进程是在时间内的。”

  • 所有这些过程，都被理解成发生在“时间之内”的。

  • “所以，虽然我们把对时间内状态的‘时间’如何源出于时间性的分析推迟到下一章才去进行，但似乎本也可以把这一分析放到对历史性与时间性之间的联系的讨论之前。”

  • 因此，虽然我们计划在下一章才详细分析流俗时间是如何从源始时间性中产生的，但看起来，这个分析似乎也可以安排在讨论历史性与时间性关系之前进行。

  • “然而对历史事物的流俗描述借助于时间内状态的时间而显得是不言而喻和唯一可能的；而要消除这种不言而喻与唯一可能的性质就应得首先纯粹地从此在的源始时间性中‘演绎’出历史性来。”

  • 但是，日常生活中对历史的描述，完全依赖于那条均匀的、可计量时间流，这使得这种描述看起来是天经地义、别无选择的。要想打破这种理所当然的看法，就必须首先从最纯粹的、此在的源始时间性出发，一步一步地推导出历史性这个概念。

  • “甚至‘事情本身’的联系也要求这样做。”

  • 而且，从哲学探究“事情本身”的内在逻辑来看，也应该这么做。

  • “当然，时间，作为时间内状态，也是从此在的时间性中‘生长’出来的，就此说来，历史性与时间内状态表明自身为同样源始的。”

  • 当然，我们也要承认，流俗的、作为“时间内状态”的时间，同样是从此在的源始时间性中“衍生”出来的。从这个共同的源头来看，历史性和时间内状态其实是“同根同源”的，它们都源于此在的时间性。

  • “从而，对历史的时间性质的流俗解释在自己的限度内也不无道理。”

  • 因此，那种用流俗时间来理解历史的做法，在它自己的适用范围和前提假设内，也并非全无道理。

3. 论证逻辑梳理

  • 前提1：此在在日常生活中确实使用并依赖于“时间内状态”（日历、钟表），并将其自身及世界的演历经验为“在时间中”发生。
  • 前提2：流俗的历史观完全建立在“时间内状态”之上，并将其视为理解历史的唯一不言而喻的基础。
  • 核心步骤：为了挑战并超越这种流俗历史观的统治地位，揭示其并非唯一可能，海德格尔认为必须进行一个“反向推导”——不是从流俗时间出发，而是从更源始的此在时间性出发，去“演绎”出历史性。
  • 补充论证：他同时指出，流俗时间（时间内状态）本身也是从源始时间性中衍生出来的。因此，历史性和时间内状态在根源上是“同样源始”的，都植根于此在的时间性。
  • 结论：基于此，流俗的历史时间解释虽然层次较浅，但因其同样源于时间性，所以在它自身的适用范围内是有效的、有道理的。

4. 整体概括

这段文字的核心在于处理此在的“源始时间性”与日常理解的“流俗时间”（时间内状态）之间的关系，特别是在解释“历史性”时的优先次序问题。海德格尔承认，此在确实活在流俗时间中并用它来理解一切。但他强调，要想真正理解历史性，不能直接从这种看似不证自明的流俗时间出发，而必须首先追溯到更根本的源始时间性，并从那里推导出历史性。这样做是为了打破流俗历史观的垄断地位。同时，他又通过指出流俗时间本身也源于时间性，缓和了二者的对立，承认流俗解释在它自己的领域内有其合理性。整个段落体现了他“正本清源”的哲学方法：先深入本源，再理解派生现象。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“同样源始”的理解： - 主流解读：这里的“同样源始”并非指历史性与时间内状态在存在论层次上平起平坐，而是指它们拥有同一个源头，即此在的源始时间性。源始时间性是根基，二者是其不同方向的“衍生”或“展开”。历史性更贴近生存本身，时间内状态则是其公共化、平均化的表达。 - 其他视角：有学者可能强调，海德格尔此处的表述带有一定的辩证性，他既要确立源始时间性的优先性，又要解释流俗时间的普遍有效性，因此“同样源始”的说法可以看作是对流俗时间的一种有限度的“安抚”或“承认”，而非严格的哲学定位。但总体而言，坚持源始时间性的奠基地位是共识。
