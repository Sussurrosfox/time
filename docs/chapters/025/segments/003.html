📖 《存在与时间》研读 逐段解析
首页 / 第 025 章 / 片段 003
📜 原文片段 (025/003)
海德格尔 原文
世界本身不是一种世内存在者。但世界对世内存在者起决定性的规定作用，从而唯当“有”世界，世内存在者才能来照面，才能显现为就它的存在得到揭示的存在者。但怎么就“有”世界？如果此在在存在者层次上是通过在世组建起来的，如果此在对其自身的存在之领会无论多么不确定，却都在本质上属于它的存在，那么此在不就具有一种对世界的领会吗？——虽然这种领会是先于存在论的领会，缺乏或至少可能缺乏确切的存在论洞见。对于操劳在世来说，随着世内照面的存在者，也就是说，随着存在者“在世界之内”这一基本性质，世界这样的东西不是已显现出来了吗？世界现象不是先于现象学就映入眼帘吗？它不是无需乎要求存在论的专题阐释就先于存在论就总已经处在先于现象学的眼界之中了吗？此在操劳消散于上手的用具。在这个环围里面，此在本身不是具有这样一种存在之可能性吗——即操劳所及的世内存在者的世界性随着这种存在者一齐以某种方式向此在亮相？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 世界：在海德格尔哲学中，“世界”不是由各种物体组成的集合，也不是物理空间，而是此在（人）生存于其中、与事物打交道的那个有意义的整体关系和境域。它先于任何具体的物体而存在，并使得物体能够作为有特定用途和意义的东西（如“工具”）向我们显现。
  • 世内存在者：指在世界之中存在的各种具体事物或对象，例如我们日常使用的工具（锤子、笔）、自然物，甚至他人。它们不能脱离“世界”这个意义背景而独立成为其所是。
  • 此在：特指人这种存在者，其本质在于“去存在”，即它总是关心、领会着自己的存在，并通过与世界打交道的方式（“在世”）来展开其生命。
  • 在世：此在最基本的存在方式，即它从来都不是孤立的，而是已经“在……世界之中”与他人、他物打交道。
  • 操劳：此在在日常世界中与事物打交道的基本方式，通常是一种非反思的、投入的使用、处理、关心活动（例如使用锤子钉钉子）。
  • 上手状态：事物在操劳活动中不是作为理论观察的“对象”，而是作为顺手可用的“工具”向我们显现的存在方式（锤子作为好用的锤子，而不是作为物理学对象）。
  • 先于存在论的领会：此在日常活动中对世界和自身存在的一种非主题化、非理论化的模糊理解。它先于任何哲学性的、系统化的存在论研究。
  • 世界性：世界之所以为世界的结构性整体，即使得世内存在者能够作为有用的、有意义的工具而出现的那个关联整体（例如，锤子的意义来自于它与钉子、木材、建房等活动构成的整个关联网络）。

2. 逐句转译

  1. “世界本身不是一种世内存在者。但世界对世内存在者起决定性的规定作用，从而唯当‘有’世界，世内存在者才能来照面，才能显现为就它的存在得到揭示的存在者。”

    • 世界本身并不是一个存在于世界之内的具体东西。但是，世界对于世界内的具体事物具有根本的决定性作用。只有在一个有意义的关系背景（世界）已经存在的前提下，世界内的具体事物才能与我们相遇，才能作为某种有特定意义和功能的东西（例如，作为一把“锤子”）被我们认识到。

  2. “但怎么就‘有’世界？如果此在在存在者层次上是通过在世组建起来的，如果此在对其自身的存在之领会无论多么不确定，却都在本质上属于它的存在，那么此在不就具有一种对世界的领会吗？——虽然这种领会是先于存在论的领会，缺乏或至少可能缺乏确切的存在论洞见。”

    • 那么，世界究竟是如何“存在”的呢？如果说，人（此在）在现实生存层面就是由“存在于世界之中”这种方式构成的，并且，人对自己存在的理解（尽管可能很模糊）在本质上就是他存在的一部分，那么，人不就已经拥有一种对世界的理解了吗？——尽管这种理解是日常的、非哲学性的，它可能缺少、或者至少有可能缺少清晰的哲学洞察。

  3. “对于操劳在世来说，随着世内照面的存在者，也就是说，随着存在者‘在世界之内’这一基本性质，世界这样的东西不是已显现出来了吗？世界现象不是先于现象学就映入眼帘吗？它不是无需乎要求存在论的专题阐释就先于存在论就总已经处在先于现象学的眼界之中了吗？”

    • 对于日常忙于事务（操劳）的人来说，当他与世界内的某个事物（比如一把锤子）打交道时，随着这个事物作为“在世界之内”的东西出现，世界这个现象本身不就已经显现出来了吗？世界的这种现象，难道不是在现象学这门学问出现之前，就已经被我们看到了吗？它难道不是不需要专门的哲学分析，在哲学研究之前，就总是已经处在我们的日常视野之中了吗？

  4. “此在操劳消散于上手的用具。在这个环围里面，此在本身不是具有这样一种存在之可能性吗——即操劳所及的世内存在者的世界性随着这种存在者一齐以某种方式向此在亮相？”

    • 人（此在）在日常生活中，会全神贯注地投入到那些顺手可用的工具（上手的用具）里。在这种被工具所环绕的境域中，人本身难道不是拥有这样一种存在的可能性吗——即，他所处理的那些事物的世界性（也就是使得该事物有意义的那整个背景关联），会伴随着这个事物本身，以某种方式向他揭示、展现出来？

3. 论证逻辑梳理

  • 前提1：世界不是世内存在者，但它规定着世内存在者如何显现。（确立世界的基础地位）
  • 问题提出：那么，世界是如何“有”的呢？（转向对世界之“存在方式”的追问）
  • 前提2：此在本质上是在世的存在，并且对自身存在有（哪怕是模糊的）领会。
  • 推论1：因此，此在天然就拥有一种对世界的（先于存在论的）领会。
  • 论证推进：通过考察此在的日常操劳活动来证实这种领会的存在。
  • 观察与反问：在操劳中，当我们使用世内存在者时，世界现象其实已经随之显现了。它先于任何哲学研究就为我们所熟悉。
  • 最终反问与深化：此在沉浸于用具时，难道不正是世界性（世界的结构整体）随着用具一同向此在揭示出来的时刻吗？这进一步巩固了“此在拥有先于存在论的世界领会”这一观点，并暗示了研究此在日常活动是通达世界现象的途径。

4. 整体概括

这段话的核心是在探讨“世界”这个现象是如何向我们呈现的。海德格尔首先强调，世界不是某个具体的东西，而是让所有东西能作为有意义的工具向我们显现的那个背景。他然后论证道，我们人（此在）因为天生就“活在世上”并且对自己的存在有所理解，所以我们其实在日常生活中，就已经对世界有了一种非反思的、直接的领会。当我们忙于使用各种工具（比如写作时用笔，修理时用锤子）时，我们不仅仅看到了笔和锤子本身，实际上，使得笔能作为笔、锤子能作为锤子的那个整个意义网络（世界）也已经一同向我们“亮相”了。这个世界现象，远在哲学家们开始研究它之前，就已经是我们日常经验的一部分了。因此，要理解“世界”，我们不应该脱离生活去空想，而应该回到我们与事物打交道的日常活动中去寻找答案。

5. 争议与说明

本段解读相对一致。海德格尔在此旨在为他的现象学方法奠定基础，即通过分析此在的日常在世存在来揭示基本的存在论结构。争议点通常不在于对本段字面意思的理解，而更多在于如何精确把握“世界”、“世界性”与“世内存在者”的关系，以及“先于存在论的领会”在方法论上究竟如何运作。有些诠释会更强调这种领会的“实践性”和“身体性”，而另一些则可能更关注其与后期“存在之历史”思想的关联。但就本段而言，其核心论证——世界现象在日常操劳中预先被给予——是海德格尔学界广泛接受的观点。
