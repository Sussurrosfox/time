海德格尔 原文
所以，仍然保存着的古董曾属于此在的世界，而它们的历史性质就奠基于此在的“过去”。这样一来，仿佛只有“过去的”此在而不是“当前的”此在是历史的。然而，如果我们把“过去”规定为“现在不再现成或不再上手”，那么根本说来此在会是过去的吗？显然此在从不可能是过去的，这倒不是因为它不流逝，而是因为它本质上就不可能是现成的，毋宁说，如果此在存在，它就生存着。在存在论的严格意义上，不再生存的此在不是过去了，而是曾在此。仍还现成的古董具有过去性质和历史性质，其根据在于它们以用具方式属于并出自一个曾在此的此在的一个曾在世界。曾在此的此在是那原本具有历史性的东西。但是否此在由于它不再在此才始成为历史性的？抑或它岂非恰恰作为实际生存着的此在就是历史性的？是否此在只在曾在此的此在这一意义上才是曾在的此在，抑或它作为当前化的将来的此在就是曾在的，亦即在其时间性的到时中就是曾在的？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在（Dasein）：海德格尔哲学中的核心概念，指人的存在方式，其本质在于“生存”（Existenz），即不断筹划自身、面向未来的可能性而存在。此在不是静态的“现成”之物，而是动态的、时间性的存在。

  • 现成（vorhanden）：指事物像客体一样静态、独立地“摆在那里”的存在方式。此在本质上不是现成的，因为它在生存中不断展开。

  • 上手（zuhanden）：指用具在实践活动中被“顺手使用”的存在方式，与人的活动紧密相关。用具只有在“上手”状态中才真正作为用具存在。

  • 曾在（Gewesen）：此在时间性中的一个维度，指此在以某种方式“已经存在过”。它不是简单的“过去”，而是此在生存中始终携带着的、构成其当前存在的背景。

  • 历史性（Geschichtlichkeit）：此在的根本属性，指此在的存在本身就是在时间中展开的、具有“命运”与“传承”的历程。历史性不是此在“结束”后才有的，而是它生存着就具备的。

  • 时间性（Zeitlichkeit）：此在存在的整体结构，由“将来”、“曾在”、“当前”三个维度共同“到时”（Zeitigung）而构成。此在的存在就是时间性的展开。

2. 逐句转译

  • “所以，仍然保存着的古董曾属于此在的世界，而它们的历史性质就奠基于此在的‘过去’。”
    → 我们现在还能看到的古董，曾经是某个人的生活世界的一部分。它们之所以有“历史感”，是因为它们和那个人的“过去”有关。

  • “这样一来，仿佛只有‘过去的’此在而不是‘当前的’此在是历史的。”
    → 这容易让人以为，只有已经“结束”了的人生才是历史的，而正在活着的人反而不是。

  • “然而，如果我们把‘过去’规定为‘现在不再现成或不再上手’，那么根本说来此在会是过去的吗？”
    → 但如果我们把“过去”理解成“现在已经不再存在、不再被使用”，那么此在真的能变成“过去”吗？

  • “显然此在从不可能是过去的，这倒不是因为它不流逝，而是因为它本质上就不可能是现成的，毋宁说，如果此在存在，它就生存着。”
    → 显然，此在不可能成为“过去”，这不是因为它不会消逝，而是因为它本质上就不是那种可以“摆在那里”的东西——只要此在还存在，它就是在“活着”、在“生存”。

  • “在存在论的严格意义上，不再生存的此在不是过去了，而是曾在此。”
    → 从哲学上严格来说，一个已经不在世的此在，我们不称它为“过去”了，而是称它“曾在此”——它曾经在这里存在过。

  • “仍还现成的古董具有过去性质和历史性质，其根据在于它们以用具方式属于并出自一个曾在此的此在的一个曾在世界。”
    → 古董之所以有“过去感”和“历史感”，是因为它们作为用具，曾经属于一个“曾在此”的人，来自那个人曾经生活过的世界。

  • “曾在此的此在是那原本具有历史性的东西。”
    → 真正具有历史性的，是那个“曾在此”的此在本身。

  • “但是否此在由于它不再在此才始成为历史性的？抑或它岂非恰恰作为实际生存着的此在就是历史性的？”
    → 但此在是不是因为它不在了，才变成“历史性的”？还是说，它恰恰在活着的时候，本身就是历史性的？

  • “是否此在只在曾在此的此在这一意义上才是曾在的此在，抑或它作为当前化的将来的此在就是曾在的，亦即在其时间性的到时中就是曾在的？”
    → 此在是不是只有等到“曾在此”时才算是“曾在的”？还是说，此在作为正在活着的、面向未来的存在，它本身在时间性的展开中，就一直是“曾在的”？

3. 论证逻辑梳理

  • 前提：我们通常认为古董是“历史的”，因为它们来自“过去的此在”。
  • 问题提出：这容易导致误解，以为只有“结束了的此在”才是历史的。
  • 关键转折：海德格尔指出，如果我们把“过去”定义为“不再现成或上手”，那么此在根本不可能成为“过去”，因为此在的本质是“生存”，不是“现成物”。
  • 概念澄清：不再生存的此在不是“过去”，而是“曾在此”；古董的历史性来自于它曾属于一个“曾在此”的此在的世界。
  • 核心追问：此在是死后才成为历史性的吗？不，海德格尔暗示：此在在生存中就是历史性的，它的“曾在”不是等到结束才有的，而是在时间性中一直伴随着它。

4. 整体概括

这段话的核心是在纠正我们对“历史性”的日常误解：我们通常以为只有“结束了”的人或事物才是历史的，但海德格尔指出，此在（人）的存在本身就是历史性的，因为它活在时间中，携带着自己的“曾在”，面向未来而生存。古董之所以是历史的，不是因为它“过去了”，而是因为它曾属于一个“曾在此”的此在的世界。此在的历史性不是死后才获得的属性，而是它作为时间性存在的本质特征。我们活着，就已经是历史性的。

5. 争议与说明

本段解读相对一致，争议不大。可能的细微分歧在于：

  • 对“曾在”（Gewesen）的理解：有学者强调它不仅是“过去的事实”，更是此在“承担并重新诠释”的生存论结构；
  • 对“历史性”与“历史学”的区分：海德格尔在此更强调生存论的历史性，而非历史学所研究的“过去事件”。

但整体上，这段的核心论证——此在在生存中即历史性——是学界共识。
