📖 《存在与时间》研读 逐段解析
首页 / 第 091 章 / 片段 007
📜 原文片段 (091/007)
海德格尔 原文
历史还意味着“在时间中”演变的存在者整体。虽然自然也“在时间中”运动，但这里强调的是“在时间中”演变的存在者与自然的区别。也就是说，历史意味着人的、人的组合及其“文化”的演变和天命，在这里历史主要不是指存在者的演历这一存在方式，而是主要指存在者的一种领域；人们着眼于人的生存的本质规定性，即通过“精神”和“文化”把这一存在者的领域与自然区别开来，虽说如果这样领会历史，即使自然也以某种方式属于历史。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 历史：在海德格尔哲学中，“历史”通常指此在（人的存在）在其时间性中的演历过程，即此在通过其生存活动展开自身的方式。但在本段中，海德格尔特别指出，这里的“历史”并非强调这种存在方式，而是指一个特定的存在者领域，即与人及其文化、天命相关的演变整体。
  • 存在者：指一切实际存在的东西，包括人、物体、自然等。在本段中，“存在者”特指那些与人的活动、文化、精神相关的存在物。
  • 自然：指非人为的、物理世界的存在者及其运动。海德格尔在此区分自然与历史，强调自然虽然也“在时间中”运动，但不具备历史所特有的人文与文化内涵。
  • 天命：指人类共同体在历史中的命运或命定历程，是集体性的历史进程，而非个人命运。
  • 精神：在此指人的意识、文化创造力和理性等，是人区别于自然的存在特征。

2. 逐句转译

  • “历史还意味着‘在时间中’演变的存在者整体。”
    → 历史也可以被理解为：所有在时间进程中发生变化的事物所构成的整体。

  • “虽然自然也‘在时间中’运动，但这里强调的是‘在时间中’演变的存在者与自然的区别。”
    → 自然世界确实也在时间中变化运动，但我们这里要强调的是：历史所指的“在时间中演变的存在者”和自然世界是不同的。

  • “也就是说，历史意味着人的、人的组合及其‘文化’的演变和天命，”
    → 换句话说，历史在这里指的是人、人类社会以及他们的文化所经历的变迁与命运。

  • “在这里历史主要不是指存在者的演历这一存在方式，而是主要指存在者的一种领域；”
    → 注意：这里所说的“历史”，重点不是指事物“如何”在时间中展开自身（即不是作为一种存在方式），而是指某一类特定的“事物领域”。

  • “人们着眼于人的生存的本质规定性，即通过‘精神’和‘文化’把这一存在者的领域与自然区别开来，”
    → 人们是根据人特有的生存本质——也就是人具有“精神”和“文化”——来把这个领域（历史）和自然区分开的。

  • “虽说如果这样领会历史，即使自然也以某种方式属于历史。”
    → 不过，即便我们这样理解历史，自然在某种意义上也可以被纳入历史的范畴。

3. 论证逻辑梳理

  • 前提：历史通常被理解为“在时间中演变的存在者整体”。自然也在时间中运动。
  • 区分提出：但本段要区分的是：历史所指的“演变的存在者”与自然不同。历史特指与人、人的组合、文化及其天命相关的演变。
  • 概念聚焦：进一步明确，这里的历史概念主要不是指“演历”这种存在方式（即事物如何在时间中展开），而是指一个特定的存在者领域——即人文、文化领域。
  • 区分依据：这一区分是基于人的生存本质，即人拥有“精神”和“文化”，从而将历史这一领域与自然区别开来。
  • 补充说明：即便做了这样的区分，自然仍可以“以某种方式”被纳入历史，但这并非本段的核心定义。

4. 整体概括

这段文字是在对“历史”这个概念进行一种特定的界定。它指出，虽然历史通常指所有在时间中变化的事物，但在这里，海德格尔强调的是历史作为“人的领域”——包括个人、群体、文化以及他们的命运变迁。这与单纯自然界的运动变化是不同的，因为历史的内涵是由人的“精神”和“文化”所定义的。尽管自然也可能被间接地纳入历史视野，但本段的核心是要把历史理解为一个以人的活动和意义为核心的独特领域，而不是泛指一切随时间变化的存在者。

5. 争议与说明

本段解读相对一致，争议较少。主要可能存在的讨论点在于：海德格尔在此对“历史”的领域化界定，是否与他后期更强调“历史性作为此在的存在方式”有所张力。但本段本身是从流俗历史观切入进行辨析，目的正是为后续引出他本人对“历史性”的生存论分析做铺垫，因此这种表面上的“领域化”定义可视为一种论述策略。
