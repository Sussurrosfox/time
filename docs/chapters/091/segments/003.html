📜 原文片段 (091/003)
海德格尔 原文
切近的目标是：为追问历史本质的源始问题亦即为历史性的生存论构造找到一个出发点。这一地点由那源始地即是历史性的东西标识出来。所以，考察以标识出那在流俗的此在解释中用“历史”和“历史的”这两个词所意指的东西开始。这两个词有多重含义。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 历史性：在海德格尔哲学中，指此在（人的存在）的根本时间性结构，即此在的存在本质上就是历史的，它总已经在历史中展开，并通过对未来的筹划来理解自身。它不是指发生在过去的事件，而是此在存在的构成方式。
  • 生存论构造：指此在存在的根本结构或构成方式，是此在在世存在的先天条件，不是后天形成的心理或社会属性。
  • 此在：海德格尔用来指称"人"的存在方式的术语，强调人不是现成的实体，而是通过其存在（在世之在、操心、时间性等）来定义自身的。
  • 流俗的此在解释：指日常生活中、未经哲学反思的普通人对"历史"的理解，通常将历史视为过去的客观事件集合。

2. 逐句转译

  • "切近的目标是：为追问历史本质的源始问题亦即为历史性的生存论构造找到一个出发点。" → 我们眼前要做的是：为探讨"历史到底是什么"这个根本问题，也就是为理解人（此在）如何本质上就是历史性的存在结构，找到一个起点。

  • "这一地点由那源始地即是历史性的东西标识出来。" → 这个起点应该由那个从一开始就是历史性的东西来标示。

  • "所以，考察以标识出那在流俗的此在解释中用'历史'和'历史的'这两个词所意指的东西开始。" → 因此，我们的研究要从弄清楚普通人在日常谈话中用"历史"和"历史的"这些词时，他们到底指的是什么开始。

  • "这两个词有多重含义。" → 这两个词在日常生活中其实有很多不同的意思。

3. 论证逻辑梳理

  • 前提：要探讨历史的本质问题，需要找到一个合适的出发点。
  • 推进：这个出发点必须由本质上就是历史性的东西来标示。既然日常理解中已经使用了"历史"概念，那么就先从分析这些日常用法入手。
  • 结论：因此，研究应该从梳理"历史"和"历史的"在日常语言中的多重含义开始，以此为后续的哲学分析奠定基础。

4. 整体概括

这段话明确了海德格尔的研究策略：要探讨"人为什么本质上是历史性的存在"这个哲学问题，不能凭空开始，而要先回到普通人对"历史"这个词的各种日常理解。通过分析这些日常用法中蕴含的多重含义，可以为更深入的哲学分析找到一个坚实的起点。这是一种"从日常理解出发，再超越日常理解"的现象学方法。

5. 争议与说明

本段解读相对一致，属于方法论说明段落，争议较少。主要共识是：海德格尔在这里采用了现象学的"返回日常"策略，通过分析流俗理解来为生存论分析铺路。
