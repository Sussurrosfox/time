海德格尔 原文
于是，历史主要不是意指过去之事这一意义上的“过去”，而是指出自这过去的渊源。“有历史”的东西处在某种变易的联系中，在这里“发展”是时兴时衰。以这种方式“有历史”的东西同时也能造就历史。这种东西以“造就时代的”或“划时代”的方式在“当前”规定一种“将来”。在这里历史意味着一种贯穿“过去”、“现在”与“将来”的事件联系和“作用联系”。从而过去在这里根本不具特别的优先地位。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 历史（Geschichte）：在海德格尔哲学中，“历史”不是指已经发生的、作为客观研究对象的一系列“过去事件”，而是指一种贯穿时间、不断生成变化的动态整体。它强调从过去流出的“渊源”如何持续地塑造和影响现在与未来。

  • 渊源（Herkunft）：指事物或存在的“来源”或“出身”，但它不是静止的起点，而是持续在当下发挥作用、规定着事物如何展开的力量。

  • 有历史（geschichtlich sein）：指某物（尤其是人的存在）本身就处在历史的联系中，它不仅承受历史的影响，也参与造就历史。这是一种存在方式，意味着在时间的整体关联中生成变化。

  • 变易的联系（Zusammenhang des Geschehens）：指历史不是一连串孤立的事件，而是一个不断变化、相互关联的动态过程。

  • 造就时代 / 划时代（epochemachend）：指在历史进程中，某些行动或事件具有决定性的力量，能够重新规定时代的走向，塑造未来的可能性。

  • 事件联系 / 作用联系（Wirkungszusammenhang）：强调历史中各个时刻不是孤立的，而是相互影响、彼此作用的整体。

2. 逐句转译

  1. “于是，历史主要不是意指过去之事这一意义上的‘过去’，而是指出自这过去的渊源。” - 这里海德格尔首先澄清：我们通常以为历史就是“过去发生的事”，但他认为历史的核心不是那些已经完结的过去，而是从过去持续涌流出来、至今仍在影响我们的“源头”或“来历”。

  2. “‘有历史’的东西处在某种变易的联系中，在这里‘发展’是时兴时衰。” - 一个真正“有历史”的事物，并非静止不动，而是处于一种不断变化的关系网络中；它的“发展”不是直线前进，而是有起有落、有兴有衰的动态过程。

  3. “以这种方式‘有历史’的东西同时也能造就历史。” - 正因为它是这样活在历史之流中，它不只是被动承受历史，同时也能主动地“创造历史”。

  4. “这种东西以‘造就时代的’或‘划时代’的方式在‘当前’规定一种‘将来’。” - 这种能够创造历史的存在，通过它在“当前”做出的具有时代意义的行动，重新定义了“未来”的方向——它的影响是决定性的，能开辟一个新的时代。

  5. “在这里历史意味着一种贯穿‘过去’、‘现在’与‘将来’的事件联系和‘作用联系’。” - 所以，海德格尔所理解的历史，是一种贯通了过去、现在与未来的整体关联；这三者不是割裂的阶段，而是相互影响、彼此作用的一个动态网络。

  6. “从而过去在这里根本不具特别的优先地位。” - 正因为历史是这样一个整体，过去并不比其他时间维度（现在、未来）更重要；它只是这个动态联系中的一个环节，没有特权。

3. 论证逻辑梳理

  • 前提：人们通常将历史等同于“过去之事”。
  • 第一步：海德格尔提出纠正——历史的核心是“出自过去的渊源”，即从过去持续影响至今的力量。
  • 第二步：进一步说明，“有历史”意味着处在不断变化的联系中，发展并非线性，而是兴衰交织。
  • 第三步：指出这种动态的存在不仅能承受历史，也能主动“造就历史”。
  • 第四步：具体说明它是如何在“当前”通过划时代的行动去规定“将来”的。
  • 第五步：由此总结，历史是过去、现在、未来三者贯通的事件与作用联系。
  • 结论：在这样的整体联系中，过去并不享有优先地位。

4. 整体概括

这段文字的核心是重新定义“历史”。海德格尔反对将历史简单看作一堆过去的、已完成的事件；他强调历史是一种从过去流出、贯穿现在并指向未来的动态整体。一个“有历史”的存在，既承受着历史的影响，也通过它在当前具有划时代意义的行动，参与塑造未来。因此，历史是过去、现在、未来相互关联、相互作用的整体过程，在这个意义上，过去并不比其他时间维度更重要。

5. 争议与说明

本段解读相对一致，学界普遍认同这是海德格尔对流俗历史观的批判，并转向一种以“时间性”和“ Wirkungszusammenhang（作用联系）”为核心的历史理解。可能的细微争议在于“渊源（Herkunft）”与“过去”的关系——有学者强调“渊源”仍带有某种“过去性”，但海德格尔在此要弱化的正是这种理解，他更强调渊源是持续“到来”并规定着当前与未来的力量。
