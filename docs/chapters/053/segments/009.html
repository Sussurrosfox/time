结构化精读

1. 术语释义

  • 先于自身的存在：此在（人）在结构上总是“走在自己前面”，向着自己的可能性去存在。这不是时间上的先后，而是指人本质上总是在筹划、朝向自己能够成为的样子。

  • 能在：此在的核心特征，指人不是固定不变的实体，而是始终拥有成为各种不同样子的可能性。人就是由这些可能性构成的。

  • 本真与非本真：

  • 本真：此在清醒地意识到并承担起自己的可能性，亲自做出选择。

  • 非本真：此在迷失于公众意见（常人），逃避自己的独有可能性，按照“大家都会怎么做”来生活。

  • 常人：一个非个人的、匿名的公众主体。它不是某个具体的人，而是支配着日常生活的社会规范、公众意见和平均化理解。

  • 筹划：此在理解自身和世界的基本方式，即总是将自己的存在投向并活出某种可能性。

  • 为何之故：此在生存的终极理由或意义指向，是此在一切行动和选择的最终依据。

2. 逐句转译

  • “先于自身的存在就是向最本己的能在的存在。”

  • “人这种存在者，其基本结构就是‘走在自身前面’。这意味着，他始终是朝着他自己最本真的、属于他自己的各种可能性去存在的。”

  • “在这种存在中，就有为本真的各种生存上的可能性所需的自由存在之可能性的生存论存在论条件。”

  • “正是在这种‘走在自身前面’的结构中，蕴含了一个根本条件。这个条件使得此在能够自由地选择，并真正地去实现那些本真的、属于他自己的生命可能性。”

  • “能在就是如其实际上存在着的那样存在的此在向来为其故而存在的东西。”

  • “这个‘可能性存在’（能在），就是每个具体存在着的人，他一切行动和选择的最终目的和意义所在。人活着，从根本上说，就是为了实现他的这些可能性。”

  • “但只要这样一种向着能在的存在本身是被自由规定的，那么此在就也可能无意地对其各种可能性行事，它可能非本真地存在且在实际上首先与通常以这种方式存在。”

  • “但是，正因为这种朝向可能性的存在是由自由决定的，人也完全可以选择不去清醒地面对它。他可能浑浑噩噩地对待自己的可能性，以一种‘非本真’的方式生活。而且，在现实中，人最开始、最经常的，恰恰就是这种状态。”

  • “那本真的‘为何之故’始终未被抓住，它自己的能在的筹划交付给常人处理了。”

  • “这样一来，他生命中那个真正属于他自己的、本真的意义和目标，他就始终没能抓住。他把自己对未来的规划和选择，完全交给了‘大家’（常人）去决定。”

  • “因而在先行于自身的存在中，这个‘自身’总是措常人自己意义上的自身。”

  • “所以，在这种‘走在自身前面’的结构中，这个被走在前面的‘自己’，其实通常指的是那个被‘大家’所定义和理解的‘自己’，而不是真正的、独特的自己。”

  • “即使在非本真状态中，此在本质上也仍然先行于自身...”

  • “然而，即便人处在这样一种迷失的、非本真的状态中，他‘走在自身前面’的这个根本结构依然存在，丝毫没有改变...”

3. 论证逻辑梳理

  1. 前提： 此在的本质结构是“先于自身的存在”（总是朝向自己的可能性）。
  2. 核心推论： 这个结构蕴含了此在能够“本真存在”（自由地承担自身可能性）的先天条件。
  3. 转折点： 然而，自由也包含了“不自由选择”的可能。此在可以逃避这种本真的承担。
  4. 常态描述： 在实际生活中，此在“首先与通常”选择的就是这种逃避状态，即“非本真存在”。
  5. 非本真机制： 在这种状态下，此在将自己的可能性筹划（对未来的理解和选择）交给了“常人”。
  6. 结论一： 因此，在日常状态下，“先于自身”中所指向的那个“自身”，实际上是“常人”所理解的自我。
  7. 结论二（强调结构优先）： 但即便如此，此在“先于自身”的这一基本生存结构本身是不可剥夺的，它即使在非本真状态下也依然成立。

4. 整体概括

这段话的核心是在解释海德格尔一个关键思想：人天生就是一种面向未来、充满可能性的存在，这为我们活出真我（本真状态）提供了基础。但恰恰因为我们是自由的，我们也完全可以逃避这份自由和责任，选择随波逐流，按照社会大众（常人）的期望去生活，这就是非本真状态。现实中，我们大部分时间都活在这种非本真状态里，把自己的生命意义和选择权交给了“别人”。因此，虽然我们结构上总是在“奔向未来”，但这个“未来的自己”往往只是社会期望的投影。然而，海德格尔强调，即便我们如此迷失，我们作为“可能性存在”的这一根本结构是永远不会改变的。

5. 争议与说明

本段解读相对一致。它清晰地阐述了“此在的生存论结构”与“此在日常的实际状态”之间的辩证关系。一个可能的细微争议点在于对“首先与通常”的强调程度：有些阐释者会更强烈地认为，海德格尔在此描绘了一种近乎命定的“沉沦”常态；而另一些则认为，他只是在描述一个事实性的倾向，并未排除本真觉醒的随时可能性。但就本段文字而言，其描述是明确且自洽的。
