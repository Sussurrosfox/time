📖 《存在与时间》研读 逐段解析

📜 原文片段 (053/020)
海德格尔 原文
在纯粹冲动中，操心还没有变成自由的，虽则是操心才从存在论上使此在可能从它本身方面受到冲动的驱迫。反之，在上瘾中，操心总已被拘束住了。上瘾与冲动是植根于此在被抛境况的两种可能性。“生命冲动”〔der Drang zu leben〕是消灭不了的，要由世界“养活”〔gelebt von〕的瘾头是铲除不掉的。但因为而且只因为二者在存在论上都植根于操心，所以二者都可以靠操心之为本真的操心而在存在者层次上和生存上改变样式。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 操心（Sorge / Care）
    在海德格尔哲学中，“操心”是此在（人的存在）的基本建构，指人总是已经在筹划自身可能性、关切自身存在的整体状态。它先于任何具体活动，构成了人的生存论基础。

  • 冲动（Trieb / Impulse）
    指此在未经反思、直接向外迸发的原始驱动力，如本能性的欲望或行动倾向。它处于前反思的层次，尚未被此在自由地把握。

  • 上瘾（Hang / Addiction）
    在此指一种沉溺性的、被世界中的某物所束缚的存在状态。此在陷入对某物的依赖，从而丧失了自由对待该物的可能性。

  • 被抛境况（Geworfenheit / Thrownness）
    指此在总是已经被抛入某个既定的世界和生存情境中，这一事实性构成了它开展生存的背景与限制。

  • 本真的操心（eigentliche Sorge / Authentic Care）
    此在以清醒、决断的方式直面自身的存在，承担起自身的被抛与可能性，从而自由地筹划其生存。

2. 逐句转译

  • “在纯粹冲动中，操心还没有变成自由的，虽则是操心才从存在论上使此在可能从它本身方面受到冲动的驱迫。”
    当我们完全被本能冲动驱使时，我们的“操心”还没有达到自由状态；尽管如此，正是“操心”这种基本结构，才在根本上使我们有可能被自身的冲动所驱动。

  • “反之，在上瘾中，操心总已被拘束住了。”
    相反，当我们陷入上瘾的状态时，“操心”已经完全被成瘾的对象所束缚、困住了。

  • “上瘾与冲动是植根于此在被抛境况的两种可能性。”
    无论是上瘾还是冲动，都是从此在的“被抛境况”中生发出来的两种可能的生存方式。

  • “生命冲动是消灭不了的，要由世界‘养活’的瘾头是铲除不掉的。”
    那种原始的生命冲动是无法彻底消除的；同样，那种依赖世界来“喂养”的瘾头也是无法根除的。

  • “但因为而且只因为二者在存在论上都植根于操心，所以二者都可以靠操心之为本真的操心而在存在者层次上和生存上改变样式。”
    但恰恰因为冲动和上瘾在根本上都来源于“操心”，所以，只要我们能够将“操心”转变为“本真的操心”，就有可能在具体的生存状态中改变冲动和上瘾的表现形式。

3. 论证逻辑梳理

  • 前提：冲动与上瘾是此在的两种生存现象，它们都源自于此在的“被抛境况”。
  • 推进1：阐明冲动与上瘾在“操心”结构中的不同位置——冲动中操心尚未自由，上瘾中操心已被束缚。
  • 推进2：指出这两种状态虽然顽固（无法消灭），但它们的存在论根源都是“操心”。
  • 结论：正因如此，通过转向“本真的操心”，此在可以在生存层面改变冲动与上瘾的样态。

4. 整体概括

这段文字探讨的是人如何被冲动与上瘾所驱动或束缚，以及改变的可能。海德格尔指出，冲动和上瘾都源于人“被抛入世界”这一基本处境，也都建立在“操心”这一生存结构之上。在冲动中，人尚未自由；在上瘾中，人已被束缚。但它们都不是命中注定不可变的——正因为它们扎根于“操心”，只要我们能够以清醒、决断的方式面对自身的存在（即“本真的操心”），就有机会在现实生活中改变冲动与上瘾的具体表现方式。

5. 争议与说明

本段解读相对一致，争议较少。主要讨论集中在“本真的操心”如何具体转化冲动与上瘾——有学者认为这是一种存在论的“转念”，也有解释强调它需要通过具体的“决断”行为在生存中实现。但核心论点（二者植根于操心，故可借本真操心改变）是学界共识。
