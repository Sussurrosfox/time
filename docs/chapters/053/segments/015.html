海德格尔 原文
此在为能在之故而在，这样的能在本身就有在世的存在方式。因此从存在论上看来能在就和世内存在者有关联。操心总是操劳与操持—即使只是通过褫夺的方式。在意求中，一个被领会的存在者被掌握了，也就是说，一个被向它的可能性加以筹划的存在者被掌握了；它是作为有待于操劳的存在者或者有待于靠操持带到其存在中去的存在者而被掌握的。因此，在意求中总包含所意求的东西，而这种东西已经从一种为何之故中得到规定。组建意求之存在论的可能性的有：一般的为何之故先行展开的状态〔先行于自身的存在〕，可操劳的东西的开展状态〔作为已经存在的何所在的世界〕，此在有所领会地向一种能在筹划自身，这种能在即向“意求的”存在者的某种可能性的能在。在意求的现象中透映出作为基础的操心之整体性。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学中的核心概念，指人的存在方式，其本质在于“去存在”，即不断通过自身的行动和选择来塑造自身。
  • 能在：此在的根本特性，指此在总是面向未来、朝向自身可能性而存在的动态能力。此在不是现成的，而是“能够去成为”某种样子。
  • 在世：此在存在的基本结构，指此在从来不是孤立的主体，而是始终已经与一个世界共同存在，与世界中的事物和他人打交道。
  • 操心：此在存在的整体结构，包含三个环节：“先行于自身”（面向可能性）、“已经在世界中”（被抛入既定的情境）、“依寓于世内存在者”（与事物和他人打交道）。它是此在存在的整体方式。
  • 操劳：操心的一种具体样式，指此在与非人的“物”（工具、器物）打交道的存在方式。
  • 操持：操心的另一种具体样式，指此在与“他人”打交道的存在方式。
  • 褫夺：一种缺失或缺乏的方式。这里指即使没有实际的操劳或操持活动，操心也以“缺失”这种方式在场。
  • 意求：一种具体的操心现象，指此在朝向某个特定的、被领会的存在者（事物或人）去存在的倾向或意图。
  • 筹划：此在理解存在的方式，即主动地向着自身的可能性展开和投射，照亮和理解事物的意义。
  • 为何之故：此在行动和筹划的最终目的或缘由，根植于此在自身的存在（即其“能在”）。
  • 先行于自身的存在：操心的第一个环节，指此在总是已经跑在自己前面，朝向自己的可能性。
  • 已经存在的何所在的世界：操心的第二个环节，指此在总是已经被抛入一个已经展开的、具有特定意义关联的世界。
  • 整体性：指操心结构（先行于自身-已经在世-依寓于世内存在者）是一个不可分割的统一整体。

2. 逐句转译

  1. 原文：此在为能在之故而在，这样的能在本身就有在世的存在方式。因此从存在论上看来能在就和世内存在者有关联。

    • 转译：人（此在）存在的根本原因，就是为了实现他自己的种种可能性（能在），而这种“去成为可能”的方式，天然就是在一个世界里、和世界里的事物他人打交道（在世）。所以，从存在论的角度看，人的可能性（能在）天生就和世界里碰到的各种东西（世内存在者）绑在一起。

  2. 原文：操心总是操劳与操持—即使只是通过褫夺的方式。

    • 转译：人的整个存在状态（操心），具体表现出来无非就是两种形式：要么在忙活东西（操劳），要么在照料他人（操持）——哪怕有时候他什么都不做，这种“不做”本身也是一种特殊形式的、缺失状态的操心。

  3. 原文：在意求中，一个被领会的存在者被掌握了，也就是说，一个被向它的可能性加以筹划的存在者被掌握了；它是作为有待于操劳的存在者或者有待于靠操持带到其存在中去的存在者而被掌握的。

    • 转译：当我们对某个东西或某个人有某种意图或目标时（意求），我们其实是已经理解了那个对象，并且把它放在它的各种可能性里来看待（筹划）。我们把这个对象看作是“需要我去使用或处理的东西”，或者是“需要我通过关怀和行动去帮助他实现自身的人”。

  4. 原文：因此，在意求中总包含所意求的东西，而这种东西已经从一种为何之故中得到规定。

    • 转译：所以，任何意图（意求）都天然地包含了它指向的那个目标物，而这个目标物之所以成为目标，是由一个更深层的“为了什么”（为何之故）所决定的。比如，你“想要一杯水”，这个意图是由你“为了解渴”这个更根本的存在目的所规定的。

  5. 原文：组建意求之存在论的可能性的有：一般的为何之故先行展开的状态〔先行于自身的存在〕，可操劳的东西的开展状态〔作为已经存在的何所在的世界〕，此在有所领会地向一种能在筹划自身，这种能在即向“意求的”存在者的某种可能性的能在。

    • 转译：一个意图（意求）之所以可能，在存在论上需要三个前提条件同时具备：
      • 第一，人总是已经为了某个终极目的（为何之故）而活着，这个目的引领着他（先行于自身的存在）。
      • 第二，人周围的世界以及世界里那些可供使用或打交道的物件和他人，它们的意义和用途已经对人敞开了（已经存在的何所在的世界）。
      • 第三，人自己能够理解自身，并主动地朝着一种可能性去塑造自己，这种可能性具体就体现在他意图去处理的那个对象（所意求的存在者）上。

  6. 原文：在意求的现象中透映出作为基础的操心之整体性。

    • 转译：所以，从“意图”这个具体的现象里，我们可以清晰地看到，它背后依赖的是人的整个生存结构（操心）——那个由“面向未来”、“身处世界”、“与物他人纠缠”三者构成的不可分割的整体。

3. 论证逻辑梳理

  1. 前提/起点：此在的本质是“能在”，并且这种能在必然是在世之在。
  2. 核心论断：此在的整体存在结构是“操心”，它具体化为“操劳”（对物）和“操持”（对人）。
  3. 分析具体现象：以“意求”（意图）这一具体现象为例进行分析。
    • 指出“意求”总是针对一个已被领会和筹划的存在者（物或人）。
    • 进而指出“意求”的内容（所意求的东西）是由更深层的“为何之故”（终极目的）所规定的。
  4. 回溯可能性条件：追问“意求”这种现象何以可能？其存在论基础是什么？
    • 答案是操心的三个结构性环节：
      • A. “先行于自身”（为何之故的展开）
      • B. “已经在世”（世界的展开）
      • C. “依寓于世内存在者并筹划自身”（向特定能在的筹划）
  5. 得出结论：因此，从“意求”这个具体的、局部的现象，可以反衬和揭示出作为其基础的、完整的操心结构。

逻辑链条总结：从“能在”的本质 → 导出“操心”的整体结构 → 通过分析“意求”这一具体样态 → 揭示“意求”依赖于操心结构的三个环节 → 最终证明操心结构是具体生存现象的统一基础。

4. 整体概括

这段话的核心是在阐述人的具体意图和行为（“意求”）是如何根植于人的整体生存结构（“操心”）之中的。海德格尔认为，人（此在）天生就是为了实现自身可能性（能在）而存在于世界之中的，这种存在方式整体上被称为“操心”，它具体表现为与事物打交道（操劳）和与他人打交道（操持）。当我们对某物或某人产生一个具体的意图（比如想喝杯水或帮助一个人）时，这个意图并不是孤立的。我们已经理解了对象，并把它置于其可能性中（筹划），而这个具体意图又是由我们更深层的人生目的（为何之故）所驱动的。因此，任何一个微小意图得以可能，都必须同时具备三个条件：1）我们有面向未来的目的性；2）我们身处一个已经对我们敞开的意义世界；3）我们能主动地朝向与那个意图对象相关的可能性去塑造自己。最终，通过分析“意图”这个看似简单的现象，海德格尔向我们揭示，它就像一扇窗户，清晰地映照出了人那由“目的-世界-行动”三者构成的、不可分割的完整生存结构——操心。

5. 争议与说明

本段解读相对一致。这段话是海德格尔在《存在与时间》中系统构建“操心”作为此在整体结构的关键环节，论证清晰，逻辑严密，旨在展示具体生存现象（意求）如何植根于基础存在论结构（操心）。学界对于“操心”结构本身的重要性并无争议，争议点多集中于这一结构在全书论证中的终极有效性，或它与后续“时间性”分析的关系，但对本段内部论证的理解是共识大于分歧的。
