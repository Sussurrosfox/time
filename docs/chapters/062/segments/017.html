📖 《存在与时间》研读 逐段解析

📜 原文片段 (062/017)
海德格尔 原文
结束的这些样式中没有一种可以恰当地标画作为此在之终结的死亡。如果在结束的上述意义下把死领会为到头，那么此在从而就被设定为现成事物或上手事物了。在死亡中，此在并未完成，也非简简单单地消失，更不曾就绪或作为上手事物颇可利用。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在 (Dasein)：海德格尔哲学的核心概念，特指“人的存在”。它不是指作为一个生物体或物体的人，而是指人这种能够反思自身存在、对“存在”发问的存在者。此在的本质在于其“生存”，在于它的可能性与对自身存在的关切。
  • 死亡 (Tod)：在海德格尔哲学中，死亡并非生物学意义上的生命终止事件，而是此在“向死存在”的生存论结构。它是此在“最本己的、无所关联的、确知的、而作为其本身则不确定的、不可逾越的可能性”。
  • 到头 (Zu-Ende-sein)：指一个事物、一个过程或一个生命简单地“完结”、“终止”或“耗尽”。海德格尔用此术语来对比那种将死亡视为生命终点的流俗理解。
  • 现成事物 (Vorhandenes)：指那些仅仅“在那里”的、具有固定属性的客体或对象（如一块石头、一张桌子）。它们的存在方式是现成的、已完成的，与此在的生存性存在相对。
  • 上手事物 (Zuhandenes)：指在实践活动中被我们“使用”或“操劳”的工具性事物（如一把锤子、一支笔）。它们的存在意义在于其“为了作…之用”，与此在的生存性筹划相关。

2. 逐句转译

  • 原文第一句：“结束的这些样式中没有一种可以恰当地标画作为此在之终结的死亡。”
    • 转译：我们日常生活中所见到的各种“结束”方式（比如任务完成了、东西用坏了、生命体征停止了），没有哪一种能够准确地描述死亡对于“此在”（人这种特殊的存在者）来说，究竟意味着怎样的终结。
  • 原文第二句：“如果在结束的上述意义下把死领会为到头，那么此在从而就被设定为现成事物或上手事物了。”
    • 转译：如果我们用上述那种普通的“结束”观念，把死亡简单地理解成生命“到头了”、“完结了”，那么我们就犯了一个错误：我们实际上是把“此在”（这个充满可能性的、动态的存在）当成了一件现成的物品（比如一个报废的机器）或者一个用完的工具（比如一支写光墨水的笔）来对待了。
  • 原文第三句：“在死亡中，此在并未完成，也非简简单单地消失，更不曾就绪或作为上手事物颇可利用。”
    • 转译：所以，对于此在而言，死亡并不意味着它“圆满完成”了（像一件作品那样），也不是说它就“凭空消失”了（像水蒸发了一样），更不是说它变得“准备就绪”或者“作为一个有用的工具可以被利用了”。

3. 论证逻辑梳理

  1. 前提/起点：存在多种世俗理解的“结束”样式（如用完、耗尽、停止）。
  2. 核心论断：所有这些“结束”样式，都无法正确描述死亡对于“此在”的意义。
  3. 反面论证（揭示错误理解）：如果强行用“到头”（简单的完结）来理解死亡，会导致一个根本性的错误——将“此在”错误地归类。
    • 逻辑推进：将死亡视为“到头” → 意味着将此在视为一个可以完结的“物” → 此在被错误地理解为“现成事物”（如一个客体）或“上手事物”（如一个工具）。
  4. 正面澄清（排除错误印象）：为了纠正这种错误，海德格尔明确指出死亡与此在的关系并非上述任何一种“物”的结束方式（完成、消失、就绪、可利用）。
  5. 隐含结论：因此，必须为“此在之死”寻找一种全新的、生存论上的理解方式，这种方式必须尊重此在作为“可能性之存在”的本质。本段虽然没有直接给出正面的定义，但通过否定流俗观点，为下文引出其著名的“向死存在”理论做好了铺垫。

4. 整体概括

这段话的核心意思是，我们不能用看待世间万物“结束”的方式来看待人的死亡。如果你把死亡仅仅看作生命的“完结”（到头），那就等于把人降格成了一个物件或工具（现成事物或上手事物），因为只有物件和工具才会有那种从有用到无用、从存在到不存在的简单终结。但人的存在（此在）并非如此，死亡对于人来说，不是一个外在的、发生在终点的事件，而是内在于我们生存本身的一种最极端的可能性，它贯穿并塑造着我们的整个生命。所以，死亡既不意味着生命的“完成”，也不是“消失”，更不是变得“可利用”，这些描述都完全搞错了方向。

5. 争议与说明

本段解读相对一致。海德格尔在此对流俗死亡观的批判是其思想中非常清晰和经典的部分，学界对此基本没有异议。争议通常出现在后续他如何正面构建“向死存在”理论，以及这种理论是否成功等方面，但就本段而言，其意图和论证是明确的。
