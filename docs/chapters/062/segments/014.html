📖 《存在与时间》研读 逐段解析

📜 原文片段 (062/014)
海德格尔 原文
结束首先意味着停止，而其存在论的意义又各不相同。雨停了。它不再现成存在。路止了。这一结束并不使路消逝；而是这一停止把路确定为这一条现成的路。所以，停止这种结束可以意味着，过渡到不现成状态，但也可以意味着：恰恰随着终结才是现成的。这后一种结束复又可以对一种未就绪的现成事物进行规定——一条正在修建的路中断了；但它也可以组建一件现成事物的“就绪”——随着最后一笔，一幅画就绪了。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 结束 (Ende)：在海德格尔哲学中，通常指某事物在时间或结构上的终结、完结状态。在本段中，海德格尔强调“结束”具有不同的存在论意义——它既可以指某物停止存在（不再现成），也可以指某物恰因终结而得以完整实现（成为现成事物）。
  • 现成存在 / 现成状态 (Vorhandenheit)：一般指事物作为客观、静态、已完成的对象而存在，具有固定的属性和界限。在本段中，海德格尔区分了两种“结束”：一种是从“现成存在”过渡到“不现成存在”（如雨停了），另一种是随着“结束”才真正成为“现成事物”（如路修完了）。
  • 停止 (Aufhören)：在本段中特指某种活动或状态的终结，但它不必然导致事物的消失，反而可能通过终结来确定事物的存在方式。

2. 逐句转译

  • “结束首先意味着停止，而其存在论的意义又各不相同。”
    → 当我们说某事物“结束”，首先想到的是它“停止了”。但从存在论的角度看，这种“结束”其实有不同的意义。

  • “雨停了。它不再现成存在。”
    → 比如雨停了，雨这种自然现象就不再作为可见、可感知的对象存在了。

  • “路止了。这一结束并不使路消逝；而是这一停止把路确定为这一条现成的路。”
    → 但如果是“路到头了”，这个“结束”并不会让路消失，反而通过这个终点，我们才明确认识到这是一条具体的、已经存在的路。

  • “所以，停止这种结束可以意味着，过渡到不现成状态，但也可以意味着：恰恰随着终结才是现成的。”
    → 因此，“停止”这种结束有两种可能：一种是事物从“存在”变成“不存在”；另一种是事物恰恰因为有了终点才真正成为“完成的事物”。

  • “这后一种结束复又可以对一种未就绪的现成事物进行规定——一条正在修建的路中断了；但它也可以组建一件现成事物的‘就绪’——随着最后一笔，一幅画就绪了。”
    → 这后一种“结束”还可以进一步细分：它可以指一个未完成的事物被迫中断（如修路修到一半停了），也可以指一个事物因完成而真正“就绪”（如画完最后一笔，画作才真正完成）。

3. 论证逻辑梳理

  • 前提：“结束”通常被理解为“停止”。
  • 分析推进：
  • 海德格尔通过两个对比案例（雨停了 vs. 路止了）揭示：“结束”对事物存在状态的影响是不同的。
  • 雨停了 → 雨不再存在；路止了 → 路并未消失，反而因终点而被确认为一条具体的路。
  • 由此推出“结束”的两种存在论意义：① 从存在到不存在；② 因终结而成为完整的存在。
  • 进一步细化：
  • 第二种意义（因终结而成为现成）又分两种情况：
    • 被迫中断（未完成状态被固定）；
    • 主动完成（通过终结实现就绪）。
  • 结论：“结束”不是一个单一的哲学概念，它在存在论上具有多重意义，取决于它如何参与并规定事物的存在方式。

4. 整体概括

这一段的核心在于：我们通常认为“结束”就是“停止”，但海德格尔指出，从存在论角度看，“结束”其实有两种截然不同的意义。一种是我们熟悉的“消失”（如雨停了，雨不再存在）；另一种却恰恰相反——“结束”反而让事物成为它自身（如一条路因为有了终点，才被确认为一条具体的路）。他甚至进一步区分后一种“结束”：它既可能是被迫中断（如修路修一半停了），也可能是主动完成（如画完最后一笔，画作才真正成立）。简单说，海德格尔是在提醒我们：不要简单地把“结束”等同于“消失”，它在哲学上可能恰恰是事物“得以成立”的关键。

5. 争议与说明

本段解读相对一致，较少有根本性争议。部分学者可能会对“未就绪的现成事物”这一表述的严谨性提出讨论，认为“未就绪”与“现成”在字面上似乎矛盾，但海德格尔正是借此强调：事物的“现成状态”并非只有“已完成”一种，被迫中断的状态也是一种被固定的、可被把握的“现成存在”。整体上，学界对这段的分析方向较为统一。
