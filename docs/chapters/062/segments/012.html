海德格尔 原文
诚然，成熟过程这种果实特有的存在同此在一样，在某种尚待界说的意义上向来也已经是它的尚未；但若说在这一点上成熟过程作为尚未的存在方式〔不成熟〕从形式上看同此在相吻合，却不能意味着：即使从存在论上的终结结构着眼，成熟这种“终结”也同死亡这种“终结”是一回事。随着成熟，果实也就完成了。此在所达到的死亡竟也是这种意义上的完成吗？诚然，随着死亡，此在也就“完成了它的行程”。但它也必定随着死亡穷尽了它特有的种种可能性吗？不倒是它恰恰被取走了这些可能性吗？“未完成的”此在却也结束了。另一方面，此在也不见得要随着死亡才成熟，它满可能在终结之前就已超过成熟了。它多半就在半完成中结束了，要么就是在崩溃或疲竭中结束了。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在 (Dasein)：海德格尔哲学的核心概念，特指“人的存在”，是一种以“关心自身存在”为基本特征的、始终处于动态展开过程中的存在者。此在的本质在于它的“生存”，即不断筹划和实现自身可能性。
  • 尚未 (Noch-nicht)：指此在始终面向未来、尚未实现的潜在状态。此在在本质上是一种“尚未”完成的存在，它总在“成为”它所能是的东西。
  • 存在论 (Ontologie)：探究“存在”本身的意义与结构的哲学研究。在这里，特指从存在（如何存在）的角度，而非仅仅从事实（存在着）的角度进行分析。
  • 终结 (Ende)：需要特别注意，海德格尔区分了两种“终结”。一种是生理生命或过程的停止或完成（如果实成熟），另一种是此在特有的、作为存在方式的终结，即死亡。后者是此在无法逾越、并从根本上规定着此在整体性的可能性。
  • 可能性 (Möglichkeit)：对此在而言，可能性不是尚未实现的“属性”，而是其存在的核心构成方式。此在就是它的可能性，它通过筹划和行动“是”它的可能性。

2. 逐句转译

  1. 原文：诚然，成熟过程这种果实特有的存在同此在一样，在某种尚待界说的意义上向来也已经是它的尚未... 转译：我们确实可以说，果实的成熟过程，作为一种特定的存在方式，和此在有一个表面上的相似点：它们都处于一种“尚未”完成的状态。

  2. 原文：但若说在这一点上成熟过程作为尚未的存在方式〔不成熟〕从形式上看同此在相吻合，却不能意味着：即使从存在论上的终结结构着眼，成熟这种“终结”也同死亡这种“终结”是一回事。 转译：但是，这种形式上的相似（都处于“尚未”）绝不意味着，如果我们从更根本的“存在结构”角度来审视它们的“终点”，果实的“成熟”和此在的“死亡”会是同一回事。

  3. 原文：随着成熟，果实也就完成了。此在所达到的死亡竟也是这种意义上的完成吗？ 转译：果实一旦成熟，它的发展和可能性就全部实现了，彻底“完成”了。难道此在的死亡也是这样一种意义上的“完成”吗？

  4. 原文：诚然，随着死亡，此在也就“完成了它的行程”。但它也必定随着死亡穷尽了它特有的种种可能性吗？ 转译：没错，从表面上看，死亡意味着此在“走完了它的人生路程”。但是，死亡真的是让它“用尽”、“实现”了所有它特有的可能性吗？

  5. 原文：不倒是它恰恰被取走了这些可能性吗？“未完成的”此在却也结束了。 转译：恰恰相反，难道死亡不正是剥夺、中断了此在的所有可能性吗？一个“尚未完成”、还有很多事没做的此在，同样也会迎来死亡。

  6. 原文：另一方面，此在也不见得要随着死亡才成熟，它满可能在终结之前就已超过成熟了。 转译：另一方面，此在并不像果实那样，必须到死的那一刻才算“成熟”。它完全可能在生命终结之前，就已经度过了它的巅峰期（“超过成熟”了）。

  7. 原文：它多半就在半完成中结束了，要么就是在崩溃或疲竭中结束了。 转译：大多数情况下，此在是在一种“半途而废”、事情只做了一半的状态下结束的，或者是在衰败、精疲力竭的状态下走向终结的。

3. 论证逻辑梳理

  • 前提：提出一个表面上的类比——果实（作为生命体）的“尚未成熟”状态与此在的“尚未完成”状态，在形式上相似。
  • 核心反驳与转折：立刻否定这种类比的深层有效性。关键在于，不能因为“过程”的相似，就推导出“终点”的相同。
  • 对比分析：
  • 果实的终结（成熟）：是过程的圆满实现，是所有内在可能性的耗尽和完成。
  • 此在的终结（死亡）：
    • 它不是可能性的实现与完成，而是所有可能性的剥夺与终结。
    • 它不要求此在达到某种“成熟”或圆满状态，此在完全可以在“未完成”或“过熟”（衰败）的状态下死亡。
  • 结论：通过这一系列对比，海德格尔有力地论证了：此在的死亡在存在论上完全不同于任何其他生命过程的终结。它不是一种实现，而是一种最极端的、使所有存在活动成为不可能的可能性。

4. 整体概括

这段话的核心目的是划清界限。海德格尔借用“果实成熟”这个生动的例子，是为了与“此在之死”形成尖锐对比，从而凸显后者独一无二的存在论特征。他想告诉我们：千万不要把人的死亡理解成像瓜熟蒂落那样的自然过程的完成。果实的成熟是它生命目的的达成，是圆满。而人的死亡恰恰相反，它不是圆满的句号，而是强行画下的休止符，它中断了人所有的计划、关系和未来的可能性。人常常是在壮志未酬、或身心衰败中死去的，死亡不是一种成就，而是对一切可能性的终极剥夺。正是这种独特的“终结”方式，反过来深刻地规定和影响着我们“向死而生”的整个存在方式。

5. 争议与说明

本段解读相对一致。海德格尔在此处的论证非常清晰，旨在进行概念区分，学界对此段的直接争议较少。可能的讨论点更多集中于由此引申出的后续理论，例如：如果死亡是可能性的剥夺，那么它如何又能成为此在“最本己的可能性”？但这已超出本段直接论述的范围。本段的核心任务就是进行否定性界定，为后续正面建构“向死存在”的概念扫清道路。
