海德格尔 原文
作为生存论阐释的给定课题的存在者具有此在的存在方式；这一存在者无法靠把现成片段拼凑成一个现成事物的方法而得。只要生存论阐释不忘记这一点，它就必须由生存观念指引自己的全部步骤。就追问先行与决心之间的可能联系这一问题来说，这一点所意味的无非是要把这些生存论现象向着在它们本身那里草描出来的生存的可能性作筹划，再从生存论上对这些现象“刨根问底”。通过这种方法，研究先行着的决心〔作为生存上的可能的本真整体能在〕的工作就去掉了任意虚构的性质。这项工作就成为以阐释方式进行的此在的解放—把此在向着它最极端的生存可能性解放出来。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在（Dasein）：指人的存在方式，其本质在于“去存在”——人并非一个固定的“什么”，而是通过自己的行动、理解与抉择不断展开、生成自身的存在。此在总是处于可能性之中，并对自身的存在有所领会。
  • 生存论阐释（existential interpretation）：对此在的存在结构进行分析与解释的方法。它不是从外部观察人，而是从人实际生活、筹划未来的内在视角出发，揭示其存在方式。
  • 生存（Existenz）：特指此在的存在方式，即人总是“向前”筹划自身、实现可能性的动态过程。生存不是现成的状态，而是不断“成为自己”的活动。
  • 现成事物/现成片段（Vorhandenes）：指像物体一样已经完成、固定存在的东西。它们没有可能性，只是“摆在眼前”的客体。海德格尔强调此在不同于现成事物。
  • 筹划（Entwurf）：此在面向未来、理解自身可能性的基本活动。人总是在某种可能性中理解自己，并据此行动。
  • 先行（Vorlaufen）：此在面向自身最本己的可能性——死亡——而存在的生存态度。它不是逃避死亡，而是清醒地将其作为可能性接纳进来，从而更本真地生活。
  • 决心（Entschlossenheit）：此在清醒地面对自身处境、果断做出抉择的生存状态。它意味着人清楚地认识到自己的有限性与责任，并据此行动。
  • 本真整体能在（eigentliches Ganzseinkönnen）：此在真正成为自己、实现其整体可能性的存在方式。“整体”意味着将死亡作为可能性纳入生命，从而不再零碎地生活。

2. 逐句转译

  1. “作为生存论阐释的给定课题的存在者具有此在的存在方式；这一存在者无法靠把现成片段拼凑成一个现成事物的方法而得。”
    生存论分析的对象是人（此在），而人的存在方式是“去生活、去成为”，而不是像拼积木那样，把零散的部件组合成一个固定物体。人不能被还原成零件来理解。

  2. “只要生存论阐释不忘记这一点，它就必须由生存观念指引自己的全部步骤。”
    只要这种分析方式始终记得“人是在生活、在筹划中存在的”，那么它的每一步分析，都必须从“人如何活着、如何面向未来”这个角度出发。

  3. “就追问先行与决心之间的可能联系这一问题来说，这一点所意味的无非是要把这些生存论现象向着在它们本身那里草描出来的生存的可能性作筹划，再从生存论上对这些现象‘刨根问底’。”
    具体到我们要研究的“先行”与“决心”如何关联这个问题，这意味着：我们要把这两个现象看作是人活着时本来就具备的可能性，然后顺着这种可能性深入挖掘，弄清楚它们到底是如何从人的生存中生长出来的。

  4. “通过这种方法，研究先行着的决心〔作为生存上的可能的本真整体能在〕的工作就去掉了任意虚构的性质。”
    这样做，我们研究“人如何带着对死亡的清醒认识（先行）去果断生活（决心）”——这种本真的、完整的生存可能性——就不再是凭空瞎想，而是有根有据的。

  5. “这项工作就成为以阐释方式进行的此在的解放—把此在向着它最极端的生存可能性解放出来。”
    这种研究实际上是通过哲学阐释，帮助人从日常的浑浑噩噩中解放出来，让人能够清醒地面对自己最极端的可能性（比如死亡），从而更真实地生活。

3. 论证逻辑梳理

  • 前提：此在的存在方式是“生存”，即不断筹划自身可能性的动态过程，不能被当作现成物来分析。
  • 方法原则：因此，生存论阐释必须始终从“生存”观念出发，即从人如何理解并实现自身可能性出发。
  • 具体应用：研究“先行”与“决心”的关系时，必须将二者视为从此在自身的生存可能性中生长出来的现象，并深入追溯其生存论根源。
  • 结论一：这种基于生存可能性的研究方法，使得对“先行的决心”（本真整体能在）的探讨摆脱了主观虚构，具有了现象学的坚实性。
  • 结论二：这项研究工作的最终目的，是通过哲学阐释唤醒此在，使其从非本真状态中解放，直面自身最极端的可能性，从而实现本真的存在。

4. 整体概括

这段话的核心是强调：研究人的哲学方法（生存论阐释）必须符合人的存在方式（此在）。人不是静态的物体，而是活生生的、面向未来筹划自身的存在。因此，当我们探究“人如何通过直面死亡（先行）来实现果断的生活（决心）”这一问题时，不能像分析零件一样拼凑答案，而必须从人本身是如何生活、如何理解自身可能性出发，去揭示这些现象的内在联系。这样的研究不是空想，而是有扎实根基的；其最终目的是通过哲学分析，帮助人从浑噩的日常中觉醒，勇敢地面对生命最根本的可能性，从而实现真正的自我解放。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“解放”一词的理解：有学者强调其作为哲学阐释的理论效果（揭示本真存在的可能性），而另一些学者则更强调其实践意涵（召唤读者实现生存转变）。但两种解读都承认，海德格尔在此旨在建立一种不脱离此在生存的、具有唤醒力量的本体论研究方法。
