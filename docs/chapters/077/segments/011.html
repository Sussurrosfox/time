📜 原文片段 (077/011)
海德格尔 原文
倘若说由于沉沦着的存在之领会〔把存在领会为现成性〕占有统治地位而此在的本己存在的存在论性质与此在已相隔甚远，那就更不用说这一存在的源始基础了。无怪乎时间乍看上去与流俗领会所通达的“时间”可能格格不入。所以，不能不经检查就把流俗时间经验的时间概念和由此滋生出来的问题提法当作衡量某种时间阐释是否适当的标准。探索工作反倒必须先熟悉源始的时间性现象，以便从这一现象出发烛照流俗时间领会的源流的必然性和方式，以及它占有统治地位的根据。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 沉沦（Verfallen）：此在（人的存在）在日常状态中，被世界和他人所牵制，迷失在非本真的存在方式中。它忙于各种事务，逃避自身的本真可能性。
  • 存在之领会（Seinsverständnis）：此在对“存在”本身有一种前反思的、非主题化的理解。这种领会通常不是关于存在的理论，而是此在在世存有的基本方式。
  • 现成性（Vorhandenheit）：一种存在方式，指事物像现成的、摆在眼前的客体那样存在。海德格尔认为，传统形而上学错误地将“存在”理解为这种“现成性”，忽略了存在的动态和时间性。
  • 此在（Dasein）：指人的存在。此在的特质在于，它的存在本身对它而言是一个问题，它关心并理解自己的存在。
  • 本己存在（eigentliches Sein）：此在的一种存在模式，它直面自身的有限性和可能性，承担起自己的存在，是真实的、负责的存在状态。
  • 源始基础（ursprüngliche Grund）：指最根本、最原初的根基。在这里，特指此在存在的最深层结构。
  • 时间性（Zeitlichkeit）：此在最源始的存在结构，由“向死存在”、“决断”等本真体验所揭示。它是“在世界之中存在”的整体结构的深层根基。
  • 流俗时间（vulgäre Zeit）：日常的、传统的时间理解，将时间视为一条由无数“现在”时刻构成的、匀质流逝的序列（过去-现在-未来）。

2. 逐句转译

  • “倘若说由于沉沦着的存在之领会〔把存在领会为现成性〕占有统治地位而此在的本己存在的存在论性质与此在已相隔甚远，那就更不用说这一存在的源始基础了。”

    • 这句话的意思是：我们日常沉沦的状态，让我们习惯于把“存在”理解成像一个摆在面前的物体那样的“现成性”。在这种状态下，我们连自己“本真的存在”（即真实的、对自己负责的存在方式）都理解不了，离它非常遥远。那么，对于比“本真存在”更深层的、“本真存在”得以可能的那个“最源始的基础”（即时间性），我们就更加无法触及和理解了。

  • “无怪乎时间乍看上去与流俗领会所通达的‘时间’可能格格不入。”

    • 这很好理解：所以，当我们（海德格尔）接下来要探讨的“源始时间”（时间性），乍一看会和我们平常所理解的、那种像流水一样均匀流逝的“时间”（流俗时间）完全不同，甚至显得格格不入。

  • “所以，不能不经检查就把流俗时间经验的时间概念和由此滋生出来的问题提法当作衡量某种时间阐释是否适当的标准。”

    • 因此，我们不能不加审视地，就把日常生活中那种时间观念，以及基于这种观念所提出的问题（比如“时间是什么？”、“时间是客观的还是主观的？”），当作评判我们（海德格尔）对时间的新解释是否正确的标准。

  • “探索工作反倒必须先熟悉源始的时间性现象，以便从这一现象出发烛照流俗时间领会的源流的必然性和方式，以及它占有统治地位的根据。”

    • 正确的探索路径恰恰相反：我们必须先深入理解“源始的时间性”这个现象本身。只有从这个根基出发，我们才能看清楚：1）那种流俗的时间观念是怎么必然地从源始时间性中衍生出来的；2）它衍生的具体方式是什么；3）以及为什么这种流俗的时间观念能在我们的日常生活中占据主导地位。

3. 论证逻辑梳理

  1. 前提/起点： 此在日常处于“沉沦”状态，其“存在之领会”是将存在视为“现成性”。这使得此在远离了其“本己存在”的真相，更远离了其存在的“源始基础”（时间性）。
  2. 推论一： 因此，源始的“时间”（时间性）现象必然与流俗的“时间”概念（现成序列）显得截然不同。
  3. 推论二（方法论警示）： 基于推论一，我们不能用流俗时间概念作为标准，来评判海德格尔即将展开的时间性理论。
  4. 结论/正面方法论： 正确的路径是进行一种“反向溯源”的研究：必须先阐明源始的时间性现象，然后再用这个源始现象作为“光源”，反过来解释流俗时间概念的派生过程、必然性及其统治地位的成因。

4. 整体概括

这段话的核心是在为海德格尔的时间性理论做“方法论清场”。海德格尔指出，因为我们日常沉沦于世，习惯于把事物（包括我们自己）看成现成的对象，所以我们不仅无法理解自己真实的存在方式，更无法触及这种存在方式的深层基础——时间性。因此，他即将探讨的“源始时间”会显得和常识中的“时间”完全不同。他警告读者，绝不能拿日常的时间观念作为标尺来衡量他的理论。相反，研究必须从最根本的“时间性”现象入手，只有先弄懂了它，才能反过来解释清楚：为什么日常的“流俗时间”会是现在这个样子（一条均匀流逝的线），以及它为什么能如此普遍地支配我们的思维。

5. 争议与说明

本段内容在学界解读相对一致，是海德格尔方法论的一个关键转折点。可能的细微争议点在于对“沉沦”的理解：有学者强调其消极性，认为它完全遮蔽了本真存在；也有学者认为“沉沦”是此在无法摆脱的基本建构，它虽然是非本真的，但也是本真性得以显现的“地平线”。不过，这并不影响对本段核心论证——即必须从源始时间性出发来批判流俗时间——的理解。
