海德格尔 原文
当然要禁止从外部把两种现象系到一起。在方法上还只留下一条可能的道路—从我们业经在其生存的可能性中证实了的决心现象出发并去追问：就其最本己的生存的存在倾向来说，决心是否先就指向作为自己最本己的本真可能性的先行着的决心？如果情况竟是，按照决心的本己意义，只有当它并不是向着随意的、不过是最近便的可能性作筹划，而是向着蛰伏于此在的一切实际能在之前的最极端的可能性作筹划，并且或多或少不加伪装地就作为这种最极端的可能性悬浮而入此在的一切实际把握了的能在之时，决心才把自己带入本真状态呢？如果情况竟是，作为此在的夺享的真理，决心唯有在向死先行之际才达到它所包含的本真的确定性呢？如果情况竟是，下决心去做的一切实际的“暂先行之”〔Vorlaeufigkeit〕唯有在向死先行〔Vorlaufein〕之中才得到本真的领会，亦即在生存上被追上呢？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 决心：海德格尔哲学中的核心概念，指此在（人的存在）的一种本真生存方式。它不是指日常意义上的“做决定”，而是此在清醒地面对自己最本己的（属于自己的）、被抛的生存处境，并主动承担起自身的存在，筹划着向未来开放。
  • 先行/先行着：指此在的一种时间性存在方式，即主动地、清醒地“跑向”或“提前进入”自己的未来可能性，尤其是最极端的可能性。它不是指在时间顺序上提前做什么事，而是一种生存论上的“提前置身于...之中”。
  • 本真状态：此在的一种存在模式。在此模式下，此在不再沉沦于常人（Das Man）的闲言碎语和公共解释，而是真正面对并承担起自身的、个体化的生存。
  • 最极端的可能性：在海德格尔的语境中，这特指死亡。死亡是此在无法逾越、绝对个体化、并且确凿无疑的终极可能性。
  • 向死先行：这是“先行”概念的具体化和极致化。指此在生存论上提前进入并直面其“死亡”这一最极端的可能性，从而被逼迫着去本真地理解和承担自身的整体存在。
  • 此在：海德格尔用以指代“人”的存在者，其本质在于“去存在”（Zu-sein），即以理解和关切自身存在的方式而存在。

2. 逐句转译

  1. 原文：当然要禁止从外部把两种现象系到一起。在方法上还只留下一条可能的道路—从我们业经在其生存的可能性中证实了的决心现象出发并去追问...

    • 转译：首先，我们不能随意地从外部将两种不同的现象（比如“决心”和“死亡”）生硬地捆绑在一起。在研究方法上，我们只剩一条路可走：那就是从我们已经确认的、在生存可能性中真实存在的“决心”现象出发，然后去追问一个更深层的问题...

  2. 原文：就其最本己的生存的存在倾向来说，决心是否先就指向作为自己最本己的本真可能性的先行着的决心？

    • 转译：从决心最根本的存在倾向来看，它本身是不是从一开始就指向了一种“先行着的决心”？也就是说，真正的决心，其本性是不是就是一种“提前行动”或“跑在前面”的状态？

  3. 原文：如果情况竟是，按照决心的本己意义，只有当它并不是向着随意的、不过是最近便的可能性作筹划，而是向着蛰伏于此在的一切实际能在之前的最极端的可能性作筹划，并且或多或少不加伪装地就作为这种最极端的可能性悬浮而入此在的一切实际把握了的能在之时，决心才把自己带入本真状态呢？

    • 转译：我们不妨这样设想：如果真正的决心，其意义恰恰在于，它不是去规划那些随随便便、唾手可得的可能性，而是去规划那个潜藏在此在所有现实可能性之“前”的、最极端的可能性（即死亡）。并且，当这个最极端的可能性或多或少清晰地浮现出来，笼罩并介入此在所有已经把握的现实可能性之中时，决心才真正达到了它的本真状态？

  4. 原文：如果情况竟是，作为此在的夺享的真理，决心唯有在向死先行之际才达到它所包含的本真的确定性呢？

    • 转译：我们再进一步设想：如果决心作为此在能够把握的真理，只有在“向死亡先行”（即提前进入并直面死亡）的过程中，才能获得它所蕴含的那种真正的、不容置疑的确定性？

  5. 原文：如果情况竟是，下决心去做的一切实际的“暂先行之”〔Vorlaeufigkeit〕唯有在向死先行〔Vorlaufein〕之中才得到本真的领会，亦即在生存上被追上呢？

    • 转译：最后再设想：如果我们在日常生活中所有那些“提前做准备”、“未雨绸缪”的具体行动，它们的真正意义，只有当我们从“向死亡先行”这个最根本的视角来理解时，才能被真正把握？也就是说，我们日常的先行筹划，只有被置于“向死而在”这个宏大的生存背景之下，其本质才被我们追上并理解？

3. 论证逻辑梳理

  1. 前提与方法论限制：论证始于一个方法论前提——不能外在地关联现象，必须从已被证实的现象（决心）内部出发进行探索。
  2. 提出核心问题：基于此方法，提出第一个探索性问题：决心本身是否内在地包含着“先行”的结构？
  3. 深化与具体化（第一层假设）：通过一个长长的假设句，将“先行”具体化。指出本真的决心不是筹划日常琐事，而是筹划“最极端的可能性”（死亡）。论证在此推进：决心要成为本真的，必须与死亡这一终极视野相关联。
  4. 进一步深化（第二、三层假设）：连续提出两个“如果”问句，层层递进。
    • 第二问：指出决心所追求的“确定性”，唯有在“向死先行”中才能获得。
    • 第三问：将论点扩展到更广泛的日常经验，指出所有“提前筹划”行为的本真意义，都根植于“向死先行”这一终极的生存论结构。
  5. 结论导向：整段话并未给出肯定结论，而是通过一系列环环相扣的修辞性问句，将论证有力地引向一个尚未明言但呼之欲出的结论：“向死先行”是决心达成其本真状态的必要条件和深层基础。

4. 整体概括

这段文字是海德格尔在为“向死而在”这一核心论点做铺垫和论证。他首先确立了从“决心”这一现象内部进行探索的方法论。然后，他通过一连串的假设性追问，逐步揭示出“决心”这一现象的本质结构：真正的、本真的决心，并非指向那些日常的、琐碎的未来计划，而是必然地、内在地指向一个最极端、最本己的可能性——死亡。只有当此在清醒地“提前进入”或“直面”死亡这一终极视野时，决心才能获得其真正的确定性和力量，而我们日常生活中所有“为未来做准备”的行为，其最深层的意义也源于此。简而言之，这段话论证了“向死先行”是“本真决心”得以可能的根基。

5. 争议与说明

本段解读相对一致。海德格尔在这里的论证逻辑是典型的“准备性”论证，通过引导性的问题将读者引向核心论点，而非直接断言。可能的细微争议点在于对“最极端的可能性”是否必然、唯一地指向“死亡”存在不同深度的理解，但将其解读为死亡是海德格尔思想脉络中最主流的、也是最自洽的理解。
