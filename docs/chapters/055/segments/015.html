📖 《存在与时间》研读 逐段解析
首页 / 第 055 章 / 片段 015
📜 原文片段 (055/015)
海德格尔 原文
这个证明当然不是因果推论，所以也就没有因果推论的不利之处。康德好像从某种时间性存在者的观念出发给出了一个“存在论证明”。乍一看，康德似乎放弃了笛卡尔的入手点，不再把独立地摆在那里的主体作为开端。但这只是假象。康德毕竟是要求为“在我之外的物的此在”提供出一种证明，这就已经表明，他提出问题时的立足点是在主体之中的，是在“我之内”的。而且这个证明本身也是从在经验上给定、“在我之内”的变易出发的。因为承担着这一证明的“时间”只“在我之内”被经验到。时间提供了基地，使证明得以跳到“我之外”去。此外，康德还强调说：“存疑的〔唯心主义〕…不过宣称除我们自身的此在以外，由直接经验来证明任何其它的此在是不可能的。这种唯心主义依据理性，合乎基本的哲学思维方式。也就是说：在发现充分的证明之前，不允许做出决定性的判断。”
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 因果推论：指基于因果关系（如A事件导致B事件）的逻辑推理方式。海德格尔指出康德的证明并非此类推理。
  • 时间性存在者：海德格尔哲学中，指那些本质上与时间相关联的存在者，尤其是人的此在（Dasein）。此处指康德可能预设了某种具有时间性特征的存在者观念。
  • 存在论证明：在哲学传统中，通常指试图通过概念分析或先验推理证明某物必然存在的论证（如上帝存在证明）。此处是康德对“我之外的物的此在”的证明。
  • 主体：哲学中常指认知或经验的中心，即自我或意识。笛卡尔以“我思”的独立主体为哲学起点。
  • 此在（Dasein）：海德格尔的核心概念，特指人的存在方式，其本质是“在世界之中存在”，具有时间性和理解存在的可能性。在本段中，也用于指一般“物的此在”（物的存在）。
  • 在我之内 / 我之外：“在我之内”指在主体的意识、经验或内在领域；“我之外”指独立于主体意识的外部世界（如外部物体）。
  • 存疑的唯心主义：康德所称的一种哲学立场，认为除了自我存在可由直接经验确证外，其他存在（如外部世界）无法由直接经验证明，必须依赖理性推理。

2. 逐句转译

  • “这个证明当然不是因果推论，所以也就没有因果推论的不利之处。”
    → 海德格尔首先说明：康德的这个证明并不是那种基于因果关系的推理（比如从结果推原因），因此它也就避免了因果推论可能带来的问题（如无限回溯或经验不确定性的困境）。

  • “康德好像从某种时间性存在者的观念出发给出了一个‘存在论证明’。”
    → 康德似乎基于一种与时间紧密相关的存在者（很可能是人这种具有时间意识的主体）的观念，提出了一种关于存在（此在）的证明。

  • “乍一看，康德似乎放弃了笛卡尔的入手点，不再把独立地摆在那里的主体作为开端。但这只是假象。”
    → 表面上，康德好像不再像笛卡尔那样，从一个孤立的、自足的主体（“我思”）出发来构建哲学。但这其实是一种错觉。

  • “康德毕竟是要求为‘在我之外的物的此在’提供出一种证明，这就已经表明，他提出问题时的立足点是在主体之中的，是在‘我之内’的。”
    → 因为康德的目标是要证明“我之外”的物体是存在的，这个提问方式本身就暴露了他的出发点：他仍然是从主体内部（“我之内”）的角度来提出问题的。

  • “而且这个证明本身也是从在经验上给定、‘在我之内’的变易出发的。”
    → 不仅如此，他的证明过程也是从那些在经验中直接被给予的、发生在“我之内”的变化（比如感官印象的流变）开始的。

  • “因为承担着这一证明的‘时间’只‘在我之内’被经验到。”
    → 这是因为，作为证明基础的关键要素——“时间”，在康德看来，仅仅是在主体内部（“我之内”）被经验到的东西。

  • “时间提供了基地，使证明得以跳到‘我之外’去。”
    → 时间就像一个跳板，康德试图通过它从内部经验（我之内）跳跃到对外部世界（我之外）存在的断言。

  • “此外，康德还强调说：‘存疑的〔唯心主义〕…不过宣称除我们自身的此在以外，由直接经验来证明任何其它的此在是不可能的。这种唯心主义依据理性，合乎基本的哲学思维方式。也就是说：在发现充分的证明之前，不允许做出决定性的判断。’”
    → 最后，海德格尔引用康德的话来佐证：康德所认同的“存疑的唯心主义”认为，除了我们自己（主体）的存在能通过直接经验确证，其他任何东西的存在都无法仅凭直接经验证明。这种立场是理性的，符合哲学的基本方法——在找到充分证据前，不应对外部世界的存在妄下判断。

3. 论证逻辑梳理

  • 前提1：康德的证明不是因果推论（避免了其缺陷）。
  • 前提2：康德看似脱离了笛卡尔的孤立主体起点，但实质未变。
  • 核心论证：
  • 康德证明的目标是“我之外的物的此在”，这本身就预设了提问者站在主体内部（“我之内”）的立场。
  • 证明的起点是“在我之内”被经验到的变易（变化）。
  • 证明的关键中介是“时间”，而时间在康德看来也只是“在我之内”被经验到的。
  • 推进步骤： 1. 从内部经验（变易）出发。 2. 以内部经验的时间性为跳板。 3. 试图论证外部世界（我之外）的存在。
  • 结论/揭示：康德的证明实质上仍是一种从主体内部出发的进路，并未真正超越笛卡尔式的内在性困境。他引用的“存疑的唯心主义”进一步印证了其立场：外部存在的证明需要理性推理，而非直接经验。

4. 整体概括

这段文字是海德格尔对康德关于“外部世界存在”证明的批判性分析。海德格尔指出，康德的证明虽然避免了因果推论的陷阱，并且表面上似乎超越了笛卡尔从孤立主体出发的路径，但其本质依然是将主体内部（“我之内”）的经验作为起点和基石。证明依赖于在主体内部被经验到的“时间”和“变易”作为跳板，试图论证“我之外”的物的存在。最后，通过引用康德对“存疑的唯心主义”的辩护，海德格尔进一步揭示，康德哲学仍然深陷于从主体意识内部去确证外部世界这一传统难题之中，未能真正解决内在性与超越性之间的鸿沟。

5. 争议与说明

本段解读相对一致。核心争议点通常不在于海德格尔对康德文本的解读本身，而在于： - 海德格尔对康德“时间”观念的诠释是否公允？康德将时间视为感性直观的先天形式，是客体向主体显现的条件；而海德格尔在此强调其“在我之内”被经验，突出了其主观内在性的一面，有学者认为这或许简化或扭曲了康德时间观的先验建构角色。 - 对“存疑的唯心主义”的引用是否完全体现了康德的最终立场？康德在《纯粹理性批判》中确实试图反驳独断的唯心论并证明外部世界的存在，海德格尔在此的引用旨在揭示其论证的起点困境，但康德研究者可能争论这是否是其体系的完备表述。

然而，海德格尔的核心论点——即康德未能彻底摆脱从主体内部出发的哲学范式——是学界广泛讨论并很大程度上接受的对康德认识论的一种批判性解读。
