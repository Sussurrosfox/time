📖 《存在与时间》研读 逐段解析
首页 / 第 055 章 / 片段 036
📜 原文片段 (055/036)
海德格尔 原文
当然，只有当此在存在，也就是说，只有当存在之领会在存在者层次上的可能性存在，才“有”存在。当此在不生存的时候，那时，“独立性”也就不“在”，“自在”也就不“在”。那时，诸如此类的东西就既不是可领会的，也不是不可领会的。那时，世内存在者就既不是可揭示的，也不能蔽而不露。那时就既不能说存在者存在，也不能说存在者不存在。现在——只要当存在之领会在，并因而对现成性的领会在——当然可以说：那时存在者还得继续存在下去。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔用来指称“人”这种特殊存在者的术语。此在的本质在于它的“存在”本身对它来说是一个问题，它能追问、领会自己的存在。在本段中，此在是“存在之领会”得以发生的必要条件。
  • 存在之领会：此在对其自身存在方式的理解与把握。它不是一种理论认知，而是此在在世生存中始终伴随的、前理论的基本理解。本段强调，这种领会是“存在”本身得以显现的先决条件。
  • 存在者层次上的可能性：此在作为具体、现实的生命个体，在其实际生存中能够展开、实现的各种潜在性。本段特指此在能够实际地去“领会存在”这种可能性。
  • 存在：海德格尔的核心问题，指使得一切存在者得以成为存在者的那个“是”本身。它不是任何具体的东西，而是显现的过程或条件。
  • 独立性 / 自在：指传统形而上学中认为的、不依赖于意识或认识而“客观存在”的性质。海德格尔在此批判这种观点，认为它们实际上依赖于此在的“存在之领会”。
  • 世内存在者：此在生存于世界之中，这个世界之内的其他非此在的存在者，例如桌椅、山川、工具等。
  • 可揭示的 / 蔽而不露：“可揭示的”指存在者的意义和存在方式能够对此在敞开、变得明晰；“蔽而不露”指存在者处于隐藏、未被理解的状态。二者都预设了一个能进行揭示活动的主体（此在）。
  • 现成性：一种存在方式，指存在者像已经制作完成的、摆在眼前的物件那样存在。这是传统哲学看待存在者的主流方式，海德格尔认为它源于此在的一种特定的（非本真的）领会方式。

2. 逐句转译

  1. 原文: 当然，只有当此在存在，也就是说，只有当存在之领会在存在者层次上的可能性存在，才“有”存在。 转译: 这是核心前提：我们之所以能谈论“存在”这回事，完全依赖于“人”（此在）这种特殊生物的出场。更具体地说，是因为人天生就有一种在实际生活中去理解“存在”是怎么回事的能力（存在之领会）。如果没有人和这种能力，“存在”这个概念根本就无从谈起。

  2. 原文: 当此在不生存的时候，那时，“独立性”也就不“在”，“自在”也就不“在”。 转译: 如果世界上根本没有人存在了，那么那些我们通常认为的“独立于人的客观实在”（独立性）和“事物本身的样子”（自在），也都失去了意义，无法被称为“存在”了。因为它们作为概念，其意义场域是由人开启的。

  3. 原文: 那时，诸如此类的东西就既不是可领会的，也不是不可领会的。 转译: 到那时，像“独立性”、“自在”这类概念，就陷入了一个尴尬的境地：我们既不能说它们能被理解，也不能说它们不能被理解。因为“理解”这个行为本身，连同判断“可理解”与“不可理解”的标准，都随着人的消失而一同消失了。

  4. 原文: 那时，世内存在者就既不是可揭示的，也不能蔽而不露。 转译: 同样地，世界上的一切事物（比如山川、石头、星辰），也将处于一种既不能被揭示出其意义和真相，也不能说是被隐藏起来的状态。“揭示”与“隐藏”是一对对立的概念，它们都发生在一个有“揭示者”（即此在）的世界里。没有揭示者，这对概念也随之失效。

  5. 原文: 那时就既不能说存在者存在，也不能说存在者不存在。 转译: 推至极致，在那个没有人的世界里，我们甚至无法对任何事物做出最基础的判断：既不能说“这个东西存在”，也不能说“这个东西不存在”。因为“存在”与“不存在”的判断，其意义和可能性都根植于人的领会活动。

  6. 原文: 现在——只要当存在之领会在，并因而对现成性的领会在——当然可以说：那时存在者还得继续存在下去。 转译: 但是，回到现实，只要我们现在有人，并且人有能力进行领会（特别是领会到事物可以像“现成的物件”那样存在），那么我们当然可以回过头来说：即使在那个假设的、没有人的远古时代或未来，那些山川石头“本身”也还是继续存在着的。海德格尔点出，这种我们习以为常的说法，其根基恰恰在于我们当下此在的特定领会方式（现成性领会）。

3. 论证逻辑梳理

  • 前提（第一句）：确立了核心论点——“存在”依赖于“此在”及其“存在之领会”。这是一个存在论上的依赖关系，而非时间上的先后关系。
  • 推论展开（第二至第五句）：通过一个思想实验（假设此在不再生存），将前提推向极端，以归谬法展示若无此在，一系列相关的存在论概念（如独立性、自在、可揭示性、存在/不存在）将全部失去效力和意义。论证层层递进，从较具体的概念（独立性）推进到最根本的判断（存在与否）。
  • 转折与深化（第六句）：从思想实验回到现实，指出我们之所以能做出“事物无人时也存在”这种日常断言，其可能性条件恰恰反过来证明了此在的领会活动是这一切的根基。我们是用此在的一种特定模式（现成性领会）去投射和理解一个无此在的世界。

4. 整体概括

这段话的核心思想是：我们所谈论的“存在”，并非一个脱离人而自在运行的客观舞台。恰恰相反，“存在”的意义是在“人”（此在）这种能够追问和领会“存在”问题的特殊存在者这里，才得以显现和成立的。如果没有人的理解和揭示活动，世界万物就无所谓“存在”或“不存在”，也无所谓“客观”或“被隐藏”，它们只是陷入一片意义和判准的虚空。我们现代科学所预设的那个无人宇宙依然“客观存在”的图景，本身也是由我们人类特定的认知方式（海德格尔称之为“现成性领会”）所构建和担保的。因此，存在问题的探究，必须回归到此在的生存分析这个基础之上。

5. 争议与说明

本段是海德格尔“存在论差异”（存在者与存在本身的区分）和“此在的优先地位”思想的集中体现，解读相对一致。可能的争议或不同理解方向在于：

  • 是否为主观唯心论：一种常见的误解是，海德格尔认为“没有人，事物就不存在”。但海德格尔反对的是这种朴素实在论与主观唯心论的非此即彼。他探讨的是“存在的意义”而非“事物的物理实在性”。他的观点是：没有此在，事物的“存在意义”（如作为工具、作为对象、作为资源）无法开启，事物处于“意义真空”，但这不否认其物理质料的持存。关键在于区分“实在”（Realität）与“存在”（Sein）。
  • “现成性领会”的地位：有学者认为，海德格尔在此对“现成性领会”的提及，暗示了自然科学客观视角的派生性和局限性，它只是此在领会存在的一种（非本真）方式。对此的强调程度在不同解读中或有差异。
