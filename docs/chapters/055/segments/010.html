📖 《存在与时间》研读 逐段解析
首页 / 第 055 章 / 片段 010
📜 原文片段 (055/010)
海德格尔 原文
对实在问题进行可能的存在论提问之前需要做一些探索工作，这些工作在前面的生存论分析中已经进行过了。那里表明，认识是通达实在事物的一种派生途径。实在事物本质上只有作为世内存在者才可通达。通向世内存在者的一切途径在存在论上都植根于此在的基本建构，都植根于在世的存在。而在世具有更为源始的操心的存在建构〔先行于自身的-已经在-世界之中的-作为寓于世内存在者的存在〕。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 实在问题：指传统哲学中讨论外部世界是否真实存在、以及我们如何认识外部世界的问题。
  • 存在论：海德格尔哲学的核心，探究“存在”本身的意义，而非具体存在者的属性。
  • 生存论分析：对“此在”（人的存在方式）的基本结构进行的先验分析。
  • 派生途径：非原始的、从更基础模式中衍生出来的方式。
  • 世内存在者：在世界之中出现的具体事物（如桌椅、工具等）。
  • 此在：特指人的存在方式，其本质在于“去存在”，具有对自身存在的领会。
  • 在世：此在的基本存在方式，即总是已经“在世界之中存在”。
  • 操心：此在存在的整体结构，包含三个环节：先行于自身（面向未来的筹划）、已经在世界之中（被抛的既定境况）、作为寓于世内存在者的存在（与事物打交道的沉沦状态）。

2. 逐句转译

  • “对实在问题进行可能的存在论提问之前需要做一些探索工作，这些工作在前面的生存论分析中已经进行过了。”
    → 在从存在论角度探讨“外部世界是否真实”这个问题之前，我们需要先做一些准备工作。这些准备工作，其实我们在之前分析“人这种存在者如何存在”时已经做过了。

  • “那里表明，认识是通达实在事物的一种派生途径。”
    → 之前的分析已经揭示：我们通常认为的“通过理性认识去把握事物”，其实是一种次要的、后发的途径。

  • “实在事物本质上只有作为世内存在者才可通达。”
    → 任何所谓“实在的东西”，本质上只有作为“在世界中显现的事物”才可能与我们照面。

  • “通向世内存在者的一切途径在存在论上都植根于此在的基本建构，都植根于在世的存在。”
    → 我们接触世间万物的所有方式，在存在论的根基处，都源于“人这种存在者”的根本结构，也就是“人总已经在世界之中”这个基本事实。

  • “而在世具有更为源始的操心的存在建构〔先行于自身的-已经在-世界之中的-作为寓于世内存在者的存在〕。”
    → 而这个“在世存在”，其实有着更深层的结构，就是“操心”——它包含三个不可分割的环节：人总是走在自身前面（筹划未来）、人总是已经被抛入某个世界境况、人总是已经与周围事物打交道。

3. 论证逻辑梳理

  • 前提：传统哲学关注“实在问题”（外部世界的实在性）。
  • 关键转折：海德格尔指出，在讨论此问题前，需先通过生存论分析厘清更基础的问题。
  • 论证推进： 1. 首先明确：认识活动是衍生的（非原始的）通达方式。 2. 进而指出：实在事物必须作为“世内存在者”才可能被遇到。 3. 然后深化：一切通达世内存在者的方式，都植根于此在的“在世”结构。 4. 最终奠基：在世的本质结构是“操心”，它包含三个动态环节，构成了此在存在的整体。
  • 结论：传统实在问题的提法本身已经预设了更源始的存在论基础——此在的操心结构。不先澄清这个基础，实在问题的讨论将是无根的。

4. 整体概括

这段文字的核心意思是：在讨论“外部世界是否真实”这个经典哲学问题之前，我们必须先回到更根本的层面——分析人本身的存在方式。海德格尔提醒我们，我们通常以为的“通过理性认识世界”其实是次要的；事实上，人首先是通过“在世存在”这种生存方式与事物打交道的。这种“在世”又源于人最根本的存在结构——“操心”，它包含着人对未来的筹划、既定的生存境况以及与万物互动这三个不可分割的维度。因此，传统认识论问题必须让位于更源始的存在论探究。

5. 争议与说明

本段解读相对一致，是海德格尔基础存在论的标准论述。可能的细微争议在于“派生”一词的理解：有些学者强调认识活动虽然派生但不可或缺；另一些则认为海德格尔确实在贬抑传统认识论的地位。但总体而言，段落的基调和主旨是明确的。
