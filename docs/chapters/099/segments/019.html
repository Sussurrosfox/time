📖 《存在与时间》研读 逐段解析
首页 / 第 099 章 / 片段 019
📜 原文片段 (099/019)
海德格尔 原文
因为实际在世的存在的时间性源始地使空间开展成为可能，而具有空间性的此在向来已从某种被揭示了的“那里”为自己指派了某种此在式的“这里”，所以，在此在的时间性中所操劳的时间就其可定期性而言向来与此在的某个处所相系束。并非说时间被联结到一个处所上，而是说时间性是定期之所以能够与空间处所性的东西相系束的条件；而这种系束在于：空间处所性的东西作为尺度对人人具有约束力。时间并非才始与空间偶对；而是：被臆想为有待偶对的“空间”只有根据操劳于时间的时间性才来照面。此在的时间性组建这一存在者为历史的存在者，而钟表与计时就奠基在这一时间性之中；据此可以显示钟表使用在存在论上其本身就在何种程度上是历史的而且每一钟表其本身又“有历史”。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 实际在世的存在 (In-der-Welt-sein)：指此在（人）最根本的存在方式，即总是已经处在世界之中，与世界内的其他存在者打交道。这种“在世”不是物理位置关系，而是指一种生存论上的关联性。
  • 时间性 (Zeitlichkeit)：此在存在的整体意义结构。它不是指我们日常理解的线性时间流，而是指此在通过“曾在-当前化-将来”的统一性展开其生存可能性。
  • 空间性 (Räumlichkeit)：此是在世界之中存在的空间维度。它不是物理的、可测量的几何空间，而是由此在的操劳活动所开显的定向和去远（使事物变近）的空间。
  • 此在 (Dasein)：指人的存在，是一种能够发问并关心自身存在的存在者。
  • 操劳 (Besorgen)：此在与世内存在者打交道的日常方式，是一种带着实用意图的繁忙活动。
  • 定期性 (Datterbarkeit)：时间之所以能被我们指明（如“开会之时”、“收获之季”）的特性。它依赖于此在能在时间中为事件“定位”。
  • 历史的存在者 (geschichtlich Seiende)：此在的本质特征之一，指此在的存在本身就是历史的——它承袭着过去，活在当下，并向着未来筹划，从而构成了它的“历史”。

2. 逐句转译

  1. “因为实际在世的存在的时间性源始地使空间开展成为可能，而具有空间性的此在向来已从某种被揭示了的‘那里’为自己指派了某种此在式的‘这里’...” - 因为我们人（此在）最根本的存在方式就是在世界之中活动，而驱动这种活动的深层结构是“时间性”，正是这个时间性才最源头地让我们能打开并体验到空间。我们人天生就有空间感，这种空间感表现为：我们总是从一个已经被我们理解了的“那里”（比如一个目标、一个去处），反过来确定我们自己当下所在的“这里”。

  2. “...所以，在此在的时间性中所操劳的时间就其可定期性而言向来与此在的某个处所相系束。” - 因此，在我们忙碌生活（操劳）中所体验到的时间，当我们想为它确定一个日期或时刻时（比如“下午三点开会”），它总是和我们所在的某个地方绑定在一起。

  3. “并非说时间被联结到一个处所上，而是说时间性是定期之所以能够与空间处所性的东西相系束的条件...” - 这里的关键不是说时间这个独立的东西被额外附加到了一个地方上。恰恰相反，是说我们人最深层的时间性结构，才是我们能够把时间点和具体地点联系起来的前提条件。

  4. “...而这种系束在于：空间处所性的东西作为尺度对人人具有约束力。” - 这种联系之所以能成立，是因为那些具有空间位置的事物（比如太阳的位置、钟表指针的位置）能够作为一种公共的、对所有人都有效的标尺。

  5. “时间并非才始与空间偶对；而是：被臆想为有待偶对的‘空间’只有根据操劳于时间的时间性才来照面。” - 并不是先有时间、空间这两个现成的东西，然后它们才开始配对。真相是：我们头脑中以为的那个可以和时间配对的、客观的“空间”，本身只有通过我们那忙于算计时间的时间性活动，才会进入我们的世界，被我们体验到。

  6. “此在的时间性组建这一存在者为历史的存在者，而钟表与计时就奠基在这一时间性之中...” - 正是此在（人）的时间性结构，把人构建成了一个本质上是“历史性的”存在者。而我们使用的钟表和计时系统，其根源就深深地扎在这个时间性之中。

  7. “...据此可以显示钟表使用在存在论上其本身就在何种程度上是历史的而且每一钟表其本身又‘有历史’。” - 基于以上原因，我们就可以揭示出：从存在论（研究存在本身）的层面看，使用钟表这个行为本身在多大程度上就是历史性的活动，并且每一块具体的钟表本身也承载着一段它自己的历史。

3. 论证逻辑梳理

  • 前提1：此在的“实际在世”由其“时间性”所规定，并且时间性优先于并使得空间性的开展成为可能。
  • 前提2：此在基于其空间性，总是从理解了的“那里”来指派自身的“这里”。
  • 推论1：因此，在操劳中可定期的时间，总是与特定的处所相联系（时间-处所的“系束”）。
  • 核心论证：这种“系束”并非外在的拼接，其可能性条件在于更深层的“时间性”。时间性使得空间性的东西能作为公共尺度发挥作用。
  • 深化论证：驳斥“时间与空间是现成偶对”的流俗观点，指出我们所理解的“空间”本身依赖于操劳的时间性才得以显现。
  • 结论1：此在的时间性使其成为历史性的存在者。
  • 结论2：钟表和计时实践根植于此在的时间性，因此它们本身就是历史性的现象，并拥有其自身的历史。

4. 整体概括

这段话的核心论点是：我们之所以能把时间和地点联系起来（比如用太阳的位置判断时间，或用钟表指针指向的位置代表几点钟），其最深层的根源不在于时间和空间是两个独立事物的外部结合，而在于我们人（此在）自身的存在结构——时间性。正是这个时间性，首先让我们能够开显出一个有意义的世界和空间。因此，我们所体验到的客观的、可度量的空间和时间，实际上都源于我们生存活动本身的时间性结构。这种结构也决定了人本质上是历史性的存在，而我们发明和使用钟表来计量时间这一行为，以及钟表本身，都是这种历史性存在的具体体现和产物。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“空间处所性的东西作为尺度对人人具有约束力”的理解。一种解读强调这是指在公共生活中形成的、客观化的社会约定（如时区、工作作息），其约束力是社会历史性的。另一种解读可能更强调这种约束力的存在论基础，即它之所以可能，是因为此在的“共在”结构，使得某种空间性标尺能够被共同理解和接受。但两种解读都承认，海德格尔的核心意图是揭示流俗时空观的存在论根源。
