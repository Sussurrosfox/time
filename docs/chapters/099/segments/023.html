📖 《存在与时间》研读 逐段解析
首页 / 第 099 章 / 片段 023
📜 原文片段 (099/023)
海德格尔 原文
时间测量锻铸时间的公共化。于是我们一般称为“时间”的东西只有在这条道路上才得识认。在操劳活动中，每一事物都配有“它的时间”。它有时间并能像有任何一种世内存在者那样“有”时间，只因它根本就“在时间之中”。我们把世内存在者“在其中”照面的时间识认为世界时间。时间性中包含有世界时间，而世界时间根据于时间性从视野绽出的建构而像世界一样具有超越性。世界时间随着世界的展开而公共化，其结果是每一寓于世内存在者并操劳于时间的存在都以寻视方式把世内存在者领会为“在时间中”来照面的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 时间测量：在海德格尔哲学中，这不是指物理或钟表的时间计量，而是此在（人）在其生存活动中对时间的一种“估算”或“安排”。它是此在操劳于世内事物时，对时间的一种实践性把握。
  • 操劳活动：此在（人）与世内存在者打交道的基本方式，是一种投入的、有目的的日常活动。在此活动中，此在不是作为一个冷静的观察者，而是作为一个使用者、关心者介入世界。
  • 世内存在者：存在于世界之中的各种事物、对象、工具，它们与此在的操劳活动相关联。
  • 时间性：此在存在的整体结构，是过去、现在、未来（海德格尔称之为“曾在”、“当前化”、“将来”）统一而原始的展开方式。它是世界时间和日常时间经验的深层基础。
  • 世界时间：在操劳活动中被遭遇和理解的公共时间。它不是客观、均匀的物理时间，而是带有意义和关联的（例如，“播种的时间”、“开会的时间”），随着世界的展开而被此在共同理解。
  • 视野绽出：时间性的三个维度（将来、曾在、当前）各自朝向并开启一个特定的意义领域（“视野”），这种开启就是“绽出”。世界时间的结构正源于时间性的这种“绽出”特性。
  • 超越性：此在本质上总是“超出”自身而指向世界。世界时间的超越性意味着它并非事物内在的属性，而是随着此在向世界的展开而呈现的。
  • 寻视：操劳活动中的一种非主题化的、实践的“看”或理解方式。此在在活动中自然而然地理解工具和情境的意义，而不是通过理论反思。

2. 逐句转译

  1. 原文: 时间测量锻铸时间的公共化。

    • 转译: 我们对时间的测量行为（比如看表、安排日程），实际上是在塑造和巩固一种人人都能理解和使用的时间，也就是公共时间。

  2. 原文: 于是我们一般称为“时间”的东西只有在这条道路上才得识认。

    • 转译: 因此，我们平常所说的那个“时间”（比如钟点、日期），只有通过这种在操劳活动中进行测量和公共化的过程，才能被我们认识到。

  3. 原文: 在操劳活动中，每一事物都配有“它的时间”。

    • 转译: 在我们的日常活动里，每一样东西都有它“合适的时间”，比如“吃饭的时间”、“工具派上用场的时间”。

  4. 原文: 它有时间并能像有任何一种世内存在者那样“有”时间，只因它根本就“在时间之中”。

    • 转译: 事物之所以能“拥有”时间，就像它们可以拥有其他属性一样，根本原因在于它们自始至终就是在一个时间性的世界中被我们遇到的，它们本身就“在时间里面”。

  5. 原文: 我们把世内存在者“在其中”照面的时间识认为世界时间。

    • 转译: 我们正是在与事物打交道的过程中，把我们所遭遇的那个时间理解成“世界时间”。

  6. 原文: 时间性中包含有世界时间，而世界时间根据于时间性从视野绽出的建构而像世界一样具有超越性。

    • 转译: 世界时间是根植于更深层的时间性之中的。时间性本身有一种向外展开的结构（视野绽出），正是这种结构使得世界时间得以形成，并且让世界时间也和世界本身一样，具有一种超出自身、指向意义的特性（超越性）。

  7. 原文: 世界时间随着世界的展开而公共化，其结果是每一寓于世内存在者并操劳于时间的存在都以寻视方式把世内存在者领会为“在时间中”来照面的。

    • 转译: 世界时间随着我们生活的世界向我们展开，而成为公共的。这样一来，每一个生活在世界中、并忙于处理时间事务的人（此在），都会在实践活动中自然而然地把遇到的事物，理解为是“在时间之中”出现的。

3. 论证逻辑梳理

  1. 前提：此在通过“时间测量”这一操劳活动，塑造了公共化的时间。
  2. 第一步推进：由此指出，我们日常理解的“时间”正是源于这条“测量-公共化”的道路。
  3. 第二步推进：具体描述操劳活动中的时间经验：每个事物都有“它的时间”。并分析其原因：事物能“有”时间，是因为它们本就“在时间之中”。
  4. 关键定义：将这种在操劳中照面的时间明确界定为“世界时间”。
  5. 根源追溯：指出世界时间的更深层基础是“时间性”，并解释其生成机制——源于时间性的“视野绽出”结构，这赋予了世界时间“超越性”。
  6. 结论：最终阐明，世界时间的公共化是一个动态过程（随世界展开而公共化），而这直接决定了此在如何以“寻视”的方式，将世内存在者领会为“在时间中”的存在。

4. 整体概括

这段话的核心是在解释我们日常生活中所熟悉的“公共时间”（如钟表时间）究竟从何而来。海德格尔认为，它并非客观存在的容器，而是源于人（此在）在忙碌的生活（操劳活动）中对时间进行估算和安排（时间测量）的过程，这个过程使时间成为公共的、可共享的。我们在生活中觉得每件事物都有“它的时间”（比如开会时间、 harvest time），正是因为事物总是在一个充满时间性意义的世界里与我们相遇。这个被我们直接体验到的、带有目的和情境的时间，就是“世界时间”。它根植于人最深层的时间性存在结构，并随着我们生活的展开而成为公共的背景。最终，我们每个人在投入日常活动时，都会不假思索地把遇到的一切事物看作是“在时间中”发生和存在的。

5. 争议与说明

本段解读相对一致，是对海德格尔时间思想中从“时间性”到“世界时间”推导过程的标准阐述。可能的细微讨论点在于对“锻铸”一词力度的理解——它更偏向于“揭示并建构”，还是更偏向于“主观创造”？主流的、也更符合海德格尔反主观主义立场的解读是前者：测量活动是让本就基于时间性的世界时间以公共的、可计量的形态“显现”出来，而非从无到有地发明了它。
