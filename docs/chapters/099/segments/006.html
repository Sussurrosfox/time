📖 《存在与时间》研读 逐段解析

📜 原文片段 (099/006)
海德格尔 原文
“公共时间”表明自身为世内上手事物与现成事物“在其中”照面的那一时间。这就要求把这种非此在式的存在者称为时间内的存在者。对时间内状态的阐释将使我们更源始地洞见“公共时间”的本质同时并使我们能够界说它的“存在”。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 公共时间：指我们在日常生活中共同使用的、客观化的时间尺度（如钟表、日历时间）。它是在世界之中与他人共有的、用于安排和测量事件序列的时间。
  • 世内上手事物：指我们直接与之打交道的、作为工具被使用的存在者（如锤子、笔）。它们不是被冷静观察的对象，而是在使用活动中与我们照面的东西。
  • 现成事物：指作为客观对象摆在那里、具有固定属性的存在者（如一块石头、一张桌子）。它们是被理论静观所把握的、脱离使用情境的对象。
  • 非此在式的存在者：指除了“此在”（人的存在）之外的存在者，即上手事物与现成事物这类不具“在世存在”结构的对象。
  • 时间内状态：指非此在式的存在者处于时间之中的那种方式，即它们是在时间“之内”被遭遇到、被安排的存在者。
  • 源始：指更原本、更基础、更接近现象本身的层次。海德格尔常用此词强调要回到比传统理解更深层的根源。

2. 逐句转译

  • “公共时间”表明自身为世内上手事物与现成事物“在其中”照面的那一时间。 → 我们所说的“公共时间”，它的本质就体现在：它正是那些我们日常打交道的事物（如工具）和那些摆在我们面前的对象事物，它们在其中与我们相遇的那个时间框架。

  • 这就要求把这种非此在式的存在者称为时间内的存在者。 → 正因为如此，我们就需要把这类不是“人”（此在）的存在者（即上手事物和现成事物），称作是“在时间之中的存在者”。

  • 对时间内状态的阐释将使我们更源始地洞见“公共时间”的本质同时并使我们能够界说它的“存在”。 → 如果我们能够深入分析和阐明这些“非人”存在者是如何存在于时间之中的（即它们的“时间内状态”），那么我们就能更根本、更深刻地看清“公共时间”的真正本质是什么，并且也能够据此去界定和说明“公共时间”本身的存在方式。

3. 论证逻辑梳理

  1. 前提/起点：存在一个被称为“公共时间”的现象。
  2. 现象描述：这个“公共时间”显现自身的方式，是作为世内事物（无论它们是作为工具被使用，还是作为对象被观察）得以与我们相遇的境域。时间是事物得以呈现的舞台。
  3. 初步结论/定义：因此，这些事物（非此在式的存在者）可以被定义为“时间内的存在者”。它们的存有模式就是在时间之中。
  4. 方法论转向与预期成果：海德格尔提出，下一步的研究路径是去阐释这种“时间内状态”。他论证说，这条路径是迂回的，但却是更有效的：通过分析这些“在时间中的事物”如何存在，我们反而能更本源地（绕开流俗时间观的遮蔽）看清“公共时间”的本质，并最终能正面回答“公共时间本身如何存在”这个更困难的问题。

4. 整体概括

这段话的核心意思是：我们通常理解的公共时间（如钟表时间），其本质需要通过它如何作为世间万物（无论是工具还是物体）显现和活动的背景框架来理解。因为这些事物都是在时间“之中”与我们相遇的，所以我们可以称它们为“时间内的存在者”。海德格尔认为，通过深入分析这些事物存在于时间中的具体方式（即“时间内状态”），我们反而能绕开对时间的流俗理解，更深刻地把握公共时间本身的根源性本质，并最终能够回答“时间本身是怎样一种存在”这个根本问题。这是一种“迂回战术”，通过分析“在时间中的存在者”来逼近“时间本身的存在”。

5. 争议与说明

本段解读相对一致。核心论点——通过分析非此在存在者的时间内状态来揭示公共时间的本质——是海德格尔时间性分析的一个关键方法策略，学界对此基本认同。可能的细微讨论点在于对“源始”一词的理解深度，但这不构成对段落主旨的根本争议。
