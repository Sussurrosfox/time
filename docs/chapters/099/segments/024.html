📖 《存在与时间》研读 逐段解析
首页 / 第 099 章 / 片段 024
📜 原文片段 (099/024)
海德格尔 原文
如果“客观”一词意指世内照面的存在者的自在现成存在，那么，现成事物动止“在其中”的时间就不是“客观的”。如果我们把“主观的”领会为在一个“主体”中现成存在或出现，那么时间也同样不是“主观的”。世界时间比一切可能的客体都更“客观”，因为它作为世界内存在者之所以可能的条件向来已随着世界的展开以绽出视野的方式“客观化”了。所以，与康德的意见相反，世界时间在物理事物那里一如在心理事物那里一样是直接现出的，而非先要假道于心理事物才在物理事物那里出现。“时间”首先恰恰是在天空显现出来的，亦即在人们自然地依照时间调整自己之际，它恰恰在人们见出它之处显现出来；结果“时间”甚至就与天空同为一事。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 客观：在本段中，海德格尔特别限定其含义为“世内照面的存在者的自在现成存在”。通俗地说，这是指一个东西像摆在面前的物体那样，独立于我们的意识、自身完备地存在。
  • 主观：在本段中，被限定为“在一个‘主体’中现成存在或出现”，即时间不是某种仅仅存在于人的心灵内部、作为心理状态或意识内容的东西。
  • 世界时间：这是海德格尔的核心概念。它不是我们通常理解的物理时间或心理时间，而是随着“世界”（此在生存的整体关联域）的展开而呈现出的时间。这种时间先于任何主客二分，是世内存在者（无论是物理事物还是心理事物）得以显现的原初条件。它通过“绽出视野”（Ekstasen-Horizonte）的方式“客观化”，意思是，它并非静止的容器，而是此在超越自身、筹划未来的动态视野。
  • 现成存在（Vorhandenheit）：指事物像现成摆在眼前的对象那样存在，具有固定的属性，可以被观察和测量。这是传统形而上学看待事物的方式。
  • 绽出视野（Ekstasen-Horizonte）：时间性的三个出离自身（朝向未来、曾在本已、当下）的维度所展开的境域。世界时间正是在这种动态的“出离-境域”结构中得以“客观化”。
  • 此在（Dasein）：指人的存在方式，其本质是“在世之存有”，即人总是已经在一个有意义的世界中与他人、他物打交道。

2. 逐句转译

  1. 如果“客观”一词意指世内照面的存在者的自在现成存在，那么，现成事物动止“在其中”的时间就不是“客观的”。
    • 我们通常认为“客观”的东西，就像一张桌子、一块石头那样，是独立于我们、自身完备的。但时间并不是这样一种可以摆在面前的“现成物体”。
  2. 如果我们把“主观的”领会为在一个“主体”中现成存在或出现，那么时间也同样不是“主观的”。
    • 反过来，如果我们认为“主观”的东西就是完全存在于人的内心、作为一种心理状态（比如一个念头或一种感觉），那么时间也不是这种意义上的“主观”东西。
  3. 世界时间比一切可能的客体都更“客观”，因为它作为世界内存在者之所以可能的条件向来已随着世界的展开以绽出视野的方式“客观化”了。
    • 海德格尔提出，“世界时间”比任何客体（物体）都更为根本和“客观”。这是因为，任何事物（无论是物理的还是心理的）要能作为某物显现给我们，首先必须有一个时间性的境域。这个时间境域随着我们投入世界、筹划生活而一同展开，并使得事物能够被我们遭遇。它不是被我们后来赋予世界的，而是先于主客二分、随着我们的生存活动本身“呈现”出来的。
  4. 所以，与康德的意见相反，世界时间在物理事物那里一如在心理事物那里一样是直接现出的，而非先要假道于心理事物才在物理事物那里出现。
    • 因此，海德格尔反对康德的观点。康德认为时间是人的内在直观形式，我们先在内心感受到时间，然后才把它投射到外部事物上去。但海德格尔认为，时间在物理事物（比如太阳的运行）和心理事物（比如我们的情绪）那里是同时直接显现的，不需要先经过心理这一关。
  5. “时间”首先恰恰是在天空显现出来的，亦即在人们自然地依照时间调整自己之际，它恰恰在人们见出它之处显现出来；结果“时间”甚至就与天空同为一事。
    • 时间最初、最原初的显现场所，就是我们抬头可见的天空。当远古的人们根据日出日落、星辰位置来安排劳作起居时，他们并不是先有一个抽象的时间概念，然后再应用到天空上。恰恰相反，他们正是在观察天空、顺应天时的具体活动中，直接领会到了时间。以至于在那种生活经验中，“时间”和“天空”（及其运行）几乎是同一回事。

3. 论证逻辑梳理

  1. 前提/破斥： 首先，海德格尔通过严格界定，排除了对时间的两种流俗理解：
    • 时间不是“客观”的（不是一种现成的物）。
    • 时间不是“主观”的（不是一种内在的心理表象）。
  2. 核心论点提出： 在破斥了流俗观点后，他提出了自己的正面论点：世界时间是更源始的“客观”。其论证是：世界时间是世内存在者（无论主客）得以可能的条件，它随着世界的展开（通过此在的绽出视野）已经先行“客观化”了。
  3. 驳论与深化： 接着，他用这个论点直接反驳康德的时间观，强调时间的直接显现性，否定了康德“时间内在于心”的间接路径。这进一步巩固了他的“世界时间”先于主客二分的观点。
  4. 现象学例证： 最后，他提供了一个强有力的现象学描述作为证据：时间原初是在天空中被经验的，与人的生存实践（依时劳作）密不可分。这个例子直观地表明，时间从一开始就是世界性的、实践性的，而非内在的、抽象的。

4. 整体概括

这段文字的核心在于，海德格尔要破除将时间要么看作外在的物理容器、要么看作内在的心理形式的传统观点。他提出，存在着一种更为源始的“世界时间”，它先于主客对立，是随着我们人（此在）在世界中生存、筹划而共同展开的一个动态境域。任何事物（物理的或心理的）要能成为我们遭遇的对象，都必须在这个时间境域中才能显现。因此，时间比任何“客体”都更客观，因为它构成了它们显现的可能性条件。他以古人观天计时的生活实践为例，说明时间最初就是在这样的世界性活动中，与天空、与人的行动直接一体地呈现出来的，从而有力地支持了他的“在世界之中”的时间观。

5. 争议与说明

本段解读相对一致，核心争议点主要在于对海德格尔“世界时间”与康德“先验观念性/经验实在性”时间观之间关系的理解。

  • 主流解读（如上文所述）：海德格尔是在批判康德将时间主体化、内在化了，他要揭示的是一个更为源始的、生存论-世界性的时间，这个时间先于主客二分。
  • 其他解读方向：有学者认为，海德格尔对康德的批评可能有些简化，康德的时间作为“先验形式”同样具有构成客观经验的普遍效力，与“心理主义”不同。海德格尔的“世界时间”可以看作是对康德时间观的“生存论化”和“具体化”，将其从纯粹意识的层面拉回到了日常生活世界的层面。争议的焦点在于，海德格尔是否完全驳倒了康德，还是提供了一种互补的、不同层面的分析。
