📜 原文片段 (099/013)
海德格尔 原文
自然的钟表的展开状态属于以被抛沉沦方式生存着的此在；在这种展开状态中同时有着别具一格的、向来已由实际此在进行着的对所操劳的时间的公共化。随着计时的完善化与钟表使用的精密化，这种公共化过程不断提高，不断落实。这里不应从历史学角度就种种可能的演变提供时间计算与钟表使用的历史发展。毋宁是要从生存论存在论上询问：在时间计算与钟表使用的形成方向上，此在时间性的何种到时样式公开出来了？回答这个问题，便定会生长出一种更源始的领会。时间测量，也就是所操劳的时间的明确的公共化根据于此在的时间性，即根据于时间性的某种完全确定的到时。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学中的核心概念，指人的存在方式，其本质在于“去存在”（Zu-sein），即不断在可能性中展开自身。
  • 被抛沉沦：“被抛”指此在总是已经被抛入一个既定的世界，无法选择；“沉沦”指此在日常状态中迷失于世界，沉溺于琐事，逃避本真自我。
  • 展开状态：此在对自身存在的理解和揭示，它总是在某种方式中“展开”或“揭示”自己的存在与世界。
  • 公共化：指此在将私人、主观的时间体验，通过某种方式（如使用钟表）转化为一个公共、可共享的时间框架。
  • 操劳：此在日常与世界打交道的非本真模式，忙于处理各种事务，沉浸在“实用性”中。
  • 时间性：此在存在的根本结构，是过去（曾在）、现在（当前化）和未来（先行）的统一动态过程。
  • 到时：时间性的“实现”或“显现”方式，指时间性如何具体地“时间化自身”、如何展开为具体的时间体验。

2. 逐句转译

  1. “自然的钟表的展开状态属于以被抛沉沦方式生存着的此在；在这种展开状态中同时有着别具一格的、向来已由实际此在进行着的对所操劳的时间的公共化。”

    • 我们日常生活中依赖的、像日出日落这样的“自然钟表”，其存在和我们对它的使用，本身就是我们作为普通人（此在）沉陷在日常琐事（被抛沉沦）中的一种表现。在这种日常状态里，我们已经一直在做一件事：把我们为了处理各种事务（操劳）而体验到的时间，转化成一个大家都能共用和遵循的公共时间。

  2. “随着计时的完善化与钟表使用的精密化，这种公共化过程不断提高，不断落实。”

    • 随着计时工具（从日晷到机械钟表）越来越精准，我们使用它们的方式也越来越精细，这个将时间“公共化”的过程就变得更加彻底和稳固。

  3. “这里不应从历史学角度就种种可能的演变提供时间计算与钟表使用的历史发展。”

    • 我们现在要做的，不是去回顾钟表和计时技术具体是怎么一步步发展起来的历史。

  4. “毋宁是要从生存论存在论上询问：在时间计算与钟表使用的形成方向上，此在时间性的何种到时样式公开出来了？”

    • 我们更应该从哲学根本上问：在时间计算和钟表使用这个现象背后，我们人类的存在结构（时间性）究竟是以一种什么样的具体模式显现出来的？

  5. “回答这个问题，便定会生长出一种更源始的领会。”

    • 如果能回答这个问题，我们就能获得一种比单纯看历史更深刻、更根本的理解。

  6. “时间测量，也就是所操劳的时间的明确的公共化根据于此在的时间性，即根据于时间性的某种完全确定的到时。”

    • 所以，时间测量（即把我们琐事中的时间明确公共化）这件事，其根源在于我们人类存在的根本时间结构（时间性），特别是这种时间结构以一种非常特定的方式（强调“当前化”和“现成性”）展现自身。

3. 论证逻辑梳理

  • 前提/现象描述 (句1-2)：首先指出一个普遍现象——此在在日常沉沦状态中，会使用“自然钟表”乃至精密钟表，并在此过程中将私人时间“公共化”，且这一过程随着技术进步不断强化。
  • 方法论界定 (句3)：明确排除了从外在历史学角度研究该现象的方法，将问题域限定在生存论-存在论层面。
  • 核心问题提出 (句4)：基于上述现象，提出核心哲学问题：钟表时间现象揭示了此在时间性的何种本质特征（何种到时样式）？
  • 问题价值与回答预示 (句5)：指出回答此问题能带来更深刻（更源始）的理解。
  • 结论性断言 (句6)：最终得出结论：时间测量的可能性根基，在于此在的时间性本身，特别是其某种特定的显现方式（到时）。

4. 整体概括

这段话的核心意思是：我们日常生活中对时间的测量和公共化（比如使用钟表制定统一作息），看似是一种外在的技术行为，但海德格尔认为，这背后有着深刻的哲学根源。他提出，我们不应该仅仅从历史角度去研究钟表怎么发明的，而应该深入追问：这种普遍依赖公共时间的现象，到底反映了我们人类自身存在的何种时间结构？他的答案是，时间测量的可能性，正根植于我们作为“此在”所具有的“时间性”这一根本属性，是时间性以一种特定的、侧重于“当前时刻”和“现成可用”的方式（到时）显现自身的结果。理解这一点，才能越过表面现象，触及时间更本质的意义。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“某种完全确定的到时”的具体理解。主流解读认为，这特指时间性中以“当前化”为主导的、非本真的到时模式，它使得时间仿佛成为一系列可以计量和分割的“现在点”的序列。但也有学者强调，即使是这种公共化的、非本真的时间，其根基仍然是本真时间性的整体结构，只是它以一种遮蔽和扁平化的方式显现。
