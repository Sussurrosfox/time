📜 原文片段 (075/012)
海德格尔 原文
出于选择了自身的能在这种“为何之故”，下了决心的此在解放自己，自由面对其世界。唯有断然朝向其自身的决心才把此在带入这样的可能性：让一道存在着的他人在他们自己最本己的能在中去“存在”，而在率先解放的操持中把他们的能在一道开展出来。这种下了决心的此在可以成为他人的“良知”。本真的共处，唯源出于决心中的本真的本身存在，而非源出于模棱两可心怀妒嫉的约许和在常人及其所欲从事之业中的喋喋不休的称兄道弟。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学中的核心概念，特指人的存在方式，即那种能够对自身存在进行发问、并关心自身存在的存在者。
  • 能在：此在的本质在于它不是现成的，而是始终面向各种可能性、能够去成为某种样态的存在。它指此在是“能够去存在”的。
  • 决心：此在的一种本真存在状态。它不是指做某个具体决定，而是指此在清醒地面对自身被抛入世的境况，并果断地将自身投向其最本己的、由“良知”所呼唤的能在。
  • 为何之故：此在生存的终极目的或意义，即为了它自身的能在而存在。这是此在一切行动和筹划的最终指向。
  • 本真/本己：此在摆脱了“常人”的支配，真正领会并承担起自身独一无二的命运与可能性的存在状态。
  • 常人：一个非人格的、平均化的、支配着日常公众意见的主体。此在在沉沦中，往往放弃自身独特性，以“常人”的方式去存在。
  • 操持：此在与其他存在者（主要是他人）打交道的一种基本方式。它关注的是与他人的共在，但其方式有“本真”与“非本真”之分。
  • 共处：此在与其他此在共同存在于世界之中的基本生存论结构。
  • 良知：在海德格尔看来，这不是道德评判，而是此在自身发出的一种呼唤，呼唤此在从“常人”的沉沦状态中抽身而出，回到它本己的自身。

2. 逐句转译

  1. 原文：出于选择了自身的能在这种“为何之故”，下了决心的此在解放自己，自由面对其世界。 转译：当一个“此在”（人）真正下定了决心，并且这个决心是源于它选择了自己的“可能性人生”（能在）作为其存在的终极目的时，这个此在就获得了自我解放。它不再被外界纷扰所束缚，能够以一种自由、开放的态度来面对它所生活的世界。

  2. 原文：唯有断然朝向其自身的决心才把此在带入这样的可能性：让一道存在着的他人在他们自己最本己的能在中去“存在”，而在率先解放的操持中把他们的能在一道开展出来。 转译：只有这种果断地、一心一意面向自身可能性人生的决心，才能让此在达到一种新的境界：它现在能够允许和鼓励那些与它共存的其他人，也去追寻和实现他们自己最独特的可能性人生。这个率先获得自由的此在，会以一种“解放性的关怀”来与他人相处，并在这个过程中，帮助他人一同展开和实现各自的人生可能性。

  3. 原文：这种下了决心的此在可以成为他人的“良知”。 转译：这样一个已经下了决心、活出本真状态的人，他本身的存在方式，就可以像一面“活生生的镜子”或一声无声的呼唤，触动他人，促使他人也去倾听自己内心的“良知”，从而唤醒他们自己的本真状态。

  4. 原文：本真的共处，唯源出于决心中的本真的本身存在，而非源出于模棱两可心怀妒嫉的约许和在常人及其所欲从事之业中的喋喋不休的称兄道弟。 转译：所以，真正深刻、真诚的人际共同生活（本真的共处），它的根源只能是每个人都从自己的决心出发，活出真实的自我。它绝不来源于那些含糊不清、带着嫉妒心的空头许诺，也不来源于在“大家伙儿”（常人）的圈子里，为了共同的事业而进行的、表面热络实则空洞的“称兄道弟”。

3. 论证逻辑梳理

  • 前提：此在能够通过“决心”选择其“为何之故”（自身的能在），从而解放自己，自由地面对世界。
  • 核心论证与推进：
    1. 文章首先确立，本真性的获得（决心）带来个体的自由。
    2. 接着，它将这种个体自由的价值向外延伸：真正的自我实现（决心）并非自私的孤立，恰恰相反，它为一种更高级的“共处”创造了条件。因为它让此在有能力和气度去“让”他人也成为他们自己。
    3. 然后，将这种影响具体化：本真的此在可以成为他人的“良知”，即通过自身的榜样作用无声地唤醒他人。
  • 结论：最终，通过对比得出核心论点——真正的、本真的人际关系（共处），其唯一坚实的基础是每个个体自身的本真存在（决心）。并明确否定了其对立面，即建立在“常人”的闲言和暧昧承诺之上的非本真共处。

4. 整体概括

这段话的核心思想是：一个人只有先勇敢地面对自己，认清并选择自己真正想要的人生（下决心），才能获得内在的自由。这种内在的自由不是孤芳自赏，反而会让他有能力去尊重和成全他人的自由，鼓励他人也去探寻他们自己的人生道路。这样的人，他活出的真实样子本身，就能像警钟一样唤醒身边的人。因此，真正高质量、有深度的社交关系，一定是源于一群各自独立的、活出了真我的人之间的共鸣与互动，而不是靠随大流、说漂亮话或者搞小团体那种虚伪的热闹能营造出来的。海德格尔在这里描绘了一幅“先成己，后达人”的伦理图景。

5. 争议与说明

本段解读相对一致。一个可能的细微争议点在于对“成为他人的‘良知’”的理解。最主流的解读是榜样/唤醒说，即本真此在以自身的存在方式无言地呼唤他人。但也有学者更强调其存在论意味，认为这不是有意的道德教化，而是此在在其本真状态中，其存在本身就“让出空间”，使他人得以在其存在的真理中显现。这两种解读方向本质上并不矛盾，前者侧重于现象描述，后者侧重于存在论根基。
