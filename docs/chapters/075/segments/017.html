📖 《存在与时间》研读 逐段解析

📜 原文片段 (075/017)
海德格尔 原文
把一种空洞的“习惯”和一种不确定的“随意动机”拼凑到一起并不就是我们以决心这一名称所称的现象。决心并非刚刚有所认知地把处境呈到眼前〔sick vorstellen〕，而是已经把自身投入〔sick stellen in〕处境。此在作为下了决心的此在己经行动着。我们有意避免使用“行动”这个语词。因为，一方面，我们不得不重新在很广泛的意思上把握这个词，结果它本似专指积极活动，却把阻碍这类“活动”也包括进来，虽然阻碍其实是消极的不活动。另一方面，它易于导致对此在存在论的误解，似乎决心是与理论职能对应的某种实践职能所特有的行为。可是操心作为有所操劳的操持却至为源始、至为整全地包罗着此在的存在，乃至若要区分理论行为与实践行为，总先就得把操心设为前提，而并非由这两种职能才始得合建起操心来—即使借辩证法之助也不行，辩证法由于未在生存论中奠立根基而必然是无根基的。决心恰只是操心本身的本真状态——是操心中为之操心的本真状态，而它只有作为操心才可能成为操心本身的本真状态。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 决心：在海德格尔哲学中，一般指此在（人的存在）通过直面自身有限性和可能性，做出本真决断的状态。它并非基于理性计算的“决策”，而是此在清醒地投入其生存处境、承担自身命运的存在方式。本段强调决心是“投入处境”而非“认知呈现”，突出了其实践性和生存性。

  • 操心：此在存在的整体结构，指人始终“关心”自身在世界中的存在，既包括与事物打交道的“操劳”，也包括与他人共在的“操持”。本段强调操心是比理论与实践区分更源始的整体存在结构。

  • 本真状态：此在摆脱常人（非本真）的支配，直面自身可能性、承担自身自由的存在方式。本段将决心定义为操心的本真状态。

  • 理论职能/实践职能：传统哲学对认知与实践的区分。海德格尔认为这种区分建立在更源始的操心结构之上，不能反过来解释操心。

2. 逐句转译

“把一种空洞的‘习惯’和一种不确定的‘随意动机’拼凑到一起并不就是我们以决心这一名称所称的现象。” → 海德格尔首先划清界限：我们所说的“决心”，不是指那种漫无目的的习惯加上模糊动机的随意组合。

“决心并非刚刚有所认知地把处境呈到眼前，而是已经把自身投入处境。” → 决心不是先冷静地分析清楚状况再做决定，而是一开始就已经让自己置身于那个具体情境之中。

“此在作为下了决心的此在己经行动着。” → 一个真正下定决心的人，其实已经在行动中了。

“我们有意避免使用‘行动’这个语词。因为，一方面，我们不得不重新在很广泛的意思上把握这个词，结果它本似专指积极活动，却把阻碍这类‘活动’也包括进来，虽然阻碍其实是消极的不活动。” → 这里特别说明为什么不用“行动”一词：因为这个词通常只指积极的做事，但如果按海德格尔的理解，它还得包括“不作为”或“阻碍”这种看似消极的状态，这就和日常理解矛盾了。

“另一方面，它易于导致对此在存在论的误解，似乎决心是与理论职能对应的某种实践职能所特有的行为。” → 更重要的是，“行动”容易让人误解，以为决心只是与实践对应的某种特定行为，就像理论思考对应认知一样。

“可是操心作为有所操劳的操持却至为源始、至为整全地包罗着此在的存在，乃至若要区分理论行为与实践行为，总先就得把操心设为前提，而并非由这两种职能才始得合建起操心来—即使借辩证法之助也不行，辩证法由于未在生存论中奠立根基而必然是无根基的。” → 但操心这个整体存在结构比理论/实践的区分更根本——我们之所以能区分思考和行动，正是因为我们已经处于操心这种生存状态中，而不是反过来用思考和行动拼凑出操心。即使动用辩证法（黑格尔式的正反合）也不行，因为它缺乏生存论的基础。

“决心恰只是操心本身的本真状态——是操心中为之操心的本真状态，而它只有作为操心才可能成为操心本身的本真状态。” → 最后点明：决心其实就是操心这种基本生存结构的本真形态，是操心在认真对待自身时的样子，也只有作为操心，决心才可能成立。

3. 论证逻辑梳理

前提：日常对“决心”的理解有误（等同于习惯+动机）。 推进1：通过对比澄清——决心是“投入”而非“认知呈现”，是已经在“行动中”。 推进2：为避免误解，说明为何不用“行动”一词（含义过窄，且易陷入理论/实践二元论）。 推进3：论证操心比理论/实践区分更源始——这种区分要以操心为前提。 结论：决心就是操心本身的本真状态，二者不可分割。

4. 整体概括

这段话的核心是在纠正我们对“决心”的日常误解。海德格尔告诉我们，决心不是先想清楚再行动的决策过程，而是直接投入生存情境的存在方式。他特别警惕用“行动”这个词，因为这会让人陷入理论VS实践的二分法陷阱。实际上，我们最基本的生存状态是“操心”——一种始终关心自身存在的整体结构，而理论思考或实际行动都只是这个结构的某种表现形态。决心，就是操心这种基本结构在认真对待自身时展现出来的本真样态。简单说，真正的决心不是你“决定做什么”，而是你“以什么样的方式存在”。

5. 争议与说明

本段解读相对一致。可能的细微争议在于“决心是否包含具体行动选择”——有学者认为决心更侧重存在态度的转变，不必然体现为具体行动；但主流解读认为，决心作为本真操心，必然通过具体生存选择显现，只是这种“行动”比传统意义上的实践更源始。
