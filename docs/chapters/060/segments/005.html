海德格尔 原文
然而，一旦此在全然不再有任何亏欠，一旦此在以这种方式“生存”，那它也已经一起变成了“不再在此”。提尽存在的亏欠等于说消灭它的存在。只要此在作为存在者存在着，它就从不曾达到它的“整全”。但若它赢获了这种整全，那这种赢得就成了在世的全然损失。那它就不能再作为存在者被经验到。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔用此在指代“人”这种存在者。此在的本质在于它的“生存”，即它不是像石头、树木那样固定不变的存在，而是不断筹划、理解自身可能性的存在。它的存在总是一种“尚未完成”的状态。
  • 亏欠：这不是指道德或债务上的亏欠，而是指此在作为一种“能在”，其存在结构中固有的“尚未”或“不完整性”。此在总是向着未来的可能性敞开，所以它永远“欠缺”着某种未来的实现。
  • 整全：指此在作为一种生命历程，其全部可能性的最终实现和完成状态。对于此在而言，这恰恰意味着其生命（生存过程）的终结，即死亡。
  • 不再在此：即此在的死亡。这不是指它移到了别处，而是指它作为“在世界之中存在”的终结，它不再能展开其生存活动。
  • 在世：此在最基本的存在结构，即它从来都不是一个孤立的主体，而是始终已经与一个世界（由用具、他人、意义构成的环境）纠缠在一起。

2. 逐句转译

  • “然而，一旦此在全然不再有任何亏欠，一旦此在以这种方式‘生存’，那它也已经一起变成了‘不再在此’。”

  • 这句话是说：如果一个人彻底完成了所有的人生可能性，不再有任何未实现的筹划和未来（即“不再有任何亏欠”），那么这种所谓的“生存”状态，实际上就是他生命的终点，他就不再存在于这个世界上了。

  • “提尽存在的亏欠等于说消灭它的存在。”

  • 这句话进一步强调：把这个“亏欠”（未完成性）彻底消除干净，就等于消灭了此在本身。因为此在之所以是此在，就在于它总是有“还没做的事”，总是处在“在路上”的状态。一旦路走完了，这个“在路上”的存在者也就消失了。

  • “只要此在作为存在者存在着，它就从不曾达到它的‘整全’。”

  • 这句话解释原因：只要一个人还活着，他就永远不可能达到生命的“完整版”。因为只要活着，未来就永远是开放的，总还有新的可能性。

  • “但若它赢获了这种整全，那这种赢得就成了在世的全然损失。”

  • 这句话揭示了一个悖论：如果一个人真的获得了生命的“整全”（即他所有的可能性都实现了），那么这种“获得”的代价就是他完全失去了“在世界中存在”这回事——他死了。

  • “那它就不能再作为存在者被经验到。”

  • 这句话是上一个句子的结果：当生命达到“整全”（死亡）时，这个人就不再能作为一个活生生的、可以被我们遭遇和打交道的存在者被经验到了。

3. 论证逻辑梳理

  1. 前提/起点：此在的本质在于其生存，而生存总包含着面向未来的“亏欠”（未完成性）。
  2. 核心推理（假设与归谬）：
    • 假设此在达到了无亏欠的状态（即“整全”）。
    • 那么，这种状态的达成，恰恰意味着此在生存的终结（变成了“不再在此”）。
    • 因此，消除亏欠就等于消灭此在的存在。
  3. 正面阐述与反面印证：
    • 正面：只要此在存在，它就达不到整全（因为它总在“生成”中）。
    • 反面：如果它达到了整全，它就失去了在世的存在（它死亡了）。
  4. 结论：此在的“整全”与它的“在世存在”是 mutually exclusive（相互排斥）的。此在的整全只能在它的终结处被触及，而此时它已不复是我们可以与之照面的存在者。

4. 整体概括

这段话的核心是在探讨一个关于人之存在的深刻悖论。海德格尔指出，我们人（此在）的本质就是一种“活在路上”的状态，总是有没做完的事，没实现的可能（这就是“亏欠”）。正是这种未完成性，定义了我们作为活生生的人。因此，如果我们想象一个人生彻底“完满”了，没有任何亏欠了，那这个状态恰恰就是他生命的终点——死亡。活着，就意味着不完整；一旦完整，生命也就结束了。所以，我们永远无法在活着的时候，经验到自己或他人作为一个“完整”的生命整体。

5. 争议与说明

本段解读相对一致。核心思想——此在的整全性只在其死亡中达成——是海德格尔死亡现象学的基石之一，学界对此基本没有争议。可能的讨论点在于如何理解“经验”一词：海德格尔强调，此在的整全（死亡）无法被此在自身“经验”到，但这是否意味着他人完全无法“经验”此在的死亡？对此，更细致的解读会区分“亡故”这一生理事件和作为存在论现象的“死亡”。他人可以经验到某人的“亡故”，但无法替代性地经验到那个死者作为此在所经历的、属于自己的“死亡”。不过，这段文字本身更侧重于从存在者层面指出，一个达到整全的此在已无法再被我们当作一个生存着的存在者来打交道。
