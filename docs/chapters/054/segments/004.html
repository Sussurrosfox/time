海德格尔 原文
不过我们须记住：在这项证据里，此在自己关于它自己所道出的东西是“源始的”，并非由种种理论阐释所规定，也没有进行理论阐释的意图。我们还须注意：此在之存在的特点是历史性；尽管这一点还有待从存在论上加以证明。如果此在在它存在的根据处就是“历史的”，那么出自其历史并复归其历史的而且又幸于一切科学的某种命题或说法就具有特殊的分量了；固然这种分量绝不会是从纯存在论上来说的。此在本身之中的存在之领会先于存在论就已道出自身了。下面所引的证据应能澄清：生存论阐释绝不是一种虚构，而是一种存在“建构”，这种建构自有它的基地，并从而也就有它种种初级的草图。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在（Dasein）：海德格尔用以指代“人”这种存在者的术语，强调人是那种能够追问自身存在、并对存在有所领会的特殊存在者。此在的存在方式就是“生存”。
  • 源始的（ursprünglich）：指非派生、非经过理论加工、最直接、最本源的样态。在本段中，它描述的是此在对其自身存在的直接言说，未经任何理论阐释的污染。
  • 历史性（Geschichtlichkeit）：此在存在的根本规定性之一。它意味着此在的存在本质上是在时间中展开的，其存在就是一个不断生成、被其过去所塑造、并面向未来的过程。此在就是它的历史。
  • 存在论（Ontologie）：传统哲学中研究“存在”本身的学问。海德格尔这里指一种系统化、理论化的对存在的研究。
  • 存在之领会（Seinsverständnis）：此在先天具有的一种对“存在”的非主题化、前理论的理解能力。我们总是在与事物打交道之前，就已经对“什么是存在”有了一种朦胧的、实践性的把握。
  • 生存论阐释（existenziale Interpretation）：海德格尔在《存在与时间》中的核心方法，旨在从此在的生存结构出发，来揭示存在的意义。它不是虚构一套理论，而是对此在已然具有的存在方式进行揭示和描述。

2. 逐句转译

  1. “不过我们须记住：在这项证据里，此在自己关于它自己所道出的东西是‘源始的’，并非由种种理论阐释所规定，也没有进行理论阐释的意图。”

    • 首先提醒我们，接下来要引用的证据（比如日常语言或文学作品中的表述），是此在（人）对其自身存在最直接、未经理论加工的言说。它不是说出来的哲学理论，而是生活本身的声音。

  2. “我们还须注意：此在之存在的特点是历史性；尽管这一点还有待从存在论上加以证明。”

    • 接着要注意，此在的存在本身就是在历史中展开的（历史性）。这一点虽然还需要从哲学上系统论证，但我们现在要先意识到它。

  3. “如果此在在它存在的根据处就是‘历史的’，那么出自其历史并复归其历史的而且又幸于一切科学的某种命题或说法就具有特殊的分量了；固然这种分量绝不会是从纯存在论上来说的。”

    • 既然此在的根基就是历史的，那么那些从历史中生长出来、并且回到历史中去影响人的说法（比如格言、诗歌），就有着独特的重要性。它们虽然不像严谨的哲学论证那样是“纯存在论”的，但它们直接关联于人的生存，因此分量很重。

  4. “此在本身之中的存在之领会先于存在论就已道出自身了。”

    • 此在对“存在”的理解，是早于任何哲学理论的。我们在进行哲学思考之前，已经在生活中用行动和语言表达着我们对存在的理解了。

  5. “下面所引的证据应能澄清：生存论阐释绝不是一种虚构，而是一种存在‘建构’，这种建构自有它的基地，并从而也就有它种种初级的草图。”

    • 所以，后面将要引用的证据可以说明：我（海德格尔）所做的生存论分析，不是凭空捏造的。它是对此在已经拥有的存在结构的揭示和描述（“建构”）。这个建构工作有其坚实的基础——就是此在自身的存在领会，并且这个基础早已为此在的生活本身勾勒出了初步的轮廓（“初级草图”）。

3. 论证逻辑梳理

  • 前提1：此在关于自身的直接言说是“源始的”，不掺杂理论。（句1）
  • 前提2：此在的存在具有“历史性”。（句2）
  • 推理与深化：由前提2推导出，那些源自历史并作用于历史的生活言说（非科学、非理论）具有特殊的重要性，因为它们直接关联于此在的历史性存在。（句3）
  • 核心论断：此在对存在的领会是先于理论化存在论的，它已经在生活中自我言说了。（句4）这是连接前提与结论的关键。
  • 最终结论/目的：因此，生存论阐释的任务，就是去揭示和描述这个早已存在的、由生活本身勾勒出的存在结构，它并非哲学家的主观虚构。（句5）

逻辑链条：源始言说 + 历史性 → 生活言说具有分量 → 存在领会先于理论 → 因此，生存论阐释是“发现”而非“发明”。

4. 整体概括

这段话的核心是在为他的哲学方法——“生存论阐释”——进行辩护和说明。海德格尔告诉我们，他的哲学不是坐在书斋里空想出来的理论。他的工作有坚实的“地基”，这个地基就是人（此在）在日常生活中对其自身存在的、最原始、最直接的理解和言说。因为人的存在本身就是“历史性”的，所以这些源于生活、影响生活的言说（比如一句谚语或一首诗所透露出的生存智慧）虽然不系统，但意义重大。他的哲学工作，就是去系统地揭示和描述这个早已被我们的生活所勾画出来的存在结构，所以他自称是在进行一种“建构”，而不是“虚构”。简而言之，他在说：“我的理论，源于生活，并描述生活。”

5. 争议与说明

本段解读相对一致，核心争议点并不在于这段话本身，而在于海德格尔所宣称的“源始性”是否可能真正达到。一些批评者认为，任何语言和概念都已经是某种“阐释”，不存在完全前理论的“源始”状态。海德格尔在这里预设了一个可以摆脱理论污染的、纯粹的生活世界作为起点，这个起点本身可能就是一个哲学建构。但总的来说，对于这段话在海德格尔自身思想体系中的意图和论证功能，学界的理解是趋同的。
