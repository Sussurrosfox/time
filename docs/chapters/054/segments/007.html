海德格尔 原文
这一前存在论的证据之所以具有特别的意义，还不仅因为它一般地把“操心”看作人的此在“有生之时”所隶属的东西，而且还在于“操心”的这种优先地位是同把人看作躯体〔泥土〕和精神的复合体这一熟知的看法联系在一起而出现的。Cura prima finxit〔操心最先造出了它〕：这一存在者在操心之中有其源头。Cura teneat， quamdiu vixerit〔只要它活着，操心就可以占有它〕：只要这一存在者“在世”，它就离不开这一源头，而是由这一源头保持、确定和始终统治着的。“在世”的存在，就存在而言刻有“操心”的印记。这一存在者的命名〔homo 〕不是着眼于它的存在，而是就组成它的东西〔humus〕而言的。至于这一构形的“源始”存在应在何处得而见之，则是由农神即“时间”来判定的。在这一寓言中表达出了对人的本质的先于存在论的规定；从上面的提法可以看出，这一本质规定一开头收入眼帘的那秒存在方式就是始终统治着人在世界中的时间性演变的那一存在方式。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 操心（Cura）：海德格尔哲学中的核心概念，指此在（人的存在）的基本结构，即人总是“关切着”、“牵挂着”自己的存在与世界，不断筹划和应对可能性。在本段中，它被寓言性地描绘为人的创造者和支配者。
  • 此在（Dasein）：特指“人的存在”，是一种能够追问自身存在意义的存在者。
  • 在世（In-der-Welt-sein）：此在的基本存在方式，指人总是已经处于与世界不可分割的关系中，与世界互动。
  • 先于存在论（vorontologisch）：指在系统的哲学分析（存在论）之前，日常生活中已对存在有某种前理性的理解或直觉。
  • 时间性（Zeitlichkeit）：此在存在的根本时间结构，操心通过时间性展开为过去、现在和未来的统一整体。

2. 逐句转译

  • “这一前存在论的证据之所以具有特别的意义，还不仅因为它一般地把‘操心’看作人的此在‘有生之时’所隶属的东西，而且也在于‘操心’的这种优先地位是同把人看作躯体〔泥土〕和精神的复合体这一熟知的看法联系在一起而出现的。”
    → 这个来自日常理解的证据很重要，不仅因为它通常认为人活着就离不开“操心”，还因为“操心”的首要地位和我们熟悉的“人是肉体加精神”的观点有关。

  • “Cura prima finxit〔操心最先造出了它〕：这一存在者在操心之中有其源头。”
    → “操心最先造出了人”：人是从操心这里起源的。

  • “Cura teneat， quamdiu vixerit〔只要它活着，操心就可以占有它〕：只要这一存在者‘在世’，它就离不开这一源头，而是由这一源头保持、确定和始终统治着的。”
    → “只要人活着，操心就占有他”：只要人存在于世界中，他就无法摆脱操心这个源头，反而一直被它维持、界定和支配。

  • “‘在世’的存在，就存在而言刻有‘操心’的印记。”
    → 人在世界中的这种存在方式，从根本上就被“操心”打上了烙印。

  • “这一存在者的命名〔homo〕不是着眼于它的存在，而是就组成它的东西〔humus〕而言的。”
    → “人”（homo）这个词的命名不是根据他的存在方式，而是根据他的构成材料（泥土，humus）。

  • “至于这一构形的‘源始’存在应在何处得而见之，则是由农神即‘时间’来判定的。”
    → 至于这种构成的最初存在应该从哪里看，是由农神——也就是“时间”——来决定的。

  • “在这一寓言中表达出了对人的本质的先于存在论的规定；从上面的提法可以看出，这一本质规定一开头收入眼帘的那秒存在方式就是始终统治着人在世界中的时间性演变的那一存在方式。”
    → 这个寓言表达了在哲学分析之前，人们对人的本质的一种直觉把握；可以看出，这种本质规定从一开始就指向那种始终支配着人在世界中时间性展开的存在方式。

3. 论证逻辑梳理

  • 前提：引用一个寓言作为“前存在论证据”，表明日常理解中已将“操心”视为人的根本。
  • 推进1：指出“操心”不仅被看作人活着就有的属性，还与“人是肉体与精神复合体”这一传统观点相关联，暗示“操心”是更原始的统合因素。
  • 推进2：通过寓言拉丁文格言，论证“操心”是人的起源和终生支配者，并明确“在世”的存在由“操心”贯穿。
  • 推进3：对比“homo”（人）的命名依据是质料（humus，泥土）而非存在方式，暗示日常理解忽略了存在的维度。
  • 推进4：引入“时间”（农神）作为判定“源始存在”的权威，将操心、时间性与人的本质联系起来。
  • 结论：寓言所呈现的先于存在论的本质规定，实际上指向了“操心”作为统治此在时间性演变的根本存在方式。

4. 整体概括

这段文字通过分析一个关于“操心”的寓言，论证了“操心”是人的此在的源头和终生支配者。它指出，尽管日常生活中人们习惯从“肉体-精神”复合的角度理解人，但更深层的前哲学直觉已意识到“操心”才是人存在于世的根本印记。这种“操心”不仅创造了人，而且只要人活着，就始终由它维系和统治。人的命名（homo）基于质料（泥土）而非存在方式，但“时间”作为最终裁决者，揭示了“操心”才是人时间性存在的原始根基。因此，该寓言本质上是对人的本质的一种先于哲学分析的洞察，直指“操心”作为贯穿人生时间演变的决定性存在方式。

5. 争议与说明

本段解读相对一致，核心争议点可能在于： - “农神即时间”的隐喻：有学者认为此处的“时间”更侧重古希腊“时机”或“命运”意味，而非线性时间；但主流解读仍采纳海德格尔将时间性视为操心之展开的基本视野。 - 先于存在论规定的地位：部分研究质疑日常寓言能否有效支撑存在论论点，但多数学者认同海德格尔是在揭示生存经验的深层结构。
