📖 《存在与时间》研读 逐段解析
首页 / 第 037 章 / 片段 010
📜 原文片段 (037/010)
海德格尔 原文
常人就这样卸除每一此在在其日常生活中的责任。不仅此也，只要在此在中有轻取与轻举的倾向，常人就用这种卸除存在之责的办法去迎合此在。又因为常人经常用卸除存在之责的办法迎合每一此在，这样就保持并巩固了他的顽强统治。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学的核心概念，特指“人的存在”。此在的本质在于它的“存在”本身是一个问题，它总是关切着自己的存在方式，并在世界中展开其生活。
  • 常人：并非指具体的某个人或群体，而是指一种匿名的、平均化的、支配日常生活的公众意见或社会规范。它规定了“人们通常怎么做”、“大家如何看问题”，从而抹杀了个体独特的生存可能性。
  • 卸除存在之责：指此在将自己对自身存在应负的责任，转让和推卸给“常人”。这意味着此在不再需要亲自做出选择、承担后果，只需按照“大家”都遵循的方式去生活即可。
  • 轻取与轻举：描绘了此在的一种生存倾向，即倾向于选择轻松、省力、不费力思索的生活方式，回避需要自己独立做出重大抉择和承担责任的沉重状态。

2. 逐句转译

  • “常人就这样卸除每一此在在其日常生活中的责任。” 这句话的意思是：我们每个人在日常生活中，总是有一种把自己的人生责任推卸掉的倾向。而“常人”——也就是那种“大家都这样”的社会氛围和规范——就是帮助我们完成这种“甩锅”行为的机制。

  • “不仅此也，只要在此在中有轻取与轻举的倾向，常人就用这种卸除存在之责的办法去迎合此在。” 不仅如此，我们人天生就有一种想“图省事”、想“随大流”的惰性。而“常人”正好利用了我们的这种惰性，它用那种“帮你承担责任”的方式，来讨好你、迎合你，让你觉得这样生活很舒服、很自在。

  • “又因为常人经常用卸除存在之责的办法迎合每一此在，这样就保持并巩固了他的顽强统治。” 而且，正因为“常人”总是通过这种“帮你卸下人生重担”的方式来迎合我们每一个人，久而久之，它就维持并不断加强了自己对我们的强大控制力。我们越依赖它，就越离不开它，它的统治地位就越稳固。

3. 论证逻辑梳理

  • 前提： 1. 此在（人）在日常生活中有一种逃避自身存在责任的倾向（即“卸除存在之责”）。 2. 此在自身存在“轻取与轻举”的惰性，即倾向于选择轻松、不费力的人生道路。

  • 论证推进： 1. “常人”是此在卸责行为的执行者和促成者。 2. “常人”主动迎合此在的惰性，通过提供一套现成的、无需独立思考的生活模板，使得卸责行为变得极具吸引力。 3. 这种迎合不是偶然的，而是持续不断发生的。

  • 结论： 通过这种持续不断的迎合，“常人”不仅维持了其对此在的影响力，更巩固了其“顽强统治”。此在越是沉溺于这种轻松，就越深地陷入“常人”的掌控之中，丧失本真的自我。

4. 整体概括

这段话深刻地揭示了现代人一种普遍的生存状态：我们为了逃避自由选择所带来的沉重感和责任，心甘情愿地将决定自己如何生活的权力，交给了那个无形的“常人”——也就是社会惯例、公众意见和平均化的生活方式。“常人”巧妙地迎合了我们贪图省事、害怕承担的心理，为我们提供了一条看似轻松的道路。然而，这条道路的代价是高昂的，我们越是依赖它，就越是被它牢牢控制，最终失去了真正属于自己的、本真的人生。这是一种舒适却充满异化色彩的统治。

5. 争议与说明

本段解读相对一致。核心争议通常不在于这段文字本身，而在于对“常人”概念的整体评价。有学者强调“常人”是此在沉沦和异化的根源，是完全消极的；也有学者认为，“常人”所维系的公共世界是此在生存不可避免的背景，具有一定的建构性作用，不能完全否定。但就本段而言，海德格尔显然是在批判“常人”通过卸责来统治此在的消极面。
