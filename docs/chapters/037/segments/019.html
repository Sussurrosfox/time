📖 《存在与时间》研读 逐段解析
首页 / 第 037 章 / 片段 019
📜 原文片段 (037/019)
海德格尔 原文
日常此在从常人的最切近的存在方式中汲取对它的存在的先于存在论的解释。存在论阐释首先追随这种先于存在论的解释的倾向，因而它从世界方面来领会此在并把此在作为摆在世界之内的存在者来发现。不仅此也，这些作为存在者的“主体”原是靠存在的意义领会的，而此在的“最近的”存在论连这种存在意义也硬从“世界”来解说。但是因为在这样消散于世之际连世界现象本身也被跳过去了，世内现成的东西即诸物件，就取而代之。若共同此在的存在者的存在被理解为现成状态了。所以，展示出最切近的日常在世的积极现象，就可能明察对这种存在建构的存在论解释之所以错失的根源了。这种在其日常存在方式中的存在建构其本身就是那个在最初错失自身和遮蔽自身的东西。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔用来指称“人”这种存在者的概念，其本质在于“去存在”，即以理解存在的方式生存着。
  • 常人：此在在日常生活中沉沦于其中的、非本己的、平均化的“他人”状态，它规定了日常生活的所有方式。
  • 先于存在论的解释：此在在投入理论反思之前，就已经对其自身的存在有一种前理论、非主题化的、直接的领会和理解。
  • 存在论阐释：对此在的存在方式进行系统性的、理论化的哲学探究。
  • 世界：在海德格尔哲学中，这不是指物理世界的集合，而是此在生存于其中、与之打交道的意义关联整体，是此在存在的构成性环节。
  • 消散于世：此在在日常生活中，完全沉溺并迷失于它所操劳的世界（即各种事务和“他人”的闲言）之中，忘记了自身的本真存在。
  • 现成状态 / 现成东西：一种存在方式，指像桌子、石头那样仅仅“摆在那里”的、属性固定的、非生存性的存在者。海德格尔认为，传统哲学错误地将“此在”也理解为这种存在者。
  • 共同此在：此在的本质结构之一，意指此在总是与其他此在共同存在于世界之中，其存在本质上是“与他人共在”。

2. 逐句转译

  • “日常此在从常人的最切近的存在方式中汲取对它的存在的先于存在论的解释。” 在日常生活中，我们（此在）对自己“如何存在”的那种最直接、最朴素的理解，并不是自己独立思考得来的，而是从那个随大流的、匿名的“常人”状态里学来的。

  • “存在论阐释首先追随这种先于存在论的解释的倾向，因而它从世界方面来领会此在并把此在作为摆在世界之内的存在者来发现。” 于是，早期的哲学研究（存在论阐释）也顺着这种日常理解的思路走了。它试图通过“世界”（被理解为外在于人的对象总和）来理解人，最终把人看作是“世界”里面的一个物件，一个现成的存在者。

  • “不仅此也，这些作为存在者的‘主体’原是靠存在的意义领会的，而此在的‘最近的’存在论连这种存在意义也硬从‘世界’来解说。” 不仅如此，这些被当成物件的主体（人），其本身的存在意义本应通过其自身的生存活动来理解。但最初的存在论（指传统哲学）却非常固执地、生硬地非要借用“世界”（物所存在的模式）来解释人的存在意义。

  • “但是因为在这样消散于世之际连世界现象本身也被跳过去了，世内现成的东西即诸物件，就取而代之。” 然而，问题在于，当此在这样完全沉溺于世界的事务中时（消散于世），它甚至连“世界”作为意义关联整体这个真正的现象都忽略了。于是，世界内部那些现成的、像工具一样的东西（诸物件），就顶替了“世界”的位置，成为了我们看待一切的模板。

  • “若共同此在的存在者的存在被理解为现成状态了。” 这样一来，连“与他人共在”（共同此在）这种本真的生存结构，也被错误地理解成了一种僵化的、现成的状态（就像一堆互不相关的物件摆在一起）。

  • “所以，展示出最切近的日常在世的积极现象，就可能明察对这种存在建构的存在论解释之所以错失的根源了。” 因此，如果我们能清晰地揭示出此在最切身的、日常生活中与世界打交道（日常在世）的真实面貌（积极现象），我们就有可能看清，为什么之前的哲学解释会从根本上错失“此在”的真正存在结构。

  • “这种在其日常存在方式中的存在建构其本身就是那个在最初错失自身和遮蔽自身的东西。” 最关键的是，此在在日常生活中的这种存在结构本身，就具有一种自我掩盖的特性。它从一开始，就倾向于让自己迷失在常人之中，从而把自己的本真面目隐藏起来。

3. 论证逻辑梳理

  1. 前提：此在日常的存在方式是由“常人”塑造的，其自我理解（先于存在论的解释）源于此。
  2. 第一步推进：传统的存在论（哲学）不加批判地沿用了这种日常理解，将“此在”视为由“世界”所规定的一个现成对象。
  3. 第二步推进与揭示错误：指出这种传统解释犯了双重错误：
    • 它用“物”的存在方式（现成状态）来理解“人”的存在。
    • 它在这样做的过程中，甚至连“世界”本身作为意义关联的整体也错过了，只看到了世界内的“物件”。
  4. 后果：这种错误导致了对“共同此在”（与他人共在）等基本生存结构的根本性误解。
  5. 提出解决方案：要纠正这个错误，必须回到源头，正面描述此在“日常在世”的真实现象。
  6. 最终结论/深刻洞察：错误的根源在于此在日常存在方式本身固有的自我遮蔽倾向。日常状态本身就“是”那个最初导致哲学迷失的东西。

4. 整体概括

这段话的核心是在批判传统哲学对“人”的理解为何会走偏。海德格尔认为，我们日常的生活方式是被“常人”所支配的，我们对自己是谁的理解很模糊。传统哲学没有去深究这种模糊性，反而直接采纳了这种日常观点，结果就把“人”当成世界里的一个现成物件来研究，就像研究一张桌子或一块石头一样。这种研究路径之所以失败，根本原因在于我们的日常生活本身就有一种自我掩盖的特性，它让我们沉溺于外部事务，从而忘记了追问自己本真的存在方式。因此，哲学的任务就是要穿透这种日常的迷雾，去揭示此在在世生存的原始真相。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“先于存在论的解释”与“存在论阐释”之间关系的理解。一种更极端的解读可能认为，海德格尔在此暗示任何从“先于存在论”出发的哲学都注定会迷失；另一种更温和的解读则认为，他只是批判了传统哲学“不加反思地”追随日常解释的倾向，而他自己所做的正是要对这种“先于存在论的解释”进行现象学的澄清，以建立正确的存在论。但总体而言，对于本段旨在揭示传统存在论错误及其日常根源的核心论点，学界共识度很高。
