📖 《存在与时间》研读 逐段解析
首页 / 第 094 章 / 片段 015
📜 原文片段 (094/015)
海德格尔 原文
一般历史学“对于生命来说”既可能“有利”也可能“有害”；这种可能性的根据在于生命在其存在的根子上就具有历史性，从而它作为实际生存的生命向来已经决定了其为本真的历史性或非本真的历史性。关于“历史学对生命的用处与弊害”，尼采在其《不合时宜的考察》的第二部〔1874年〕里已经认识到了本质的东西，他在那里说得明确一义，入木三分。尼采区分了三种历史学：纪念碑式的、尚古的与批判的历史学，但他不曾明确展示这三种方式的必然性及其统一的根据。历史学的三重性在此在的历史性中已经草描出来了。此在的历史性同时也可使我们领会到本真的历史学在何种程度上必须是这三种可能性的实际而具体的统一。尼采的划分不是偶然的。从他的《考察》的开端处就可推知他领会的比他昭示出来的更多。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 历史学：在海德格尔哲学中，广义上指人类对过去的研究与记述活动，但此处特指“一般历史学”，即日常生活中人们理解、研究和讲述历史的方式，它可能与生命存在建立不同的关系。
  • 生命：在此语境下，并非指生物学意义上的生命，而是海德格尔所说的“此在”（Dasein），即人的存在方式，特点是能够追问自身存在、具有时间性和历史性。
  • 历史性：指此在（人的存在）本质上是一种历史性的存在，意味着人的存在是被抛入时间之中的，其当前的理解与行动总是受到过去的塑造，并朝向未来展开。它是人存在的根本结构。
  • 本真的历史性：此在主动承担自身的历史命运，清晰地认识到自己的有限性和被抛境况，并在决断中继承过去、面向未来。
  • 非本真的历史性：此在被日常公众意见和历史叙事所裹挟，被动地接受历史，逃避自身的历史责任与可能性。
  • 尼采的三种历史学：尼采在《不合时宜的考察》中提出的三种对待历史的态度：
  • 纪念碑式的历史学：从过去选取伟大的榜样，用以激励当下的行动。
  • 尚古的历史学：崇古守旧，把过去视为神圣不可侵犯的模板。
  • 批判的历史学：批判性地审视过去，以摆脱历史包袱，解放当下。

2. 逐句转译

  • 原文第一句：一般历史学“对于生命来说”既可能“有利”也可能“有害”；这种可能性的根据在于生命在其存在的根子上就具有历史性，从而它作为实际生存的生命向来已经决定了其为本真的历史性或非本真的历史性。

  • 转译：我们通常所说的历史学，对人的生命既可以有好处，也可以有坏处。之所以会有这两种截然不同的影响，根源在于人这种存在者的本性就是历史性的——人从一出生就被抛入历史之中，他的生命活动天然就带有历史的烙印。因此，人在实际生活中，要么是采取一种本真的态度面对历史（主动承担并理解），要么是采取非本真的态度（随波逐流、逃避责任）。正是这种根本的历史性结构，决定了历史学对人会产生积极或消极的影响。

  • 原文第二句：关于“历史学对生命的用处与弊害”，尼采在其《不合时宜的考察》的第二部〔1874年〕里已经认识到了本质的东西，他在那里说得明确一义，入木三分。

  • 转译：关于“历史学对生命究竟有利还是有害”这个核心问题，尼采在他1874年出版的《不合时宜的考察》第二部中，已经抓住了问题的本质。他的论述非常精准、深刻，一针见血。

  • 原文第三、四句：尼采区分了三种历史学：纪念碑式的、尚古的与批判的历史学，但他不曾明确展示这三种方式的必然性及其统一的根据。历史学的三重性在此在的历史性中已经草描出来了。

  • 转译：尼采把历史学分成了三类：纪念碑式的、崇古的和批判的。但是，他并没有进一步说明，为什么历史学必然是这三种形式？它们背后有没有一个共同的、统一的根源？海德格尔认为，这个根源其实就隐藏在“此在的历史性”之中。换句话说，正是因为人这种存在者本身具有历史性的结构，才使得历史学必然呈现出这三种可能的面貌。

  • 原文第五句：此在的历史性同时也可使我们领会到本真的历史学在何种程度上必须是这三种可能性的实际而具体的统一。

  • 转译：反过来，如果我们深刻理解了“此在的历史性”，我们就能明白：一种真正本真的、负责任的（本真的）历史学，不能只偏向这三种模式中的任何一种，而必须在实际的、具体的研究中，将这三种可能性有机地统一起来。

  • 原文第六、七句：尼采的划分不是偶然的。从他的《考察》的开端处就可推知他领会的比他昭示出来的更多。

  • 转译：因此，尼采提出这三种分类绝非偶然，而是触及了问题的深层结构。从他著作的开头部分就能推断出，尼采本人对这个问题有非常深刻的直觉和洞见，他实际理解的东西，比他明确写出来的要更多、更深。

3. 论证逻辑梳理

  1. 前提与问题提出：海德格尔开篇设定了一个核心观察——历史学对生命的影响是双重的（有利或有害），并将此现象的原因追溯到生命（此在）的根本属性：历史性。此在的历史性本身就包含了本真与非本真两种基本模式。
  2. 引入尼采的观点作为佐证与铺垫：他指出，尼采已经敏锐地洞察到了历史学与生命之间的这种双重关系，并通过区分三种历史学类型深化了这一问题的讨论。
  3. 指出尼采理论的不足并提出海德格尔自己的解决方案：海德格尔认为，尼采的分类虽然深刻，但只是现象描述，未能揭示其“必然性”和“统一根据”。海德格尔随即提出，这个被尼采忽略的“根据”正是“此在的历史性”本身。
  4. 从根源推导出本真历史学的形态：基于“此在的历史性”这一根基，海德格尔进一步论证，真正的（本真的）历史学实践，必然是尼采所划分的那三种历史学模式的辩证统一，而不是孤立地取用其一。
  5. 对尼采工作的评价：最后，海德格尔为他的解读提供支持，认为尼采的划分不是随意的，而是源于他对问题深层的、或许尚未完全理论化的深刻理解。

4. 整体概括

这段文字的核心论点是：历史学对人产生或好或坏的影响，其根本原因在于人本身就是一种历史性的存在。海德格尔借助尼采对历史学的三种分类（纪念碑式、尚古式、批判式），指出尼采虽然看到了现象，但没有深挖其背后的必然原因。海德格尔认为，这个原因就是“此在的历史性”——人天生就在时间中展开其生命，并以本真或非本真的方式与历史打交道。正因为人的存在结构如此，历史学才必然表现为那三种形态；同时，一种真正有生命力的、本真的历史学研究，必须是在具体实践中将这三种视角融合统一，而不是偏执一端。

5. 争议与说明

本段解读相对一致。海德格尔在此处对尼采的解读是建设性的，他并非批评尼采，而是将尼采的洞察纳入自己的存在论框架，并加以深化。可能的细微争议点在于：海德格尔声称从尼采文本开端即可推知其领会了“此在的历史性”这一深层根据，这是一种“深度诠释”，有学者可能认为这是海德格尔将自己的哲学框架投射到了尼采身上，尼采本人未必是在“此在的历史性”这一意义上进行思考的。但总体上，海德格尔对尼采三种历史学与存在结构之关系的阐发，被广泛认为是极具创造性和说服力的。
