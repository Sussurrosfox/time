📖 《存在与时间》研读 逐段解析

📜 原文片段 (094/017)
海德格尔 原文
具体表现历史学在生存论历史性上的源头这一工作是借分析组建着这门科学的专题化进程来进行的。历史学专题化的要点在于形成诠释学处境。随着历史地生存着的此在的决定，诠释学处境向着重演着开展曾在此的此在这一活动敞开自身。历史学真理的可能性与结构要从历史生存的本真展开状态〔“真理”〕得到演示。然而，因为无论诸门历史科学的基本概念所涉及的是历史学的对象还是其处理方式，反正这些基本概念都是生存概念，所以诸人文科学的理论都把对此在历史性的专题生存论阐释作为前提。这一阐释始终是狄尔泰的研究工作所欲接近的目标，而瓦尔吞堡〔Wartenburg〕的约克伯爵的诸观念则更深入地照明了这一目标。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 历史学：此指广义的历史科学，其研究对象是人类的过去。在海德格尔看来，历史学不是中性的、客观的学科，其根基在于人的“历史性”。
  • 生存论历史性：指此在（人）的存在方式本身就是历史的。人不是在一个空洞的时间中活动，而是始终已经承载着、并筹划着其历史，他的存在就是时间性的、历史的。
  • 专题化：指将某物作为一个特定的对象或课题来研究、聚焦的过程。在历史学中，就是将过去的事件、人物等作为研究的主题。
  • 诠释学处境：指理解活动得以发生和进行的那个具体的、前理论的背景和条件总和。它包含了理解者的前有、前见和前把握，决定了理解的可能方向和视野。
  • 此在：海德格尔哲学的核心概念，特指“人”这种存在者。此在的存在方式是“生存”，即它关心并追问自己的存在。
  • 曾在此的此在：指过去的、曾经生存过的人及其生命可能性。
  • 重演：不是一个简单的复制或模仿，而是此在通过对过去的理解和解释，将过去的生命可能性“重新取得”并“带入”当下，使之对当下的生存抉择产生影响。
  • 本真展开状态：指此在摆脱常人的公共意见，直面自身最本己的可能性（尤其是死亡），并承担起自身命运的生存状态。这是此在获得其“真理”的方式。
  • 生存概念：指那些源出于此在生存本身，用于理解和解释此在存在方式的概念。它们不是关于外部对象的形式逻辑概念。

2. 逐句转译

  1. 原文：具体表现历史学在生存论历史性上的源头这一工作是借分析组建着这门科学的专题化进程来进行的。 转译：要弄清楚历史学这门学问，其真正的根基其实是来自于人本身那种历史性的存在方式。为了说明这一点，我们需要去分析历史学家是如何把“过去”确定为自己研究对象的这个过程。

  2. 原文：历史学专题化的要点在于形成诠释学处境。 转译：历史学家要研究历史，关键在于他必须先形成一个特定的“理解背景”或“解读框架”。这就像你要读懂一封旧信，需要先了解写信的人和那个时代的情况一样。

  3. 原文：随着历史地生存着的此在的决定，诠释学处境向着重演着开展曾在此的此在这一活动敞开自身。 转译：这个“理解背景”并不是一成不变的。它随着我们这些活在历史中的人所做的每一个重要选择而改变。正是通过这些选择，我们才能向一种可能性敞开：去深入地理解和“重新活过”那些过去的人们曾经活出的生命经验。

  4. 原文：历史学真理的可能性与结构要从历史生存的本真展开状态〔“真理”〕得到演示。 转译：所以，历史学所说的“真理”是否可能，以及它是什么样的结构，都不能从外部标准来衡量，而必须回到人那种最真实、最投入的生存状态中去寻找和证明。这里的“真理”，指的是存在的敞开与显现。

  5. 原文：然而，因为无论诸门历史科学的基本概念所涉及的是历史学的对象还是其处理方式，反正这些基本概念都是生存概念，所以诸人文科学的理论都把对此在历史性的专题生存论阐释作为前提。 转译：道理很简单，无论历史学研究的对象（比如“革命”、“文化”），还是它的研究方法（比如“理解”、“解释”），它们最基本的概念，本质上都是关于“人如何生存”的概念。因此，所有人文科学的理论，其背后都有一个默认的前提，那就是我们必须首先从哲学上弄清楚“人的历史性存在”究竟是怎么回事。

  6. 原文：这一阐释始终是狄尔泰的研究工作所欲接近的目标，而瓦尔吞堡〔Wartenburg〕的约克伯爵的诸观念则更深入地照明了这一目标。 转译：哲学家狄尔泰一生的研究，始终在努力接近这个目标（即阐明人的历史性）。而与他通信的约克伯爵所提出的思想，则让这个目标变得更为清晰和深刻了。

3. 论证逻辑梳理

  • 前提/起点：海德格尔要探究历史学的哲学基础。
  • 论证核心步骤： 1. 切入点：他选择从分析历史学的“专题化”（研究对象的选择与确立过程）入手。 2. 关键环节：他指出，专题化的核心是形成一个“诠释学处境”，即特定的理解背景。 3. 动态发展：这个理解背景不是静态的，而是随着此在（历史研究者）自身的生存决定而变动，并最终导向对过去的“重演”。 4. 结论一（关于真理）：由此推导出，历史学的真理根植于此在“本真”的历史性生存。 5. 结论二（普遍性）：进一步推论，由于历史学乃至所有人文学科的基本概念都是“生存概念”，所以它们全都依赖于对“此在历史性”的哲学阐明。
  • 最终结论/支持性论据：狄尔泰和约克伯爵的工作，正是这种哲学探索的先驱和印证。

4. 整体概括

这段话的核心思想是：历史学并非一门自给自足的客观科学，它的深层根基在于人（此在）自身就是历史性的存在。历史学家研究历史的过程（专题化），本质上是基于他自身的生存背景（诠释学处境）和理解框架，并在他做出生存抉择时，通过“重演”与过去的生命产生共鸣。因此，历史学所追求的真理，其可能性和形态都必须从人最本真的历史性生存中去寻找和论证。正因如此，所有人文科学理论，其底层逻辑都预设了对“人的历史性存在”这一哲学问题的先行探索。狄尔泰和约克伯爵的思想，正是这一探索道路上的重要里程碑。

5. 争议与说明

本段解读相对一致，核心争议点通常不在于这段文字本身，而在于对海德格尔整体哲学，尤其是“重演”和“本真性”等概念的理解。一种常见的争议是：“重演”是否意味着某种保守的、对过去的盲目回归？主流的、更自洽的解读认为，“重演”恰恰是批判性的，它不是重复过去的事实，而是自由地面对过去的可能性，从中汲取资源以应对当下的决断。另一种争议涉及海德格尔对“科学”的界定，他是在颠覆近代以来客观、价值中立的科学观，将科学（此处是历史学）重新锚定在人的生存实践之中，这在科学哲学领域有其独特的立场和引发的讨论。
