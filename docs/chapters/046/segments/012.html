📖 《存在与时间》研读 逐段解析
首页 / 第 046 章 / 片段 012
📜 原文片段 (046/012)
海德格尔 原文
以上述方式起封闭作用的闲言乃是除了根的此在领会的存在样式。但它并不是一种现成状态，摆在一个现成事物那里。它恰恰是以不断被除根的方式而在生存论上是除了根的。这在存在论上等于说：作为在世的存在，滞留于闲言中的此在被切除下来—从对世界、对共同此在、对“在之中”本身的首要而源始真实的存在联系处切除下来。它滞留在飘浮中，但在这种方式中它即始终依乎“世界”、共乎他人、向乎自身而存在着。这种存在者的展开状态是由现身领会的话语组建的，也就是说，它在这种存在论建构中是它的“此”，即在“世界之中”；只有这样一种存在者才具有这种除根的存在可能性。除根不构成此在的不存在，它倒构成了此在的最日常最顽固的“实在”。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 闲言（Gerede）：在海德格尔哲学中，指一种非本真、流于表面的日常交谈方式。它不触及事物的真实存在，而是重复和传播未经审视的现成观点，使人脱离对自身存在的深层领会。
  • 除根（entwurzelt）：字面意为“连根拔除”。在此指此在（人的存在）脱离了与世界的源始、真切的存在关联，陷入一种无根基的状态。它不是一次性的状态，而是持续发生的动态过程。
  • 此在（Dasein）：海德格尔的核心概念，特指“人的存在”。它是一种能够追问自身存在、在世界之中展开其生命的存在者。
  • 在世（In-der-Welt-sein）：此在的基本建构，意味着人从来不是孤立的主体，而是始终已经嵌入并参与到世界之中。
  • 生存论（existenzial）：对此在存在方式的先验结构分析，区别于具体的生活经验（生存状态）。
  • 现身领会（Befindlichkeit und Verstehen）：此在展开自身的两种基本方式。“现身”指此在总是已经处在某种情绪中并觉察自身处境；“领会”指此在对自身存在可能性的一种前反思的把握。
  • 展开状态（Erschlossenheit）：此在通过现身、领会和话语而向世界和自身敞开的基本方式。

2. 逐句转译

  • “以上述方式起封闭作用的闲言乃是除了根的此在领会的存在样式。” 这种能把人封闭起来、让人无法深入理解事物的“闲言”，其实是人的一种失去了根基的理解方式。

  • “但它并不是一种现成状态，摆在一个现成事物那里。” 但这种无根的状态，并不是像一个物体那样，固定不变地摆在那里。

  • “它恰恰是以不断被除根的方式而在生存论上是除了根的。” 恰恰相反，它是在生存结构上，通过不断地、持续地被“拔除根基”这个过程，才维持着这种无根的状态。它不是静止的，而是一个动态的过程。

  • “这在存在论上等于说：作为在世的存在，滞留于闲言中的此在被切除下来—从对世界、对共同此在、对‘在之中’本身的首要而源始真实的存在联系处切除下来。” 从存在论的角度看，这意味着：作为活在世界中的人，当他沉溺于闲言时，他就仿佛被“切断了”——切断了与世界、与他人共在、以及与自身“存在于世”这种最根本、最真实联系的联系。

  • “它滞留在飘浮中，但在这种方式中它即始终依乎‘世界’、共乎他人、向乎自身而存在着。” 他于是停留在一种漂浮无根的状态里。但即使在这种状态下，他依然是在“依附着”世界、“与他人共在”、并且“面向着”自身而存在。他没有离开这些基本结构，只是以一种扭曲、异化的方式与之关联。

  • “这种存在者的展开状态是由现身领会的话语组建的，也就是说，它在这种存在论建构中是它的‘此’，即在‘世界之中’；” 人这种存在者的敞开状态，是由他的情绪化处境、他的理解以及他的言谈所共同构成的。正因为有这种先天的存在建构，他才拥有一个“此”，一个他得以展开和存在的具体空间，也就是“在世界之中”。

  • “只有这样一种存在者才具有这种除根的存在可能性。” 正因为人是一种拥有“此”、能在世界之中展开自身的存在者，他才有可能陷入这种“被除根”的生存方式。这恰恰是他的存在方式所特有的一种可能性。

  • “除根不构成此在的不存在，它倒构成了此在的最日常最顽固的‘实在’。” 所以，这种“除根”的状态并不是说人不存在了，恰恰相反，它构成了人最日常、最顽固的“现实”。它是此在一种非常真实、甚至是最常见的存在样态。

3. 论证逻辑梳理

  1. 前提：闲言是一种起封闭作用的、非本真的理解模式。
  2. 核心论断：这种闲言所对应的，是此在的一种“除了根”的存在样式。
  3. 性质界定：海德格尔立即澄清，这种“除根”不是一种静态的、像物体属性一样的“现成状态”，而是一个动态的、持续“被除根”的过程。
  4. 存在论解读：他将这个过程解读为：沉溺于闲言的此在，从其与世界、他人、自身存在的源始真切联系中被“切除”了。
  5. 看似矛盾的描述：尽管被“切除”，此在并未离开其基本生存结构（在世、共在、向自身存在），只是以一种“飘浮”的、异化的方式维系着这些关系。
  6. 可能性条件：海德格尔进一步指出，这种“除根”的可能性，恰恰根源于此在的存在论建构——正是因为他本质上是“展开的”、拥有一个“此”（在世），他才可能以这种扭曲的方式存在。
  7. 最终结论：因此，“除根”不是此在的虚无或消失，反而是它最日常、最顽固的“实在”，是一种虽非本真但却极其普遍和真实的存在方式。

4. 整体概括

这段话的核心是在深入剖析我们日常生活中一种非常普遍的状态：沉溺于流言蜚语、陈词滥调（闲言）所带来的生存论后果。海德格尔指出，这种状态并非偶然，而是人的存在（此在）一种深刻的“无根”形态。它不是静止的，而是通过不断地切断我们与生活世界、与他人、乃至与自身真实感受的深刻联系，来维持着这种漂浮。有趣且关键的是，他指出，人之所以能陷入这种“无根”状态，恰恰是因为人天生就是“有根”的——他天生就拥有一个可以向世界和自身敞开的结构（“此”）。因此，这种看似消极的“除根”状态，并非人的不存在，反而构成了我们最熟悉、最难以摆脱的日常现实。他用“最顽固的‘实在’”来形容它，意在强调其真实性与支配力。

5. 争议与说明

本段解读相对一致。可能的细微讨论点在于对“最日常最顽固的‘实在’”中“实在”一词的理解。有学者会强调，这里的“实在”绝非传统哲学中与意识对立的、客观的“现实”（Realität），而应理解为海德格尔存在论意义上的、此在的一种真切不虚的存在样态。它描述的是此在沉沦于常人的非本真状态时，那种虽非本真、却无比真切和普遍的生活实感。
