📖 《存在与时间》研读 逐段解析

📜 原文片段 (046/003)
海德格尔 原文
闲言这个词在这里不应用于位卑一等的含义之下。作为术语，它意味着一种正面的现象，这种现象组建着日常此在进行领会和解释的存在样式。话语通常要说出来，而且总已经是〔有人〕说出过的。话语即语言。而在说出过的东西里向已有领会与解释。语言作为说出过的东西包含有一种对此在之领会的解释方式。解释方式像语言一样殊非仅止现成的东西；它的存在是此在式的存在。此在首先并且在某种限度内不断交托给这种解释方式；它控制着、分配着平均领会的可能性以及和平均领会连在一起的现身情态的可能性。说出过的东西分成环节，成为含义之间的联络；它就在这含义联络的整体中保存着对展开的世界的领会，并从而同等源始地保存着对他人的共同此在的领会以及对向来是本己的“在之中”的领会。所以，在说出过的东西背后已有一种领会；这种领会涉及到渐次达到而承袭下来的存在者的揭示状态，也涉及到对存在的当下领会以及为了重新解释或从概念上加以分环勾连所需用的可能性和视野。此在的这种解释方式确是实情，但仅仅指出这一点是不够的，现在我们还必须寻问说出过的话语以及正说出来的话语的生存论存在样式。如果我们不可把这些话语领会为现成的东西，那么，何者是这些话语的存在呢？关于此在的日常存在样式，话语的存在从原则上所说的是什么呢？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 闲言（Gerede）：在海德格尔哲学中，“闲言”不是日常贬义的“闲聊”，而是指一种日常的、平均化的理解与解释方式。此在（人的存在）通过这种被普遍接受、未经深刻反思的言谈方式来理解世界和自身。它构建了日常生活的理解背景，但往往掩盖了存在的本真可能性。

  • 此在（Dasein）：海德格尔哲学的核心概念，指“人的存在”。此在不是现成的物体，而是以“在世之在”的方式存在，始终处在理解、解释和与世界的互动中。它的存在方式是“生存”，具有可能性和时间性。

  • 领会（Verstehen）：此在基本的生存能力，指对自身存在可能性的前反思性理解。它不是认知性的“知道”，而是此在在世的基本方式。

  • 解释（Auslegung）：领会的具体化和展开。此在将领会到的可能性整理为明确的意义结构。

  • 现身情态（Befindlichkeit）：此在总是已经处在某种情绪或心境中，这种情绪揭示了此在“身处何处”的基本状态。

  • 在之中（In-der-Welt-sein）：此在的基本建构，指此在始终已经嵌入并参与到世界之中，与世界不可分割。

  • 生存论（existenzial）：关于此在存在结构的哲学分析，区别于具体的生活经验（生存上的）。

  • 现成的东西（Vorhandenes）：指像物体那样静态、被动存在的东西，与此在的动态、可能性开放的存在方式相对。

2. 逐句转译

  1. 原文：闲言这个词在这里不应用于位卑一等的含义之下。作为术语，它意味着一种正面的现象，这种现象组建着日常此在进行领会和解释的存在样式。 转译：首先说明，“闲言”在这里不是贬义词。作为一个哲学概念，它描述的是一种实实在在的、构成性的现象，它塑造了我们日常生活中那种惯常的、不经深入思考就去理解和解释事物的基本模式。

  2. 原文：话语通常要说出来，而且总已经是〔有人〕说出过的。话语即语言。而在说出过的东西里向已有领会与解释。 转译：我们说的话通常是要说出口的，而且这些话本质上都是已经被别人说过、在社会中流传的。这些说出来的话，就是语言。而在这个“已经被说过”的语言里，已经预先包含了一套大家普遍共享的理解和解释世界的框架。

  3. 原文：语言作为说出过的东西包含有一种对此在之领会的解释方式。解释方式像语言一样殊非仅止现成的东西；它的存在是此在式的存在。 转译：所以，语言，作为被反复言说的东西，本身就包含着一种解释“人是什么”的方式。这种解释方式，和语言本身一样，都不是像桌子椅子那样摆在眼前的死物件；它的存在方式是和“人”（此在）的存在方式绑定的，是活生生的、动态的。

  4. 原文：此在首先并且在某种限度内不断交托给这种解释方式；它控制着、分配着平均领会的可能性以及和平均领会连在一起的现身情态的可能性。 转译：我们人，首先并且在很大程度上，是不自觉地把自己交给了这种公共的解释方式。它像一个背景程序，规定和分配着我们能有哪些“一般人都这么认为”的理解，以及和这种平均理解相伴而生的情绪和感受。

  5. 原文：说出过的东西分成环节，成为含义之间的联络；它就在这含义联络的整体中保存着对展开的世界的领会，并从而同等源始地保存着对他人的共同此在的领会以及对向来是本己的“在之中”的领会。 转译：被说出来的话，其意义是相互关联、构成一个网络的。就在这个意义网络中，保存着我们对这个已经展开的世界的共同理解，也同样原初地保存着我们对“他人也存在于世”的理解，以及对我们“自己身处于世界之中”这件事的理解。

  6. 原文：所以，在说出过的东西背后已有一种领会；这种领会涉及到渐次达到而承袭下来的存在者的揭示状态，也涉及到对存在的当下领会以及为了重新解释或从概念上加以分环勾连所需用的可能性和视野。 转译：所以说，在说出来的话语背后，已经预先存在一种更基础的领会。这种领会既关系到历史上流传下来的、对各种事物（存在者）的认知状态，也关系到我们当下对“存在”本身的理解，还为我们提供了未来重新解释事物或进行概念化思考所需要的可能性和视角。

  7. 原文：此在的这种解释方式确是实情，但仅仅指出这一点是不够的，现在我们还必须寻问说出过的话语以及正说出来的话语的生存论存在样式。 转译：指出“人依赖于这种公共解释方式”这个事实是对的，但光指出这一点还不够。我们现在必须进一步追问：这些“已经被说过”和“正在被说出”的话语，它们本身的存在方式是什么？从“此在”的生存论结构来看，它们是怎么“存在”的？

  8. 原文：如果我们不可把这些话语领会为现成的东西，那么，何者是这些话语的存在呢？关于此在的日常存在样式，话语的存在从原则上所说的是什么呢？ 转译：如果我们不能把话语理解为像实物一样摆在眼前的“现成东西”，那么，话语的存在到底是什么？对于理解人（此在）的日常存在方式而言，话语的这种存在方式，从根本上告诉了我们什么？

3. 论证逻辑梳理

  1. 前提确立：首先界定核心概念“闲言”，明确其作为构建日常理解方式的中性、建构性现象。
  2. 现象描述：指出语言（话语）的本质是“已被说出的”，并由此揭示语言内在地承载着公共的领会与解释。
  3. 存在论定性：将这种解释方式与“此在”的存在方式绑定，强调其动态、生存性的特质，而非静态的现成物。
  4. 功能分析：阐述这种公共解释方式如何具体运作——它预先规定了平均化的理解和情绪，并通过含义网络保存着对世界、他人和自我的领会。
  5. 深化追问：在承认上述事实的基础上，提出更深层的问题：仅仅描述现象不够，必须探究话语本身的存在方式（生存论样式）。
  6. 问题聚焦：明确核心问题：如果我们不把话语当作现成物，它的存在是什么？这对其所揭示的此在日常存在意味着什么？

逻辑推进：从概念界定 → 现象描述 → 存在论定性 → 功能分析 → 提出更深层的哲学问题。论证的核心是从对“闲言”现象的描述，转向对“话语存在本身”的生存论根基的追问。

4. 整体概括

这段话的核心在于阐明，“闲言”（公共话语）是我们日常生活中理解和解释世界的基础背景。我们使用的语言从来不是中性的工具，它本身就沉淀了一套被社会普遍接受的理解模式和情感基调，我们一开口，就不自觉地在这套模式里打转了。这套模式像一个巨大的、活的意义网络，它既承载着我们对世界、对他人、对自己的常规理解，也为我们未来的一切思考和言说提供了基础和视野。海德格尔承认这是无法回避的事实，但他真正的意图不止于此。他通过这段论述，将问题引向了一个更根本的层面：既然我们无法脱离话语，那么话语本身是以什么方式“存在”的？如果我们不能把它简单看成字典里的死文字，那么它的活生生的存在，反过来又揭示了“人”这种存在者（此在）的日常状态在根本上是什么样的？这是在为后续深入分析“沉沦”等此在的基本生存状态做铺垫。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“闲言”的消极性程度判断。虽然海德格尔在此强调其中性、建构性的“正面现象”一面，但结合全书语境，他最终旨在揭示这种平均化理解对“本真性”的遮蔽。因此，有解读会更强调“闲言”作为“沉沦”样式的预备和铺垫作用，认为此处的“正面”仅指其现象上的实存性与建构性，而非价值上的积极肯定。但就本段文字而言，主流解读均聚焦于其作为日常理解之构成性基础这一核心论断。
