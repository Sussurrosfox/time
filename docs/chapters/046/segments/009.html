📖 《存在与时间》研读 逐段解析
首页 / 第 046 章 / 片段 009
📜 原文片段 (046/009)
海德格尔 原文
话语本质上属于此在的存在建构，一道造就了此在的展开状态。而话语有可能变成闲言。闲言这种话语不以分成环节的领会来保持在世的敞开状态，而是锁闭了在世，掩盖了世内存在者。这里无须乎意在欺骗。闲言并无这样一种存在样式：有意识地把某种东西假充某种东西提供出来。无根的人云和人云亦云竟至于把开展扭曲为封闭。因为所说的东西首先总被领会为“有所说的东西”亦即有所揭示的东西。所以，既然闲言本来就不费心去回溯到所谈及的东西的根基之上去，那闲言原原本本就是一种封闭。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 话语：在海德格尔哲学中，指此在（人的存在）与世界打交道的原初方式之一，是此在“展开状态”的基本构成部分。话语让事物得以被谈论、被理解，从而让世界对人呈现出来。
  • 闲言：话语的一种沉沦样式，即人云亦云、不加反思的日常交谈。它不再真正揭示事物本身，反而遮蔽了世界的真实面貌。
  • 此在：海德格尔用来指代“人”这种特殊存在的术语，其本质是“在世存在”，总是已经处于与世界、与他人打交道的过程中。
  • 展开状态：此在的基本存在方式，指此在对自身、对世界保持开放和理解的生存姿态。
  • 在世：此在存在的根本结构，指人总是已经“在世界之中”，与世界不可分割地联系在一起。
  • 世内存在者：在世界中与我们相遇的各种事物、他人等。

2. 逐句转译

  • “话语本质上属于此在的存在建构，一道造就了此在的展开状态。”
    话语是人存在方式的一个基本组成部分，它参与塑造了人理解世界、理解自己的开放状态。

  • “而话语有可能变成闲言。”
    但话语这种能力可能会堕落成一种人云亦云的闲聊。

  • “闲言这种话语不以分成环节的领会来保持在世的敞开状态，而是锁闭了在世，掩盖了世内存在者。”
    这种闲聊不是通过一步步深入理解来保持我们对世界的开放视野，反而封闭了我们对世界的感知，遮蔽了事物的本来面目。

  • “这里无须乎意在欺骗。”
    这种封闭不是因为有谁存心要欺骗别人。

  • “闲言并无这样一种存在样式：有意识地把某种东西假充某种东西提供出来。”
    闲聊并不是故意要把假的东西说成真的。

  • “无根的人云和人云亦云竟至于把开展扭曲为封闭。”
    那种没有根基、随声附和式的交谈，恰恰把人原本开放的理解状态扭曲成了封闭状态。

  • “因为所说的东西首先总被领会为‘有所说的东西’亦即有所揭示的东西。”
    因为当我们听到别人说什么时，我们首先会认为这些话是在揭示某种真实情况。

  • “所以，既然闲言本来就不费心去回溯到所谈及的东西的根基之上去，那闲言原原本本就是一种封闭。”
    所以，既然闲聊根本不关心去追溯所谈论事物的真实根基，那么它本质上就是一种对世界的封闭。

3. 论证逻辑梳理

  • 前提：话语是此在展开状态的基本构成要素。
  • 转折点：话语可能堕落为闲言。
  • 核心论证： 1. 闲言不再以真正的理解保持世界开放，反而封闭了世界。 2. 这种封闭不是故意的欺骗，而是一种无意识的状态。 3. 由于人们倾向于相信话语总是有所揭示，闲言就利用这种信任，让人在不自觉中接受了表面的说法。 4. 闲言不追溯事物根基的特性，决定了它本质上就是封闭的。
  • 结论：闲言从本质上就是对世界的封闭，因为它切断了人与事物真实根基的联系。

4. 整体概括

这段话探讨了话语如何从揭示世界真相的能力堕落为遮蔽世界的闲言。海德格尔指出，我们原本通过话语与世界建立真实的联系，但日常生活中的闲聊却让我们满足于人云亦云的表面理解。这种闲聊不是故意的谎言，而是一种更隐蔽的危险——它让我们以为自己理解了，实际上却切断了与事物真实根基的联系。就像人们传播未经核实的消息，不是要骗人，而是因为懒得去追问真相，结果大家都活在表面的理解中，离真实越来越远。闲言因此成为了一种存在论意义上的封闭，让我们失去了对世界的真正开放。

5. 争议与说明

本段解读相对一致。可能的细微争议在于对“无根”的理解：有学者强调这是指脱离了此在的本真生存，另有学者认为更多是指话语脱离了具体的生活实践。但总体上，对闲言作为话语沉沦形态的理解是共识性的。
