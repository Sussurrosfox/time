📖 《存在与时间》研读 逐段解析
首页 / 第 086 章 / 片段 005
📜 原文片段 (086/005)
海德格尔 原文
对操劳活动的时间性的分析首先就从寻视着对上手事物有所事的样式着手。而后分析工作将追问是什么样的生存论时间性上的可能性使寻视操劳得以变式为对世内存在者的“仅仅”观看着的揭示，其意义也就是追问科学研究的某些可能性。对寻视着、以及理论操劳着寓于世内上手事物与现成事物的存在所具有的时间性进行阐释，这一工作同时也将显示，这同一个时间性如何先已是寓于世内存在者的一般存在奠基于其中的在世之所以可能的条件。在世的时间性建制的专题分析寻问下述问题：世界这样的东西以何种方式一般地是可能的？世界在何种意义上存在？世界超越什么？如何超越？无所赖系的世内存在者如何同超越的世界“联系”？从存在论上摆明这些问题并不就是回答了这些问题。倒不如说，这使我们先就有必要澄清超越会要由之提出的那些结构。在世的生存论时间性阐释将分为三层进行考察：a．寻视操劳的时间性；b．寻视操劳变式为对世内现成事物的理论认识的时间性意义；c．世界之超越的时间性问题。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 操劳：指人在日常世界中，与事物打交道、处理事务的基本生存活动。它不是纯粹的理论思考，而是实际的、有目的的忙碌。
  • 寻视：在日常操劳中，我们并非以客观观察者的态度看待事物，而是带着“为了什么目的”的视角，关注事物的用途、位置和关联。这是一种实用的、情境化的“看”。
  • 时间性：海德格尔哲学的核心概念，指人的存在（此在）并非存在于一个个孤立的“现在”点中，而是作为一个“向未来投射，并带着过去，在当下行动”的整体动态结构。它是理解“存在”意义的地平线。
  • 上手事物：指那些在我们日常生活中直接使用、与之打交道的工具或物品（如锤子、笔）。它们对我们是“透明”的，我们关注的是它们的用途，而非它们作为客体的属性。
  • 现成事物：指那些被我们当作纯粹的、与我们的活动无关的客观对象来观察和研究的实体。这是理论科学态度的对象。
  • 在世：指人的存在（此在）最根本的状态，即“在世界之中存在”。人从来都不是一个孤立的主体，而是始终已经与一个充满意义的世界纠缠在一起。
  • 超越：在此语境下，并非指超越到一个神性领域，而是指此在（人）超越（越过）个别世内存在者，而朝向一个作为整体和意义背景的“世界”。世界是此在理解任何存在者的先决条件。

2. 逐句转译

  1. 原文：对操劳活动的时间性的分析首先就从寻视着对上手事物有所事的样式着手。 转译：我们要分析日常忙碌活动（操劳）背后的时间性结构，首先就得从我们如何使用和看待身边工具（上手事物）的那种实用视角（寻视）开始。

  2. 原文：而后分析工作将追问是什么样的生存论时间性上的可能性使寻视操劳得以变式为对世内存在者的“仅仅”观看着的揭示，其意义也就是追问科学研究的某些可能性。 转译：接下来，我们要追问：是基于怎样一种时间性结构上的可能性，才让我们能从实用的、与事物打交道（寻视操劳）的状态，转变为一个纯粹的、冷漠的观察者，仅仅去认识世界内的客观对象（现成事物）？这个问题，本质上就是在追问：像科学研究这样的理论活动，是如何从我们的生存活动中衍生出来的？

  3. 原文：对寻视着、以及理论操劳着寓于世内上手事物与现成事物的存在所具有的时间性进行阐释，这一工作同时也将显示，这同一个时间性如何先已是寓于世内存在者的一般存在奠基于其中的在世之所以可能的条件。 转译：当我们分别解释了实用态度（寻视）和理论态度（理论操劳）背后各自的时间性时，我们会发现，这同一个时间性结构，其实更早就已经是“在世界中存在”（在世）这个基本事实得以可能的前提条件。正是因为有了这个时间性结构，我们才能理解世间万物（世内存在者）的“存在”意义。

  4. 原文：在世的时间性建制的专题分析寻问下述问题：世界这样的东西以何种方式一般地是可能的？世界在何种意义上存在？世界超越什么？如何超越？无所赖系的世内存在者如何同超越的世界“联系”？ 转译：所以，对“在世”的时间性结构进行专门分析，就是要回答以下这些根本问题：像“世界”这样一个意义整体，到底是怎么成为可能的？我们说世界“存在”，究竟是什么意思？世界“超越”了什么？（它超越了个别事物）。它是如何超越的？那些看似独立存在的单个事物（世内存在者），又是如何与这个超越的、作为背景的世界产生“联系”的？

  5. 原文：从存在论上摆明这些问题并不就是回答了这些问题。倒不如说，这使我们先就有必要澄清超越会要由之提出的那些结构。 转译：不过，从哲学上（存在论上）清晰地提出这些问题，并不等于就回答了它们。恰恰相反，我们首先必须搞清楚，到底是哪些结构使得“超越”（世界对事物的超越）这种现象得以出现。

  6. 原文：在世的生存论时间性阐释将分为三层进行考察：a．寻视操劳的时间性；b．寻视操劳变式为对世内现成事物的理论认识的时间性意义；c．世界之超越的时间性问题。 转译：因此，对于“在世界中存在”的时间性解释，我们将分三个步骤来研究：a. 日常实用活动（寻视操劳）的时间性；b. 从实用活动转变为理论认识，这一转变过程的时间性意义；c. “世界”本身能够“超越”个别事物的时间性问题。

3. 论证逻辑梳理

  • 前提：我们理解人的存在（此在），必须从其最基础的、与事物打交道的日常活动（操劳）入手，尤其是这种活动背后的时间性结构。
  • 推进1：从基础出发，分析日常实用视角（寻视）的时间性。这是最源初、最贴近生存的层次。
  • 推进2：基于第一步，进一步追问：这种实用的时间性结构内部，包含了哪些可能性，使得我们能“切换模式”，从一个使用者变成一个纯粹的观察者或理论研究者？这揭示了理论科学态度根植于更源初的生存实践。
  • 推进3：将上述两种态度（寻视与理论）的时间性分析进行整合与深化，指出它们共同指向一个更根本的事实：同一个时间性结构，是“在世界中存在”（在世）本身的可能条件。这引出了关于“世界”本身如何可能的核心哲学问题。
  • 结论/任务设定：因此，对“在世”的完整时间性分析，必须系统地分为三个层层递进的课题来展开，从具体的操劳，到理论的衍生，最终到世界超越性的根基。

4. 整体概括

这段文字是海德格尔为其时间性分析绘制的一幅“研究路线图”。他开宗明义地指出，要理解人（此在）的时间性，必须从我们最日常、最实用的活动（比如用锤子钉钉子）开始分析，因为这是我们与世界打交道的原初方式。接下来，他要探究一个关键转变：我们是如何从这种沉浸式的、实用的状态中“抽身出来”，变成一个冷眼旁观的科学家或理论家，仅仅把事物当作客观对象来研究的？海德格尔认为，这个转变的秘密就藏在时间性的结构里。最终，他雄心勃勃地指出，对这两种态度（实用和理论）的时间性分析，将共同揭示一个更深刻的真相：我们之所以能拥有一个充满意义、作为背景的“世界”（而不仅仅是一堆杂乱的对象），其根本条件也正是这个时间性结构。因此，他的整个研究计划将分三步走，从具体到抽象，从衍生到本源，一步步解开“在世界中存在”的时间性之谜。

5. 争议与说明

本段是《存在与时间》中的纲领性段落，其解读相对一致。它清晰地勾勒了海德格尔从生存论分析过渡到时间性分析，并最终指向世界之超越性问题的核心路径。可能的细微争议点在于：

  • 主流解读：普遍认为此段精确地预告了《存在与时间》第二篇（特别是第三部分）的核心任务，即揭示时间性作为在世之在以及世界超越性的根基。
  • 其他解读方向：有学者可能会讨论，海德格尔这里设定的三步计划，在《存在与时间》未完成的后续部分是否被彻底执行了，或者他后来的思想（所谓“转向”）是否意味着对这个计划的修正。但仅就本段文字本身而言，其意图和结构是清晰且公认的。
