📖 《存在与时间》研读 逐段解析
首页 / 第 086 章 / 片段 045
📜 原文片段 (086/045)
海德格尔 原文
把在世引回到时间性的绽出的统一视野上就使此在的这种基本建构的生存论存在论的可能性成为可理解的了。同时也就弄清楚了：只有充分可靠地依循业已澄清的一般存在观念来讨论可能的世内存在者的存在论，才能着手具体廓清一般世界结构及其种种可能的衍变。而若要能阐释一般存在的观念就首须清理出此在的时间性，而现下对在世的描述就是为这一工作服务的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 在世：指人（此在）最基本的存在方式——总是“在世界之中存在”。这不是物理位置关系，而是指人总是已经与一个充满意义和关系的世界纠缠在一起。
  • 时间性：海德格尔哲学中的核心概念，指此在存在的根本意义。它不是指钟表时间的流逝，而是指此在通过“向死存在”、“筹划”等方式，将过去、现在、未来统合为一个动态的、有意义的整体生存结构。
  • 绽出：时间性的核心特征。指此在超越当下、向外“站出去”的特性。它使此在能够面向未来（先行）、承担过去（曾在）并投入当下（当前化），这三者构成了“绽出的统一”。
  • 生存论存在论：探究此在“如何存在”（生存方式）的哲学基础，而非仅仅研究“是什么”的传统存在论。
  • 世内存在者：在世界之中与我们照面的各种东西（如工具、他人等）。
  • 一般存在观念：关于“存在”本身的最普遍、最根基性的理解。

2. 逐句转译

  • 第一句：如果我们能把“人在世界中存在”（在世）这种现象，追溯到它的根源——也就是“时间性”那种能将过去、现在、未来三者动态统一起来的能力——那么我们就能从根本上理解，人这种特殊的存在者为何会具有如此这般的生存结构。
  • 第二句：同时，这也让我们明白了一个前提：我们只有牢牢地抓住那个已经被我们弄清楚的、关于“存在”本身的根本观念，我们才有可能去真正分析世界上那些具体事物（比如一把锤子、一个他人）的存在方式。
  • 第三句：而要想阐明那个关于“存在”本身的根本观念，首要任务就是把人（此在）的时间性彻底搞清楚。我们现在所做的所有这些对“在世”现象的描述和分析，最终目的就是为了完成这个清理时间性的核心任务。

3. 论证逻辑梳理

  1. 核心论点（第一句）：阐明“在世”结构的可能性，根源在于“时间性”。
  2. 前提与目标（第二句）：指出若要分析“世内存在者”（具体事物），必须以清晰的“一般存在观念”为基础。
  3. 任务与手段（第三句）：阐明当前工作（描述“在世”）的最终目的——通过分析“在世”来揭示“此在的时间性”，进而为阐明“一般存在观念”铺平道路。

逻辑链条：理解“在世” → 依赖“时间性” → 若要理解“世内存在者” → 依赖“一般存在观念” → 若要理解“一般存在观念” → 依赖“此在的时间性” → 当前对“在世”的描述 → 服务于揭示“时间性”。这是一个层层递进、环环相扣的奠基关系。

4. 整体概括

这段话的核心意思是：海德格尔告诉我们，要想真正理解人为何总是“在世界中存在”，就必须找到这个现象的最深根基——那就是人的“时间性”。只有通过时间性，人才能把过去、现在和未来联系起来，从而构建出一个有意义的世界。更进一步说，我们想研究世界上各种东西（比如工具、他人）的存在方式，必须先搞清楚“存在”本身是什么意思。而要想搞清楚“存在”，又必须先搞清楚人的“时间性”。所以，他花这么大篇幅描述“在世”现象，根本目的就是为了给最终揭示“时间性”这个终极答案做准备。整段话就像一份研究路线图，指明了从“在世”现象出发，最终抵达“时间性”这一核心目标的哲学路径。

5. 争议与说明

本段解读相对一致。这段话清晰地阐述了海德格尔在《存在与时间》中的核心方法论和论证结构，即通过此在的生存论分析（在世）来通达时间性，并最终为基础存在论（一般存在观念）奠基。学界对此论证路径的总体框架基本认同。可能的细微讨论点在于对“绽出的统一视野”的具体构成（即“将来”、“曾在”、“当前化”三者如何具体统一）存在不同的侧重和理解，但这并不影响对本段核心论证逻辑的把握。
