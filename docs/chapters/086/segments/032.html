📖 《存在与时间》研读 逐段解析
首页 / 第 086 章 / 片段 032
📜 原文片段 (086/032)
海德格尔 原文
科学发展史上的经典例子，但同时甚至是其存在论发生的经典例子，是数学化的物理学。科学形成的关键既不在于给予对“事实”的观察以更高的估价，也不在于把数学“应用”来规定自然进程，而在于对自然本身的数学筹划。这一筹划先揭示出一种持驻的现成事物〔物质〕，开启出一种视野，从而主要地着眼于这一现成事物的可从量上加以规定的组建环节〔运动、力、处所、时间〕。只有借如此得以筹划的自然之“光”才会发现“事实”，并为从这一筹划加以调整界说的实验设定“事实”。只有研究者领会到原则上并没有“纯粹事实”，“事实科学”的“论证”才是可能的。而且就自然的数学筹划来说，起首要决定作用的又不在于数学的东西本身，而在于：数学筹划对先天的东西有所开展。所以，数学化的自然科学之作为典范，也就不在于它特别精确以及它对“人人”都一样有约束力，而在于数学中成为课题的存在者是以其唯一能被揭示的方式而得到揭示的—先行筹划存在者的存在建构。一旦从基本概念上把起领导作用的存在之领会研究清楚，方法上的线索、概念方式的结构、真理与确定性的与之相属的可能性、论证方式和证明方式、约束性的样式和传达方式等等也就得到确定。这些环节的整体组建着科学的完整的生存论概念。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 数学筹划：海德格尔用此概念指一种预先对自然的理解方式，它不是事后应用数学，而是事先通过数学的视野来规定自然应当如何被看待。筹划在此是“开启一种理解框架”，使事物仅以其可被量化、可被数学规定的方面显现。
  • 现成事物：指被理解为固定、持存、已经在那里的对象，它具有可被客观考察的属性，如运动、力等。在海德格尔看来，这种“现成性”恰恰是数学筹划的结果，而非事物本来的样态。
  • 先天的东西：这里不是康德式的“先验范畴”，而是指在经验之先、通过筹划所展开的“可能性条件”。数学筹划之所以重要，正因为它事先展开了自然可以被认识的先天结构。
  • 生存论概念：海德格尔用“生存论”特指从此在（人的存在）的存在方式出发理解现象。科学的“生存论概念”意味着从科学的实践者（研究者）如何存在、如何与世界打交道的方式来理解科学本身。

2. 逐句转译

  • “科学发展史上的经典例子，但同时甚至是其存在论发生的经典例子，是数学化的物理学。”
    → 物理学的数学化不仅是科学史上的里程碑，更是科学如何从一种特定的存在理解（存在论）中诞生的典型范例。

  • “科学形成的关键既不在于给予对‘事实’的观察以更高的估价，也不在于把数学‘应用’来规定自然进程，而在于对自然本身的数学筹划。”
    → 科学之所以成为科学，关键不是因为我们更重视观察“事实”，也不是因为把数学工具用到自然现象上，而是因为我们事先就用数学的眼光来理解自然——我们为自然设定了一个“可被数学描述”的框架。

  • “这一筹划先揭示出一种持驻的现成事物〔物质〕，开启出一种视野，从而主要地着眼于这一现成事物的可从量上加以规定的组建环节〔运动、力、处所、时间〕。”
    → 这种数学筹划首先让我们把自然看作是一堆固定在那里的对象（物质），并让我们只关注那些可以被量化的方面，比如运动、力、位置、时间。

  • “只有借如此得以筹划的自然之‘光’才会发现‘事实’，并为从这一筹划加以调整界说的实验设定‘事实’。”
    → 只有通过这个数学的“滤镜”，我们才能看到所谓的“事实”，并设计出符合这一框架的实验来确认这些事实。

  • “只有研究者领会到原则上并没有‘纯粹事实’，‘事实科学’的‘论证’才是可能的。”
    → 只有当研究者明白，世界上本没有独立于我们理解框架的“纯粹事实”时，所谓“基于事实的科学”才能真正展开论证。

  • “而且就自然的数学筹划来说，起首要决定作用的又不在于数学的东西本身，而在于：数学筹划对先天的东西有所开展。”
    → 数学筹划的关键不在于数学公式多精确，而在于它事先展开了我们认识自然所需的基本结构（先天条件）。

  • “所以，数学化的自然科学之作为典范，也就不在于它特别精确以及它对‘人人’都一样有约束力，而在于数学中成为课题的存在者是以其唯一能被揭示的方式而得到揭示的—先行筹划存在者的存在建构。”
    → 因此，数学化的自然科学之所以是典范，不是因为它精确或客观，而是因为它以一种特定的方式（通过事先筹划）揭示了研究对象的存在结构。

  • “一旦从基本概念上把起领导作用的存在之领会研究清楚，方法上的线索、概念方式的结构、真理与确定性的与之相属的可能性、论证方式和证明方式、约束性的样式和传达方式等等也就得到确定。”
    → 一旦我们弄清楚了背后主导的“存在理解”，那么科学研究的方法、概念结构、真理标准、证明方式、客观性要求、知识传播方式等，都会随之确定下来。

  • “这些环节的整体组建着科学的完整的生存论概念。”
    → 所有这些部分合在一起，构成了科学作为一个人类活动（生存论概念）的完整图景。

3. 论证逻辑梳理

  • 前提：科学（以数学化物理学为例）的本质不在于观察事实或应用数学工具。
  • 核心推进：科学的真正基础是一种“数学筹划”，即事先用数学的眼光规定自然该如何被认识。这种筹划首先把自然视为可量化的现成事物，并只关注其量化属性。
  • 关键转折：事实只有在筹划所开启的视野中才成为“事实”；研究者必须意识到没有“纯粹事实”，科学论证才可能。
  • 深化论点：数学筹划的关键不是数学本身，而是它展开了认识的先天结构。
  • 结论1：数学化科学的典范性在于它通过筹划揭示了研究对象的存在结构。
  • 结论2：一旦理解了这种主导性的“存在领会”，科学的全部方法论和认识论环节（方法、概念、真理、证明、客观性、传达）都由此确定。
  • 最终整合：所有这些环节共同构成了科学的“生存论概念”，即科学是此在（人）的一种存在方式。

4. 整体概括

这段文字的核心论点是：现代科学的本质不是基于客观事实或数学应用，而是基于一种“数学筹划”——我们事先用数学的眼光去理解自然，把自然框定为一个可由运动、力、位置、时间等量化属性所规定的“现成事物”领域。只有通过这个框架，所谓的“事实”才得以显现，实验才得以设计；而研究者必须明白，不存在脱离这种理解框架的“纯粹事实”。数学化科学的典范性，正在于它通过这种先行筹划，揭示了研究对象的存在结构。一旦这种主导性的“存在理解”被澄清，科学的全部方法、概念、真理标准和论证方式都将随之确定。最终，科学被理解为一种由筹划所引导的人类实践（生存论概念），而非对现成世界的客观反映。

5. 争议与说明

本段解读相对一致，核心争议通常不在于字面含义，而在于如何理解“数学筹划”与“事实”的关系。
- 主流解读：海德格尔在此揭示科学的“存在论基础”，强调科学认知的“筹划性”先于“事实性”，事实总已在某种理解视域中被给出。
- 其他可能解读：有学者会联系海德格尔后期对“技术本质”（集置）的批判，认为此处已隐含对现代科学“促逼”自然、使之仅作为“持存物”的批评。但需注意，《存在与时间》时期的海德格尔更侧重于存在论基础的描述，而非价值批判。
