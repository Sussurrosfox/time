📖 《存在与时间》研读 逐段解析
首页 / 第 086 章 / 片段 029
📜 原文片段 (086/029)
海德格尔 原文
话语之所及，即重的锤子，何以在变式了的话语中就有不同的显现？不在于我们与操作保持距离，但也不在于我们仅仅不顾这一存在者的用具性质，而在于我们“从新”视见前来照面的上手事物，把它看作现成事物。与世内存在者操劳着打交道的活动是由存在之领会领导的，现在是这一存在之领会转变了。我们不再寻视着考虑上手事物，而是把上手事物作为现成事物来“看待”。但由此就已组建起一种科学态度了吗？而且，即使上手事物也可以成为科学研究与科学规定的课题；例如：把研究某一周围世界、研究某人的环境同研究某一历史传记联系起来。日常上手的用具联系，它在历史上的产生、利用，它在此在中的实际地位，这是经济学的对象。上手事物无须失去其用具特征也照样能成为一门科学的“对象”。对于面向“物”的理论行为的发生来说，存在之领会的式变似乎并不必然具有组建作用。诚然——如果式变应得是说：摆在眼前的存在者的在领会活动中得到领会的存在方式发生变化。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 话语：在海德格尔哲学中，“话语”是此在（人）展开自身世界的基本方式，它揭示并构建着我们对存在的理解。在本段中，它特指我们描述和理解事物的语言方式。

  • 上手事物：指我们在日常操劳活动中直接使用、与之打交道的工具或物品（如锤子），它们处于一种非主题化的、顺畅可用的状态，其存在方式是“上手的”。

  • 现成事物：与“上手事物”相对，指被我们当作纯粹摆在眼前、可被客观观察和研究的对象，其存在方式是“现成的”。

  • 存在之领会：此在（人）对存在者之存在的先行理解，它引导着我们与事物打交道的方式。它不是一种理论认识，而是一种前反思的、实践性的理解。

  • 寻视：在操劳活动中，我们环顾四周、为了某种目的而看待和使用事物的方式，它是“上手事物”得以呈现的视野。

  • 科学态度/理论行为：一种将事物视为独立的、可客观研究的现成对象的认知方式。

  • 式变：存在之领会发生了样式上的转变，即从对事物的上手理解转变为现成理解。

2. 逐句转译

  • “话语之所及，即重的锤子，何以在变式了的话语中就有不同的显现？”：为什么同一把重的锤子，在我们改变了描述它的语言方式后，会呈现出不同的样貌？

  • “不在于我们与操作保持距离，但也不在于我们仅仅不顾这一存在者的用具性质，而在于我们‘从新’视见前来照面的上手事物，把它看作现成事物。”：这种变化的原因，不是因为我们站远了观察它，也不是因为我们刻意忽略它作为工具的性质，而是因为我们用一种全新的眼光，将那个原本在熟练使用中与我们照面的工具（上手事物），看作了一个摆在面前、可供审视的对象（现成事物）。

  • “与世内存在者操劳着打交道的活动是由存在之领会领导的，现在是这一存在之领会转变了。”：我们与世界内的东西打交道、操劳忙碌，这一切活动都是由我们对“存在”的理解所引导的。而现在，恰恰是这种“存在之领会”本身发生了变化。

  • “我们不再寻视着考虑上手事物，而是把上手事物作为现成事物来‘看待’。”：我们不再是为了使用它而环顾、打量它（寻视），而是把它当作一个现成的对象来“观看”和“思考”。

  • “但由此就已组建起一种科学态度了吗？”：但是，仅仅这样，就足以构成一种科学的研究态度了吗？

  • “而且，即使上手事物也可以成为科学研究与科学规定的课题；例如：把研究某一周围世界、研究某人的环境同研究某一历史传记联系起来。”：况且，即便是那些上手使用的东西，也同样可以成为科学研究和规定的对象。比如，研究某个人的生活环境、他周围的物质世界，并将这些研究与他的个人传记联系起来。

  • “日常上手的用具联系，它在历史上的产生、利用，它在此在中的实际地位，这是经济学的对象。”：我们日常使用的工具之间的关联、它们在历史上是如何被制造和使用的、它们在人的实际生活中占据什么位置——这些都可以是经济学研究的对象。

  • “上手事物无须失去其用具特征也照样能成为一门科学的‘对象’。”：一个东西作为工具的性质（用具特征）并不需要被取消，它同样可以成为一门科学的“对象”。

  • “对于面向‘物’的理论行为的发生来说，存在之领会的式变似乎并不必然具有组建作用。”：这样看来，对于那种面向“物”的理论研究行为（科学态度）的产生来说，“存在之领会”的样式转变（从上手到现成）似乎并不是一个必然的、构成性的条件。

  • “诚然——如果式变应得是说：摆在眼前的存在者的在领会活动中得到领会的存在方式发生变化。”：确实如此——前提是，这里所说的“式变”，指的是在领会活动中，那个被摆在我们面前的存在者，其被我们领会到的“存在方式”发生了改变。

3. 论证逻辑梳理

  1. 提出核心问题：段落开篇提出一个现象学问题：同一事物（锤子）为何因描述方式（话语）的改变而呈现不同？
  2. 给出初步解释：答案指向了“存在之领会”的根本转变——我们从实践的、使用的眼光（上手），转为了观察的、对象的眼光（现成）。
  3. 推进并质疑：随即提出一个关键质疑：这种视角转变，是否就等同于构建了“科学态度”？
  4. 引入反例与分析：通过举例（经济学研究日常用具）论证，科学完全可以将“上手事物”作为对象，而无须剥夺其“用具特征”。这表明，科学对象化不必然要求我们事先在存在论上将其视为“现成事物”。
  5. 得出初步结论：因此，“存在之领会的式变”（从上手到现成）对于理论行为（科学态度）的发生，似乎并非必要条件。
  6. 限定与澄清：最后一句是对“式变”概念的精确定义，强调它特指存在方式在领会中的变化，这为上述讨论划定了范围，也暗示了问题的复杂性。

4. 整体概括

这段文字的核心是在探讨我们看待事物的视角转变（从上手的工具变为观察的对象）与科学态度形成之间的关系。海德格尔指出，这种视角转变源于我们最根本的“存在理解”发生了变化。但他紧接着质疑：仅仅有这种转变，就足以形成科学吗？他通过举例说明，科学（如经济学）完全可以在不改变事物“工具身份”的情况下研究它们。因此，他得出结论：将事物“对象化”的科学研究，并不必然依赖于我们事先在哲学层面把它理解为一个纯粹的“现成对象”。他是在区分日常实践中的对象化与哲学存在论上的对象化，并暗示科学的根基可能比单纯的视角转变更为复杂。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对最后一句限定条件的理解。一种主流解读认为，海德格尔在此严格限定了“式变”的含义，强调它是指在“存在论”层面对存在方式的领会发生了根本转变，这不同于科学实践中简单的“注意力的转移”。另一种可能的解读方向是，海德格尔在此埋下伏笔，暗示即使科学不必然需要这种存在论上的式变，但科学本身作为一种人类活动，其可能性依然根植于此在某种更源初的“存在之领会”中，只是这种领会未必是“现成性”的。争议的核心在于如何精确界定“存在之领会的式变”与“科学对象化”之间的因果关系和层次关系。
