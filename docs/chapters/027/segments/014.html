📖 《存在与时间》研读 逐段解析
首页 / 第 027 章 / 片段 014
📜 原文片段 (027/014)
海德格尔 原文
此在向来已经熟悉意蕴。意蕴就包含有此在有所领会并做出解释之际能够把“含义”这样的东西开展出来的存在论条件；而含义复又是言词与语言可能存在的基础。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在 海德格尔哲学中的核心概念，特指“人”这种存在者，其本质在于“去存在”，即它总是处在理解、筹划和展开自身可能性的动态过程中。此在不是现成的物体，而是通过它的生存活动来定义自身的。

  • 意蕴 世界不是一个由孤立物体堆积而成的空间，而是一个由“为了作…之用”、“与…相关”等指引关系相互勾连构成的、有意义的整体网络。此在天然地就沉浸并熟悉这个意义网络，它是一切具体理解和解释得以发生的背景。

  • 领会 此在存在的基本方式之一。它不是指理论上的认识或理解一个命题，而是指此在总是先行地对自身的种种可能性以及世界的意蕴有一种前反思的、实践性的“懂得如何行事”的熟悉状态。

  • 解释 建立在领会基础之上的活动。它把领会中那些已经非主题化地敞开的意义关系明确地、主题化地阐释出来，可以理解为“领会”的清晰化和 Articulation。

  • 含义 在解释活动中被明确指向和固定下来的、可被交流的“意义”。它是意蕴网络中某个具体节点或关系被明确揭示后的产物。

  • 存在论条件 使某个事物能够如其所示那样存在的根本前提或基础。它不是事实性的条件，而是关乎存在方式的可能性条件。

2. 逐句转译

  • “此在向来已经熟悉意蕴。” 我们人（此在）从一开始，就生活在一个充满意义的世界里。这个世界里的东西不是孤立的，它们总是“用来做什么的”、“和什么相关的”，我们自然而然地、不假思索地就懂得如何与这个世界打交道。

  • “意蕴就包含有此在有所领会并做出解释之际能够把‘含义’这样的东西开展出来的存在论条件；” 这个我们熟悉的意义整体（意蕴），恰恰为我们能够去理解事物、并进一步说出“这个东西是什么意思”（开展出含义）提供了最根本的可能性。换句话说，没有这个先行的意义网络，具体的理解和解释就无从谈起。

  • “而含义复又是言词与语言可能存在的基础。” 进而，这些在解释活动中被明确出来的具体“含义”，构成了词语和语言能够存在和起作用的基础。语言之所以能表达意义，是因为它植根于这些已经从背景中凸显出来的“含义”。

3. 论证逻辑梳理

  • 前提： 此在生存于世的基本状态是“熟悉意蕴”。这是被给定的、先于任何反思的事实。
  • 推进一： 从这一前提出发，论证意蕴是先行的，它为后续的“领会”和“解释”这两个层次的活动提供了可能性的土壤（存在论条件）。意蕴是使“含义”得以被揭示的背景。
  • 推进二： 进一步向下追溯，指出被解释活动所固定下来的“含义”，又是更表层的现象——“言词与语言”——得以可能的基础。
  • 结论： 由此建立了一个从根基到表层的依赖链条：意蕴 → 领会与解释 → 含义 → 言词/语言。语言的意义最终植根于此在先行熟悉的意蕴世界。

4. 整体概括

这段话的核心是在追溯我们日常语言和交流能力的终极根源。海德格尔指出，我们之所以能使用词语说话，是因为词语承载着具体的“含义”；而我们之所以能形成和理解这些含义，又依赖于我们之前进行的“解释”活动；解释活动本身，则又立足于我们对世界一种更原初、更整体的“领会”；而这种领会之所以可能，归根结底是因为我们人从一开始就被抛入并熟悉一个由各种用途和关联构成的“意蕴”世界。所以，语言的根不在语法书里，而在我们与生俱来的、与世界打交道的实践性生活之中。

5. 争议与说明

本段解读相对一致。海德格尔在此处旨在构建一个现象学的奠基关系，从最源初的生活经验（意蕴）推导出派生现象（语言），这一思路在其哲学框架内是清晰且自洽的。可能的讨论点在于“意蕴”本身的构成是否完全先于语言，但在此段中，海德格尔明确将语言置于意蕴所奠基的序列末端，立场是明确的。
