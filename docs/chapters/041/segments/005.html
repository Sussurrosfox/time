📖 《存在与时间》研读 逐段解析
首页 / 第 041 章 / 片段 005
📜 原文片段 (041/005)
海德格尔 原文
有威胁性质的东西的特点已如上述，而害怕本身则以让它来牵涉自己的方式把这种具有威胁性质的东西开放出来。并非先断定了一种未来的折磨〔malam futurum〕才害怕。但害怕也并非先确定有一种临近前来的东西，害怕先就在这种东西的可怕性中揭示这种东西。怕而后才可以一面害怕一面明确观望可怕的东西，把它“弄明白”。寻视之所以能看到可怕的东西，因为它是在怕的现身之中。怕是现身在世的潜在的可能性，即“会怕”。作为这种可能性，怕已经这样展开了世界—使可怕的东西等等能够从世界方面来接近。而‘能接近”本身则是由在世在本质上具有的生存论空间性开放出来的。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 威胁性质的东西：指在“怕”这种情绪中，被此在（Dasein，即人的存在）经验为具有潜在危险或有害性的对象或情境。它不是客观的危险物，而是在此在的“怕”中显现为威胁的存在者。
  • 开放/揭示：海德格尔的核心概念，指此在通过其生存活动（如情绪、理解）让事物如其所示地显现出来，成为可理解、可遭遇的。
  • 怕（Furcht）：一种基本的现身情态（Befindlichkeit），此在通过它直接而前反思地遭遇到世界中的威胁性。它不是基于认知判断，而是更原初的、情绪性的敞开方式。
  • 现身（Befindlichkeit）：此在总是已经处在某种情绪状态中，并通过这种情绪来理解自身和世界。它是此在“发现自己已然如此存在”的基本方式。
  • 在世（In-der-Welt-sein）：此在最基本的生存结构，意味着人从来不是孤立的主体，而是始终已经“在世界之中”并与世界内的存在者打交道。
  • 生存论空间性：此在在世的一种基本方式，不是物理的、可测量的空间，而是此在通过其操劳活动（如接近、躲避、定向）所展开的意蕴空间。

2. 逐句转译

  • 原文第一句：“有威胁性质的东西的特点已如上述，而害怕本身则以让它来牵涉自己的方式把这种具有威胁性质的东西开放出来。”

    • 转译：前面已经描述了“具有威胁性的东西”是什么样的。而“怕”这种情绪，是通过让自己被这种东西所牵连、所触动的方式，从而把它作为一个威胁给揭示和显现出来。

  • 原文第二、三句：“并非先断定了一种未来的折磨〔malam futurum〕才害怕。但害怕也并非先确定有一种临近前来的东西，害怕先就在这种东西的可怕性中揭示这种东西。”

    • 转译：我们不是因为先通过理性判断，确认了“未来会有一个灾祸”，然后才感到害怕。同时，害怕也不是因为先确定了一个正在逼近的具体物体。恰恰相反，害怕一开始就直接在那种东西自带的“可怕性质”中，把它给揭露出来了。

  • 原文第四句：“怕而后才可以一面害怕一面明确观望可怕的东西，把它‘弄明白’。”

    • 转译：正是在这种原始的“怕”的情绪基础上，我们才能一边感到害怕，一边去仔细打量那个可怕的东西，试图从认知上把它搞清楚。

  • 原文第五句：“寻视之所以能看到可怕的东西，因为它是在怕的现身之中。”

    • 转译：我们那种在日常生活中环顾、打量事物的眼光（寻视），之所以能“看到”某个东西是可怕的，正是因为我们首先就处在“怕”这种情绪状态里。

  • 原文第六句：“怕是现身在世的潜在的可能性，即‘会怕’。”

    • 转译：“怕”是此在（人）作为身处世界之中的情绪性存在，所固有的一种潜在能力，简单说，就是人“会害怕”的能力。

  • 原文第七、八句：“作为这种可能性，怕已经这样展开了世界—使可怕的东西等等能够从世界方面来接近。而‘能接近’本身则是由在世在本质上具有的生存论空间性开放出来的。”

    • 转译：正是作为这种“会怕”的可能性，“怕”已经预先为我们展开了一个世界——使得“可怕的东西”能够从这个世界里向我们逼近、与我们遭遇。而这种“能够逼近、遭遇”的可能性本身，根源在于我们的“在世存在”从本质上就具有一种生存论上的空间性，是这种空间性开放出了事物得以“接近”我们的场域。

3. 论证逻辑梳理

  1. 前提：海德格尔已经在前文描述了“具有威胁性质的东西”的特征。
  2. 核心论点提出：“怕”不是基于认知判断的结果，而是一种更原初的、情绪性的揭示方式。它直接让威胁性显现（第一句）。
  3. 否定性论证：通过两次否定来强化论点：怕既非源于对未来的灾祸判断，也非源于对临近物体的确认（第二、三句）。这划清了“怕”与理性认知的界限。
  4. 阐明关系：指出认知性的“观望”和“弄明白”是在原初的“怕”的情绪基础上才得以可能的（第四句）。并用“寻视”依赖于“怕的现身”来进一步确证这种奠基关系（第五句）。
  5. 存在论深化：将“怕”提升到此在生存论的基本结构层面，定义其为“现身在世的潜在可能性”（第六句）。
  6. 最终推导：论证这种可能性（会怕）如何作用于世界：它“展开世界”，使威胁物得以“接近”。并最终追溯到这种“接近”可能性的根源——此在“在世”所固有的“生存论空间性”（第七、八句）。逻辑链条为：怕（情绪）→ 展开世界 → 事物得以接近 → 此根源在于生存论空间性。

4. 整体概括

这段话的核心是在为“怕”这种情绪进行存在论层面的正名。海德格尔坚决反对将“怕”理解为一种次生的、基于理性判断（比如“我判断那很危险”）的心理反应。他强调，“怕”是一种更原始、更根本的生存方式。我们首先是“怕着”的，正是在这种情绪中，世界才以其威胁性的面目向我们呈现；换句话说，事物是作为“可怕的”东西被我们直接遭遇的。之后，我们才能在此基础上，去观察、分析那个可怕的对象。因此，“怕”是人（此在）存在于世界的一种基本能力和方式，它预先为我们打开了一个能让威胁得以“逼近”的意义空间，这个空间的开放性，最终根植于人“在世存在”本身的结构之中。

5. 争议与说明

本段解读相对一致。海德格尔对情绪（怕是其范本）的生存论分析，旨在颠覆传统哲学将情绪视为模糊、主观、次于理性的附属物这一观点，论证情绪是此在理解世界和自身更源始的方式。这一解读方向在学界是主流。可能的细微讨论点在于对“生存论空间性”与此在情绪性开显世界之间关系的具体机制有更技术化的探讨，但这并不影响对本段核心论旨的理解。
