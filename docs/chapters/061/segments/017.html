海德格尔 原文
在对此在向不再此在亦即向不再在世过渡作出描述的时候，我们还会显示出：必须把此在在死这个意义上的去世同某种仅仅具有生命的东西的“去世”区别开来。我们用“完结”这个术语来把握生物的终结。只有把此在式的终结同某种生命的终结区划开来，才能看清上述区别。虽说也可以从生理学生物学角度来看待死，但exitus〔死〕这一医学概念却同完结这一概念不相涵盖。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在：海德格尔哲学的核心概念，特指“人的存在”。它不是指一个现成的、固定不变的存在者，而是指那种能够对自身存在有所领会、有所追问的存在方式。此在的本质在于“去存在”，它总是处在可能性之中，并通过在世（与世界打交道）来展开自身。

  • 不再此在 / 不再在世：指此在的死亡。对海德格尔而言，此在的死亡不是一个单纯的生物学事件，而是此在存在的终极可能性。当此在死亡，它不再作为“在世界之中存在”的方式显现，即“不再在世”。

  • 完结：指生物（非人生命体）生命过程的自然终结。它是一个生物学事件，标志着生命机能的停止。海德格尔用此概念来与“此在的死亡”进行对比。

  • Exitus：医学术语，指生理上的死亡，即生命体征的停止。它与“完结”概念相近，但海德格尔强调，即便从生物学或医学角度研究死亡，这种“生理性终结”的概念也无法涵盖“此在式的死亡”的全部内涵。

2. 逐句转译

  1. 原文：在对此在向不再此在亦即向不再在世过渡作出描述的时候，我们还会显示出：必须把此在在死这个意义上的去世同某种仅仅具有生命的东西的“去世”区别开来。 转译：当我们尝试描述“人”是如何走向死亡（也就是不再作为“在世界中存在”的方式）时，我们会发现一个关键点：我们必须把“人”所特有的死亡方式，和那些仅仅有“生命”的东西（比如动植物）的死亡方式，严格地区分开。

  2. 原文：我们用“完结”这个术语来把握生物的终结。 转译：我们这里用“完结”这个词，来指代一般生物的生命终结。

  3. 原文：只有把此在式的终结同某种生命的终结区划开来，才能看清上述区别。 转译：只有先把“人特有的死亡”和“一般生物的生命终结”划分清楚，我们才能真正看清楚刚才说的那个区别。

  4. 原文：虽说也可以从生理学生物学角度来看待死，但exitus〔死〕这一医学概念却同完结这一概念不相涵盖。 转译：虽然我们当然也可以从生理学或生物学的角度来研究死亡，但请注意，医学上用的“死亡”概念，和我们这里定义的“完结”概念，并不是一回事。

3. 论证逻辑梳理

  • 前提：海德格尔要描述“此在”（人）是如何走向死亡（“不再此在”/“不再在世”）的。
  • 核心论点提出：在描述之前，必须先确立一个根本性的区分，即“人的死亡”与“一般生物的死亡”是两回事。
  • 概念定义与划界：
  • 他用“完结”一词来专门指称“一般生物的死亡”。
  • 他强调，必须先做好这个概念上的划界，才能清晰地讨论“人的死亡”究竟有何特殊之处。
  • 进一步澄清与加固边界：
  • 他承认死亡可以从生物学、医学的角度研究（即exitus）。
  • 但他立刻指出，即便是这种科学研究的死亡概念，也和他要讨论的“完结”（作为生物终结）不完全是一回事。这从侧面再次强调了“此在的死亡”是一个需要独立出来、进行专门哲学探讨的领域，不能被科学概念所替代或覆盖。

4. 整体概括

这段话的核心目的在于为后续深入探讨“人的死亡”做概念上的准备和划界。海德格尔开门见山地指出，我们不能把人的死亡混同于动植物的死亡。他把后者称为“完结”，一个纯粹生物学意义上的生命终结。他强调，必须先把这条界线划清楚，我们才有可能去理解“人”这种特殊的存在者，其死亡究竟意味着什么——那不仅仅是生理机能的停止，更是其独特“在世存在”方式的终结。他最后还特意说明，即便是医学上的死亡概念，也无法完全涵盖他所要探讨的哲学问题。这段话可以看作是为“此在之死”这一核心论题清理场地，划定专属的研究范围。

5. 争议与说明

本段内容主要是概念界定和划界，属于海德格尔论证的预备阶段，其目的在于确立一个独特的研究领域，因此在解读上相对一致，并无广为人知的重大争议。
