海德格尔 原文
前此对此在的存在建构的分析是否指出了一条道路，可使我们从存在论上理解呼唤者的存在方式，并从而理解呼唤的存在方式？呼声不是明确地由我呼出的，倒不如说“有一声呼唤”，但这不是在某种非此在式的存在者中寻找呼唤者的理由。此在一向实际生存着。此在并非飘浮无据的自身筹划；它由被抛境况规定为它所是的存在者的实是；这样，它总曾己托付给并仍不断托付给生存。此在的实际性却在本质上有别于现成事物的事实性。生存着的此在不是作为一种世内现成事物向它自己照面的。而被抛境况也并不是像某种无法通达的、对此在的生存无足轻重的性质那样贴在此在身上。此在作为被抛的此在被抛入生存。它作为这样一种存在者生存着：这种存在者不得不如它所是的和所能是的那样存在。
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 此在 (Dasein)：海德格尔用以专指“人”这种存在者的术语。此在的本质在于它的“生存”，即它总是通过理解和筹划自身可能性而“去存在”，而不是像一块石头或一张桌子那样仅仅“现成存在”。
  • 存在论 (Ontological)：关于“存在”本身的研究，探究事物“作为存在”意味着什么，而非仅仅研究具体存在者的属性。
  • 呼唤/呼声 (Call)：指此在内心深处的一种召唤，它来自此在自身，呼唤此在从沉沦于常人的日常状态中返回本真的自我。它没有具体内容，是一种让其“成为自己”的催促。
  • 被抛境况 (Thrownness)：此在的一个基本规定性。指此在总是已经被抛入一个它未曾选择的世界、历史、文化和具体情境中，并不得不从这种既定的、事实性的处境开始它的生存。它不是此在自主选择的结果。
  • 筹划 (Projection)：此在面向未来、理解自身并谋划其可能性的存在方式。此在不是现成的，它总是在“成为”某种可能性的过程中。
  • 实际性 (Facticity)：专属于此在的概念。指此在总是已经在世界之中，并承担着其被抛境况的这一事实。它强调的是此在生存的具体、现实的处境。
  • 事实性 (Factuality)：指普通现成事物（如石头、树木）单纯“在那里”的属性。与此在的“实际性”有本质区别。
  • 生存 (Existence)：此在特有的存在方式。意味着此在的本质就在于它的“去存在”，在于它不断地出离自身、筹划并实现其可能性。
  • 现成事物 (Present-at-hand)：指以静态、观察对象的方式存在的事物，其存在方式是被规定的、已完成的状态。

2. 逐句转译

  • “前此对此在的存在建构的分析是否指出了一条道路，可使我们从存在论上理解呼唤者的存在方式，并从而理解呼唤的存在方式？”

    • 转译：我们之前对此在（人）的存在结构所做的分析，是否能帮助我们从根本上（存在论上）搞清楚：那个发出呼唤的东西（呼唤者）是以什么方式存在的？以及，呼唤这个行为本身，又是以什么方式存在的？

  • “呼声不是明确地由我呼出的，倒不如说‘有一声呼唤’，但这不是在某种非此在式的存在者中寻找呼唤者的理由。”

    • 转译：这声呼唤并不是由日常生活中那个“我”明确发出的。更准确的感觉是，我们只是“听到了”一声呼唤。但是，我们也不能因此就认为，这呼唤是来自我之外的某个东西（比如上帝或世界精神）。

  • “此在一向实际生存着。此在并非飘浮无据的自身筹划；它由被抛境况规定为它所是的存在者的实是；这样，它总曾己托付给并仍不断托付给生存。”

    • 转译：此在（人）从来都是实实在在地生活着的。它的自我规划和可能性，并不是悬在空中的、毫无根据的幻想。它从一开始，就被“抛入”了一个特定的、它无法选择的现实境况（比如出身、时代、文化），正是这个被抛的境况，定义了它作为这样一个具体的人的现实基础。因此，它过去一直是，并且未来也持续是，被交付给了“生存”这回事——即，它必须不断地去成为它自己。

  • “此在的实际性却在本质上有别于现成事物的事实性。”

    • 转译：但是，此在的这种“实际性”（由被抛境况规定的具体生存）和一张桌子、一块石头那种“摆在那里”的“事实性”，在本质上是完全不同的。

  • “生存着的此在不是作为一种世内现成事物向它自己照面的。而被抛境况也并不是像某种无法通达的、对此在的生存无足轻重的性质那样贴在此在身上。”

    • 转译：一个正在生存着的人，并不是像看到一个外部物体那样来面对自己的。同样，他的“被抛境况”（他所处的既定事实）也不是一个贴在他身上、他无法触及、对他的生活无关紧要的标签。

  • “此在作为被抛的此在被抛入生存。它作为这样一种存在者生存着：这种存在者不得不如它所是的和所能是的那样存在。”

    • 转译：此在，就是作为一个“被抛”的存在者，被扔进了“生存”之中。它就是这样一种存在者：它别无选择，只能以它“已经是”的样子（被抛境况）为起点，并以它“可能是”的样子（筹划）为目标，去存在，去生活。

3. 论证逻辑梳理

  1. 前提与问题： 段落开头提出了一个核心问题：我们已有的分析能否帮我们理解“呼唤”的来源（呼唤者）和方式？
  2. 界定呼唤的特征： 首先澄清呼唤不是由日常的“我”发出的，但也不是来自外部。这为在“此在自身”内部寻找答案奠定了基础。
  3. 分析此在的存在结构（核心论证）：
    • 第一步： 指出此在的生存是“实际的”，不是凭空幻想。它的筹划扎根于“被抛境况”。
    • 第二步： 强调此在的“实际性”与物体的“事实性”有本质区别，防止将人物化。
    • 第三步： 进一步阐述，此在无法像看物体一样旁观自己，其被抛境况也并非外在、无关的属性，而是内在于其生存，是它必须承担和理解的。
  4. 得出结论： 最终将“被抛”与“生存”紧密绑定，描绘出此在的宿命：它必须以其被给予的特定条件为前提，去谋划和实现它的可能性。这个关于此在存在方式的结论，为下一阶段探讨“呼唤”正源于此在自身的这一存在结构（即良知）做好了准备。

4. 整体概括

这段话的核心是在为理解“良知呼唤”的来源做铺垫。海德格尔首先提出，要理解那声神秘的呼唤，不能向外找，而必须从此在自身的存在结构中寻找答案。他随即深入剖析了此在的一个根本特征：“被抛的筹划”。人不是一张白纸，他总是已经被扔进一个特定的、无法选择的现实世界（被抛境况），他的所有梦想、计划和可能性（筹划）都必须从这个现实基础出发。同时，人所处的这个现实，又不同于一个物体的冰冷事实，它深刻地、内在地构成了人必须去面对和承担的生存本身。因此，人注定要以他“已经是”的样子，去成为他“可能是”的样子。这段话最终描绘了此在的一种“宿命式”的生存结构，暗示了那声呼唤正是源于人自身的这种既被规定又要求自我超越的、充满张力的存在方式。

5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“呼唤者”的最终归属有不同侧重的解读。虽然海德格尔明确排除了外部来源，并引导向此在自身，但对于“此在自身”的哪个层面是呼唤者，存在讨论空间：

  • 主流解读（也是后续文本支持的）： 呼唤来自此在的“本己自身”，呼唤此在从“常人”的沉沦状态中返回自身。呼唤者是此在的“能在”或“本真存在”。
  • 其他可能的解读方向： 有学者会强调呼唤的“匿名性”和“来自存在本身”的意味，认为它源于此在与“存在”的关联，而不仅仅是心理主体。但海德格尔在《存在与时间》中主要锚定于此在的存在结构，外部“存在”的维度在此阶段并非重点。争议点在于如何平衡呼唤的“内在性”与“超越日常自我”的特性。
