海德格尔 原文
上面把良知阐释为操心的呼声。然而，人们将对这种阐释提出质疑说：一种与“自然经验”相去如此之远的良知解释能站得住脚吗？良知首先与通常只是责斥与警告，这时它应得怎样才能充任唤向最本己的能在的唤起者呢？良知是这样就一种最本己的能在而空洞不定地发言，而不是就铸成的或面临的失误疏漏而确切具体地发言吗？所称的呼唤生自“坏”良知抑或“好”良知？难道良知竟提供出了什么正面的东西而并非像以前那样仅只起批评作用吗？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 良知：在海德格尔哲学中，良知并非传统道德意义上的“良心”，而是此在（人的存在）的一种基本存在方式。它通过一种无声的呼唤，将此在从日常的沉沦状态唤醒，使其直面自身最本己的能在（潜在的可能性）。在本段中，海德格尔预设读者已了解他将良知定义为“操心的呼声”。
  • 操心：此在的整体存在结构，指人始终在“已经存在于世”与“面向未来谋划”之间展开其存在。良知作为操心的呼声，是从这种整体结构中发出的。
  • 此在：指人的存在，其本质在于“去存在”，即不断筹划自身可能性。
  • 最本己的能在：此在完全基于自身理解与抉择所展开的、最真实、最个体化的存在可能性。
  • 沉沦：此在日常陷入闲谈、好奇、两可的公众意见，逃避自身本真状态的存在方式。
  • 呼唤：良知的存在方式，它不是清晰的语言，而是将此在唤回自身的一种触动。

2. 逐句转译

  • “上面把良知阐释为操心的呼声。然而，人们将对这种阐释提出质疑说：一种与‘自然经验’相去如此之远的良知解释能站得住脚吗？”

    • 前文将良知解释为源于人的整体存在结构（操心）的一种呼唤。但有人会质疑：这种解释和人们通常对良知的体验差距太大，真的合理吗？

  • “良知首先与通常只是责斥与警告，这时它应得怎样才能充任唤向最本己的能在的唤起者呢？”

    • 因为良知在日常生活中，主要体现为对我们过错行为的责备和警告。它怎么能承担起“唤醒人去面对自身最真实可能性”这么崇高的任务呢？

  • “良知是这样就一种最本己的能在而空洞不定地发言，而不是就铸成的或面临的失误疏漏而确切具体地发言吗？”

    • 良知真的是在空泛地谈论“你的可能性”，而不是针对那些已经发生或即将发生的具体错误，给出明确具体的指摘吗？

  • “所称的呼唤生自‘坏’良知抑或‘好’良知？”

    • 你所说的这种呼唤，到底是来自于我们做错事后的“坏良心”（愧疚感），还是来自于做好事后的“好良心”（无愧感）呢？

  • “难道良知竟提供出了什么正面的东西而并非像以前那样仅只起批评作用吗？”

    • 难道良知除了像传统认为的那样只会批评人，还能提供某种积极的、建设性的内容吗？

3. 论证逻辑梳理

  • 前提（提出的质疑）：海德格尔在此段并非陈述自己的观点，而是系统地陈列一个假想的批评者对其良知理论的质疑。
  • 论证推进：质疑沿着一个清晰的逻辑链条展开：
    1. 挑战理论根基：首先质疑海德格尔的阐释与日常“自然经验”脱节，缺乏直观基础。
    2. 质疑功能定位：指出良知的日常表现（责斥、警告）与其理论功能（唤向本己能在）之间存在巨大鸿沟。
    3. 质疑内容特性：进一步诘难良知呼唤的内容是“空洞不定”的，与日常良知对“具体失误”的指摘相悖。
    4. 质疑来源与性质：追问呼唤的来源（好/坏良知），并最终挑战其根本性质——良知是否可能具备“正面”的建设性作用，而非仅仅是负面的批评。
  • 结论：本段本身没有结论，而是通过一系列层层递进的质疑，为海德格尔在下文为自己理论的辩护和深化（阐明良知呼唤的否定性如何恰恰开启了最积极的自我领会）设置了靶子。

4. 整体概括

这段文字是海德格尔预设的、针对他自己将良知定义为“操心的呼声”这一理论所提出的系统性反驳。批评者认为，这种哲学阐释过于抽象和反常，因为它无法解释我们日常生活中良知的普遍经验：良知通常是事后对具体错误的、明确的、负面的责备和警告（“坏良心”），听起来内容具体，作用消极。它如何能摇身一变，成为一种内容空灵、却能引导人面向未来积极谋划自身最真实可能性的“呼唤”？这段话的核心在于凸显海德格尔的良知理论与流俗良知观念之间的尖锐对立，从而引出一个必须回答的问题：一种只知批评的良知，如何能成为本真存在的引导者？

5. 争议与说明

本段是海德格尔设想的反对意见，其解读相对一致。后续的争议主要集中在海德格尔本人的答复是否成功： - 主流解读：认为海德格尔成功地将良知的“否定性”（无声的、令人不安的呼唤）重新解释为一种“奠基性的肯定”，即通过打断沉沦状态，为此在提供了选择本真自我的可能性空间。批评本身正是积极自由的开启。 - 其他解读方向：有批评者认为，海德格尔的回应未能充分解决本段提出的“空洞性”问题，他的“良知”过于形式化，缺乏具体的道德内容，无法真正指导行动。此外，关于良知呼唤是否完全排除了任何“好良知”的积极体验，也存在讨论。
