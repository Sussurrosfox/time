📜 原文片段 (072/011)
海德格尔 原文
“世间”无可规定呼唤者为谁。他是无家可归的此在，是源始的、不在家的被抛在世的存在，是在世界之无中的赤身裸体的“它存在”。呼唤者与平均的常人本身不亲不熟——所以传来的像是一种陌生的声音。常人迷失于它所操劳的纷纷扰扰的“世界”，对它来说，还有什么比那在无家可归中个别化为自己的、被抛入无的自身更陌生呢？一声呼唤；而这对操劳好奇的耳朵却不提供任何可以听来再去对别人讲、去同公众议论的东西。然而，从无家可归的被抛存在中，此在又有什么可加报导的呢？除了在畏中暴露出来的此在本身的能在，还给此在剩下什么？除了向着只关此在的这一能在唤起，还该怎样呼唤？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 世间（world）：在海德格尔哲学中，“世间”指此在日常沉沦于其中的公共生活场域，由闲谈、好奇、两可等非本真生存方式构成。本段中特指此在迷失于其中的日常操劳领域。

  • 呼唤者（the caller）：指发出良知呼唤的存在。它不是任何具体的他人或神灵，而是此在自身本真的、超越日常沉沦状态的深层自我。

  • 此在（Dasein）：海德格尔对人的特殊称谓，指那种能够追问自身存在的存在者。本段强调其“被抛于世”和“无家可归”的基本境况。

  • 被抛（thrownness）：此在不得不已经存在于世的基本事实，是此在无法选择却必须承担的生存前提。

  • 常人（the they）：支配日常生活的匿名他人，通过规范与惯例消解个体性，使此在逃避自身本真可能性。

  • 无（the nothing）：不是空无所有，而是指超越日常意义体系的本真生存维度，在“畏”中揭示出的存在根基。

  • 能在（potentiality-for-Being）：此在面向未来开放的可能性，是此在最本己的生存潜能。

2. 逐句转译

  • “世间无可规定呼唤者为谁。他是无家可归的此在，是源始的、不在家的被抛在世的存在，是在世界之无中的赤身裸体的‘它存在’。”
    → 我们无法在日常生活的范畴内说清谁在发出良知的呼唤。这个呼唤者其实就是我们每个人那个无家可归的本真自我——那个最原始、始终不得安宁的被抛到这个世界的存在，是剥离了所有世俗伪装后，赤裸裸直面世界虚无的“我存在”本身。

  • “呼唤者与平均的常人本身不亲不熟——所以传来的像是一种陌生的声音。”
    → 这个呼唤者与日常生活中随波逐流的“大众自我”毫无共同语言，所以当良知呼唤响起时，听起来就像来自陌生人的声音。

  • “常人迷失于它所操劳的纷纷扰扰的‘世界’，对它来说，还有什么比那在无家可归中个别化为自己的、被抛入无的自身更陌生呢？”
    → 沉陷于日常琐事的“大众自我”，早已忘记了自己的本真面目。对它而言，那个在无家可归境况中独自面对虚无的真实自我，简直就是世界上最陌生的存在。

  • “一声呼唤；而这对操劳好奇的耳朵却不提供任何可以听来再去对别人讲、去同公众议论的东西。”
    → 良知的呼唤虽然响起，但对于习惯了猎奇和闲聊的耳朵来说，这种呼唤没有任何可供传播和公开讨论的内容。

  • “然而，从无家可归的被抛存在中，此在又有什么可加报导的呢？除了在畏中暴露出来的此在本身的能在，还给此在剩下什么？”
    → 但是，从这个无家可归的被抛境况中，我们又能向外界报告什么呢？除了在“畏”这种情绪中揭示出的、此在本身面向未来的可能性，我们还拥有什么？

  • “除了向着只关此在的这一能在唤起，还该怎样呼唤？”
    → 除了唤醒此在直面自身独有的可能性，良知还能怎样呼唤呢？

3. 论证逻辑梳理

前提：此在在日常状态中沉沦于“常人”的支配，逃避本真自我。

推进过程： 1. 首先指出呼唤者的匿名性——它不属于日常世界的任何角色 2. 揭示呼唤者实为剥离了社会面具的、直面虚无的本真此在 3. 通过对比说明，为何这个本真自我对沉沦的常人显得如此陌生 4. 解释良知呼唤为何无法被日常闲谈所消化——它不提供可八卦的内容 5. 通过连续反问，将注意力引向此在最核心的生存事实：被抛境况与能在

结论：良知的本质就是唤醒此在从沉沦状态中抽身，直面自身最本己的可能性。

4. 整体概括

这段话深刻揭示了良知呼唤的本质特征。海德格尔指出，当我们听到良知呼唤时，之所以感觉陌生和难以言传，正是因为呼唤来自我们每个人最本真的自我——那个剥离了所有社会角色、赤裸面对生存真相的自我。日常生活中我们习惯了随波逐流，用忙碌和闲聊掩盖存在的虚无，所以当那个真实的自我发出呼唤时，反而显得格格不入。但这种呼唤恰恰是要把我们唤醒，让我们从浑浑噩噩的日常状态中抽离出来，直面自己独一无二的生命可能性。良知不提供任何可以拿来闲聊的素材，它的唯一目的就是让我们认清：除了承担起自己的生命可能性，我们别无所有。

5. 争议与说明

本段解读相对一致。唯一可能的争议点在于对“无”的理解——有学者强调“无”在此主要指向死亡作为最极端的可能性，而另一些解读则更宽泛地理解为超越日常意义体系的生存维度。但就本段而言，两种解读都能自洽，不影响对良知呼唤本质的理解。
