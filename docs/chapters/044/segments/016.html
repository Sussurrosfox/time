📖 《存在与时间》研读 逐段解析
首页 / 第 044 章 / 片段 016
📜 原文片段 (044/016)
海德格尔 原文
对于哲学考察来说，〔逻各斯〕本身是一存在者：按照古代存在论的方向，〔逻各斯〕是一现成存在者。当〔逻各斯〕用词汇和词序道出自身的时候，词汇和词序首先是现成的，也就是说像物一样摆在面前。人们在寻找如此这般现成的〔逻各斯〕的结构之时，首先找到的是若干词汇的共同现成的存在。是什么促成了这种“共同”的统一？柏拉图认识到：这种统一在于〔逻各斯〕总是〔以某种东西的逻各斯〕。诸语词着眼于在〔逻各斯〕中公开的存在者而合成一个语词整体。亚里士多德的眼光更为彻底：任何〔逻各斯〕都既是〔综合〕又是〔分解〕；而非要么是那么一种所谓“肯定判断”要么是那么一种“否定判断”。毋宁说，无论一个命题是肯定的还是否定的，是真的还是假的，它都同样源始地是〔综合〕与〔分解〕。展示就是合成与分离。诚然，亚里士多德不曾把分析的问题继续推进到这样一个问题上：在〔逻各斯〕的结构范围之内，究竟是哪一种现象允许我们并要求我们把一切命题都描述为综合与分解？
💡 逐段解析与义理阐释
结构化精读

1. 术语释义

  • 逻各斯（Logos）：在海德格尔哲学中，逻各斯通常指“言说”或“话语”，但更根本的是指一种“让事物被看见”或“展示事物”的方式。在本段中，它特指作为哲学考察对象的“陈述”或“命题”本身。
  • 存在者（Seiendes）：指任何“存在着的东西”，可以是具体的物体、抽象的概念或如“逻各斯”这样的语言现象。
  • 现成存在者（vorhandenes Seiendes）：指一种被理解为“已经在那里”“摆在面前”的、如同物体一样静态固定的存在方式。在本段中，传统哲学将逻各斯视为这样一种现成对象。
  • 综合（σύνθεσις, synthesis）：在亚里士多德语境中指将不同的元素“结合”或“聚合”在一起。
  • 分解（διαίρεσις, diairesis）：在亚里士多德语境中指将整体“分离”或“区分”开来。
  • 展示（ἀπόφανσις, apophansis）：在本段中意为通过逻各斯“让事物被看见”“揭示出来”。

2. 逐句转译

  • “对于哲学考察来说，〔逻各斯〕本身是一存在者：按照古代存在论的方向，〔逻各斯〕是一现成存在者。” 在传统的哲学研究中，人们把“逻各斯”（也就是我们说的话、做的陈述）看作一个实实在在的东西。按照古希腊哲学的理解方式，这个“逻各斯”就像是摆在面前的一个现成物件。

  • “当〔逻各斯〕用词汇和词序道出自身的时候，词汇和词序首先是现成的，也就是说像物一样摆在面前。” 当“逻各斯”通过词语和语序表达出来的时候，人们首先看到的是那些词语和语序本身，它们就像桌子上的物品一样，是固定、现成的东西。

  • “人们在寻找如此这般现成的〔逻各斯〕的结构之时，首先找到的是若干词汇的共同现成的存在。是什么促成了这种‘共同’的统一？” 当我们去分析这种被视为现成之物的“逻各斯”的结构时，首先注意到的是这些词语是“一起摆在那里”的。那么，是什么把这些词语联系在一起，构成了一个整体呢？

  • “柏拉图认识到：这种统一在于〔逻各斯〕总是〔以某种东西的逻各斯〕。诸语词着眼于在〔逻各斯〕中公开的存在者而合成一个语词整体。” 柏拉图意识到了关键：这种统一性在于，任何“逻各斯”总是“关于某个东西的逻各斯”。词语之所以能组成一个整体，是因为它们共同指向、共同揭示了某个被谈论的对象。

  • “亚里士多德的眼光更为彻底：任何〔逻各斯〕都既是〔综合〕又是〔分解〕；而非要么是那么一种所谓‘肯定判断’要么是那么一种‘否定判断’。” 亚里士多德看得更深入。他认为，任何“逻各斯”都同时包含“结合”与“分离”这两个动作，而不能简单地被归类为“肯定判断”或“否定判断”。

  • “毋宁说，无论一个命题是肯定的还是否定的，是真的还是假的，它都同样源始地是〔综合〕与〔分解〕。” 换句话说，不管一个陈述是肯定的（如“天是蓝的”）还是否定的（如“天不是蓝的”），是真的还是假的，它在根本上、从一开始就同时包含着“结合”与“分离”。

  • “展示就是合成与分离。” “展示事物”（即通过语言让事物被我们看见）这个行为的本质，就是进行“结合”与“分离”的活动。

  • “诚然，亚里士多德不曾把分析的问题继续推进到这样一个问题上：在〔逻各斯〕的结构范围之内，究竟是哪一种现象允许我们并要求我们把一切命题都描述为综合与分解？” 不过，海德格尔指出，亚里士多德虽然走到了这一步，但他没有继续追问一个更深层的问题：在“逻各斯”的结构中，到底是什么根本的现象，使得我们能够、并且必须用“综合”与“分解”来描述所有的命题？

3. 论证逻辑梳理

  1. 前提： 本段从回顾传统哲学对“逻各斯”的理解开始，即将其视为一个“现成存在者”，其结构就像分析一个物体的结构一样。
  2. 问题提出： 面对这个被视为“现成物”的逻各斯，第一个问题是：是什么把分散的词语统一成一个整体？
  3. 柏拉图的解答： 柏拉图提供了初步解答：统一性来自于逻各斯总是“关于某物的”，词语因共同指向一个被谈论的对象而结合。
  4. 亚里士多德的深化： 亚里士多德将分析推进了一步，指出逻各斯的深层结构是“综合”与“分解”的统一。这超越了简单的肯定/否定二分，揭示了任何言说行为都内在包含将事物联系起来（综合）和区分开来（分解）的维度。
  5. 核心论断： 由此得出核心观点：展示（揭示事物）的本质就是综合与分解。
  6. 海德格尔的追问： 最后，海德格尔点出亚里士多德的未尽之处，即他没有追问“为何综合与分解是可能的？”这个问题，从而为海德格尔自己的探索——回到更源初的“存在”问题——留下了空间。

4. 整体概括

这段文字在梳理传统哲学（尤其是柏拉图和亚里士多德）如何理解语言（逻各斯）。它指出，传统观点一开始把语言当成一个摆在面前的现成物件来研究，关注词语如何组合。柏拉图认识到词语的统一性在于它们共同指向某个对象。亚里士多德则更进一步，揭示了任何语言陈述，无论肯定否定、真假，其深层结构都同时包含“结合”（综合）与“区分”（分解）这两个不可分割的动作，语言揭示事物的方式本身就是这种既联结又区别的活动。但海德格尔认为，亚里士多德止步于此，没有去追问这种“综合与分解”结构之所以可能的更深层根源是什么。

5. 争议与说明

本段解读相对一致。海德格尔在此是在进行“解构性”的哲学史回顾，他的描述是为了引出他自己的问题，而非对柏拉图或亚里士多德思想进行全面的历史考据。因此，争议点不在于他对古希腊哲学的复述是否完全精确，而在于他这种“为了当下哲学目的而解读历史”的方法是否合理。有些古典学者可能认为海德格尔对亚里士多德的解读带有过于强烈的个人目的论色彩，但就本段所传达的核心思想——即指出传统存在论将逻各斯现成化，以及亚里士多德揭示了综合与分解的源初性——而言，学界的接受度较高。
