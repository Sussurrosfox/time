## 题目 (7.txt)

常人本身有自己去存在的方式。前面我们把共在的一种倾向称为庸庸碌碌，这种倾向的根据就在于：共处同在本身为平均状态而操劳。平均状态是常人的一种生存论性质。常人本质上就是为这种平均状态而存在。因此常人实际上保持在下列种种平均状态之中：本分之事的平均状态，人们认可之事和不认可之事的平均状态，人们允许他成功之事的和不允许他成功之事的平均状态，等等。平均状态先行描绘出了什么是可能而且容许去冒险尝试的东西，它看守着任何挤上前来的例外。任何优越状态都被不声不响地压住。一切源始的东西都在一夜之间被磨平为早已众所周知之事。一切奋斗得来的东西都变成唾手可得之事。任何秘密都失去了它的力量。为平均状态操心又揭开了此在的一种本质性的倾向，我们称之为对一切存在可能性的平整。


---

\begin{solution}

### 1. 术语释义
- **常人**：海德格尔用此概念指代一种非本真的人的存在方式，它不是指某个具体的人，而是指日常生活中的一种匿名的、平均化的集体状态。它规定了“人们通常怎么做”，个体往往不加批判地遵循这种集体的、匿名的规范。
- **共在**：此在（人的存在）的基本建构之一，指的是此在本质上总是与他人共同存在于世界之中。它描述了人的存在无法摆脱的社会性维度。
- **庸庸碌碌**：共在的一种非本真模式。在此模式下，此在完全沉溺于其所处世界的公共事务和闲谈中，丧失了对自身独特可能性的清醒认识，只是随波逐流。
- **操劳**：此在与世界内照面的存在者（主要是用具）打交道的基本方式。在这里，“为平均状态而操劳”是一种引申用法，指常人围绕并忙于维护那种平均化的公共状态。
- **平均状态**：常人的核心生存论性质。它不是统计学概念，而是指一种拉平一切、消除差异和例外的强制性规范。它规定了什么是“正常”的、可接受的，什么不是。
- **生存论性质**：用以描述此在（人）之存在方式的那些基本结构或特征。
- **平整**：对“平均状态”之运作效果的动态描述。这是一个将一切突出的、独特的、源始的存在可能性都拉平、抹杀，使之归于无差别、无危险的平庸状态的过程。

### 2. 逐句转译
- “常人本身有自己去存在的方式。” -> 那个匿名的、代表公共意见的“常人”，有它自己独特的存在和运作模式。
- “前面我们把共在的一种倾向称为庸庸碌碌，这种倾向的根据就在于：共处同在本身为平均状态而操劳。” -> 之前我们说过，人在一起共存时，容易陷入一种浑浑噩噩、随大流的状态。这种状态的根源在于，人们共同相处这件事，其内在的运作逻辑就是要去维护和追求一种“平均化”的标准。
- “平均状态是常人的一种生存论性质。常人本质上就是为这种平均状态而存在。” -> 追求和维持“平均状态”，是“常人”最核心、最根本的特征。可以说，“常人”存在的目的和意义，就是为了确立和守护这种平均。
- “因此常人实际上保持在下列种种平均状态之中：本分之事的平均状态，人们认可之事和不认可之事的平均状态，人们允许他成功之事的和不允许他成功之事的平均状态，等等。” -> 所以，“常人”实际上主导着我们生活中方方面面的标准：比如什么是你应该做的分内事，什么是大家赞同或反对的，以及什么事情你被允许成功、什么事情不被允许成功，所有这些都有个无形的、平均化的尺度。
- “平均状态先行描绘出了什么是可能而且容许去冒险尝试的东西，它看守着任何挤上前来的例外。” -> 这个平均标准，在我们行动之前，就已经预先划定了哪些事情是可能被允许去尝试和冒险的。它像一个卫兵，时刻警惕并阻止任何试图超越常规的特例出现。
- “任何优越状态都被不声不响地压住。” -> 任何比平均水平更优秀、更卓越的状态，都会被它悄无声息地打压下去。
- “一切源始的东西都在一夜之间被磨平为早已众所周知之事。” -> 所有具有原创性、本源性的新事物或思想，很快就会被它解释成“这没什么稀奇，我们早就知道了”的样子，从而失去其新颖和冲击力。
- “一切奋斗得来的东西都变成唾手可得之事。” -> 所有需要艰苦努力才能获得的成就，都被它描述得好像人人都能轻松得到一样，贬低了个人奋斗的价值。
- “任何秘密都失去了它的力量。” -> 任何深奥的、不为人知的秘密，在它面前都会失去神秘感和力量，因为它要么将其公开化、庸俗化，要么就斥为无稽之谈。
- “为平均状态操心又揭开了此在的一种本质性的倾向，我们称之为对一切存在可能性的平整。” -> 这种对维持平均状态的执着和忙碌，又向我们揭示了人的一种深层的、固有的倾向：那就是把所有独特的、丰富的、充满各种可能性的生存方式，全都“铲平”，变得整齐划一、平淡无奇。

### 3. 论证逻辑梳理
- **前提**：此在的生存论结构包含“共在”，而“共在”有一种沉沦的倾向，即“庸庸碌碌”。
- **核心论证与推进**：
  1.  首先点明“庸庸碌碌”的根源在于“共在”本身内在地“为平均状态而操劳”。这确立了“平均状态”是理解“常人”的关键。
  2.  接着将“平均状态”界定为“常人”的本质属性，甚至说“常人”就是“为这种平均状态而存在”。这提升了“平均状态”的核心地位。
  3.  然后，通过一系列排比句（本分之事、认可之事、成功之事等）具体展示“平均状态”如何渗透并主宰日常生活的所有领域，使其论述变得丰满具体。
  4.  再然后，通过描述“平均状态”的一系列动态运作（看守例外、压制优越、磨平原初、贬低奋斗、消除秘密），生动地揭示了它作为一种压制性、消解性力量的具体表现。
  5.  **结论**：最后，将上述所有现象归结为“此在的一种本质性的倾向”，并为其命名——“对一切存在可能性的平整”。这最终完成了从现象描述到本质概括的跃升，揭示了这种平整倾向是内在于此在结构的一种深刻机制。

### 4. 整体概括
这段话的核心是在剖析我们日常生活中那个无形的“暴君”——“常人”。海德格尔指出，当我们沉浸在公共生活中时，会不自觉地被一种追求“平均状态”的力量所支配。这种力量预先规定了什么是正常的、可接受的，什么是出格的、不允许的。它像一个无形的过滤器，把任何独特的、卓越的、原创的、需要艰辛努力的事物，要么打压下去，要么磨平其棱角，使之变得平庸化和理所当然。最终，这种力量暴露出人自身存在的一种深层倾向：即通过“平整”一切，来消除差异、风险和不确定性，从而获得一种虚假的安全感和安稳感，但这同时也扼杀了我们本真的、充满各种可能性的生存方式。

### 5. 争议与说明
本段解读相对一致。海德格尔对“常人”和“平均状态”的批判是其哲学中非常鲜明和核心的部分，学界对其描述的现象和基本论断争议不大。可能的讨论点在于对“平整”倾向的伦理评价：它是否完全是一种消极的、需要被克服的东西？还是说，作为社会性存在的此在，这种平均化在构建共享世界和日常秩序方面也有其不可或缺的功能？但就本段文字而言，海德格尔显然是聚焦于其压抑本真可能性的负面效应。

\end{solution}
