## 题目 (10.txt)

例如，不成熟的果子渐趋成熟。在这种成熟过程中，果实尚未是的那种东西绝不是作为尚未现成的片段积拢到果实上来的。它自已把自己带向成熟，这一点标画出它作为果实的存在。如果果实不丛它本身方面趋向成熟，则一切可以附加上去的设想之事都无法消除这一存在者的不成熟。不成熟的这种尚未并非意指一种悬搁在外的它者，仿佛这个它者可以以对果实无所谓的方式依它和共它现成存在。不成熟这种尚未在果实特有的存在方式中意指着果实本身。尚未充盈的总额作为一种上手事物对欠缺的未上手的余额是“无所谓的”。严格说来它对之既不是无所谓的也不是有所谓的。但不仅正在成熟的果实对不成熟这样一种它自己的它者不是无所谓的，而且它就在成熟过程中是这种不成熟。尚未已经被包括到果实的本已存在之中；这时它绝不是作为随随便便的规定性，而是作为组建因素。与此相当，只要此在存在，它也向来已是它的尚未。


---

\begin{solution}

### 1. 术语释义

- **尚未 (Not-yet)**：指一种“还没有实现，但正在朝向实现”的状态。它不是外在的缺失，而是事物自身存在结构的内在组成部分。在本段中，海德格尔强调这种“尚未”是事物自身运动和发展的构成性因素。

- **存在 (Being / Sein)**：在海德格尔哲学中，存在不是静态的属性，而是事物“如何是”的方式，是动态的、时间性的展开过程。在本段，果实的存在即体现为“趋向成熟”这一动态过程。

- **此在 (Dasein)**：特指“人的存在”。此在的本质在于它的“去存在”（Zu-sein），即它总是处在筹划、实现自身可能性的过程中。本段末尾将此在与果实的成熟过程类比，说明此在的存在结构也内在包含“尚未”。

### 2. 逐句转译

- “例如，不成熟的果子渐趋成熟。”  
  → 就像一颗还没熟的果子，它正在逐渐变熟。

- “在这种成熟过程中，果实尚未是的那种东西绝不是作为尚未现成的片段积拢到果实上来的。”  
  → 果子在变熟的过程中，它将来会成为的“成熟状态”，并不是像一个外来的零件那样，从外面拼装到果子上去的。

- “它自已把自己带向成熟，这一点标画出它作为果实的存在。”  
  → 是果子自己让自己走向成熟的，这一点恰恰定义了它作为一颗果子的存在方式。

- “如果果实不丛它本身方面趋向成熟，则一切可以附加上去的设想之事都无法消除这一存在者的不成熟。”  
  → 如果果子不是从自身内部主动趋向成熟，那么无论我们从外面给它附加多少“它应该熟了”的想象，都无法改变它实际上没熟的事实。

- “不成熟的这种尚未并非意指一种悬搁在外的它者，仿佛这个它者可以以对果实无所谓的方式依它和共它现成存在。”  
  → “不熟”这种“还没……”的状态，并不是一个和果子没关系、悬在外面的东西，好像这个外在的东西可以随意地跟果子放在一起，也可以不放在一起。

- “不成熟这种尚未在果实特有的存在方式中意指着果实本身。”  
  → “不熟”作为“还没……”的状态，恰恰是在果子独特的存在方式中，指向了果子自身。

- “尚未充盈的总额作为一种上手事物对欠缺的未上手的余额是‘无所谓的’。”  
  → （这里海德格尔用了一个对比：）比如一笔还没凑齐的钱，作为一件“待办事项”，它对那笔还没到账的余额是“无所谓”的——因为钱只是被动等待凑齐。

- “严格说来它对之既不是无所谓的也不是有所谓的。但不仅正在成熟的果实对不成熟这样一种它自己的它者不是无所谓的，而且它就在成熟过程中是这种不成熟。”  
  → 严格来说，果子对它自己的“不熟”状态，不是“无所谓”能形容的。它不仅不是无所谓，它甚至可以说，在成熟的过程中，它本身“就是”这种不成熟。

- “尚未已经被包括到果实的本已存在之中；这时它绝不是作为随随便便的规定性，而是作为组建因素。”  
  → “还没熟”这个状态，已经被包含在果子最本真的存在之中了；它不是一种可有可无的属性，而是构成它存在的关键因素。

- “与此相当，只要此在存在，它也向来已是它的尚未。”  
  → 与此类似，只要人（此在）存在，他也向来就已经是他的“尚未”——他总处在“还未完成”的状态，并朝着未来的可能性生活。

### 3. 论证逻辑梳理

1. **前提**：以果实的成熟过程为例，说明“尚未”（不成熟）不是外在的、可附加的属性。
2. **推进一**：论证果实是“自己使自己成熟”的，其“尚未成熟”是它自身存在方式的构成部分，而非外在缺失。
3. **对比分析**：用“未凑齐的钱”作反例，说明有些“尚未”是外在的、被动等待的；但果实的“尚未”是内在的、主动构成的。
4. **核心论断**：果实不仅“有”不成熟，它在成熟过程中“就是”不成熟——尚未是它存在的内在组建因素。
5. **类比推广**：将这一结构应用于“此在”（人），指出人只要存在，就内在包含着他的“尚未”（未实现的可能性和未来）。

### 4. 整体概括

这段文字的核心在于阐明：事物的“尚未完成”状态（如果子没熟）不是外在的、可有可无的缺失，而是事物自身存在方式的内在构成部分。果子是自己走向成熟的，它的“不熟”恰恰是它作为“正在成熟的果子”的本质体现。海德格尔借此说明，人（此在）的存在也是如此：我们总是“已经在途中”，我们的“尚未实现”不是外在的欠缺，而是我们不断朝向未来、实现自身可能性的生存结构本身。存在，就是这种包含“尚未”的、动态的展开过程。

### 5. 争议与说明

本段解读相对一致，是海德格尔用日常例子引入其核心时间性概念的典型段落。可能的细微争议点在于：

- **类比的有效性**：有学者质疑将有机生命的“成熟”直接类比于此在的“时间性”是否恰当，认为这可能模糊了此在的“筹划”与生物“生长”的本质区别。
- **“尚未”的主动性**：另一种解读更强调此在的“尚未”是透过“操心”和“筹划”主动承担的，而果实的成熟更多是生物学过程，二者在“能动性”层面存在张力。

但主流解读仍认为，此处的核心在于通过鲜活例子揭示“尚未作为存在之内在组建因素”这一结构，类比在直观教学层面是成功且有效的。

\end{solution}
