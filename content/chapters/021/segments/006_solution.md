## 题目 (6.txt)

如果现在追问，在认识本身的现象实情中自行显现出来的是什么，那么就可以确定：认识本身先行地奠基于“已经寓于世界的存在”中——而这一存在方式就在本质上组建着此在的存在。这种“已经依寓”首先不仅仅是对一个纯粹现成的东西的瞠目凝视。在世作为操劳活动乃沉迷于它所操劳的世界。为了使对现成事物的观察式的规定性认识成为可能，首须“操劳着同世界打交道”的活动发生某种残断。从一切制做、操作等等抽手不干之际，操劳便置身于现在还仅剩的“在之中”的样式中，即置身于“还仅仅延留在某种东西处”这种情况中。这种向着世界的存在方式乃是这样一种存在方式：在世界内照面的存在者只还在其纯粹外观中来照面。而只有基于这种向着世界的存在方式，并且作为这种存在方式的一种样式，才可能以明确的形式“观察”如此这般照面的存在者。这种观察总已选定了某种特定的方向去观望某种东西，总已瞄准了某种现成的东西。它先就从照面的存在者那里取得了一种“着眼点”。这种观望自行进入一种样式：独立持留于世界内的存在者。在如此这般发生的“滞留”中——这种滞留乃是对所有操作和利用的放弃——发生对现成东西的知觉。知觉的完成方式是把某某东西看作某种东西，把它作为某种东西来谈论。在解释这种最广泛意义的基础上，知觉就变为规定。被知觉的东西和被规定的东西可以在语句中被说出，于是就作为这样被道出的东西保持和保存下来。有所知觉地保持关于某某东西的命题，这本身就是在世的一种方式，而不可被阐释为这样一种“过程”，仿佛通过这种过程某个主体获得了关于某某东西的表象，它们作为如此被据为己有的表象始终保留“在内”，于是对这些表象来说可能会发生出它们如何同现实“相符合”的问题来。

\begin{solution}

### 1. 术语释义

- **认识 (Erkennen / cognition)**: 在海德格尔哲学中，认识并非首要或孤立的主体活动，而是**此在**在世界中生存的一种派生模式。它基于更原初的“在世存在”。
- **此在 (Dasein)**: 指人的存在，其本质在于“去存在”，其核心结构是“在世之中”。
- **在世 (In-der-Welt-sein / Being-in-the-world)**: 此在最基本的存在方式，意味着人从来都不是一个孤立的主体，而是已经并始终与一个充满意义的**世界**纠缠在一起。
- **寓于世界的存在 (Being-already-alongside-the-world)**: 此在先天就沉浸在世界之中，与世界内的存在者打交道。这是认识得以可能的基础。
- **操劳 (Besorgen / concern)**: 此在在日常世界中与器物打交道的原初方式，是充满实践目的的活动（如使用、制作、处理），而非静观。
- **现成东西 (Vorhandenes / present-at-hand)**: 以 detached 的、理论凝视的姿态所遭遇的对象，仿佛它只是摆在那里、拥有固定属性的客体。这是传统认识论默认的对象模式。
- **照面 (Begegnen / encountering)**: 存在者以此在某种存在方式中显现自身。
- **知觉 (Wahrnehmung / perception)**: 在此指一种已经包含了理解和解释的“看”，总是“把某物看作某物”，而非感官数据的被动接收。
- **命题/语句 (Aussage / assertion)**: 将被知觉和规定的东西以语言形式表达并固定下来。

### 2. 逐句转译

1.  **原文**: 如果现在追问，在认识本身的现象实情中自行显现出来的是什么，那么就可以确定：认识本身先行地奠基于“已经寓于世界的存在”中——而这一存在方式就在本质上组建着此在的存在。
    *   **转译**: 如果我们仔细观察“认识”这种现象本身，就会发现一个基本事实：认识活动并不是起点，它早就植根于一种“已经生活在世界之中”的存在状态——而这种与世界打交道的状态，恰恰构成了人之为人的根本方式。

2.  **原文**: 这种“已经依寓”首先不仅仅是对一个纯粹现成的东西的瞙目凝视。
    *   **转译**: 这种“已经在世界中”的状态，最初并不是像一个旁观者那样，呆呆地凝视着一个已经完工、摆在面前的客体。

3.  **原文**: 在世作为操劳活动乃沉迷于它所操劳的世界。
    *   **转译**: 人活在世上，首先是忙于各种事务，全身心地投入到他所关心的世界里（比如工作、使用工具），而不是在冷眼旁观。

4.  **原文**: 为了使对现成事物的观察式的规定性认识成为可能，首须“操劳着同世界打交道”的活动发生某种残断。
    *   **转译**: 要想获得那种理论性的、观察并定义对象的知识，首先必须让这种忙碌的、实践性的活动“中断”或“暂停”下来。

5.  **原文**: 从一切制做、操作等等抽手不干之际，操劳便置身于现在还仅剩的“在之中”的样式中，即置身于“还仅仅延留在某种东西处”这种情况中。
    *   **转译**: 当我们从所有制作、操作等实践活动中抽身而出时，我们与世界打交道的方式就转变为一种剩余的模式：仅仅是“停留在某物旁边”，不再使用它，只是看着它。

6.  **原文**: 这种向着世界的存在方式乃是这样一种存在方式：在世界内照面的存在者只还在其纯粹外观中来照面。
    *   **转译**: 在这种面对世界的模式中，我们遇到的事物，只以其纯粹的外观呈现给我们（比如，锤子不再是可以敲钉子的工具，而只是一个有着特定形状、颜色的物体）。

7.  **原文**: 而只有基于这种向着世界的存在方式，并且作为这种存在方式的一种样式，才可能以明确的形式“观察”如此这般照面的存在者。
    *   **转译**: 只有在这种（抽身出来的）与世界打交道的方式基础上，并且作为这种方式的一种具体表现，我们才能进行明确形式的“观察”，去审视如此显现的事物。

8.  **原文**: 这种观察总已选定了某种特定的方向去观望某种东西，总已瞄准了某种现成的东西。
    *   **转译**: 这种观察总是已经预先选择了某个特定的角度去看待事物，总是已经将某物当作一个摆在面前的、固定的对象来瞄准。

9.  **原文**: 它先就从照面的存在者那里取得了一种“着眼点”。
    *   **转译**: 在观察之初，它就已经从遇到的事物那里获得了一个特定的“观察视角”或“切入点”。

10. **原文**: 这种观望自行进入一种样式：独立持留于世界内的存在者。
    *   **转译**: 于是，这种观看就固定成了一种模式：持久地、独立地停留在世界中的那个存在者（对象）身上。

11. **原文**: 在如此这般发生的“滞留”中——这种滞留乃是对所有操作和利用的放弃——发生对现成东西的知觉。
    *   **转译**: 在这种发生的“滞留”中——也就是放弃了所有实际操作和利用之后——对那个作为现成对象的事物的“知觉”就产生了。

12. **原文**: 知觉的完成方式是把某某东西看作某种东西，把它作为某种东西来谈论。
    *   **转译**: 知觉的达成，总是“把某个东西看作是某个东西”（例如，把屏幕上的光点看作文字），并且能够将其作为某种东西来谈论。

13. **原文**: 在解释这种最广泛意义的基础上，知觉就变为规定。
    *   **转译**: 在这种最宽泛的“理解性看待”的基础上，知觉就进一步变成了“规定”，即明确界定对象的属性是什么。

14. **原文**: 被知觉的东西和被规定的东西可以在语句中被说出，于是就作为这样被道出的东西保持和保存下来。
    *   **转译**: 被知觉和规定的对象，可以通过语句被说出来（例如，“这是一个红色的立方体”），于是它就以这种被言说的形式被固定和保存下来。

15. **原文**: 有所知觉地保持关于某某东西的命题，这本身就是在世的一种方式，而不可被阐释为这样一种“过程”，仿佛通过这种过程某个主体获得了关于某某东西的表象，它们作为如此被据为己有的表象始终保留“在内”，于是对这些表象来说可能会发生出它们如何同现实“相符合”的问题来。
    *   **转译**: 这种有所知觉地持有关于某物的命题，其本身就是人存在于世界的一种方式。绝不能把它解释成这样一种“过程”：好像一个孤立的主体先获得了关于外界事物的内心表象（或意象），这些表象被主体占有并存储在“内心”之中，然后才会产生出这些内心表象如何与外部“现实”相符的问题。

### 3. 论证逻辑梳理

1.  **前提/论点**：从现象学审视“认识”，发现其根基在于“已经寓于世界的存在”（此在的本质结构）。
2.  **对比与深化**：阐明这种原初的“寓于”不是理论凝视，而是实践的“操劳”，是沉迷于世界的活动。
3.  **关键转折**：指出理论认识（观察规定）的可能性条件，在于实践操劳活动的“中断”。只有从使用中抽身，事物才作为“纯粹外观”（现成东西）显现。
4.  **描述理论认识的发生过程**：
    *   中断操劳 → 进入“仅仅延留”的存在模式。
    *   在此模式下，事物仅以“纯粹外观”照面。
    *   基于此模式，明确的“观察”得以可能。
    *   观察总是有角度（着眼点）且针对“现成东西”。
    *   观察固化为“滞留”于对象。
    *   在滞留中，发生“知觉”（看作某物）。
    *   知觉基于解释，并发展为“规定”。
    *   规定可通过“语句”被说出和保存。
5.  **最终结论与批判**：保有命题（知识）本身就是在世的一种方式。**批判传统认识论模型**：知识不是主体内部表象与外部现实符合的过程，而是此在在世的一种衍生样式。由此消解了“内部表象如何符合外部世界”这个伪问题。

### 4. 整体概括

这段文字的核心在于**解构传统认识论，并将认识重新植根于此在的生存论结构之中**。海德格尔认为，我们通常所理解的理论知识（观察、规定、命题）并非起点，而是从一个更原初、更基本的层面派生出来的。这个原初层面就是人与世界打交道的日常实践生活（“操劳”）。当我们暂时停下手中的活计，从实践参与中抽离出来，世界中的事物才以一种可供观察和定义的“纯粹对象”样貌呈现给我们。随后的一系列认知活动——知觉、规定、形成命题——都发生在这个已经转变了的与世界的关系之中。因此，知识并不是一个孤立的主体去准确描绘一个外部客体的过程，而是人（此在）存在于世界的一种特定模式。传统哲学纠结的“内心想法如何匹配外界事物”的问题，在海德格尔看来，是因为错误地将这种派生性的认知模式当成了起点，忽略了人最初就“已经在世界之中”这一根本事实。

### 5. 争议与说明

本段解读相对一致，是海德格尔基础存在论的核心论证之一。可能的细微讨论点在于对“残断”程度的理解：这种从操劳到理论态度的转变，是彻底的断裂，还是一种存在关注焦度的调制？但主流解读倾向于认为这是一种存在方式的“样式变更”，而非创造了一种全新的、无世界的主体。海德格尔的核心目的始终是揭示理论的生存论根源，论证方向是明确的。
