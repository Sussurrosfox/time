## 题目 (7.txt)

看起来，还有什么比描述生死之间的“生命联系”来得“更简单”呢？这一“生命联系”由“在时间中”一一相继的体验组成。若更深入一步来察看对这种成问题的联系的描述，尤其是查看一下其中包含的存在论先见，结果就会发现一些值得注意的东西。在这一一相续的体验中，“真正说来”向来只有“在各个现在中”现成的体验是“现实的”。过去的以及还待来临的体验则相反不再是或还不是“现实的”。在两条界限之间的一段时间〔Zeitspan〕是赋予此在的，此在遍历这段时间的方式是：它向来只在现在是“现实的”，就仿佛把它的“时问”的一一相续的现在都跳跃一遍。所以人们说，此在是“时间性的”。在体验的这种不断变化之中，自身始终保持在某种一定的自一性中。在如何规定这种持久的东西及其与体验变化所可能具有的联系之际，意见开始发生分歧。这一持久的变化着的体验联系的存在则始终未予规定。但在这样描述生命联系的时候，无论人们是否愿意承认，其实都已设置了一个“在时间中”现成的东西，虽然不言而喻地是一个“非物性的东西”。

\begin{solution}

### 1. 术语释义

- **生命联系**：在海德格尔哲学中，泛指此在（Dasein）在世存在的一种整体性结构，表现为体验、行动与理解的前后关联。在本段中，它特指一种被传统哲学误解为“在时间中相继发生的体验序列”的存在方式。
- **此在**：海德格尔哲学的核心概念，指人的存在方式，其本质在于“去存在”，即不断筹划、理解自身可能性，而非一个现成的实体。本段中，此在被传统观点误解为“只在现在是现实的”存在者。
- **现在**：指流俗时间观中的“当前时刻”，被视为唯一“现实”的时间点，过去和未来则被视为“不现实”。海德格尔批判这种将时间碎片化的观点。
- **现实的**：在本段语境中，是流俗时间观中的概念，指“正在发生、可被直接把握”的状态。海德格尔认为这恰恰遮蔽了此在的真实时间性。
- **时间性的**：在海德格尔哲学中，此在的本质是“时间性”，意味着此在的存在本身就是时间化的过程，而非仅仅“在时间中”。但本段中，它被传统观点曲解为此在只是经历一系列“现在”点的存在者。
- **自一性**：指某种自我同一性、持续不变的同一状态。本段中，它是在传统观点下被视为在体验流变中保持不变的“基底”。

### 2. 逐句转译

- “看起来，还有什么比描述生死之间的‘生命联系’来得‘更简单’呢？这一‘生命联系’由‘在时间中’一一相继的体验组成。”  
  → 表面上，描述人从生到死的生命历程似乎很简单，人们通常把它理解为一连串在时间中先后发生的体验。

- “若更深入一步来察看对这种成问题的联系的描述，尤其是查看一下其中包含的存在论先见，结果就会发现一些值得注意的东西。”  
  → 但如果仔细审视这种描述背后预设的哲学观念，就会发现有问题。

- “在这一一相续的体验中，‘真正说来’向来只有‘在各个现在中’现成的体验是‘现实的’。过去的以及还待来临的体验则相反不再是或还不是‘现实的’。”  
  → 在这种观点下，只有当下此刻的体验才被视为“真实存在”，过去和未来的体验则被认为是“不真实”的。

- “在两条界限之间的一段时间是赋予此在的，此在遍历这段时间的方式是：它向来只在现在是‘现实的’，就仿佛把它的‘时间’的一一相续的现在都跳跃一遍。”  
  → 人生被看作一段从出生到死亡的时间段，人活着就像从一个“现在”跳到下一个“现在”，只有当前这一刻才算数。

- “所以人们说，此在是‘时间性的’。”  
  → 因此人们就认为，人的存在是“有时间性的”。

- “在体验的这种不断变化之中，自身始终保持在某种一定的自一性中。”  
  → 尽管体验不断变化，但人们认为有一个不变的“自我”贯穿始终。

- “在如何规定这种持久的东西及其与体验变化所可能具有的联系之际，意见开始发生分歧。”  
  → 当要说明这个不变的“自我”是什么，以及它如何与变化的体验关联时，各种理论就产生分歧了。

- “这一持久的变化着的体验联系的存在则始终未予规定。”  
  → 但这种“生命联系”本身的存在方式（它到底是什么）却一直没有被真正说清楚。

- “但在这样描述生命联系的时候，无论人们是否愿意承认，其实都已设置了一个‘在时间中’现成的东西，虽然不言而喻地是一个‘非物性的东西’。”  
  → 关键在于，这种描述其实偷偷预设了一个前提：生命是一个“在时间中”已经摆在那里的东西——虽然他们嘴上说它不是物质实体。

### 3. 论证逻辑梳理

- **前提**：人们通常认为描述生命联系很简单，即把它看作时间中相继的体验序列。
- **分析推进**：
  1. 揭示这种描述背后的预设：只有“现在”是现实的，过去和未来不是。
  2. 指出这种观点将此在的存在方式理解为不断跳跃的“现在点”的集合。
  3. 尽管承认体验流变中有某种“自一性”，但这种自一性的本质及其与体验的关系众说纷纭。
  4. 最关键的是，这种生命联系本身的存在方式从未被真正追问。
- **结论**：这种看似简单的描述，实际上不自觉地预设了此在是一个“在时间中现成存在”的东西——这正是海德格尔要批判的传统存在论错误。

### 4. 整体概括

这段文字是海德格尔对传统时间观和生命观的批判。他指出，人们通常把生命看作在时间中一连串先后发生的体验，只有“现在”被认为是真实的。这种观点将人生理解为从一个“现在点”跳到下一个“现在点”，虽然承认有一个不变的“自我”贯穿其中，但这个自我是什么以及它如何与变化体验关联，却说法不一。更根本的问题是，这种描述从未真正追问生命联系本身的存在方式，而是在不自觉中预设了生命是一个“在时间中已经摆在那里”的现成物——这正是海德格尔认为的传统哲学的根本错误：误解了此在的真实存在方式。

### 5. 争议与说明

本段解读相对一致，是海德格尔对传统流俗时间观的典型批判。可能的细微争议在于对“自一性”的理解：有学者认为这里海德格尔暗示了此在的“持存性”问题，但主流解读仍聚焦于他对“现成性”预设的揭露。

\end{solution}
