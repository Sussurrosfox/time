## 题目 (22.txt)

在描述从“实践地”寻视着的操作、使用及诸如此类到“理论”研究的转折时，下述方式最为近便：对存在者的纯观看是由于操劳从当下操作抽身而发生的。于是乎，理论态度“发生”的关键就在于“实践”的消失：恰恰是当人们把“实践”操劳设为实际此在的首要的和占统治地位的存在方式之时，“理论”的存在论可能性就被归因于实践的阙然，亦即归因于一种阙失。然而，在操劳打交道之际，一种特定操作的中断并不就让引导这操作的寻视简简单单地作为一种残剩物留在后面。这时，操劳活动倒毋宁特特试着仅仅左寻右视。但这还绝未达到“理论的”科学态度。相反，那中止操作的延留可以取得一种更尖锐的寻视的性质：作为“反顾”，作为对已达到的东西的翻检，作为对这时“停顿下来的活动”的综观。从用具的使用抽身，这还远不已经是“理论”；延留着、“考察着”的寻视还完全附于所操劳的上手用具。“实践的”打交道有它本己的延留方式。就像实践具备其特有的视〔“理论”〕一样，理论研究也并非没有它自己的实践。收取实验所产生的数据往往需要错综复杂的“技术性”工作来建立实验程序。显微镜观察依赖于“被检验标本”的制作。在考古学中，挖掘工作先行于对“发现”的阐释，而挖掘工作要求最粗拙的操作。但就连研究问题、确立已获得的东西这一类“最抽象的”工作，也要使用书写用具之类进行操作。对科学研究来说，这些组成部分尽可以是“无趣的”和“不言而喻的”，但它们在存在论上却绝非无关紧要。指出科学行为作为在世的一种方式并非仅是“纯精神活动”，这可以被看作琐碎或多余。但愿人们无须涉此琐碎就会明白：“理论”行为与“非理论”行为之间的存在论界线真正该在哪里划分还绝不曾大白于天下呢!

\begin{solution}

### 1. 术语释义

- **寻视**：在海德格尔哲学中，指此在（人的存在）在日常实践活动中对周遭世界的关切性观看。它不是一种纯粹的视觉观察，而是带有目的导向的、融于操作中的理解方式。在本段中，寻视是实践活动的核心认知方式，即使在实践中断时也不会简单消失。

- **操劳**：此在在世存在的基本方式，指人忙于与用具打交道的日常实践活动。操劳总是关乎用具的“上手状态”，即事物作为被使用的工具而非被审视的对象而存在。本段中，操劳是理论态度得以“发生”的背景。

- **理论态度**：一种脱离直接实践、对存在者进行纯粹观看的存在方式。在本段中，海德格尔要批判的正是那种将理论视为“实践消失之结果”的流俗观点。

- **上手状态**：事物作为被熟练使用的工具而呈现的存在方式，与“现成状态”（作为被观察的客体）相对。在本段中，即使实践中断，寻视仍可能停留在对上用具的关涉中，尚未达到真正的理论态度。

- **此在**：指人的存在，其本质是“在世界之中存在”。本段中，科学研究被揭示为此在在世的一种方式，而非脱离世界的“纯精神活动”。

### 2. 逐句转译

- “在描述从‘实践地’寻视着的操作、使用及诸如此类到‘理论’研究的转折时，下述方式最为近便：对存在者的纯观看是由于操劳从当下操作抽身而发生的。”  
  → 当我们想说明人如何从日常实践转向理论研究时，最方便的说法是：那种纯粹的观察，是因为人从手头的活动中抽身出来才发生的。

- “于是乎，理论态度‘发生’的关键就在于‘实践’的消失：恰恰是当人们把‘实践’操劳设为实际此在的首要的和占统治地位的存在方式之时，‘理论’的存在论可能性就被归因于实践的阙然，亦即归因于一种阙失。”  
  → 这样一来，理论态度的出现关键就在于实践的消失。尤其是当人们认为实践是人生在世的根本方式时，理论的可能性就被解释为实践的缺席，是一种缺失。

- “然而，在操劳打交道之际，一种特定操作的中断并不就让引导这操作的寻视简简单单地作为一种残剩物留在后面。”  
  → 但是，在日常实践活动中，某个操作的中断并不会让指导这个操作的寻视简单地作为残留物留下来。

- “这时，操劳活动倒毋宁特特试着仅仅左寻右视。但这还绝未达到‘理论的’科学态度。”  
  → 这时候，操劳活动反而会试着继续东看西看，但这还远远不是理论性的科学态度。

- “相反，那中止操作的延留可以取得一种更尖锐的寻视的性质：作为‘反顾’，作为对已达到的东西的翻检，作为对这时‘停顿下来的活动’的综观。”  
  → 相反，这种暂停操作的停留可以变成一种更犀利的寻视：它成为一种回顾，对已经完成的东西进行检查，对此刻“停顿下来的活动”进行整体审视。

- “从用具的使用抽身，这还远不已经是‘理论’；延留着、‘考察着’的寻视还完全附于所操劳的上手用具。”  
  → 仅仅从用具使用中抽身，还远远不是理论；这种停留着的、考察着的寻视仍然完全依附于正在被使用的用具。

- “‘实践的’打交道有它本己的延留方式。就像实践具备其特有的视〔‘理论’〕一样，理论研究也并非没有它自己的实践。”  
  → 实践性的活动有它自己特有的停留方式。就像实践本身就有它自己的观看方式（这甚至可称为一种“理论”）一样，理论研究也并非没有自己的实践。

- “收取实验所产生的数据往往需要错综复杂的‘技术性’工作来建立实验程序。显微镜观察依赖于‘被检验标本’的制作。在考古学中，挖掘工作先行于对‘发现’的阐释，而挖掘工作要求最粗拙的操作。”  
  → 收集实验数据常常需要复杂的技术性工作来建立实验程序。用显微镜观察依赖于制作标本。在考古学中，挖掘工作先于对发现的解释，而挖掘工作本身需要最粗糙的操作。

- “但就连研究问题、确立已获得的东西这一类‘最抽象的’工作，也要使用书写用具之类进行操作。”  
  → 但即使是研究问题、确认研究成果这种“最抽象”的工作，也需要使用书写工具等操作。

- “对科学研究来说，这些组成部分尽可以是‘无趣的’和‘不言而喻的’，但它们在存在论上却绝非无关紧要。”  
  → 对科学研究来说，这些部分可能被认为是无趣和不言自明的，但从存在论的角度看，它们绝不是无关紧要的。

- “指出科学行为作为在世的一种方式并非仅是‘纯精神活动’，这可以被看作琐碎或多余。”  
  → 指出科学行为作为在世的一种方式并非仅仅是“纯精神活动”，这可能会被认为是琐碎或多余的。

- “但愿人们无须涉此琐碎就会明白：‘理论’行为与‘非理论’行为之间的存在论界线真正该在哪里划分还绝不曾大白于天下呢!”  
  → 但愿人们不需要通过这种琐碎的说明就能明白：理论行为与非理论行为之间的存在论界线究竟在哪里，这个问题还远未被弄清楚！

### 3. 论证逻辑梳理

- **前提**：流俗观点认为理论态度的产生是由于从实践活动中“抽身”，将理论视为实践的“缺失”。
- **转折分析**：海德格尔指出，实践的中断并不简单地让寻视消失，而是可能转化为一种更尖锐的寻视（反顾、翻检、综观）。
- **关键论证**：仅仅从用具使用中抽身并不就是理论，因为寻视仍然依附于上手用具。实践有自己的“视”（观看方式），理论也有自己的实践。
- **例证支撑**：通过科学实验、显微镜观察、考古挖掘、书写等例子，证明即使最“抽象”的理论研究也包含具体的实践操作。
- **结论**：理论行为与非理论行为的存在论界线远比流俗观点认为的复杂，这个问题尚未得到澄清。

### 4. 整体概括

这段文字批判了那种将“理论”简单视为“实践”之缺席的流俗观点。海德格尔指出，当我们从日常实践中抽身时，并不会简单地进入“纯理论”状态，而是可能进入一种对实践活动的回顾性审视，这种审视仍然依附于实践世界。更重要的是，理论研究本身也包含大量的实践活动——从实验操作到书写记录。因此，理论并非与实践对立，而是以特定方式与实践交织在一起。海德格尔最终提醒我们，理论行为与非理论行为的存在论界限问题远未解决，需要我们重新思考。

### 5. 争议与说明

本段解读相对一致。海德格尔对理论与实践关系的重构是他基础存在论计划的重要组成部分，旨在打破传统哲学中理论与实践的二分割。学界普遍认同这是他对西方哲学传统的深刻批判。可能的细微争议在于如何准确理解“寻视”在实践中断时的转变性质，但这不影响对段落核心论点的把握。
