## 题目 (8.txt)

可定期状态的结构本质上属于借“现在”“而后”与“当时”得到理解的东西。这一点为被解释的东西源出于解释自身的时间性这回事提供了最基本的证明。只要说到“现在”，我们就总也已经领会着“某事正发生之际”，虽然这一点不必一道说出来。这是为什么呢？因为“现在”解释着存在者的某种当前化。在“现在正…”中有着当前的绽出性质。“现在”、“而后”与“当时”的可定期性是时间性的绽出建构的反照并因而对道将出来的时间本身也是本质性的。“现在”、“而后”与“当时”的可定期性的结构是一般证据，表明“现在”、“而后”与“当时”来自时间性而它们本身就是时间。有所解释地道出“现在”、“而后”与“当时”，这是最源始的列举时间。时间性随着可定期性得到领会，虽然未成为课题，未作为它本身得到认识，但因为在时间性的绽出统一中此在向来已作为在世的存在对它自己展开了，而世内存在者也随之一道得到了揭示，所以，得到解释的时间向来也已从随着此的展开状态来照面的存在者方面而具有某种定期：现在，门正撞上；现在，我正缺那本书；诸如此类。

\begin{solution}

### 1. 术语释义

- **可定期状态（Datierbarkeit）**：指时间表述（如“现在”、“而后”、“当时”）能够与具体事件或情境挂钩的特性。在海德格尔哲学中，时间不是抽象的刻度，而是通过我们在世的具体活动而被赋予内容和意义。

- **时间性（Zeitlichkeit）**：此在（Dasein，指人的存在）的根本存在方式，表现为过去、现在、未来的统一动态展开。它不是线性的时间流，而是此在筹划未来、承担过去、投入现在的生存结构。

- **绽出（Ekstase）**：时间性的三个维度（曾在、当前化、将来）不是静态的点，而是“向外站出”的开放状态，使此在能够超越当下、面向世界。时间性的“绽出统一”指这三个维度相互交织、共同构成此在的展开。

- **当前化（Gegenwärtigen）**：时间性的一个绽出环节，指此在让事物作为“在场”或“正在发生”而照面的方式。它不是客观的“现在”时刻，而是与我们的活动和关注紧密相连。

- **此在（Dasein）**：指人的存在方式，其本质在于“去存在”（Zu-sein），总是已经在世界中并与事物、他人打交道。此在通过时间性展开自身与世界。

- **在世的存在（In-der-Welt-sein）**：此在的基本建构，表示人始终已经嵌入并参与到世界之中，无法脱离世界而孤立存在。

### 2. 逐句转译

- **第一句**：“可定期状态的结构本质上属于借‘现在’‘而后’与‘当时’得到理解的东西。”  
  → 我们之所以能理解“现在”、“以后”、“以前”这些时间表述，是因为它们天然地能够被赋予具体内容（即可定期性）。

- **第二句**：“这一点为被解释的东西源出于解释自身的时间性这回事提供了最基本的证明。”  
  → 这正好证明了：我们对时间的这些理解，其实根源于我们自身的存在方式——时间性。

- **第三句**：“只要说到‘现在’，我们就总也已经领会着‘某事正发生之际’，虽然这一点不必一道说出来。”  
  → 每当我们说“现在”，即使不明确说出来，其实已经隐含地理解了“有某件事正在发生”。

- **第四句**：“这是为什么呢？因为‘现在’解释着存在者的某种当前化。”  
  → 原因在于，“现在”这个表述，实际上是我们让某个事物作为“正在眼前发生”而呈现出来的方式。

- **第五句**：“在‘现在正…’中有着当前的绽出性质。”  
  → “现在正…”这样的说法，本身就体现了时间性中“当前化”这一维度的开放和动态特征。

- **第六句**：“‘现在’、‘而后’与‘当时’的可定期性是时间性的绽出建构的反照并因而对道将出来的时间本身也是本质性的。”  
  → “现在”、“以后”、“以前”能够被赋予具体内容，其实是时间性（过去-现在-未来的动态统一）的一种反射；因此，这种可定期性对于被我们说出来的时间而言是根本性的。

- **第七句**：“‘现在’、‘而后’与‘当时’的可定期性的结构是一般证据，表明‘现在’、‘而后’与‘当时’来自时间性而它们本身就是时间。”  
  → 可定期性这一结构，普遍地证明了：“现在”、“以后”、“以前”不仅来源于时间性，它们本身就是时间（的体现）。

- **第八句**：“有所解释地道出‘现在’、‘而后’与‘当时’，这是最源始的列举时间。”  
  → 当我们带着具体情境说出“现在如何”、“以后怎样”、“当时那样”，这就是最原本、最直接地指认时间的方式。

- **第九句**：“时间性随着可定期性得到领会，虽然未成为课题，未作为它本身得到认识，但因为在时间性的绽出统一中此在向来已作为在世的存在对它自己展开了，而世内存在者也随之一道得到了揭示，所以，得到解释的时间向来也已从随着此的展开状态来照面的存在者方面而具有某种定期。”  
  → 我们是通过可定期性来领会时间性的，虽然我们通常不会直接把时间性当作对象来研究。这是因为，在此在的时间性展开中，此在已经作为在世的存在向自己敞开了，同时世界中的事物也随之被揭示。因此，被我们解释的时间，总是已经从那些与我们照面的事物那里获得了某种具体定期的内容。

- **第十句**：“现在，门正撞上；现在，我正缺那本书；诸如此类。”  
  → 例如：“现在，门正在撞上”；“现在，我正缺那本书”；等等。

### 3. 论证逻辑梳理

- **前提**：我们日常使用的时间表述（“现在”、“而后”、“当时”）具有“可定期性”，即它们总是指向具体的事件或情境。
- **第一步**：分析“现在”的例子，揭示其隐含的“某事正发生”的领会，指出这源于时间性的“当前化”环节。
- **第二步**：将“可定期性”与时间性的“绽出建构”联系起来，论证前者是后者的“反照”，从而表明日常时间根源于更深层的时间性。
- **第三步**：进一步论断，可定期结构不仅证明日常时间来源于时间性，而且它们本身就是时间（的显现形式）。
- **第四步**：指出这种有所解释地道出时间是最源始的时间列举方式。
- **第五步**：解释为何时间性能通过可定期性被领会（即使未被主题化）：因为此在的时间性展开同时展开了自身和世界，使得被解释的时间天然地从照面的存在者那里获得定期。
- **结论/例证**：通过具体实例（“门正撞上”、“我正缺那本书”）展示日常时间如何总是与世内存在者和我们的活动紧密绑定。

### 4. 整体概括

这段文字的核心论点是：我们日常生活中所使用的“现在”、“以后”、“以前”这些时间表述，并非空洞的刻度，而是天生就能被填充进具体事件（即可定期性）。海德格尔认为，这一点恰恰证明了我们对时间的理解源自我们自身存在的根本结构——时间性。时间性是此在（人）动态地筹划未来、承担过去、投入现在的生存方式。当我们说“现在”时，即使不明说，也已经是在指涉某个正在发生的事件，这体现了时间性中“当前化”这一维度的作用。因此，日常时间的可定期性其实是时间性（过去-现在-未来统一体）的一种折射和体现。我们最源始地指认时间，就是在具体情境中说“现在如何”。最后，由于此在始终是在世界中存在，并在与事物打交道中展开自身，所以我们领会到的时间也总是从我们周遭的具体事物和情境中获得其内容和意义。

### 5. 争议与说明

本段解读相对一致。海德格尔在此旨在揭示流俗时间观（作为序列的现在）的存在论根源在于此在的时间性，这是《存在与时间》中的核心论证脉络之一，学界对此基本方向争议不大。可能的细微讨论点在于对“反照”（Widerschein）一词力度的理解：它是一种直接的“显现”，还是某种程度上的“衍生”或“变异”，但这通常不影响对段落核心思想的把握。
