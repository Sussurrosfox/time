## 题目 (17.txt)

我们的分析将从展示怕的时间性开始。怕曾被描述为非本真的现身情态。在何种程度上曾在是使怕成为可能的生存论意义？这种绽出的何种样式标识着怕所特有的时间性？怕是在某种具有威胁性质的东西面前害怕。我们曾描述过这种对此在的实际能在有害的东西怎样在操劳所及的上手事物与在手事物的范围内临近。害怕以日常寻视的方式开展这一威吓者。一个仅止直观的主体从不能揭示这样的东西。但“在…面前害怕”的这种展开不就是一种“让来到自己”吗？人们曾把怕规定为对某种来临的恶事的预期不是颇有道理吗？无庸争议，害怕不仅使自身“关系”到唯“在时间中”来临的东西这一含义上的“将来的东西”；而且这一自身关系本身在源始的时间性意义上就是将来的。怕的生存论时间性建制虽然一道包含有一种期备，但这首先只等于说：怕的时间性是非本真的时间性。“在…面前害怕”仅只是对某种来临的威胁者的预期吗？预期来临的威胁者无须乎已经是怕，仅仅预期它倒恰恰缺乏怕所特有的情绪性质。这种情绪性质在于：怕这种期备让威胁者回到实际操劳着的能在。只有当所回到的东西根本已经以绽出方式敞开着，威胁者才以回到我所是的存在者的方式被期备，于是此在才被威胁。有所害怕的期备“自己”害怕，亦即：“在…之前害怕”向来就是“因…害怕”；这其中就有怕的情绪性质与激动性质。怕的生存论时间性意义由一种自身遗忘组建起来；这种自身遗忘是：在本己的实际能在面前迷乱放溜，而被威胁的在世就作为这种迷乱放溜而操劳于上手事物。亚里士多德正确地把怕规定为〔一种抑制或迷乱〕。抑制把此在逼回到它的被抛境况，而其方式却恰恰是使被抛境况封闭起来。迷乱奠基于一种遗忘。在实际的下了决心的能在之前遗忘着放溜，这种活动附于先前就由寻视揭示开来的诸种自救与闪避的可能性，惧怕着的操劳活动因为遗忘自己并从而不掌握任何确定的可能性而从切近的可能性跳到切近的可能性。一切“可能的”可能性，亦即连不可能的可能性也包括在内，纷陈眼前。害怕的人不把定任何一个；“周围世界”并不消失，而是在不复在周围世界之中认出自己的境况下来照面。这种迷乱地把就近处最好的东西摆到当前的作法属于怕之中的自身遗忘。以人所周知的例子来说：房子失火时，住在里面的人经常去“救”最不相干的然而就近上手的什物。遗忘了自身而把一团乱七八糟东浮西飘的可能性摆在当前，这使得构成怕的情绪性质的那种迷乱成为可能。迷乱这种忘却也使期备改变其样式，使它的特性成为受到抑制的或迷乱的期备，这种期备当然与纯粹的预期有别。

\begin{solution}

### 1. 术语释义

- **怕（Furcht）**：在海德格尔哲学中，怕是一种非本真的现身情态（Befindlichkeit），指此在（人的存在）在面对具体威胁时的情绪反应。它让此在迷失于日常操劳的事物中，逃避自身的本真能在。
- **时间性（Zeitlichkeit）**：时间性是此在存在的根本结构，由曾在、当前化和将来三种绽出（Ekstasen）共同构成。它不同于线性时间，而是此在展开自身存在的方式。
- **现身情态（Befindlichkeit）**：此在总是已经处于某种情绪状态中，这种情绪揭示了此在“存在于世”的基本境况。
- **非本真（Uneigentlich）**：此在迷失于日常世界，逃避自身本真可能性的存在方式。
- **曾在（Gewesenheit）**：此在的过去不是已逝的片段，而是持续影响当前的存在维度。
- **绽出（Ekstase）**：时间性的三个维度（曾在、当前化、将来）不是孤立的时间点，而是相互交织、共同展开的“出离”状态。
- **期备（Gewärtigen）**：非本真的将来模式，此在被动等待或预期某个具体事件，而非主动承担自身的可能性。
- **自身遗忘（Selbstvergessenheit）**：此在在怕中迷失于日常事物，逃避对自身存在的清醒认识。
- **被抛境况（Geworfenheit）**：此在总是已经被抛入一个既定的世界，无法选择自己的起点和基本条件。
- **操劳（Besorgen）**：此在日常生活与上手事物打交道的非本真模式。
- **实际能在（ faktisches Seinkönnen）**：此在具体处境中的现实可能性。

### 2. 逐句转译

- “我们的分析将从展示怕的时间性开始。怕曾被描述为非本真的现身情态。”  
  → 我们先来探讨怕这种情绪的时间结构。之前我们说过，怕是一种非本真的情绪状态。

- “在何种程度上曾在是使怕成为可能的生存论意义？这种绽出的何种样式标识着怕所特有的时间性？”  
  → 我们要问：此在的“过去”（曾在）如何构成了怕的存在论基础？怕的时间性具体表现为时间结构的哪个方面？

- “怕是在某种具有威胁性质的东西面前害怕。我们曾描述过这种对此在的实际能在有害的东西怎样在操劳所及的上手事物与在手事物的范围内临近。”  
  → 怕就是面对某个威胁时的恐惧。我们之前分析过，这种威胁会出现在我们日常打交道的事物中，危害我们现实的可能性。

- “害怕以日常寻视的方式开展这一威吓者。一个仅止直观的主体从不能揭示这样的东西。”  
  → 怕是通过日常的操心活动来感知威胁的。一个纯粹旁观的主体无法真正理解这种威胁。

- “但‘在…面前害怕’的这种展开不就是一种‘让来到自己’吗？人们曾把怕规定为对某种来临的恶事的预期不是颇有道理吗？”  
  → 这种害怕的过程，不就是让威胁逼近自己吗？所以人们把怕定义为对即将到来的坏事的预期，是有道理的。

- “无庸争议，害怕不仅使自身‘关系’到唯‘在时间中’来临的东西这一含义上的‘将来的东西’；而且这一自身关系本身在源始的时间性意义上就是将来的。”  
  → 显然，怕不仅指向按钟表时间将要发生的事情，而且这种指向本身就是时间性中的“将来”维度在起作用。

- “怕的生存论时间性建制虽然一道包含有一种期备，但这首先只等于说：怕的时间性是非本真的时间性。”  
  → 怕的时间结构中确实包含预期，但这恰恰说明怕的时间性是非本真的。

- “‘在…面前害怕’仅只是对某种来临的威胁者的预期吗？预期来临的威胁者无须乎已经是怕，仅仅预期它倒恰恰缺乏怕所特有的情绪性质。”  
  → 但害怕仅仅是对威胁的预期吗？不是。单纯的预期并不构成怕，因为它缺少怕那种特有的情绪体验。

- “这种情绪性质在于：怕这种期备让威胁者回到实际操劳着的能在。”  
  → 怕的情绪特质在于：它让威胁与我们现实生活中的可能性联系起来。

- “只有当所回到的东西根本已经以绽出方式敞开着，威胁者才以回到我所是的存在者的方式被期备，于是此在才被威胁。”  
  → 只有当我们的存在本身已经展开，威胁才能以回到我们自身的方式被预期，我们才会真正感到受威胁。

- “有所害怕的期备‘自己’害怕，亦即：‘在…之前害怕’向来就是‘因…害怕’；这其中就有怕的情绪性质与激动性质。”  
  → 害怕的预期本身就是害怕，所以“对某物害怕”其实就是“因为某物而害怕”，这正体现了怕的情绪性和激动性。

- “怕的生存论时间性意义由一种自身遗忘组建起来；这种自身遗忘是：在本己的实际能在面前迷乱放溜，而被威胁的在世就作为这种迷乱放溜而操劳于上手事物。”  
  → 怕的时间性本质在于自我遗忘：我们在自己真正的可能性面前迷失方向，于是只能慌乱地抓住手头的事物来应对威胁。

- “亚里士多德正确地把怕规定为〔一种抑制或迷乱〕。抑制把此在逼回到它的被抛境况，而其方式却恰恰是使被抛境况封闭起来。迷乱奠基于一种遗忘。”  
  → 亚里士多德说得对，怕就是一种迷乱。这种迷乱把我们推回被抛境况，却又让我们无法真正认识它，因为迷乱基于遗忘。

- “在实际的下了决心的能在之前遗忘着放溜，这种活动附于先前就由寻视揭示开来的诸种自救与闪避的可能性，惧怕着的操劳活动因为遗忘自己并从而不掌握任何确定的可能性而从切近的可能性跳到切近的可能性。”  
  → 在真正的决心面前，我们因遗忘而慌乱，只能抓住那些日常活动中浮现的自保和逃避的可能。害怕的人因为没有自我把握，只能从一个近便的可能跳到另一个近便的可能。

- “一切‘可能的’可能性，亦即连不可能的可能性也包括在内，纷陈眼前。害怕的人不把定任何一个；‘周围世界’并不消失，而是在不复在周围世界之中认出自己的境况下来照面。”  
  → 所有可能的选择，甚至包括不可能的选择，都杂乱地出现在眼前。害怕的人无法专注任何一个；周围世界并没有消失，但我们却无法在其中认出自己。

- “这种迷乱地把就近处最好的东西摆到当前的作法属于怕之中的自身遗忘。以人所周知的例子来说：房子失火时，住在里面的人经常去‘救’最不相干的然而就近上手的什物。”  
  → 这种慌乱地把最近的东西当作救命稻草的做法，正是怕中的自我遗忘。就像众所周知的例子：房子着火时，人们常常去抢救最无关紧要但随手可拿的东西。

- “遗忘了自身而把一团乱七八糟东浮西飘的可能性摆在当前，这使得构成怕的情绪性质的那种迷乱成为可能。迷乱这种忘却也使期备改变其样式，使它的特性成为受到抑制的或迷乱的期备，这种期备当然与纯粹的预期有别。”  
  → 忘记自我而让各种杂乱的可能性充斥眼前，这造就了怕的迷乱特质。这种迷乱的遗忘也改变了预期的性质，使它成为受抑制的、混乱的预期，这与单纯的预期完全不同。

### 3. 论证逻辑梳理

**前提**：
- 怕是一种非本真的现身情态。
- 怕涉及对威胁的预期。

**推进过程**：
1. 首先确认怕确实包含对将来的预期，但这只是表面现象。
2. 进而指出单纯的预期不足以解释怕的情绪特质。
3. 深入分析怕的本质：它通过自我遗忘，让此在迷失于日常事物，逃避自身的本真能在。
4. 引用亚里士多德的观点佐证怕的迷乱特性。
5. 具体描述这种迷乱的表现：从一个个近便的可能性中慌乱跳跃，无法专注。
6. 用房子失火的例子形象说明这种迷乱行为。

**结论**：
- 怕的时间性本质是由自我遗忘构成的非本真时间性。
- 怕的预期不是单纯的预期，而是受抑制的、迷乱的预期。

### 4. 整体概括

这段文字深入剖析了“怕”这种情绪的时间性结构。海德格尔认为，怕不仅仅是对未来威胁的简单预期，而是一种更深层的存在状态。在怕中，我们因为逃避面对自己真实的可能性（本真能在），陷入了自我遗忘的状态，于是只能慌乱地抓住手边各种近便的可能性来应对威胁。就像房子着火时人们去抢救无关紧要的物品一样，这种迷乱的行为暴露了怕的非本真性：我们不是清醒地面对威胁，而是在慌乱中迷失自我。因此，怕的时间性不是纯粹的将来预期，而是一种由自我遗忘构成的、受抑制的非本真时间性。

### 5. 争议与说明

本段解读相对一致。海德格尔对怕的分析被视为对传统情绪理论的重大突破，将情绪从心理学层面提升到了存在论层面。学界普遍认同他对怕的时间性结构的分析，特别是将怕与非本真时间性、自我遗忘联系起来的部分。可能的细微争议在于对“期备”与“预期”的区分是否足够清晰，但这并不影响整体理解。
