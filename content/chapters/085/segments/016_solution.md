## 题目 (16.txt)

我们曾强调，诸种情绪虽在存在者层次上已为熟知，却并不曾就其源始的生存论作用得到认识。情绪被当作流变的体验，这些体验为“灵魂状态”的整体“染上色彩”。对于一种观察来说，具有消长流变性质的东西却属于生存的源始的持驻性。尽管如此，种种情绪却又该与“时间”有何共同之处呢？这些“体验”来而又去，“在时间中”相续而过；确认这回事是琐碎之举。当然有这回事，虽然这只是一种存在者层次上的心理学确认。有待完成的任务则是把有情绪状态的存在论结构在其生存论时间性建制中展示出来。而首先则只能设法使一般情绪的时间性得以视见。“现身原本奠基在曾在状态中”这一命题等于说：情绪的基本生存性质是一种“带回到…”。这一“带回到…”并非才刚产生出曾在状态，而是：现身为生存论分析公开出曾在的一种样式。从而，现身的时间性阐释不可能意在从时间性演绎出诸种情绪并使它们消散到纯粹的到时现象中。所要作的只是表明：若非基于时间性，诸种情绪在生存上所意味的东西及其“意味”的方式就都不可能存在。这里的时间性阐释限于怕和畏这两种在准备阶段已经分析过的现象。

\begin{solution}

### 1. 术语释义

- **情绪（Befindlichkeit / Attunement）**：在海德格尔哲学中，情绪并非指心理学上短暂的心理状态，而是指此在（人的存在）向世界敞开的一种基本方式。它揭示了此在“如何”存在于世，以及世界“如何”向此在显现。在本段中，情绪被强调为具有生存论上的源始性，并非流变的体验，而是与时间性结构紧密相关。

- **存在者层次（ontisch / ontic）**：指对实际存在的事实的、经验性的描述，属于日常或科学研究的层面。与之相对的是存在论（ontologisch）层次，关注存在本身的结构。本段指出，传统心理学对情绪的理解停留在存在者层次，未能触及其在生存论上的本质。

- **生存论（existenzial / existential）**：海德格尔用来分析此在存在结构的哲学方法。它关注的是此在的根本可能性与结构，而非具体经验内容。本段强调情绪具有“生存论作用”，即它在构成此在存在方式中的基础性地位。

- **时间性（Zeitlichkeit / Temporality）**：此在存在的根本结构，表现为“曾在—当前—将来”的统一整体。它不同于日常线性时间，而是此在展开其生存的动态过程。本段指出情绪必须基于时间性才能被理解。

- **现身（Befindlichkeit 的另一种译法，亦指情绪）**：在本段中，“现身”与“情绪”基本同义，强调此在通过情绪“发现自己已在世界中”的状态。

- **曾在状态（Gewesenheit / Having-been）**：时间性的一个维度，指此在“已经是的”那个存在，它不是过去的事实，而是持续影响当前的存在方式。本段指出情绪“奠基在曾在状态中”，意味着情绪总带着某种“被抛”的底色。

- **怕（Furcht / Fear）**与**畏（Angst / Anxiety）**：两种基本情绪。怕是对世内具体事物的恐惧，畏则是无具体对象的、对此在自身存在可能性的焦虑。海德格尔在前期已分析过两者，本段将以它们为例阐释情绪的时间性。

### 2. 逐句转译

- “我们曾强调，诸种情绪虽在存在者层次上已为熟知，却并不曾就其源始的生存论作用得到认识。”  
  → 我们之前说过，虽然情绪在日常生活中很常见，但人们从未真正理解它在构成人的存在方式上的根本作用。

- “情绪被当作流变的体验，这些体验为‘灵魂状态’的整体‘染上色彩’。”  
  → 通常人们把情绪看作是不断变化的心理感受，就像给内心状态“涂上颜色”一样。

- “对于一种观察来说，具有消长流变性质的东西却属于生存的源始的持驻性。”  
  → 但从生存论的角度看，这种看似变化无常的东西，实际上恰恰属于人最根本、最持久的存在结构。

- “尽管如此，种种情绪却又该与‘时间’有何共同之处呢？这些‘体验’来而又去，‘在时间中’相续而过；确认这回事是琐碎之举。”  
  → 你可能会问：情绪和时间能有什么关系？情绪体验来了又走，在时间中依次出现——指出这点太简单了。

- “当然有这回事，虽然这只是一种存在者层次上的心理学确认。”  
  → 没错，情绪确实在时间中流转，但这只是心理学的事实描述，没触及本质。

- “有待完成的任务则是把有情绪状态的存在论结构在其生存论时间性建制中展示出来。”  
  → 真正的任务是：揭示情绪的存在论结构是建立在时间性这个根基之上的。

- “而首先则只能设法使一般情绪的时间性得以视见。”  
  → 所以我们先要试着让大家“看到”情绪本质上是有时间性的。

- “‘现身原本奠基在曾在状态中’这一命题等于说：情绪的基本生存性质是一种‘带回到…’。”  
  → 说“情绪根植于曾在状态”，意思是：情绪的根本性质是一种“带回到……”的力量。

- “这一‘带回到…’并非才刚产生出曾在状态，而是：现身为生存论分析公开出曾在的一种样式。”  
  → 这种“带回到……”不是创造了“曾在”，而是情绪向我们的分析揭示出“曾在”是如何呈现的。

- “从而，现身的时间性阐释不可能意在从时间性演绎出诸种情绪并使它们消散到纯粹的到时现象中。”  
  → 所以，对情绪做时间性分析，不是为了从时间性推导出各种具体情绪，然后把情绪简化成抽象的时间现象。

- “所要作的只是表明：若非基于时间性，诸种情绪在生存上所意味的东西及其‘意味’的方式就都不可能存在。”  
  → 我们只想说明：如果没有时间性这个基础，情绪对人的存在所具有的意义，以及它呈现意义的方式，就都不可能。

- “这里的时间性阐释限于怕和畏这两种在准备阶段已经分析过的现象。”  
  → 这里的分析只限于“怕”和“畏”这两种情绪，因为它们之前已经讨论过了。

### 3. 论证逻辑梳理

1. **前提**：传统观点将情绪视为流变的心理体验（存在者层次的认识）。
2. **问题提出**：这种流变性与“生存的源始持驻性”形成张力，引出“情绪与时间有何关系”的疑问。
3. **否定浅层回答**：承认情绪在时间中流转是琐碎的心理事实，但强调这未触及存在论层面。
4. **任务转向**：真正任务是在生存论时间性中揭示情绪的结构。
5. **核心命题**：提出“情绪奠基在曾在状态中”，并解释这意味着情绪是一种“带回到…”的结构。
6. **澄清意图**：强调时间性阐释不是要消解情绪，而是要表明情绪的意义依赖于时间性。
7. **限定范围**：将具体分析限定于“怕”和“畏”这两种已分析的情绪。

### 4. 整体概括

这段文字的核心在于扭转我们对情绪的常识理解。海德格尔指出，情绪不是飘忽不定的心理色彩，而是人存在于世的根本方式，它深深地扎根于我们的时间性结构之中。尤其是“曾在状态”——我们无法选择的、已经被抛入的存在背景——构成了情绪的底色。情绪总是一种“带回到…”的力量，让我们以某种方式承载着自己的历史而存在。因此，不理解时间性，就不可能真正理解情绪对人的生存意味着什么。本文承诺将以“怕”和“畏”为例，来具体展示情绪与时间性的这种本质关联。

### 5. 争议与说明

本段解读相对一致。可能的细微争议点在于对“带回到…”（Zurückbringen auf...）的理解：  
- **主流解读**：这指的是情绪将此在带回到其被抛的“曾在”状态，使此在不得不面对它已经是的那个存在。  
- **其他可能解读**：有学者认为“带回到…”不仅指向被抛性，也可能暗示情绪具有唤醒此在对其整体生存境况觉悟的潜能。  
但整体上，对本段基本命题——“情绪奠基在曾在状态中”——的理解是学界共识。

\end{solution}
