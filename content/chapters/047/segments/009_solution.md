## 题目 (9.txt)

而自由空闲的好奇操劳于看，却不是为了领会所见的东西，也就是说，不是为了进入一种向着所见之事的存在，而俘牛为了看。它贪新鹜奇，仅止为了从这一新奇重新跳到另一新奇上去。这种看之操心不是为了把捉，不是为了有所知地在真相中存在，而只是为了能放纵自己于世界。所以，好奇的特征恰恰是不厚留于切近的事物。所以，好奇也不寻求闲暇以便有所逗留考察，而是通过不断翻新的东西、通过照面者的变异寻求着不安和激动。好奇因不肯逗留而操劳于不断涣散的可能性。好奇同叹为观止地考察存在者不是一回事，同〔惊奇〕不是一回事。对好奇来说，问题不在于被惊奇带入无所领会；好奇操劳于一种知，但仅止为了有所知而已。不逗留在操劳所及的周围世界之中和涣散在新的可能性之中，这是对好奇具有组建作用的两个环节。它们奠定了好奇现象的第三种本质性质—我们把这种性质称为丧失去留之所的状态。好奇到处都在而无一处在。这种在世样式崭露出日常此在的一种新的存在方式。此在在这种方式中不断地被连根拔起。


---

\begin{solution}

### 1. 术语释义

- **好奇**：海德格尔用此术语并非指日常意义上的求知欲，而是指一种**不安定、不停滞**的存在方式。它表现为不断追逐新奇事物，却从不深入理解或停留于任何事物之上。其本质是**逃避真正的领会**，只在表面上游移。
- **操劳**：此在（人）与世界打交道的基本方式，通常指日常活动中投入性的、有目的的忙碌。在本段中，好奇作为一种“操劳”，是此在逃避自身真实存在的一种非本真模式。
- **领会**：此在通过投身于事物而理解其意义的能力，是此在面向可能性的开放状态。好奇恰恰**缺乏**这种领会。
- **丧失去留之所**：好奇的此在无法在任何地方“停留”或“扎根”，总是处于一种无家可归、飘忽不定的状态。这是一种存在论上的无根状态。
- **此在**：指人的存在，其本质是“在世界之中存在”，并且总是关心自己的存在方式。

### 2. 逐句转译

- “而自由空闲的好奇操劳于看，却不是为了领会所见的东西，也就是说，不是为了进入一种向着所见之事的存在，而仅仅为了看。”  
  → 这种好奇看起来是在“看”世界，但它看的目的不是为了理解看到的东西，不是为了和看到的事物建立深刻的关系，而仅仅是为了“看”这个动作本身。

- “它贪新鹜奇，仅止为了从这一新奇重新跳到另一新奇上去。”  
  → 它追逐新奇，只是为了从一个新奇的东西，马上跳到下一个新奇的东西。

- “这种看之操心不是为了把捉，不是为了有所知地在真相中存在，而只是为了能放纵自己于世界。”  
  → 这种看背后的操心，不是为了抓住事物的本质，也不是为了生活在真相之中，而只是为了让自己在世界中放纵、漂流。

- “所以，好奇的特征恰恰是不厚留于切近的事物。”  
  → 所以，好奇的特点就是它从不停留在身边近处的事物上。

- “所以，好奇也不寻求闲暇以便有所逗留考察，而是通过不断翻新的东西、通过照面者的变异寻求着不安和激动。”  
  → 所以，好奇也不追求停下来仔细考察，反而是通过不断追逐新的、变化的东西，来寻求那种不安和刺激的感觉。

- “好奇因不肯逗留而操劳于不断涣散的可能性。”  
  → 好奇因为它拒绝停留，所以它忙着追逐各种不断分散、消散的可能性。

- “好奇同叹为观止地考察存在者不是一回事，同〔惊奇〕不是一回事。”  
  → 好奇和那种带着惊叹去深入考察事物不是一回事，和真正的“惊奇”也不是一回事。

- “对好奇来说，问题不在于被惊奇带入无所领会；好奇操劳于一种知，但仅止为了有所知而已。”  
  → 对于好奇来说，它不会被惊奇带入一种无法理解的境地；好奇也追求一种“知道”，但它只是为了“知道”这个状态本身，而不是为了真正的理解。

- “不逗留在操劳所及的周围世界之中和涣散在新的可能性之中，这是对好奇具有组建作用的两个环节。”  
  → “不停留在日常世界之中”和“不断分散到新的可能性之中”，这是构成好奇的两个基本环节。

- “它们奠定了好奇现象的第三种本质性质—我们把这种性质称为丧失去留之所的状态。”  
  → 这两个环节共同构成了好奇的第三个本质特征——我们称之为“丧失去留之所”，即失去能够停留之地的状态。

- “好奇到处都在而无一处在。”  
  → 好奇无处不在，但又哪里都不在（因为它从不真正扎根于任何地方）。

- “这种在世样式崭露出日常此在的一种新的存在方式。此在在这种方式中不断地被连根拔起。”  
  → 这种存在于世界的方式，揭示出日常此在的一种新的生存模式。在这种模式中，此在不断被连根拔起，无法安顿。

### 3. 论证逻辑梳理

- **前提**：海德格尔从描述“好奇”这种特定的“操劳”方式开始。他指出，好奇的本质是“看”，但这种看并非为了“领会”。
- **推进分析**：
  1.  他首先界定好奇的目的：不是为了理解，而是为了不断追逐新奇本身。
  2.  接着，他通过对比来澄清好奇的特征：它不停留、不考察，反而追求不安与激动。它忙于追逐不断“涣散”的可能性。
  3.  他进一步将好奇与真正的“叹为观止”和“惊奇”区分开来，强调好奇所追求的“知”是空洞的，仅为知而知。
- **核心论证与结论**：
  1.  他从上述分析中提炼出构成好奇的两个“组建环节”：a) 不逗留于切近的周围世界；b) 涣散于新的可能性。
  2.  这两个环节共同导致了好奇的第三个本质性质：“丧失去留之所”。这是一种存在论上的无根状态。
  3.  最终结论：好奇作为一种在世的样式，表现为“到处都在而无一处在”，它使得日常此在不断地“被连根拔起”，无法获得安定的存在。

### 4. 整体概括

这段话深刻地剖析了“好奇”作为一种非本真的存在方式。海德格尔指出，我们日常生活中常见的那种不停刷新闻、逛社交媒体、追逐热点的心态，就是一种“好奇”。这种心态表面上看是在积极地与世界互动（“操劳于看”），但其核心是逃避——逃避对事物的深入领会，逃避与切近事物建立深厚的联系，逃避承担起自身存在的责任。它只是为了追求新鲜刺激的体验本身，从一个热点跳到另一个热点，永远在移动，永远不扎根。最终，这种生活方式导致人“丧失去留之所”，感觉上好像哪里都去过、什么都看过，但实际上灵魂无处安放，生命处于一种不断“被连根拔起”的漂泊状态。这是一种深刻的现代性症候。

### 5. 争议与说明

本段解读相对一致。主要的讨论点在于如何将海德格尔的“好奇”概念精准地对应到现代生活的具体现象中。例如，对于“刷社交媒体”是否完全等同于海德格尔的“好奇”，可能存在细微的讨论空间，但将其核心特征——不停留、求新异、无领会——视为对现代人某种生存状态的深刻描绘，是学界的主流共识。

\end{solution}
